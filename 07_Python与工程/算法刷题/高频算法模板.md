# 高频算法模板

## 知识点解析

### 概述

高频算法模板用于把题目特征快速映射到可复用解法。面试时不能只背代码，需要先说明适用条件、维护的不变量、复杂度和边界，再写出简洁实现。本文集中整理数组、字符串、链表、树、图、堆、贪心和动态规划中最常出现的模式。

### 双指针

适用信号：有序数组、原地去重、两端夹逼、快慢指针、链表环。

```python
def two_sum_sorted(nums: list[int], target: int) -> tuple[int, int]:
    left, right = 0, len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return left, right
        if total < target:
            left += 1
        else:
            right -= 1
    return -1, -1
```

核心不变量是答案如果存在，始终位于 `[left, right]` 内。每次移动指针都要能排除一批不可能答案。

### 滑动窗口

适用信号：连续子数组或子串、最长或最短区间、至多或至少满足某个条件。

```python
def longest_unique_substring(s: str) -> int:
    last: dict[str, int] = {}
    left = 0
    answer = 0
    for right, char in enumerate(s):
        if char in last:
            left = max(left, last[char] + 1)
        last[char] = right
        answer = max(answer, right - left + 1)
    return answer
```

模板要点是右指针扩张窗口，条件不满足时移动左指针恢复合法性。先明确窗口表示什么，再决定何时更新答案。

### 前缀和

适用信号：区间和、子数组和等于目标值、频繁区间查询。

```python
def count_subarrays(nums: list[int], target: int) -> int:
    count = {0: 1}
    prefix = 0
    answer = 0
    for value in nums:
        prefix += value
        answer += count.get(prefix - target, 0)
        count[prefix] = count.get(prefix, 0) + 1
    return answer
```

区间 `[i, j]` 的和等于 `prefix[j] - prefix[i - 1]`。哈希表保存历史前缀和次数，可以把二重枚举降为 `O(n)`。

### 单调栈

适用信号：下一个更大或更小元素、左右第一个满足条件的位置、柱状图面积。

```python
def next_greater(nums: list[int]) -> list[int]:
    answer = [-1] * len(nums)
    stack: list[int] = []
    for i, value in enumerate(nums):
        while stack and nums[stack[-1]] < value:
            answer[stack.pop()] = value
        stack.append(i)
    return answer
```

栈中通常保存下标，便于计算距离。每个元素最多入栈和出栈一次，因此复杂度是 `O(n)`。

### 堆与 Top K

求最大的 K 个元素时维护大小为 K 的小根堆；求最小的 K 个元素时维护大根堆。

```python
import heapq


def top_k(nums: list[int], k: int) -> list[int]:
    if k <= 0:
        return []
    heap: list[int] = []
    for value in nums:
        if len(heap) < k:
            heapq.heappush(heap, value)
        elif value > heap[0]:
            heapq.heapreplace(heap, value)
    return heap
```

时间复杂度是 `O(n log k)`，适合 `k` 远小于 `n`。如果要求整体有序，还需要对结果额外排序。

### 链表

链表题优先考虑虚拟头节点、快慢指针和局部指针反转。

```python
def reverse_list(head):
    previous = None
    current = head
    while current:
        following = current.next
        current.next = previous
        previous = current
        current = following
    return previous
```

反转时必须先保存后继节点。处理删除头节点、合并链表等问题时，虚拟头节点能减少边界分支。

### 树的 DFS 与 BFS

```python
from collections import deque


def level_order(root) -> list[list[int]]:
    if root is None:
        return []
    queue = deque([root])
    levels = []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        levels.append(level)
    return levels
```

DFS 适合递归结构、路径与子树信息；BFS 适合层序和无权最短路。树形递归需要先明确函数返回值代表什么。

### 图搜索与拓扑排序

图搜索必须处理 `visited`，有向依赖问题优先考虑入度和拓扑排序。

```python
from collections import deque


def can_finish(count: int, edges: list[tuple[int, int]]) -> bool:
    graph = [[] for _ in range(count)]
    indegree = [0] * count
    for course, prerequisite in edges:
        graph[prerequisite].append(course)
        indegree[course] += 1

    queue = deque(i for i, degree in enumerate(indegree) if degree == 0)
    visited = 0
    while queue:
        node = queue.popleft()
        visited += 1
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)
    return visited == count
```

无权最短路使用 BFS；非负权单源最短路使用 Dijkstra；存在负权边时不能直接使用 Dijkstra。

### 贪心

贪心每一步选择当前看来最优的决策，只有能证明局部最优可导向全局最优时才成立。常见信号包括区间调度、最少次数、按某个关键字排序后选择。

证明通常采用：

- 交换论证：任意最优解都能交换成贪心选择而不变差。
- 领先法：贪心方案在每个前缀上都不落后。
- 反证法：假设最优解不包含贪心选择会产生矛盾。

### 动态规划

动态规划适合有最优子结构和重叠子问题的场景。固定回答顺序：

1. 定义状态。
2. 写状态转移。
3. 确定初始化。
4. 确定遍历顺序。
5. 分析复杂度和空间优化。

```python
def length_of_lis(nums: list[int]) -> int:
    if not nums:
        return 0
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

这里 `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度。定义必须包含足够信息，使下一步能够从已知状态转移。

### 面试编码检查清单

- 输入是否可能为空。
- 是否存在重复值、负数或溢出。
- 循环边界使用闭区间还是左闭右开。
- 是否修改了输入数据。
- 递归深度是否可能过大。
- 时间和空间复杂度是否满足数据规模。
- 是否能用一个最小样例手动走通。

## 面试应对

### 如何快速判断一道算法题属于什么模型？

回答思路：先看数据结构和连续性，再看目标与约束。

回答模板：

我会先看题目处理的是连续区间、树图结构还是动态集合，再结合数据规模判断复杂度上限。连续子数组或子串优先考虑滑动窗口和前缀和；有序数据考虑二分或双指针；动态维护极值考虑堆；依赖关系考虑拓扑排序；存在重复子问题和最优子结构时考虑动态规划。确定模型后，我会先说清维护的不变量或状态定义，再写代码并检查空输入、重复值和边界。

### 动态规划和贪心怎么区分？

回答思路：说明贪心需要可证明的局部选择性质，DP 保留多个中间状态。

回答模板：

贪心每一步只保留当前最优选择，因此必须证明这个选择不会排除全局最优解，常用交换论证。动态规划不会过早丢弃可能性，而是定义状态保存子问题的最优结果，再通过状态转移组合答案。如果我找不到可靠的贪心证明，或者当前选择会受后续决策影响，通常会优先考虑动态规划。
