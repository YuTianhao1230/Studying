# 10 编程与算法工程能力

## 面试问题

1. Python 中 list、tuple、dict、set 的底层特点和适用场景是什么？
2. 迭代器、生成器、装饰器、上下文管理器分别是什么？
3. Python 多线程、多进程、asyncio 的区别是什么？
4. GIL 是什么？它对 CPU 密集和 IO 密集任务有什么影响？
5. 如何写一个高可靠的数据处理脚本？
6. 如何处理百万级/亿级数据文件？
7. 如何设计日志、异常处理和重试机制？
8. 如何保证实验代码可复现？
9. 常见数据结构和算法复杂度如何分析？
10. 如何写单元测试、集成测试和回归测试？
11. 代码 review 时你最关注哪些问题？
12. 如何把研究代码重构成可维护的工程代码？

## 核心知识点

- Python 基础：数据结构、作用域、闭包、类型注解、异常、文件 IO。
- 并发模型：threading、multiprocessing、asyncio、队列、锁、信号量。
- 性能优化：profile、批处理、流式读取、缓存、向量化、NumPy/Pandas、内存控制。
- 工程质量：模块划分、配置管理、日志、错误码、测试、lint、格式化。
- 可复现性：随机种子、依赖版本、数据版本、模型版本、环境变量、运行参数。
- 算法基础：数组、链表、栈、队列、哈希表、堆、树、图、排序、二分、动态规划。
- 复杂度：时间复杂度、空间复杂度、均摊复杂度、最坏/平均情况。

## 回答要点

- 数据处理脚本要优先保证可恢复、可验证、可追溯，而不是只追求一次跑通。
- 大文件处理应避免一次性读入内存，优先使用流式读取、分块处理、增量落盘。
- 并发任务要考虑超时、重试、限流、异常隔离和部分失败后的续跑。
- 实验代码应保存完整配置、git commit、输入数据版本、输出路径和随机种子。
- 重构研究代码时，先抽离数据、模型、训练、评测、配置和日志，再补测试。
