# C 基础

## 知识点解析

### 概述

C 语言常用于考查指针、数组、字符串、结构体、内存管理、函数调用和代码输出。运营商计算机岗位以及部分银行科技岗会把 C 与数据结构、操作系统结合考查。重点是理解内存模型和表达式行为，不是背大量库函数。

### 基本类型与存储

C 常见基本类型包括 `char`、`short`、`int`、`long`、`float`、`double`。具体字节数与编译器和平台有关，不能脱离题目环境武断判断。

- 局部自动变量通常位于栈上。
- 动态分配内存通常位于堆上。
- 全局变量和静态变量具有静态存储期。
- 字符串字面量通常存放在只读区域，不应通过字符指针修改。

### 指针

指针变量保存对象地址：

```c
int x = 10;
int *p = &x;
*p = 20;
```

`&x` 表示取地址，`*p` 表示解引用。指针运算的步长由指针指向的类型决定，例如 `int *` 加 1 通常移动一个 `int` 大小的元素。

常见指针类型：

- 空指针：不指向有效对象。
- 野指针：未初始化或指向已失效地址。
- 悬空指针：所指对象生命周期已经结束。
- 函数指针：保存函数地址，可用于回调。

解引用空指针、野指针或越界指针都可能产生未定义行为。

### 数组与指针

数组名在很多表达式中会退化为指向首元素的指针，但 `sizeof(array)` 在数组仍处于数组类型的作用域内时得到整个数组大小。数组作为函数参数传递时通常退化为指针，因此函数无法仅通过参数得到数组长度。

```c
int a[5];
sizeof(a) / sizeof(a[0])  /* 在定义数组的作用域内可得到 5 */
```

二维数组作为函数参数时，除第一维外的维度通常必须明确，否则编译器无法计算元素地址。

### 字符串

C 字符串以 `'\0'` 作为结束标志。数组容量不足、忘记预留结束字符或使用不安全的复制函数都可能造成越界。

- `strlen` 计算结束符之前的字符数，不包含 `'\0'`。
- `sizeof` 对字符数组计算数组占用空间，对指针只计算指针本身大小。
- `strcmp` 比较字符串内容，不能用 `==` 比较两个字符串是否相等。

### 函数、作用域和存储类别

- 传值调用：函数获得实参值的副本。
- 通过指针传参：函数可通过地址修改外部对象。
- `static` 局部变量在多次函数调用之间保持值。
- `static` 全局变量或函数限制链接范围，只在当前源文件可见。
- `extern` 用于声明在其他文件中定义的对象或函数。

递归函数需要明确终止条件，并注意栈空间和重复计算。

### 结构体、联合体和枚举

- `struct` 的各成员分别占用存储空间。
- `union` 的成员共享同一段存储空间，大小通常由最大成员决定并受对齐影响。
- `enum` 用于定义一组整型常量。
- 结构体可能因为内存对齐产生填充字节，`sizeof` 不一定等于各成员大小简单相加。

### 动态内存

- `malloc` 分配未初始化的内存。
- `calloc` 分配内存并通常清零。
- `realloc` 调整已分配空间大小，可能移动原地址。
- `free` 释放动态内存。

常见错误包括内存泄漏、重复释放、释放后使用、越界访问和分配失败后继续使用指针。`malloc` 返回的内存需要根据实际类型转换或赋值使用，并检查是否为 `NULL`。

### 编译过程

C 程序通常经历：

```text
预处理 -> 编译 -> 汇编 -> 链接
```

- 预处理：展开宏、处理头文件和条件编译。
- 编译：把源代码转换为汇编或中间表示并进行语法语义检查。
- 汇编：生成目标文件。
- 链接：合并目标文件和库，解析符号引用。

头文件通常放声明，源文件放定义。重复定义和声明不一致可能在编译或链接阶段报错。

## 易错点

- 数组作为函数参数时通常已经退化为指针。
- `sizeof` 计算数组大小，`strlen` 计算字符串长度，二者不能混用。
- C 没有真正意义上的字符串对象，字符串依赖 `'\0'` 结束。
- `free` 后指针变量不会自动变成空指针。
- `realloc` 可能返回新地址，不能无条件假设原指针仍然有效。
