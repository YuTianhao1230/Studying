# 数据库

本目录整理关系数据库的数据建模、SQL 查询、索引与执行计划、事务并发控制，以及 Oracle 和数据库运维基础。Redis 缓存与跨服务分布式事务由“分布式与中间件”目录维护，本页仅提供关联入口。

## 知识卡片

| [SQL与关系模型](<SQL与关系模型.md#sql与关系模型>) | SQL 逻辑执行顺序、连接、聚合、集合运算、关系模型、范式和 ER 映射。 |
| [索引与查询优化](<索引与查询优化.md#索引与查询优化>) | B+ 树、聚簇与非聚簇索引、联合索引、执行计划和慢 SQL 排查。 |
| [事务锁与MVCC](<事务锁与MVCC.md#事务锁与mvcc>) | ACID、隔离级别、锁、MVCC、undo、redo、binlog 和故障恢复。 |
| [SQL高频题](<SQL高频题.md#sql高频题>) | 多表连接、分组聚合、Top N、去重、窗口函数、连续日期和留存。 |
