# 二叉树与BST

## 知识点解析

### 概述

本文整理二叉树遍历、树形递归、二叉搜索树、完全二叉树、满二叉树和平衡二叉树。由遍历序列还原二叉树见 [二叉树遍历还原](<二叉树遍历还原.md>)。

### 核心结论

- 前序：根、左、右。
- 中序：左、根、右。
- 后序：左、右、根。
- 层序：按层从左到右。
- BST 的中序遍历是有序序列。
- 完全二叉树适合数组存储，堆通常就是完全二叉树。

### 常见考法

| 题型 | 常见问法 | 解题方法 |
| --- | --- | --- |
| 遍历序列 | 写出前序、中序、后序、层序 | 按根节点访问位置判断 |
| 递归性质 | 最大深度、节点数、是否平衡 | 先定义子树函数返回值 |
| 路径问题 | 路径和、树的直径、最近公共祖先 | DFS 返回状态或记录路径 |
| 层级问题 | 每层节点、最小深度、右视图 | BFS 按层遍历 |
| BST | 查找、插入、删除、验证 | 利用左小右大的有序性 |
| 完全二叉树 | 节点编号、叶子数量、堆下标 | 使用数组下标关系 |

### 遍历怎么解

递归遍历的区别只在于“什么时候处理根节点”：

```python
def traverse(root):
    if root is None:
        return

    # 放在这里是前序：根、左、右
    traverse(root.left)
    # 放在这里是中序：左、根、右
    traverse(root.right)
    # 放在这里是后序：左、右、根
```

- 需要先处理父节点，再处理子树：前序。
- 需要按 BST 大小顺序访问：中序。
- 需要先获得左右子树结果，再计算父节点：后序。
- 需要按距离根节点的层数处理：层序 BFS。

### 树形递归框架

做树题前先明确递归函数的含义。例如判断平衡二叉树，可以让函数返回子树高度；一旦发现不平衡，返回特殊值：

```python
def height(root) -> int:
    if root is None:
        return 0

    left_height = height(root.left)
    if left_height == -1:
        return -1

    right_height = height(root.right)
    if right_height == -1:
        return -1

    if abs(left_height - right_height) > 1:
        return -1

    return max(left_height, right_height) + 1
```

树形递归常见返回值包括高度、节点数、是否满足条件、子树最优值和目标节点。

### BST

BST，Binary Search Tree，二叉搜索树满足：左子树节点值小于根节点，右子树节点值大于根节点，左右子树也分别是 BST。查找、插入、删除的平均复杂度是 O(log n)，但如果树退化成链表，最坏会变成 O(n)。

BST 操作：

- 查找：目标值小则进入左子树，大则进入右子树。
- 插入：沿查找路径走到空位置后创建节点。
- 删除叶子：直接删除。
- 删除只有一个孩子的节点：用孩子替代当前节点。
- 删除有两个孩子的节点：用中序后继或中序前驱替换，再删除对应节点。

验证 BST 不能只比较节点与直接孩子，因为整个左子树都必须小于根，整个右子树都必须大于根。常见方法是中序遍历检查严格递增，或递归维护每个节点允许的取值上下界。

### 常见树形

| 树形 | 核心定义 |
| --- | --- |
| 满二叉树 | 每层节点数都达到最大值 |
| 完全二叉树 | 除最后一层外都满，最后一层从左向右连续 |
| 平衡二叉树 | 任意节点左右子树高度差不超过 1 |
| 满二叉树的另一种语境 | 每个节点要么没有孩子，要么恰有两个孩子 |

中文教材中“满二叉树”通常指每层都达到最大节点数；英文 Full Binary Tree 常指节点度数只能为 0 或 2，答题时要注意语境。

完全二叉树按从 0 开始的数组下标存储时：

```text
父节点：(i - 1) // 2
左孩子：2 * i + 1
右孩子：2 * i + 2
```

### 易错点

- 二叉树不等于二叉搜索树，普通二叉树没有大小关系。
- 平衡二叉树不一定是完全二叉树，完全二叉树也不一定满足 BST。
- 递归题必须先处理空树。
- 最近公共祖先在普通二叉树和 BST 中的解法不同。
- 由遍历序列还原普通二叉树通常必须包含中序序列。


## 面试应对


回答思路：结合中序的左、根、右顺序和 BST 的大小关系。

回答模板：

中序遍历的顺序是左子树、根节点、右子树，而 BST 中左子树的值都小于根节点，右子树的值都大于根节点。递归应用这个性质后，中序遍历得到的就是递增序列。这个性质也常用于判断一棵树是否是 BST。

### 二叉树题如何设计递归函数？

回答思路：先定义返回值，再说明递归边界和父子状态组合。

回答模板：

我会先用一句话定义递归函数对一棵子树返回什么，例如返回子树高度、节点数、是否平衡或某个最优值。然后确定空树的返回值，再分别获取左右子树结果，最后在当前节点组合。这样可以避免一边写递归一边猜状态。若题目需要全局最大值，我会区分“递归返回给父节点的值”和“遍历过程中更新的全局答案”。

### 如何验证一棵树是不是 BST？

回答思路：强调不能只比较直接孩子。

回答模板：

只比较节点和左右孩子是不够的，因为 BST 要求整个左子树都小于根、整个右子树都大于根。我可以用中序遍历检查结果是否严格递增，也可以递归传递每个节点允许的上下界。两种方法时间复杂度都是 O(n)，递归栈空间取决于树高。

### 完全二叉树为什么适合数组存储？

回答思路：说明节点连续和下标关系。

回答模板：

完全二叉树的节点按层从左到右连续排列，中间没有大量空位置，因此放入数组不会浪费太多空间。使用从 0 开始的下标时，节点 i 的左孩子是 `2i+1`，右孩子是 `2i+2`，父节点是 `(i-1)//2`，不需要额外保存指针。堆就是利用这一性质实现的。
