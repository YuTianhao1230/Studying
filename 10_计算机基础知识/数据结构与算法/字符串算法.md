# 字符串算法

## 知识点解析

### 概述

字符串算法主要解决模式匹配、前缀查询、子串统计和字符串之间的相似性问题。笔试中最常考朴素匹配、KMP 的前缀函数、Trie、字符串哈希，以及“子串、子序列、公共子串、公共子序列”的概念辨析。

设文本串长度为 n，模式串长度为 m，通常假设 `n >= m`。

### 子串、子序列和子数组

| 概念 | 是否连续 | 典型例子 |
| --- | --- | --- |
| 子串 | 连续 | `"abcde"` 的 `"bcd"` |
| 子序列 | 不要求连续，但保持相对顺序 | `"abcde"` 的 `"ace"` |
| 子数组 | 数组中的连续区间 | `[2,3,4]` |
| 子集 | 不要求顺序和连续 | `{a,c}` |

最长公共子串要求连续，常用二维 DP 的相等位置转移；最长公共子序列不要求连续，转移时需要在上方和左方取最大值。不能把二者的状态转移混用。

### 朴素字符串匹配

朴素匹配把模式串从文本串的每个可能起点对齐，逐字符比较：

```text
for start = 0 .. n-m:
    j = 0
    while j < m and text[start+j] == pattern[j]:
        j += 1
    if j == m:
        返回 start
```

最好情况在第一个字符就完成判断，约为 `O(n)`；最坏情况每个起点都比较近 m 个字符，时间复杂度为 `O((n-m+1)m)`，最坏为 `O(nm)`，额外空间 `O(1)`。

它实现简单，适合模式短、输入规模小或需要快速写出正确代码的题目。

### 前缀函数

对于模式串 `pattern`，前缀函数 `pi[i]` 表示：

```text
pattern[0..i] 的最长真前缀，同时也是它的后缀的长度
```

真前缀不能等于整个字符串。例如 `pattern = "abab"`：

```text
pi[0] = 0
pi[1] = 0
pi[2] = 1
pi[3] = 2
```

前缀函数记录了模式串内部的重复结构。匹配失败时，不必把模式串退回起点，而是跳到当前最长相等前后缀对应的位置。

### KMP

KMP 使用前缀函数避免主串指针回退：

```python
def prefix_function(pattern):
    pi = [0] * len(pattern)
    j = 0
    for i in range(1, len(pattern)):
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j
    return pi


def kmp_search(text, pattern):
    if not pattern:
        return 0
    pi = prefix_function(pattern)
    j = 0
    for i, char in enumerate(text):
        while j > 0 and char != pattern[j]:
            j = pi[j - 1]
        if char == pattern[j]:
            j += 1
        if j == len(pattern):
            return i - len(pattern) + 1
    return -1
```

构造前缀函数时间为 `O(m)`；匹配阶段主串指针只向前走，模式指针通过 `pi` 回退，时间为 `O(n)`；总时间为 `O(n+m)`，额外空间为 `O(m)`。

KMP 的关键不只是“有 next 数组”，而是理解 `pi[j-1]` 表示模式串当前已匹配前缀的下一次候选长度。不同教材可能把 next 定义为 `pi` 的右移或减一版本，做题时必须先确认下标约定。

### Trie 与前缀查询

Trie 适合多个字符串共享前缀的场景。每条从根到某个结束节点的路径代表一个字符串。

```text
insert(word):
    node = root
    for char in word:
        node = node.children[char]，不存在则创建
    node.is_end = True

search(word):
    沿每个字符走向子节点
    中途不存在则失败
    走完后返回 node.is_end

starts_with(prefix):
    沿 prefix 走完
    能走完则前缀存在
```

设单词长度为 L，三种操作都是 `O(L)`。Trie 适合自动补全、词频统计、IP 前缀匹配和字典序遍历，但所有字符节点的总量可能很大。小字符集可以使用数组，大字符集或稀疏节点通常使用哈希映射。

### 字符串哈希

字符串哈希把字符串映射为数值，利用前缀哈希在 `O(1)` 时间计算子串哈希，从而支持快速比较。常见滚动哈希形式：

```text
H[i+1] = (H[i] × base + value(s[i])) mod M
```

选择两个前缀位置时，子串哈希可以通过前缀值和 `base` 的幂次计算。使用单模哈希存在碰撞风险，工程上可使用双模哈希、随机 base 或哈希后再做一次真实字符串比较。

字符串哈希适合：

- 判断大量子串是否相等。
- 查找重复子串。
- 二分答案加哈希检查最长重复子串。
- 滚动窗口去重。

哈希相同不能在理论上直接推出字符串一定相同；哈希算法用于概率判断时必须说明碰撞风险。

### 其他匹配方法对比

| 方法 | 预处理 | 匹配/操作 | 适用场景 |
| --- | --- | --- | --- |
| 朴素匹配 | 无 | 最坏 `O(nm)` | 模式短、实现简单 |
| KMP | `O(m)` | `O(n)` | 单模式精确匹配 |
| Trie | 建树总字符数 | `O(L)` | 多模式、前缀查询 |
| 字符串哈希 | `O(n)` | 子串比较常可 `O(1)` | 大量子串比较 |
| Aho-Corasick | 建 Trie 和失配指针 | 与文本和匹配总量有关 | 多模式匹配 |

Aho-Corasick 可以看作 Trie 加 KMP 思想的多模式匹配结构；如果只考基础笔试，先掌握 Trie 和 KMP，再了解其用途即可。

### 最长公共子串与子序列

**最长公共子串：**

设 `dp[i][j]` 表示两个字符串分别以 `i-1`、`j-1` 结尾时的最长公共子串长度：

```text
若 a[i-1] == b[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
否则:
    dp[i][j] = 0
```

答案取所有 `dp[i][j]` 的最大值。

**最长公共子序列：**

```text
若 a[i-1] == b[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1
否则:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

最长公共子串的“不相等归零”是最常见的笔试陷阱。

## 笔试常考

- 子串、子序列、子数组和子集的区别。
- 朴素匹配的最坏复杂度。
- 前缀函数/next 数组的含义和手算。
- KMP 为什么主串指针不回退。
- Trie 完整单词查询和前缀查询。
- 字符串哈希的碰撞问题。
- 最长公共子串和最长公共子序列的状态转移。
- 选择 KMP、Trie、哈希还是 DP。

## 解题步骤

1. 判断题目是单模式匹配、多模式匹配、前缀查询还是子串比较。
2. 如果只需要一次短串匹配，先考虑朴素方法。
3. 如果文本和模式较长且是单模式，考虑 KMP。
4. 如果有大量单词和前缀操作，考虑 Trie。
5. 如果大量比较不同区间，考虑字符串哈希并处理碰撞。
6. 如果问公共子串或子序列，先明确连续性，再定义 DP 状态。

## 易错点

- KMP 的 `next`、`pi` 可能采用不同下标定义，不能直接照抄数组。
- 前缀必须是真前缀，不能把字符串自身作为前缀。
- KMP 的失配回退只移动模式指针，不回退文本指针。
- 哈希碰撞意味着哈希相等不一定字符串相等。
- 最长公共子串不相等时状态归零，最长公共子序列不相等时取上方/左方最大值。
- Trie 的完整单词查询要检查结束标记，不能只检查路径存在。

## 自测

1. 模式串 `"ababaca"` 的前缀函数为 `[0,0,1,2,0,1,0]`。
2. KMP 的总时间复杂度是 `O(n+m)`，不是 `O(nm)`。
3. 字符串 `"abc"` 是 `"xabcy"` 的子串，也是它的子序列。
4. 如果只共享前缀但没有单词结束标记，Trie 不能区分 `"app"` 和 `"apple"` 是否都在字典中。
5. 最长公共子串的 DP 在字符不相等时必须归零。

## 面试应对

### KMP 为什么是 O(n+m)？

KMP 先对模式串构造前缀函数，时间是 O(m)。匹配过程中，文本指针只向前移动，不会因为失配退回；模式指针根据最长相等前后缀跳转，虽然会回退，但总回退次数受前进次数限制。因此匹配阶段是 O(n)，总复杂度是 O(n+m)，额外空间是 O(m)。

### Trie 和 KMP 分别适合什么场景？

KMP 解决一个文本和一个模式串的线性匹配，重点是利用模式串内部重复结构减少回退；Trie 把多个字符串按字符组织成共享前缀的树，重点是完整单词查询、前缀查询和多词典管理。单模式匹配优先考虑 KMP，前缀和多词典场景优先考虑 Trie。

### 最长公共子串和最长公共子序列有什么区别？

公共子串要求连续，因此两个字符不相等时，以它们结尾的公共子串长度必须归零；公共子序列只要求保持相对顺序，不要求连续，字符不相等时可以跳过一个字符，状态取上方和左方的最大值。二者的状态转移不同，不能混用。
