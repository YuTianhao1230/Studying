# 二分查找

## 知识点解析

### 概述

本文整理有序数组二分、左右边界查找和二分答案，重点说明搜索区间、循环不变量、判定函数和边界处理。

### 两类应用

- 在有序数组中查找目标值、第一个满足条件的位置或最后一个满足条件的位置。
- 对答案进行二分，例如最小可行速度、最大可分配资源、满足条件的最小容量。

### 常见考法

| 题型 | 常见问法 | 解题关键 |
| --- | --- | --- |
| 精确查找 | 在有序数组中找目标值 | 比较后排除一半区间 |
| 左边界 | 第一个大于等于目标的位置 | 找第一个满足条件的位置 |
| 右边界 | 最后一个小于等于目标的位置 | 找最后一个满足条件的位置 |
| 旋转数组 | 有序数组旋转后查找 | 每次判断哪一半有序 |
| 二分答案 | 最小速度、最大距离、最小容量 | 构造单调判定函数 |

### 边界原则

写二分前先明确搜索区间是闭区间 `[left, right]` 还是左闭右开区间 `[left, right)`，循环条件和边界收缩必须与区间定义一致。避免只背模板而不理解不变量。

### 精确查找模板

闭区间 `[left, right]` 始终保存所有尚未排除的候选下标；区间外已确定不可能等于目标。每次比较后排除 `middle` 及其一侧，因此使用 `left <= right`：

```python
def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1

    while left <= right:
        middle = left + (right - left) // 2
        if nums[middle] == target:
            return middle
        if nums[middle] < target:
            left = middle + 1
        else:
            right = middle - 1

    return -1
```

循环结束时 `left > right`，候选区间为空，所以目标不存在。空数组会直接返回 `-1`。

### 左右边界模板

下面使用左闭右开区间 `[left, right)`，返回第一个大于等于 `target` 的位置：

```python
def lower_bound(nums: list[int], target: int) -> int:
    left, right = 0, len(nums)

    while left < right:
        middle = left + (right - left) // 2
        if nums[middle] < target:
            left = middle + 1
        else:
            right = middle

    return left
```

循环不变量：

- `[0, left)` 中的元素确定小于 `target`。
- `[right, len(nums))` 中的元素确定大于等于 `target`。
- 循环结束时 `left == right`，该位置就是左边界。

把判断改为 `nums[middle] <= target`，可以得到第一个严格大于 `target` 的位置：

```python
def upper_bound(nums: list[int], target: int) -> int:
    left, right = 0, len(nums)

    while left < right:
        middle = left + (right - left) // 2
        if nums[middle] <= target:
            left = middle + 1
        else:
            right = middle

    return left
```

由此可统一处理左右边界和目标不存在：

```python
def first_equal(nums: list[int], target: int) -> int:
    index = lower_bound(nums, target)
    return index if index < len(nums) and nums[index] == target else -1


def last_equal(nums: list[int], target: int) -> int:
    index = upper_bound(nums, target) - 1
    return index if index >= 0 and nums[index] == target else -1
```

`lower_bound` 本身返回合法插入位置，范围是 `[0, n]`；最后一个小于等于目标的位置是 `upper_bound(nums, target) - 1`，可能为 `-1`。只有查找“等于目标”的下标时才额外检查数组越界和值是否相等。

### 旋转有序数组

对无重复元素的升序数组，旋转后每次至少有一半仍然有序。先判断目标是否落在有序半边，再保留可能含目标的另一半：

```python
def search_rotated(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1

    while left <= right:
        middle = left + (right - left) // 2
        if nums[middle] == target:
            return middle
        if nums[left] <= nums[middle]:
            if nums[left] <= target < nums[middle]:
                right = middle - 1
            else:
                left = middle + 1
        elif nums[middle] < target <= nums[right]:
            left = middle + 1
        else:
            right = middle - 1
    return -1
```

不变量是：目标若存在，就始终位于 `[left, right]`。存在大量重复值时，`nums[left] == nums[middle] == nums[right]` 可能使有序半边无法判定，只能收缩端点，最坏复杂度会退化到 `O(n)`。

### 二分答案

二分答案不直接查数组，而是在候选答案范围内查找。适用条件是：答案域有序且边界有限，`check(answer)` 可计算并具有单调性，单次检查足够高效，而且已明确要找“第一个真”还是“最后一个真”。解题步骤：

1. 明确答案上下界。
2. 编写 `check(answer)` 判断候选答案是否可行。
3. 证明 `check` 的真假随答案单调变化。
4. 判断要找第一个可行值，还是最后一个可行值。
5. 确认边界覆盖真假分界；若不保证有解，返回前检查候选值。
6. 使用对应边界模板。

例如“以最小速度在规定时间内完成任务”：速度越大越容易完成，因此 `check(speed)` 从假变真，应找第一个为真的速度。

```python
def first_true(left: int, right: int) -> int:
    # 前提：right 可行，check 在区间内由假变真
    while left < right:
        middle = left + (right - left) // 2
        if check(middle):
            right = middle
        else:
            left = middle + 1
    return left


def last_true(left: int, right: int) -> int:
    # 前提：left 可行，check 在区间内由真变假
    while left < right:
        middle = left + (right - left + 1) // 2
        if check(middle):
            left = middle
        else:
            right = middle - 1
    return left
```

`last_true` 使用向上取整的中点，避免只剩两个候选值时 `left = middle` 导致死循环。整数答案按区间收缩停止；浮点答案通常按误差阈值或固定迭代次数停止。

### 易错点

- `middle` 应写成 `left + (right - left) // 2`，避免某些语言中加法溢出。
- 更新边界后必须缩小搜索区间，否则可能死循环。
- 找边界时即使已经命中，也不能立即返回。
- 二分答案的难点是证明单调性，不是写循环。
- 浮点二分通常按误差或固定迭代次数停止。

## 笔试常考

- 精确查找使用闭区间时，循环条件是 `left <= right`，无解时返回 `-1`。
- `lower_bound` 返回第一个大于等于目标的位置，`upper_bound` 返回第一个大于目标的位置，两者都可能返回 `n`。
- 第一个或最后一个等于目标的位置必须在边界结果上继续检查越界和值；目标不存在时返回 `-1`。
- 旋转数组每轮先识别有序半边；存在重复值时最坏可能退化为 `O(n)`。
- 二分答案必须有有序答案域、可计算的单调判定函数和覆盖分界的上下界。
- 查找“最后一个真”时使用向上取整中点，保证边界每轮严格推进。

## 面试应对

### 二分查找为什么是 O(log n)？

回答思路：说明每次把候选范围减半。

回答模板：

二分查找每次比较后都能排除当前搜索区间的一半。经过 k 次后，候选规模从 n 变成 `n / 2^k`，当它缩小到 1 时有 `k = log2(n)`，所以时间复杂度是 O(log n)。它成立的前提是数据有序，或者判定函数在答案空间上具有单调性。

### 什么情况下可以二分答案？

回答思路：强调答案空间有序，判定函数具有单调性。

回答模板：

当答案空间有序，并且给定一个候选答案后，可以通过判定函数判断它是否可行，而且可行性随答案单调变化时，就可以二分答案。例如速度越大越容易按时完成任务，就可以二分最小可行速度。关键是找到单调的判定条件，而不是题目里必须出现有序数组。

### 如何避免二分查找边界错误？

回答思路：强调区间定义与循环不变量。

回答模板：

我不会混用不同模板，而是先明确搜索区间。比如使用左闭右开区间 `[left, right)` 时，循环条件是 `left < right`，右边界更新为 `right = middle`；使用闭区间 `[left, right]` 时，循环条件通常是 `left <= right`，排除中点后更新为 `middle - 1` 或 `middle + 1`。写完后我会用空数组、单元素、目标不存在和重复元素检查边界。
