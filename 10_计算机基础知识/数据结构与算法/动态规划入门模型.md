# 动态规划入门模型

## 知识点解析

### 概述

本文整理动态规划的适用条件、状态设计、状态转移、遍历顺序和空间优化，并介绍背包、最长递增子序列、最长公共子序列和编辑距离。

### DP 解题框架

1. 定义状态。
2. 写状态转移。
3. 确定初始化。
4. 确定遍历顺序。
5. 分析复杂度，考虑空间优化。

### 怎么判断能否使用 DP

常见信号：

- 题目求最大、最小、方案数或是否可行。
- 当前选择会影响后续结果，不能直接使用贪心。
- 原问题可以拆成规模更小、形式相同的子问题。
- 不同递归路径会重复计算相同状态。

DP 通常需要两个性质：

- 最优子结构：原问题的最优解可以由子问题最优解构成。
- 重叠子问题：相同子问题会被重复计算，可以缓存结果。

没有可靠贪心证明时，不能因为“每一步看起来最好”就直接使用贪心。

### 四个入门模型

| 模型 | 状态示例 | 关键点 |
| --- | --- | --- |
| 背包 | `dp[j]` 表示容量 j 的最优值 | 0/1 背包倒序，完全背包正序 |
| LIS | `dp[i]` 表示以 i 结尾的最长递增子序列 | 可 O(n^2)，也可贪心 + 二分 |
| LCS | `dp[i][j]` 表示两个前缀的最长公共子序列 | 相等取左上 +1，不等取上/左最大 |
| 编辑距离 | `dp[i][j]` 表示两个前缀互转最少操作 | 增删改三种选择 |

### 背包问题

#### 0/1 背包

每件物品最多选择一次。设 `dp[j]` 表示容量不超过 `j` 时的最大价值：

```text
dp[j] = max(dp[j], dp[j - weight] + value)
```

容量必须倒序遍历，避免当前物品在同一轮被重复使用。

#### 完全背包

每件物品可以选择任意次，状态转移相同，但容量正序遍历，使本轮刚更新的状态可以继续使用当前物品。

#### 常见变形

- 恰好装满：不可达状态初始化为负无穷。
- 求方案数：状态保存方案数量，转移使用加法。
- 多重背包：每件物品有有限数量，可拆分或使用单调队列优化。

### 最长递增子序列

基础 DP：

```text
dp[i] = 以 nums[i] 结尾的最长递增子序列长度
dp[i] = max(dp[j] + 1)，其中 j < i 且 nums[j] < nums[i]
```

时间复杂度为 `O(n^2)`。进一步可以维护不同长度递增子序列的最小结尾，并通过[二分查找](<二分查找.md>)优化到 `O(n log n)`。

注意子序列不要求连续，子数组和子串才要求连续。

### 最长公共子序列

设 `dp[i][j]` 表示字符串 `first[:i]` 和 `second[:j]` 的最长公共子序列长度：

```text
如果 first[i - 1] == second[j - 1]：
    dp[i][j] = dp[i - 1][j - 1] + 1
否则：
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

如果题目要求输出具体序列，需要从 `dp` 表末尾反向恢复路径。

### 编辑距离

设 `dp[i][j]` 表示把前 `i` 个字符转换成前 `j` 个字符所需的最少操作。

字符相同：

```text
dp[i][j] = dp[i - 1][j - 1]
```

字符不同：

```text
dp[i][j] = 1 + min(
    dp[i - 1][j],      # 删除
    dp[i][j - 1],      # 插入
    dp[i - 1][j - 1]   # 替换
)
```

初始化 `dp[i][0] = i`、`dp[0][j] = j`，表示与空字符串互相转换。

### 常见考法与解题步骤

| 题型 | 怎么考 | 状态设计方向 |
| --- | --- | --- |
| 路径最值 | 网格最小路径和、不同路径 | `dp[i][j]` 表示到达当前位置 |
| 子序列 | LIS、LCS、编辑距离 | 以前缀或结尾位置定义状态 |
| 背包 | 容量限制下最大价值或方案数 | 状态包含物品范围和容量 |
| 区间 DP | 合并石子、回文子序列 | `dp[left][right]` 表示区间 |
| 树形 DP | 打家劫舍、树上选择 | 每个节点返回选与不选状态 |
| 状态压缩 | 节点数小、集合选择 | 用二进制位表示已选集合 |

做题时按以下顺序组织答案：

1. 说明为什么存在重叠子问题和最优子结构。
2. 用自然语言定义每个状态。
3. 从“最后一步选择”推导状态转移。
4. 根据依赖关系确定遍历顺序。
5. 设置空集、首行首列等边界。
6. 先保证二维版本正确，再考虑空间优化。

### 易错点

- 状态定义不完整，导致无法从子问题推出当前状态。
- 只背转移式，不清楚 `dp[i][j]` 的含义。
- 0/1 背包容量误用正序，导致同一物品重复选择。
- 初始化把不可达状态设为 0，产生虚假方案。
- 求方案数时物品和容量遍历顺序可能影响组合数与排列数。
- 过早做滚动数组优化，导致依赖顺序被覆盖。

## 面试应对

### 动态规划题怎么讲思路？

回答思路：状态、转移、初始化、遍历、复杂度。

回答模板：

我会先判断问题是否有重叠子问题和最优子结构。如果适合 DP，就先定义状态，比如 `dp[i]` 表示前 i 个元素的最优解，或者 `dp[i][j]` 表示两个前缀之间的关系。然后根据最后一步选择写状态转移，确定初始化和遍历顺序，最后分析复杂度。如果状态只依赖上一层或前几个状态，再考虑滚动数组优化空间。

### 0/1 背包和完全背包遍历有什么区别？

回答思路：物品能否重复选。

回答模板：

0/1 背包每个物品只能选一次，所以一维优化时容量要倒序遍历，避免同一个物品在本轮被重复使用。完全背包每个物品可以选多次，所以容量正序遍历，让当前物品可以继续基于本轮更新后的状态转移。简单记就是：0/1 背包倒序，完全背包正序。

### 动态规划和贪心有什么区别？

回答思路：比较保留状态数量和正确性条件。

回答模板：

贪心每一步只保留当前看来最优的选择，因此必须证明局部最优选择不会排除全局最优解，常用交换论证。动态规划会保存不同子问题的最优结果，再通过状态转移组合答案，适合当前选择会影响后续、又存在重叠子问题的场景。如果我无法证明贪心选择性质，通常不会只凭直觉使用贪心。

### 子数组、子串和子序列有什么区别？

回答思路：强调连续性。

回答模板：

子数组和子串都要求元素在原序列中连续，区别只是数组和字符串的称呼；子序列只要求保持原有相对顺序，不要求连续。例如最长递增子序列可以跳过元素，而最长连续递增子数组不能跳过。这个区别会直接影响状态设计，连续问题常只依赖前一个位置，子序列问题通常需要在更大范围内寻找前驱状态。
