# 图算法进阶

## 知识点解析

### 概述

图算法根据顶点、边、方向和权值的关系，解决依赖顺序、最短路、最小生成树、匹配和路径存在性问题。选算法时先判断图是否有向、是否有权、是否允许负权、是否要求经过所有点或所有边，再看稠密/稀疏和是否需要单源或多源答案。

设图有 V 个顶点、E 条边。使用邻接表时，遍历类算法通常按 `O(V+E)` 分析；使用邻接矩阵时，空间为 `O(V²)`，很多操作会变成 `O(V²)`。

### 算法一句话速查

| 算法 | 一句话：它主要解决什么问题 |
| --- | --- |
| BFS | 在无权图或等权图中，从一个起点按层扩展并求最短边数。 |
| DFS | 深入搜索图的结构，用于连通性、路径枚举、环检测和回溯。 |
| 拓扑排序 | 给有向无环图安排满足依赖关系的执行顺序，并可用于判断有向环。 |
| Dijkstra | 在没有负权边的带权图中，求一个起点到其他点的最短距离。 |
| Bellman-Ford | 在允许负权边的带权图中，求一个起点的最短路并检测可达负环。 |
| Floyd-Warshall | 用动态规划一次求出所有点对之间的最短距离。 |
| DAG 动态规划 | 利用拓扑顺序求 DAG 上的最短路、最长路或路径数量。 |
| Prim | 在无向带权图中逐点扩展，求连接所有顶点且总边权最小的生成树。 |
| Kruskal | 在无向带权图中按边权从小到大选边，利用并查集求最小生成树。 |
| 并查集 | 维护集合的合并和连通关系，快速判断两个顶点是否属于同一集合。 |
| 二分图匹配 | 在左右两组顶点的兼容边中，寻找数量最多且顶点不重复的配对。 |
| 欧拉路径/回路 | 寻找一条每条边恰好经过一次的路径或回路。 |
| 哈密顿路径/回路 | 寻找一条每个顶点恰好访问一次的路径或回路，一般判定较难。 |

记忆顺序：

```text
遍历：BFS / DFS
最短路：BFS / Dijkstra / Bellman-Ford / Floyd
依赖：拓扑排序
连通所有点：Prim / Kruskal
动态连通：并查集
配对：二分图匹配
每条边一次：欧拉
每个点一次：哈密顿
```

### 拓扑排序

拓扑序只适用于有向无环图（DAG），要求每条有向边 `u -> v` 中 u 都出现在 v 之前。它用于课程先修、编译依赖、任务调度和项目流程。

#### Kahn 入度算法

1. 统计每个顶点入度。
2. 把所有入度为 0 的顶点放入队列。
3. 取出一个顶点加入答案，删除它发出的边，邻接点入度减一。
4. 新变成入度 0 的顶点入队。
5. 若最终输出顶点数少于 V，说明图中有环。

时间复杂度为 `O(V+E)`，空间复杂度为 `O(V+E)`。队列替换为小根堆，可以得到字典序最小的拓扑序，但复杂度变为 `O((V+E)log V)`。

#### DFS 拓扑排序

DFS 中将节点标记为未访问、访问中和已完成：

- 访问中节点再次被遇到，说明存在环。
- 一个节点的所有后继处理完后，再把它加入栈。
- 最后反转栈得到拓扑序。

DFS 和 Kahn 都能判环。Kahn 以入度为核心，适合统计当前可执行任务；DFS 以递归路径为核心，适合和其他 DFS 逻辑组合。

### Bellman-Ford

Bellman-Ford 用于单源最短路，可以处理负权边，也可以检测从源点可达的负权环。

对所有边 `(u, v, w)` 做 V−1 轮松弛：

```text
dist[source] = 0，其余为无穷大
重复 V-1 次：
    changed = false
    for (u, v, w) in edges:
        if dist[u] != INF and dist[v] > dist[u] + w:
            dist[v] = dist[u] + w
            changed = true
    如果本轮没有更新，可以提前结束
```

若第 V 轮仍能松弛某条从可达顶点出发的边，则存在源点可达的负权环。时间复杂度为 `O(VE)`，空间复杂度为 `O(V)`。边数很多且没有负权时，Dijkstra 通常更高效。

### Floyd-Warshall

Floyd 用动态规划求所有点对最短路。初始化 `dist[i][j]` 为直接边权，不存在边为 INF，`dist[i][i]=0`，再依次允许顶点 k 作为中间点：

```text
for k = 0..V-1:
    for i = 0..V-1:
        for j = 0..V-1:
            dist[i][j] = min(dist[i][j],
                             dist[i][k] + dist[k][j])
```

状态含义是：只允许前 k 个顶点作为中间点时，i 到 j 的最短距离。时间复杂度为 `O(V³)`，空间复杂度为 `O(V²)`。可以处理负权边，但不能在存在负权环时给出有定义的最短路；若最终存在 `dist[i][i] < 0`，说明有负权环。

Floyd 适合顶点数较小、需要全部点对答案的场景，不适合大规模稀疏图。

### 最短路算法对比

| 算法 | 问题 | 边权限制 | 时间复杂度 | 备注 |
| --- | --- | --- | --- | --- |
| BFS | 单源无权最短路 | 边权相同或忽略权重 | `O(V+E)` | 按层扩展 |
| Dijkstra | 单源最短路 | 不能有负权边 | 堆实现约 `O((V+E)log V)` | 贪心确定 |
| Bellman-Ford | 单源最短路 | 可有负权，可检测负环 | `O(VE)` | 适合边数较少或需负权 |
| Floyd | 全源最短路 | 可有负权，不能有负环 | `O(V³)` | 矩阵 DP |
| DAG DP | DAG 上最短/最长路 | 可有负权 | `O(V+E)` | 先拓扑排序 |

“无权最短路”不是使用 Dijkstra 的理由；边权全为 1 时 BFS 更直接。

### 最小生成树

给定无向连通带权图，最小生成树（MST）连接所有顶点、不形成环，并使总边权最小。MST 有 `V−1` 条边；如果图不连通，得到的是最小生成森林。

#### Kruskal

Kruskal 按边权从小到大排序，如果一条边连接两个不同连通分量，就选择它，否则跳过。用并查集判断两个端点是否已经连通。

```text
按边权升序排序
for edge (u, v, w):
    if find(u) != find(v):
        union(u, v)
        加入答案
    如果已选 V-1 条边，结束
```

排序占主要成本，时间复杂度为 `O(E log E)`，并查集操作为近似常数摊销。

#### Prim

Prim 从一个顶点开始，维护已加入集合和未加入顶点到集合的最小连接代价，每次选择代价最小的顶点加入，再更新邻接点。最小堆实现通常为 `O(E log V)`，邻接矩阵实现为 `O(V²)`。

| 对比项 | Kruskal | Prim |
| --- | --- | --- |
| 核心 | 全局按边排序 | 从顶点集合向外扩展 |
| 依赖 | 并查集 | 优先队列或矩阵 |
| 适合 | 边较少、稀疏图 | 稠密图或邻接矩阵 |
| 结果 | MST 或森林 | 从起点可达部分的 MST |

负权边不会破坏 MST 算法；只要图是无向图，切分性质仍适用。不能把 MST 和最短路混淆：MST 最小化的是所有选边总和，不保证任意两点路径最短。

### 二分图

二分图可以把顶点分成左右两个集合，使每条边只连接左右两侧。判断二分图可以用 BFS/DFS 染色，发现相邻顶点颜色相同则不是二分图。

等价条件：

- 图可以二染色。
- 图中不存在奇环。

二分图最大匹配是从边中选出尽可能多的边，使任意顶点至多出现在一条匹配边中。常见基础算法是增广路：

1. 依次尝试为左侧顶点寻找匹配。
2. 如果右侧顶点未匹配，直接匹配。
3. 如果已匹配，尝试把原匹配对象改配其他位置。
4. 找到一条增广路后，匹配数加一。

朴素 DFS 增广路算法常见复杂度为 `O(VE)`；Hopcroft-Karp 可达到 `O(E√V)`。题目只要求判断是否存在完美匹配时，还要结合两侧顶点数量和匹配结果判断。

### DAG 上的动态规划

DAG 没有环，因此可以按拓扑序处理依赖：

- 最短路：按拓扑序松弛出边。
- 最长路：按拓扑序做最大值转移。
- 路径计数：`dp[v] += dp[u]`。
- 任务排期：先修依赖完成后才能处理后继。

时间复杂度为 `O(V+E)`。这也是“最长路径在 DAG 上可解，但一般图的最长简单路径很难”的原因之一。

### 欧拉与哈密顿

| 问题 | 约束 | 一般复杂度 |
| --- | --- | --- |
| 欧拉路径/回路 | 每条边恰好一次 | 可多项式判定和构造 |
| 哈密顿路径/回路 | 每个顶点恰好一次 | 判定一般为 NP 完全 |

无向图存在欧拉回路的常见条件是：忽略孤立点后连通，且所有顶点度数为偶数；存在欧拉路径但不是回路时，恰有两个奇度顶点。哈密顿问题关注顶点访问，不要把“每条边一次”和“每个顶点一次”混淆。

## 解题步骤

1. 先判断图的方向、权值、是否有负边和是否有环。
2. 无权最短路优先 BFS；非负权单源最短路优先 Dijkstra。
3. 有负边选 Bellman-Ford；多源且顶点不大选 Floyd。
4. 求连接所有顶点的最小总权值选 MST，稀疏图常选 Kruskal，稠密图可选 Prim。
5. 依赖关系先考虑拓扑排序；DAG 上再做 DP。
6. 两侧匹配问题先检查是否二分图，再考虑增广路或 Hopcroft-Karp。
7. 看到“每条边一次”和“每个点一次”先分别对应欧拉和哈密顿。

## 易错点

- Dijkstra 不能处理负权边；Bellman-Ford 可以处理负权但不能让负环上的最短路有定义。
- Floyd 的三重循环中间点 k 必须放在最外层。
- MST 不等于从某个源点出发的最短路径树。
- Kruskal 适合无向图 MST，不能直接拿来求有向图最小生成树。
- 拓扑排序输出顶点少于 V 才能判断有环，不能只看是否出现入度大于 0。
- 二分图不存在奇环，但“没有三角形”不等于一定是二分图。
- 欧拉关注边，哈密顿关注顶点。
- DAG 上最长路可用 DP，不代表一般图最长简单路径也容易。

## 自测

1. 有向图存在环时不存在拓扑序。
2. Floyd 最终 `dist[i][i] < 0` 可以提示存在负权环。
3. Kruskal 选择边时若两端已在同一并查集集合中，应跳过以避免成环。
4. 无向图中所有非孤立顶点度数为偶数且连通时存在欧拉回路。
5. MST 总边数为 `V−1`，但最短路树的路径距离才是从源点出发的最短距离。

## 面试应对

### Dijkstra、Bellman-Ford 和 Floyd 怎么选？

Dijkstra 解决非负权图的单源最短路，使用优先队列时效率较高；Bellman-Ford 允许负权边，并能检测从源点可达的负权环，但复杂度是 O(VE)；Floyd 使用矩阵动态规划解决全源最短路，复杂度 O(V³)，适合顶点数较小的图。选择时先看是否有负边、是单源还是多源，再看规模。

### Kruskal 和 Prim 有什么区别？

Kruskal 从全局角度按边权排序，每次选择不会形成环的最小边，通常配合并查集，适合稀疏图。Prim 从一个顶点出发，不断选择连接已选集合和未选集合的最小边，通常配合优先队列或邻接矩阵，适合稠密图。二者都求无向图最小生成树，但 MST 优化的是总边权，不是任意两点的最短距离。

### 为什么 DAG 上的最长路可以用 DP？

DAG 没有环，可以通过拓扑序保证一个顶点的所有前驱先被处理。定义 `dp[v]` 为到达 v 的最优值，处理边 `u -> v` 时用 `dp[u]` 更新 `dp[v]`。每条边只处理一次，因此时间复杂度为 O(V+E)。一般图有环时可能无限绕圈或需要处理简单路径约束，问题难度会显著提高。
