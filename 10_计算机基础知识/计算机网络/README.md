# 计算机网络

本目录整理计算机网络的核心协议与通信链路，覆盖传输层可靠传输、Web 与域名解析、IP 寻址和路由交换，以及运营商网络协议与 QoS。各卡片均包含知识点解析、笔试常考和面试应对，可按下表顺序复习。

## 知识卡片

| 卡片 | 重点 |

| [TCP与UDP](<TCP与UDP.md#tcp与udp>) | 对比 TCP 与 UDP，并梳理握手挥手、可靠传输、滑动窗口、流量控制和拥塞控制。 |
| [HTTP HTTPS与DNS](<HTTP HTTPS与DNS.md#http-https与dns>) | 讲解 HTTP 版本与缓存、HTTPS/TLS、DNS、会话状态、常用端口及网页访问链路。 |
| [IP子网与路由交换](<IP子网与路由交换.md#ip子网与路由交换>) | 覆盖网络分层、IP/MAC/ARP/ICMP、子网计算、NAT、交换转发和路由选择。 |
| [运营商网络协议与QoS](<运营商网络协议与QoS.md#运营商网络协议与-qos>) | 聚焦 VLAN、STP、DHCP、动态路由、MPLS、QoS、网络时延和 IPv6。 |
