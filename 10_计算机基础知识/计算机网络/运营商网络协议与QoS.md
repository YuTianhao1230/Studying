# 运营商网络协议与 QoS

## 知识点解析

### 概述

通用网络知识解决主机之间如何通信，运营商网络还要处理大规模接入、路由域、业务隔离、带宽保障和流量工程。运营商笔试常考 VLAN、STP、DHCP、动态路由、MPLS、QoS 和 IPv6 的基础概念。

### VLAN

VLAN 在同一物理交换网络上划分多个逻辑广播域。不同 VLAN 默认不能直接通过二层交换通信，通常需要三层交换或路由器转发。

- Access 端口：通常连接终端，属于一个 VLAN。
- Trunk 端口：通常连接交换机或网络设备，承载多个 VLAN。
- VLAN 标签：用于在链路上标识数据所属的逻辑 VLAN。

VLAN 能隔离广播域，但不是完整的安全边界。跨 VLAN 的访问仍需结合路由、防火墙和访问控制策略。

### STP

二层网络存在冗余链路时可能形成环路，引发广播风暴、MAC 地址表震荡和重复帧。STP 通过选举根桥、计算路径并阻塞部分端口形成无环逻辑拓扑。

RSTP 是对 STP 的快速收敛改进。链路冗余提高可靠性，但必须配合环路控制机制。

### DHCP

DHCP 用于自动分配 IP 地址、子网掩码、默认网关、DNS 等网络参数。经典过程常记为 DORA：

```text
Discover -> Offer -> Request -> ACK
```

DHCP Discover 通常是客户端广播寻找服务器；服务器 Offer 提供地址租约；客户端 Request 选择租约；服务器 ACK 确认配置。

### 动态路由协议

| 协议 | 类型 | 适用范围 | 主要特点 |
| --- | --- | --- | --- |
| RIP | 距离矢量 | 小规模网络 | 以跳数为主要度量 |
| OSPF | 链路状态 | 自治系统内部 | 基于链路状态计算最短路径 |
| BGP | 路径矢量 | 自治系统之间 | 根据路径属性进行路由选择 |

OSPF 会维护链路状态信息并计算路径；BGP 重点是自治系统之间的策略和路径交换。不能把 BGP 简单理解为“更快的 OSPF”。

### MPLS

MPLS 在入口处为报文分配标签，后续设备根据标签进行转发。它可以支持：

- 运营商 VPN。
- 业务隔离。
- 流量工程。
- 服务质量保障。
- 大规模骨干网络转发。

MPLS 并不是替代 IP 的全部功能，而是可以和 IP 网络结合使用的转发和承载技术。

### QoS

QoS 用于在网络拥塞或资源不足时对业务进行区分保障。常见流程包括：

1. 分类：识别业务类型。
2. 标记：给报文设置优先级标记。
3. 排队：把不同业务放入不同队列。
4. 调度：决定各队列发送顺序和带宽。
5. 整形/限速：平滑或限制流量。

常见排队和调度方式包括先进先出、优先级队列、加权公平队列。高优先级队列可能导致低优先级业务饥饿，因此需要综合公平性和业务等级设计。

### 带宽、吞吐、时延和抖动

- 链路带宽：理论传输能力。
- 吞吐量：实际单位时间完成的数据传输量。
- 时延：数据从发送到接收的时间。
- 抖动：时延变化的幅度。
- 丢包率：丢失报文占总报文的比例。

视频、语音和工业控制对时延、抖动和丢包更敏感；备份和文件传输通常更关注吞吐量。高带宽不等价于低时延。

### IPv6 与网络演进

IPv6 地址长度为 128 位，拥有更大的地址空间。IPv6 使用邻居发现等机制完成地址解析和邻居管理，组播在很多场景中替代 IPv4 广播。

运营商网络还会结合 SDN、NFV、云网协同和网络切片，把传统专用网络设备能力逐步软件化、虚拟化和集中编排。

## 易错点

- VLAN 隔离广播域，但不是天然的安全隔离。
- STP 通过阻塞部分链路防环，不是把所有链路同时用于转发。
- DHCP ACK 之前，客户端通常还没有最终确认租约。
- OSPF 主要用于自治系统内部，BGP 主要用于自治系统之间。
- QoS 不能凭空增加物理带宽，只能进行业务调度和资源保障。
