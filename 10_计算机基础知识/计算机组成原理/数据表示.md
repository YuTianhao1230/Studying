# 数据表示

## 知识点解析

### 概述

本文整理计算机中的进制转换、原码反码补码、整数溢出、IEEE 754 浮点数和字节序。

### 进制换算

二进制转十进制按权展开，十进制转二进制用除 2 取余倒序。八进制每 1 位对应 3 位二进制，十六进制每 1 位对应 4 位二进制。

```text
101101B = 45D
101101B = 55O
101101B = 2DH
```

### 原码、反码、补码

正数的原码、反码、补码相同。负数反码是符号位不变、数值位取反；补码是反码加 1。计算机使用补码，是因为补码能把加法和减法统一成加法，并且只有一个 0。

n 位有符号补码范围：

```text
-2^(n-1) 到 2^(n-1)-1
```

### 溢出

两个正数相加得到负数，或两个负数相加得到正数，说明有符号溢出。一个正数和一个负数相加不会发生有符号溢出。

### 浮点数

浮点数由符号位、指数位和尾数位组成。它能表示很大或很小的数，但不能精确表示所有十进制小数。例如 0.1 在二进制中无法有限表示，因此浮点运算可能产生误差。

### 大端和小端

大端序把高位字节放在低地址，小端序把低位字节放在低地址。网络字节序通常是大端，x86 常用小端。

### 常见计算题

#### 进制转换

- 二进制转十进制：整数部分按 `2^0、2^1...` 展开，小数部分按 `2^-1、2^-2...` 展开。
- 十进制整数转二进制：除 2 取余，余数倒序。
- 十进制小数转二进制：反复乘 2，依次取整数部分。
- 二进制转八进制：从小数点向两侧每 3 位一组。
- 二进制转十六进制：从小数点向两侧每 4 位一组。

#### 补码运算

求负数补码：

1. 写出对应正数的二进制。
2. 数值位按位取反。
3. 末位加 1。

补码转真值时，若符号位为 1，可以再次取反加 1 得到绝对值，再加负号。

#### 溢出判断

同号数相加得到异号结果时发生有符号溢出：

```text
正 + 正 = 负：正溢出
负 + 负 = 正：负溢出
```

也可以比较符号位的进位和最高数值位的进位，两者不同则溢出。无符号数溢出通常看最高位进位。

### IEEE 754 浮点数

单精度浮点数通常由 1 位符号、8 位阶码和 23 位尾数组成；双精度通常由 1 位符号、11 位阶码和 52 位尾数组成。

规格化数可理解为：

```text
(-1)^S × 1.fraction × 2^(exponent - bias)
```

做题步骤：

1. 把十进制数转换为二进制。
2. 规格化成 `1.x × 2^e`。
3. 写符号位。
4. 将真实指数加偏置得到阶码。
5. 保存小数点后的尾数并按规则舍入。

还要区分正负零、非规格化数、正负无穷和 NaN。

### 常见考法与解题策略

| 题型 | 解题方法 |
| --- | --- |
| 进制转换 | 按权展开、除基取余、分组转换 |
| 补码范围 | n 位有符号补码为 `[-2^(n-1), 2^(n-1)-1]` |
| 补码加减 | 统一按二进制加法，截取固定字长后判断溢出 |
| 浮点编码 | 符号、规格化、阶码加偏置、填写尾数 |
| 浮点误差 | 判断十进制小数能否有限表示为二进制 |
| 大小端 | 将多字节值拆成字节，再按低地址顺序排列 |

### 易错点

- `B` 表示字节，`b` 表示比特，`1 B = 8 b`。
- n 位补码最小值没有对应的正数表示。
- 移位和溢出必须结合有符号或无符号语义判断。
- 浮点数比较不宜直接依赖严格相等，通常使用误差范围。
- 大端和小端只影响多字节数据的字节排列，不改变位内顺序。

## 面试应对

### 为什么计算机用补码？

回答思路：统一加减法、唯一零、硬件简单。

回答模板：

计算机用补码表示有符号整数，主要是因为补码可以把减法转换成加法，用同一套加法器处理加减运算，硬件实现更简单。同时补码只有一个零，不像原码和反码有正零、负零的问题。n 位补码的范围是 `-2^(n-1)` 到 `2^(n-1)-1`，负数范围多一个值。

### 为什么浮点数会有精度误差？

回答思路：有限二进制位无法精确表示所有小数。

回答模板：

浮点数用有限的符号位、指数位和尾数位表示实数，但很多十进制小数在二进制中不能有限表示，比如 0.1，只能近似存储。参与运算时，尾数位有限还会带来舍入误差。所以浮点数适合科学计算和近似计算，但金额这类精确计算通常不能直接用普通浮点数。

### 如何判断补码加法是否溢出？

回答思路：按操作数和结果符号判断。

回答模板：

有符号补码加法中，只有两个同号数相加才可能溢出。两个正数相加得到负数属于正溢出，两个负数相加得到正数属于负溢出；正数和负数相加不会发生有符号溢出。硬件上也可以比较符号位进位和最高数值位进位，两者不同表示溢出。

### 大端和小端有什么区别？

回答思路：说明多字节数据在低地址处存放哪一端。

回答模板：

大端序把数值的高位字节放在低地址，小端序把低位字节放在低地址。例如 `0x12345678` 从低地址开始，大端依次是 `12 34 56 78`，小端依次是 `78 56 34 12`。网络字节序通常采用大端，x86 通常采用小端。
