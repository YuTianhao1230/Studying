# 银行金融科技

## 概述

银行金融科技涉及核心账务、支付清算、交易一致性、金融安全、容灾和数据审计。宏观经济、货币银行学与会计见[综合知识](<../../13_笔试/综合知识/README.md>)，行史、使命价值观和业务品牌见[银行企业文化](<../../13_笔试/企业文化/银行/README.md>)。

## 知识卡片

| 卡片 | 重点 |

| [银行信息系统与支付清算](<银行信息系统与支付清算.md>) | 核心账务、渠道、支付、清算、结算、对账和幂等。 |
| [银行系统安全与容灾](<银行系统安全与容灾.md>) | 认证授权、密钥、审计、备份、RPO/RTO、双活和恢复。 |

## 复习顺序

1. 先理解渠道、业务服务和核心账务的分层。
2. 再掌握支付、清算、结算、对账和交易幂等。
3. 最后掌握安全、容灾、双活、备份和恢复演练。

## 重点提醒

银行科技题经常把技术概念放进资金交易场景中。遇到“超时、重复、冲正、对账、双活、灾备”等关键词，要优先从一致性、可追溯和恢复能力判断。
