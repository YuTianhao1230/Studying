# 银行金融科技

## 概述

本目录整理六大行科技岗笔试中与计算机相关的银行系统知识，重点覆盖核心账务、支付清算、交易一致性、金融安全、容灾和数据审计。宏观经济、货币银行学、会计和银行企业文化仍放在 `13_行测/银行笔试` 中。

| [银行信息系统与支付清算](<银行信息系统与支付清算.md>) | 核心账务、渠道、支付、清算、结算、对账和幂等。 |

## 复习顺序

1. 先理解渠道、业务服务和核心账务的分层。
2. 再掌握支付、清算、结算、对账和交易幂等。
3. 最后掌握安全、容灾、双活、备份和恢复演练。

## 重点提醒

银行科技题经常把技术概念放进资金交易场景中。遇到“超时、重复、冲正、对账、双活、灾备”等关键词，要优先从一致性、可追溯和恢复能力判断。
