# 笔试训练

本目录用于把知识卡片转化为银行和运营商笔试中的选择题、判断题、计算题和代码输出题，建议按索引顺序完成通用专项后再做岗位综合训练。题目以自编训练题和知识点复盘为主，不把未经核验的网络回忆题标记为真题。
