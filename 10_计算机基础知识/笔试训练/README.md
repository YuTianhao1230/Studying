# 笔试训练

## 概述

本目录用于把知识卡片转化为银行和运营商笔试中的选择题、判断题、计算题和代码输出题。题目以自编训练题和知识点复盘为主，不把未经核验的网络回忆题标记为真题。

| 文件 | 内容 |
| --- | --- |
| [银行运营商计算机综合训练](<银行运营商计算机综合训练.md>) | 银行与运营商共同高频的概念、计算和场景题。 |
| [通信与网络专项训练](<通信与网络专项训练.md>) | 通信原理、5G、光纤、路由、QoS 和网络计算。 |

| [数据结构与算法专项训练](<数据结构与算法专项训练.md>) | 复杂度、线性结构、树堆、排序查找、图算法和动态规划。 |

## 使用方法

1. 首次学习后立即做一遍，不查答案。
2. 把错误归类为概念混淆、公式错误、计算失误或审题错误。
3. 一周后重做错题，并把仍然错误的内容回链到知识卡片。
4. 考前按目标单位和岗位进行限时混合训练。
