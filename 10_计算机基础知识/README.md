## 复习路线

针对六大行和三大运营商，建议按“先通用底层，再岗位技术，最后面试深挖”的顺序复习：

1. 通用底层：数据结构、操作系统、网络、数据库和计算机组成原理。
2. 数据结构与算法：先学复杂度基础，再学线性结构、树图、字符串、算法范式和笔试题。
3. 笔试扩展：密码学与安全、软件工程、云计算、大数据、人工智能和信创。
4. 三大运营商：通信原理、移动通信、5G、光纤、运营商网络、物联网和算力网络。
5. 六大行：核心账务、支付清算、交易幂等、金融安全、容灾和 Oracle。
6. 综合岗补充：计算机应用基础、Office、文件格式和信息化常识。
7. 语言专项：C、Java 或 Python 代码输出与基础语法。
8. 笔试训练：限时完成综合题、通信网络题、数据库操作系统题并整理错题。
9. 面试深挖：最后再补 Redis、消息队列、分布式事务、JVM 和工程排查。

## 高频交叉问题

- 进程、线程、协程的区别。
- 用户态和内核态为什么要区分。
- 虚拟内存为什么能让程序以为自己有连续大内存。
- B+ 树为什么适合数据库索引。
- TCP 为什么需要三次握手和四次挥手。
- HTTP 和 HTTPS 的区别。
- 数据库事务 ACID 和隔离级别。
- 哈希冲突怎么解决。
- Cache 为什么能提升性能，局部性原理是什么。
- Redis 为什么快，缓存穿透/击穿/雪崩怎么解决。
- SQL 注入、XSS、CSRF 怎么防。
- 消息队列如何保证不丢、不重、不乱序。
- 采样、调制、复用和香农公式如何区分。
- eMBB、mMTC、URLLC、SA/NSA 和网络切片分别解决什么问题。
- 支付、清算、结算、对账和交易幂等有什么区别。
- RPO、RTO、热备、双活和异地灾备如何区分。
- Oracle 的 `DUAL`、`ROWNUM`、`ROWID` 分别是什么。
- VLAN、STP、OSPF、BGP、MPLS 和 QoS 分别解决什么问题。
- AVL、红黑树、Trie、B 树和 B+ 树分别适合什么场景。
- BFS、Dijkstra、Bellman-Ford、Floyd 和 MST 如何选择。
- 贪心、分治、回溯和动态规划如何区分。

## 使用方式

- 笔试前：先看各分类 README 的“笔试常考”，再刷对应知识卡片。
- 运营商笔试：优先看[运营商技术基础](<运营商技术基础/README.md>)，再做通信网络专项训练。
- 银行科技岗：优先看[银行金融科技](<银行金融科技/README.md>)、Oracle 和安全卡片。
- 银行综合岗：优先看[计算机应用基础与Office](<通用扩展/计算机应用基础与Office.md>)和综合训练。
- 数据结构与算法：先看[复杂度分析与算法基础](<数据结构与算法/复杂度分析与算法基础.md>)，再按树、字符串、图和算法范式学习，最后做[自编笔试题](<数据结构与算法/数据结构算法笔试题.md>)。
- 训练题：先独立作答，再回到知识卡片修正错因，不把训练题答案当成知识点本身。
- 面试前：优先背知识卡片里的“回答模板”。
- 查漏补缺：不会的问题直接定位到对应分类，不在总纲里反复翻找。
