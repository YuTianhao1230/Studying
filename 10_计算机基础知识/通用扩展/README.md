# 通用扩展

## 概述

本目录整理银行和运营商笔试中常见的跨领域信息技术知识，包括密码学与安全合规、云计算、大数据、人工智能、信创和 Office。内容以客观题、概念辨析和场景判断为主。

## 知识卡片

| 卡片 | 重点 |
| --- | --- |
| [密码学与安全合规](<密码学与安全合规.md>) | 加密、哈希、签名、证书、TLS、国密和安全治理。 |
| [云计算大数据与人工智能](<云计算大数据与人工智能.md>) | 云服务、容器、大数据组件、AI 基础和 RAG。 |
| [信创与国产化基础](<信创与国产化基础.md>) | 技术栈、迁移、兼容适配、国密和测试。 |
| [计算机应用基础与Office](<计算机应用基础与Office.md>) | 硬件、文件、存储、Excel、Word、PowerPoint 和办公安全。 |
| [信息安全](<../扩展基础/信息安全.md>) | Web 攻击、认证、授权和安全分析。 |
| [软件工程与测试](<../扩展基础/软件工程与测试.md>) | 生命周期、开发模型、测试、耦合内聚和项目管理。 |
| [设计模式](<../扩展基础/设计模式.md>) | 常见设计模式和适用场景。 |

## 复习顺序

1. 银行和运营商共同重点：密码学与安全合规。
2. 技术岗重点：云计算、大数据、人工智能和信创。
3. 银行综合岗重点：计算机应用基础与 Office。
4. 需要面试或研发岗时，再补设计模式和工程实践。
