# 通信原理与数字通信

## 知识点解析

### 概述

通信原理研究信息如何经过发送设备、信道和接收设备从信源传递到信宿。三大运营商笔试中的通信基础通常不要求复杂推导，但会考查模拟与数字通信、采样量化、调制解调、复用、信道容量、噪声和误码率等概念边界。做题时要先判断题目问的是“信号表示”“传输方式”“共享信道方法”还是“传输质量指标”。

### 通信系统基本组成

```text
信源 -> 输入变换器 -> 发送设备 -> 信道 -> 接收设备 -> 输出变换器 -> 信宿
```

- 信源：产生语音、图像、文字或数据。
- 发送设备：完成编码、调制、放大和发射。
- 信道：传输信号的媒介，可以是光纤、双绞线、无线空间等。
- 接收设备：完成滤波、放大、解调和译码。
- 噪声：传输过程中叠加在有用信号上的随机干扰。

通信系统的主要性能指标是有效性和可靠性。有效性强调传输速率和频带利用率，可靠性强调抗干扰能力、误码率和通信稳定性。

### 模拟通信与数字通信

| 对比项 | 模拟通信 | 数字通信 |
| --- | --- | --- |
| 信号 | 连续信号 | 离散符号或比特 |
| 抗干扰能力 | 再生困难，噪声容易累积 | 可通过再生和纠错恢复 |
| 保密和复用 | 相对不便 | 便于加密、压缩和复用 |
| 典型问题 | 噪声随传输累积 | 需要同步、量化和编码 |

数字通信并不是“没有噪声”，而是接收端可以根据判决门限把受干扰的波形恢复为 0 或 1。噪声过大时仍会产生误码。

### 采样、量化和编码

模拟信号数字化通常经历：

```text
采样 -> 量化 -> 编码
```

1. 采样：按一定时间间隔读取模拟信号的瞬时值。
2. 量化：把连续幅度映射到有限个离散等级。
3. 编码：把量化等级表示成二进制码。

对于频谱限制在 `0` 到 `f_max` 的带限低通或基带信号，奈奎斯特采样定理给出的理想无失真恢复条件是：

```text
f_s >= 2f_max
```

这一常见表达式包含低通信号前提。若带通信号的频谱只占据 `[f_L, f_H]` 且 `f_L > 0`，带宽为 `B = f_H - f_L`，`2f_max` 仍是充分条件，但不一定是最低采样率；在严格选择采样频率、确保采样后的频谱副本不重叠时，可以使用带通采样，使采样率低于 `2f_H` 并接近 `2B`。可用采样区间取决于上下边频，不能不检查频带位置就直接令 `f_s = 2B`。实际系统还要为非理想抗混叠滤波器留出过渡带，因此采样率通常高于理论下限。

采样频率不满足相应条件会发生混叠。量化级数越多，量化误差通常越小，但每个样本需要的编码位数和数据量也越大。量化级数为 `L` 时，采用等长二进制编码所需的最少位数为：

```text
n = ceil(log2 L)
```

仅当 `L = 2^n` 时，才可写成 `n = log2 L`；若 `L` 不是 2 的整数次幂，必须向上取整。

若采用等长二进制 PCM 编码，不考虑压缩、帧同步和信道编码等额外开销，PCM 码率为：

```text
R_PCM = f_s × n = f_s × ceil(log2 L)  bit/s
```

例如，最高频率为 `4 kHz` 的语音按最低奈奎斯特采样率 `8 kHz` 采样，每个样本量化为 `256` 级，即 `n = 8 bit`，则 PCM 码率为 `8 kHz × 8 bit = 64 kbit/s`。

### 信号、带宽和速率

- 频率：单位时间内周期性变化的次数，单位为 Hz。
- 周期：完成一次重复变化所需的时间，`T = 1/f`。
- 带宽：信号占用的频率范围，带宽越大通常能承载更高的数据速率。
- 比特率：每秒传输的比特数，单位 bit/s。
- 波特率：每秒传输的码元数，单位 Baud。

如果一个码元可以表示 `M` 种状态，则理想情况下：

```text
比特率 = 波特率 × log2(M)
```

比特率和波特率不是同一个概念。一个码元只表示 1 bit 时，二者数值才相同。

### 调制与解调

调制是用数字基带信号改变载波的某个参数，使信号适合在信道中传输；解调是接收端从载波中恢复原始信息。

| 调制方式 | 改变参数 | 记忆点 |
| --- | --- | --- |
| ASK | 振幅 | 振幅键控 |
| FSK | 频率 | 频率键控 |
| PSK | 相位 | 相位键控 |
| QAM | 振幅和相位 | 提高单位码元携带比特数 |

高阶调制可以提高频谱效率，但星座点间距变小，对信噪比和信道质量要求更高。5G 中常见 QPSK、16QAM、64QAM、256QAM 等调制方式，实际调制阶数会根据无线信道质量自适应调整。

### 复用技术

复用允许多个信号共享一条传输媒介，接收端再通过解复用分离信号。

| 复用方式 | 区分维度 | 典型理解 |
| --- | --- | --- |
| FDM | 频率 | 不同用户占用不同频段 |
| TDM | 时间 | 不同用户占用不同时间片 |
| CDM | 编码 | 不同用户使用不同码序列 |
| WDM | 光波长 | 光纤中使用不同波长传输 |
| OFDM | 正交子载波 | 把高速数据分到多个正交子载波 |

OFDM 能有效利用频谱并抵抗多径影响，但对频偏和同步误差较敏感。WDM 是光纤通信中的波分复用，不能和无线通信中的 OFDM 混为一谈。

### 香农公式与奈奎斯特公式

有噪声信道的最大传输速率可用香农公式表示：

```text
C = B log2(1 + S/N)
```

- `C`：信道容量，单位为 bit/s。
- `B`：信道带宽，单位为 Hz。
- `S/N`：无量纲的线性功率比，不能直接使用分贝值。

香农公式说明，增加带宽或提高信噪比可以提高理论容量，但容量存在上限。奈奎斯特公式主要描述无噪声有限带宽信道的理想码元速率：

```text
码元速率 <= 2B
R_b,max = 2B log2(M)  bit/s
```

其中 `B` 的单位为 Hz，`M` 是每个码元可取的离散状态数。该公式假设理想无噪声低通信道且无码间串扰；香农公式则给出带宽为 `B`、存在高斯噪声时的理论容量上限，不直接规定调制状态数。实际系统同时受码元速率、调制阶数和信噪比限制，不能把两个公式互相替代。题目给出 dB 信噪比时，应先用 `S/N = 10^(SNR_dB/10)` 转为线性值再代入香农公式。

### 噪声、误码率和编码

- 信噪比越高，接收端越容易正确判决。
- 误码率 BER 是错误比特数与接收总比特数之比。
- 检错只能发现错误，纠错还要能够根据冗余信息恢复错误。
- 奇偶校验、CRC 主要用于检错。
- 海明码、卷积码、LDPC 等可以提供纠错能力。

增加冗余通常会降低有效数据速率，但可以提升可靠性。通信系统需要在速率、时延、频谱效率和可靠性之间取舍。

## 笔试常考

- 低通采样的 `f_s >= 2f_max` 前提，以及带通信号可在频谱副本不重叠时采用低于 `2f_H` 的采样率。
- PCM 码率计算：先求 `n = ceil(log2 L)`，再用 `R_PCM = f_s × n`；仅当 `L = 2^n` 时可直接写成 `n = log2 L`，并注意单位换算和额外开销是否计入。
- 比特率、波特率和调制阶数的换算：`R_b = R_s log2(M)`。
- ASK、FSK、PSK、QAM 的区别。
- FDM、TDM、CDM、WDM、OFDM 的区分。
- 奈奎斯特最高比特率 `2B log2(M)` 与香农容量 `B log2(1 + S/N)` 的计算和适用条件。
- CRC 能检错但不能直接纠错。
- 高阶调制频谱效率高，但对信道质量要求更高。

## 易错点

- `f_s >= 2f_max` 是带限低通或基带信号的常见采样条件；带通信号存在低于 `2f_H` 的采样方案，但不能脱离上下边频直接套用 `f_s = 2B`。
- 波特率表示码元速率，比特率还要乘以每个码元携带的比特数。
- 香农公式中的信噪比必须使用线性值，不能直接把 dB 数字代入。
- 数字通信仍然会发生误码，不是完全不受噪声影响。
- WDM 面向光波长，OFDM 面向正交子载波，二者不是同一种复用。

## 面试应对

### 1. 为什么数字通信通常比模拟通信抗干扰能力强？

**回答思路：** 从门限判决与中继再生说明噪声不易逐段累积，再补充信道编码能力和数字通信仍会误码的边界。

**回答模板：** 数字通信的优势在于接收端可以依据判决门限恢复离散的 0、1 或其他码元，中继节点还能对信号整形、定时和再生，因此只要噪声没有使码元跨过判决边界，波形失真就不会逐段累积。同时，数字系统便于加入检错、纠错和交织编码进一步提高可靠性。但它并非不受噪声影响，信噪比过低时仍会出现误码。

### 2. 什么是采样混叠，如何避免？

**回答思路：** 先说明频谱重叠导致不同频率无法区分，再区分低通采样条件与带通采样例外，最后补充抗混叠滤波和工程裕量。

**回答模板：** 混叠是采样后原信号的频谱副本发生重叠，使不同频率分量无法区分，而且通常不能靠后处理完整恢复。对于频谱从直流延伸到 `f_max` 的带限低通信号，理想条件是 `f_s >= 2f_max`；工程上还要使用抗混叠滤波器并留出过渡带裕量。若信号只占据 `[f_L, f_H]` 的带通频带，`2f_H` 是充分条件但不一定必要，在保证频谱副本不重叠时可采用更低的带通采样率，其可选范围取决于上下边频，不能简单把采样率固定为两倍带宽。

### 3. 为什么不能始终使用更高阶的 QAM？

**回答思路：** 说明高阶 QAM 的频谱效率收益，以及星座点变密带来的信噪比、误码率和功放线性度代价。

**回答模板：** `M` 阶 QAM 每个码元可携带 `log2(M)` bit，因此提高调制阶数能在相同码元速率下提升比特率和频谱效率。但阶数越高，星座点越密，噪声和失真更容易导致错误判决，对信噪比、信道估计和功放线性度的要求也更高。实际系统会根据信道质量自适应选择调制编码方案，而不是固定使用最高阶 QAM。

### 4. 奈奎斯特公式和香农公式有什么区别？

**回答思路：** 对比假设、限制对象和参数，最后说明实际链路要同时满足两类约束。

**回答模板：** 奈奎斯特公式面向理想无噪声、带宽受限且无码间串扰的低通信道，给出最大码元速率 `2B`，采用 `M` 进制调制时最高比特率为 `2B log2(M)`。香农公式 `C = B log2(1 + S/N)` 面向有噪声信道，给出任意可靠通信在理论上不能超过的容量，其中信噪比必须使用线性值。前者突出带宽和码元状态数，后者突出带宽和信噪比，实际速率不能突破任一约束。
