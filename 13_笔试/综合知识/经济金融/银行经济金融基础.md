# 银行经济金融基础

## 知识点解析

### 概述

经济金融研究资源配置、产出与价格、货币信用、金融市场和风险管理。微观分析关注个体选择及市场均衡，宏观分析关注经济总量；商业银行通过存贷款、支付结算等业务连接资金供需双方。

### 宏观经济

- GDP 衡量一国或地区一定时期内最终产品和服务的市场价值。
- 经济增长关注产出增加，经济发展还包括结构、质量、分配和民生改善。
- 通货膨胀是物价总水平持续上涨，通货紧缩是物价总水平持续下降并伴随需求不足。
- 失业率、通货膨胀率、经济增长率和国际收支是常见宏观指标。
- 财政政策通过政府支出、税收和政府债务影响总需求。
- 货币政策通过利率、准备金率、公开市场操作和结构性工具影响流动性与融资条件。

### 微观经济

- 需求通常随价格上升而下降，供给通常随价格上升而上升。
- 均衡价格由供求关系共同决定。
- 机会成本是选择一种方案而放弃的其他方案中价值最高者。
- 边际成本、边际收益和规模经济常用于企业决策。
- 市场失灵包括外部性、公共物品、信息不对称和垄断。

#### 供求变化与弹性

商品自身价格变化引起沿需求曲线移动；收入、偏好、替代品价格变化引起需求曲线移动。“需求量增加”与“需求增加”在经济学题目中含义不同。

- 替代品：其他条件不变，咖啡涨价可能增加茶的需求，交叉价格弹性通常为正。
- 互补品：汽车使用成本上涨可能减少汽车需求，交叉价格弹性通常为负。
- 需求价格弹性绝对值 $|E_d|=\left|\frac{\text{需求量变动率}}{\text{价格变动率}}\right|$。大于1为富有弹性，小于1为缺乏弹性。
- 对小幅价格变化，富有弹性的商品降价通常增加销售收入；缺乏弹性的商品降价通常减少销售收入。**收入不等于利润**，利润还要扣成本。
- 若题目给出前后两个离散状态，优先直接算 $\text{价格}\times\text{销量}$；弧弹性采用中点法，不能混用初期和平均值作分母。

边际决策比较新增收益与新增成本；已发生且无法收回的沉没成本不影响当前最优选择。完全竞争企业是价格接受者，满足适用条件时以 $P=MR=MC$ 确定候选产量；短期是否停产还要比较价格与平均可变成本。

#### GDP核算与名义、实际指标

支出法：$GDP=C+I+G+(X-M)$。其中投资是资本形成，不是居民购买股票；政府转移支付本身不对应当期生产，不能直接计入政府购买。二手商品的既有价值不再次计入当期GDP，当期提供的交易服务计入。

名义GDP使用当期价格，实际GDP使用不变价格。基期价格指数取100时，$\text{GDP平减指数}=\frac{\text{名义GDP}}{\text{实际GDP}}\times100$。CPI针对居民消费的一篮子商品和服务，不能与覆盖国内生产的GDP平减指数混用。

GNI（旧称GNP的对应收入概念）按**常住单位**归属计算，等于GDP加来自国外的初次收入净额；不能简单按国籍区分。

### 货币银行

| 概念 | 重点 |
| --- | --- |
| M0 | 流通中货币 |
| M1 | 2025 年新口径包括 M0、单位活期存款、个人活期存款、非银行支付机构客户备付金 |
| M2 | M1 加准货币，反映更广义流动性 |
| 存款准备金率 | 商业银行缴存中央银行的准备金比例 |
| 公开市场操作 | 中央银行买卖有价证券调节流动性 |
| 再贴现/再贷款 | 中央银行向金融机构提供资金的工具 |

商业银行核心业务包括负债业务、资产业务和中间业务。存款是主要负债，贷款是主要资产，结算、代理和银行卡等属于中间业务或相关服务。

#### 政策传导与银行业务辨析

| 情境 | 直接影响 | 易混点 |
| --- | --- | --- |
| 央行买入证券、实施逆回购 | 向市场投放流动性 | 到期回笼与操作时投放方向相反 |
| 央行卖出证券、实施正回购 | 回笼流动性 | 不等于财政部门征税 |
| 降低法定存款准备金率 | 释放可用资金，通常支持信贷 | 不保证新增资金全部形成贷款 |
| 财政增加政府购买 | 直接增加总需求中的G | 央行再贷款属于货币政策 |
| 银行吸收客户存款 | 银行负债增加 | 客户视角才是其金融资产 |
| 银行发放贷款 | 银行资产增加 | 信用卡透支也形成银行信贷资产，不能把全部银行卡业务都归中间业务 |

简单存款乘数 $\frac{1}{\text{法定准备金率}}$ 仅适用于无现金漏损、无超额准备金等理想模型。现实货币创造还受现金偏好、资本、风险、信贷需求和监管约束，不能把降准金额机械乘为实际新增贷款。

### 国际金融

- 汇率上升或下降必须先明确是直接标价还是间接标价。
- 国际收支包括经常账户、资本和金融账户等。
- 外汇储备、贸易顺差、跨境资本流动和汇率制度是常考主题。
- 利率平价、购买力平价、汇率变动对进出口的影响可能以基础判断题出现。

直接标价示例：1美元由7元人民币变成7.2元人民币，表示美元升值、人民币贬值。其他条件不变时，本币贬值通常有利于出口价格竞争力、提高进口本币成本；实际贸易变化还受供求弹性、合同和调整时滞影响。

名义利率、实际利率与通胀率的精确关系为 $1+i=(1+r)(1+\pi)$，低利率时近似 $r\approx i-\pi$。不要把名义收益为正直接判为购买力上升。

### 金融市场与银行风险指标

| 对象 | 定义与规则 |
| --- | --- |
| 货币市场 | 通常交易期限在一年及以内的短期金融工具，如同业拆借、回购 |
| 资本市场 | 股票和中长期债券等长期资金融通市场 |
| 一级/二级市场 | 新证券发行/已发行证券转让，划分标准是交易环节 |
| 固定利率债券 | 其他条件不变，市场利率上升使未来现金流现值下降、债券价格下跌 |
| 资本充足率 | 合格资本与风险加权资产之比；不是现金与存款之比 |
| 不良贷款率 | 不良贷款余额/贷款总额 |
| 拨备覆盖率 | 贷款损失准备/不良贷款余额；不能与资本充足率混用 |
| 净息差 | 净利息收入/平均生息资产；不等于单笔贷款利率减存款利率 |

存款是银行负债，银行理财是投资产品，不能把两者的风险和兑付安排混为一谈。监管比例和存款保险规则若出现在题目中，应按所问年度及适用机构判断。

### 金融风险

常见风险包括信用风险、市场风险、操作风险、流动性风险、声誉风险和合规风险。内部控制强调岗位分离、授权审批、相互制约、流程记录和风险监测。

辨识时先找**直接触发因素**：借款人违约为信用风险；汇率、价格变化为市场风险；有资产但短期无法筹足现金为流动性风险；流程、人员、系统失误或外部事件引起损失为操作风险。同一事件可连锁引发多类风险，题干问“首先”“主要”时不要只看最终损失。

## 典型题与解析

以下均为自编练习。

1. 某商品价格下降5%，销量增加10%，销售收入如何变化？  
   **答案：增加4.5%。** $0.95\times1.10-1=4.5\%$；不能直接用10%-5%作为精确答案。
2. 本金1000元，一年名义收益5%，同期通胀率2%，实际收益率约多少？  
   **答案：2.94%。** $\frac{1.05}{1.02}-1\approx2.941\%$，近似法给3%。
3. 一年期零息债券到期支付1050元，市场收益率5%时价格1000元；收益率升至6%时价格多少？  
   **答案：约990.57元。** $\frac{1050}{1.06}\approx990.57$，体现价格与收益率反向变动。
4. 银行贷款总额100亿元，不良贷款2亿元，贷款损失准备3亿元。两项风险指标是多少？  
   **答案：不良贷款率2%，拨备覆盖率150%。** 分母分别是贷款总额和不良贷款余额。

## 笔试应对

### 常考题型

- 货币政策和财政政策工具判断。
- M0、M1、M2 口径区分。
- GDP、通胀、失业和国际收支。
- 商业银行业务和金融风险。
- 汇率、利率和金融市场基础。

### 解题方法

先判断题目属于宏观、微观、货币银行还是国际金融；政策题看工具和作用对象，银行业务题看资产/负债/中间业务，汇率题先确认标价法。

### 易错点

- 把财政政策工具和货币政策工具混淆。
- 把存款准备金率上调理解成扩大贷款。
- 忽略 M1 自 2025 年起的统计口径变化。
- 汇率题没有确认直接标价还是间接标价。

## 面试应对

### 常考点及考法

常围绕宏观政策传导、商业银行资产负债、利率汇率变化和风险指标追问，回答要区分直接作用、传导链条与成立条件。

### 1. 货币政策和财政政策有什么区别？

**回答思路：** 从实施主体、主要工具、传导方式和典型作用对象四个维度比较。

**回答模板：** “货币政策主要由中央银行实施，通过利率、准备金、公开市场操作等工具影响流动性、融资成本和信用扩张；财政政策由政府财政部门实施，通过税收、政府支出和转移支付直接影响总需求与资源配置。两者可以协调配合，但不能把降准归为财政政策，也不能把政府购买归为货币政策。”

### 2. 降准为什么不等于贷款一定按乘数增加？

**回答思路：** 先说明释放基础资金的直接影响，再列出现实中的现金漏损、超额准备金、资本约束、风险偏好和信贷需求。

**回答模板：** “降准会释放银行可用资金，并通常有助于提升信贷供给能力，但简单存款乘数只在无现金漏损、无超额准备金等理想条件下成立。现实中贷款还受资本充足率、资产质量、银行风险偏好、企业融资需求和监管要求约束，因此不能把释放金额机械乘以理论倍数当作实际新增贷款。”

### 3. 如何区分银行的信用风险、市场风险、操作风险和流动性风险？

**回答思路：** 按直接触发因素分类，并说明同一事件可能形成风险链条。

**回答模板：** “借款人或交易对手违约主要是信用风险；利率、汇率和市场价格不利变动属于市场风险；人员、流程、系统或外部事件造成损失属于操作风险；机构有资产但短期无法以合理成本获得足够现金，则是流动性风险。同一事件可能引发多类风险，判断时我会先看题目问的是直接原因还是后续影响。”

### 面试易错点

- 只罗列政策工具，不解释传导路径和约束条件。
- 混淆银行视角下的资产、负债与客户视角。
- 将资本充足率、不良贷款率和拨备覆盖率的分母混用。
