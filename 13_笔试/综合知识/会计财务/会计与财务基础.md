# 会计与财务基础

## 知识点解析

### 概述

会计通过确认、计量、记录和报告反映企业财务状况与经营成果。财务分析利用报表衡量偿债、营运和盈利能力，财务管理进一步比较现金流的时间价值、风险与投资收益。

### 会计基础

会计六要素：资产、负债、所有者权益、收入、费用、利润。

基本会计等式：

```text
资产 = 负债 + 所有者权益
利润 = 收入 - 费用 + 直接计入当期利润的利得 - 直接计入当期利润的损失
```

借贷记账法中，资产和费用增加通常记借方；负债、所有者权益和收入增加通常记贷方。

“借”“贷”是记账方向，不直接等同于增加、减少或现金收付。每笔分录借贷金额相等，但借贷平衡不能保证科目、期间和业务判断全部正确。累计折旧属于资产备抵科目，增加通常记贷方。

### 权责发生制与基本分录

权责发生制按收入、费用应归属的期间确认，不按现金是否已收付判断；收入确认还要结合履约及控制权转移等条件。

| 业务（忽略税费） | 分录 | 对利润及现金的影响 |
| --- | --- | --- |
| 股东投入现金10万元 | 借银行存款10，贷实收资本10 | 权益增加，不是收入 |
| 借入短期贷款10万元 | 借银行存款10，贷短期借款10 | 资产负债同增，不是收入 |
| 赊销商品，售价6万元、成本4万元，满足收入确认条件 | 借应收账款6，贷主营业务收入6；借主营业务成本4，贷库存商品4 | 利润增加2，尚未收到现金 |
| 收回上述应收账款 | 借银行存款6，贷应收账款6 | 资产内部变动，不再次确认收入 |
| 预收尚未履约的货款 | 借银行存款，贷合同负债 | 收到现金不代表当期收入 |
| 计提管理用设备折旧 | 借管理费用，贷累计折旧 | 利润减少，无当期现金支付 |

### 三大财务报表

| 报表 | 反映内容 |
| --- | --- |
| 资产负债表 | 某一时点的资产、负债和所有者权益 |
| 利润表 | 一定期间的收入、费用和利润 |
| 现金流量表 | 一定期间经营、投资和筹资活动的现金流量 |

### 常见会计概念

- 收入是日常活动形成的、会导致所有者权益增加且与投入资本无关的经济利益总流入。
- 费用是日常活动形成的、会导致所有者权益减少且与分配利润无关的经济利益总流出。
- 资产是企业过去交易或事项形成、由企业拥有或控制、预期带来经济利益的资源。
- 负债是过去交易形成、预期导致经济利益流出的现时义务。
- 固定资产折旧减少账面价值，按用途计入当期费用或相关资产成本；计入存货成本的部分不一定立即减少当期利润。计提折旧本身不产生当期现金流出。

### 存货、折旧与减值

- 存货采购支出一般先形成资产，出售并确认对应收入时再结转成本；不能把购入存货全额立即当作费用。
- 在适用企业会计准则的通常情形下，存货期末按成本与可变现净值孰低计量。可变现净值需扣除完工成本及销售相关费用税费，不等于预计售价。
- 年限平均法年折旧额：`(原价-预计净残值)/预计使用年限`。若题目给净残值率，用 `原价×(1-净残值率)/年限`。
- 减值与折旧原因不同：折旧系统分摊可折旧金额，减值反映账面价值不能收回的损失；减值能否转回取决于资产类别及准则，不能一概而论。

### 财务指标

| 指标 | 公式或含义 |
| --- | --- |
| 流动比率 | 流动资产 / 流动负债 |
| 速动比率 | 速动资产 / 流动负债 |
| 资产负债率 | 负债总额 / 资产总额 |
| 毛利率 | 毛利 / 营业收入 |
| 净利率 | 净利润 / 营业收入 |
| 净资产收益率 | 净利润 / 平均净资产 |
| 存货周转率 | 营业成本 / 平均存货 |

平均数常按 `(期初+期末)/2`；题目提供更细口径时从题意。速动资产应剔除存货、预付款项等变现能力较弱项目，简单题可能明确采用“流动资产-存货”，须读取定义。

**杜邦分解：**

`净资产收益率=销售净利率×总资产周转率×权益乘数`，其中总资产周转率为营业收入/平均总资产，权益乘数为平均总资产/平均净资产。分子分母与期间口径一致才能约分。杠杆提高可能推高ROE，也增加财务风险，不能据此单独认定经营改善。

流动比率高不必然更好，可能存在存货积压；低也需结合行业、现金流和到期债务判断。财务比率题的正确分析通常需要横向同业、纵向历史比较。

### 财务管理

常考资金时间价值、成本收益、投资回收期、净现值、风险收益关系、资本结构和预算管理。简单题优先列现金流和时间点，不要把利润直接当成现金流。

| 项目 | 公式与条件 |
| --- | --- |
| 单利终值 | `FV=P(1+nr)`，仅本金生息 |
| 复利终值 | `FV=P(1+r)^n`，每期利息再投资 |
| 复利现值 | `PV=FV/(1+r)^n` |
| 普通年金现值 | 每期末等额A，`PV=A[1-(1+r)^(-n)]/r`，r不为0 |
| 净现值NPV | 各期增量现金流折现之和减初始投资 |
| 静态回收期 | 按未折现现金流收回投资所需时间，忽略资金时间价值及回收后收益 |

现金流和折现率期间必须相同。独立项目在给定折现率下NPV大于0通常可接受；互斥方案、预算约束、不同寿命需要进一步比较。沉没成本不计入增量现金流，放弃可行替代用途的机会成本应计入。

## 典型题与解析

以下均为自编练习，金额单位为万元，忽略税费。

1. 管理设备原价10，净残值1，使用5年，年限平均法年折旧额是多少？  
   **答案：1.8。** `(10-1)/5=1.8`。全年正常计提时，账面价值与当期利润各减少1.8，计提本身不减少现金。
2. 流动资产90，其中存货20、预付款10，流动负债30；题目将存货、预付款均排除出速动资产。  
   **答案：流动比率3，速动比率2。** `90/30=3`，`(90-20-10)/30=2`。
3. 初始投资100，一年末收回110，要求收益率8%，NPV是多少？  
   **答案：约1.85。** `110/1.08-100≈1.8519`。不能用110-100=10替代NPV。
4. 当期赊销收入6，成本4；当期未收款，也没有其他业务。收入、毛利、销售收现分别是多少？  
   **答案：6、2、0。** 收入、利润与现金流三者不同。
5. 净利率10%，总资产周转率0.8次，权益乘数2，ROE是多少？  
   **答案：16%。** `10%×0.8×2=16%`，需保持平均资产和平均净资产口径一致。

## 笔试应对

### 常考题型

- 会计要素和会计等式。
- 三大报表的内容归属。
- 收入、费用、资产和负债的定义。
- 财务指标计算。
- 折旧、利润、现金流和投资决策。

### 解题方法

概念题先判断时间范围和对象；报表题看“时点/期间”；计算题先写公式再代数值；财务管理题区分利润、现金流和资金时间价值。

### 易错点

- 把资产负债表当成期间报表。
- 把收入等同于收到现金。
- 把费用等同于现金支出。
- 资产负债率、流动比率分子分母写反。
- 折旧减少利润却误判为当期现金流出。
