# 综合知识

综合知识按学科分为政治与时政、经济金融、会计财务、管理营销。常识判断作为行测题型单独归入[行测/常识判断](<../行测/常识判断/>)，本目录保留银行、运营商综合知识中的专项内容。

| 分支 | 重点 |
| --- | --- |
| [政治与时政](<政治与时政/README.md>) | 政治哲学、国家制度、重大会议、年度政策、新质生产力和央国企时政 |
| [经济金融](<经济金融/README.md>) | 微观宏观、货币银行、金融市场、国际金融和风险指标 |
| [会计财务](<会计财务/README.md>) | 会计分录、财务报表、折旧、财务比率和投资计算 |
| [管理营销](<管理营销/README.md>) | 管理职能、组织激励、决策、STP、营销组合和客户服务 |

## 关联

- 单位沿革、使命、价值观与品牌：[银行企业文化](<../企业文化/银行/README.md>)、[运营商企业文化](<../企业文化/运营商/README.md>)。
- 定量资源配置与收益比较：[决策分析与材料决策](<../行测/数量关系/决策分析与材料决策.md>)。
- 岗位技术知识：[计算机基础总纲](<../../10_计算机基础知识/计算机基础面试笔试总纲.md>)、[运营商技术基础](<../../10_计算机基础知识/运营商技术基础/README.md>)。

先学习固定原理，再做场景辨析和计算；法律按适用时间判断，时政按文件年份判断。银行财会或营销岗位还应对照招聘科目要求补充专业深度。
