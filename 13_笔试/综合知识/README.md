# 综合知识

综合知识按学科分为政治与时政、经济金融、会计财务、管理营销。常识判断作为行测题型单独归入[行测/常识判断](<../行测/常识判断/>)，本目录保留银行、运营商综合知识中的专项内容。

先学习固定原理，再做场景辨析和计算；法律按适用时间判断，时政按文件年份判断。岗位技术知识可结合[计算机基础总纲](<../../10_计算机基础知识/计算机基础面试笔试总纲.md>)与[运营商技术基础](<../../10_计算机基础知识/运营商技术基础/README.md>)复习。
