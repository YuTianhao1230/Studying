# 时政热点与央国企高频表述

## 知识点解析

### 概述

时政热点主要考查重大会议、重要政策、年度经济部署、科技成就、央国企改革、核心价值观、双碳目标和国家安全等内容。与常识判断不同，时政具有明显时效性，需要在考前集中刷新。央国企笔试尤其偏好政策原文、固定提法、重大科技“首次/最高/最新”表述和企业文化相关内容。

### 时效口径

本卡片核验日期为2026-09-27。年度目标与历史会议分别注明年份；2026年度部署以政府工作报告、中央一号文件及国资委公开资料为依据。题目指定历史年份时，应使用该年份文件。

### 党的二十届三中全会（2024年）

进一步全面深化改革的总目标：

```text
继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
```

关键时间：

- 锚定 2035 年基本实现社会主义现代化。
- 到 2029 年，即中华人民共和国成立 80 周年时，完成本决定提出的改革任务。

三中全会“六个坚持”：

| 序号 | 内容 |
| --- | --- |
| 1 | 坚持党的全面领导 |
| 2 | 坚持以人民为中心 |
| 3 | 坚持守正创新 |
| 4 | 坚持以制度建设为主线 |
| 5 | 坚持全面依法治国 |
| 6 | 坚持系统观念 |

三中全会“七个聚焦”：

- 聚焦构建高水平社会主义市场经济体制。
- 聚焦发展全过程人民民主。
- 聚焦建设社会主义文化强国。
- 聚焦提高人民生活品质。
- 聚焦建设美丽中国。
- 聚焦建设更高水平平安中国。
- 聚焦提高党的领导水平和长期执政能力。

### 新质生产力与高质量发展

新质生产力的内涵：

- 创新起主导作用。
- 摆脱传统经济增长方式和生产力发展路径。
- 具有高科技、高效能、高质量特征。
- 以全要素生产率大幅提升为核心标志。
- 特点是创新，关键在质优，本质是先进生产力。

新发展理念：

```text
创新、协调、绿色、开放、共享。
```

其中创新发展居首，是第一动力。高质量发展是全面建设社会主义现代化国家的首要任务；实体经济是坚实支撑，数字经济是重要驱动。

高频原文表述：

- 因地制宜发展新质生产力。
- 健全因地制宜发展新质生产力体制机制。
- 加快形成同新质生产力相适应的生产关系。

### “十五五”开局与2026年政策

2026 年是“十五五”规划开局之年，也是深入推进科技强国建设的关键之年。

**2024年12月中央经济工作会议**提出的“五个必须统筹好”（历史表述）：

| 统筹关系 | 关键词 |
| --- | --- |
| 有效市场和有为政府 | 既放得活又管得住 |
| 总供给和总需求 | 畅通国民经济循环 |
| 培育新动能和更新旧动能 | 因地制宜发展新质生产力 |
| 做优增量和盘活存量 | 提高资源配置效率 |
| 提升质量和做大总量 | 夯实现代化物质基础 |

来源：[2024年中央经济工作会议](https://www.gov.cn/yaowen/liebiao/202412/content_6992258.htm)。二十届四中全会与“十五五”原则另见[会议政策与新质生产力](<会议政策与新质生产力.md>)。

**2026年政府工作报告**的宏观政策表述：

- 继续实施更加积极的财政政策。
- 继续实施适度宽松的货币政策。
- 持续支持“两重”建设、“两新”工作等。

报告中“做好新形势下经济工作”的五点认识为：充分挖掘经济潜能；坚持政策支持和改革创新并举；做到既“放得活”又“管得好”；坚持投资于物和投资于人紧密结合；以苦练内功来应对外部挑战。不要与2024年的“五个必须统筹好”串用。

“两重”指国家重大战略实施和重点领域安全能力建设；“两新”指大规模设备更新和消费品以旧换新。报告开头的2025年工作回顾，不是2026年度目标。

来源：[2026年政府工作报告](https://www.gov.cn/gongbao/2026/issue_12646/202603/content_7064134.html)。

### 中央一号文件与乡村振兴

2026年中央一号文件为《关于锚定农业农村现代化 扎实推进乡村全面振兴的意见》，文件落款2026年1月3日，2月3日公开发布。它是党的十八大以来第14个指导“三农”工作的中央一号文件。

总抓手是推进乡村全面振兴，引领是学习运用“千万工程”经验，根本动力是改革创新。六个部分依次为：

1. 提升农业综合生产能力和质量效益。
2. 实施常态化精准帮扶。
3. 积极促进农民稳定增收。
4. 因地制宜推进宜居宜业和美乡村建设。
5. 强化体制机制创新。
6. 加强党对“三农”工作的全面领导。

要区分2025年“进一步深化农村改革”与2026年“锚定农业农村现代化”的文件标题。农业银行、邮储的涉农业务题可关联粮食安全、乡村产业、普惠服务，但企业定位仍以各行官网为准。

来源：[2026年中央一号文件全文](https://www.gov.cn/yaowen/liebiao/202602/content_7056929.htm)。

2026年政府工作报告回顾了以下**2025年进展**。复习时把“事件发生年”和“资料发布年”分开，不把项目规划或预测写成已完成事实。

| 领域 | 高频表述 |
| --- | --- |
| 深空 | 天问二号开启“追星”之旅 |
| 导航 | 北斗规模应用全面拓展 |

### 央国企改革重点

总要求：

```text
推动国有资本和国有企业做强做优做大，增强核心功能、提升核心竞争力。
```

2026 央企目标：“两个确保、两个力争”：

- 确保增加值持续增长，力争与 GDP 增速匹配。
- 确保“一利五率”稳中向好，力争总体优化。

“一利五率”：

| 指标 | 内容 |
| --- | --- |
| 一利 | 利润总额 |
| 五率 | 营业收现率、净资产收益率、研发经费投入强度、全员劳动生产率、资产负债率 |

2026年公开口径使用“营业收现率”。旧资料中的“营业现金比率”名称及分子定义不同，不能直接作为同一公式使用；做历史题应以题目年份为准。

“三个集中”：

- 向关系国家安全、国民经济命脉的重要行业和关键领域集中。
- 向关系国计民生的公共服务、应急能力、公益性领域等集中。
- 向前瞻性战略性新兴产业集中。

“五个价值”：

- 增加值。
- 功能价值。
- 经济增加值。
- 战略性新兴产业收入和增加值占比。
- 品牌价值。

国企高频表述：

- 做强做优做大。
- 增强核心功能、提升核心竞争力。
- 因地制宜发展新质生产力。
- 两个毫不动摇。

来源：[国资委转载：两个万亿元，标注国资央企创新刻度（2026-02-03）](http://www.sasac.gov.cn/n4470048/n35313464/n35346844/n35347362/c35340050/content.html)。国资委监管央企的经营指标不能直接当作六大行统一考核口径。

### 核心价值观、双碳与国家安全

社会主义核心价值观：

| 层面 | 内容 |
| --- | --- |
| 国家 | 富强、民主、文明、和谐 |
| 社会 | 自由、平等、公正、法治 |
| 个人 | 爱国、敬业、诚信、友善 |

双碳目标：

```text
2030 年前碳达峰，2060 年前碳中和。
```

总体国家安全观：

```text
以人民安全为宗旨，以政治安全为根本，以经济安全为基础，
以军事科技文化社会安全为保障，以促进国际安全为依托。
```

### 央国企企业文化备考法

目标公司三看：

1. 官网“关于我们/企业文化/社会责任”页面。
2. 近期年报。
3. 重大新闻，包括重组、国家战略任务、获奖、重大项目。

必背四类：

- 企业文化与愿景使命。
- 党和国家重大会议。
- 行业知识，例如通信、能源、金融、交通等。
- 重大科技与经济政策热点。

## 笔试应对

### 常考题型

- 填空或判断政策原文，如新质生产力、高质量发展、六个坚持。
- 选择题混淆会议目标、时间节点和政策表述。
- 科技成就题考“首次、世界首次、数量、时间、限定场景”。
- 央国企题考“一利五率”“三个集中”“两个确保、两个力争”。
- 企业文化题考目标公司的使命、愿景、价值观和近期重大事件。

### 解题方法

1. 先识别题目是会议、政策、科技、国企改革还是企业文化。
2. 政策题优先匹配原文表述，不随意改词。
3. 科技题盯限定词和阶段：首次的范围、发射或返回、开工或投产。
4. 国企题背固定表述：做强做优做大、核心功能、核心竞争力、一利五率。
5. 考前 3 天集中刷新当年会议、科技成就和目标公司新闻。

### 易错点

- 把“月球背面采样返回”说成普通月球采样。
- 把“营业收现率”和旧口径“营业现金比率”混淆。
- 新质生产力只记“科技”，漏掉全要素生产率、质优和先进生产力。
- 双碳年份记反：2030 碳达峰，2060 碳中和。
- 三中全会总目标和时间节点记不准。
- 时政资料过期，没有考前刷新。
