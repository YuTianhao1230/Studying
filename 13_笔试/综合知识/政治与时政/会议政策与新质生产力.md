# 会议政策与新质生产力

## 知识点解析

### 概述

本卡是会议与政策事实的权威正文。常考范围包括重大会议目标、改革任务、新发展理念、高质量发展、新质生产力、中央经济工作会议、宏观政策组合和重点专项部署。标准方法是背原文关键词，并区分“目标、原则、路径、政策工具”。

### 时效口径

本卡核验日期为2026-10-05。年度目标与历史会议分别注明年份；2026年度部署以政府工作报告、中央经济工作会议、中央一号文件等公开资料为依据。题目指定历史年份时，应使用该年份文件，不把历史表述当作当前部署。

### 党的二十届三中全会（2024年）

进一步全面深化改革总目标：

```text
继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
```

六个坚持：

- 坚持党的全面领导。
- 坚持以人民为中心。
- 坚持守正创新。
- 坚持以制度建设为主线。
- 坚持全面依法治国。
- 坚持系统观念。

七个聚焦：

- 聚焦构建高水平社会主义市场经济体制。
- 聚焦发展全过程人民民主。
- 聚焦建设社会主义文化强国。
- 聚焦提高人民生活品质。
- 聚焦建设美丽中国。
- 聚焦建设更高水平平安中国。
- 聚焦提高党的领导水平和长期执政能力。

关键时间：

- 锚定2035年基本实现社会主义现代化。
- 到2029年，即中华人民共和国成立80周年时，完成本决定提出的改革任务。

### 党的二十届四中全会与“十五五”（2025年）

四中全会审议通过“十五五”规划《建议》，对应规划时期为2026—2030年。“十五五”时期是基本实现社会主义现代化夯实基础、全面发力的关键时期。

| 要素 | 表述 |
| --- | --- |
| 主题 | 推动高质量发展 |
| 根本动力 | 改革创新 |
| 根本目的 | 满足人民日益增长的美好生活需要 |
| 根本保障 | 全面从严治党 |

“十五五”时期经济社会发展遵循的六个原则：坚持党的全面领导、坚持人民至上、坚持高质量发展、坚持全面深化改革、坚持有效市场和有为政府相结合、坚持统筹发展和安全。

**辨析方法：** 三中全会“以人民为中心、守正创新、以制度建设为主线”等属于进一步全面深化改革的原则；四中全会“人民至上、高质量发展、有效市场和有为政府相结合”等属于“十五五”时期发展原则。两者都可简称“六个坚持”，必须先定位会议及文件。

来源：[二十届四中全会公报](https://www.gov.cn/yaowen/liebiao/202510/content_7045444.htm)。

### 新质生产力

核心表述：

- 创新起主导作用。
- 高科技、高效能、高质量。
- 核心标志是全要素生产率大幅提升。
- 特点是创新，关键在质优，本质是先进生产力。
- 因地制宜发展新质生产力。

来源：[《发展新质生产力是推动高质量发展的内在要求和重要着力点》](https://www.gov.cn/yaowen/liebiao/202405/content_6954761.htm)。

### 高质量发展

高质量发展是全面建设社会主义现代化国家的首要任务，也是新时代的硬道理。必须完整、准确、全面贯彻创新、协调、绿色、开放、共享的新发展理念，加快建设现代化经济体系，推进高水平科技自立自强，加快构建新发展格局，并统筹高质量发展和高水平安全。

### 中央经济工作会议的历史表述

2024年12月中央经济工作会议提出“五个必须统筹好”：

| 统筹关系 | 关键词 |
| --- | --- |
| 有效市场和有为政府 | 既放得活又管得住 |
| 总供给和总需求 | 畅通国民经济循环 |
| 培育新动能和更新旧动能 | 因地制宜发展新质生产力 |
| 做优增量和盘活存量 | 提高资源配置效率 |
| 提升质量和做大总量 | 夯实现代化物质基础 |

来源：[2024年中央经济工作会议](https://www.gov.cn/yaowen/liebiao/202412/content_6992258.htm)。

2025年12月中央经济工作会议总结2025年经济工作并部署2026年工作，提出五点认识：

1. 必须充分挖掘经济潜能。
2. 必须坚持政策支持和改革创新并举。
3. 必须做到既“放得活”又“管得好”。
4. 必须坚持投资于物和投资于人紧密结合。
5. 必须以苦练内功来应对外部挑战。

会议部署八项重点任务：内需主导、创新驱动、改革攻坚、对外开放、协调发展、“双碳”引领、民生为大、守牢底线。它们是2026年工作的直接会议依据，不能与2024年的“五个必须统筹好”串用。

来源：[2025年中央经济工作会议](https://www.gov.cn/yaowen/liebiao/202512/content_7050963.htm)。

### 2026年宏观政策

2026年主要预期目标：

| 指标 | 目标 |
| --- | --- |
| 经济增长 | 4.5%—5%，实际工作中努力争取更好结果 |
| 城镇调查失业率 | 5.5%左右 |
| 城镇新增就业 | 1200万人以上 |
| 居民消费价格涨幅 | 2%左右 |
| 粮食产量 | 1.4万亿斤左右 |
| 单位国内生产总值二氧化碳排放 | 降低3.8%左右 |

以下为2026年政府工作报告及2025年中央经济工作会议的政策方向：

| 政策 | 方向 |
| --- | --- |
| 财政政策 | 继续实施更加积极的财政政策 |
| 货币政策 | 继续实施适度宽松的货币政策 |
| 两新 | 大规模设备更新和消费品以旧换新 |
| 两重 | 国家重大战略实施和重点领域安全能力建设 |

政府工作报告提出持续支持“两重”建设、“两新”工作等。报告开头的2025年工作回顾不是2026年度目标；上节五点认识来自2025年中央经济工作会议。

来源：[2026年政府工作报告主要目标](https://www.gov.cn/yaowen/liebiao/202603/content_7062620.htm)、[政府工作报告全文](https://www.gov.cn/yaowen/liebiao/202603/content_7062625.htm)。年度科技事件、央企监管口径和考前刷新入口见[时政热点与央国企高频表述](<时政热点与央国企高频表述.md#时政热点与央国企高频表述>)。

### 2026年中央一号文件与乡村振兴

2026年中央一号文件为《关于锚定农业农村现代化 扎实推进乡村全面振兴的意见》，文件落款2026年1月3日，2月3日公开发布。它是党的十八大以来第14个指导“三农”工作的中央一号文件。

总抓手是推进乡村全面振兴，引领是学习运用“千万工程”经验，根本动力是改革创新。六个部分依次为：

1. 提升农业综合生产能力和质量效益。
2. 实施常态化精准帮扶。
3. 积极促进农民稳定增收。
4. 因地制宜推进宜居宜业和美乡村建设。
5. 强化体制机制创新。
6. 加强党对“三农”工作的全面领导。

要区分2025年“进一步深化农村改革”与2026年“锚定农业农村现代化”的文件标题。农业银行、邮储的涉农业务题可关联粮食安全、乡村产业和普惠服务，但企业定位仍以各行官网为准。

来源：[2026年中央一号文件全文](https://www.gov.cn/yaowen/liebiao/202602/content_7056929.htm)、[发布说明](https://www.gov.cn/yaowen/liebiao/202602/content_7056934.htm)。

### 金融五篇大文章

| 方向 | 重点 |
| --- | --- |
| 科技金融 | 投早、投小、投长期、投硬科技 |
| 绿色金融 | 坚持先立后破，统筹绿色发展与低碳转型 |
| 普惠金融 | 中小微、民营、乡村振兴、社会民生 |
| 养老金融 | 银发经济、多层次、多支柱养老保险体系 |
| 数字金融 | 金融机构数字化转型 |

记忆顺序：科技金融、绿色金融、普惠金融、养老金融、数字金融。五者不是彼此割裂的业务标签，例如数字能力可以提升普惠服务效率，科技金融和绿色金融也都需要风险定价、数据治理与合规能力支撑。

来源：[国务院办公厅关于做好金融“五篇大文章”的指导意见](https://www.gov.cn/zhengce/content/202503/content_7010604.htm)。

## 典型题与解析

以下为自编练习。

1. “新质生产力只存在于新兴产业，传统产业改造与其无关”是否正确？  
   **答案：错误。** 创新能够通过技术、要素配置和产业改造提升传统产业生产力，不能按产业的新旧标签直接划分。
2. “坚持有效市场和有为政府相结合”属于本卡哪组原则？  
   **答案：四中全会提出的‘十五五’时期发展原则。** 不能因题干出现“六个坚持”就套三中全会清单。
3. 2026年政策中的“两重”是否指设备更新和消费品以旧换新？  
   **答案：否。** 后者为“两新”，“两重”是国家重大战略实施和重点领域安全能力建设。
4. 2026年中央一号文件的年度主题能否沿用2025年标题？
   **答案：不能。** 2026年标题强调“锚定农业农村现代化、扎实推进乡村全面振兴”，历史题与当年题必须按年份匹配文件。

## 笔试应对

### 常考题型

- 会议总目标原文填空。
- 六个坚持、七个聚焦排序或识别。
- 新质生产力内涵判断。
- 高质量发展、宏观政策和重点专项表述。
- 中央一号文件与金融五篇大文章识别。

### 解题方法

政策题按“原文关键词”处理，不能用近义词随意替换。新质生产力题抓创新、质优、先进生产力和全要素生产率。

### 易错点

- 把新质生产力简单理解为高科技产业。
- 漏掉“因地制宜”。
- 把财政政策和货币政策方向记反。
- 把“两重”和“两新”记反。
- 六个坚持和七个聚焦混背。
- 混用不同年份的中央一号文件标题和年度部署。
- 双碳年份记反：2030年碳达峰，2060年碳中和。

## 面试应对

### 常考点及考法

常要求解释新质生产力、高质量发展及重大会议部署，并结合岗位说明如何落实；回答应先准确复述政策定位，再转化为业务行动。

### 1. 如何理解新质生产力？

**回答思路：** 依次回答主导力量、基本特征、核心标志、本质和发展方法，避免只列举新兴产业。

**回答模板：** “新质生产力由创新起主导作用，具有高科技、高效能、高质量特征，核心标志是全要素生产率大幅提升，特点是创新、关键在质优、本质是先进生产力。发展新质生产力要因地制宜，既培育新产业，也通过技术创新和要素优化改造传统产业，不能简单等同于追逐少数热门技术。”

### 2. 如何区分三中全会改革原则与‘十五五’发展原则？

**回答思路：** 先定位会议和文件，再分别记忆总目标、原则及应用语境，不依赖“六个坚持”这一共同数量。

**回答模板：** “我会先看题目对应的是进一步全面深化改革，还是‘十五五’时期经济社会发展。三中全会的原则围绕党的领导、人民中心、守正创新、制度建设、依法治国和系统观念；‘十五五’原则包含人民至上、高质量发展、全面深化改革以及有效市场和有为政府相结合等内容。两组都可能概括为六项，必须依靠文件语境和关键词区分。”

### 3. 怎样把高质量发展落实到具体岗位？

**回答思路：** 将创新、效率、质量、安全和客户价值转化为可衡量的流程改进，结合岗位举例。

**回答模板：** “我理解高质量发展不是单纯追求规模，而是兼顾质量、效率、创新与安全。在具体岗位上，我会从客户真实需求出发，用数字化工具提升流程效率，以数据指标持续评估效果，同时守住合规和风险底线。这样既形成可衡量的业务价值，也避免为了短期速度牺牲长期质量。”

### 4. 如何理解金融五篇大文章之间的关系？

**回答思路：** 先准确列出五项，再从服务对象、发展方式与风险治理说明其协同关系。

**回答模板：** “金融五篇大文章是科技金融、绿色金融、普惠金融、养老金融和数字金融。它们分别回应科技创新、绿色转型、小微与薄弱群体、人口老龄化和数字化发展等需求，但不是彼此割裂的业务标签。例如数字能力可以提升普惠服务效率，科技金融和绿色金融也都需要风险定价、数据治理与合规能力支撑。”

### 面试易错点

- 把新质生产力等同于新兴产业或单一技术。
- 背诵政策原文后没有结合岗位和可执行动作。
- 混用不同会议、不同年份的目标和原则。
- 回答金融五篇大文章时只罗列名称，没有说明协同关系。
