# 数学基础

本目录面向银行、运营商的科技岗、数据岗和 AI 岗专业笔试，整理高等数学、线性代数与概率统计中的高频公式、题型识别和易错边界。普通综合岗未必单独考大学数学，应以目标单位、分子公司、岗位和当批通知为准。

这里的数学基础与[数量关系](<../行测/数量关系/README.md#数量关系>)分工不同：

| 模块 | 主要任务 | 典型题目 |
| --- | --- | --- |
| 数量关系 | 用初等数学快速解决应用题 | 工程、行程、利润、排列组合、数字推理 |
| 数学基础 | 判断大学数学概念并完成公式计算 | 极限、导数、积分、矩阵、特征值、条件概率、分布 |

## 复习优先级

### 第一优先级：必须会

- 高数：基本求导、链式法则、单调性与极值、梯度和偏导。
- 线代：矩阵乘法维度、转置与逆、秩、线性方程组、特征值与特征向量。
- 概率：条件概率、全概率、贝叶斯、独立性、期望、方差、协方差和常见分布。

### 第二优先级：常见加分项

- 高数：重要极限、等价无穷小、定积分、Taylor 展开、Hessian。
- 线代：正交投影、正定矩阵、对称矩阵、相似对角化、奇异值分解。
- 概率：联合与边缘分布、大数定律、中心极限定理、极大似然估计。

### 第三优先级：按岗位补充

- 通信、电气和控制类岗位：微分方程、Fourier/Laplace 变换。
- 算法研究类岗位：矩阵微分、凸优化、信息论和更完整的数理统计。
- 普通银行或运营商统一卷：不应让低频大学数学挤占行测、企业文化和计算机基础的复习时间。

## 推荐顺序

1. 时间有限时只读[数学公式高频必背](<数学公式高频必背.md#数学公式高频必背>)。
2. P0 掌握后再读[数学公式速查表](<数学公式速查表.md#数学公式速查表>)中的 P1 内容，并按“概率统计 → 线性代数 → 高等数学”的顺序补原理；AI 岗通常对前两者更敏感。
3. 每个公式至少做一道直接计算题和一道概念辨析题。
4. 错题必须记录“错在公式没记住、条件没检查，还是计算失误”，不要只抄正确答案。

## 使用边界

- 公式中的向量默认是列向量，概率中的随机变量默认具有相应期望或方差。
- 极限等价替换、矩阵求逆、概率密度积分等公式都依赖成立条件，不能脱离条件机械套用。
- 本目录所称“全量”是指银行、运营商科技岗和 AI 岗基础笔试的常见范围，不是大学数学教材的全部章节。
- 本目录优先覆盖客观题和基础计算题，不替代高校课程教材，也不覆盖完整证明体系。
