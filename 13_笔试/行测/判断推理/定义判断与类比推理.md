# 定义判断与类比推理

## 知识点解析

### 概述

定义判断和类比推理是判断推理中规则最稳定的文字题。定义判断考“给定概念是否满足条件”，关键是拆出主体、客体、方式、目的、条件和结果；类比推理考“两个词之间的关系是否一致”，关键是先定一级关系，再用二级辨析排除干扰项。

### 定义判断

定义判断的拆解维度：

| 维度 | 问题 |
| --- | --- |
| 主体 | 谁实施行为 |
| 客体 | 行为作用于谁 |
| 方式 | 通过什么方式 |
| 目的 | 为了什么 |
| 条件 | 在什么前提下 |
| 结果 | 造成什么结果 |

做题顺序：

1. 圈定义关键词。
2. 标出必要条件。
3. 逐项核对选项。
4. 主体、客体、条件不一致直接排除。
5. 注意题干问“符合”还是“不符合”。

### 类比推理一级关系

| 关系 | 内容 |
| --- | --- |
| 语义关系 | 近义、反义、象征、比喻 |
| 语法关系 | 主谓、动宾、偏正、并列 |
| 逻辑关系 | 全同、并列、包容、交叉、对应 |
| 常识关系 | 功能、材料、组成、场所、因果、时间顺序 |

### 类比推理二级辨析

一级关系相同后，看：

- 词性是否一致。
- 感情色彩是否一致。
- 程度轻重是否一致。
- 主体对象是否一致。
- 必然关系还是或然关系。
- 词语结构是否一致。

### 必要要件与选言条件

适用条件：题目以给定定义为判断标准。步骤：抽取必要条件，区分“并且/或者”，逐项找符合事实；不能把定义中的例子当成穷尽列举。

自编例：题设定义“定向补贴”为政府向特定对象发放、用于指定用途、无偿的资金。政府向低收入家庭发无偿购药补助，三个条件均满足；银行向同类家庭提供购药贷款，不满足政府主体和无偿条件，不能因用途相同就选入。

陷阱：定义要求“目的”时不必然要求目的已实现；写“方式 A 或 B”不要求二者同时具备，未提到的事实不能随意脑补。

### 造句与种属、组成

适用条件：类比词项的一级关系存在多个候选。步骤：用同一短句表达原关系，再把选项逐组替换，保持方向、层级和关系性质一致。

自编例：“轮胎:汽车”可说“轮胎是汽车的组成部分”。“键盘:电脑”同属组成；“轿车:汽车”是种属（轿车是一种汽车），不能替换为组成。反过来“汽车:轮胎”方向也不一致。

陷阱：造句须有区分力，“A 与 B 有关”几乎对所有选项都成立；不能为了匹配某选项加入题干没有的修饰条件。

## 笔试应对

### 常考题型

- 定义判断考主体、条件、目的缺失。
- 类比推理考包容、对应、功能、材料和因果。
- 干扰项常一级关系相似，但二级属性不一致。

### 解题方法

定义判断按关键词逐项核对，不做常识扩展；类比推理先定一级关系，再用词性、色彩、主体和必然性做二级辨析。

### 易错点

- 定义判断把“可能符合”当“严格符合”。
- 忽略题干“不属于”的反向问法。
- 类比只看表面相似，不看关系一致。
- 一级关系一致后不做二级辨析。

## 面试应对

### 定义判断的核心解题原则是什么？

回答思路：以题干定义为唯一标准，拆解必要要件并逐项核对。

口述模板：

定义判断要服从题干给出的定义，而不是依赖日常印象。我会拆出主体、客体、方式、目的、条件和结果，标出其中不可缺少的必要要件，再逐项核对。选项只要违反一个必要条件就可以排除；题干没有要求的内容不能自行补充，定义里的例子也不能当作穷尽范围。

### 类比推理为什么要先看一级关系再做二级辨析？

回答思路：先确定关系类型，再比较方向、词性、程度和必然性。

口述模板：

我先判断题干是语义、语法、逻辑还是常识关系，再用同一句有区分力的话代入选项。多个选项一级关系都成立时，再比较关系方向、词性、感情色彩、程度和必然性。例如“轮胎是汽车的组成部分”不能等同于“轿车是一种汽车”，前者是组成关系，后者是种属关系。

### 定义或类比存在模糊空间时怎样把握边界？

回答思路：优先文本约束和最严格同构，不用宽泛常识强行解释。

口述模板：

遇到模糊项时，我会回到题干措辞，优先选择与原关系在层级、方向和适用条件上最一致的选项。定义题中“可能达到目的”不等于“结果已经发生”，“A 或 B”也不要求两者同时具备；类比题中“有关联”过于宽泛，必须给出能排除其他选项的具体关系。如果仍有两个候选，再用二级属性做最小差异比较。

### 这两类题应如何复盘？

回答思路：把错因归到漏要件、扩定义、关系误判或方向错误。

口述模板：

定义判断错题我会重新标注必要要件，确认是漏看主体条件、忽略反向提问，还是擅自加入常识。类比推理错题则重写题干造句，记录一级关系和真正起区分作用的二级属性。复盘结果要形成稳定标签，例如“种属与组成混淆”或“必然关系误当或然关系”，便于下次快速识别。
