# 定义判断与类比推理

## 知识点解析

### 概述

定义判断和类比推理是判断推理中规则最稳定的文字题。定义判断考“给定概念是否满足条件”，关键是拆出主体、客体、方式、目的、条件和结果；类比推理考“两个词之间的关系是否一致”，关键是先定一级关系，再用二级辨析排除干扰项。

### 定义判断

定义判断的拆解维度：

| 维度 | 问题 |
| --- | --- |
| 主体 | 谁实施行为 |
| 客体 | 行为作用于谁 |
| 方式 | 通过什么方式 |
| 目的 | 为了什么 |
| 条件 | 在什么前提下 |
| 结果 | 造成什么结果 |

做题顺序：

1. 圈定义关键词。
2. 标出必要条件。
3. 逐项核对选项。
4. 主体、客体、条件不一致直接排除。
5. 注意题干问“符合”还是“不符合”。

实战补充：

- 先看主客体，再看方式、目的、原因、结果和时间。
- “即、也就是说、换句话说”后的内容通常是定义补充说明。
- 多定义题只重点拆题目所问的定义；纠结时利用不同定义之间的差异。
- 定义出现并列要点时，重点看并列部分，选项常与这些要点一一对应。
- 选项结构高度相似时，先提取其共同结构；它们可能因同一要件而同对同错，再逐项核证。

### 类比推理一级关系

| 关系 | 内容 |
| --- | --- |
| 语义关系 | 近义、反义、象征、比喻 |
| 语法关系 | 主谓、动宾、偏正、并列 |
| 逻辑关系 | 全同、并列、包容、交叉、对应 |
| 常识关系 | 功能、材料、组成、场所、因果、时间顺序 |

逻辑关系的快速区分：

| 关系 | 识别方式 | 例子 |
| --- | --- | --- |
| 全同 | 古今别称、音译、俗称、美称、尊称或谦称 | 土豆：马铃薯 |
| 矛盾 | 非此即彼，不存在第三种情况 | 动：静 |
| 反对 | 同一类别下还有第三种情况 | 黑：白 |
| 交叉 | 可以造句“有的 A 是 B，有的 A 不是 B” | 青年：干部 |
| 种属 | A 是一种 B | 老虎：动物 |
| 组成 | A 是 B 的一部分 | 后视镜：汽车 |

种属与组成的秒判：能说“一种”是种属，能说“一部分”是组成。组成关系还可继续比较部件是否核心、多个部件是否共同组成完整事物。

### 类比推理二级辨析

一级关系相同后，看：

- 词性是否一致。
- 感情色彩是否一致。
- 程度轻重是否一致。
- 主体对象是否一致。
- 必然关系还是或然关系。
- 词语结构是否一致。

高频对应关系的二级辨析：

| 一级关系 | 二级检查 |
| --- | --- |
| 原材料 | 直接/间接、必然/或然、物理/化学变化、主要/次要、单一/多重 |
| 功能 | 时间先后、是否配套使用、动力来源、功能是否相似 |
| 职业/身份 | 工作对象、工具、场所和方式 |
| 属性 | 必然属性还是或然属性 |
| 顺序 | 时间早晚、是否发生转换、主体是否相同 |
| 因果 | 必然/或然，自然/人为，结果积极/消极 |
| 方式目的 | 方式能否真正实现目的 |
| 条件 | 充分条件还是必要条件 |
| 常识 | 人工/自然、命名方式、动力来源和原理是否相同 |

仍无法区分时，再比较特指/泛指、程度轻重、相同性质、排列顺序和抽象/具体。类比题优先采用大众、稳定的关系，不钻冷门常识。

### 必要要件与选言条件

适用条件：题目以给定定义为判断标准。步骤：抽取必要条件，区分“并且/或者”，逐项找符合事实；不能把定义中的例子当成穷尽列举。

自编例：题设定义“定向补贴”为政府向特定对象发放、用于指定用途、无偿的资金。政府向低收入家庭发无偿购药补助，三个条件均满足；银行向同类家庭提供购药贷款，不满足政府主体和无偿条件，不能因用途相同就选入。

陷阱：定义要求“目的”时不必然要求目的已实现；写“方式 A 或 B”不要求二者同时具备，未提到的事实不能随意脑补。

### 造句与种属、组成

适用条件：类比词项的一级关系存在多个候选。步骤：用同一短句表达原关系，再把选项逐组替换，保持方向、层级和关系性质一致。

自编例：“轮胎:汽车”可说“轮胎是汽车的组成部分”。“键盘:电脑”同属组成；“轿车:汽车”是种属（轿车是一种汽车），不能替换为组成。反过来“汽车:轮胎”方向也不一致。

陷阱：造句须有区分力，“A 与 B 有关”几乎对所有选项都成立；不能为了匹配某选项加入题干没有的修饰条件。
