# 论证削弱与加强

## 知识点解析

### 概述

论证题考查论点、论据和论证关系。削弱题要找能让论点不成立或论据无法支持论点的选项；加强题要找能让论据更能推出论点的选项。解题第一步必须找论点，不能只看题干材料中的背景信息。常见技巧是先看结论词，如“因此、说明、认为、由此可见”。

### 论证结构

```text
论据 -> 论证桥梁 -> 论点
```

论点是作者要证明的结论，论据是支持结论的事实或理由，桥梁是论据和论点之间隐含的关系。

### 削弱方向

| 方向 | 类型 | 说明 |
| --- | --- | --- |
| 结论 | 反例或反面事实 | 检验是否针对原结论的对象、范围和强度 |
| 联系 | 拆桥 | 说明论据不足以支持结论 |
| 证据 | 样本或测量问题 | 说明论据不可靠、不具代表性 |
| 因果 | 他因、倒因果 | 为同一现象提供替代解释 |

不存在脱离题面的固定强弱排序。全面解释现象的他因可以很强；只口头复述“结论不对”并无证据，不能因类型标签就判最强。

### 加强方向

| 方向 | 类型 | 说明 |
| --- | --- | --- |
| 联系 | 搭桥 | 补足题干缺失的联系，注意方向 |
| 证据 | 补充论据 | 增加相关且可比的事实 |
| 因果 | 排除他因、机制说明 | 提高原解释相对替代解释的可信度 |

### 前提假设

前提假设题常问“必须假设什么”。否定代入适用于必要前提，不能直接代替“补充哪项足以推出”的充分条件检验。

步骤：

1. 写清论据和结论，找结论新增概念。
2. 对候选项作逻辑否定，不是改成语气最强的反面。
3. 保持题干事实不变，加入否定项，检验原推理是否失去必要支持。
4. 排除只是“有帮助”而非“不可缺”的项；归纳论证失去支持不等于现实结论必假。

| 原命题 | 逻辑否定 |
| --- | --- |
| 所有 A 都是 B | 至少一个 A 不是 B |
| 有的 A 是 B | 没有 A 是 B |
| A 且 B | 非 A 或非 B |
| A→B | A 且非 B |
| 至少 n 个 | 至多 n-1 个 |

自编例：项目唯一收益是节省人工费 10 万元/年，无其他收益；因此采用后每年净节省为正。必要条件是“每年新增总成本小于 10 万元”。否定为成本至少 10 万元，则净节省 $10-\text{成本}\le 0$，结论不能成立。“完全没有维护费”过强：即使维护费 2 万元，仍可净省 8 万元。

陷阱：把“所有”否定成“所有都不”、把“有些”否定成“有些不”，都会改变检验对象。

方法核验：[中公公开教学说明，逻辑判断如何找前提](https://www.offcn.com/gwy/2019/0704/17912.html)介绍搭桥与反向验证；本卡示例自编，逻辑量词按上表独立校验，不照搬文章中的强弱表述。

### 因果论证与评价

适用条件：由相关、前后对比或不同组差异推出因果。步骤：找原因 X、结果 Y、比较组，检查共同原因、选择偏差、时间和测量口径；评价题尝试把候选问题分别回答“是/否”，看是否明显影响论证。

自编例：受训组 80/100 人合格、未受训组 60/100 人合格，据此称培训有效。若受训前两组就分别为 80% 和 60%，则观察差距可能来自原有差异；若同等基础随机分组且其他条件一致，因果解释得到加强。“两组基础是否相当”就是有效评价问题。

陷阱：存在他因不必证明培训完全无效；削弱只要求降低支持度，不能把“未证明有效”改成“已证明无效”。

## 笔试应对

### 常考题型

- 问最能削弱或最能加强的一项。
- 问论证成立的前提。
- 问解释某种矛盾现象。
- 选项偷换论点、只攻击背景或只讨论无关对象。

### 解题方法

先找论点和论据，再看选项如何改变两者联系；比较对象、范围、证据强度和直接性，不按类型固定排队。必要前提用规范否定代入，评价题用正反回答检验。

### 易错点

- 没找论点就看选项。
- 选择了只削弱论据细节但不影响论点的弱项。
- 他因削弱和拆桥混淆。
- 前提题没有用否定代入。

## 面试应对

### 论证题为什么必须先找论点和论据？

回答思路：先固定要证明的结论，再判断选项作用于证据、桥梁还是结论。

口述模板：

我会先用结论词、作者态度和首尾句定位论点，再概括支撑它的论据，最后写出二者之间缺失的桥梁。这样看选项时能判断它是在反驳结论、质疑证据，还是切断论据与论点的联系。只攻击背景信息或讨论无关对象，即使内容正确，也不能有效削弱原论证。

### 削弱或加强选项怎样比较强弱？

回答思路：比较对象、范围、直接性和证据质量，不按类型机械排序。

口述模板：

我先确认选项与原论点的对象、范围和结论强度一致，再看它改变论证成立概率的程度。能直接给出反例、拆掉唯一桥梁或排除关键他因的选项通常更有力，但不存在脱离题面的固定排序。一个只说明“还可能有别的原因”的选项，如果没有解释当前现象，往往弱于能覆盖同一现象的具体替代原因。

### 必要前提和充分加强有什么区别？

回答思路：必要前提不可缺，充分加强只需显著提高支持度。

口述模板：

必要前提是论证成立不能缺少的条件，我会对候选项做规范的逻辑否定，并保持题干事实不变；若否定后论据无法再支持结论，该项才是必要前提。加强项只要求提高结论可信度，不一定不可缺。因此否定代入适合判断必要性，不能把一个很强但非必需的补充证据误当作前提。

### 论证题错题怎样复盘？

回答思路：重写论证链，标注选项作用点并检查范围偷换。

口述模板：

我会把题目压缩成“论据、桥梁、论点”三部分，再给每个选项标注作用位置和方向。错题重点检查是否找错论点、忽略比较基准、把相关当因果，或者被范围和强度偷换干扰。因果题还会补查共同原因、倒因果、样本选择和测量口径，形成下一次可直接调用的检查清单。
