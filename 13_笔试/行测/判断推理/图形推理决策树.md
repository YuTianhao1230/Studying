# 图形推理决策树

## 知识点解析

### 概述

图形推理决策树的核心是按“元素组成”快速分流，避免在没有方向时盲目数点线面。图推第一判断不是规律本身，而是图形之间像不像：元素完全相同看位置，元素相似看样式，元素不同先看属性再看数量，出现立体图再进入空间规律。

### 四类分流

| 图形状态 | 优先规律 |
| --- | --- |
| 元素组成相同 | 位置：平移、旋转、翻转 |
| 元素组成相似 | 样式：遍历、加减同异、黑白运算 |
| 元素组成不同 | 属性：对称、曲直、开闭；再数量：点线角面素 |
| 立体图形 | 空间：折纸盒、截面、三视图、拼合 |

### 九宫格横行优先

看到 3x3 九宫格，优先看横行：

1. 横行是否有相同变化。
2. 横行没有，再看竖列。
3. 再看整体遍历。
4. 再看米字形或中心对称。
5. 最后看相邻运算。

### 黑白块：移动与逐格运算

黑块数量相同且能整体平移、旋转时，先验证位置变化；两图对应格叠加得到第三图时，再试逐格黑白运算。位置改变不等于一定做黑白运算，数量变化也不能排除运算模型。

适用条件：网格尺寸一致、对应格明确。步骤：黑记 1、白记 0，用已知两组验证同一运算表，再用于缺失格。

自编例：三格图 `101` 与 `110`，逐格异或（同为 0、不同为 1）得 `011`；另一组 `110` 与 `011` 得 `101`。若题图要求这两组都成立，该规则通过现有检验。

陷阱：不能只凭一个格子就认定运算；或、与、异或的真值表不同。若黑点从第 1 格到第 2 格再到第 3 格，简单平移已足够，不必强行叠加。

### 功能元素

黑点、箭头、小圆、小三角等功能元素常用于标记：

- 交点。
- 线段。
- 角。
- 面。
- 方向。
- 长短。
- 相邻或相对关系。

功能元素不是普通数量元素，优先看它“指向哪里”或“落在哪里”。

### 一笔画与最少笔画

适用条件：把交点、端点视为图的顶点，线段视为边，要求每条边恰走一次。步骤：先判断非孤立部分是否连通，再数奇数度顶点 O；连通图 O=0 或 2 可一笔画，O>2 时最少 O/2 笔。

自编例：一个四边形的四个顶点度数均为 2，可一笔画；加一条对角线后有两个 3 度顶点，仍可一笔画；加两条相交对角线后四个角均为 3 度，中心为 4 度，最少 2 笔。

陷阱：两个分离的圆共有 0 个奇点，却须 2 笔。多连通分量应分别计算 $\max(1,O_i/2)$ 后相加；仅视觉交叉但题设不连通的线不能算同一顶点，允许重描时也不能照搬该公式。

### 分类题的规则一致性

适用条件：六图分两组或序列找规律。步骤：统一计数标准，验证每张图，而不是只解释选中的一组。

自编例：三图线条数分别 3、4、5，另三图为 6、7、8，不能仅称“都有直线”就完成分组，因为两组均满足；若前组三图恰一条对称轴、后组三图恰两条，则同一可检查属性完成区分。

陷阱：封闭面数通常不含外部无限区域；交点是否包含端点、角是否只计某类，都须一致。

## 笔试应对

### 常考题型

- 一组图形元素完全相同，考平移、旋转、翻转。
- 黑白块题考黑白运算或部分数。
- 九宫格考横行、竖列、整体遍历。
- 小黑点、箭头考功能元素。

### 解题方法

元素特征只决定优先尝试顺序，不排斥其他规律。对移动、叠加、计数各提出一个可检验规则，再验证全部已知图。

### 易错点

- 所有图推都先数点线面。
- 把位置变化直接等同黑白运算。
- 九宫格不看横行，直接找复杂关系。
- 功能元素当普通元素数个数。

## 面试应对

### 图形推理为什么要先做题型分流？

回答思路：说明元素相似度决定优先规则，但不是排他结论。

口述模板：

图形推理先分流是为了控制搜索范围。元素完全相同，我优先看平移、旋转和翻转；元素相似，优先看遍历、叠加和黑白运算；元素不同，再看对称、曲直、开闭和点线面数量。分流只决定尝试顺序，不代表其他规律一定不存在，候选规则仍要覆盖全部已知图形。

### 如何区分黑白块的移动规律和逐格运算？

回答思路：比较数量是否保持、对应格关系以及多组一致性。

口述模板：

如果黑块数量基本不变，而且整体可以通过平移或旋转对应，我会先验证位置规律；如果第三幅图像由前两幅对应格叠加生成，再测试与、或、异或等逐格运算。判断依据不是某一个格子碰巧符合，而是同一运算表能解释至少两组完整关系。数量变化只能作为线索，不能单独证明存在黑白运算。

### 功能元素题的判断边界是什么？

回答思路：把小元素视为标记，检查指向对象和关系是否稳定。

口述模板：

黑点、箭头和小三角出现得少且位置醒目时，我会先把它们当成功能标记，观察它指向交点、角、线、面还是方向。有效规则必须让标记对象在每幅图中保持同一种关系。只有当这种关系无法稳定解释全部图形时，我才回到普通数量或位置规律，不能看到小黑点就机械数个数。

### 图形推理错题怎样复盘才可迁移？

回答思路：记录识别路径、计数口径和反例，而不是记具体图案。

口述模板：

我会记录自己在哪一步分流错误，例如把属性题误判成数量题，或者统一计数口径时漏了端点和外部区域。然后写出最终规则，并找一幅已知图验证、再找一幅可能推翻它的图做反例检查。这样复盘保留的是识别顺序和判断依据，而不是对具体图案的记忆。
