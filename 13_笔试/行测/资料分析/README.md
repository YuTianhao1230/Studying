# 资料分析

本目录整理资料分析的题型地图、核心公式、速算方法和公开真题案例。目标是在保证口径、时间、主体和单位正确的前提下，提高定位与计算速度。

## 训练顺序

1. 先用题型地图和核心公式建立统一口径。
2. 再训练速算技巧、增长类题型及比重平均数与倍数。
3. 最后做材料阅读、综合判断和真题案例，记录定位错误、口径错误与计算错误。
