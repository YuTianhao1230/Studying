# 资料分析考纲题型地图

## 知识点解析

### 概述

资料分析的考纲范围可以概括为“读材料、找数据、套统计关系、做近似计算”。材料形式包括文字、表格、柱状图、折线图、饼图和综合材料；题型包括直接查找、增长类、比重类、平均数类、倍数类、贡献率与拉动增长、指数、进出口和综合判断。标准方法是先识别统计口径，再确定公式，最后根据选项差距选择精算或估算。

### 材料类型

| 材料 | 读法 |
| --- | --- |
| 文字材料 | 先圈主体、时间、单位和指标，避免信息串行读错 |
| 表格材料 | 先看行列含义，再按题干关键词定位单元格 |
| 柱状图 | 适合比较数量大小和增减变化 |
| 折线图 | 适合看趋势、增速和峰谷 |
| 饼图 | 适合看结构占比 |
| 综合材料 | 先判断题目落在哪一张图表或哪一段文字 |

### 标准题型范围

| 题型 | 问法 | 方法 |
| --- | --- | --- |
| 直接查找 | 最大、最小、多少、第几 | 定位后核对单位 |
| 增长率 | 增长了百分之几 | $\frac{\text{现期}-\text{基期}}{\text{基期}}$ |
| 增长量 | 增加多少 | $\text{现期}-\text{基期}$ 或 $\frac{\text{现期}\times r}{1+r}$ |
| 基期量 | 上年/去年为多少 | $\frac{\text{现期}}{1+r}$ |
| 比重 | 占比、比重 | $\frac{\text{部分}}{\text{整体}}$ |
| 基期比重 | 上年占比 | $\frac{\text{部分}}{\text{整体}}\times\frac{1+\text{整体}r}{1+\text{部分}r}$ |
| 平均数 | 人均、单位量 | $\frac{\text{总量}}{\text{份数}}$ |
| 倍数 | 是几倍、多几倍 | 直接相除或相除后减 1 |
| 拉动增长 | 拉动几个百分点 | $\frac{\text{部分增量}}{\text{整体基期}}$ |
| 贡献率 | 贡献多少 | $\frac{\text{部分增量}}{\text{整体增量}}$ |
| 指数 | 以某期为 100 | $100\times\frac{\text{现期}}{\text{基期}}$ |
| 进出口 | 顺差、逆差、总额 | 出口、进口、差额分别处理 |

### 复合问法识别

| 问法 | 先做什么 | 完整方法 |
| --- | --- | --- |
| 上年两指标相差多少 | 各还原基期，再相减 | [增长类题型](<增长类题型.md#增长类题型>) |
| 合计增速或某部分权重 | 用基期量加权、线段反比 | [增长类题型](<增长类题型.md#增长类题型>) |
| 二季度同比，给半年与一季度 | 累计现期、累计基期分别作差 | [增长类题型](<增长类题型.md#增长类题型>) |
| 哪个比值更大 | 交叉相乘、同基准、差分 | [速算技巧](<速算技巧.md#速算技巧>) |
| 平均数增加多少而非增长多少 | 先还原基期平均数再相减 | [比重平均数与倍数](<比重平均数与倍数.md#比重平均数与倍数>) |

自编识别例：收入增长 20%、人数增长 10%，问“人均收入增长率”。分子是收入，分母是人数，故为 $\frac{1.2}{1.1}-1\approx9.09\%$；不是收入增速 20%，也不是两增速直接相减的 10%。先认清题型再选公式。

### 综合判断题

综合判断题通常一题四个选项，每个选项对应一种小题型。常见设错位置是主体、时间、单位、增长率与增长量、百分点与百分比。先看问“正确”还是“不正确”，再按读数、简单比较、复杂计算的成本核验；单选题找到符合问法的确定项才停止，不按字母位置猜测。

## 笔试应对

### 常考题型

- 图表定位题考材料阅读速度。
- 增长、比重、平均数、倍数题考公式识别。
- 综合判断题考多口径核对。
- 进出口题考顺差、逆差和混合增速。

### 解题方法

先按题干关键词确定题型，再去材料定位；定位时核对时间、主体和单位；计算时看选项差距决定精度。综合判断题不逐项精算，找到确定项就停。

### 易错点

- 把增长量和增长率混用。
- 忽略单位换算。
- 基期、现期拿反。
- 比重差写成百分比。

## 面试应对

### 如何概括资料分析的完整解题流程？

回答思路：按审题、定位、建模、计算和校验五步回答，突出统计口径先于公式和计算。

回答模板：

我会先审题，圈出时间、主体、指标、单位和所求；再根据关键词回到材料定位数据；随后判断是增长、比重、平均数、倍数还是综合关系，并写出对应式子。计算时根据选项差距决定估算或精算，最后检查基期与现期、百分数与百分点、部分与整体以及单位是否一致。资料分析的核心不是背公式，而是先保证口径和关系正确。

### 面对复合问法，如何选择正确公式？

回答思路：先拆分分子、分母及其时期，再判断所求是量、率、比重还是差值，必要时先还原中间量。

回答模板：

复合问法不能直接按关键词套公式。我会先把所求量写成分子和分母，分别标明主体、时间和单位，再判断题目要现期值、基期值、增长率、增长量还是比重差。比如平均数增长本质上是两个比值的变化，累计期间的单季数据则要先用累计量作差。只要先拆清统计关系，复杂题通常可以还原成几种基础公式的组合。

### 资料分析中什么时候估算，什么时候精算？

回答思路：依据选项差距、误差传播和比较目标选择精度；先估算筛选，接近边界时再精算。

回答模板：

如果选项差距大，或只比较大小和趋势，我会采用截位、直除、差分或近似基期量来降低计算量；如果选项接近、多个近似误差会叠加，或题目涉及百分点、贡献率等易混口径，就保留更多有效数字。估算必须有误差意识，能够确认近似结果不会跨过选项边界；无法确认时应对最接近的候选项精算，而不是继续扩大近似。

### 综合判断题如何安排核验顺序和停止条件？

回答思路：先核验定位和比较成本低的选项，再做复杂计算；找到符合题问的确定项后停止，同时防止看反“正确/不正确”。

回答模板：

我会先确认题目问正确还是不正确，再按成本排序核验选项：直接读数、单位和明显大小关系优先，简单增长或比重其次，跨期复合计算最后。每个选项都先核对主体、时间和统计口径，再决定是否计算。单选题找到与题问一致且证据充分的确定项后即可停止；如果只是近似判断或存在口径疑点，则必须继续核验，不能按选项位置猜答案。
