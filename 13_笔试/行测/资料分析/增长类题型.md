# 增长类题型

## 知识点解析

### 概述

增长类题型是资料分析的半壁江山，围绕现期量、基期量、增长量、增长率、年均增长、间隔增长和增长量比较展开。解题关键是先判断题干问的是“率”还是“量”，再确定已知条件是现期、基期还是增长率。增长题最常用的[速算技巧](<速算技巧.md>)是百化分和 `1/n` 法。

### 基础公式

| 问法 | 公式 |
| --- | --- |
| 增长率 | `r = (现期 - 基期) / 基期` |
| 增长量 | `现期 - 基期` |
| 已知基期和增长率求现期 | `现期 = 基期 x (1 + r)` |
| 已知现期和增长率求基期 | `基期 = 现期 / (1 + r)` |
| 已知现期和增长率求增长量 | `增长量 = 现期 x r / (1 + r)` |

### 1/n 法

增长率或下降幅度的绝对值约为 `1/n` 时（下降要求 `n>1`）：

```text
增长量 约等于 现期 / (n + 1)
下降量 约等于 现期 / (n - 1)
```

自编例：现期 800、增长率 14.3% 约等于 1/7，则增长量约为 100；精算 `800×0.143/1.143≈100.09`。若是下降 20%，现期 800，则下降量为 `800/(5-1)=200`，基期为 1000。

### 增长量比较

精确公式：

```text
增长量 = 现期 x r / (1 + r)
```

当增长率不大时，可近似看：

```text
增长量 约等于 现期 x r
```

现期量均为正、增长率均非负时，现期大且增长率也大，可直接判断增长量不小；负增长时不能照搬。交叉大小时应比较完整的 `现期×r/(1+r)`。

自编反例：甲现期 110、增长 10%，乙现期 60、增长 20%。只看 `现期×r` 得 11 与 12，但真实增量均为 10。近似法的相对高估幅度恰为 r，接近选项尤其不能省略分母。

### 年均增长

| 题型 | 公式 |
| --- | --- |
| 年均增长量 | `(现期 - 基期) / n` |
| 年均增长率 | `(现期 / 基期)^(1/n) - 1` |

`n` 是间隔年数。例如 2018 到 2021 是 3 年。问“年均增长最快”看年均增长率，问“年均增长最多”看年均增长量。

### 间隔增长率

连续两年增长率为 `r1`、`r2`，隔一年总增长率为：

```text
R = r1 + r2 + r1 x r2
```

若 `r1`、`r2` 很小，先用 `r1 + r2` 粗估，再根据选项判断是否补乘积项。

### 混合增长与线段法

适用条件：两部分不重不漏组成整体、统计期一致、两部分基期量均为正。设基期量为 B1、B2，增速为 r1、r2：

```text
R = (B1×r1 + B2×r2)/(B1+B2)
若 r1 > R > r2，则 B1:B2 = (R-r2):(r1-R)
```

步骤：先确认加总口径，再将三个增速放在线段上；两端基期量之比等于到整体增速距离的反比。已知现期量时，先各自除以 `1+r`。

自编例：甲现期 120、增长 20%，乙现期 330、增长 10%。基期分别 100、300，整体增长 `(450-400)/400=12.5%`；线段距离得 `甲基期:乙基期=2.5:7.5=1:3`。

陷阱：用现期 120:330 加权会算出约 12.67%，不是精确值；两部分增速相同不能反推权重；净出口、利润差额等含相减关系，不适用正权重“居中”结论。

### 基期差与基期和

适用条件：两个可比指标各给现期及同比，要求上年差额或合计；现期作差后一般不能直接除以某一方增速。

步骤：分别还原基期，再加减；增速相同才可提取共同分母。

```text
基期差 = A/(1+a) - B/(1+b)
基期和 = A/(1+a) + B/(1+b)
```

自编例：出口现期 120、增长 20%，进口现期 88、增长 10%；上年顺差 `100-80=20`，现期顺差 32，顺差增长 60%。不能把 32 除以 1.2 或 1.1。

陷阱：两项接近时，分别粗估再相减会放大相对误差；差额为零时增速无定义，基期为负时应按题设口径解释。

### 增速变化与累计拆分

适用条件：增速“提高/回落几个百分点”是加减百分点；累计量拆当期要求统计范围一致且可加。

步骤：先还原上一期增速，再算增长关系；累计材料先分别还原各自基期，不能直接相减累计增长率。

自编例：上半年 220、同比 10%，一季度 120、同比 20%；二季度现期 `220-120=100`，基期 `220/1.1-120/1.2=100`，同比为 0%，不是 `10%-20%=-10%`。本年增速 8%、较上年回落 2 个百分点，上年增速是 10%。

陷阱：累计平均数、累计比重和累计增速不是可直接相减的总量。

## 笔试应对

### 常考题型

- 已知现期和增长率，求基期或增长量。
- 比较多个行业、地区的增长量大小。
- 求年均增长率或年均增长量。
- 用两年增速求间隔增长率。

### 解题方法

先判断问的是增长率、增长量、基期还是年均。能控制误差时用百化分；增长量交叉比较保留 `1+r`，混合增长找基期权重，基期差分别还原，间隔增长保留乘积项核验。

### 易错点

- 增长量比较只看增长率。
- 基期公式忘记除以 `1 + r`。
- 下降题仍按增长题套 `n + 1`。
- 年均增长的间隔年数数错。
