# 比重平均数与倍数

## 知识点解析

### 概述

比重、平均数和倍数是资料分析中最容易因概念混淆而丢分的题型。比重看部分与整体，平均数看总量与份数，倍数看两个量之间的比值。解题时要先判断题干在问“占多少”“平均多少”还是“是几倍/多几倍”，再套对应公式。

### 比重三件套

| 题型 | 公式 |
| --- | --- |
| 现期比重 | `部分 / 整体` |
| 基期比重 | `(部分 / 整体) x (1 + 整体增长率) / (1 + 部分增长率)` |
| 两期比重差 | `现期比重 x (部分增长率 - 整体增长率) / (1 + 部分增长率)` |

方向判断：

```text
部分增长率 > 整体增长率 -> 比重上升
部分增长率 < 整体增长率 -> 比重下降
```

### 百分点

比重差的单位是“百分点”。例如：

```text
30% - 25% = 5 个百分点
```

不能说“增长 5%”。`%` 表示比例，百分点表示两个百分数相减后的差值。

### 平均数

平均数公式：

```text
平均数 = 总量 / 份数
```

平均数增长率：

```text
r = (a - b) / (1 + b)
```

其中 `a` 是总量增长率，`b` 是份数增长率。若总量增长率大于份数增长率，则平均数上升；反之下降。

### 倍数

| 表述 | 含义 |
| --- | --- |
| A 是 B 的 n 倍 | `A / B = n` |
| A 比 B 多 n 倍 | `A / B - 1 = n` |
| A 比 B 增长 n% | `(A - B) / B = n%` |

“多 2 倍”等于“是 3 倍”，这是倍数题最高频陷阱。

### 两期比重与平均数的核算

适用条件：部分包含于整体、份数为正、两期统计范围一致，相关基期量为正。步骤：先列现期比值，再用增长因子还原基期，最后分清“比值差”与“比值增长率”。

自编例：某类产品现期销售额 120，总额 300，分别增长 20%、10%。现期比重 40%，基期比重 `100/(300/1.1)=36.67%`，上升 `40%×(20%-10%)/1.2=3.33` 个百分点；比重本身的相对增长率却是 `40%/36.666…%-1≈9.09%`。

自编例：现期收入 240 万元、员工 120 人，分别增长 20%、10%。人均收入现期 2 万元，基期 `2×1.1/1.2≈1.83` 万元，增量约 0.17 万元，增长率 `(20%-10%)/1.1≈9.09%`。

陷阱：平均数增长率的分母为 `1+份数增速`；比重差公式的分母为 `1+部分增速`，两式不能混用。

### 合并平均数的权重

适用条件：两组对象不重不漏、平均指标和单位相同。步骤：用“组均值×组人数”恢复总量，加总后除以总人数；未知人数比可用[增长类题型](<增长类题型.md>)中的加权线段关系，但权重此时为人数。

自编例：甲组 10 人均分 80，乙组 30 人均分 60，合计均分 `(10×80+30×60)/40=65`，不是 70；以 65 为中点，人数比 `(65-60):(80-65)=1:3`。

陷阱：只在两组权重相同时才能直接算两个平均数的算术平均；人均、店均、单位面积等分别用相应人数、门店数、面积加权。

## 笔试应对

### 常考题型

- 问某部分占整体的比重。
- 问基期比重或比重变化方向。
- 问平均数是否上升、平均数增长率是多少。
- 问 A 是 B 的几倍或比 B 多几倍。

### 解题方法

比重题先找部分和整体；平均数题先找总量和份数；倍数题先判断“是几倍”还是“多几倍”。比重变化方向只看部分增长率和整体增长率的大小。

### 易错点

- 把百分点写成百分号。
- 基期比重增长率项写反。
- 平均数增长率把总量增速和份数增速混淆。
- “多 n 倍”误解为“是 n 倍”。

## 面试应对

### 1. 两期比重题怎样先判断变化方向？

- 常考点及考法：给出部分和整体增速，要求判断比重升降或计算百分点变化。
- 回答思路：比较部分增速与整体增速判断方向，需要数值时再代入两期比重差公式。
- 易错点：先做复杂除法，或把比重差的百分点误写成相对增长百分比。
- 回答模板：比重等于部分除以整体，因此部分增速大于整体增速时比重上升，反之下降。若还要求变化量，我使用“现期比重乘以部分增速与整体增速之差，再除以一加部分增速”。计算结果是百分点，不是比重的相对增长率。

### 2. 平均数增长率公式如何理解和记忆？

- 常考点及考法：给出总量增速和份数增速，要求判断平均数变化或求其增长率。
- 回答思路：从平均数等于总量除以份数出发，用两个增长因子的比值推导。
- 易错点：直接用总量增速减份数增速，遗漏分母 `1+b`。
- 回答模板：平均数等于总量除以份数。设总量增速为 a、份数增速为 b，两期平均数之比是 `(1+a)/(1+b)`，所以平均数增长率为 `(a-b)/(1+b)`。方向可以先比较 a 和 b，只有需要具体数值时再计算完整公式。

### 3. “是几倍”和“多几倍”有什么区别？

- 常考点及考法：通过相近文字表述考查倍数与增长率的基准。
- 回答思路：先算 `A/B`，再根据题目问法决定是否减 1。
- 易错点：把“A 比 B 多 2 倍”理解成“A 是 B 的 2 倍”。
- 回答模板：“A 是 B 的几倍”直接计算 `A/B`；“A 比 B 多几倍”计算 `(A-B)/B`，也就是 `A/B-1`。因此 A 比 B 多 2 倍，表示 A 是 B 的 3 倍。遇到倍数题我会先确认比较基准，再决定是否减 1。
