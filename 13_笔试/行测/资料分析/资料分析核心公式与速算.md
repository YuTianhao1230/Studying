# 资料分析核心公式与速算

## 使用定位

本卡只负责题型识别和公式速查。公式推导、成立条件与核算例分别见[增长类题型](<增长类题型.md>)、[比重平均数与倍数](<比重平均数与倍数.md>)和[速算技巧](<速算技巧.md>)；完整公开题解见[资料分析真题案例](<资料分析真题案例.md>)。

## 题型识别

| 题面关键词 | 所求结构 | 公式区域 |
| --- | --- | --- |
| 同比、环比、增加/减少多少、上年、年均 | 现期、基期、增长量或增长率 | 增长类 |
| 隔年、连续两期增速、整体与部分增速 | 间隔增长或混合增长 | 间隔与混合增长 |
| 占、比重、百分点 | 部分与整体的比值或比重差 | 比重 |
| 人均、户均、单位面积、每家 | 总量除以份数 | 平均数 |
| 是几倍、多几倍 | 比值或比值减 1 | 倍数 |
| 拉动、贡献、指数 | 部分增量/整体基期、部分增量/整体增量或现基期比值 | 拉动、贡献与指数 |
| 顺差、逆差、进出口总额 | 出口与进口的和差 | 进出口 |
| 选项差距大、百分数接近简单分数、两个比值接近 | 截位、百化分、反向代入或分数比较 | 速算 |

## 增长类公式

| 题型 | 公式 |
| --- | --- |
| 增长率 | $r=\frac{\text{增长量}}{\text{基期}}=\frac{\text{现期}-\text{基期}}{\text{基期}}$ |
| 现期量 | $\text{现期}=\text{基期}\times(1+r)$ |
| 基期量 | $\text{基期}=\frac{\text{现期}}{1+r}$ |
| 增长量 | $\text{现期}-\text{基期}=\text{基期}\times r=\frac{\text{现期}\times r}{1+r}$ |
| 年均增长量 | $\frac{\text{现期}-\text{基期}}{n}$ |
| 年均增长率 | $\left(\frac{\text{现期}}{\text{基期}}\right)^{1/n}-1$ |

$n$ 为间隔期数，不是端点个数。下降率按负增长率代入增长母式；若题目直接给下降幅度 $d>0$，则基期量为 $\frac{\text{现期}}{1-d}$。

## 间隔与混合增长

| 题型 | 公式或识别条件 |
| --- | --- |
| 连续两期增长 | $R=r_1+r_2+r_1r_2$ |
| 两部分混合增长 | $R=\frac{B_1r_1+B_2r_2}{B_1+B_2}$，$B_1,B_2$ 为基期量 |
| 混合增长线段关系 | 若 $r_1>R>r_2$，则 $B_1:B_2=(R-r_2):(r_1-R)$ |
| 基期差 | $\frac{A}{1+a}-\frac{B}{1+b}$ |
| 基期和 | $\frac{A}{1+a}+\frac{B}{1+b}$ |

混合增长要求各部分不重不漏、统计口径一致且基期权重为正。已知现期量时须先分别还原基期；差额指标不能直接套正权重居中关系。

## 比重、平均数与倍数

| 题型 | 公式或判断 |
| --- | --- |
| 现期比重 | $\frac{\text{部分}}{\text{整体}}$ |
| 基期比重 | $\frac{\text{部分}}{\text{整体}}\times\frac{1+r_{\text{整体}}}{1+r_{\text{部分}}}$ |
| 两期比重差 | $\text{现期比重}\times\frac{r_{\text{部分}}-r_{\text{整体}}}{1+r_{\text{部分}}}$ |
| 比重方向 | 部分增速大于整体增速则比重上升，反之下降 |
| 平均数 | $\frac{\text{总量}}{\text{份数}}$ |
| 平均数增长率 | $\frac{a-b}{1+b}$，$a$ 为总量增速，$b$ 为份数增速 |
| A 是 B 的几倍 | $\frac{A}{B}$ |
| A 比 B 多几倍 | $\frac{A}{B}-1$ |

比重差使用“百分点”；“多 $n$ 倍”表示“是 $n+1$ 倍”。

## 拉动增长、贡献率与指数

| 概念 | 公式 | 单位或识别 |
| --- | --- | --- |
| 拉动增长 | $\frac{\text{某部分增量}}{\text{整体基期量}}\times100$ | 个百分点 |
| 贡献率 | $\frac{\text{某部分增量}}{\text{整体增量}}\times100\%$ | 百分比 |
| 二者关系 | $\text{拉动增长}=\text{贡献率}\times\text{整体增长率}$ | 统计口径一致时成立 |
| 指数 | $100\times\frac{\text{现期}}{\text{基期}}$ | 指数点 |
| 同基指数跨期增速 | $\frac{\text{本期指数}}{\text{上期指数}}-1$ | 两期须采用同一基准 |

拉动增长与贡献率要求部分、整体可加且统计口径一致；贡献率要求整体增量不为 0，拉动增长要求整体基期量不为 0。指数跨期比较须使用同一基准。

存在负增长部分时，正增长部分的增量可能大于正负抵消后的整体增量，因此其贡献率可以超过 100%。例如两部分增量分别为 15 和 -5，整体增量为 10，则前者贡献率为 150%，后者为 -50%，二者仍合计 100%；不能仅因贡献率超出 $[0,100\%]$ 就判错。

指数点是以选定基期为 100 后得到的相对水平，不是实际量，也不能把指数点差直接当增长率。同基指数从 120 点升至 132 点，增长率为 $\frac{132}{120}-1=10\%$，指数点差为 12 点；若不知道基期实际量，也不能据此推出实际增加量。

## 进出口

| 概念 | 公式 |
| --- | --- |
| 顺差 | $\text{出口额}-\text{进口额}>0$ |
| 逆差 | $\text{进口额}-\text{出口额}>0$ |
| 进出口总额 | $\text{出口额}+\text{进口额}$ |

净出口是差额，不能把出口增速和进口增速直接平均；基期顺逆差应分别还原出口与进口后再作差。

## 速算公式与识别

| 信号 | 速算关系 | 适用提醒 |
| --- | --- | --- |
| $r\approx1/n$，求增长量 | $\text{增长量}\approx\frac{\text{现期}}{n+1}$ | 选项接近时用精确式核验 |
| 下降幅度 $d\approx1/n$，求下降量 | $\text{下降量}\approx\frac{\text{现期}}{n-1}$ | 要求 $n>1$ |
| $r\approx m/n$，求增长量 | $\text{增长量}\approx\frac{\text{现期}\times m}{n+m}$ | $m>1$ 时不能套 $n+1$ 法 |
| 小增速求基期 | $\frac{1}{1+r}\approx1-r+r^2$ | 余项为 $-\frac{r^3}{1+r}$，增速大或选项近时不用 |
| 两个正分数比较 | 优先交叉相乘；差值小时可用差分法 | 只比较大小，不把比较法当求商公式 |
| 普通除法 | 按选项间距截位直除 | 结果区间跨选项时增加有效位或精算 |

速算精度由选项间距决定。只有误差区间唯一对应一个选项时才能停止计算，具体方法、边界和例题统一进入[速算技巧](<速算技巧.md>)。
