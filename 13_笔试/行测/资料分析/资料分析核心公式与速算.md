# 资料分析核心公式与速算

## 知识点解析

### 概述

资料分析主要考查对统计材料中现期、基期、增长率、增长量、比重、平均数、倍数、贡献率和进出口关系的快速定位与计算。它的题型固定、公式稳定，得分关键在于先识别题型，再选择公式，最后用截位直除、百化分、首数法、尾数法和差分法减少计算量。资料分析不是比谁算得精，而是比谁能在保证选项区分度的前提下算得足够快。

### 速算基础

#### 百化分

| 分数 | 百分数 |
| --- | --- |
| 1/7 | 14.3% |
| 1/11 | 9.1% |
| 1/12 | 8.3% |
| 1/13 | 7.7% |
| 1/14 | 7.1% |
| 1/15 | 6.7% |

当增长率 `r` 近似等于 `1/n` 时：

| 情况 | 秒算公式 |
| --- | --- |
| 已知现期和增长率，求增长量 | 增长量约等于 `现期 / (n + 1)` |
| 已知现期和下降率，求下降量 | 下降量约等于 `现期 / (n - 1)` |
| 比较增长量 | 正现期、非负增速下可用同向大小判断；交叉大小比较完整 `现期量 x r/(1+r)` |

#### 截位直除

| 选项差距 | 截位策略 |
| --- | --- |
| 选项首位不同或差距大 | 分母截两位 |
| 首位相同，次位差大于首位 | 分母截两位 |
| 首位相同，次位差小于等于首位 | 分母截三位 |

表中截位策略只是经验起点，不保证误差。选项接近时应多保留有效位或用上下界核验，具体见[速算技巧](<速算技巧.md>)的区间例。

#### 常用速算法

- 尾数法：精确整数加减、乘法及正整数次幂可按模 10 或模 100 计算，不能直接用于除法及近似统计量。
- 特征数字法：把除法转为乘法，例如 `÷12.5% = x8`，`÷33.3% 约等于 x3`。
- 差分法：比较两个接近分数 `A/B` 与 `C/D`，可用差分数 `(A-C)/(B-D)` 与小分数比较。

### 增长相关

| 题型 | 公式 |
| --- | --- |
| 增长率 | `r = 增长量 / 基期 = (现期 - 基期) / 基期` |
| 增长量 | `增长量 = 现期 - 基期 = 基期 x r = 现期 x r / (1 + r)` |
| 基期量 | `基期 = 现期 / (1 + r)` |
| 现期量 | `现期 = 基期 x (1 + r)` |
| 年均增长量 | `(现期 - 基期) / 间隔年数` |
| 年均增长率 | `(现期 / 基期)^(1/n) - 1` |

年均题最容易错在年数。比如 2018 到 2021 是 3 年，不是 4 年。问“年均增长最快”通常比较年均增长率，问“年均增长最多”通常比较年均增长量。

### 间隔增长率与混合增长率

间隔增长率用于连续两期增长后的总增速：

```text
R = r1 + r2 + r1 x r2
```

当两个增长率都较小时，可以先用 `r1 + r2` 粗估，再看选项是否需要补乘积项。

混合增长率要求同口径部分不重不漏、基期权重为正；两部分时整体增速介于两端，并偏向基期量较大的一端。设 `r1>R>r2`：

```text
部分1基期量 : 部分2基期量 = (R-r2) : (r1-R)
```

常见场景包括进出口混合、城乡混合、线上线下混合和行业内部结构混合。

现期权重须先还原基期，基期差须分别还原再相减；完整步骤和自编核算例见[增长类题型](<增长类题型.md>)。

### 比重三件套

| 题型 | 公式与判断 |
| --- | --- |
| 现期比重 | `部分 / 整体` |
| 基期比重 | `(部分 / 整体) x (1 + 整体r) / (1 + 部分r)` |
| 两期比重差 | `现期比重 x (部分r - 整体r) / (1 + 部分r)` |
| 比重变化方向 | 部分增长率大于整体增长率，比重上升；反之下降 |

比重差的单位是“百分点”，不是百分号。比如 `30% - 25% = 5 个百分点`，不能写成“增加 5%”。

### 平均数与倍数

平均数等于 `总量 / 份数`。平均数增长率公式为：

```text
r = (a - b) / (1 + b)
```

其中 `a` 是总量增长率，`b` 是份数增长率。

倍数题要区分“是几倍”和“多几倍”：

| 表述 | 计算 |
| --- | --- |
| A 是 B 的 n 倍 | `A / B = n` |
| A 比 B 多 n 倍 | `A / B - 1 = n`，即 A 是 B 的 `n + 1` 倍 |

### 拉动增长、贡献率与指数

| 概念 | 公式 | 单位 |
| --- | --- | --- |
| 拉动增长 | `某部分增量 / 整体基期量 x 100` | 个百分点 |
| 贡献率 | `某部分增量 / 整体增量 x 100%` | `%` |
| 指数 | `100 x 现期 / 基期` | 指数点 |

指数以某一期为 100。指数从 100 到 105，表示增长 5%，不是增长 5 个单位的实际量。

适用条件：贡献率、拉动增长都要求部分和整体可加且统计口径一致；贡献率要求整体增量不为零，拉动增长要求整体基期量不为零。指数跨期比较须采用相同基准。步骤：先找所求指标的分母，再核对单位。

自编例：整体基期 200、增量 20，某部分增量 8，则贡献率 `8/20=40%`，拉动 `8/200×100=4` 个百分点，整体增长 10%，并有 `40%×10%=4%`。另一部分若下降，某部分贡献率可以超过 100%。同基指数从 120 到 132，增长 `132/120-1=10%`，不是 12%。

### 进出口

| 概念 | 公式 |
| --- | --- |
| 顺差 | `出口额 - 进口额 > 0` |
| 逆差 | `进口额 - 出口额 > 0` |
| 进出口总额 | `出口额 + 进口额` |

净出口增速不能简单用出口增速和进口增速平均。涉及进出口混合时，要分别算出口、进口或总额的基期和增量。

## 笔试应对

### 常考题型

- 给出现期和增长率，问增长量、基期量或基期比重。
- 给出两个年份数据，问增长率、年均增长率或年均增长量。
- 给出部分和整体，问现期比重、基期比重、比重上升还是下降。
- 给出两个部分的增长率，问整体增长率范围或混合增长率。
- 综合判断题让判断四个选项正误，常在单位、年份、主体和百分点上设错。

### 解题方法

1. 先看题干关键词：增长率、增长量、基期、比重、百分点、平均数、倍数。
2. 再定位材料里的主体、时间、单位，避免拿错数据。
3. 选公式，不急着计算。
4. 看选项差距，决定用截位、百化分、首数法还是精算。
5. 综合判断题先确认问正确还是不正确，优先验证最易定位或计算的项；单选且已确定符合问法的唯一项才停止。

### 易错点

- 增长量比较只看增长率，忽略现期量或基期量。
- 基期公式把 `1 + r` 写成 `1 - r`，尤其是下降率题。
- 年均增长率的 `n` 数错，把年份个数当间隔年数。
- 把“百分点”和“%”混用。
- “多 2 倍”误算成“是 2 倍”，正确是“是 3 倍”。
- 综合判断题忽略单位，例如亿元、万人、万美元、百分号。

## 面试应对

### 1. 资料分析的完整作答流程是什么？

- 常考点及考法：要求说明从材料定位、题型识别到计算复核的稳定步骤。
- 回答思路：依次完成口径核对、公式选择、算法选择和结果校验。
- 易错点：看到数字立即计算，或只检查算式而不复核主体、时间和单位。
- 回答模板：我先根据题干定位主体、时间、指标和单位，再识别所求属于增长、比重、平均数还是倍数。确定公式后观察选项差距，选择截位、百化分或精算；得到结果后再核对数量级、方向和单位。资料分析首先是口径题，其次才是计算题。

### 2. 增长量、基期量和比重公式怎样避免混淆？

- 常考点及考法：给出现期和增速，追问不同指标公式的来源与分母。
- 回答思路：以 `现期=基期×(1+r)` 为增长母式，以“部分/整体”为比重定义逐步推导。
- 易错点：背孤立公式，把基期量写成 `现期/(1-r)`，或把比重差和平均数增速的分母互换。
- 回答模板：增长类公式都从 `现期=基期×(1+r)` 变形，基期是 `现期/(1+r)`，增长量是 `现期×r/(1+r)`。比重始终从“部分除以整体”出发，两期比重差的分母是一加部分增速；平均数增长率的分母则是一加份数增速。我通过定义推导，不孤立死记。

### 3. 什么时候可以速算，什么时候必须精算？

- 常考点及考法：给出选项间距不同的计算题，要求说明精度决策。
- 回答思路：先估结果量级和误差上界，只有近似区间唯一落入某个选项时才停止。
- 易错点：固定截两位，或估算值落在两个选项之间仍凭感觉选择。
- 回答模板：速算精度由选项间距决定。我会先判断数量级，再选择截位、特征数字或百化分，并估计近似方向和误差。若整个可能区间都只对应一个选项，就无需继续；若结果靠近分界或两个选项很接近，就增加有效位或改用精算。

### 4. 贡献率和拉动增长有什么区别？

- 常考点及考法：考查两个指标的分母、单位及其与整体增长率的关系。
- 回答思路：分别用整体增量和整体基期量作分母，并核对部分与整体是否同口径可加。
- 易错点：把贡献率写成百分点，或认为部分贡献率一定不超过 100%。
- 回答模板：贡献率等于某部分增量除以整体增量，单位是百分比；拉动增长等于某部分增量除以整体基期量，单位是百分点。二者要求部分和整体统计口径一致。部分之间存在负增长时，某部分贡献率可以超过 100%，所以不能仅凭范围判断错误。
