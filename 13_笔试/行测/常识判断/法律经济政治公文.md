# 法律经济政治公文

## 知识点解析

### 概述

法律、经济、政治和公文是常识判断中最稳定的制度类考点。法律题重在部门法归属和基本原则，经济题重在指标含义和宏观政策，政治题重在党史、哲学和国家制度，公文题重在文种用途和行文关系。这类题不要求深度论述，但要求概念边界清楚。

### 法律

| 部门法 | 高频范围 |
| --- | --- |
| 宪法 | 根本法、国家机构、公民基本权利和义务 |
| 民法 | 民事主体、民事行为能力、物权、合同、侵权、诉讼时效 |
| 刑法 | 犯罪构成、刑事责任年龄、正当防卫、紧急避险 |
| 行政法 | 行政许可、行政处罚、行政复议、行政诉讼 |

易混：民事行为能力属于民法，刑事责任年龄属于刑法。

#### 民事主体与法律行为

| 主体或制度 | 判断规则 |
| --- | --- |
| 未满8周岁 | 无民事行为能力，由法定代理人代理实施民事法律行为 |
| 8周岁以上未成年人 | 一般为限制民事行为能力；可独立实施纯获利益及与年龄、智力相适应的行为 |
| 16周岁以上未成年人，以自己劳动收入为主要生活来源 | 视为完全民事行为能力人；仅有零花钱或偶发收入不足以满足条件 |
| 成年人 | 一般为完全民事行为能力人；不能辨认或不能完全辨认自己行为的成年人另有规定 |
| 法人、法定代表人 | 法人是组织，法定代表人是依法代表组织从事民事活动的人 |
| 子公司、分公司 | 子公司有法人资格，依法独立承担民事责任；分公司不具有法人资格，其民事责任由公司承担 |

一般民事法律行为有效，需要相应行为能力、真实意思表示，以及不违反法律行政法规的强制性规定、不违背公序良俗。涉及欺诈、胁迫、重大误解等应区分可撤销与当然无效，不能看到“不公平”就直接判无效。

普通诉讼时效一般为3年，从权利人知道或应当知道权利受到损害以及义务人之日起计算；法律另有规定的从其规定。时效届满产生义务人抗辩权，不等于实体债权自动消灭。

#### 银行业务相关的担保与合同

- 抵押通常不转移财产占有；动产质押通常以交付质物设立，权利质押按相应规则办理。
- 保证分一般保证和连带责任保证，责任承担顺序不同。未约定或约定不明确时，按民法典认定为一般保证，不能沿用旧法答案。
- “定金”不同于“订金”。定金数额不得超过主合同标的额20%，超过部分不产生定金效力；适用定金罚则还需满足违约导致合同目的不能实现等法定条件。
- 同时约定违约金与定金，发生符合条件的违约时可选择适用其一，不能机械叠加两种罚则。

#### 行政与刑事责任辨析

罚款属于行政处罚，罚金属于刑罚；行政拘留不等于刑事拘留，后者属于刑事强制措施。没收违法所得、暂扣或吊销许可证件等属于法定行政处罚种类，不能将许可审批本身当处罚。

正当防卫针对正在进行的不法侵害；防卫过当需同时满足“明显超过必要限度”和“造成重大损害”。对正在进行的严重危及人身安全的暴力犯罪，另有特殊防卫规则。事后报复不属于正当防卫。

### 公司治理

公司以全部财产对债务承担责任；有限责任公司股东原则上以认缴出资额为限承担责任，但未履行出资义务、滥用法人独立地位等情形可能触发额外责任，不能把“有限责任”理解成绝对免责。

股东会负责法律与章程规定的重大事项，董事会执行股东会决议并作经营决策，经理按章程或董事会授权负责经营管理。监督机构设置需结合公司类型与现行法：2023年修订、2024年7月1日施行的公司法允许依章程在董事会设置审计委员会行使监事会职权，不设监事会或监事，不能认定所有公司都必须有监事会。

### 经济

| 考点 | 重点 |
| --- | --- |
| GDP/GNI | 境内生产与常住单位收入；GNI对应旧称GNP的收入概念，不能按国籍简单划分 |
| CPI/PPI | 消费者与生产者 |
| 恩格尔系数 | 食品支出占比，反映生活水平 |
| 基尼系数 | 收入分配差距 |
| 宏观调控 | 财政政策、货币政策 |
| 支出法GDP | 消费、投资、政府购买、净出口；口诀“三驾马车”不能代替完整核算公式 |

### 公文

| 文种 | 用途 |
| --- | --- |
| 请示 | 上行，请求批准，一文一事，事前行文 |
| 报告 | 上行，汇报工作或反映情况 |
| 批复 | 下行，答复请示 |
| 函 | 平行或不相隶属机关商洽、询问、答复 |
| 通知 | 发布、传达、批转 |
| 通报 | 表彰、批评、传达重要情况 |

#### 行文方法

1. 先看发文对象与隶属关系，再看具体用途。
2. 请求上级批准事项一般用请示，汇报已完成工作用报告；报告中不能夹带请示事项。
3. 不相隶属机关请求批准有关事项可用函，不能仅因“请求批准”就选请示。
4. 公告用于向国内外宣布重要事项或者法定事项；通告用于在一定范围内公布应当遵守或者周知的事项。
5. 纪要记载会议主要情况和议定事项；会议记录是对会议过程的记录，二者不等同。

法定文种“命令（令）”是一个文种；一般不得越级行文，特殊情况必须越级时应依规则办理。企业内部邮件、营销通知不因名称相同就自动成为党政机关法定公文。

## 典型题与解析

以下均为自编练习。

1. 17岁的小甲以稳定劳动收入为主要生活来源，能否独立实施与其相应的民事法律行为？  
   **答案：可以，视为完全民事行为能力人。** 关键条件是年龄与劳动收入来源同时满足。
2. 借款保证合同没有约定保证方式，按现行民法典如何认定？  
   **答案：一般保证。** 不按旧法“约定不明则连带”的记忆作答。
3. 某局向不相隶属的主管部门请求批准事项，用请示还是函？  
   **答案：函。** “不相隶属”优先于“请求批准”的表面关键词。
4. “公司法允许部分公司以董事会审计委员会承接监事会职权，所以监督职能消失。”是否正确？  
   **答案：错误。** 变化的是机构设置与职权承担方式，监督职能并未消失。

## 笔试应对

### 常考题型

- 法律题考部门法归属。
- 经济题考指标含义和政策工具。
- 政治题考党史节点和哲学规律。
- 公文题考文种用途和行文方向。

### 解题方法

先分类，再看关键词。法律看归属，经济看指标对象，政治看时间节点，公文看上行、下行还是平行。

### 易错点

- 民法和刑法概念混淆。
- GDP/GNP、CPI/PPI 混淆。
- 请示和报告混淆。
- 把函当成上下级机关文种。

## 面试应对

### 法律常识题应怎样确定适用规则？

回答思路：先分部门法，再核对主体、行为、时间和法定条件。

口述模板：

我会先判断问题属于民法、刑法还是行政法，再识别主体、行为性质和法律效果。民事行为能力不能与刑事责任年龄混用，罚款是行政处罚而罚金是刑罚，正当防卫还要求不法侵害正在进行。涉及法条变化时要按题目时点适用有效规则，不能沿用已经变化的旧结论。

### 经济指标和政策工具如何作答？

回答思路：说明统计对象或执行主体，再分析方向和边界。

口述模板：

经济指标先说测量对象，例如GDP强调境内生产，GNI强调常住单位收入，CPI和PPI分别关注消费端与生产端价格。政策工具则区分财政和货币主体，并结合操作方向判断扩张或紧缩。像“三驾马车”是需求拉动的概括，完整的支出法核算还包括政府购买和净出口，不能用口诀替代公式。

### 请示、报告和函怎样区分？

回答思路：以隶属关系、行文目的和事前事后为判断依据。

口述模板：

向有隶属关系的上级请求批准，一般使用请示，而且应一文一事、事前行文；向上级汇报工作或反映情况使用报告，报告中不能夹带请示事项。不相隶属机关之间商洽、询问、答复或请求批准有关事项，通常使用函。因此文种判断要同时看关系和用途，不能只抓“请求批准”四个字。

### 法律经济公文错题应怎样复盘？

回答思路：建立概念对照表，记录决定答案的条件和规则时点。

口述模板：

我会把错题整理成概念对照，例如抵押与质押、罚款与罚金、GDP与GNI、请示与函，并写出真正决定答案的主体、对象或程序条件。对法律和统计口径注明生效时间，对公文题补画发文机关与受文机关的关系。复盘时删除只记选项字母的信息，保留可以迁移到新题的判断标准。
