# 行测

行测侧重通用认知能力、信息处理能力与限时决策。本目录按建议训练顺序索引五个直属分支；各分支先掌握题型框架，再学习专项方法并用案例复盘。

## 内容索引

| 顺序 | 分支 | 训练重点 |
| ---: | --- | --- |
| 1 | [言语理解](<言语理解/README.md#言语理解>) | 结构阅读、语境辨析与语句表达 |
| 2 | [判断推理](<判断推理/README.md#判断推理>) | 图形、定义、类比、逻辑与空间推理 |
| 3 | [资料分析](<资料分析/README.md#资料分析>) | 材料定位、公式识别与速算 |
| 4 | [数量关系](<数量关系/README.md#数量关系>) | 题型建模、数字特性与取舍策略 |
| 5 | [常识判断](<常识判断/README.md#常识判断>) | 法律、政治、经济、文史与科技常识 |
