# 数量关系高频题型与秒杀方法

## 知识点解析

### 概述

数量关系以数量约束和数学模型为核心，常见方法包括代入排除、数字特性、赋值、和差倍比、盈亏及加权混合。题型包括工程、行程、利润、排列组合概率、容斥、最值、几何、年龄日期、植树方阵、牛吃草、溶液和数列。简化方法均依赖题设条件和选项区分度。

### 三种基础简化方法

| 方法 | 触发信号 | 做法 |
| --- | --- | --- |
| 代入排除 | 选项给具体数值 | 先代易算项；求最值可从端点开始，单调时才能排除整侧 |
| 数字特性 | 出现整数、倍数、余数、奇偶、整除 | 用末位、数字和、奇偶、倍数关系排除 |
| 赋值法 | 只给比例、效率、倍数，没有具体量 | 赋最小公倍数或特值，把比例变成整数 |

数量关系中，只要选项是具体数，优先考虑代入排除。很多题不需要列复杂方程。

### 数字特性

#### 整除规则

| 数 | 判断方法 |
| --- | --- |
| 2 | 末位为偶数 |
| 3 | 各位数字和能被 3 整除 |
| 4 | 末两位能被 4 整除 |
| 5 | 末位是 0 或 5 |
| 8 | 末三位能被 8 整除 |
| 9 | 各位数字和能被 9 整除 |

#### 奇偶与尾数

- 奇 + 偶 = 奇，偶 + 偶 = 偶，奇 + 奇 = 偶。
- 奇 x 奇 = 奇，只要有偶数相乘结果就是偶数。
- $a+b$ 与 $a-b$ 同奇偶。
- 乘方尾数有循环，2 的尾数 2、4、8、6 循环，5 恒为 5，6 恒为 6。

#### 倍数特性

若 a、b、m、n 均为正整数，$a=\frac{m}{n}b$，且 m、n 互质，则 a 是 m 的倍数，b 是 n 的倍数。近似比例或非整数数量不能直接套倍数结论。

### 工程问题

基本关系：

$$
\begin{aligned}
\text{工作总量} &= \text{工作效率}\times\text{工作时间} \\
\text{合作效率} &= \text{各自效率之和}
\end{aligned}
$$

给完工时间时，常用赋值总量法。比如甲 6 天完工，乙 8 天完工，总量赋为 24，则甲效率 4，乙效率 3，合作时间为 $\frac{24}{4+3}$。

给效率比时，常用赋效率法。比如甲乙效率比为 2:3，可设甲效率 2，乙效率 3，再根据时间或总量求解。

### 行程问题

| 类型 | 公式 |
| --- | --- |
| 基本行程 | $s=vt$ |
| 相遇 | $\text{路程和}=(v_1+v_2)t$ |
| 追及 | $\text{路程差}=(v_1-v_2)t$ |
| 流水行船 | 顺速 = 船速 + 水速，逆速 = 船速 - 水速 |
| 环形相遇 | 同地同时反向匀速出发，不计起点相遇，第 n 次再相遇合走 n 圈 |
| 时钟问题 | 时针 0.5 度/分，分针 6 度/分，追及速度 5.5 度/分 |

行程题最重要的是判断“相遇”还是“追及”。相遇用速度和，追及用速度差。

### 利润与经济问题

| 概念 | 公式 |
| --- | --- |
| 利润 | $\text{售价}-\text{进价}$ |
| 利润率 | $\frac{\text{利润}}{\text{进价}}$ |
| 折扣价 | $\text{原价}\times\text{折扣}$ |
| 总价 | $\text{单价}\times\text{数量}$ |

分段计费题按区间逐段算再相加，不能把最高档费率套到全部数量。总价一定时，单价和数量反向变化。

### 排列组合与概率

基本原则：

- 分类用加法。
- 分步用乘法。
- 相邻问题用捆绑法。
- 不相邻问题用插空法。
- 正面情况复杂时，先求反面，再用 $1-\text{对立概率}$。

常见公式：

| 类型 | 公式 |
| --- | --- |
| 排列 | $A_n^m=\frac{n!}{(n-m)!}$ |
| 组合 | $C_n^m=\frac{n!}{m!(n-m)!}$ |
| 圆桌排列 | n 人互异、旋转等价而镜像不等价时为 $(n-1)!$ |
| 平均分组 | 仅同规模且无标签的组除以对应组数的阶乘去重 |
| 概率 | 有限等可能样本空间中为 $\frac{\text{满足条件数}}{\text{总数}}$ |

### 容斥原理

| 类型 | 公式 |
| --- | --- |
| 两集合 | $\lvert A\rvert+\lvert B\rvert-\lvert A\cap B\rvert=\text{总数}-\text{都不满足}$ |
| 三集合 | $\lvert A\rvert+\lvert B\rvert+\lvert C\rvert-\text{两两交人数之和}+\lvert A\cap B\cap C\rvert=\text{总数}-\text{都不满足}$ |
| 非标准三集合 | $\lvert A\rvert+\lvert B\rvert+\lvert C\rvert-\text{只满足两项的人数}-2\lvert A\cap B\cap C\rvert=\text{总数}-\text{都不满足}$ |

容斥题先画集合关系或列公式，不要凭感觉加减。

### 最值问题

和定最值：

- 求某量最大，则其余量尽量小。
- 求某量最小，则其余量尽量大。
- 涉及不同整数时，常用等差构造。

最不利原则：

$$
\text{保证拿到 }n\text{ 件}=\text{最坏情况下仍差一点}+1
$$

例如要保证拿到某颜色球，先把不满足条件的最大数量都取完，再加 1。

### 几何与其他高频题型

几何题重点背基础公式和常见勾股数：

- 长方形、圆、三角形、柱体的周长、面积、体积。
- 勾股数：3-4-5、5-12-13、8-15-17 及其倍数。
- 不规则图形用割补、相似、等积变形。

其他题型：

| 题型 | 核心规则 |
| --- | --- |
| 年龄 | 年龄差永远不变，代入验证最稳 |
| 日期星期 | 平年 365 天，闰年 366 天，星期加减 7 等价 |
| 植树 | k 个间隔：两端栽 k+1、栽一端 k、两端不栽 k-1；环形 k |
| 方阵 | 实心方阵总数 $N^2$；N≥2 时外层 $4(N-1)$，N=1 为 1 |
| 牛吃草 | $y=(N-x)T$，$y$ 为原有量，$x$ 为草长速度 |
| 溶液 | 浓度 = 溶质 / 溶液，混合用十字交叉 |
| 数列 | 先看等差、等比、做差、做商、平方立方 |
| 余数同余 | 将条件写成 $N\bmod m=r$；同余数时 N-r 为各模数公倍数 |

## 笔试应对

### 常考题型

- 选项给具体数，考代入排除。
- 题干给比例、效率、时间，考赋值法。
- 出现整数、倍数、余数，考数字特性。
- 工程和行程题考基本公式和合作、相遇、追及。
- 排列组合考相邻、不相邻、分类分步、反面求解。
- 最值题考和定最值、最不利原则。

### 解题方法

1. 先判断题是否值得做：熟悉题型做，不熟悉先跳。
2. 有具体选项考虑代入，优先可快速核验或最值端点的选项。
3. 只有比例没有实际量，用赋值法。
4. 看到整数和倍数，用数字特性先筛选。
5. 工程题赋总量，行程题分清相遇和追及。
6. 时间不够时只保留能 1-2 分钟解决的题。

### 易错点

- 数量关系想全做，导致高性价比模块时间不够。
- 工程题忘记合作效率相加。
- 行程题把相遇速度和写成速度差。
- 分段计费把最高费率套到全部。
- 排列组合没有区分排列和组合。
- 平均分组忘记除以组数阶乘去重。
- 最不利题忘记最后 $+1$。

## 面试应对

### 如何建立数量关系的整体解题框架？

回答思路：按题型识别、关系表达、方法选择和选项验证四步回答，突出先简化再计算，而不是见题列复杂方程。

回答模板：

我会先根据题干中的比例、效率、路程、利润、计数或最值信号识别题型，再把文字关系转换为等式、比例或约束。方法上优先选择代入排除、赋值和数字特性，只有关系复杂且无法直接筛选时才列方程。计算完成后还要检查单位、取值范围、整数性和题目所求，并把结果代回关键条件验证。

### 代入排除、赋值法和方程法应该怎么选？

回答思路：按选项信息、比例自由度和未知量关系判断；方法选择以减少变量和计算量为目标。

回答模板：

选项给出具体数值且代入验证成本低时，我优先用代入排除；题目只给比例、效率或浓度而总量任意时，我会赋一个便于整除的值；未知量少、等量关系清晰时直接列方程更稳。若题干强调整数、倍数或余数，还可以先用数字特性筛选。选择标准不是偏爱某种技巧，而是哪种方法能用最少计算完整保留题目约束。

### 什么时候可以估算或利用选项，什么时候必须精算？

回答思路：看选项间距、误差上界和答案边界；估算必须能保证不会跨越选项分界，并用精算处理临界情况。

回答模板：

当选项差距明显、只需判断数量级或单调关系时，可以估算、截位或利用选项反推；但估算前必须判断误差是否可能改变排序。若选项接近、涉及整除余数、临界最值、概率或题目要求精确值，就应保留足够精度甚至完整计算。我的原则是先用粗算定位候选，再对临界项精算验证，而不是为了追求速度牺牲可判定性。

### 数量关系模块如何设置取舍和止损边界？

回答思路：从整卷得分效率出发，按熟悉度、计算长度和选项可利用程度排序，并给单题设时间上限。

回答模板：

数量关系的目标不是做完所有题，而是在有限时间内获得最高期望分。我会先做题型熟悉、关系短、选项可快速利用的题，再处理需要两三步计算的题；条件混乱、分支很多或长时间无法建模的题先跳过。每题设置明确止损点，超过时间仍没有形成可执行关系式就转下一题，最后再用剩余时间回看，而不挤占资料分析等更稳定的得分模块。
