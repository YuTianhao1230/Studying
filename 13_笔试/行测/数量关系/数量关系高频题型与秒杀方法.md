# 数量关系高频题型与秒杀方法

## 使用定位

本卡只负责方法选型与专题路由。拿到题目后先识别约束和选项结构，再选择代入、数字特性、赋值、方程或标准模型；公式推导、适用边界和例题进入对应专题卡。

## 方法选型

| 题面信号 | 首选方法 | 快速核验 | 专题入口 |
| --- | --- | --- | --- |
| 选项为具体数值，代回成本低 | 代入排除 | 普通求值先代易算项；只有关系单调时才可一次排除整侧 | [数字特性赋值与代入排除](<数字特性赋值与代入排除.md#数字特性赋值与代入排除>) |
| 整数、倍数、奇偶、尾数、余数 | 数字特性 | 必要条件筛选后仍须代回全部约束 | [数字特性赋值与代入排除](<数字特性赋值与代入排除.md#数字特性赋值与代入排除>) |
| 只给比例、效率、浓度或折扣 | 赋值法 | 所求须具有缩放不变性；有固定差额或固定费用时不能任意赋值 | [数字特性赋值与代入排除](<数字特性赋值与代入排除.md#数字特性赋值与代入排除>) |
| 未知量少、等量关系清晰 | 方程法 | 列式前统一对象、单位和时间口径 | [数字特性赋值与代入排除](<数字特性赋值与代入排除.md#数字特性赋值与代入排除>) |
| 完工时间、效率、相遇、追及、流水、环形 | 工程或行程模型 | 工程看总量守恒，行程先判断速度和还是速度差 | [工程与行程问题](<工程与行程问题.md#工程与行程问题>) |
| 排列限制、抽取概率、集合人数 | 分类分步、捆绑插空、对立事件或容斥 | 先判断有序/无序、等可能性和交集口径 | [排列组合概率与容斥](<排列组合概率与容斥.md#排列组合概率与容斥>) |

| 数列、数字推理或开放型规律 | 做差、做商、幂次、递推或选项验证 | 优先检验简单稳定规律，避免过拟合 | [思维策略与数字推理](<思维策略与数字推理.md#思维策略与数字推理>) |
| 排队、预算、配套短板或材料约束决策 | 枚举、瓶颈或约束优化 | 列全约束后再比较可行方案 | [决策分析与材料决策](<决策分析与材料决策.md#决策分析与材料决策>) |

## 作答路由

1. 先用题干信号定位专题，不因题目背景陌生而改变底层模型。
2. 再看选项能否支持代入、整数筛选或量级判断。
3. 选能完整保留约束且计算量最低的方法。
4. 结果须复核单位、整数性、取值范围和题目所求。
5. 做题顺序、时间预算、期望收益与止损见[数量关系解题策略](<数量关系解题策略.md#数量关系解题策略>)；公开题解见[数量关系真题案例](<数量关系真题案例.md#数量关系真题案例>)。
