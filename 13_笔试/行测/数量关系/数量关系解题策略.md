# 数量关系解题策略

## 知识点解析

### 概述

数量关系解题策略包括题型识别、代入排除、数字特性、赋值和时间预算。先处理有明确解题路径的题，再依据剩余时间、可排除选项和计分规则决定是否继续计算，避免单道难题消耗过多时间。

### 三种基础简化方法

| 方法 | 信号 | 操作 |
| --- | --- | --- |
| 代入排除 | 选项是具体数 | 先代最易算的项；关系单调才可据大小排除整侧 |
| 数字特性 | 整数、倍数、奇偶、余数 | 用整除、奇偶、尾数筛选 |
| 赋值法 | 只有比例没有具体量 | 赋最小公倍数或特殊值 |

### 挑题原则

优先做：

- 工程问题。
- 行程基础题。
- 利润折扣题。
- 容斥题。
- 最不利原则题。
- 选项可代入的题。

谨慎做：

- 条件很多的排列组合。
- 阅读量大的综合应用题。
- 需要复杂方程组的题。
- 看不出题型的创新题。

### 蒙题策略

没有排除信息且各选项等可能时，固定选一个字母和随机选的单题期望得分相同；没有可靠依据认为居中选项更容易正确。若答错不扣分、空白得零，最后应填写剩余题；若答错扣分，先算期望收益。

自编例：答对得 1 分、答错扣 0.5 分、留空 0 分，判断正确的概率为 p，则作答期望为 `p-0.5(1-p)`，仅当 `p>1/3` 时高于留空。四选一完全盲猜 p=1/4，期望为 -0.125；能排除两个选项且余下等可能时 p=1/2，期望为 0.25。

## 笔试应对

### 常考题型

- 选项给具体数字，考代入排除。
- 比例题不给具体量，考赋值法。
- 整数题考奇偶、整除、倍数。
- 时间分配上考考生是否会取舍。

### 解题方法

数量关系先判断能不能快速做。能代入就代入，能赋值就赋值，能用数字特性就先筛选。不会的题不硬做，保证其他模块时间。

### 易错点

- 死磕难题导致全卷节奏崩。
- 看到数量题就列方程，不看选项。
- 忽略扣分规则，或把答案位置当成可靠线索。
- 把“会做但耗时很长”的题误当高性价比题。

## 笔试自测

### 一题两步筛选（自编）

20 道题，答对得 2 分、答错扣 1 分、未答不计分。共得 23 分，未答题数为偶数。答错可能为 3、4、5、6 中哪一个？

步骤：设对 x、错 y、空 z，`x+y+z=20`、`2x-y=23`。先由奇偶排除 y=4、6；代 y=3 得 x=13、z=4，满足条件；代 y=5 得 x=14、z=1，不满足。答案为错 3 题。

适用条件：数量是非负整数，选项可直接验证；陷阱是只检验分数、不检验未答数的奇偶。

### 计分阈值（自编）

答对 a 分、答错扣 b 分、空白 0 分，且只比较本题期望分数，作答收益为 `pa-(1-p)b`；当 `p>b/(a+b)` 时作答优于空白。若答对 2、答错扣 1，四选一排除一项后剩余等可能，p=1/3，期望为 0，恰与空白持平。

步骤：读计分规则，估有效排除后的正确概率，比较收益再决策。陷阱：未经证实的排除不能直接当成概率提升；另有必须作答、限时或不能回看的规则时，也须一起考虑。

## 面试应对

### 1. 数量关系题的总体解题流程是什么？

- 常考点及考法：要求概括拿到一道数量题后的判断顺序和方法选择。
- 回答思路：先识别题型与约束，再看选项能否支持代入、数字特性或赋值；选择计算成本最低的方法，完成后用单位和边界复核。
- 易错点：不看选项直接列复杂方程，或为了使用熟悉公式而忽略更短路径。
- 回答模板：我会先识别题型、所求量和整数等约束，再观察选项是否适合代入、数字特性或赋值。方法选择以计算成本最低为原则，得到结果后用原条件、单位和边界做快速复核。

### 2. 如何判断一道数量题是否值得继续做？

- 常考点及考法：讨论限时考试中的取舍、做题顺序和时间管理。
- 回答思路：根据题型熟悉度、可用方法、剩余计算量和当前时间评估收益；超过预设时间仍无稳定路径就标记跳过。
- 易错点：因已经投入时间而继续死磕，或把“能做出来”等同于“值得现在做”。
- 回答模板：我会综合判断题型熟悉度、能否快速建模、选项可否排除以及剩余计算量。达到单题时间上限仍没有稳定路径时立即跳过，先保证整卷可得分部分，不受沉没成本影响。

### 3. 代入、赋值和方程法应如何选择？

- 常考点及考法：同一道题存在多种方法，要求比较适用条件。
- 回答思路：具体选项且验证简单时优先代入；只有比例关系时优先赋值；关系复杂但变量少、线性明显时列方程。
- 易错点：把技巧当固定套路，忽略整数、单调性和缩放不变等适用条件。
- 回答模板：我按题目结构选方法：选项具体且容易验证时用代入，只有比例且允许缩放时用赋值，变量少且关系清晰时列方程。若存在整数约束，我还会先用整除、奇偶或余数筛选。

### 4. 有倒扣分时应该猜答案吗？

- 常考点及考法：给出答对得分、答错扣分和主观正确概率，问是否作答。
- 回答思路：比较作答与留空的期望分；答对得 a、答错扣 b 时，只有估计正确率 `p>b/(a+b)` 才值得作答。
- 易错点：忽略扣分规则，或把没有依据的感觉当成可靠概率。
- 回答模板：我会按期望收益决策。若答对得 a 分、答错扣 b 分，作答期望为 `pa-(1-p)b`，因此正确率超过 `b/(a+b)` 才优于留空；无倒扣且必须作答时再填写剩余题。
