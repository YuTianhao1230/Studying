# 利润最值几何与杂题

## 知识点解析

### 概述

利润、最值、几何和杂题是数量关系中常见的中低难度得分点。利润题围绕进价、售价、利润率和折扣；最值题围绕极端构造和最不利原则；几何题围绕基础公式、勾股数和割补；杂题包括年龄、日期、植树、方阵、牛吃草、溶液和数列。掌握标准模型后，很多题可快速识别。

### 利润问题

| 概念 | 公式 |
| --- | --- |
| 利润 | `售价 - 进价` |
| 利润率 | `利润 / 进价` |
| 售价 | `进价 x (1 + 利润率)` |
| 折扣价 | `原价 x 折扣` |
| 总收入 | `单价 x 数量` |

分段计费题按每一段单独计算，再求和。

### 最值问题

和定最值：

- 求某项最大，让其他项尽量小。
- 求某项最小，让其他项尽量大。
- 若要求互不相同，按最小等差序列构造。

最不利原则：

```text
保证发生 = 最坏情况 + 1
```

### 几何问题

高频内容：

- 长方形、正方形、三角形、圆的周长面积。
- 长方体、正方体、圆柱的体积表面积。
- 勾股数：3-4-5、5-12-13、8-15-17。
- 相似三角形、割补、等积变形。

### 杂题模型

| 题型 | 核心规则 |
| --- | --- |
| 年龄 | 年龄差不变 |
| 日期星期 | 每 7 天星期相同，平年 365、闰年 366 |
| 植树 | 间隔数为 k：两端都栽 k+1、只栽一端 k、两端不栽 k-1；闭环 k |
| 方阵 | 实心方阵总人数 `N^2`；N≥2 时最外层 `4(N-1)`，N=1 单独计 1 |
| 牛吃草 | `原有草量 = (牛数 - 草长速度) x 时间` |
| 溶液 | 浓度 = 溶质 / 溶液，混合可用十字交叉 |
| 数列 | 等差、等比、做差、做商、平方立方 |

### 十字交叉与加权线段法

适用条件：两部分可以相加、采用同一种平均口径且权重为正。高值 a、低值 b 混合成 c，满足 `a>c>b`：

```text
高值部分权重 : 低值部分权重 = (c-b):(a-c)
```

步骤：找平均指标和真正权重，在线段两端写 a、b，中间写 c；交叉作差求权重比，再用已知总量还原。

自编例：30% 与 10% 盐水混成 100 克 18% 盐水，两者质量比 `(18-10):(30-18)=2:3`，分别 40、60 克；含盐 `40×30%+60×10%=18` 克，核验浓度 18%。

陷阱：溶液质量加权不能随意换成体积；平均分按人数加权，利润率若以成本为分母则按成本加权。两端相等时无法反推权重。方法来源可参照[华图数量资料公开讲义，十字交叉法](https://upload.htexam.com/jiangyi/15061005031714498.pdf)及[线段法教学说明](https://www.huatu.com/dxgk/bkjx/xcjx/20190812/1761168.html)，本例自编。

### 溶质守恒与反复替换

适用条件：溶质不挥发、不反应，每次抽取前混匀；每次抽出质量占总质量比例 f，补等质量纯水且总质量保持不变。步骤：加水或蒸发先守恒溶质；反复替换时每次溶质保留 `1-f`。

自编例：100 克 20% 盐水蒸发 20 克水，浓度 `20/80=25%`。另有 100 克 20% 盐水，每次混匀后抽出 25 克、补入 25 克纯水，重复两次后浓度 `20%×(3/4)^2=11.25%`。

陷阱：抽走的是溶液而非纯溶质；若每次抽走量或总量变化，不能直接用同一个幂。

### 牛吃草的净消耗

适用条件：草量匀速增长、每头牛效率相同且不变。赋每头牛每日吃草为 1，步骤：用两组牛数和时间列 `Y=(N-g)T`，先解增长速度 g，再解原有量 Y。

自编例：10 头牛吃 8 天、6 头吃 24 天，`(10-g)8=(6-g)24`，得 g=4、Y=48；8 头吃完需 `48/(8-4)=12` 天。

陷阱：N≤g 时不能在有限时间吃完；水池持续进水、排队持续到达也须区分流入和净流出。

### 最不利与抽屉原则

适用条件：题目要求“保证”，按对手最不利安排。步骤：构造仍不达目标的最大数量，再加 1，并检查该构造确实可实现。

自编例：3 种颜色各 5 个球，保证有 3 个同色，最坏每色先取 2 个，共 6 个，第 7 个必使某色达到 3 个。不是保证指定颜色有 3 个；若指定红色，则先取其余 10 个，再取红色 3 个，共 13 个。

### 几何比例与日期边界

适用条件：相似图形的对应线性尺寸成同一比例。步骤：先找长度比 k，再用面积比 k²、体积比 k³。

自编例：相似三角形对应边比 2:3，小三角形面积 8，则大面积 `8×9/4=18`。陷阱：只有周长相同不足以推出面积相同，非相似图形不能套平方比。

日期按公历判断闰年：能被 4 整除且不能被 100 整除，或能被 400 整除。自编例：2000 年是闰年、2100 年不是；周一之后第 10 天为周四（10 除以 7 余 3），若“含当天数第 10 天”则仅推 9 天，为周三。先明确是否计入起点。

## 笔试应对

### 常考题型

- 利润折扣和分段计费。
- 和定最值、最不利原则。
- 基础几何面积体积。
- 年龄差、星期周期、植树方阵、牛吃草。

### 解题方法

利润题先列进价、售价和利润率；最值题先构造极端情况；几何题先看是否能套基础公式或割补；杂题先识别模型。

### 易错点

- 利润率分母用错，利润率通常除以进价。
- 最不利原则忘记加 1。
- 方阵最外层公式写错。
- 溶液混合把溶质和溶液混淆。
