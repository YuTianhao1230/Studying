# 排列组合概率与容斥

## 知识点解析

### 概述

排列组合、概率和容斥题本质都是计数问题。解题时先判断是分类还是分步，是有序还是无序，是正面直接算还是反面更简单。容斥题要先明确集合范围和交集关系，再按公式加减。

### 排列组合

| 情况 | 方法 |
| --- | --- |
| 分类讨论 | 加法 |
| 分步完成 | 乘法 |
| 与顺序有关 | 排列 |
| 与顺序无关 | 组合 |
| 相邻 | 捆绑法 |
| 不相邻 | 插空法 |
| 圆桌 | n 人互异、旋转视为相同而镜像不同，`(n-1)!`；座位有编号则为 n! |
| 平均分组 | 同规模且无标签的组才除以对应组数阶乘；有名称的组不除 |

### 概率

```text
等可能有限样本空间：概率 = 满足条件数 / 总数
```

若正面情况复杂，优先算反面：

```text
目标概率 = 1 - 对立事件概率
```

### 容斥

两集合：

```text
A + B - A交B = 总数 - 都不满足
```

三集合：

```text
A + B + C - 两两交 + 三者交 = 总数 - 都不满足
```

非标准三集合：

```text
A + B + C - 只满足两两 - 2 x 三者交 = 总数 - 都不满足
```

其中“两两交”包含三者交；“只满足两两”指恰好属于两个集合的人数合计，不能混用。

### 捆绑、插空与分组

适用条件：对象互异、每种安排等权计数。步骤：先处理受限对象，再补内部顺序，最后检查是否重复计数。

| 自编问题 | 步骤与结果 | 陷阱 |
| --- | --- | --- |
| 5 人排一列，甲乙相邻 | 把甲乙看成一块，`4!×2!=48` | 别漏甲乙内部两种顺序 |
| 5 人排一列，甲乙不相邻 | 其余 3 人排列形成 4 个空，`3!×C(4,2)×2!=72` | 两人不能放同一空；48+72=5! |
| 6 人分成 3 个无名二人组 | `C(6,2)C(4,2)C(2,2)/3!=15` | 若分给三个指定部门，则为 90 |

### 条件概率与独立性

适用条件：已知事件 B 发生且 `P(B)>0`。步骤：缩小到 B 对应样本空间，再计算目标；乘法用 `P(A且B)=P(B)P(A|B)`，仅独立时可写 `P(A)P(B)`。

自编例：袋内 3 红 2 蓝，不放回取 2 个。已知首个为红，第二个为红概率 `2/4=1/2`；两红概率 `(3/5)(2/4)=3/10`；至少一红概率 `1-(2/5)(1/4)=9/10`。

陷阱：不放回通常不独立；“红红、红蓝、蓝红、蓝蓝”四类结果不等可能，不能直接以类别数作分母。

### 容斥与“至少两个”

适用条件：同一总体且集合统计口径一致。步骤：明确两两交是否含三重交，再按每人被计数的次数修正。

```text
至少两项 = 两两交人数之和 - 2×三者交
恰好两项 = 两两交人数之和 - 3×三者交
```

自编例：A、B、C 人数为 20、18、16，两两交为 8、7、6，三重交为 3。并集 `54-21+3=36`，至少两项 `21-6=15`，恰好两项 `21-9=12`。三重交在“至少两项”中保留一次，在“恰好两项”中全部扣除。

## 笔试应对

### 常考题型

- 相邻或不相邻排列。
- 平均分组去重。
- 概率正难则反。
- 两集合、三集合容斥。

### 解题方法

先判断顺序是否重要，再判断分类还是分步。排列组合复杂时先看是否有相邻、不相邻或平均分组。概率题看反面是否更简单。容斥题先列集合公式。

### 易错点

- 把排列当组合。
- 平均分组忘记除以阶乘。
- 不相邻题没有插空。
- 三集合容斥交集加减号错。
