# 数量关系

本目录整理数量关系的题型识别、快速策略、常见模型和公开真题案例。训练目标是在有限时间内判断题目是否值得做，并选择代入、赋值、方程或公式等成本最低的方法。

建议先通过高频题型和解题策略建立做题优先级，再按数字特性、工程行程、排列组合、利润几何、思维策略和决策分析分专题训练，最后用真题案例复盘方法选择。
