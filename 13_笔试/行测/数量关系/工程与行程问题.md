# 工程与行程问题

## 知识点解析

### 概述

工程问题和行程问题是数量关系中最稳定的公式题。工程问题围绕工作总量、效率和时间，常用赋值总量法；行程问题围绕路程、速度和时间，关键是区分相遇、追及、流水行船和环形运动。两类题都适合优先拿分。

### 工程问题

基本公式：

```text
工作总量 = 工作效率 x 工作时间
合作效率 = 各效率之和
```

给完成时间且效率恒定、合作无额外损耗时，总量赋各时间的最小公倍数。自编例：甲 6 天、乙 8 天完成，总量赋 24，甲效率 4，乙效率 3，合作时间为 `24 / 7`。

给效率比时，直接赋效率。比如甲乙效率比 2:3，可设甲效率 2、乙效率 3。

### 行程问题

| 类型 | 公式 |
| --- | --- |
| 基本 | `s = v x t` |
| 相遇 | `路程和 = (v1 + v2) x t` |
| 追及 | `路程差 = (v1 - v2) x t` |
| 流水行船 | 顺速 = 船速 + 水速，逆速 = 船速 - 水速 |
| 环形相遇 | 同地反向同时出发、不计起点相遇，每合走一圈再相遇一次 |
| 时钟 | 时针 0.5 度/分，分针 6 度/分，追及速度 5.5 度/分 |

### 判断相遇和追及

- 两者相向而行，距离被共同缩短，用速度和。
- 同向快追慢，距离被速度差缩短，用速度差。
- 环形同向追及用速度差，反向相遇用速度和。

### 轮换工程与末轮

适用条件：按固定顺序轮流工作，单人效率恒定。步骤：先算一个周期工作量，扣除不会提前完工的完整周期，再按轮换顺序处理余量；末次通常不足一整天。

自编例：甲单做 6 天、乙单做 8 天，每天轮换、甲先。总量 24，甲日效 4、乙 3；三轮 6 天完成 21，余 3 由甲做 `3/4` 天，总计 6.75 天。

陷阱：不能把轮换等同每天合作，也不能因有余量就整天向上取整；问完整工作日或必须整天结算时另按题意。

### 等距平均速度与相对位移

适用条件：两段距离相等且各段匀速。步骤：设每段距离 s，用总路程除总时间：

```text
平均速度 = 2s/(s/v1+s/v2) = 2v1v2/(v1+v2)
```

自编例：去程 60 千米/时、回程 40 千米/时，等距平均速度 48，不是 50；等时间才是算术平均。

环形自编例：周长 400 米，同地同向两人速度 5、3 米/秒，首次再相遇 `400/(5-3)=200` 秒；反向首次再相遇 50 秒。若初始错开 100 米，先将初始间距加入相对位移，不能仍用“第 n 次即 n 圈”。

### 火车过桥与流水分解

适用条件：匀速且长度、时间已统一单位。步骤：过桥看车头从进入到车尾离开需走“车长+桥长”；流水分解顺、逆速度的和差。

自编例：车长 200 米、桥长 400 米、全车过桥 30 秒，速度 `(200+400)/30=20` 米/秒，即 72 千米/时。船顺速 18、逆速 10 千米/时，静水速 14、水速 4。

陷阱：车头过桥与全车过桥路程不同；流水须两次静水船速与水速相同，逆行可达还需船速大于水速。

## 笔试应对

### 常考题型

- 多人合作完工，求合作时间。
- 工程中有人中途加入或退出。
- 两车相遇、追及、环形跑道。
- 顺水逆水求船速或水速。

### 解题方法

工程题先赋总量或效率，再列效率关系。行程题先判断是相遇还是追及，再决定用速度和还是速度差。

### 易错点

- 合作效率没有相加。
- 相遇用成速度差，追及用成速度和。
- 流水题把顺速和逆速写反。
- 环形题没把相遇次数转成圈数。

## 面试应对

### 1. 工程问题为什么常用赋值法？

- 常考点及考法：已知多人单独完工时间或效率比，求合作、轮换或中途加入后的时间。
- 回答思路：把总量赋为各完工时间的最小公倍数，使效率整数化；按时间段累加工作量，最后用总量守恒求解。
- 易错点：合作效率未相加，或人员加入、退出后仍沿用同一个阶段效率。
- 回答模板：工程题的核心是“工作量=效率×时间”。只给完工时间时，我会把总量赋成时间的最小公倍数，得到整数效率，再按人员变化分段累加，最后检查总工作量是否守恒。

### 2. 相遇和追及怎样快速区分？

- 常考点及考法：两人或两车相向、同向、环形运动，求相遇时间或追及次数。
- 回答思路：观察初始距离如何变化；共同缩短距离用速度和，快者弥补距离差用速度差，环形题再把相对位移换成圈数。
- 易错点：只看运动方向，不看相对距离；初始位置错开时仍机械套一圈公式。
- 回答模板：我先定义两者之间的待消除距离。相向运动时该距离按速度和缩短，同向追及时按速度差缩短；环形运动则把相对位移表示为整数圈，并纳入初始间距。

### 3. 等距往返的平均速度为什么不是算术平均？

- 常考点及考法：去回速度不同但路程相同，求全程平均速度。
- 回答思路：平均速度始终等于总路程除以总时间；等距时两段耗时不同，推得调和平均 `2v1v2/(v1+v2)`。
- 易错点：看到两个速度就直接相加除以 2；只有等时间时才能取算术平均。
- 回答模板：平均速度取决于总路程和总时间。等距往返时慢速段耗时更长，因此不能直接算术平均，结果应为两速度的调和平均；若题目明确两段时间相等，才取算术平均。

### 4. 轮换工程如何处理最后一个周期？

- 常考点及考法：多人按固定顺序轮流工作，求完成时刻或实际工作天数。
- 回答思路：先算完整轮换周期的工作量，扣除不会提前完工的完整周期，再按顺序处理剩余量，末段按实际所需时间计算。
- 易错点：把轮换当合作，或把最后不足一个单位时间的工作强行向上取整。
- 回答模板：我会先计算一个完整轮换周期能完成的工作量，再确定可执行的完整周期数。剩余工作按既定顺序逐人扣减，最后一人只计算完成余量所需的实际时间。
