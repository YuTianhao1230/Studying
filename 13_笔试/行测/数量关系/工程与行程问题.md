# 工程与行程问题

## 知识点解析

### 概述

工程问题和行程问题是数量关系中最稳定的公式题。工程问题围绕工作总量、效率和时间，常用赋值总量法；行程问题围绕路程、速度和时间，关键是区分相遇、追及、流水行船和环形运动。两类题都适合优先拿分。

### 工程问题

基本公式：

```text
工作总量 = 工作效率 x 工作时间
合作效率 = 各效率之和
```

给完成时间且效率恒定、合作无额外损耗时，总量赋各时间的最小公倍数。自编例：甲 6 天、乙 8 天完成，总量赋 24，甲效率 4，乙效率 3，合作时间为 `24 / 7`。

给效率比时，直接赋效率。比如甲乙效率比 2:3，可设甲效率 2、乙效率 3。

### 行程问题

| 类型 | 公式 |
| --- | --- |
| 基本 | `s = v x t` |
| 相遇 | `路程和 = (v1 + v2) x t` |
| 追及 | `路程差 = (v1 - v2) x t` |
| 流水行船 | 顺速 = 船速 + 水速，逆速 = 船速 - 水速 |
| 环形相遇 | 同地反向同时出发、不计起点相遇，每合走一圈再相遇一次 |
| 时钟 | 时针 0.5 度/分，分针 6 度/分，追及速度 5.5 度/分 |

### 判断相遇和追及

- 两者相向而行，距离被共同缩短，用速度和。
- 同向快追慢，距离被速度差缩短，用速度差。
- 环形同向追及用速度差，反向相遇用速度和。

### 轮换工程与末轮

适用条件：按固定顺序轮流工作，单人效率恒定。步骤：先算一个周期工作量，扣除不会提前完工的完整周期，再按轮换顺序处理余量；末次通常不足一整天。

自编例：甲单做 6 天、乙单做 8 天，每天轮换、甲先。总量 24，甲日效 4、乙 3；三轮 6 天完成 21，余 3 由甲做 `3/4` 天，总计 6.75 天。

陷阱：不能把轮换等同每天合作，也不能因有余量就整天向上取整；问完整工作日或必须整天结算时另按题意。

### 等距平均速度与相对位移

适用条件：两段距离相等且各段匀速。步骤：设每段距离 s，用总路程除总时间：

```text
平均速度 = 2s/(s/v1+s/v2) = 2v1v2/(v1+v2)
```

自编例：去程 60 千米/时、回程 40 千米/时，等距平均速度 48，不是 50；等时间才是算术平均。

环形自编例：周长 400 米，同地同向两人速度 5、3 米/秒，首次再相遇 `400/(5-3)=200` 秒；反向首次再相遇 50 秒。若初始错开 100 米，先将初始间距加入相对位移，不能仍用“第 n 次即 n 圈”。

### 火车过桥与流水分解

适用条件：匀速且长度、时间已统一单位。步骤：过桥看车头从进入到车尾离开需走“车长+桥长”；流水分解顺、逆速度的和差。

自编例：车长 200 米、桥长 400 米、全车过桥 30 秒，速度 `(200+400)/30=20` 米/秒，即 72 千米/时。船顺速 18、逆速 10 千米/时，静水速 14、水速 4。

陷阱：车头过桥与全车过桥路程不同；流水须两次静水船速与水速相同，逆行可达还需船速大于水速。

## 笔试应对

### 常考题型

- 多人合作完工，求合作时间。
- 工程中有人中途加入或退出。
- 两车相遇、追及、环形跑道。
- 顺水逆水求船速或水速。

### 解题方法

工程题先赋总量或效率，再列效率关系。行程题先判断是相遇还是追及，再决定用速度和还是速度差。

### 易错点

- 合作效率没有相加。
- 相遇用成速度差，追及用成速度和。
- 流水题把顺速和逆速写反。
- 环形题没把相遇次数转成圈数。
