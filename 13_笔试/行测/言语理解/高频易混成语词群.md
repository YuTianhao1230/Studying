# 高频易混成语词群

## 使用定位

本卡整理《言语理解成语积累》中的全部近义辨析：第一部分 10 组，第二部分 20 组，共 30 组。学习目标不是背同义解释，而是找到同组词之间最小且决定性的差别。

做题顺序：

1. 先由上下文确定空格需要表达的行为、阶段、对象和结果。
2. 再比较适用对象、句法、褒贬和程度。
3. 最后将整组选项回代，不因某个词眼熟就作答。

单个成语释义见[成语500速查索引](<成语500速查索引.md#成语500速查索引>)，通用辨析方法见[近义词与成语辨析](<近义词与成语辨析.md#近义词与成语辨析>)。

## 第一部分：双词辨析

### 1. 安之若素 / 随遇而安

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 安之若素 | 面对不顺或反常情况仍像平常一样安然处之 | 有明确的不利处境，强调态度平静 |
| 随遇而安 | 能顺应所处环境，在不同境遇中都能安顿 | 环境可好可坏，强调适应性 |

判别轴：题干若点明艰难、异常仍不在意，优先“安之若素”；只强调适应各种环境，优先“随遇而安”。

### 2. 爱财如命 / 一毛不拔

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 爱财如命 | 把钱财看得像生命一样重要 | 强调对财富的态度和性格 |
| 一毛不拔 | 极端吝啬，极小付出也不愿承担 | 强调不给、不付出的行为 |

二者均含贬义，不要机械认定固定的轻重顺序，应由语境决定。

### 3. 爱不释手 / 手不释卷

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 爱不释手 | 喜爱得舍不得放下 | 对象范围广，可指书、器物等 |
| 手不释卷 | 书本不离手，形容勤奋好学 | 对象限于书卷，强调长期学习状态 |

### 4. 按图索骥 / 顺藤摸瓜

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 按图索骥 | 按既有图样、标准或线索寻找；也可批评机械照搬 | 线索往往预先给定或计划化 |
| 顺藤摸瓜 | 沿已经显露的线索继续追查 | 线索多在调查过程中自然出现 |

### 5. 八面玲珑 / 面面俱到

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 八面玲珑 | 为人处世灵活圆滑，各方面都能应付 | 多形容人和交际方式，常含贬义或中性 |
| 面面俱到 | 各方面都照顾到，没有明显遗漏 | 多形容做事、考虑或说明 |

### 6. 白云苍狗 / 变化无常

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 白云苍狗 | 比喻世事、人事变化不定 | 适用范围较窄，文学色彩强 |
| 变化无常 | 经常变化，没有稳定常态 | 人事、天气、心理、手法等均可 |

### 7. 本末倒置 / 舍本逐末

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 本末倒置 | 把主要与次要、本质与非本质的位置颠倒 | 两方面都还存在，只是主次错位 |
| 舍本逐末 | 放弃根本，只追求枝节 | 含“舍弃主要方面”的行为 |

### 8. 并驾齐驱 / 不相上下

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 并驾齐驱 | 并肩前进，发展速度或地位不分先后 | 有共同前进、竞争发展的动态感 |
| 不相上下 | 程度、水平、高低差不多 | 只说明比较结果，无须共同前进 |

### 9. 背井离乡 / 流离失所

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 背井离乡 | 被迫或不得已离开故乡 | 核心是离乡 |
| 流离失所 | 辗转流离，没有安身之处 | 核心是失去住所，不必已经离开故乡 |

### 10. 步履维艰 / 寸步难行

| 词语 | 决定性差别 | 典型对象或限制 |
| --- | --- | --- |
| 步履维艰 | 行走困难，也比喻事业推进艰难 | 强调艰难前进 |
| 寸步难行 | 一步也难走，也比喻处境极其困难 | 程度通常更重，适用范围更广 |

## 第二部分：多词词群

### 11. 浮光掠影 / 浅尝辄止 / 走马观花 / 蜻蜓点水

| 词语 | 决定性差别 |
| --- | --- |
| 浮光掠影 | 观察不细、印象不深，可形容观察结果 |
| 走马观花 | 看得匆忙、粗略，强调观察速度和方式 |
| 浅尝辄止 | 稍作尝试就停止，强调不能继续深入 |
| 蜻蜓点水 | 做事停留表面，强调做得肤浅 |

判别轴：先分“看”还是“做”，再分匆忙观察、印象浅、尝试即停和做事浮浅。

### 12. 循规蹈矩 / 按部就班 / 墨守成规 / 固步自封

| 词语 | 决定性差别 | 色彩 |
| --- | --- | --- |
| 循规蹈矩 | 遵守规矩、不轻举妄动；特定语境也可指不知变通 | 中性为主 |
| 按部就班 | 按步骤、次序办事 | 中性，可暗含缺乏创新 |
| 墨守成规 | 固守旧规则，不愿改变 | 贬义 |
| 固步自封 | 安于现状，不求进步 | 贬义 |

### 13. 未雨绸缪 / 防患未然 / 防微杜渐 / 居安思危 / 有备无患

| 词语 | 决定性差别 |
| --- | --- |
| 未雨绸缪 | 事情发生前先准备 |
| 防患未然 | 灾祸尚未发生时采取预防措施 |
| 防微杜渐 | 错误或坏事刚有苗头就制止 |
| 居安思危 | 身处安定环境仍想到危险 |
| 有备无患 | 强调事先准备能避免祸患的结果 |

判别轴：准备、预防危险、遏制苗头、安中思危、准备后的无患状态。

### 14. 同日而语 / 等量齐观 / 相提并论 / 混为一谈 / 一视同仁

| 词语 | 决定性差别 | 句法或色彩 |
| --- | --- | --- |
| 同日而语 | 把不同情况放在一起谈论、比较，也常比较同一事物不同时期 | 多用于否定句 |
| 等量齐观 | 对不同事物用同一标准同等看待 | 多用于否定口吻 |
| 相提并论 | 把有差别或悬殊的人、事物放在一起谈论比较 | 多用于否定口吻 |
| 混为一谈 | 把不同事物说成同一事物 | 贬义，多用于否定 |
| 一视同仁 | 不分亲疏贵贱而同等看待 | 中性或褒义 |

### 15. 有的放矢 / 量体裁衣 / 因势利导 / 因时制宜 / 因地制宜

| 词语 | 决定性差别 |
| --- | --- |
| 有的放矢 | 有明确目标和针对性 |
| 量体裁衣 | 按个体实际条件办事 |
| 因势利导 | 顺着事物发展趋势加以引导 |
| 因时制宜 | 根据时期、时机调整办法 |
| 因地制宜 | 根据地区条件制定办法 |

### 16. 相辅相成 / 相得益彰 / 珠联璧合

| 词语 | 决定性差别 |
| --- | --- |
| 相辅相成 | 两者互相辅助、互相补充，强调关系 |
| 相得益彰 | 两者配合后优势或作用更加显著，强调效果提升 |
| 珠联璧合 | 优秀人物或美好事物结合，强调强强结合和美好结果 |

### 17. 削足适履 / 扬汤止沸 / 矫枉过正 / 舍本逐末

| 词语 | 决定性差别 |
| --- | --- |
| 削足适履 | 不顾实际条件，勉强迁就既定规范 |
| 扬汤止沸 | 办法不彻底，不能从根本解决问题 |
| 矫枉过正 | 纠正错误超过应有限度 |
| 舍本逐末 | 放弃根本，专顾枝节 |

### 18. 鞭长莫及 / 望尘莫及 / 望其项背

| 词语 | 决定性差别 | 句法或限制 |
| --- | --- | --- |
| 鞭长莫及 | 因距离、条件或力量限制而管不到、做不到 | 核心是作用范围够不着 |
| 望尘莫及 | 远远落后，赶不上 | 核心是差距大 |
| 望其项背 | 能看见对方颈背，比喻有能力赶上 | 常用于“难以/不能望其项背”等否定式 |

### 19. 望而生畏 / 望而却步 / 望洋兴叹

| 词语 | 决定性差别 |
| --- | --- |
| 望而生畏 | 看见就产生畏惧，强调心理 |
| 望而却步 | 因畏惧或厌恶而退缩，强调行动 |
| 望洋兴叹 | 因能力不足或条件不具备而无可奈何 |

### 20. 寥寥无几 / 历历可数 / 吉光片羽 / 凤毛麟角

| 词语 | 决定性差别 | 典型对象 |
| --- | --- | --- |
| 寥寥无几 | 数量非常少 | 人或事物均可 |
| 历历可数 | 可以清楚地逐一数出 | 强调清楚可数，不必珍贵 |
| 吉光片羽 | 残存的珍贵文物或文化片段 | 文化遗产、文献 |
| 凤毛麟角 | 稀少而珍贵的人或事物 | 强调“少且珍贵” |

### 21. 缘木求鱼 / 饮鸩止渴 / 抱薪救火

| 词语 | 决定性差别 |
| --- | --- |
| 缘木求鱼 | 方法或方向错误，根本达不到目的 |
| 饮鸩止渴 | 为解决眼前困难而不顾严重后果 |
| 抱薪救火 | 错误方法不但无效，反而使问题加重 |

### 22. 杀鸡取卵 / 寅吃卯粮 / 竭泽而渔

| 词语 | 决定性差别 |
| --- | --- |
| 杀鸡取卵 | 为眼前利益损害根本或长期利益 |
| 寅吃卯粮 | 收入不够支出，预先支用未来收入 |
| 竭泽而渔 | 把资源索取殆尽，不留余地和持续性 |

### 23. 人云亦云 / 随波逐流 / 拾人牙慧

| 词语 | 决定性差别 |
| --- | --- |
| 人云亦云 | 别人怎么说就跟着说，强调没有主见的言论 |
| 随波逐流 | 随着别人行动，强调没有立场和判断 |
| 拾人牙慧 | 抄用别人的片言只语当作自己的见解 |

### 24. 口若悬河 / 夸夸其谈 / 侃侃而谈 / 津津乐道

| 词语 | 决定性差别 | 色彩 |
| --- | --- | --- |
| 口若悬河 | 能说善辩，连续不断 | 中性或褒义 |
| 夸夸其谈 | 说话或文章浮夸、不切实际 | 贬义 |
| 侃侃而谈 | 理直气壮、从容不迫地说 | 褒义为主 |
| 津津乐道 | 很有兴趣地谈论 | 中性 |

### 25. 良莠不齐 / 泥沙俱下 / 参差不齐 / 鱼龙混杂 / 鱼目混珠

| 词语 | 决定性差别 |
| --- | --- |
| 良莠不齐 | 好坏混杂、质量不一 |
| 泥沙俱下 | 好坏事物在涌入、出现的过程中一同混入 |
| 参差不齐 | 长短、高低或水平不一致 |
| 鱼龙混杂 | 好人坏人或好坏事物混在一起，难以辨别 |
| 鱼目混珠 | 用假的冒充真的，或以次充好 |

判别轴：前三个先看“好坏混杂”还是“水平不齐”，鱼目混珠必须有冒充行为。

### 26. 纸上谈兵 / 坐而论道 / 徒托空言 / 照本宣科

| 词语 | 决定性差别 |
| --- | --- |
| 纸上谈兵 | 空谈理论，不能解决实际问题 |
| 坐而论道 | 只讲大道理而不行动 |
| 徒托空言 | 只说空话或把希望寄托于空话，不实行 |
| 照本宣科 | 死板地照稿、照条文讲述，没有发挥 |

### 27. 休戚与共 / 同舟共济 / 息息相关 / 唇齿相依

| 词语 | 决定性差别 |
| --- | --- |
| 休戚与共 | 福祸、忧喜共同承担，强调利害一致 |
| 同舟共济 | 团结协作，共同战胜困难 |
| 息息相关 | 联系非常密切，不必相互依存 |
| 唇齿相依 | 关系密切且相互依存，关联强于一般相关 |

### 28. 水到渠成 / 顺理成章 / 理所当然 / 迎刃而解

| 词语 | 决定性差别 |
| --- | --- |
| 水到渠成 | 条件成熟后事情自然成功 |
| 顺理成章 | 顺着道理或情势自然产生结果 |
| 理所当然 | 按道理本应如此，不强调形成过程 |
| 迎刃而解 | 问题得到顺利解决 |

### 29. 南辕北辙 / 分道扬镳 / 背道而驰

| 词语 | 决定性差别 |
| --- | --- |
| 南辕北辙 | 同一主体的行动与目的相反 |
| 分道扬镳 | 因目标或志趣不同而各走各路 |
| 背道而驰 | 两者方向、方针相反，或行动与正确方向相反 |

### 30. 慧眼识珠 / 明察秋毫 / 洞若观火 / 了如指掌

| 词语 | 决定性差别 |
| --- | --- |
| 慧眼识珠 | 识别有价值的人才或事物 |
| 明察秋毫 | 能发现极细小、不易察觉的问题 |
| 洞若观火 | 把事情观察得清楚透彻 |
| 了如指掌 | 对情况了解得非常清楚，不强调观察动作 |

## 高频句法限制

| 限制 | 词语 |
| --- | --- |
| 常用于否定句 | 望其项背、同日而语；等量齐观、相提并论也常见于否定口吻 |
| 主要形容人或人际协作 | 八面玲珑、同舟共济、休戚与共 |
| 主要形容做事 | 面面俱到、按部就班、蜻蜓点水 |
| 必须包含“少且珍贵” | 凤毛麟角 |
| 必须包含“以假乱真” | 鱼目混珠 |
| 必须包含“条件成熟” | 水到渠成 |
| 必须包含“最先受攻击或遭灾” | 首当其冲，不等于排在第一 |
