# 逻辑填空

## 知识点解析

### 概述

逻辑填空以语境对应为核心，需要联合词义、搭配、句间关系和语体作判断。多空题可从提示最强的一空切入，再验证全部空；词语熟悉程度和空格位置都不能单独决定答案。

### 稳空突破

| 步骤 | 做法 |
| --- | --- |
| 定位 | 找解释最明确、搭配限制最强的一空，不固定先看第二空 |
| 排除 | 将候选词代入，排除与语境直接冲突的项 |
| 回验 | 用语义、搭配、色彩及句间关系验证全部空 |

不要按空格顺序机械做。哪个空前后提示最强，就先做哪个空。

### 语境四关系

| 关系 | 信号 | 选词方向 |
| --- | --- | --- |
| 解释关系 | 即、也就是说、冒号、破折号 | 选同义或解释对应词 |
| 反对关系 | 但、却、不是而是 | 选反向语义 |
| 递进关系 | 甚至、更、乃至 | 后空语义更重 |
| 并列关系 | 和、并、同时 | 结构与语境相容，不必同义，如“机遇与挑战” |

### 词语辨析四维度

1. 语义侧重：词义核心是否对应语境。
2. 固定搭配：动宾、主谓、修饰对象是否自然。
3. 语境对应：是否呼应前后提示词。
4. 感情色彩：褒义、贬义、中性是否一致。

### 成语辨析

成语题尤其看感情色彩和适用对象。例如“趋之若鹜”是贬义，“争先恐后”较中性；“凤毛麟角”强调稀少且珍贵，“寥寥无几”只强调数量少。

### 多空联动例

适用条件：每组词须同时填入多个空。步骤：优先利用强解释句或固定搭配排除，再回代其他空检查整体。

自编题：“改革既不能因循守旧，也不能______；只有______，逐步调整，才能降低转型风险。”

| 选项 | 第一空 | 第二空 |
| --- | --- | --- |
| A | 急于求成 | 循序渐进 |
| B | 循序渐进 | 急于求成 |
| C | 墨守成规 | 一蹴而就 |
| D | 瞻前顾后 | 按图索骥 |

“逐步调整”直接解释第二空，应为“循序渐进”；回代第一空，“不能守旧”与“不能急于求成”构成两端约束，答案 A。C 的第一空与“因循守旧”重复，第二空又与逐步相反；D 也无照图查找的依据。

陷阱：不是看到“既……也……”就找同义词，该结构可以并列禁止两种相反倾向。

### 词义侧重的证据链

适用条件：两个词基本义接近。步骤：用后文解释定位强调的是数量、质量、对象还是程度，再比较词的适用范围。

自编例：“留存的手稿仅两件，数量______。”在“寥寥无几/凤毛麟角”中选前者，原文只给数量证据，没有强调珍贵稀有的人才或事物；若原文是“能独立完成这一高难实验的专家堪称______”，则“凤毛麟角”更贴合评价语境。

陷阱：不能脱离实际句法把词表中的褒贬、强弱顺序当作绝对规则；“甚至”的递进有时是范围或难度递进，不仅是词义轻重。

## 笔试应对

### 常考题型

- 多空题考某一空作为突破口。
- 近义词辨析考搭配对象。
- 成语题考褒贬和适用语境。
- 递进或转折关系考语义轻重。

### 解题方法

先找前后文提示最强的空，不按顺序硬填。确定稳空后，用语义、搭配、感情色彩验证。遇到成语，先判断褒贬和适用对象。

### 易错点

- 只看词语意思，不看语境关系。
- 忽略固定搭配。
- 贬义成语用到中性或褒义语境。
- 多空题从第一个空硬做，错过明显突破口。
