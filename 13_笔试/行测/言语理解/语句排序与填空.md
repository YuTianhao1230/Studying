# 语句排序与填空

## 知识点解析

### 概述

语句排序和语句填空考查语段连贯性。核心不是逐句翻译，而是找首句、找捆绑、看指代、看关联词和看话题一致。排序题把散句拼成完整逻辑，填空题判断横线位置承担总领、承转还是总结功能。

### 排序题步骤

1. 定首句：背景句、下定义句、提出话题句优先。
2. 检查依赖前文的句子：无指代对象的“上述/这”、承接前论的结论句通常不先行；不能只看开头有指代或转折词就绝对排除。
3. 找捆绑：指代词、关联词、同一话题、时间顺序。
4. 验尾句：总结、对策、结论常做尾句。

### 常见捆绑

| 捆绑类型 | 例子 |
| --- | --- |
| 指代捆绑 | 这、其、该、上述，前文必须有指代对象 |
| 关联词捆绑 | 不仅...而且、虽然...但是、因为...所以 |
| 话题捆绑 | 同一主体连续展开 |
| 时间捆绑 | 先后顺序、历史发展顺序 |
| 逻辑捆绑 | 提出问题 -> 分析原因 -> 解决问题 |

### 填空题位置

| 横线位置 | 作用 |
| --- | --- |
| 开头 | 引出话题、总领全文 |
| 中间 | 承上启下、解释说明、转折递进 |
| 结尾 | 总结观点、提出对策 |

填空选项必须与前后文话题一致、语气一致、逻辑一致。

### 先定依赖，再用选项验证

适用条件：句子可组成一个连贯语段，选项给出排序。步骤：找明确指代与时间依赖，组成小段，再用选项差异定位最后一个争议连接。

自编例：

1. 某社区试行预约办事。
2. 这项服务减少了居民现场等候。
3. 为扩大覆盖，社区又开通了电话预约。
4. 不过，最初只有熟悉手机操作的人能够使用它。

“这项服务”承接 1，“不过”转向原服务的限制，3 的电话预约回应 4，顺序为 1→2→4→3。每次连接均有指代或问题对策依据。

陷阱：指代依赖只保证先后，不必保证紧邻；“这种材料是一种合金”句内已可解释指代，不能仅因“这种”而排除首句。

### 横线的双向约束

适用条件：句子填空尤其在段中。步骤：先概括上文已知话题，再看下文解释或转折，候选句必须同时连接两侧。

自编例：“设备虽然已经联网，______。因此，要制定统一的数据格式，打通系统接口。”填“但不同系统间的数据仍难以互通”；前接让步，后接解决办法。填“用户总量不断增加”没有建立后文因果。

陷阱：横线在末尾也可能继续解释或举例，不必一定是总结或对策。

### 下文推断

适用条件：问最可能接着论述什么。步骤：抓尾句新提出但尚未展开的核心话题，再排除前文已详述内容和跳出范围的项。

自编例：“前文已介绍线上办理的便利，但对老年人的数字障碍仍需专门解决。”下文更可能讲适老化措施，而非重复线上办理的便利。此为篇章连贯判断，不表示作者下一句在逻辑上必然如此。

## 笔试应对

### 常考题型

- 语句排序考首句排除和句间捆绑。
- 语句填空考横线前后的承接关系。
- 选项设置指代不明、话题突变和逻辑断裂。

### 解题方法

排序题先排除不能做首句的句子，再找指代和关联词捆绑，最后通读验证。填空题先看横线位置，再判断它要总领、承转还是总结。

### 易错点

- 让找不到指代对象的依赖句做首句，或仅凭首词机械排除。
- 忽略“虽然...但是”等固定关联词搭配。
- 填空题只看横线后，不看横线前。
- 话题从一个主体跳到另一个主体。
