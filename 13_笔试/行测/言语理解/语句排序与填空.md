# 语句排序与填空

## 知识点解析

### 概述

语句排序和语句填空考查语段连贯性。核心不是逐句翻译，而是找首句、找捆绑、看指代、看关联词和看话题一致。排序题把散句拼成完整逻辑，填空题判断横线位置承担总领、承转还是总结功能。

### 排序题步骤

大原则：从选项入手，用排除法答题。首句初排除，捆绑再排除，尾句作参考，有时间再验证。

1. 定首句：背景句、下定义句、提出话题句优先。
2. 检查依赖前文的句子：无指代对象的“上述/这”、承接前论的结论句通常不先行；不能只看开头有指代或转折词就绝对排除。
3. 找捆绑：指代词、关联词、同一话题、时间顺序。
4. 验尾句：总结、对策、结论常做尾句。
5. 哪一步最容易排除就先用哪一步，不必机械固定顺序。

首句高频特征：

| 不适合首句 | 适合首句 |
| --- | --- |
| 指代不明的指示代词 | 下定义 |
| 成组关联词的后半部分 | 背景铺垫 |
| 结论句 | 援引观点 |
| 补充、解释或细节描述 | 提出新话题 |

### 常见捆绑

| 捆绑类型 | 例子 |
| --- | --- |
| 指代捆绑 | 这、其、该、上述，前文必须有指代对象 |
| 关联词捆绑 | 不仅...而且、虽然...但是、因为...所以 |
| 话题捆绑 | 同一主体连续展开 |
| 时间捆绑 | 先后顺序、历史发展顺序 |
| 逻辑捆绑 | 提出问题 -> 分析原因 -> 解决问题 |

补充：

- 指示代词通常紧跟被指代内容；自己无法确定时，结合选项排除。
- 重复词可形成话题捆绑，注意“顶真”手法，即上句末尾成为下句开头。
- 成组关联词能确定先后顺序，但不一定严格紧邻，一般不会相隔太远。
- 除逻辑顺序外，还要检查文章行文脉络和时空顺序。

### 填空题位置

| 横线位置 | 作用 |
| --- | --- |
| 开头 | 引出话题、总领全文 |
| 中间 | 承上启下、解释说明、转折递进 |
| 结尾 | 总结观点、提出对策 |

填空选项必须与前后文话题一致、语气一致、逻辑一致。

语句衔接采用 213 题序：先看提问，再读文段，最后看选项。首尾空常变相考主旨；中间空通常承上启下且更偏向启下。逻辑关联词和标点符号可辅助判断。

### 先定依赖，再用选项验证

适用条件：句子可组成一个连贯语段，选项给出排序。步骤：找明确指代与时间依赖，组成小段，再用选项差异定位最后一个争议连接。

自编例：

1. 某社区试行预约办事。
2. 这项服务减少了居民现场等候。
3. 为扩大覆盖，社区又开通了电话预约。
4. 不过，最初只有熟悉手机操作的人能够使用它。

“这项服务”承接 1，“不过”转向原服务的限制，3 的电话预约回应 4，顺序为 1→2→4→3。每次连接均有指代或问题对策依据。

陷阱：指代依赖只保证先后，不必保证紧邻；“这种材料是一种合金”句内已可解释指代，不能仅因“这种”而排除首句。

### 横线的双向约束

适用条件：句子填空尤其在段中。步骤：先概括上文已知话题，再看下文解释或转折，候选句必须同时连接两侧。

自编例：“设备虽然已经联网，______。因此，要制定统一的数据格式，打通系统接口。”填“但不同系统间的数据仍难以互通”；前接让步，后接解决办法。填“用户总量不断增加”没有建立后文因果。

陷阱：横线在末尾也可能继续解释或举例，不必一定是总结或对策。

### 下文推断

适用条件：问最可能接着论述什么。步骤：抓尾句新提出但尚未展开的核心话题，再排除前文已详述内容和跳出范围的项。

自编例：“前文已介绍线上办理的便利，但对老年人的数字障碍仍需专门解决。”下文更可能讲适老化措施，而非重复线上办理的便利。此为篇章连贯判断，不表示作者下一句在逻辑上必然如此。

尾句类型与下文方向：

| 尾句 | 下文优先方向 |
| --- | --- |
| 提出新话题 | 继续解释该话题 |
| 提出问题，尚未分析 | 先分析问题，或在选项中优先检查针对性解决方案 |
| 已经分析完问题 | 解决问题 |
| 提出对策 | 展开途径、建议和具体做法 |

错误项常重复前文已讲内容，或突然跳到无关信息。两个选项难分时，针对核心问题的解决方案通常比重复病症更有推进性。

### 训练与止损

- 排序题适合成组专项训练，例如每组连续做 20 题。
- 复盘同一道题时尝试 2-3 种排除路径，训练对捆绑信息的敏感度。
- 锁定选项后大胆通读验证；验证失败就换候选，避免在同一顺序上反复自证。

## 笔试应对

### 常考题型

- 语句排序考首句排除和句间捆绑。
- 语句填空考横线前后的承接关系。
- 选项设置指代不明、话题突变和逻辑断裂。

### 解题方法

排序题先排除不能做首句的句子，再找指代和关联词捆绑，最后通读验证。填空题先看横线位置，再判断它要总领、承转还是总结。

### 易错点

- 让找不到指代对象的依赖句做首句，或仅凭首词机械排除。
- 忽略“虽然...但是”等固定关联词搭配。
- 填空题只看横线后，不看横线前。
- 话题从一个主体跳到另一个主体。

## 面试应对

### 1. 语句排序题的稳定解题步骤是什么？

- 常考点及考法：要求说明首句判断、句间捆绑和选项验证的先后关系。
- 回答思路：先排除强依赖前文的句子，再建立确定捆绑，最后用选项差异验证整体顺序。
- 易错点：只凭首句特征直接确定答案，或把存在先后关系误认为必须紧邻。
- 回答模板：我先排除缺少指代对象的句子和明显的结论、转折承接句，再寻找指代、关联词、时间和问题对策形成的确定捆绑。随后利用选项之间的顺序差异重点验证争议连接，最后通读检查话题推进。首句和捆绑都是高概率线索，必须由完整语段复核。

### 2. 段中语句填空为什么要双向验证？

- 常考点及考法：横线位于文段中间，选项既要承接上文又要引出下文。
- 回答思路：分别概括前文已知信息和后文待解释内容，判断横线承担的逻辑功能。
- 易错点：只因选项能接上前一句就选择，忽略它与后文的因果或转折关系。
- 回答模板：段中填空受到前后文双重约束。我会先概括上文的话题和已知结论，再看下文是在解释、转折、举例还是提出对策，由此确定横线应承担的功能。正确选项要同时满足对象一致、逻辑连贯和语气匹配，不能只与一侧表面衔接。

### 3. 下文推断题如何控制推断范围？

- 常考点及考法：根据文段尾部判断下一段最可能展开的内容。
- 回答思路：抓尾句新提出但尚未展开的话题，排除已充分论述和跨度过大的选项。
- 易错点：选择与全文主题相关却没有承接尾句的内容，或把“最可能”理解为逻辑必然。
- 回答模板：下文推断重点看尾部的话题落点。我会找最后新出现且尚未展开的对象、问题或对策，再判断哪个选项能直接延续它。前文已经详细说明的内容通常不会立即重复，突然更换主体或上升到更大主题的选项也应排除。
