# 言语理解

本目录整理片段阅读、主旨意图、逻辑填空、语句表达和公开真题案例。核心是识别文段结构与作者意图，并用语境和搭配约束排除干扰选项。

## 训练顺序

1. 先学习结构阅读与选项辨析，再训练片段阅读和主旨意图题。
2. 接着学习逻辑填空和词语辨析，用专项真题建立语境、搭配和多空联动意识。
3. 最后用真题案例记录文段结构误判、概念偷换和范围扩大等错因。
