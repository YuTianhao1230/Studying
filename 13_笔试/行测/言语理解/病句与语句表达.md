# 病句与语句表达

## 知识点解析

### 概述

病句与语句表达是银行和运营商言语题中常见的补充题型，主要考查句子成分、搭配、语序、逻辑和表意完整性。常见病句包括成分残缺、搭配不当、语序不当、重复赘余、结构混乱、不合逻辑和主客体偷换。

### 常见病句类型

| 类型 | 判断方法 |
| --- | --- |
| 成分残缺 | 看主语、谓语、宾语是否完整 |
| 搭配不当 | 看主谓、动宾、定中是否能搭配 |
| 语序不当 | 看时间、范围、逻辑顺序 |
| 重复赘余 | 看是否重复表达同一含义 |
| 结构混乱 | 两套句式杂糅 |
| 不合逻辑 | 因果、递进、并列关系不成立 |
| 主客体混乱 | “对/使/由”引出的对象关系错误 |
| 两面对一面 | “是否/能否”与单一结果不匹配 |

### 快速检查顺序

1. 找主干：主语、谓语、宾语。
2. 看搭配：动词与宾语、形容词与中心词。
3. 看关联词：关系是否匹配，位置与主语是否协调；关联词可以依法省略，不要求机械成对出现。
4. 看逻辑：因果、递进、并列、时间顺序是否合理。
5. 看限定词：是否、能否、至少、主要、通过等是否前后一致。

### 语句表达

常见题型包括语句排序、语句衔接、下文推断和句子改写。排序先定首句，再找指代和关联词捆绑；下文推断要承接文段最后一个话题，不能引入无关新主题。

### 压缩主干与最小修改

适用条件：判断或修改病句，须保留原意。步骤：暂去修饰语找主谓宾，定位搭配或成分缺口，再作最小修改并通读。

| 自编病句 | 诊断与修改 | 陷阱 |
| --- | --- | --- |
| 通过这次培训，使员工掌握了流程。 | “通过”使前半成介词结构，后半又以“使”引出对象，主语残缺；删“通过”或删“使” | “通过……使……”只是风险信号；“我们通过培训使员工掌握流程”主语完整 |
| 项目能否完成，取决于团队的努力已经取得成功。 | 句式混杂且逻辑不清；改“项目能否完成，取决于团队能否有效协作” | 修改须对应原意，不能凭看到“能否”就判病 |
| 本次调查的对象主要是以青年为主。 | “主要是……”与“以……为主”杂糅；删去一套 | 不要同时删除必要成分 |
| 今年成本比去年下降了一倍。 | 非负成本不能按通常含义下降 100%以上；若实际为原来一半，应写“下降了 50%” | 倍数、百分比变化须明确基数 |

### 否定、两面与歧义

适用条件：有“防止、避免、无不、能否、是否”等高风险词。步骤：把否定逐层展开，分别试代正反情况，检查句意是否都通。

自编例：“应防止类似事故不再发生”与想避免事故的本意相反，应删“不再”改为“应防止类似事故再次发生”。“是否认真，是成绩好坏的重要因素”中两面对应两面，不因出现“是否”而判错。

歧义自编例：“三个学校的老师参加了会议”可指三所学校，也可误解为三个老师；若原意是三所学校，应写“三所学校的老师参加了会议”。先确定原意，不能随意替用户选一种解释。

陷阱：双重否定不一定错误；“无不”可表示全都，“避免不必要的损失”本身没有否定错误。

## 笔试应对

### 常考题型

- 下列句子有语病/没有语病。
- 句子排序。
- 横线处语句衔接。
- 根据文段推断下文。

### 解题方法

先压缩主干，再检查搭配和逻辑；排序依据指代是否明确、语义是否依赖前文，而非只看开头词；下文推断重点看尾部未展开的话题。

### 易错点

- 只凭读起来顺不顺判断。
- 忽略“通过……使……”造成主语残缺。
- 忽略“是否/能否”造成两面对一面。
- 排序题只看单句，不看句间指代和话题连续。

## 面试应对

### 1. 判断病句时采用什么检查顺序？

- 常考点及考法：要求说明如何系统识别成分残缺、搭配不当、结构混乱和逻辑错误。
- 回答思路：先压缩主干，再恢复修饰语检查搭配、语序、关联词和逻辑。
- 易错点：完全依赖语感，或看到固定高风险结构就不核对句子主干。
- 回答模板：我先去掉修饰成分，检查主语、谓语和宾语是否完整、搭配是否成立；再恢复定语和状语，检查语序、关联词位置及句式是否杂糅；最后核对否定、两面词、数量关系和因果逻辑。高风险结构只是定位线索，仍要结合完整句法判断。

### 2. 如何判断“是否”“能否”造成的两面对一面？

- 常考点及考法：句中出现两面词，要求判断后文结果能否同时对应正反两种情况。
- 回答思路：分别代入肯定和否定情况，看谓语及结果是否都能成立。
- 易错点：见到两面词就判错，忽略“成败、优劣、高低”等隐含两面的词。
- 回答模板：我会把“是否”分别替换成肯定和否定两种情况，检查后面的结果是否都能承接。如果前面是两面、后面只有“取得成功”这类单面结果，就可能不对应；如果后面是“成败”或“高低”等两面结果，则结构可以成立，不能机械判错。

### 3. 修改病句时为什么强调最小修改？

- 常考点及考法：给出病句并要求说明修改方法及原意保持。
- 回答思路：先定位唯一或主要病因，只调整必要成分，再通读复核语义。
- 易错点：为了让句子通顺而改换主题、删掉关键信息或引入新的歧义。
- 回答模板：修改病句的目标是消除语病并保留原意。我会先根据句子主干定位成分、搭配或逻辑问题，只删除、补充或调整必要部分，然后复核主客体、语气和信息范围是否变化。能改一个位置解决的问题，不同时重写其他内容。
