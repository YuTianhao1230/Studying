# 言语理解结构阅读与选项辨析

## 使用定位

本卡只负责阅读顺序、题型识别和选项淘汰。行文结构进入[片段阅读](<片段阅读.md>)，主旨、意图、细节、标题与词句理解进入[主旨意图细节与标题](<主旨意图细节与标题.md>)，选词进入[逻辑填空](<逻辑填空.md>)，句序与语句衔接进入[语句排序与填空](<语句排序与填空.md>)，词义与成语积累进入[近义词与成语辨析](<近义词与成语辨析.md>)。

## 阅读顺序

1. 先看问法，确认要概括、推断、核对细节、选词还是判断句间衔接。
2. 再读文段骨架，标记背景、观点、解释、例子、转折、结论和对策。
3. 提取“主题对象 + 核心判断”，并保留范围、条件、时态和语气。
4. 比较选项差异，不从头平均验证所有文字；先查决定答案的差异点。
5. 回到原文核证，确认所选项既覆盖任务要求，又没有改变逻辑关系。

结构词只用于识别句间关系，不能机械决定全文重点。转折后、尾句或对策句是否重要，仍须结合其在全文中的功能判断。

## 题型识别

| 问法或题面 | 当前任务 | 首要证据 | 专题入口 |
| --- | --- | --- | --- |
| “主要说明”“概括最准确” | 主旨概括 | 结构重点、主题对象和核心判断 | [主旨意图细节与标题](<主旨意图细节与标题.md>) |
| “意在说明/强调”“启示” | 意图判断 | 主旨及文本是否明确支持对策 | [主旨意图细节与标题](<主旨意图细节与标题.md>) |
| “符合/不符合原文” | 细节理解 | 主体、范围、程度、时态和因果的逐项对应 | [主旨意图细节与标题](<主旨意图细节与标题.md>) |
| “最适合做标题”“词句理解” | 标题或语境释义 | 全文覆盖、文体和就近解释 | [主旨意图细节与标题](<主旨意图细节与标题.md>) |
| 完整文段后问中心、结构或观点 | 片段阅读 | 总分、并列、转折、因果及句子功能 | [片段阅读](<片段阅读.md>) |
| 一个或多个词语空缺 | 逻辑填空 | 稳空、语境关系、搭配和感情色彩 | [逻辑填空](<逻辑填空.md>) |
| 散句排序、横线补句、下文推断 | 语句衔接 | 指代、关联、话题、时间与双向约束 | [语句排序与填空](<语句排序与填空.md>) |
| 近义词或成语差异难以区分 | 词义辨析 | 语义侧重、对象、搭配、程度、褒贬和语体 | [近义词与成语辨析](<近义词与成语辨析.md>) |

## 选项淘汰框架

把候选项拆成“对象 + 判断 + 限定”，按下列顺序检查：

| 检查维度 | 淘汰信号 |
| --- | --- |
| 任务匹配 | 主旨题只复述例子，细节题加入推断，填空题忽略横线功能 |
| 主题对象 | 偷换主体、对象或讨论层级，只因出现原文关键词就冒充同义转述 |
| 信息范围 | 只覆盖并列的一部分，或把局部背景扩大为全文结论 |
| 逻辑关系 | 把并列、相关、先后改成因果，把必要条件改成充分条件 |
| 程度与时态 | 把“可能、部分、主要、正在”改成“必然、全部、唯一、已经” |
| 观点位置 | 把例子、他人观点、背景或让步内容当成作者最终判断 |
| 对策边界 | 对策未回应原文问题，或新增原文未支持的主体、技术和目标 |
| 语言适配 | 词义大致相近，但搭配对象、褒贬、语体或递进强度不合 |

两个选项都与原文相关时，优先保留同时满足以下条件的一项：

1. 覆盖题目要求的范围，而不是只命中局部词语。
2. 保留原文的核心判断及条件、因果和程度。
3. 不增加原文没有论证的原因、对策或价值判断。
4. 回代后能与全文或全部空格共同成立。

## 最终检查

- 主旨和意图：是否保留“对象 + 核心判断”，对策是否有文本依据。
- 细节：是否逐项核对主体、时间、范围、程度和逻辑。
- 逻辑填空：是否先由语境定方向，再核对词义、搭配和色彩。
- 排序与填空：是否同时满足指代依赖、话题推进和前后衔接。
- 所有题型：正确项应是受原文支持的准确表达，而不是仅凭常识成立。
