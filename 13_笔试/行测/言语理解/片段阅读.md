# 片段阅读

## 知识点解析

### 概述

片段阅读方法强调“找结构、定重点、比选项”。片段阅读不是逐字读懂全部材料，而是通过行文脉络、关联词和主题词判断作者重点。主旨题抓核心观点，意图题看是否需要对策，细节题回原文逐项比对。

### 行文脉络

| 结构 | 重点 |
| --- | --- |
| 总-分 | 总句 |
| 分-总 | 结论句 |
| 分-总-分 | 中间总句或首尾呼应 |
| 并列 | 全面概括 |
| 问题-危害-对策 | 对策 |
| 现象-原因-结论 | 原因或结论 |

### 关联词重点

| 关联词 | 重点位置 |
| --- | --- |
| 但、然而、其实、事实上 | 转折后 |
| 因此、所以、可见 | 结论 |
| 甚至、更、尤其 | 递进后 |
| 同时、此外、另一方面 | 并列各方面都要覆盖 |

### 主题词与核心判断

主题词是贯穿全文的核心对象，可有同义替换、省略和上位概括。反复出现次数只是线索；正确选项还须保留作者对对象作出的核心判断，不能只匹配关键词。

### 意图判断

明示对策且处于全文重点时选其同义转述；仅提出问题时，须检查作者论述目的和选项依据，不能自动补一个建议。选择条件详见[主旨意图细节与标题](<主旨意图细节与标题.md>)。

### 句子功能标注与层次

适用条件：主旨题包含例子、背景、观点或多层转折。步骤：每句标“背景/观点/解释/例子”，先找能统摄其他句的判断，再检验关联词影响的是一句还是全文。

自编例：“一些老街修缮只求外观整齐。比如统一招牌虽然漂亮，却可能抹去特色。保护老街更应延续居民生活。”三句分别为现象、例证、总观点；中心是“保护应延续生活”，不是第二句局部的“招牌不应统一”。

陷阱：并非每个转折后的话都是全文主旨，例子内部也有转折；首尾句同样须完整核对。

### 并列概括与条件句

适用条件：文段有平行方面，或用条件句表达目标与必要做法。步骤：并列找共同上位概念且保留重要分支；条件句同时保留措施和目标，判断其在全文中的地位。

自编例：“数字馆藏方便远程检索，实体展览提供现场体验。”两部分平行，可概括“数字与实体服务各有优势”；只选数字便利则遗漏一半。

自编例：“历史街区特色各异，只有因地制宜，才能保护其独特风貌。”中心是保护须因地制宜；“只要因地制宜就一定保护成功”把必要条件误改成充分条件。

陷阱：条件句也可能只是客观说明，如“温度达到阈值才报警”，不能仅凭“才”就推成作者倡议。

## 笔试应对

### 常考题型

- 主旨概括题考结构重点。
- 意图判断题考问题后的对策。
- 标题题考短小准确和主题覆盖。
- 选项设置局部概括、过度引申、无中生有。

### 解题方法

先看首尾句和关联词，再核对各句功能与主题。主旨题保留核心判断，意图题仅在文本支撑时选对策，选项对比时检查范围、条件和语气。

### 易错点

- 并列结构只选其中一部分。
- 看到对策就选，但对策并不针对文段问题。
- 主题词被偷换。
- 把例子当主旨。
