# 主旨意图细节与标题

## 知识点解析

### 概述

主旨概括、意图判断、细节理解、标题填入和词句理解是言语理解的标准题型。主旨题问文段核心观点，意图题问作者目的，细节题问选项是否符合原文，标题题要求短小覆盖主题，词句理解题要求回到上下文解释。标准方法是先判断题型，再用结构、主题词和选项排雷处理。

### 主旨概括

主旨题常见问法：

- 这段文字主要说明。
- 这段文字意在强调。
- 对这段文字概括最准确的是。

解法：

1. 找行文结构。
2. 找主题词。
3. 找作者观点句。
4. 排除例子、背景、局部内容。

### 意图判断

“意在说明/强调”常仍要求概括中心，不意味着一定向外引申。先看原文是否明确主张行动，或问题与原因是否足以支持某个对策；文段若以解释事实为目的，准确概括现象、原因即可。

### 对策项的选择条件

适用条件：主旨、意图题中，作者在全文层面提出问题和解决方向，而非仅在引语、例子里出现“应该”。

步骤：

1. 明确作者关注的主体、问题、原因和目标。
2. 文段明示对策时，优先寻找保持范围与语气的同义转述。
3. 只有问题时，对策必须直接回应原文已指出的障碍，不能增加未经论证的技术、资金或制度前提。
4. 没有可支撑的对策，选准确主旨；不能因有“应当”就优先。

自编例：某市办事材料重复提交，原因是部门数据不互通。文段最后说“因此应打通部门数据接口”。中心是“以数据共享减少重复提交”；“全面取消审批”“增加窗口人员”都不对应明确原因。

反例（自编）：某地降雨偏少，材料用海温和环流解释其成因，未讨论政策。主旨应概括“降雨变化的气候原因”；不能自行选“立即开展人工增雨”。

陷阱：对策未必是越具体越好；执行主体、目标范围、限制条件都不能偷换。教学参照：[中公，对策何时才能选](https://eoffcn.com/kszx/detail/1343806.html)，方法名称据公开说明核验，本卡条件与短例独立整理。

### 细节理解

细节题常见错误：

| 错误 | 表现 |
| --- | --- |
| 无中生有 | 原文没有提 |
| 偷换概念 | 主体、对象、范围变化 |
| 偷换程度 | 可能变必然，部分变全部 |
| 偷换时态 | 已然、未然、正在混淆 |
| 强加因果 | 把相关或先后说成因果 |

### 标题填入

标题要满足：

- 覆盖主题。
- 简洁凝练。
- 适合文体。
- 不夸大、不偏题。

新闻类抓导语核心，议论文同主旨，说明文抓说明对象，记叙文抓主题或情感。

### 词句理解

词句理解遵循就近原则。先看该词句前后是否有解释、转折、总结或例子，再确定含义。不能脱离语境按字面意思发挥。

### 细节与标题的对照例

适用条件：细节题核对命题是否受原文支持，标题题则需覆盖全文而非照抄一个局部。步骤：标主体、时间、范围、程度，逐一对齐。

自编原文：“在三家试点网点，预约服务使高峰期等待时间有所缩短，能否推广还需评估。”

- 可推出“试点网点高峰期等待有所改善”。
- 不能推出“所有网点已全面推广”或“预约彻底消除了排队”。
- 标题“预约服务试点的效果与推广评估”覆盖全文；“银行不再排队”夸大效果。

陷阱：细节题的“未提及”不等于现实世界必假；“一定/全部”也不天然错误，关键是原文是否明确支持。

## 笔试应对

### 常考题型

- 主旨题考结构和主题词。
- 意图题考对策选择。
- 细节题考选项设错。
- 标题题考主题覆盖和文体适配。
- 词句理解题考上下文解释。

### 解题方法

主旨题找核心观点，意图题看是否有问题对策，细节题逐词比对原文，标题题选短小且覆盖主题，词句理解回到上下文。

### 易错点

- 主旨题选择例子或背景。
- 意图题选择无中生有的对策。
- 细节题忽略程度词和时态词。
- 标题题选项太宽或太窄。
