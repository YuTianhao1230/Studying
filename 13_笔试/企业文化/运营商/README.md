# 运营商企业文化

## 概述

中国移动、中国电信、中国联通均为中央企业体系下的电信运营商。三者的共同业务已从传统语音、短信和宽带，扩展到云计算、算力、数据、人工智能及行业数字化服务；各自的法人结构、文化用语、客户品牌和战略表述仍有明显差异。

企业文化知识需要区分四个层次：企业身份与沿革、使命愿景价值观、品牌与服务、特定年度的发展战略。“集团成立”“股份公司成立”“上市”和“重组”是不同事件；文化愿景、阶段性战略目标、品牌广告语也不能互相替代。

资料核验日期：2026-09-27。主要依据官方公司介绍、企业文化页面、2025年年度或社会责任报告，以及2026年中期业绩资料。个别文化条目使用更早的官方材料，具体年份在卡片中单列。

## 年份与证据

1. 先看资料期，再看发布日期。2025年年度报告通常在2026年发布，“2026年核验”不代表报告中的每项数据都属于2026年。
2. 无更新时间的官网页面仅记录核验日期，不推定其内容首次发布或修订于2026年。
3. 战略、品牌和业务分类会调整。旧材料中的正式表述可以是正确的历史知识，但不宜直接替代较新年度口径。
4. 引号内的文化或战略用语注明官方出处；解释段落用于说明概念，不是新增的官方口号。
5. 本目录不根据培训机构宣传推定“必考”或“高频”。具体招聘考试要求应以招聘单位当期公告为准。
6. 不使用动态用户规模、市场排名或领导姓名作为识别公司的主要依据。
