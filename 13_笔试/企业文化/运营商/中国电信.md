# 中国电信

## 概述

中国电信的业务包括移动通信、固定通信、互联网、卫星通信，以及云计算、算力、大数据、人工智能和行业信息化服务。其战略强调云与网络的融合，并逐步强化面向客户和行业的智能化服务。[T1] [T2]

资料核验日期：2026-09-27。身份主要依据集团官网、2025年报和官方沿革资料；较新战略采用2026年中期口径。文化部分区分2015年报、2022年官方报道及2025年社会责任报告，避免把不同年份的表述合并成一套现行原文。

## 身份与沿革

### 集团与上市主体

| 层次 | 名称与性质 | 区分要点 |
| --- | --- | --- |
| 集团 | 中国电信集团有限公司 | 国家单独出资设立的中央企业，控股中国电信股份有限公司等公司。[T1] |
| 上市公司 | 中国电信股份有限公司 | 在中国境内注册成立，发行H股和A股；与集团母公司是不同法人。[T2] [T3] [T4] |
| 业务范围 | 移动、固定、卫星、互联网及综合信息服务等 | “中国电信”不是只经营固定电话，也不因采用“云改”战略就不再提供通信服务。[T1] [T2] |

中国电信股份有限公司的注册地在中国境内，不应因其在香港上市而误写为香港注册公司。这与中国移动有限公司的注册地情况不同。

### 关键时间

| 时间 | 事件 | 区分要点 |
| --- | --- | --- |
| 2000年5月 | 中国电信集团挂牌。 | 官方沿革中的集团阶段，不是股份公司设立时间。[T5] |
| 2002-05-16 | 新的中国电信集团与中国网通集团挂牌。 | 电信体制改革中的重组节点，不能与同年股份公司设立混为一事。[T5] |
| 2002-09-10 | 中国电信股份有限公司成立。 | 2025年报财务报表附注列示的上市主体设立日期。[T3] |
| 2002-11-15 | 中国电信股份有限公司H股在香港上市。 | 股票代码00728。[T4] |
| 2008年12月 | 推出移动业务品牌“天翼”。 | 业务及品牌沿革节点，不是集团首次成立。[T5] |
| 2021-08-20 | 中国电信股份有限公司A股在上海上市。 | 股票代码601728。[T4] |

2019-09-09，中国电信与中国联通签署5G网络共建共享合作协议。[T5] 网络合作不等于两家企业合并，也不意味着品牌、客户关系和客服号码统一。

## 企业文化与服务

### 2015年报列示的文化体系

下表是2015年年度报告“企业文化”页原有字段，属于明确的历史资料口径。不能仅凭这份材料断言其中每项都是2026年最新表述。[T6]

| 类别 | 官方表述 | 理解要点 |
| --- | --- | --- |
| 企业使命 | 让客户尽情享受信息新生活 | 以客户的信息服务体验为落点。 |
| 战略目标 | 做世界级综合信息服务提供商 | 原文类别是“战略目标”，不擅自改标为同年“企业愿景”。 |
| 核心价值观 | 全面创新、求真务实、以人为本、共创价值 | 分别涉及创新、务实、人的发展与价值创造。 |
| 经营理念 | 追求企业价值与客户价值共同成长 | 同时关注企业发展与客户获得的价值。 |
| 服务理念 | 用户至上、用心服务 | 强调客户导向和服务投入。 |
| 企业形象口号 | 世界触手可及 | 形象传播用语，不是使命或核心价值观。 |

价值观、经营理念和服务理念虽然相互关联，但不是同一个字段。例如“用户至上、用心服务”不应在这份资料中被替换标注为完整核心价值观。

### 2022年报道中的使命愿景与精神

2022-09-14，中国电信官网转载的国企改革报道，将以下内容放在企业使命愿景的语境中：[T7]

- “党领导下完成政治任务的经济组织”。
- “建设网络强国、数字中国和维护网信安全的主力军”。
- “领先的综合智能信息服务运营商”。

原报道并未将上述三项分别整理为一一对应的“使命”“愿景”“价值观”表格，因此本卡按原有语境整体保留，不人为拆分字段。

该报道还列出“红色电信精神”：听党指挥、信念坚定、一心为民、变革创新、崇尚科技、安全畅通。[T7] 这是精神传承的表述，与2015年报的四项核心价值观不是同一张清单。

### 较近资料中的服务理念

2025年社会责任报告的“用心服务客户”页面于2026-07-02发布，继续使用“用户至上、用心服务”，并介绍“客户说了算”及“用心、放心、称心”的服务体系。[T10]

可据此确认“用户至上、用心服务”仍见于较近年度的官方服务材料；这项连续性证据不自动证明2015年报所有文化字段都未发生变化。

## 业务品牌与服务号码

| 名称 | 层次与定位 | 资料口径及辨析 |
| --- | --- | --- |
| 天翼 | 中国电信移动业务品牌。 | 官方沿革记载于2008年12月推出；品牌名不等于上市公司法定名称。[T5] |
| 天翼云 | 云计算与智能云相关品牌。 | 2025年及2026年中期业绩的重要业务内容；不是仅供手机用户使用的个人网盘概念。[T8] [T9] |
| 星辰大模型 | 人工智能模型体系相关名称。 | 与天翼云的云服务层次不同，不能把模型品牌写成云品牌的别称。[T8] |
| 息壤 | 算力平台名称。 | 侧重算力资源与调度等平台能力，不是通信套餐品牌。[T8] |
| 翼支付 | 支付业务品牌。 | 官方沿革记载于2011年推出；本卡仅用于识别业务归属，不涉及实时产品或金融资质判断。[T5] |
| 10000 | 内地公众客户服务热线。 | 2025年社会责任报告使用的服务热线；与中国移动10086、中国联通10010区分。[T10] |

官方沿革还记载了“商务领航”（2005年，企业客户）、“我的E家”（2006年，家庭客户）、“天翼飞young”（2012年，年轻客户）等历史品牌。[T5] 这些名称适合放入品牌沿革理解，不能据此声称它们构成2026年的完整在售品牌矩阵。

## 战略内涵

### 从“云改数转”到“云改数转智惠”

2022年改革报道阐释“云改数转”，强调以客户为中心、以科技创新为驱动，建设云网融合、绿色安全的基础设施，并推进数字平台、改革与生态协同。[T7]

2025年中期业绩资料提出升级实施“云改数转智惠”战略；2026年中期业绩继续使用这一表述，并推进服务型、科技型、安全型企业建设。[T8] [T9]

| 关键词 | 结合官方业务内容的理解 |
| --- | --- |
| 云改 | 围绕云与网络融合调整能力供给、产品服务和运营方式，不只是把文件搬到云盘。 |
| 数转 | 既包含企业自身数字化转型，也包含为客户和行业提供数字化服务。 |
| 智惠 | 将人工智能能力进一步用于内部提效和外部服务，使智能化能力转化为客户可获得的产品与应用。 |
| 服务型 | 以客户需求和服务价值组织业务，不能只关注基础设施投入。 |
| 科技型 | 强调科技创新及成果转化，形成云、算力、模型和应用等能力。 |
| 安全型 | 将网络、数据及服务安全作为发展要求，而不是孤立的一种增值产品。 |

以上是便于辨析的解释，不是逐字拆词形成的新增官方定义。“智惠”也不能缩减为某一个模型名称或单一智能客服产品。

### 智能云“五位一体”

2025年及2026年中期资料使用“算力+平台+数据+模型+应用”的智能云体系。[T8] [T9]

| 层次 | 概念位置 |
| --- | --- |
| 算力 | 支撑计算和模型运行的资源基础。 |
| 平台 | 提供资源组织、开发和服务支撑等能力。 |
| 数据 | 支撑数据开发利用及智能化应用。 |
| 模型 | 提供人工智能模型能力。 |
| 应用 | 将前述能力落实到个人、企业及行业场景。 |

这五项是智能云体系的能力组成，不是五个客户品牌，也不是五家独立公司。“天翼云”“星辰大模型”“息壤”应在各自层次理解，不机械地视为五项要素的完整一一映射。

### 战略与业务分类的区别

“云改数转智惠”是发展战略；移动、固网、卫星等是业务或连接类型；“算力+平台+数据+模型+应用”是智能云体系结构。三个层次不能互相替代。

年度报告和中期报告的业务分类也可能调整。例如2026年中期资料围绕通信业务和智能业务展开，而较早材料还使用基础业务、产业数字化等口径。[T8] [T9] 比较年度收入时应核对定义与可比口径，不能只凭名称相近就直接计算增减。

## 易混辨析

1. 中国电信集团有限公司与中国电信股份有限公司不是同一法人；H股、A股对应的是后者，且后者在中国境内注册。
2. 2000年集团挂牌、2002年集团重组、2002年股份公司成立、2002年H股上市是不同事件。
3. “让客户尽情享受信息新生活”是2015年报的使命；“世界触手可及”是同份材料的企业形象口号。
4. “用户至上、用心服务”是服务理念，且在2025年社会责任报告中继续出现；不能将它与四项核心价值观或红色电信精神混写。
5. 天翼是业务品牌，天翼云是云相关品牌，星辰是模型相关名称，息壤是算力平台。
6. “云改数转智惠”不是“云改数转”材料中天然存在的完整原句，需匹配资料年份；5G共建共享也不等于企业合并。

## 自编笔试题

以下均为单项选择题，依据本卡注明年份的资料编写，不是官方真题。

### 第1题：主体与上市

关于中国电信，下列说法正确的是：

A. 中国电信股份有限公司在中国境内注册，H股与A股上市对应这一股份公司，而非集团母公司。

B. 中国电信集团有限公司于2021年A股上市时首次成立。

C. 在香港上市意味着中国电信股份有限公司一定在香港注册。

D. 与中国联通开展5G共建共享，意味着两家公司的客服号码已经统一。

答案：A。

解析：股份公司于2002年成立，分别于2002年、2021年在香港和上海上市；上市地点不能代替注册地判断。网络共建共享属于合作，不改变本卡所列主体与客服号码的归属。[T3] [T4] [T5] [T10]

### 第2题：文化字段

依据2015年报企业文化页，并结合2025年社会责任报告，下列说法正确的是：

A. “世界触手可及”在2015年报中被列为核心价值观。

B. “做世界级综合信息服务提供商”在2015年报中的字段名称是企业形象口号。

C. “用户至上、用心服务”在2015年报中属于服务理念，并在2025年社会责任报告中继续出现。

D. 只要2025年仍使用某项服务理念，就能证明2015年全部文化字段都是2026年最新版本。

答案：C。

解析：A对应的是企业形象口号，B对应的是战略目标。单项用语的延续只能证明该项在新资料中出现，不能外推为全部文化字段均未变化。[T6] [T10]

### 第3题：战略与品牌

关于“云改数转智惠”和智能云体系，下列说法正确的是：

A. 五位一体指天翼、全球通、动感地带、沃派、神州行五个品牌。

B. 星辰大模型是10000客服号码的另一种名称。

C. “云改数转智惠”意味着中国电信停止提供通信服务。

D. 五位一体包括算力、平台、数据、模型、应用，分别处在相互协同的能力层次。

答案：D。

解析：五位一体是智能云体系的能力结构，不是客户品牌清单。战略是在通信与云网能力基础上扩展智能化服务；星辰属于模型相关名称，10000属于客户服务号码。[T8] [T9] [T10]

## 面试应对

### 问题1：如何区分中国电信集团与上市公司？

回答思路：说明两个法人、股份公司注册地及H股和A股时间线。

口述模板：中国电信集团有限公司是集团母公司，中国电信股份有限公司是境内注册的上市主体，二者不是同一法人。集团在2000年挂牌并于2002年经历重组，股份公司于2002年成立并在香港上市，2021年又在上海上市。香港上市不等于公司在香港注册。

### 问题2：怎样回答中国电信的企业文化？

回答思路：主动说明资料年份，分别给出2015年文化字段、2022年使命愿景语境和较近服务理念。

口述模板：中国电信的文化回答必须带版本。2015年报列示使命“让客户尽情享受信息新生活”、核心价值观“全面创新、求真务实、以人为本、共创价值”，服务理念是“用户至上、用心服务”；后者在2025年社会责任报告中仍有使用。2022年官方报道还列出红色电信精神，但它不是2015年核心价值观的同义替换。

### 问题3：如何理解“云改数转智惠”？

回答思路：解释云改、数转、智惠的协同关系，再落到智能云“五位一体”。

口述模板：“云改数转智惠”是中国电信在2025年中期提出升级、2026年中期继续使用的战略。它以云网融合为基础，推动自身和客户数字化转型，并把人工智能能力转化为服务。对应的智能云体系包括算力、平台、数据、模型、应用五个层次，天翼云、星辰大模型和息壤应分别按云、模型和算力平台理解。
