# 中国移动

## 概述

中国移动以通信网络和客户服务为基础，业务覆盖移动通信、家庭宽带、政企信息化、云与算力、数字内容及人工智能应用。识别中国移动，需要同时区分集团与上市公司、企业文化与年度战略、客户品牌与技术产品。

资料核验日期：2026-09-27。身份沿革主要依据2025年可持续发展报告和上市公司简介；较新战略采用2026年中期业绩口径；官网文化页未标更新时间，单独注明来源，不与年度战略愿景合并。

## 身份与沿革

### 集团与上市主体

| 层次 | 名称与性质 | 区分要点 |
| --- | --- | --- |
| 集团 | 中国移动通信集团有限公司 | 中央企业集团，是中国移动有限公司的最终控股股东。[M1] [M2] |
| 上市公司 | 中国移动有限公司 | 在香港注册成立，在香港、上海上市。集团母公司与上市公司是不同法人。[M2] |
| 报告中的“本集团” | 取决于报告定义 | 上市公司报告中的“本集团”通常指中国移动有限公司及其附属公司，不自动等于中国移动通信集团有限公司。[M2] |

集团名中的“通信集团”与上市公司名中的“有限公司”不是可随意省略或互换的修饰语。判断成立、上市、业务收入等信息时，应先确定资料描述的是哪个主体。

### 关键时间

| 时间 | 事件 | 所属层次 |
| --- | --- | --- |
| 1997-09-03 | 中国移动有限公司这一上市主体在香港注册成立。 | 上市公司。[M2] |
| 1997-10-23 | 在香港联合交易所上市。 | 上市公司，不是集团母公司。[M2] |
| 2000-04-20 | 中国移动集团成立。 | 集团沿革。[M1] |
| 2004年 | 主营业务资产整体上市。 | 集团主营业务资产的上市进程，不表示集团母公司变成上市公司。[M1] |
| 2022-01-05 | 中国移动有限公司A股在上海证券交易所上市。 | 上市公司。[M1] [M2] |

上市主体的注册时间早于集团成立时间，并不矛盾：两条时间线对应不同法人及资产组织过程。不能把1997年、2000年、2022年都写成“中国移动成立”的同一答案。

## 企业文化与服务

### 官网文化体系

以下为集团官网“企业文化理念”页面的列示口径，页面未标更新时间，核验于2026-09-27。[M3]

| 类别 | 官方表述 | 理解要点 |
| --- | --- | --- |
| 核心价值观 | 正德厚生、臻于至善 | 官网以“责任”和“卓越”说明文化内涵，分别强调履行责任与追求更高品质。 |
| 企业使命 | 创无限通信世界，做信息社会栋梁 | 前半句体现通信与信息服务能力，后半句体现服务信息社会的责任。 |
| 企业愿景 | 成为卓越品质的创造者 | 指向品质创造，不只是网络覆盖或客户规模。 |

“使命”说明企业承担什么责任，“愿景”说明希望成为什么样的企业，“价值观”说明行动和判断遵循什么原则。这是概念解释，不是对官方用语的改写。

### 服务品牌与口号

2023年官网服务报道使用“心级服务，让爱连接”，并回顾“沟通从心开始”等历史服务口号。[M6]

- “心级服务”属于服务品牌表达，不是上述核心价值观或企业使命的名称。
- 相关报道围绕精彩、智惠、便捷、透明、安全、应急六个方面介绍服务升级，体现服务内容与体验的具体化。
- “沟通从心开始”适合作为历史服务口号识别；不能仅凭熟悉程度，将其填入当前资料中的任意文化字段。

### 与2026年战略愿景的区别

2026年中期业绩资料以“世界一流科技服务企业”为愿景，并提出“网络强基、全栈创新”发展战略。[M4]

这里与文化页中的“成为卓越品质的创造者”属于不同资料场景。本卡分别保留出处：题目若指定“官网企业文化”，按文化页判断；若指定“2026年中期战略”，按当期资料判断。不推断两者在所有文件中互相替代。

## 战略内涵

### “网络强基、全栈创新”

2026年中期业绩资料提出发展通信、算力、智能三大服务，面向公众和政企两类客群，并推进通信网、算力网、智能网相关能力建设。[M4]

| 关键词 | 依据当期业务内容的解释 |
| --- | --- |
| 网络强基 | 将网络连接和基础设施能力作为服务基础，同时面向算力与智能服务扩展网络能力。不能仅理解为增加移动基站。 |
| 全栈创新 | 创新覆盖网络、算力、数据、算法及应用等相互衔接的环节，不仅是增加一款面向用户的应用。 |
| 通信服务 | 包括移动通信、宽带、物联网等连接服务。 |
| 算力服务 | 围绕数据中心、云与算力资源，以及相关服务和应用形成供给能力。 |
| 智能服务 | 围绕数据、算法和人工智能应用，延伸至行业应用、具身智能、数智文化等场景。 |

上述解释用于把战略词语与业务对象对应起来，不构成额外的官方战略定义。三类服务之间存在协同关系，也不等于各项收入必然能够按名称直接相加。

### CHBN与三大服务

2024年度业绩资料使用CHBN四大市场的经营视角，并于2025-03-20在集团官网发布。[M7]

| 字母 | 对应市场 | 识别要点 |
| --- | --- | --- |
| C | 个人市场 | 面向个人用户的通信和相关服务。 |
| H | 家庭市场 | 面向家庭的宽带、组网和数字生活服务。 |
| B | 政企市场 | 面向政府与企业客户的信息服务。 |
| N | 新兴市场 | 当期资料包括国际业务、数字内容、金融科技、股权投资等。 |

CHBN主要按市场和经营领域组织认识；通信、算力、智能主要按服务能力和内容组织认识。二者不是字母与数字的一一翻译，也不能仅根据2026年采用新表述，就推断CHBN在所有业务管理中已经取消。

## 易混辨析

1. 2000年是集团成立时间，1997年是上市主体注册及香港上市的时间；2004年“主营业务资产整体上市”不是集团母公司整体变成上市公司。
2. “正德厚生、臻于至善”是核心价值观；“创无限通信世界，做信息社会栋梁”是使命；“心级服务，让爱连接”是服务品牌口号。
3. “成为卓越品质的创造者”来自文化页；“世界一流科技服务企业”来自2026年战略资料，作答需匹配题目给定材料。
4. 全球通、动感地带、神州行是客户品牌；移动云、九天、咪咕分别侧重不同业务能力与场景。
5. CHBN四大市场不等于通信、算力、智能三大服务，也不等于通信网、算力网、智能网三类网络能力。

## 自编笔试题

以下均为单项选择题，依据本卡注明年份的资料编写，不是官方真题。

### 第1题：主体与时间

关于中国移动身份沿革，下列说法正确的是：

A. 中国移动通信集团有限公司与中国移动有限公司是同一法人。

B. 上市主体于1997年在香港注册及上市，集团成立于2000年，这些事件属于不同主体的时间线。

C. 2022年A股上市是中国移动集团首次成立。

D. 2004年主营业务资产整体上市，意味着集团母公司与上市公司从此成为同一法人。

答案：B。

解析：集团与上市公司必须分开识别。1997年对应上市主体注册及香港上市，2000年对应集团成立，2022年对应上市公司A股上市；资产上市不消除母公司与上市公司的法人区别。[M1] [M2]

### 第2题：文化与服务

根据集团官网文化页及服务资料，下列对应关系正确的是：

A. 核心价值观是“正德厚生、臻于至善”，内地公众客服号码为10086。

B. 企业使命是“心级服务，让爱连接”，内地公众客服号码为10010。

C. 动感地带是企业愿景，全球通是企业使命。

D. “成为卓越品质的创造者”是神州行的品牌口号。

答案：A。

解析：文化页列示的价值观、使命、愿景具有固定字段；客户品牌和服务口号不能替代这些字段。10086为中国移动客服号码；10010属于中国联通。[M3] [M5] [M6]

### 第3题：战略层次

关于2026年中期业绩中的战略表述，下列理解正确的是：

A. CHBN中的四个字母分别对应通信、算力、智能、安全四大服务。

B. “网络强基”仅涉及手机语音，不包含其他网络能力。

C. “全栈创新”意味着云、数据和算法与业务创新无关。

D. 通信、算力、智能属于服务体系视角，与CHBN的市场划分不能机械一一对应。

答案：D。

解析：2026年资料使用通信、算力、智能三大服务体系；CHBN是较早资料中的个人、家庭、政企、新兴市场视角。不同维度之间可交叉，不能直接互译。[M4] [M7]
