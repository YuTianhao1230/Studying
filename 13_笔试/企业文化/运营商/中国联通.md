# 中国联通

## 概述

中国联通是中央企业体系下的电信运营商，业务覆盖公众通信、家庭服务、政企数字化、云与算力、数据和人工智能应用等领域。其近年发展重点是依托连接能力，向数字化综合服务商转型。[U1] [U4]

资料核验日期：2026-09-27。主体结构与文化主要依据2025年报，核心价值观保留2024年报的明确列示口径；较新战略结合2026年中期业绩。集团历史另用国资委资料交叉核对。

## 身份与沿革

### 四个容易混淆的主体

| 层次 | 法定名称 | 区分要点 |
| --- | --- | --- |
| 集团 | 中国联合网络通信集团有限公司 | 集团母公司，不等于A股或港股上市公司。[U1] [U8] |
| A股上市公司 | 中国联合网络通信股份有限公司 | 境内注册的上市主体，股票代码600050。[U1] [U6] |
| 港股上市公司 | 中国联合网络通信（香港）股份有限公司 | 香港注册的上市主体，股票代码00762。[U1] [U3] |
| 境内运营公司 | 中国联合网络通信有限公司 | 港股公司的全资附属公司，承担境内运营业务；名称中没有“股份”二字。[U1] |

A股公司和港股公司是不同法人。两者存在通过中间持股实体形成的股权联系，不能简化成“同一家中国联通公司同时发行A股和H股”，也不能忽略中间层而把间接持股一律写成直接持股。

年报中的“本公司”“本集团”必须按该报告定义理解。例如港股年报的“本公司”指港股上市主体，“本集团”通常指该公司及其附属公司，不是所有叫“中国联通”的法人主体的统称。[U1]

### 关键时间

| 时间 | 事件 | 所属层次 |
| --- | --- | --- |
| 1994年 | 中国联通的历史起点。 | 企业历史，不是当前港股公司的注册日期。[U9] |
| 2000-02-08 | 港股上市主体在香港注册成立。 | 港股公司。[U1] [U3] |
| 2000-06-22 | 港股上市主体在香港联合交易所上市。 | 港股公司。[U1] [U3] |
| 2008-10-15 | 港股公司与中国网通集团（香港）有限公司完成合并。 | 上市主体层面的合并，不与集团组建日期混写。[U1] [U3] |
| 2009-01-06 | 中国联合网络通信集团有限公司组建。 | 原联通与原网通重组后的集团层面节点。[U7] [U8] |
| 2017年 | 推进混合所有制改革，通过A股公司引入战略投资者。 | 涉及股份发行、股份转让等安排；混改不是将港股和A股合成同一法人。[U1] |
| 2021-05-18 | 港股公司在纽约证券交易所交易的美国存托证券退市。 | 不能继续把旧材料中的三地上市状态当成现状。[U3] |

“1994年成立”“2000年上市”“2008年合并”“2009年组建”可以同时成立，但回答的是不同主体、不同性质的历史事件。2017年混改也不等于集团不再属于中央企业体系。

## 企业文化与服务

### 2025年报列示的使命、愿景与作风

以下依据2025年年度报告“企业文化”页，报告于2026年发布。[U1]

| 类别 | 官方表述 | 理解要点 |
| --- | --- | --- |
| 企业使命 | 数字信息运营服务国家队、数字技术融合创新排头兵 | 同时强调数字信息服务责任与数字技术融合创新。 |
| 企业愿景 | 具有全球竞争力的世界一流科技服务企业 | 不能只概括为传统通信管道运营商。 |
| 企业作风 | 严实精细快 | 属于工作作风要求，不应改标为核心价值观。 |

“国家队”“排头兵”描述的是企业在数字信息服务与技术创新中的角色，不是独立业务品牌，也不是客服口号。

### 2024年报列示的核心价值观

2024年年度报告“企业文化”页明确列出六项核心价值观：[U2]

| 官方表述 | 理解侧重 |
| --- | --- |
| 客户为本 | 以客户需求和客户价值为出发点。 |
| 员工为根 | 重视员工及其能力对企业发展的支撑。 |
| 服务为上 | 将服务质量与服务价值放在重要位置。 |
| 创新为魂 | 通过创新推动企业发展。 |
| 奋斗为荣 | 倡导担当与实干。 |
| 清廉为基 | 强调廉洁与规范经营的基础作用。 |

同页还列出经营理念：“为客户创造价值”“市场和创新双轮驱动”“一个联通，一体化能力聚合、一体化运营服务”。[U2]

这六项价值观与经营理念均按2024年报口径记录。2025年报文化页没有以同样方式完整列出六项价值观，不能仅据缺省判断它们已被废止，也不能把2024年页签直接称为2026年新发布版本。

### 服务导向与品牌表达

“为客户创造价值”在2024年报中属于经营理念。[U2] 2025年报还使用“精准找到需求、快速弄懂需求、高效满足需求”等客户服务表达。[U1]

国资委2026年品牌资料回顾，中国联通于2019年提出“创新与智慧同行”品牌语。[U9] 它属于品牌传播表达，不等于企业使命、愿景或六项核心价值观。本卡不将不同资料中的服务表述拼成一条未经官方列示的“统一服务口号”。

## 业务品牌与服务号码

2025年报区分企业品牌、客户品牌和产品品牌；2026年中期业绩还介绍了算力、模型与行业应用相关能力。[U1] [U4]

| 名称 | 层次与定位 | 易混点 |
| --- | --- | --- |
| 中国联通 / UniCom | 2025年报列示的企业品牌。 | 企业品牌不等于某一个具体上市法人的完整名称。 |
| 联通智家 | 家庭场景客户品牌。 | 不等于单项宽带资费或一个云计算平台。 |
| 联通沃派 | 客户品牌，侧重年轻群体相关服务。 | “沃派”不是集团名称或人工智能模型名称。 |
| 联通慧商 | 2025年报列示的客户品牌。 | 具体产品、资费及适用客户以业务资料为准，不仅凭名称扩大其范围。 |
| 联通云 | 云服务相关产品品牌。 | 与天翼云、移动云分属不同运营商。 |
| 联通元景 | 大模型及MaaS相关品牌。 | MaaS在此指模型即服务，不是移动通信客户品牌。 |
| 联通星罗 | 算力调度相关平台名称。 | 与元景的模型能力层次不同。 |
| 云犀 | 工作流智能体等智能应用相关名称。 | 不应与联通云这一云品牌混为同名产品。 |
| 格物 | 工业领域平台与应用相关名称。 | 属于行业数字化能力，不是公众客服号码。 |
| 墨攻 | 安全相关产品品牌。 | 不能因有独立安全品牌，就把企业安全职责全部等同于该产品。 |
| 10010 | 内地公众客户服务热线。 | 来自官方联系页面；与投资者关系联系电话不是同一用途。[U5] |

“沃”相关名称常见于中国联通历史品牌材料，但不能据此把不同时期的全部品牌矩阵都简化成一个“沃”字。学习时应保留企业、客户、产品、平台的层次。

## 战略内涵

### 发展主基调与转型方向

2025年报以“守正创新、行稳致远”为“十五五”发展主基调，聚焦连接、算力、服务、安全四大核心赛道。[U1] 2026年中期业绩延续上述赛道布局，提出向数字化综合服务商转型。[U4]

| 表述 | 结合业务内容的理解 |
| --- | --- |
| 守正创新 | 在履行基础通信与信息服务责任的同时，推进技术、产品和服务创新。 |
| 行稳致远 | 强调稳健经营与长期发展，不能仅以短期规模扩张解释。 |
| 数字化综合服务商 | 在连接业务基础上，组合算力、数据、模型、应用与服务能力，解决客户的综合数字化需求。 |

以上是理解层面的归纳，不替代年报中的正式表述。“发展主基调”“企业使命”“业务赛道”“转型方向”分别回答不同问题。

### 四大核心赛道

| 赛道 | 业务位置 | 辨析 |
| --- | --- | --- |
| 连接 | 移动、宽带及相关连接能力构成客户服务基础。 | 不只指手机语音或单一接入方式。 |
| 算力 | 云、计算资源、调度及模型相关能力。 | 不只是购买服务器，也不与某一个模型品牌等同。 |
| 服务 | 将能力转化为客户和行业的综合解决方案及服务体验。 | 不只是客服热线或售后接听。 |
| 安全 | 为网络、数据、平台和应用提供安全保障与相关服务。 | 既有安全产品，也有跨业务的安全要求。 |

四大赛道是经营发展重点，不代表四个完全隔离的收入科目。联通星罗、元景、云犀、格物、墨攻等体现不同层次的能力，不能将品牌数量与赛道数量机械对应。[U1] [U4]

### 与2024年材料的区别

2024年报文化页使用“融合创新”战略表述，愿景为“加快成为具有全球竞争力的世界一流科技服务企业”。[U2] 2025年报的文化与战略版面则采用本卡前述使命、愿景和发展主基调。[U1]

同一企业不同年度的资料可以保留相近方向而改变具体措辞。题目如果明确指定2024年报，应按2024年资料判断；引用2025年报或2026年中期战略时，不将历史短语当成所有年份的唯一答案。

## 易混辨析

1. “集团有限公司”“股份有限公司”“（香港）股份有限公司”“有限公司”对应不同法人，不能只因都简称“中国联通”就互相替代。
2. 中国联通A股和港股不是同一法人发行的A股、H股；股权联系也不能一律写成直接控股。
3. 1994年历史起点、2000年港股主体注册上市、2008年上市公司合并、2009年集团组建不是同一个日期问题。
4. “数字信息运营服务国家队、数字技术融合创新排头兵”是2025年报使命；“严实精细快”是作风；“创新与智慧同行”是品牌语。
5. 六项核心价值观按2024年报口径识别；连接、算力、服务、安全是较新资料中的四大核心赛道。
6. 联通智家、沃派、慧商属于客户品牌；联通云、元景等属于不同产品与能力层次；内地公众客服号码为10010。

## 自编笔试题

以下均为单项选择题，依据本卡注明年份的资料编写，不是官方真题。

### 第1题：法人结构

关于中国联通主体结构，下列说法正确的是：

A. 中国联合网络通信集团有限公司就是股票代码600050对应的上市法人。

B. A股公司和港股公司只是同一法人的两种简称。

C. A股公司与港股公司是不同法人，境内运营公司的名称又与二者不同。

D. 港股公司美国存托证券在2021年退市，意味着中国联通集团于同年解散。

答案：C。

解析：集团、A股公司、港股公司、境内运营公司须分别识别。存托证券退市是证券市场事件，不是集团解散；A股和港股的结构不能照搬同一公司发行A股、H股的模式。[U1] [U3] [U6]

### 第2题：文化层次

根据2024年及2025年年报，下列对应关系正确的是：

A. “严实精细快”是2025年报中的六项核心价值观。

B. “客户为本、员工为根、服务为上、创新为魂、奋斗为荣、清廉为基”是2024年报列示的核心价值观。

C. “创新与智慧同行”是2025年报列示的企业使命。

D. “联通沃派”是企业愿景，“10010”是算力平台名称。

答案：B。

解析：六项核心价值观来自2024年报；“严实精细快”在2025年报中属于企业作风；“创新与智慧同行”是品牌语；沃派和10010分别属于客户品牌与客服号码。[U1] [U2] [U5] [U9]

### 第3题：战略与产品

关于2025年报及2026年中期业绩中的发展重点，下列说法正确的是：

A. 四大核心赛道是连接、算力、服务、安全，星罗与元景分别体现算力调度和模型服务等不同能力。

B. 四大核心赛道就是全球通、动感地带、神州行、天翼四个客户品牌。

C. “服务”赛道仅指拨打客服热线，不包括行业综合服务。

D. “守正创新、行稳致远”是港股上市主体的法定名称。

答案：A。

解析：赛道划分与品牌名称、法人名称属于不同层次。联通星罗、联通元景等服务于不同能力环节；服务赛道也不能缩减为单一热线功能。[U1] [U4]

## 面试应对

### 问题1：为什么中国联通的主体结构容易混淆？

回答思路：依次说明集团、A股公司、港股公司和境内运营公司，并指出A股与港股并非同一法人。

口述模板：中国联通至少要区分四个主体：集团母公司中国联合网络通信集团有限公司，A股上市公司中国联合网络通信股份有限公司，港股上市公司中国联合网络通信（香港）股份有限公司，以及承担境内运营的中国联合网络通信有限公司。A股和港股公司存在股权联系，但不是同一法人发行A股和H股，回答时不能省略主体层次。

### 问题2：如何概括中国联通的企业文化？

回答思路：按2025年使命愿景作风、2024年核心价值观分别作答。

口述模板：2025年报列示的使命是“数字信息运营服务国家队、数字技术融合创新排头兵”，愿景是“具有全球竞争力的世界一流科技服务企业”，作风是“严实精细快”。六项核心价值观来自2024年报，包括客户为本、员工为根、服务为上、创新为魂、奋斗为荣、清廉为基。两个年份的字段应分别引用。

### 问题3：怎样理解中国联通的四大核心赛道？

回答思路：逐项说明连接、算力、服务、安全，再关联产品品牌但不做机械映射。

口述模板：中国联通在2025年报和2026年中期资料中聚焦连接、算力、服务、安全四大核心赛道。连接是基础，算力承载云、计算和调度能力，服务把能力转化为客户解决方案，安全贯穿网络、数据、平台和应用。联通星罗、元景、云犀、格物、墨攻体现不同能力层次，但品牌数量与赛道并非一一对应。
