# 中国农业银行

## 概述

中国农业银行是以服务“三农”为重要历史基础、同时经营城乡综合金融业务的国有大型商业银行。其前身可追溯至1951年成立的农业合作银行，1979年恢复成立，2009年整体改制，2010年在上海和香港先后上市。这些节点分别对应前身、恢复建制、公司制改革和资本市场上市，不能合并成一个“成立日期”。[^1][^2]

农行的组织特色不是只在农村开网点，而是在综合性商业银行内部持续配置面向农业、农村和农民的服务资源，同时服务城市客户、企业和金融市场。“面向‘三农’”与“服务城乡”并列，意味着专业特色与综合经营同时存在。[^1][^3]

资料核验日期：2026-09-27。文化原文依据官网“企业文化核心理念”；战略使用官网公司概述所载2025年度口径。下文内涵说明为依据来源整理的知识解析。

### 时间轴

| 时间 | 事件 | 区分要点 |
| --- | --- | --- |
| 1951年7月10日 | 前身农业合作银行建立 | 农行官方历史追溯的起点；当时名称不是今天的股份公司全称 |
| 1955年3月 | 以“中国农业银行”名称建立 | 此后仍经历建制调整，不是1951年至今机构形态始终不变 |
| 1963年11月 | 中国农业银行再次建立 | 与早期多次合并、恢复的历史相联系 |
| 1979年2月23日 | 国务院发出《关于恢复中国农业银行的通知》 | 对应恢复建立，而不是最早前身的成立 |
| 1994年4月 | 向新组建的中国农业发展银行划转绝大部分政策性业务 | 帮助理解商业性支农与政策性支农的组织分工 |
| 1996年8月 | 不再领导管理农村信用社，脱离行政隶属关系 | 农村信用社不是农行分支机构 |
| 2009年1月15日 | 中国农业银行股份有限公司成立 | 对应股份公司成立；不能替代1951年前身或1979年恢复节点 |
| 2010年7月15日、16日 | A股、H股分别在上海、香港挂牌上市 | 顺序为先上海、后香港，两地并非同一天上市 |

以上日期和事件逐项取自官网“农行历程”。[^2] 1952年、1957年和1965年分别发生与人民银行合并的建制调整，因而不宜将农行写成“自1951年起一直以同一机构形态连续经营”。[^2]

### 与其他涉农金融机构的关系

农业银行与农业发展银行不是简称不同的同一家银行。农行的沿革明确记载政策性业务向新组建的农发行划转；农行此后的发展方向是商业银行。农村信用社同样不能视为农行基层网点，1996年的行政隶属关系调整是辨析这一点的直接历史依据。[^2]

服务“三农”也不等于贷款自动获得财政兜底。农行必须在风险可控、商业可持续的条件下开展服务；“稳健行远”的文化要求与“三农”定位并不矛盾。

## 企业文化

### 官方精确表述

| 层级 | 官网原文 |
| --- | --- |
| 使命 | “面向‘三农’，服务城乡，回报股东，成就员工。” |
| 愿景 | “建设国际一流商业银行集团。” |
| 核心价值观 | “诚信立业，稳健行远。” |
| 经营理念 | “以市场为导向，以客户为中心，以效益为目标。” |
| 管理理念 | “细节决定成败，合规创造价值，责任成就事业。” |
| 服务理念 | “客户至上，始终如一。” |
| 风险理念 | “违规就是风险，安全就是效益。” |
| 人才理念 | “德才兼备，以德为本，尚贤用能，绩效为先。” |
| 廉洁理念 | “清正廉洁，风清气正。” |

以上依据“企业文化核心理念”栏目，使命内层引号为排版调整。[^3]

### 内涵解析

使命的前半句说明服务方向，后半句说明价值创造对象。“面向‘三农’”保持历史责任与特色市场定位，“服务城乡”说明业务不局限于农村；“回报股东、成就员工”体现现代商业银行的治理与人才发展要求。四个分句应整体理解，不能将“面向‘三农’”单独当作全部使命。

“诚信立业”将信用和真实经营放在银行关系的基础位置；“稳健行远”强调持续经营能力。与此配套的管理理念把细节、合规、责任联系起来：规则执行不是业务完成后的附加环节，而是授信、支付、客户服务等活动本身的一部分。

“违规就是风险，安全就是效益”是风险理念，不是核心价值观原文。它强调违规会形成经营隐患以及安全对长期效益的意义，不能反向推断“合规项目必然没有信用风险”或“风险管理可以保证永不发生损失”。

## 战略定位与业务品牌

### 一个主题、两大定位、三大战略

官网公司概述的2025年度口径列示如下。[^1]

| 层级 | 表述 | 内涵解析 |
| --- | --- | --- |
| 主题 | 高质量发展 | 服务能力、风险约束与经营可持续性共同影响发展质量，不能只看资产扩张 |
| 定位一 | “服务乡村振兴的领军银行” | 将服务农业农村现代化与县域发展作为重要特色和责任 |
| 定位二 | “服务实体经济的主力银行” | 业务覆盖城乡及多类实体经济主体，不能把农行缩成只做农业融资的专门机构 |
| 战略一 | “‘三农’普惠” | 联系“三农”需求与金融服务可得性，兼顾服务覆盖和可持续经营 |
| 战略二 | “绿色金融” | 服务经济社会绿色转型，将环境因素纳入金融服务和经营管理 |
| 战略三 | “数字经营” | 运用数据与技术改变经营、服务和管理方式，而不只是增加手机银行功能 |

“三农”普惠在这里是一项战略，不能拆成“三农”和“普惠”两大战略，继而把农行“三大战略”记成四项。上述三项也不是金融“五篇大文章”的完整名称。

### 三农金融事业部的组织含义

官网历程记载，农行于2008年开展“三农”金融事业部改革试点，并于当年8月在总行设立“三农”金融事业部。[^2] 这里的“事业部”是商业银行内部围绕特定业务和客群建立的组织安排，核心是让服务“三农”有专门的职责承接和资源配置，不是又成立了一家独立的银行。

从组织逻辑看，按地区设置的分支机构解决“在哪里服务”，围绕业务或客群设置的专业条线解决“如何专业化服务”。两者可以交叉协同，因此县域支行与三农业务条线不能当成互相替代的两套机构。

### 品牌与客群对应

| 名称 | 官网定位 | 辨析 |
| --- | --- | --- |
| 金钥匙 | 个人金融品牌，提供满足个人多元化、个性化需求的金融产品和服务 | 不是单一银行卡或贷款名称 |
| 金钥匙宣传语 | “开启财富 引领生活” | 属于品牌宣传语，不是农行使命 |
| 金益农 | 面向“三农”客户的金融服务品牌，是农行旗下二级品牌 | 服务范围包括生产生活、现代农业、农村流通、中小企业、基础设施等，不只覆盖农户种植 |
| 金益农宣传语 | “惠农天下，益农万家” | 不能与全行价值观“诚信立业，稳健行远”混用 |
| “大行德广 伴您成长” | 官网品牌释义中使用的全行品牌传播表述 | 有品牌文化含义，但不是官网“核心价值观”字段的原文 |

金钥匙依据官网简介内嵌的品牌展示，金益农依据官网2015年品牌释义页面；后者用于说明已有品牌内涵，不据此宣称2026年全部产品或营销安排未变化。[^1][^4]

金益农的“益”包括益友良伴与互益共赢，官网按“益农、益行、益国”解释其关系：客户获得金融支持，银行形成可持续服务能力，国家与社会获得农村经济发展的效益。它体现的是多方价值关系，而不是“所有涉农业务都无偿提供”。[^4]

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 农行的最早前身成立于1979年 | 最早追溯至1951年的农业合作银行，1979年是恢复节点 |
| 2009年股份公司成立后立即同年上市 | 上市在2010年7月，且沪港相隔一天 |
| 农行、农发行、农信社是一套机构 | 三者组织身份不同，农行官方沿革明确记载业务划转和脱离行政隶属关系 |
| 服务城乡意味着取消“三农”特色 | 两者同属使命，相互补充 |
| “客户至上，始终如一”是核心价值观 | 它是服务理念；核心价值观是“诚信立业，稳健行远” |
| 金益农只是一项农户贷款 | 它是覆盖多类涉农需求的金融服务品牌 |
| 三大战略就是三项具体产品 | 战略决定服务与经营方向，品牌、产品是不同层级的具体承载 |

## 笔试自测

以下3题均为自编单项选择题，不是银行公布的真题。

### 自编题1：沿革与上市

关于农行历史，下列说法正确的是：

A. 1951年成立的前身名称是中国农业银行股份有限公司  
B. 1979年是恢复成立的重要节点，2010年7月先在上海、后在香港上市  
C. 1996年农村信用社改成农业银行的分支机构  
D. 农业银行于2009年1月在沪港两地同日上市

答案：B。

解析：1951年前身为农业合作银行；1996年是脱离行政隶属关系；2009年是股份公司成立，2010年7月15日、16日分别为A股、H股上市。[^2]

### 自编题2：文化字段

根据农行官网“企业文化核心理念”，下列配对正确的是：

A. 核心价值观：诚信立业，稳健行远  
B. 风险理念：客户至上，始终如一  
C. 服务理念：细节决定成败，合规创造价值，责任成就事业  
D. 愿景：面向“三农”，服务城乡，回报股东，成就员工

答案：A。

解析：B对应服务理念，C对应管理理念，D对应使命。愿景是“建设国际一流商业银行集团”。[^3]

### 自编题3：战略与品牌

按照本卡采用的官网2025年度公司概述及品牌释义，下列理解正确的是：

A. “‘三农’普惠”应拆成两大战略，再与绿色金融组成三大战略  
B. “金钥匙”只服务涉农企业，“金益农”只服务城市高净值客户  
C. 农行三大战略是“三农”普惠、绿色金融、数字经营，金益农属于面向“三农”的服务品牌  
D. 金益农是与农业银行并列的独立银行

答案：C。

解析：题干要求区分全行战略、服务品牌与法人机构。三农普惠是一项战略，金益农是农行旗下品牌；金钥匙对应个人金融。[^1][^4]
