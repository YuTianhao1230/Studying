# 六大行企业文化与特色知识

## 概述

六大行均为国有大型商业银行，但历史来源、文化表述、客群特色及组织模式不同。本目录把这些知识分为六张银行卡片，本页用于横向对照；各卡包含历史、文化原文与内涵、战略品牌、易混点及3道自编单项选择题，共18题。

资料核验日期：2026-09-27。引文使用银行官网、官方招聘页、年报和社会责任报告；阶段性战略明确标注资料年份。官网栏目未注明发布日期时，只表示核验当日可见，不据此推定首次启用日期。具体引用与支持范围见各卡末尾。

## 共同概念辨析

| 概念 | 含义与边界 |
| --- | --- |
| 金融“五篇大文章” | 科技金融、绿色金融、普惠金融、养老金融、数字金融，是重点服务领域；不等于某家银行的“五化” |
| 科技金融与金融科技 | 前者侧重服务科技创新主体和活动，后者侧重技术对金融经营的赋能 |
| 综合化经营 | 用不同专业能力满足多种金融需求；不能理解为任一分行拥有集团全部牌照 |
| 全球化或国际化 | 跨市场布局和服务能力；不意味着免受当地监管或跨境风险约束 |
| 服务“三农” | 面向农业、农村、农民；并非农行独占业务，也不等于政策性银行身份 |
| 普惠金融 | 改善金融服务可得性与适配性；不等于所有申请无条件获批 |
| 零售银行 | 突出个人等零售客群服务；不等于只能做储蓄或完全没有公司业务 |
