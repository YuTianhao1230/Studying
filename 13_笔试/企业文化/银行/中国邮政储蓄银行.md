# 中国邮政储蓄银行

## 概述

中国邮政储蓄银行是在改革原邮政储蓄管理体制基础上，于2007年挂牌成立的银行。邮政储金业务可以追溯至1919年，但业务历史不等于今天银行法人的成立历史。2012年整体改制、2016年H股上市和2019年A股上市，分别属于公司制改革与资本市场发展节点。[^1]

邮储的组织特色，是依托“自营+代理”模式服务“三农”、城乡居民和中小企业，将银行自营渠道与邮政网络的服务覆盖相结合。“大型零售银行”说明其零售定位突出，不意味着只吸收个人存款、不经营公司业务，也不意味着所有邮政网点都是银行自营网点。[^1][^3]

资料核验日期：2026-09-27。文化引文采用官网“企业文化理念”；“六化”升级采用2026年3月发布的2025年度业绩公告，并与核验时官网简介交叉核对。品牌部分使用官方既有专题说明，不据此推断全部产品权益、准入条件始终不变。

| 时间 | 事件 | 不应混淆的概念 |

### “自营+代理”的组织内涵

“自营”是银行通过自身机构开展经营与服务；“代理”是依托邮政企业的相关网点，按委托安排代理办理约定范围的基础金融业务。中国邮政官方说明将邮储银行的“自营+代理”、中邮保险的“自营+代管”、中邮证券的“自营+协同”分别列示，说明它们属于不同业务主体的组织安排。[^3]

这一模式的作用，是将银行的专业金融服务能力与邮政网络的城乡覆盖相结合，使部分金融服务可以更接近客户。它并不意味着所有邮政业务都变成银行业务，也不意味着代理网点可以自行扩大授信、理财或其他业务权限。办理何种业务、由谁承担相应职责，仍应按机构授权与具体业务规则识别。

从组织管理看，两类渠道共同服务客户，更需要在服务标准、风险控制、消费者权益保护及协同衔接上保持一致。渠道广泛是服务条件，持续、合规地满足需求才是经营能力。

## 企业文化

### 官方精确表述

以下全部取自官网《中国邮政储蓄银行企业文化理念》。[^2]

| 层级 | 官方原文 |
| --- | --- |
| 使命 | “普惠城乡，让金融服务没有距离” |
| 愿景 | “建设客户信赖、特色鲜明、稳健安全、创新驱动、价值卓越的一流大型零售银行” |
| 企业精神 | “有担当，有韧性，有温度” |
| 品牌主张 | “进步 与您同步” |

官网价值观为六个完整分句，不能只用几个概括词替代原文：

| 价值观原文 | 内涵解析 |
| --- | --- |
| 为客户创造价值 | 从客户实际需求和长期利益出发评价服务，而不只看产品销量 |
| 诚信是立业之基 | 信用关系、真实信息与履行承诺构成银行经营基础 |
| 因为稳健，所以持久 | 风险管理与持续经营相联系，不能以短期扩张损害长期安全 |
| 员工是最重要的资本 | 人才能力、专业成长和组织参与是服务质量的重要来源 |
| 专业才能卓越 | 产品、风险、运营和服务均需要专业判断与持续学习 |
| 拥抱变化，持续创新 | 适应技术、市场和客户变化，不把既有渠道优势视为永久不变的竞争力 |

### 使命、愿景与应用理念怎样联系

“普惠城乡”说明服务覆盖及可得性，“让金融服务没有距离”既涉及地理上的接近，也可以从线上线下衔接和使用便利性理解。它不是“所有人都必然获得贷款”的授信承诺，服务普惠仍须与风险管理相结合。

愿景中的“客户信赖、特色鲜明、稳健安全、创新驱动、价值卓越”共同修饰“一流大型零售银行”，不宜漏掉一部分后声称是完整原文。零售定位强调个人等客群服务的重要性，但公司金融也可围绕产业、企业经营和零售客户需求形成协同。

官网还列出应用理念，体现文化如何落实到组织运作。[^2]

| 类型 | 官方原文 |
| --- | --- |
| 管理理念 | “删繁就简，让管理变轻” |
| 经营理念 | “洞悉市场，先行一步” |
| 风险理念 | “审慎合规是行稳之道，驾驭风险是致远之路” |
| 服务理念 | “竭诚竭心竭力，让客户满意” |
| 人才理念 | “尊重员工价值，开发员工潜能，成就员工梦想” |
| 协同理念 | “胸怀全局，同心同向，共享共进” |

“让管理变轻”指提高管理效率，不能解释为减少必要的合规与风控；“有温度”强调服务体验，也不能凌驾于客户身份识别、适当性或消费者权益保护规则之上。

## 战略与业务品牌

### “六化”升级：2026年发布的阶段口径

2026年3月30日官网《邮储银行发布2025年度业绩》在展望“十五五”时提出全面推进“六化”升级，实现从规模驱动转向价值驱动。核验时官网简介也列出相同六项。[^1][^4]

| 方向 | 官方公告对应的组织与经营内涵 |
| --- | --- |
| 特色化 | 做强“三农”、城乡居民和中小企业金融，协同邮政集团商流、物流、资金流、信息流资源 |
| 轻型化 | 发展“轻资本”“轻资产”“轻负债”业务，拓展非利息收入来源；不是取消存贷款业务 |
| 综合化 | 从单一产品供给向综合金融服务、从融资中介向服务中介转变 |
| 生态化 | 将金融嵌入客户生产经营和社会网络，围绕全链条、全场景、全周期需求提供服务 |
| 精细化 | 通过科学管理形成集约高效、专业智能、服务卓越、创新驱动的现代银行管理体系 |
| 数智化 | 建设自主可控、安全稳健的金融科技平台及全域智能、开放融合的数字生态银行 |

金融“五篇大文章”是科技金融、绿色金融、普惠金融、养老金融、数字金融，属于重点服务领域；“六化”属于转型路径。这一公告不能继续概括成“五化”，也不能把工行的五化内容移植给邮储。[^4]

公告同时提出持续完善“全面、全程、全时、全域”的风险管理体系，表明转型与风险约束需要共同推进。“轻型化”不是“轻视风险”，“生态化”也不是对合作伙伴的全部经营活动承担无限责任。[^4]

### 品牌、客群与服务场景

以下依据官网“绿色让生活更美好”品牌专题中的产品与服务说明，该专题含2022年阶段材料。[^5]

| 名称 | 对应领域 | 应当区分的边界 |
| --- | --- | --- |
| 邮银财富 | 专业、普惠的财富管理业务品牌，强调为客户创造价值 | 不是一个固定收益率的单一产品 |
| U+卡 | 面向新市民客群的专属借记卡及相关综合服务 | 是借记卡，不应直接等同信用卡或贷款 |
| 邮车贷 | 个人汽车消费贷款业务品牌 | 对应汽车消费融资，不是寄递物流业务 |
| 邮享贷 | 服务购物、装修、交通、教育等多样化消费贷款需求 | 属于消费融资，仍须符合具体申请与用途要求 |
| 邮惠客户“+计划” | 以基础存贷、交易银行、投资银行等产品体系支撑的公司综合金融服务 | 说明邮储具有公司金融服务，不是只面向个人储户 |

品牌把若干产品和服务组织起来，产品则有具体的期限、费用、用途、风险和合同责任。记忆品牌定位即可建立知识关联，不能据专题旧文推断2026年所有额度、权益或办理条件完全相同。

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 邮储银行成立于1919年 | 1919年是邮政储金业务起点，银行于2007年挂牌成立 |
| 2007年已经是股份有限公司 | 最初为有限责任公司，2012年整体改制 |
| 2016年A股上市、2019年H股上市 | 顺序相反：2016年H股、2019年A股 |
| 邮政集团与邮储银行的文化口号可以互换 | “人民邮政为人民”是邮政服务宗旨；邮储银行使命为“普惠城乡，让金融服务没有距离” |
| 自营+代理说明所有邮政网点都是银行自营机构 | 自营与代理的组织身份和业务权限不同 |
| 大型零售银行只做个人储蓄 | 零售是突出定位，仍经营公司等综合金融服务 |
| “进步 与您同步”是核心价值观 | 是品牌主张，价值观为官网列示的六个分句 |
| 2026年业绩公告的转型方向仍应记成“五化” | 该公告明确列出“六化”升级，需按资料年份识别 |

## 笔试自测

以下3题均为自编单项选择题，不是银行公布的真题。

### 自编题1：历史沿革

关于邮储银行，下列说法正确的是：

A. 1919年中国邮政储蓄银行股份有限公司正式成立  
B. 2007年银行挂牌成立，2012年整体改制，2016年H股、2019年A股上市  
C. 2012年在香港、上海同日上市  
D. 2019年首次开办邮政储金业务

答案：B。

解析：1919年、2007年、2012年、2016年、2019年分别对应业务追溯、银行成立、股份制改革、H股上市、A股上市。[^1]

### 自编题2：文化字段

依据邮储官网企业文化，下列配对正确的是：

A. 使命：进步 与您同步  
B. 品牌主张：有担当，有韧性，有温度  
C. 企业精神：为客户创造价值  
D. 使命：普惠城乡，让金融服务没有距离

答案：D。

解析：“进步 与您同步”为品牌主张，“有担当，有韧性，有温度”为企业精神，“为客户创造价值”为六项价值观之一。[^2]

### 自编题3：组织与转型

根据本卡引用的官方简介及2026年3月业绩公告，下列理解正确的是：

A. 自营+代理意味着代理网点可以自行开展一切银行业务  
B. 轻型化意味着停止所有存贷款业务  
C. 六化包括特色化、轻型化、综合化、生态化、精细化、数智化  
D. 综合化与大型零售银行定位相互矛盾

答案：C。

解析：六化的完整名称见公告；代理模式仍有委托范围，轻型化强调经营结构与服务模式调整，零售特色也可以由综合金融服务支撑。[^1][^3][^4]

## 面试应对

### 问题1：如何区分邮储的业务历史与银行沿革？

回答思路：区分1919年业务起点、2007年银行成立、2012年改制和两地上市。

口述模板：邮政储金业务可以追溯到1919年，但中国邮政储蓄银行是在2007年挂牌成立的，2012年整体改制为股份有限公司，2016年在香港上市，2019年在上海上市。因此，1919年代表业务历史，不是现行银行法人的成立时间。

### 问题2：怎样理解邮储的“自营+代理”和大型零售定位？

回答思路：说明两类渠道的协同价值及权限边界，再解释零售不排斥公司业务。

口述模板：邮储通过银行自营机构和邮政代理网点协同服务“三农”、城乡居民和中小企业，渠道覆盖是其重要特色。但代理网点只能在委托范围内办理业务，并不等于全部邮政网点都是银行自营机构。大型零售银行强调个人等零售客群的重要性，也不排斥公司金融和综合服务。

### 问题3：如何概括邮储文化与“六化”升级？

回答思路：先说使命、愿景核心，再完整列出2026年公告的六化并区分层级。

口述模板：邮储使命是“普惠城乡，让金融服务没有距离”，愿景是建设客户信赖、特色鲜明、稳健安全、创新驱动、价值卓越的一流大型零售银行。2026年3月发布的阶段性“六化”包括特色化、轻型化、综合化、生态化、精细化、数智化，强调从规模驱动向价值驱动转变。文化是长期价值导向，六化是特定阶段的转型路径。
