# 中国工商银行

## 概述

中国工商银行是在我国中央银行与专业银行职能分离过程中成立的国有大型商业银行。其历史起点是1984年承接中国人民银行原有的工商信贷和储蓄业务，而不是2005年股份制改造或2006年上市。今天的工行已提供公司金融、个人金融、金融市场及综合金融服务，不能将名称中的“工商”理解为只服务工厂和商户。[^1][^2]

理解工行特色，可以把三条线联系起来：工商信贷和储蓄业务形成的客户基础，覆盖多类客群的综合金融服务，以及围绕风险管理、经营结构和数字化展开的转型。“提供卓越金融服务”是企业使命，“工于至诚，行以致远”是价值观，“五化转型”则是有明确资料年份的经营转型路径，三者层级不同。[^2][^3][^4]

资料核验日期：2026-09-27。文化引文依据核验时官网展示；转型内容采用2025年官方经营公告口径。以下“内涵解析”是依据来源整理的知识解释，不是另拟官方口号。

### 成立、改制、上市各指什么

| 时间 | 事件 | 应当区分的含义 |
| --- | --- | --- |
| 1983年9月 | 国务院决定人民银行专门行使中央银行职能，另组建工商银行 | 这是制度安排和筹建背景，不是正式成立日 |
| 1984年1月1日 | 中国工商银行正式成立 | 承接原由人民银行办理的工商信贷和储蓄业务，是工行成立日期 |
| 2005年10月28日 | 整体改制为股份有限公司 | 改变公司组织形式、治理及产权安排，不是重新开始计算银行历史 |
| 2006年10月27日 | 在上交所和香港联交所同日挂牌上市 | A股、H股同日上市；不等于股份公司成立日 |

时间依据官方《中国工商银行简史（1984-2014）》和《2025年业务综述》。[^1][^2]

制度上的关键，是将中央银行的货币管理职能与商业性的工商信贷、储蓄经营分开。因此，工行与人民银行有业务承接关系，但二者不是同一机构，也不能从该沿革推出工行具有制定货币政策的职能。

## 企业文化

### 官方精确表述

以下按官网“企业文化”栏目列示，换行合并不改变词语。[^3]

| 层级 | 官方表述 |
| --- | --- |
| 使命 | “提供卓越金融服务” |
| 使命展开 | “服务客户”“回报股东”“成就员工”“奉献社会” |
| 愿景 | “全面建设具有中国特色的世界一流现代金融企业，成为基业长青的银行” |
| 价值观 | “工于至诚，行以致远” |
| 价值观展开 | “诚信、人本、稳健、创新、卓越” |

### 内涵解析

使命回答的是银行通过金融服务为谁创造价值。四个对象分别是客户、股东、员工和社会：客户获得适合的产品与服务，股东获得可持续回报，员工获得职业发展，社会获得支持实体经济和民生的金融供给。四者共同构成使命的展开，不能只保留“回报股东”就把使命解释成利润最大化。

“工于至诚”突出诚信作为金融关系的基础；“行以致远”强调长期经营而非短期冲量。五项展开中，诚信涉及承诺和真实信息，人本涉及客户与员工，稳健涉及风险承受和经营连续性，创新涉及产品、技术和服务改进，卓越涉及专业品质。它们是相互约束的要求：创新应当受风险和合规约束，稳健也不等于停止创新。

愿景是长期组织目标。“世界一流现代金融企业”描述能力与治理追求，“基业长青”强调可持续经营。不能用一次产品发布、某年排名或一个业务规模指标替代愿景。

## 业务品牌与战略辨析

### 综合服务为什么是组织能力

工行的公司、个人和金融市场业务可以围绕同一经济活动协同。例如企业经营需要结算、融资和资金管理，企业员工需要工资账户、消费和养老服务，跨境经营还需要外汇与国际结算。综合服务是将这些需求有组织地连接起来，而不只是将产品目录加长。2025年业务综述同时强调服务实体经济、风险为本、数智化转型和专业化经营。[^2][^4]

### “五化转型”：2025年官方口径

2025年一季度经营公告明确列出“智能化风控、现代化布局、数字化动能、多元化结构、生态化基础”。下表释义依据该公告分项内容整理。[^4]

| 转型方向 | 组织与业务内涵 |
| --- | --- |
| 智能化风控 | 将数据和智能技术用于风险感知、识别、预警、处置，并加强跨境、跨市场风险联防联控；不是只部署一个反欺诈模型 |
| 现代化布局 | 使机构、业务和金融基础设施更适配经济发展，涉及清算、结算、支付、托管以及国际金融中心服务 |
| 数字化动能 | 通过手机银行、开放银行、人工智能等改进经营和服务；不只是把柜面流程搬到手机端 |
| 多元化结构 | 优化客户、业务和板块结构，平衡公司、普惠、个人等不同客群，减少对单一来源的依赖 |
| 生态化基础 | 沿着资金往来识别客户之间的关联，连接客户链、服务链与价值链，形成持续服务关系 |

金融“五篇大文章”是科技金融、绿色金融、普惠金融、养老金融、数字金融，描述重点服务领域；工行“五化转型”描述自身经营能力和模式如何改进。两者都有“五”，但不是同一组概念。[^4]

### 品牌、方案与技术体系

| 名称 | 类型和实际含义 | 易混边界 |
| --- | --- | --- |
| 工银养老金融 | 2025年官方公告披露的养老金融品牌，连接金融产品与养老消费服务 | 是业务品牌，不是全行使命或价值观 |
| 工银全球司库 | 2025年官方公告披露的品牌，面向跨国公司深化综合金融服务 | 司库关注企业资金统筹，不能当成面向个人的养老产品 |
| “如意人生”个人养老服务全面金融解决方案 | 覆盖财务规划、资金配置、服务保障、资产安排四大核心情景，组合养老规划、优选产品和养老服务 | 是综合方案，不是一个统一期限、统一收益的单一存款 |
| 工银e生活 | 官方公告列举的数字化服务平台之一 | 平台是服务入口，与“数字工行”这一更广泛的转型建设不能画等号 |
| ECOS2.0 | 公告中的数字技术生态体系 | 属于技术支撑层，不是个人理财产品 |

品牌与平台依据2025年经营公告；“如意人生”依据官网方案介绍。[^4][^6]

“如意人生”尤其适合用来理解主体边界：方案中的理财、基金、保险由相应产品管理机构发行与管理，工行承担相关代销角色；养老服务由养老服务机构提供。品牌统一不意味着所有产品都是工行存款，也不意味着工行直接经营所有养老设施。[^6]

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 工行成立于2005年或2006年 | 1984年成立，2005年股改，2006年上市 |
| 承接人民银行业务，所以工行是中央银行 | 承接的是工商信贷与储蓄业务；成立的背景恰是两类职能分离 |
| “提供卓越金融服务”是愿景 | 它是使命；愿景强调世界一流现代金融企业与基业长青 |
| “诚信、人本、稳健、创新、卓越”是五化转型 | 它们是价值观展开；五化转型有另一组完整名称 |
| 科技金融等于金融科技 | 前者主要指服务科技创新主体和活动；后者是技术对金融服务与管理的赋能 |
| 养老服务方案中所有产品均保本 | 方案可以包含不同法律性质、不同风险等级的产品，应分别识别 |

## 笔试自测

以下3题均为自编单项选择题，用于核对本卡知识，不是银行公布的真题。

### 自编题1：历史节点

下列工行历史事件与日期的对应，正确的是：

A. 1983年9月，工商银行正式成立  
B. 1984年1月1日，工商银行整体改制为股份有限公司  
C. 2005年10月28日，工商银行整体改制为股份有限公司  
D. 2006年10月27日，工商银行仅在香港上市

答案：C。

解析：1983年9月对应组建决定；正式成立是1984年1月1日；2006年10月27日为沪港同日挂牌上市。[^1][^2]

### 自编题2：文化层级

根据工行官网“企业文化”栏目，下列属于价值观而不是使命或愿景的是：

A. 提供卓越金融服务  
B. 工于至诚，行以致远  
C. 成为基业长青的银行  
D. 服务客户

答案：B。

解析：A为使命，D为使命的展开，C是愿景中的组成部分，B才是价值观原文。[^3]

### 自编题3：转型与业务

根据2025年一季度经营公告及官网养老方案，下列理解正确的是：

A. “五化转型”就是金融“五篇大文章”的另一种叫法  
B. “多元化结构”仅指增加网点数量  
C. “如意人生”中的理财、基金、保险均应视为银行存款  
D. “智能化风控”强调运用智能能力贯穿风险识别、预警和处置

答案：D。

解析：五化转型是自身经营转型路径，五篇大文章是重点服务领域；多元化结构涉及客户、业务和板块；综合养老方案的产品法律性质必须分别判断。[^4][^6]
