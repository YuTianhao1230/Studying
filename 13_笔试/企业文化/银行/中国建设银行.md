# 中国建设银行

## 概述

中国建设银行的前身是1954年成立的中国人民建设银行，早期与国家基本建设投资拨款和监督工作紧密相连。后来经历专业银行、商业银行和股份制商业银行等阶段，服务范围逐步扩展为公司金融、个人金融和资金资管等综合业务。名称中的“建设”反映历史渊源与服务国家建设的传统，不意味着今天只办理工程贷款或住房按揭。[^1][^2][^3]

建行特色需要同时理解历史基础和组织转型：基础设施、住房等领域形成了业务积累；普惠金融、金融科技和各类数字平台则把服务能力扩展到小微企业、乡村及生活场景。品牌平台、年度战略和企业文化各有层级，不能把“建行生活”当作全行愿景，也不能把某一阶段“三大战略”当成任何年份都不变的完整战略清单。

资料核验日期：2026-09-27。文化表采用官网“企业文化”页面可检索文字交叉核对。经营能力和平台定义采用《2025年年度报告》，三大战略采用2018年度业绩公告的明确历史口径。

### 关键时间轴

| 时间 | 事件 | 应当区分的含义 |
| --- | --- | --- |
| 1954年10月1日 | 中国人民建设银行正式成立 | 前身与国家基本建设投资管理相联系 |
| 1979年 | 成为国务院直属金融机构 | 对应机构管理体制调整，不是最早成立时间 |
| 1994年 | 政策性贷款业务随政策性金融体制改革作相应移交 | 与国家开发银行承接相关政策性业务相联系，建行走向商业银行经营 |
| 1996年 | 更名为中国建设银行 | 更名不等于银行初次成立 |
| 2004年9月17日 | 中国建设银行股份有限公司成立 | 在分立基础上实施股份制改革，不宜笼统写成所有原业务原样整体改名 |
| 2005年10月27日 | 在香港联交所上市 | H股上市 |
| 2007年9月25日 | 在上海证券交易所上市 | A股上市，与H股相隔近两年 |

沿革与改革、上市节点依据官网“企业历史”；1954年精确成立日期另见60周年官方报道。[^2][^3]

### 从财政职能到商业银行

早期建行经办国家基本建设投资拨款并实施监督，体现计划投资管理的组织安排。随着经济体制和金融体制变化，信贷、结算及商业经营职能逐步发展，政策性业务与商业性业务又进一步分工。因此，“支持国家建设”是长期服务方向，而“直接经办财政拨款”属于特定历史职能，两者不能画等号。

2004年股份公司成立改变的是组织和治理结构。2005年、2007年上市则是进入相应资本市场的事件，不能将股份制改革、H股上市和A股上市合并成一个日期。

## 企业文化

### 核验时官网表述

下表按官网“企业文化”页面的可检索文字整理，空格与标点作阅读性规范。页面主体以图片展示；引文对应该页检索可提取的中文，不由英文自行回译。[^4]

| 层级 | 官方表述 |
| --- | --- |
| 愿景 | “建设最具价值创造力的国际一流银行集团。” |
| 使命 | “为客户提供更好服务，为股东创造更大价值，为员工搭建广阔的发展平台，为社会承担全面的企业公民责任” |
| 核心价值观 | “诚实 公正 稳健 创造” |

### 内涵解析

使命的四个对象是客户、股东、员工和社会。客户服务影响银行存在的基础，股东价值要求经营具有可持续回报，员工平台关系到能力培养和组织发展，社会责任则将金融服务放在经济社会发展的整体关系中。它不是只面向一个群体的单目标口号。

“诚实”要求信息、承诺和行为可信；“公正”涉及公平对待和依规则处理；“稳健”要求重视风险、资本与长期经营；“创造”体现产品、服务和组织改进。稳健与创造应当同时理解：创新不能脱离风险承受能力，风险管理也不是停止为客户解决问题。

愿景中的“价值创造力”强调持续创造价值的能力，而不仅是某一年度利润或规模排名。价值创造需要业务、科技、风险、运营等部门共同发挥作用，不能只归因于前台销售。

### 官网页面口径说明

官网另一可访问的企业文化页面载有愿景“始终走在中国经济现代化的最前列，成为世界一流银行。”，使命末句同样为“为社会承担全面的企业公民责任”，核心价值观为“诚实、公正、稳健、创造”。[^5]

这些页面没有足以确定版本先后或切换日期的说明，本卡不据页面路径推断新旧版本。识别题目时应以题干给定材料为准，不把不同页面的愿景或其他时期宣传语拼成一套原文。

## 业务特色与战略辨析

### 三大战略：2018年度资料口径

2019年发布的2018年度业绩公告明确列出住房租赁、普惠金融、金融科技“三大战略”。下表解释采用该公告的具体内容，不将这三项声称为2026年全部战略。[^6]

| 战略 | 组织与业务内涵 |
| --- | --- |
| 住房租赁 | 通过住房租赁服务平台、住房服务公司和长租社区等连接房源、租赁需求与金融服务；不只是向买房者发放按揭贷款 |
| 普惠金融 | 利用客户信息与技术改善小微等客群服务，形成批量获客、客户画像、自动审批、智能风控与综合服务的衔接 |
| 金融科技 | 运用大数据、人工智能等改进产品、客户服务和风险管理，并通过专门科技组织和系统形成集团能力 |

“科技金融”侧重金融如何服务科技创新，“金融科技”侧重技术如何改进金融经营。二者可相互促进，但不能在原文匹配题中互换。

### 2025年年报中的“三个能力”

《2025年年度报告》明确将“三个能力”解释为“服务国家建设能力、防范金融风险能力、参与国际竞争能力”，并在公司简介中强调金融“五篇大文章”和内涵式高质量发展。[^1]

三个能力描述银行需要具备的能力，三大战略描述特定时期的重点方向，五篇大文章描述科技、绿色、普惠、养老、数字等金融服务领域。三组概念的数量、层级与适用资料年份均不同。

### 业务品牌与平台

| 名称 | 定位与内涵 | 易混边界 |
| --- | --- | --- |
| 建融家园 | 2018年度公告中的住房租赁长租社区实践 | 对应住房租赁服务，不是企业文化愿景 |
| 建行惠懂你 | 2025年年报定义的、面向普惠金融客户的综合化生态型服务平台 | 是服务平台，不是保证所有申请必获贷款的承诺 |
| “双子星” | 2025年年报中指手机银行和“建行生活” | 是两个服务入口的组合，不是两个独立银行法人 |
| 裕农通 | 依托线下服务站点、线上APP及微信生态的乡村振兴综合服务平台 | 侧重综合服务渠道，不等于一项贷款 |
| 裕农贷款 | 向以农户为主的个人经营主体发放的贷款产品，包括“裕农快贷”和“裕农贷”产品体系 | 与裕农通平台应区分 |

“建融家园”依据2018年度公告；其余平台、产品名称与定义依据2025年年报“释义”。[^1][^6]

平台化服务的组织含义，是把获客、身份识别、业务申请、风险判断和后续服务衔接起来。平台提高可得性并不取消授信审核；线上入口也不改变存款、贷款、基金或保险各自的法律性质。

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 建行自1954年成立时就使用今天的全称 | 前身为中国人民建设银行，1996年更名，2004年股份公司成立 |
| 2004年建行已经沪港上市 | 2004年是股份公司成立，H股2005年、A股2007年上市 |
| 建行只服务基建和住房客户 | 今天提供多类综合金融服务，历史特色不等于业务边界 |
| “诚实 公正 稳健 创造”是三大战略 | 是核心价值观，三大战略另有具体年度口径 |
| 住房租赁战略就是个人住房按揭业务 | 租赁服务还涉及房源、平台、运营和租赁关系 |
| 裕农通与裕农贷款是同一个产品 | 前者是综合平台，后者是贷款产品体系 |
| 集团有保险、基金子公司，所以在建行购买的都属于存款 | 应按具体发行管理主体与合同识别产品性质 |

## 笔试自测

以下3题均为自编单项选择题，不是银行公布的真题。

### 自编题1：历史节点

下列建行事件按时间先后排序，正确的是：

A. A股上市、H股上市、股份公司成立、前身成立  
B. 前身成立、股份公司成立、H股上市、A股上市  
C. 股份公司成立、前身成立、A股上市、H股上市  
D. 前身成立、H股上市、股份公司成立、A股上市

答案：B。

解析：对应年份依次为1954年、2004年、2005年、2007年，不能用上市年份替代成立年份。[^1][^2][^3]

### 自编题2：文化层级

依据本卡核验的建行官网文化页面，下列属于核心价值观的是：

A. 服务国家建设能力、防范金融风险能力、参与国际竞争能力  
B. 住房租赁、普惠金融、金融科技  
C. 诚实 公正 稳健 创造  
D. 手机银行和建行生活

答案：C。

解析：A是2025年年报的三个能力，B是2018年度公告的三大战略，D是“双子星”定义，C才是核心价值观。[^1][^4][^6]

### 自编题3：平台与产品

根据2025年年报“释义”，下列配对正确的是：

A. 裕农通：金融服务乡村振兴综合服务平台  
B. 建行惠懂你：独立于建设银行的另一家银行  
C. 裕农贷款：建行手机银行与建行生活的合称  
D. 双子星：两种统一保本的个人理财产品

答案：A。

解析：裕农通是服务平台；惠懂你面向普惠金融客户；裕农贷款是贷款产品体系；双子星指手机银行与建行生活。[^1]

## 面试应对

### 问题1：如何概括建设银行的历史主线？

回答思路：从基本建设投资职能切入，依次说明更名、股份公司和两地上市。

口述模板：建行前身中国人民建设银行于1954年成立，早期承担国家基本建设投资拨款和监督等职能。1996年更名为中国建设银行，2004年成立股份有限公司，2005年和2007年分别在香港、上海上市。历史上的财政和基建职能是发展背景，今天的建行是经营多类综合金融业务的商业银行。

### 问题2：如何回答建行文化表述？

回答思路：给出官网文化字段，并说明不同页面不足以证明版本先后。

口述模板：官网企业文化页面载有“建设最具价值创造力的国际一流银行集团”的愿景，使命面向客户、股东、员工和社会，其中包括“为社会承担全面的企业公民责任”，核心价值观是“诚实、公正、稳健、创造”。官网其他可访问页面还载有另一愿景表述，但页面本身不足以证明版本先后，因此面试时我会按题目指定材料回答，不拼接不同页面的表述。

### 问题3：怎样区分建行的三大战略、三个能力和业务平台？

回答思路：按年份和概念层级分别列示，并举平台与产品的例子。

口述模板：建行2018年度三大战略是住房租赁、普惠金融、金融科技；2025年年报的三个能力是服务国家建设、防范金融风险、参与国际竞争。建行惠懂你、裕农通属于服务平台，裕农贷款属于贷款产品体系，“双子星”指手机银行和建行生活。战略、组织能力、平台和产品不能互换。
