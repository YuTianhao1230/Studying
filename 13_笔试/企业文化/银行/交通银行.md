# 交通银行

## 概述

交通银行始建于1908年，1987年重新组建后正式营业，成为中国第一家全国性的国有股份制商业银行，总部设在上海。1908年是历史起点，1987年是重新组建后的营业节点，2004年又实施深化股份制改革，2005年、2007年分别完成H股和A股上市，不能只记一个“成立年份”来代替全部沿革。[^1][^2]

交行今天是国有大型商业银行集团，不是只服务交通运输行业的专业机构。其综合金融服务与财富金融特色相联系，同时发展普惠金融、贸易金融和科技金融。集团内部不同专业条线、分支机构和子公司需要协同，但“一个交行、一个客户”的经营理念不意味着取消法人、牌照和风险管理边界。[^1][^2]

资料核验日期：2026-09-27。交行文化存在明确的历史版本差异：本卡分别列出2009年报告、2017年官方简介、核验时招聘页和2025年年报的表述，不将不同年份拼成一套“现行完整文化原文”。

### 关键节点

| 时间 | 事件 | 区分要点 |
| --- | --- | --- |
| 1908年 | 交通银行始建 | 历史起点 |
| 1958年 | 内地业务分别并入当地人民银行和中国人民建设银行，香港分行持续营业 | 不能把内地业务调整写成所有机构在全球同时停止营业 |
| 1986年 | 国务院批准重新组建交通银行 | 批准重组与正式开业不是同一节点 |
| 1987年4月1日 | 重新组建后的交行正式对外营业 | 成为首家全国性的国有股份制商业银行，总行设上海 |
| 2004年 | 实施深化股份制改革，完成财务重组并引入境外战略投资者 | 是既有股份制银行的深化改革，不是第一次采用股份制 |
| 2005年6月 | 在香港联交所挂牌上市 | H股上市 |
| 2007年5月 | 在上交所挂牌上市 | A股上市 |

历史调整及2004年改革依据2017年官方简介；成立、重新营业和上市月份与2025年年报交叉核对。[^1][^2]

“全国性国有股份制商业银行”中的“全国性”指经营布局，“国有”涉及所有权性质，“股份制”涉及公司组织与产权形式，三者不冲突。它也不意味着交行在现行分类中应被排除出国有大型商业银行。

## 企业文化与版本辨析

### 2017年官方简介中的文化表述

| 层级 | 该版本官方原文 |
| --- | --- |
| 企业使命 | “创造共同价值” |
| 企业愿景 | “建设中国最佳财富管理银行” |
| 企业精神 | “拼搏进取、责任立业、创新超越” |
| 经营理念 | “一个交行、一个客户” |
| 广告语 | “百年交行——您的财富管理银行” |

以上完整对应2017年官方简介的同一段落。[^2] 核验时官方招聘页“交行文化”仍列出“拼搏进取、责任立业、创新超越”，并解释拼搏进取包括昂扬向上的斗志、坚韧不拔的毅力、知难而上的勇气。招聘页未在这一位置将三项明确命名为“核心价值观”，因此本卡保留原字段区别。[^4]

### 核心价值观：可追溯的2009年版本

官网2009年企业社会责任报告“战略与文化”列示如下。[^3]

| 层级 | 2009年官方原文 |
| --- | --- |
| 企业使命 | “提供更优金融方案 持续创造共同价值” |
| 企业远景 | “建设价值卓越的一流国际金融集团” |
| 核心价值观 | “责任立业 创新超越” |
| 经营理念 | “诚信永恒 稳健致远” |
| 服务宗旨 | “以您为先 灵活稳健” |

这里的“核心价值观”确有官方出处，但本次未取得足以证明它是2026年现行完整字段的材料。2017年的企业精神增加“拼搏进取”，也不能仅因词语部分重合就自行宣布它是2009年核心价值观的正式改名。本卡按来源年份记忆，不猜测内部制度修订时间。

### 内涵解析

“共同价值”强调银行与客户、股东、员工、社会的价值关系：客户获得适合的金融服务，银行保持可持续经营，员工参与组织成长，社会获得金融对经济活动的支持。共同价值不是所有参与者获得同一种收益，也不是对每项业务作无风险承诺。

“责任立业”强调岗位、组织与社会责任；“创新超越”强调改进产品、流程和经营方式；“拼搏进取”强调面对困难的执行与持续改进。责任与创新需要共同发挥作用，不能把创新解释为绕过规则。

“一个交行、一个客户”适合从集团协同理解。同一企业可能同时需要授信、结算、跨境业务和员工金融服务，不同条线应围绕客户整体需求提供协调服务，而不是各自重复作业。协同需要职责分工、信息合规和风险控制支撑，并不等于客户数据可以不受限制地流转。

## 战略与业务品牌

### 2025年度报告的战略结构

2025年年报明确战略目标为“建设具有特色优势的世界一流银行集团”，持续打造四大业务特色，提升五大专业能力，并以上海主场建设和数字化转型作为战略突破口。同年度可持续发展报告明确“以绿色为全集团业务经营发展底色”。[^1][^5]

| 层级 | 具体内容 | 内涵 |
| --- | --- | --- |
| 战略目标 | 建设具有特色优势的世界一流银行集团 | 长期集团建设目标，不等于2017年文化页愿景逐字沿用 |
| 四大业务特色 | 普惠金融、贸易金融、科技金融、财富金融 | 说明重点形成差异化服务能力的业务方向 |
| 五大专业能力 | 客户经营、科技引领、风险管理、协同作战、资源配置 | 说明支撑业务方向的组织能力 |
| 战略突破口 | 上海主场建设、数字化转型 | 一项联系总部所在地及区域资源，一项联系全行经营方式与技术能力 |
| 经营发展底色 | 绿色 | 可持续发展报告强调绿色融入全集团经营，不是因未列入四特色就不开展绿色金融 |

四大业务特色与金融“五篇大文章”不是同一张清单：前者含贸易金融、财富金融，后者为科技金融、绿色金融、普惠金融、养老金融、数字金融。概念数量相近不意味着可以互相替换。

### 品牌与客群

以下名称与定义依据2025年年报“释义”。[^1]

| 品牌或平台 | 服务定位 | 组织或产品边界 |
| --- | --- | --- |
| 交银蕴通 | 公司业务核心品牌，提供公司金融一站式数智化服务体系，服务理念为“蕴新致远 通赢未来” | 面向公司金融需求，不是全行企业使命 |
| 沃德财富 | 零售业务主品牌，强调“丰沃共享，厚德载富” | 财富服务品牌，不等于旗下产品均为保本存款 |
| 交银展业通 | 普惠金融业务品牌 | 面向小微等普惠服务需求 |
| 交银益农通 | 服务乡村振兴品牌 | 涉农与县域服务不只属于名称带“农业”的银行 |
| 买单吧 | 一站式金融生活平台 | 是客户服务入口，不是银行法人或一款贷款 |
| 云上交行 | 以远程视频服务等连接云网点、云柜员、云管家 | 是服务模式与渠道能力，不等于简单把柜台表单电子化 |

财富金融的内涵也不只是销售理财产品。客户财富管理涉及资金安排、风险偏好、不同生命周期的需求和综合服务；具体存款、基金、保险及理财产品仍分别由相应合同与管理规则界定。

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 交行成立于1987年，没有更早历史 | 1908年始建，1987年是重新组建后营业 |
| 交行2004年才第一次实行股份制 | 1987年重新组建已体现股份制，2004年是深化改革 |
| 交行总部在北京 | 总部设上海 |
| 2017年“企业精神”等于2009年“核心价值观”字段 | 应保留字段与年份，不能自行互换 |
| 2017年文化愿景与2025年战略目标必须逐字相同 | 不同年份、不同字段，应分别引用 |
| 四大业务特色包含绿色金融、不含贸易金融 | 年报四特色为普惠、贸易、科技、财富；可持续发展报告另强调绿色为经营发展底色 |
| “一个交行、一个客户”取消各机构法律责任 | 协同经营不改变具体机构的法律与监管责任 |

## 笔试自测

以下3题均为自编单项选择题，不是银行公布的真题。

### 自编题1：历史身份

关于交通银行，下列说法正确的是：

A. 1908年始建，1987年重新组建后营业，总部设在上海  
B. 1987年首次创立，并于同年在沪港上市  
C. 2004年才首次成为股份制商业银行  
D. 2005年在上海上市，2007年在香港上市

答案：A。

解析：成立、重新组建、深化改革、上市必须分别识别；H股2005年、A股2007年。[^1][^2]

### 自编题2：文化版本

根据本卡引用的2009年报告和2017年官方简介，下列配对正确的是：

A. 2009年核心价值观：一个交行、一个客户  
B. 2017年企业使命：创造共同价值  
C. 2017年企业精神：建设中国最佳财富管理银行  
D. 2009年服务宗旨：责任立业 创新超越

答案：B。

解析：A实际是2017年经营理念；C是2017年愿景；D是2009年核心价值观。题干限定年份，避免把不同资料混为一套。[^2][^3]

### 自编题3：业务特色

依据2025年年报，下列完整对应交行“四大业务特色”的是：

A. 住房租赁、普惠金融、金融科技、个人按揭  
B. 公司金融、个人金融、金融市场、资产托管  
C. 普惠金融、贸易金融、科技金融、财富金融  
D. 绿色金融、养老金融、数字金融、科技金融

答案：C。

解析：C是年报四大业务特色的完整组合；同年度可持续发展报告另强调绿色为经营发展底色，五大专业能力则属于支撑能力层。[^1][^5]

## 面试应对

### 问题1：如何介绍交通银行的历史与身份？

回答思路：区分始建、重新组建、深化改革和两地上市，并点明总部。

口述模板：交通银行始建于1908年，1987年重新组建后正式营业，总部设在上海，是全国性国有股份制商业银行改革的重要实践。2004年是深化股份制改革，2005年在香港上市，2007年在上海上市。它今天是国有大型商业银行，不是只服务交通运输行业的专业机构。

### 问题2：怎样处理交行企业文化的版本差异？

回答思路：分别引用2009年、2017年和核验时招聘页，不组合成所谓现行完整体系。

口述模板：交行文化需要按版本回答。2009年报告的核心价值观是“责任立业 创新超越”；2017年简介的使命是“创造共同价值”，企业精神是“拼搏进取、责任立业、创新超越”，经营理念是“一个交行、一个客户”。核验时招聘页仍展示三项文化关键词，但没有足够资料证明2009年或2017年整套字段就是2026年现行版本。

### 问题3：如何概括交行2025年的战略特色？

回答思路：说清战略目标、四大业务特色、五大能力和两个突破口。

口述模板：交行2025年战略目标是建设具有特色优势的世界一流银行集团，四大业务特色是普惠金融、贸易金融、科技金融、财富金融，五大专业能力是客户经营、科技引领、风险管理、协同作战、资源配置，并以上海主场建设和数字化转型为突破口。绿色是经营发展底色，但不是四大特色清单中的替换项。
