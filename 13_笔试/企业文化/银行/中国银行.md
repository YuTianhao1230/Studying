# 中国银行

## 概述

中国银行成立于1912年，是具有长期跨境金融经营传统的国有大型商业银行。它曾在不同历史阶段承担中央银行、国际汇兑银行和外汇外贸专业银行职能，1994年开始向国有商业银行转化，2004年整体改建为股份有限公司，2006年先后在香港和上海上市。历史上曾承担的职能不能直接套用到今天。[^1][^2]

中行的特色可以沿着“全球化网络、综合化服务、境内外协同”理解。全球化不只是境外网点数量，而是连接不同市场中的客户、资金、结算和风险管理需求；综合化也不意味着每家分行都能自行经营所有金融牌照业务。集团通过银行主体及相关机构提供多类服务，具体业务仍有法人、牌照和所在地监管边界。[^1]

资料核验日期：2026-09-27。文化完整引文采用《2022年社会责任报告》，并与官网分行所列集团文化交叉核对；经营定位另参考官网所载2025年年报简介。以下内涵解析是知识说明，不是新增官方口号。

### 成立、职能变化与上市

| 时间 | 事件 | 辨析 |
| --- | --- | --- |
| 1912年2月5日 | 中国银行成立 | 是银行成立日，不是股份公司成立日 |
| 1912年至1928年 | 行使当时政府中央银行职能 | 是历史阶段，不表示今日中行制定国家货币政策 |
| 1928年 | 改为政府特许的国际汇兑银行 | 国际业务传统有明确历史来源 |
| 1942年 | 成为发展国际贸易的专业银行 | 与今天的综合性商业银行定位不同 |
| 1979年3月13日 | 获批从人民银行中分设出来，同时行使国家外汇管理总局职能 | 银行经营与外汇行政管理曾有特定历史安排 |
| 1983年9月国务院决定之后 | 与国家外汇管理总局分设，各行其职 | 不能据1979年的安排推断今日中行就是外汇管理部门 |
| 1994年初 | 由外汇外贸专业银行开始向国有商业银行转化 | 商业化转型节点 |
| 2004年8月26日 | 整体改建为中国银行股份有限公司 | 股份制改革节点 |
| 2006年6月1日、7月5日 | 分别在香港联交所、上交所上市 | 先H股后A股，不是同日上市 |

1912年的精确日期见官网刊载的百年发展文章，其余节点见历史梗概。[^2][^3] 中行是首家在内地和香港发行上市的中资商业银行，指其完成两地上市的组合事实；“中国境内首家赴境外发行上市的商业银行”则涉及交行2005年的境外上市，两个限定条件不同。[^1][^6]

## 企业文化

### 官方精确表述

以下为《2022年社会责任报告》所列文化体系，官网罗安达分行“发展战略”页面亦明确将这三项归于集团目标。不能把该分行的本地经营策略当成全集团使命。[^4][^5]

| 层级 | 官方表述 |
| --- | --- |
| 使命 | “融通世界 造福社会” |
| 愿景 | “建设全球一流现代银行集团” |
| 价值观 | “卓越服务、稳健创造、开放包容、协同共赢” |

### 内涵解析

“融通世界”包含跨市场连接和金融资源配置，不只是提供外币兑换；“造福社会”说明连接与配置的目的包含服务经济社会发展。二者合在一起，才构成使命的完整关系，不能将“融通世界”孤立理解成不受约束地扩大海外业务。

“卓越服务”不仅指柜面态度。报告将总行服务分行、后线服务前线、全行服务客户联系起来，说明客户体验依赖组织内部的服务链条。前台接触客户，后台处理结算、系统和风险事项，任何一环失效都可能影响最终服务。[^4]

“稳健创造”把价值创造与风险约束结合起来；“开放包容”强调吸收不同市场、业务和人才的经验；“协同共赢”涉及内外、上下、左右的合作。跨境客户往往需要境内分行、境外机构和专业产品条线协同，但协同仍须遵守信息保护、反洗钱和当地经营规则，不能解释成机构之间没有边界。

愿景中的“现代银行集团”强调治理、专业能力和集团经营形态。它不同于单一产品品牌，也不能由某一年全球排名直接替代。

## 业务特色与战略辨析

### 全球化与综合化怎样协同

以企业开展跨境贸易为例，可能同时需要境内收付款、境外账户服务、贸易融资、汇率风险管理和资金集中管理。中行的全球化网络提供跨市场服务条件，综合化能力提供多种金融工具，境内外机构协同则把分散的需求连成完整服务。

外汇交易、国际结算与跨境人民币业务并不是同义词：国际结算关注贸易及其他跨境往来的资金清偿，外汇交易涉及不同货币的兑换或风险管理，跨境人民币强调跨境使用人民币。三者可以同时出现在同一客户的业务链中，但不能互相替换。

### “一体两翼”：2022年报告口径

《2022年社会责任报告》介绍的“一体两翼”格局，以境内商业银行为主体，以全球化、综合化为两翼。主体与两翼说明业务依托关系，不是三个平行法人，也不意味着境内业务仅服务本地、境外业务仅服务外国客户。[^4]

该阶段报告列举的“八大金融”包括科技金融、绿色金融、普惠金融、跨境金融、消费金融、财富金融、供应链金融、县域金融。它们是特定阶段的重点领域，不应与后来金融“五篇大文章”拼接成一套固定口号。[^4]

官网所载2025年年报简介强调：以服务实体经济为根本宗旨，以防控风险为永恒主题，将巩固扩大全球化优势、提升全球布局能力作为首要任务，并围绕科技、绿色、普惠、养老、数字金融“五篇大文章”开展服务。这里使用的是2025年资料口径，不据此推定其他年份材料也使用相同措辞。[^1]

### 品牌、资格与主体边界

| 名称或事项 | 含义 | 不能混同的概念 |
| --- | --- | --- |
| 惠如愿 | 《2022年社会责任报告》列示的普惠金融品牌，承载小微等客群服务 | 不是中行全行使命，也不是一款统一期限的理财产品 |
| “双奥银行” | 中行先后服务北京2008年奥运会和北京2022年冬奥会、冬残奥会形成的身份表述 | 是历史服务身份，不是核心价值观 |
| 中银香港、澳门分行的发钞行身份 | 官方简介分别说明有关机构的当地发钞行资格 | 不能推断中国银行在内地发行人民币 |
| 集团综合化经营 | 银行及相关机构在不同金融领域提供服务 | 集团拥有相关业务，不等于任一营业网点都有全部业务权限 |

“惠如愿”依据社会责任报告；其他事项依据公司简介。[^1][^4] 同一品牌下的融资、结算和其他服务仍须按具体合同识别，不能因为品牌归属于银行就将所有服务认定为存款。

## 易混点

| 容易混淆的说法 | 正确理解 |
| --- | --- |
| 中国银行就是中国人民银行 | 中行是商业银行，历史职能不能替代现行机构身份 |
| 中国银行成立于2004年 | 1912年成立，2004年股改 |
| 2006年中行A股、H股同日上市 | H股6月1日、A股7月5日，先香港后上海 |
| “融通世界 造福社会”是愿景 | 是使命；愿景是建设全球一流现代银行集团 |
| “一体两翼”指公司、个人、金融市场业务 | 2022年报告的一体是境内商业银行，两翼是全球化与综合化 |
| 国际结算只能使用外币 | 跨境人民币同样可以用于国际业务结算 |
| 中银香港的发钞身份意味着内地中行发行人民币 | 涉及不同地区、不同机构及不同货币的制度安排 |

## 笔试自测

以下3题均为自编单项选择题，不是银行公布的真题。

### 自编题1：历史与上市

关于中国银行，下列说法正确的是：

A. 1912年2月5日成立，2004年整体改建为股份有限公司  
B. 2004年成立后，2005年在沪港同日上市  
C. 2006年先在上海、后在香港上市  
D. 因历史上曾承担中央银行职能，今日仍负责制定国家货币政策

答案：A。

解析：成立、股改和上市是不同节点；2006年先H股、后A股。历史职能必须按时期理解。[^2][^3]

### 自编题2：文化对应

根据《2022年社会责任报告》，中行使命是：

A. 工于至诚，行以致远  
B. 面向“三农”，服务城乡，回报股东，成就员工  
C. 融通世界 造福社会  
D. 普惠城乡，让金融服务没有距离

答案：C。

解析：C是中行使命原文；中行价值观另为“卓越服务、稳健创造、开放包容、协同共赢”，不能把使命与价值观混为一项。[^4][^5]

### 自编题3：组织与战略

根据本卡引用的2022年报告及公司简介，下列理解正确的是：

A. “一体两翼”的“两翼”是信用卡和消费贷款  
B. 集团经营证券和保险业务，意味着每家分行都拥有同样的业务牌照  
C. “惠如愿”属于全行愿景  
D. 全球化网络与综合化服务需要机构协同，但具体业务仍受法人和监管边界约束

答案：D。

解析：2022年“一体两翼”中的两翼为全球化、综合化；惠如愿是普惠金融品牌。集团经营范围不等于单个分支机构的全部权限。[^1][^4]
