# 笔试

本章面向六大行、三大运营商及其他央国企笔试，按考试能力领域组织为行测、综合知识、英语和企业文化。具体科目、题量、计时、回跳与计分规则以目标单位当期通知为准。

## 内容索引

| 分支 | 内容 |
| --- | --- |
| [行测](<行测/README.md#行测>) | 常识判断、言语理解、数量关系、判断推理、资料分析；空间推断归判断，数字推理和材料决策归数量 |
| [综合知识](<综合知识/README.md#综合知识>) | 政治与时政、经济金融、会计财务和管理营销 |
| [英语](<英语/README.md#英语笔试>) | 词汇语法、完形、阅读、长难句、金融商务词汇、通信科技词汇和公开题源 |
| [企业文化](<企业文化/README.md#企业文化>) | 六大行与三大运营商的沿革、使命价值观、品牌业务和阶段性战略 |
