# 笔试

本章面向六大行、三大运营商及其他央国企笔试，按考试能力领域组织为行测、综合知识、英语和企业文化。具体科目、题量、计时、回跳与计分规则以目标单位当期通知为准。

## 组织原则

- 行测按题型归档公式、规则、解题步骤、适用条件和案例。
- 常识判断按行测题型归档；综合知识保留政治时政及银行、运营商常见专业基础。
- 英语按可复用语言能力组织，不为每家单位重复建立题型目录。
- 企业文化按单位独立成卡，文化原文、年度战略和品牌名称分别标注资料口径。

## 考情与题源

[运营商与六大行考情审计](<运营商与六大行考情审计.md>)用于按单位和岗位选择复习内容。公开案例区分官方大纲例题、机构整理、考生回忆和原创练习；历史卷用于识别题型，不能直接当作本年度固定考纲。

英语历史材料以客观选择题中的词汇语法、选词填空和阅读为主，部分批次出现完形。可下载整理卷、答案纠错和ETS补充样题见[英语题源与案例](<英语/英语题源与案例.md>)。

## 复习顺序

1. 按目标单位和岗位确认考试模块。
2. 行测先掌握题型与方法，再进行限时训练。
3. 综合知识按固定基础、年度时政和岗位侧重点分层复习。
4. 英语持续练习词汇语法、完形和阅读，并记录错因。
5. 企业文化按目标单位复习，并在考前刷新官网和年报中的阶段性表述。
