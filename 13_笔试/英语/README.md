# 英语笔试

## 知识点解析

### 概述

英语笔试中的词汇语法题主要检验句子结构、词义、搭配与语法形式；完形填空检验局部句法和篇章衔接；阅读理解检验信息定位、同义改写、逻辑推断与作者立场。长难句分析贯穿三类题型，行业词汇帮助识别金融、通信和商务材料中的专门含义。

题型与作答形式是两个维度。“选词填空”既可能指四选一的不完整句，也可能指从词库中选词填入多处空格；“完形填空”描述篇章设空，不表示一定要求手写答案。题材也不限于行业新闻，通知、邮件、科普、社会生活和一般商业报道都能训练相同的阅读能力。

理解英文材料需要同时保留主语、时间、条件、数量和语气强度。例如 `may reduce costs` 只表示“可能降低成本”，不能改写成“一定降低成本”；`by 10%` 与 `to 10%` 分别表示变化幅度和变化后的水平。

## 英语是否只有选择题

### 已有证据支持什么

截至 2026-09-27，已核验的中行、工行 2019 年春招机构整理卷包含词汇语法单项选择和阅读选项题。历史资料中也有部分批次的完形填空记录。因而，以选择类客观题作为基础训练方向是合理的；但这些材料不是所有机构、岗位和年份的统一考纲。

| 对象 | 当前可用依据 | 可以采用的结论 |
| --- | --- | --- |
| 中国银行、工商银行 | 可读取的 2019 年机构整理卷，有具体题面 | 历史卷存在选词、阅读等选择类题型，答案需复核 |
| 农业银行、邮储银行 | 机构说明或历史笔经，证据强度较低 | 可以辅助确定练习方向，不能直接沿用题量、时长 |
| 建设银行、交通银行 | 本轮未核验到完整官方英语卷 | 不能据其他银行题型断言其当期安排 |
| 中国联通 | 2021 年历史笔经转载，提及词汇语法和阅读 | 只反映该记录所述考试，不能推广到所有岗位 |
| 中国移动、中国电信 | 已查材料不足以确认统一英语模块 | 是否考英语、如何作答，按具体招聘通知确认 |

“目前可核验的历史卷主要是选择题”不等于“英语永远只有选择题”。本目录没有足够证据确认目标批次一定包含或一定排除翻译、写作、听力等其他形式。报名所需的英语证书或成绩，也不能用来反推笔试模块。

### 需要从当期通知核对的字段

- 机构、地区、岗位、校招或社招、年度与批次。
- 是否设独立英语模块，是否与职业能力共用计时。
- 单选、多选、词库填空、输入答案等具体作答形式。
- 题量、时长、是否可回看、是否允许跨模块切换。
- 计分规则，尤其是错答是否扣分；未知时不能把猜题策略当作通则。

中国银行[2027 年全球校园招聘公告](https://www.boc.cn/aboutboc/bi4/202609/t20260903_25689311.html)发布于 2026-09-03，初步安排在 2026 年 10 月中下旬统一笔试，具体安排另行通知。公告没有给出详细英语题型，也明确声明从未编辑或出版校园招聘考试参考资料、从未向任何机构提供考试相关资料和信息。

## 有没有真题

有公开流传并标为历年考题的机构整理资料，但应区分“可下载的整理卷”和“招聘机构官方公开卷”。本目录采用以下标记：

| 标记 | 含义 | 用途 |
| --- | --- | --- |
| 官方招聘公告 | 招聘机构发布的安排或说明 | 确认适用批次、通知方式和官方声明 |
| 机构整理卷节选 | 培训机构整理的历史题面，非官方认证逐题原卷 | 观察历史形式、练习，并独立复核 |
| 历史笔经 | 考生回忆或转载 | 辅助了解形式，完整性和适用范围有限 |
| 官方标准化考试样题 | ETS 发布的 TOEIC 样题 | 补练阅读技能，不是银行或运营商招聘真题 |
| 原创自测 | 本目录编写的练习 | 巩固知识，不作为考情证据 |

本目录其余专项卡片中的练习均为原创自测。公开题面只在[英语题源与案例](英语题源与案例.md)少量节选，并标注链接、页码、题号和答案复核结果。题库中的答案字母只是待检验信息，不能代替语法与原文证据。

## 学习路径

1. 先掌握句子骨架与词性。每题写出“缺哪种成分、哪个词决定搭配”，不要只记选项字母。
2. 用完形把句法与逻辑连起来。先填确定性强的空，暂留需要跨句证据的空，最后全文回填。
3. 阅读时建立证据定位。每道题标记对应句、同义改写、条件与量词；主旨题结合全文结构判断。
4. 按目标补行业词汇。银行方向优先财务、信贷、支付和风险；运营商方向优先网络性能、运维、客户和合同；两类都需要一般商务词汇。
5. 最后用公开案例检查错误答案辨别能力，再做综合原创自测。ETS 样题可选 Reading Part 5、6、7，具体练法见题源卡。

### 建议的练习记录

| 维度 | 记录内容 | 复盘动作 |
| --- | --- | --- |
| 词汇 | 原句、词性、该句含义、搭配 | 换一个语境再造句，检查是否仍适用 |
| 语法 | 主干、空格成分、形式约束 | 写出排除另外三个选项的理由 |
| 完形 | 空前、空后、全文证据 | 区分局部搭配错误与篇章方向错误 |
| 阅读 | 题型、证据句、选项改写 | 检查是否偷换对象、时间、范围或因果 |
| 时间 | 正确率、耗时、回读次数 | 先找出卡点，再逐步限时 |

初练先保证解释完整，再记录用时；限时训练可自行设置“10 道单句题 + 1 篇完形 + 1 组阅读”。这只是练习组合，不代表任何机构的正式题量或模块时间。词汇基础可借四级、六级资料查缺，但不能据此把招聘英语与四级、六级难度简单等同。

## 使用边界

- 行业知识用于理解材料；作答仍以英文题面为准，不能用现实常识覆盖原文设定。
- 没有当前批次证据时，不给固定题量、固定时长、固定行业词汇占比等承诺。
- 原创题涉及的公司、数据和安排都是练习设定，不是实际机构业务信息。
- 各卡片均提供答案与解析；复盘重点是证据与适用条件，而非背字母。
