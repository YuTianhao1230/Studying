# 第21题：推理树平衡链路

来源：[牛客试卷页面](<https://www.nowcoder.com/exam/test/67115327/summary>)

## 题目描述

输入含 `None` 的二叉树层序序列。统计所有始终从祖先向后代延伸、节点和为 0 且至少包含 2 个节点的路径。路径可从任意节点开始，答案可能超过 32 位。

建树采用队列规则：每次取出一个非空节点，再依次读取它的左右孩子。

## 解题思路

对根到当前节点的路径定义前缀和 $S$。一条祖先之后到当前节点的路径和为 0，当且仅当两端对应的前缀和相等。

深度优先遍历时维护当前根路径上各前缀和的出现次数。进入值为 $v$ 的节点后令 $S'=S+v$：

1. `frequency[S']` 就是以当前节点结尾的零和向下路径数。
2. 若当前节点值为 0，其中恰有一条是长度为 1 的当前节点路径，需要减去 1。
3. 把 $S'$ 加入频次后遍历孩子，离开节点时撤销，保证哈希表中只有当前祖先链。

为避免深度达到 20 万导致递归栈溢出，代码使用带进入、退出状态的显式栈。建树也按题目定义使用非空节点队列，不能把输入位置直接当作完全二叉树下标。

## 正确性说明

遍历当前节点时，频次表包含虚拟根前缀 0 以及从根到父节点的全部前缀和。每个与当前前缀相等的祖先前缀唯一对应一条和为 0、以当前节点结尾的向下路径，反之每条此类路径也对应其中一个前缀。减去值为 0 时的单节点路径后，保留的恰好都是长度至少为 2 的合法路径。每个节点作为终点统计一次，所以无遗漏也无重复。

## 复杂度分析

- 时间复杂度：$O(n)$。
- 空间复杂度：$O(n)$。

## 样例

输入：

```text
3
0 0 0
```

输出：

```text
2
```
