# 华为编程题算法分类

本页按截图中的 12 类算法组织当前目录 43 道编程题。一个题目可能涉及多个方法，表中“主类”按决定复杂度和正确性的核心算法归类。

## 考场代码原则

1. 先按数据范围选复杂度，再写状态或不变量。
2. 使用 `input = sys.stdin.buffer.readline`；输入很少时直接用 `input()`。
3. 变量优先使用 `n,m,k,a,dp` 等竞赛常用短名，不拆过多辅助函数。
4. 只保留解释关键状态、边界或剪枝的一两条注释。
5. 不为“漂亮”增加类、数据类或多层封装；但不能通过压成一行牺牲正确性。
6. 浮点题先确认舍入规则；图、树和 DP 题先确认不可达状态。
