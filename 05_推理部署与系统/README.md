# 推理部署与系统

本目录回答“模型如何稳定、高效地上线运行”。内容覆盖推理引擎、KV Cache、Batching、量化、Serving，以及把模型服务接入网关、路由、容量、SLO、可观测性、灰度、回滚和降级的生产系统设计。

| 子目录 | 内容说明 |
| --- | --- |
| [推理工程](<推理工程/README.md>) | vLLM、KV Cache、Batching、量化、CUDA Graph、TensorRT-LLM、Serving 等推理优化。 |
| [生产系统设计](<生产系统设计/README.md>) | AI 系统设计、模型路由、MLOps、容量与线上服务稳定性。 |

## 内容边界

- 这里关注模型上线后的推理与生产运行，不承载训练算法、数据治理或搜索推荐业务算法。
- Docker 等方向无关工具进入 [06_Python与工程/工程工具](<../06_Python与工程/工程工具/README.md>)。
- 召回、粗排、精排和重排进入 [09_搜索推荐广告](<../09_搜索推荐广告/README.md>)；RAG 和模型服务可链接复用。
