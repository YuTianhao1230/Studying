# 系统设计

本目录整理 AI 系统设计和模型生产化能力，重点是把模型从离线实验接入真实服务。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [AI系统设计.md](<AI系统设计.md>) | AI 应用系统的模块拆分、链路设计和工程权衡。 |
| [模型路由.md](<模型路由.md>) | AI 产品中按任务、风险、输入模态、成本和延迟选择模型或处理链路的方法。 |
| [召回粗排精排重排.md](<召回粗排精排重排.md>) | AI 产品和 RAG 中候选召回、粗排、精排、重排的分层筛选机制。 |
| [MLOps与模型生产化.md](<MLOps与模型生产化.md>) | 数据、训练、部署、监控、回滚和持续迭代的 MLOps 流程。 |

## 学习路线

1. 先看 [AI系统设计.md](<AI系统设计.md>)，理解系统模块和数据流。
2. 再看 [模型路由.md](<模型路由.md>)，理解 AI 产品如何按任务选择模型和链路。
3. 接着看 [召回粗排精排重排.md](<召回粗排精排重排.md>)，理解 AI 产品如何从大量候选里找到、筛选和排序有效信息。
4. 最后看 [MLOps与模型生产化.md](<MLOps与模型生产化.md>)，理解模型上线后的版本、监控和迭代。
