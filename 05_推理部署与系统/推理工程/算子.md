# 算子

## 知识点解析

### 概述

算子是模型计算中的一个基本操作单元，例如矩阵乘法、卷积、LayerNorm、Softmax、Attention、激活函数等。

### 直观理解

神经网络看起来是一个完整模型，但真正执行时会被拆成很多计算步骤。

例如一个 Transformer block 里有：

```text
输入
  -> LayerNorm
  -> Q/K/V 线性变换
  -> Attention
  -> 残差连接
  -> LayerNorm
  -> FFN
  -> 激活函数
  -> 残差连接
```

这些步骤里的每个计算都可以称为算子。

### 常见算子

#### 基础数学算子

- Add：加法。
- Mul：乘法。
- MatMul：矩阵乘法。
- ReduceSum：求和。
- ReduceMean：求均值。
- Exp / Log / Sqrt：指数、对数、开方。

#### 神经网络算子

- Conv：卷积。
- Linear / GEMM：线性层，本质通常是矩阵乘法。
- ReLU / GELU / SiLU：激活函数。
- BatchNorm / LayerNorm / RMSNorm：归一化。
- Softmax：归一化为概率分布。
- Embedding：查表获取 token 向量。

#### Transformer 相关算子

- QKV Projection：生成 Query、Key、Value。
- Attention Score：计算 `QK^T`。
- Masked Softmax：带 mask 的 softmax。
- Attention Value：计算 attention 权重和 V 的加权和。
- RoPE：旋转位置编码。
- FFN：前馈网络。

### 算子为什么重要

模型推理和训练速度很大程度取决于算子的效率。

同一个模型结构，如果算子实现不同，速度和显存可能差很多。

例如：

- 普通 Attention 显存占用高。
- FlashAttention 通过优化计算和访存，显著提升速度、降低显存。
- 算子融合可以减少中间结果读写，提升吞吐。

### 算子融合是什么

算子融合是把多个连续小算子合并成一个更大的算子执行。

例如：

```text
MatMul -> BiasAdd -> GELU
```

可以融合成：

```text
Fused MatMul + Bias + GELU
```

好处：

- 减少 GPU kernel launch 次数。
- 减少中间 tensor 的显存读写。
- 提升吞吐和降低延迟。

### Kernel 和算子的区别

- 算子是逻辑上的计算操作。
- Kernel 是硬件上执行该操作的具体程序，通常指 GPU kernel。

例如 MatMul 是算子，CUDA 里具体执行 MatMul 的实现可以是一个或多个 kernel。
