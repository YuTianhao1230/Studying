# 生产系统设计

本目录整理把模型从离线实验接入真实服务所需的系统能力。推理引擎只解决模型如何执行；生产系统还要处理网关与鉴权、模型路由、容量和 SLO、可观测性、灰度发布、回滚、降级与持续运营。
