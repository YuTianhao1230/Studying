# 生产系统设计

本目录整理把模型从离线实验接入真实服务所需的系统能力。推理引擎只解决模型如何执行；生产系统还要处理网关与鉴权、模型路由、容量和 SLO、可观测性、灰度发布、回滚、降级与持续运营。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [AI系统设计.md](<AI系统设计.md>) | AI 应用的模块拆分、容量估算、SLO、链路设计、可靠性和工程权衡。 |
| [模型路由.md](<模型路由.md>) | 按任务、风险、输入模态、成本、延迟和系统状态选择模型或处理链路。 |
| [MLOps与模型生产化.md](<MLOps与模型生产化.md>) | 模型注册、部署、监控、灰度、回滚和持续迭代的生产化流程。 |

## 学习路线

1. 先看 [AI系统设计.md](<AI系统设计.md>)，理解系统模块和数据流。
2. 再看 [模型路由.md](<模型路由.md>)，理解 AI 产品如何按任务选择模型和链路。
3. 最后看 [MLOps与模型生产化.md](<MLOps与模型生产化.md>)，理解模型上线后的版本、监控和迭代。

候选检索与排序属于业务算法，统一从 [召回、粗排、精排与重排](<../../09_搜索推荐广告/召回粗排精排重排.md>)进入；生产系统只负责承载这些能力并满足延迟、容量和可靠性要求。
