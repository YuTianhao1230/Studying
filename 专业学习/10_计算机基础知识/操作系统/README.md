# 操作系统

本目录整理操作系统对 CPU、内存、文件、设备和并发执行的管理机制，覆盖进程与线程、同步与死锁、虚拟内存、调度、文件系统及磁盘可靠性。

建议先理解执行单元与资源隔离，再学习并发控制、内存管理和调度存储机制；具体原理、笔试考法与面试回答均由下列知识卡片承载。
