# 线性表

## 知识点解析

### 概述

本文整理线性结构的逻辑关系、存储方式、基本操作和典型题型，包括顺序表、链表、栈、队列，以及双指针、滑动窗口、前缀和、链表反转、环检测和括号匹配等常用解题方法。

### 线性表基础

线性表是由有限个同类型数据元素组成的有序序列。除首尾元素外，每个元素都有唯一前驱和唯一后继。这里的“有序”表示元素之间存在先后关系，不代表关键字已经按大小排序。

线性表描述的是逻辑结构，顺序表和链表是它的两种主要存储结构：

| 对比项 | 顺序表 | 链表 |
| --- | --- | --- |
| 存储方式 | 连续内存 | 节点分散，通过指针连接 |
| 按下标访问 | O(1) | O(n) |
| 查找指定值 | O(n) | O(n) |
| 已知位置插入删除 | 通常 O(n)，需要移动元素 | 已知节点后可 O(1) 修改指针 |
| 空间特点 | 可能预留容量，缓存局部性好 | 每个节点额外保存指针 |
| 扩容 | 动态数组可能整体搬迁 | 按需申请节点 |

### 数组

数组使用连续内存存储相同类型的元素，可以根据首地址和元素大小直接计算目标地址，因此支持 `O(1)` 随机访问。中间插入或删除通常要移动后续元素，时间复杂度为 `O(n)`。

#### 数组常见考法

- 给定操作序列，计算插入、删除或移动次数。
- 根据一维存储下标计算二维数组或特殊矩阵的位置。
- 连续子数组、子串的最长或最短区间。
- 区间和、区间增量和大量查询。
- 有序数组去重、两数之和、合并有序数组。

#### 特殊矩阵和压缩存储

特殊矩阵可以只存储必要元素，再通过逻辑坐标与一维数组下标的映射恢复访问。对称矩阵只需存上三角或下三角；三角矩阵只需存非零三角部分，并额外保存另一侧共享的常量；稀疏矩阵常用三元组 `(row, col, value)` 记录非零元素。

笔试计算映射下标时，要先确认存储上三角还是下三角、按行还是按列、数组下标从 0 还是从 1 开始，再统计目标元素之前完整行或列的元素数量。压缩存储节省空间，但通常不再支持按普通二维数组公式直接寻址。

#### 双指针

看到“有序数组”“首尾夹逼”“原地删除”“快慢位置”时优先考虑双指针。

- 对撞指针：左右两端向中间移动，例如有序数组两数之和。
- 快慢指针：快指针扫描，慢指针维护有效区间，例如原地去重。

解题关键是说明指针移动后排除了哪些不可能答案，即维护什么不变量。

#### 滑动窗口

看到“连续子数组或子串”“最长或最短”“满足某个约束”时考虑滑动窗口。

```text
右指针扩张窗口
  -> 更新窗口状态
  -> 条件不满足时移动左指针
  -> 在合法或刚满足条件时更新答案
```

滑动窗口通常要求窗口条件具有单调性。如果左指针右移后条件可能反复失控，就不能直接套模板。

#### 前缀和与差分

前缀和用于频繁查询区间和：

$$
\begin{aligned}
\mathrm{prefix}[i] &= \text{前 }i\text{ 个元素之和} \\
\text{区间 }[\mathrm{left}, \mathrm{right}]\text{ 的和}
&= \mathrm{prefix}[\mathrm{right} + 1] - \mathrm{prefix}[\mathrm{left}]
\end{aligned}
$$

差分用于频繁执行区间加减，最后一次性还原原数组：

```text
区间 [left, right] 加 value
diff[left] += value
diff[right + 1] -= value
```

记忆：**前缀和解决多次区间查询，差分解决多次区间修改。**

### 链表

链表由节点和指针组成，不要求节点在内存中连续，因此无法根据下标直接定位。链表的插入删除优势有一个前提：已经找到待操作节点或其前驱；如果还要先查找位置，总复杂度仍可能是 `O(n)`。

#### 常见链表

- 单链表：每个节点只保存后继指针。
- 双链表：同时保存前驱和后继，便于双向移动和删除当前节点。
- 循环链表：尾节点重新指向头节点，适合循环调度。
- 静态链表：使用数组下标模拟指针，常见于不支持指针的环境和概念题。

#### 链表常见考法

| 题型 | 识别方法 | 核心解法 |
| --- | --- | --- |
| 反转链表 | 要求改变指针方向 | 保存后继，再修改当前节点指针 |
| 合并有序链表 | 两条链表均有序 | 双指针选择较小节点 |
| 找中点 | 一次遍历、不能统计长度 | 快指针走两步，慢指针走一步 |
| 判断环 | 链表可能循环 | Floyd 快慢指针 |
| 找环入口 | 要求返回开始成环节点 | 相遇后一个指针回头，同速前进 |
| 删除倒数第 N 个 | 只允许一次遍历 | 快指针先走 N 步，再同步移动 |
| 相交链表 | 两链表共享尾部 | 双指针分别走完两条链表 |

#### 反转链表

反转时必须先保存后继节点，否则修改 `current.next` 后会丢失剩余链表：

```python
def reverse_list(head):
    previous = None
    current = head

    while current is not None:
        following = current.next
        current.next = previous
        previous = current
        current = following

    return previous
```

#### Floyd 环检测

快指针每次走两步，慢指针每次走一步：

- 如果没有环，快指针最终到达空节点。
- 如果有环，快慢指针一定会在环内相遇。
- 相遇后让一个指针回到头节点；若两个指针已经重合，则该节点就是环入口，否则让它们每次各走一步，下一次相遇的位置就是环入口。

入口定位可由同余关系严格推出。设头到环入口距离为 a，入口到首次相遇点沿环方向的距离为 b，其中 $0 \le b < c$，环长为 c；设首次相遇时慢指针共走了 t 步。快慢指针位于环中同一位置，因此：

$$
\begin{aligned}
t &\equiv a + b \pmod c \\
2t &\equiv a + b \pmod c
\end{aligned}
$$

两式相减得 $t \equiv 0 \pmod c$，再结合第一式可得 $a + b \equiv 0 \pmod c$，即 $a \equiv -b \pmod c$。因此，一个指针从头节点走 a 步恰好到达入口；另一个指针从相遇点走 a 步后，其相对入口的偏移为 $b + a \equiv 0 \pmod c$，也到达入口。

当 $a = 0$，环入口就是头节点，此时由同余式可得 $b = 0$。由于算法在指针至少移动一步后才检查相遇，首次相遇不是初始状态，而是慢指针走完整圈后的 $t = c$；进入入口定位阶段后，两个指针一开始就在入口。

#### 虚拟头节点

删除节点、合并链表等题目经常需要特殊处理头节点。增加一个指向头节点的虚拟节点，可以统一普通节点和头节点的操作，减少边界分支。

### 栈和队列

栈和队列是操作受限的线性表。

#### 栈

栈遵循后进先出，只允许在栈顶插入和删除。

常见考法：

- 判断给定出栈序列是否合法。
- 括号匹配。
- 中缀、前缀、后缀表达式转换和求值。
- 函数调用与递归栈。
- 单调栈求下一个更大元素或柱状图面积。

判断出栈序列时，可以按给定入栈顺序模拟：目标元素不在栈顶就继续入栈，无法继续入栈且栈顶仍不匹配，则该序列非法。

括号匹配的解法：

```text
遇到左括号：入栈
遇到右括号：检查栈顶是否为对应左括号
扫描结束：栈必须为空
```

中缀表达式转后缀表达式时，操作数直接输出，左括号入栈，右括号弹出到对应左括号；遇到运算符时，持续弹出优先级更高的栈顶运算符，同优先级是否弹出取决于结合性，最后再将当前运算符入栈。后缀表达式求值只需一个操作数栈：

```text
扫描 token：
  操作数 -> 入栈
  运算符 -> 先弹出右操作数，再弹出左操作数，计算后入栈
结束时栈中唯一元素就是结果
```

前缀表达式可从右向左用同样思路求值。最常见错误是减法、除法弹栈后颠倒左右操作数，以及忽略幂运算等右结合运算符。

#### 队列

队列遵循先进先出，在队尾入队、队头出队。适合处理按到达顺序执行的任务，也是 BFS 和树层序遍历的基础。

常见考法：

- 给定入队、出队操作，判断队头和队尾位置。
- 循环队列判空、判满和元素个数计算。
- 用两个栈实现队列，或用两个队列实现栈。
- BFS、层序遍历和多源扩散。
- 单调队列维护滑动窗口最大值。

两个栈实现队列时，一个栈 `in` 负责入队，另一个栈 `out` 负责出队；仅当 `out` 为空时，才把 `in` 全部倒入 `out`。每个元素最多在两个栈各进出一次，因此单次出队最坏 `O(n)`，一系列操作的摊销时间为 `O(1)`。

用队列实现栈时，可在每次入栈后把队列前面的旧元素依次移到队尾，使新元素位于队头，此后出栈直接出队；也可用两个队列搬运到只剩最后一个元素。前者入栈 `O(n)`、出栈 `O(1)`，后者可按实现把代价放在出栈阶段。

多源 BFS 要先把所有源点以距离 0 同时入队，再统一按层扩散。节点应在入队时标记访问，而不是出队时标记，否则同一节点可能被多个前驱重复入队。对无权图而言，队列中首次到达某节点的层数就是它到最近源点的最短距离，复杂度为 `O(V+E)`；网格图可写为 `O(rows*cols)`。

#### 循环队列

顺序队列直接移动队头会造成数组前部空间无法复用，循环队列通过取模让下标回到数组开头。

采用“牺牲一个存储单元”区分队空和队满时：

$$
\begin{aligned}
\text{队空：}\quad &\mathrm{front} = \mathrm{rear} \\
\text{队满：}\quad &(\mathrm{rear} + 1) \bmod \mathrm{capacity} = \mathrm{front} \\
\text{队列长度：}\quad &(\mathrm{rear} - \mathrm{front} + \mathrm{capacity}) \bmod \mathrm{capacity}
\end{aligned}
$$

必须先看题目如何定义 `front` 和 `rear`，以及是否牺牲一个单元；不同教材约定可能不同。

#### 双端队列与单调队列

双端队列允许在两端插入和删除。单调队列在双端队列中保持元素单调：

- 队列通常保存元素下标，便于判断元素是否已经离开窗口。
- 新元素入队时，删除队尾中不可能再成为答案的元素。
- 队首下标离开窗口时，将其移除。
- 队首始终是当前窗口最大值或最小值。

每个元素最多入队和出队一次，因此滑动窗口最值可以做到 `O(n)`。

## 笔试常考

| 题目描述 | 优先想到 | 解题关键 |
| --- | --- | --- |
| 有序数组找两个数 | 对撞双指针 | 根据和的大小移动一侧 |
| 连续区间满足约束 | 滑动窗口 | 维护窗口状态和合法性 |
| 多次查询区间和 | 前缀和 | 用两个前缀相减 |
| 多次执行区间加 | 差分 | 只修改区间边界 |
| 链表倒数第 N 个 | 快慢指针 | 快指针先走 N 步 |
| 链表是否有环、环入口 | Floyd 快慢指针 | 首次相遇满足 $a + b \equiv 0 \pmod c$ |
| 括号或嵌套结构 | 栈 | 最近未匹配元素优先处理 |
| 最少步数或层级扩散 | 队列/BFS | 按层处理状态 |
| 滑动窗口最大值 | 单调队列 | 队首保存当前最值 |

### 易错点

- 顺序表中“按位查找”是 `O(1)`，“按值查找”通常是 `O(n)`。
- 链表插入删除的 `O(1)` 建立在已经定位节点或前驱的基础上。
- Python `list.pop(0)` 需要移动后续元素，是 `O(n)`；队列应优先使用 `collections.deque`。
- 环形队列公式取决于是否牺牲空位，必须先确认题目约定。
- 双指针和滑动窗口不是同义词；滑动窗口要求维护连续区间。
- 前缀和适合静态区间查询；如果还频繁单点更新，应考虑树状数组或线段树。

## 面试应对

### 数组和链表怎么选？

回答思路：访问、插入删除、内存局部性。

回答模板：

数组适合随机访问和连续遍历，因为下标访问是 O(1)，缓存局部性也好，但中间插入删除需要移动元素。链表适合在已知节点附近频繁插入删除，只需要改指针，但查找位置需要 O(n)，缓存局部性也差。工程上读多查多通常用数组或动态数组，频繁插入删除且位置已知时才考虑链表。

### 如何判断链表是否有环，并找到环入口？

回答思路：先讲快慢指针判环，再说明相遇后的入口定位。

回答模板：

我会使用 Floyd 快慢指针。慢指针每次走一步，快指针每次走两步；如果链表无环，快指针会到达空节点，如果有环，两者一定会在环内相遇。设头节点到入口的距离为 a，入口到相遇点的环上距离为 b，环长为 c，慢指针首次相遇时走了 t 步。相遇位置满足 $t \equiv a + b \pmod c$ 和 $2t \equiv a + b \pmod c$，两式相减可得 $t \equiv 0 \pmod c$，进而得到 $a + b \equiv 0 \pmod c$。所以相遇后把一个指针放回头节点；若两个指针已经重合就直接返回，否则让它们每次各走一步，下一次相遇的位置就是入口。当 $a = 0$ 时，首次相遇发生在慢指针走完整圈的 $t = c$，而不是初始时刻；进入定位阶段时两个指针已经都在入口。整个过程时间复杂度是 O(n)，额外空间是 O(1)。

### 循环队列如何判断队空和队满？

回答思路：先说明需要区分两种状态，再给出一种常见约定。

回答模板：

如果循环队列只记录 `front` 和 `rear`，可以牺牲一个存储单元区分队空和队满。此时 $\mathrm{front} = \mathrm{rear}$ 表示队空，$(\mathrm{rear} + 1) \bmod \mathrm{capacity} = \mathrm{front}$ 表示队满，队列长度是 $(\mathrm{rear} - \mathrm{front} + \mathrm{capacity}) \bmod \mathrm{capacity}$。也可以额外维护元素个数或标志位，但回答前要先确认题目采用哪种约定。

### 单调队列为什么能在线性时间内求滑动窗口最值？

回答思路：说明队列保存的内容、队首和队尾的维护规则，以及摊销复杂度。

回答模板：

求滑动窗口最大值时，我会用双端队列保存元素下标，并让下标对应的值从队首到队尾单调递减。每加入一个新元素，先移除已经离开窗口的队首下标，再从队尾删除所有不大于新元素的下标，最后将新下标入队，此时队首就是当前窗口最大值。每个下标最多入队一次、出队一次，所以总时间复杂度是 O(n)，空间复杂度是 O(k)；求最小值时只需维护单调递增队列。
