# 二叉树遍历还原

## 知识点解析

### 概述

本文整理如何根据前序、中序、后序和层序遍历判断二叉树能否被唯一确定，以及对应的递归还原方法。

### 前提与合法性

除非题目另有说明，遍历还原通常默认所有节点值互异，并且给出的各序列长度相同、包含完全相同的节点集合。

- 节点值互异时，根在中序序列中的位置唯一，左右子树边界才能唯一划分。
- 序列长度、节点集合或递归区间不一致，说明输入不是同一棵树的合法遍历。
- 若节点值可重复，仅凭值序列无法唯一定位同值节点；必须额外提供节点标识或明确消歧规则。

### 常见遍历

- 前序遍历：根、左、右。
- 中序遍历：左、根、右。
- 后序遍历：左、右、根。
- 层序遍历：按层从左到右。

### 可以唯一确定二叉树的组合

| 遍历组合 | 是否能唯一确定 | 原因 |
| --- | --- | --- |
| 前序 + 中序 | 可以 | 前序确定根，中序划分左右子树 |
| 中序 + 后序 | 可以 | 后序确定根，中序划分左右子树 |
| 中序 + 层序 | 可以 | 层序先遇到根，中序划分左右子树 |

前序的第一个元素是根，后序的最后一个元素是根，层序中当前子树最先出现的元素是根。中序遍历能把根左边的节点划为左子树、根右边的节点划为右子树，所以只要有中序，再配合能确定根的遍历，通常就能递归还原唯一二叉树。

### 前序与中序的递归区间拆分

使用左闭右开区间表示子树。前序区间的第一个元素是根；根在中序区间中的位置把节点分成左右子树，左子树大小又能确定前序区间的分界：

```python
def build_tree(preorder, inorder):
    n = len(preorder)
    if n != len(inorder):
        raise ValueError("遍历序列长度不一致")
    index = {value: i for i, value in enumerate(inorder)}
    if len(index) != n or set(preorder) != set(inorder):
        raise ValueError("节点必须互异且集合一致")

    def construct(pre_left, pre_right, in_left, in_right):
        if pre_left == pre_right:
            return None
        root_value = preorder[pre_left]
        middle = index[root_value]
        if not in_left <= middle < in_right:
            raise ValueError("遍历序列不合法")
        left_size = middle - in_left

        root = TreeNode(root_value)
        root.left = construct(pre_left + 1, pre_left + 1 + left_size, in_left, middle)
        root.right = construct(pre_left + 1 + left_size, pre_right, middle + 1, in_right)
        return root

    return construct(0, n, 0, n)
```

索引表把“在中序中寻找根”从每层 `O(n)` 扫描降为均摊 `O(1)`，每个节点只创建一次，所以时间复杂度为 `O(n)`；索引表和返回的树占 `O(n)` 空间，递归栈占 `O(h)`。若每层都调用 `inorder.index` 或切片扫描，斜树输入最坏会达到 `O(n²)` 时间。

中序与后序的拆分完全对称：后序区间最后一个元素是根，中序位置给出 `left_size`，再按该大小划分后序的左右区间。中序与层序还原时，当前子树在层序中最先出现的节点是根，再按中序左右节点集合稳定筛分后续层序元素。

### 不能唯一确定二叉树的组合

一般情况下，**前序 + 后序不能唯一确定普通二叉树**。原因是前序和后序都能确定根，但不能可靠划分左右子树边界，尤其当某个节点只有一个孩子时，无法判断这个孩子是左孩子还是右孩子。

例如只有两个节点：

```text
前序：A B
后序：B A
```

可能是：

```text
  A
 /
B
```

也可能是：

```text
A
 \
  B
```

二者前序和后序完全相同，所以不能唯一确定。

### 特殊情况

如果题目明确说明是**满二叉树**，也就是每个节点要么有 0 个孩子，要么有 2 个孩子，那么前序 + 后序可以唯一确定。因为不存在“只有一个孩子但不知道在左还是右”的歧义。

## 笔试常考

- 唯一还原通常以节点值互异、序列长度和节点集合一致为前提。
- 前序 + 中序能唯一确定二叉树；使用中序索引表和递归区间可在 `O(n)` 时间完成。
- 不建索引表而反复扫描中序位置，斜树输入最坏为 `O(n²)`。
- 中序 + 后序能唯一确定二叉树。
- 中序 + 层序能唯一确定二叉树。
- 前序 + 后序一般不能唯一确定普通二叉树。
- 前序 + 后序在满二叉树条件下可以唯一确定。
- 只有一种遍历序列不能唯一确定二叉树。

## 面试应对

### 哪些遍历组合可以唯一确定二叉树？

回答思路：先给结论，再解释中序的作用。

回答模板：

能唯一确定普通二叉树的常见组合有前序加中序、中序加后序、中序加层序。原因是前序第一个是根，后序最后一个是根，层序里当前子树最先出现的是根；而中序可以根据根的位置把节点划分成左子树和右子树，然后递归还原。一般前序加后序不能唯一确定普通二叉树，因为当某个节点只有一个孩子时，无法判断这个孩子在左边还是右边。

### 为什么前序和后序不能唯一确定普通二叉树？

回答思路：说明无法划分左右子树，并举单孩子例子。

回答模板：

前序和后序都能确定根节点，但缺少中序时，无法稳定划分左右子树。比如前序是 `A B`，后序是 `B A`，这棵树可以是 A 的左孩子是 B，也可以是 A 的右孩子是 B，两种结构的前序和后序完全一样。所以对于普通二叉树，前序加后序不能唯一确定；只有题目限制为满二叉树时，前序加后序才可以唯一确定。

### 如何将前序加中序还原优化到 O(n)？

回答思路：说明索引表、递归区间和每个节点只处理一次。

回答模板：

我会先把中序序列的“节点值到下标”建立成哈希表，再用左闭右开的下标区间递归，不创建数组切片。每次由前序区间首元素确定根，通过哈希表在 O(1) 时间找到根的中序位置，用左子树大小同步划分前序区间。这样每个节点只创建一次，总时间是 O(n)，索引表是 O(n)，递归栈是 O(h)。这个结论要求节点值互异；若有重复值，还需要额外标识来消歧。
