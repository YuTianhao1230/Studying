# 六大行与三大运营商AI岗笔试专项报告

核验日期：2026-10-06。考察范围为2022—2026年公开招聘公告、考试通知和可交叉核对的考生笔经。

## 先看结论

AI岗的笔试通常不是纯AI卷，而是以下三类之一：

1. **银行统一科技卷**：行测、英语、时政/企业知识、408和数据库为主体，机器学习或深度学习只占少量选择题。
2. **银行研发中心专项卷**：计算机基础、SQL和编程为主体，行测很少甚至不考；农行研发中心、建信金科等更接近这一类。
3. **运营商专业公司卷**：行测与技术题并存，研究院、数科、云公司可能追加2—3道编程题，近两年开始出现Transformer、Agent等AI题。

因此，AI岗备考优先级不是“深度学习 > 一切”，而是：

> 行测速度 + 408/数据库/Linux + Python/SQL + 基础算法编程 > 机器学习基础 > 深度学习与大模型专题。

### 行测中可以降级准备的内容

- **银行AI岗**：空间折叠、立体旋转不是稳定独立模块；有余力再练。
- **运营商AI岗**：只有中国移动应重点准备空间能力；电信、联通通常不单列。
- **纯公务员式常识判断**：文史地理、科技生活不是银行科技卷主线。银行更常见时政、金融常识和企业知识，电信、联通是否考公共常识取决于单位。
- **资料分析**：六大行普遍不能放弃；中国移动近年有的批次不单列，电信、联通则随单位变化。
- **思维策略**：工行、农行、中行、邮储较值得准备；建行、交行可能并入数量或逻辑；运营商除移动外不稳定。

## 九家单位AI岗具体判断

### 工商银行

**行测**

- 稳定考：言语、数字运算、逻辑推理、资料分析、思维策略。
- 常见：图形推理、任务情境或决策分析。
- 通常不单列：空间能力、纯公务员式常识。

2023届科技菁英笔经记录了言语7题、数字运算15题、逻辑20题、思维策略15题、资料分析15题；2024和2025届笔经的模块仍一致，说明五类EPI稳定。

**技术**

- 高频：C/C++/Java/Python基础、数据结构、数据库、操作系统、计算机网络、Linux。
- 常见：组成原理、软件工程、测试、信息安全。
- 偶尔：人工智能、机器学习基本概念。
- 分行科技菁英近年多为约20道计算机选择题，通常没有编程。
- 软件开发中心、业务研发中心等专业机构可能另设编程或专业测评，不能用分行卷判断。

**AI岗策略**：先保证EPI和408，不要把时间主要押在深度学习偏题上。

### 农业银行

需区分 **分行科技岗** 与 **研发中心**。

**分行科技岗行测**

- 稳定考：言语、数量、逻辑、资料、思维策略。
- 常见：图形推理。
- 通常不单列：空间能力。

**研发中心行测**

- 仅少量数字运算和逻辑/思维题，部分批次约10题。
- 有笔经记录某批次不考完整行测，只保留少量数学或逻辑题。

**技术**

- 高频：SQL与数据库原理、数据结构、计算机网络、Java/C代码阅读、软件测试。
- 常见：操作系统、Linux、新技术。
- 编程：研发中心近年较稳定出现3题，常见字符串、数组、排序、简单数学、模拟等，通常为LeetCode简单到中等。
- AI专项：笔试中机器学习、深度学习未形成稳定大模块；算法岗的AI深度更多体现在面试和项目追问。

**AI岗策略**：报研发中心时优先SQL、数据结构和编程；报省分行科技岗时仍须完整准备公共卷。

### 中国银行

**行测**

- 稳定考：言语、数字运算、逻辑推理、思维策略、资料/图表分析。
- 常见：图形推理。
- 同一职业能力模块还常混入时政、金融常识和中行知识。
- 通常不单列：空间能力。

2022—2025年多份信息科技笔经均记录职业能力约70题、60分钟，五类行测结构高度稳定。

**技术**

- 高频：操作系统、计算机网络、数据结构、数据库、组成原理。
- 常见：Java/C、Linux、软件工程、软件测试、密码学与信息安全。
- 偶尔：机器学习、人工智能、大数据、GFS、Matlab等。
- 统一信科卷通常是大量单选、多选和不定项，不直接编程。
- 软件中心等单位可能在统一笔试后追加3—4道编程能力测评。

**AI岗策略**：中行信科的特点是“广而杂”，408完整度比AI深度更重要，多选题要练概念边界。

### 建设银行

**行测**

- 稳定考：言语、数量、逻辑、资料分析。
- 常见：图形推理。
- 偶尔：数字推理或思维策略，通常并入数量/逻辑。
- 通常不单列：空间能力。

2023年信息技术类笔经记录言语20题、数学15题、逻辑30题、资料15题，说明四大核心模块都不能放弃。

**技术**

官方信息技术类范围明确包括：

- 计算机网络、操作系统。
- 软件工程、信息安全、设计模式。
- 数据结构与算法。
- 开发语言语法、数据库语法。

公开笔经还出现组成原理、深度学习、Hadoop、测试等。普通信息技术类卷以选择题为主；建信金科算法类可能另考2道算法编程题。

**AI岗策略**：报建行直属机构或分行时选信息技术类；报建信金科时额外准备编程，但仍以通用计算机基础为底盘。

### 交通银行

**行测**

- 总行/分行科技岗常见：言语、数量、逻辑、图形、资料分析。
- 思维策略偶尔出现。
- 交银金科、软件中心独立专业测评可能只保留少量行测，甚至不单列。
- 空间能力通常不单列。

**技术**

- 高频：数据结构与算法、数据库、操作系统、计算机网络、编程语言。
- 常见：SQL编程、统计学、概率论、信息安全、Java框架。
- 偶尔：机器学习、Web、金融知识。
- 交银金科公开笔经出现选择/判断、SQL题和算法编程题；广东下属分行金融科技岗出现数据库、Java、Web、通信协议和机器学习选择题。

**AI岗策略**：总行数据/AI方向要补概率统计；交银金科或软件中心要把SQL和基础编程提升到高优先级。

### 邮储银行

**行测**

- 稳定考：言语、数量、逻辑、思维策略、资料分析。
- 常见：图形推理。
- 通常不单列：空间能力。

**技术**

- 波动最大。2022年部分科技岗有Java、SQL等专业题；2023年部分总行信息科技卷几乎以金融、时政、邮储知识为主，仅有少量金融科技、概率统计或程序填空。
- 另一些研发中心笔经记录约20%的Java、SQL和计算机基础。
- 编程题在统一笔试中不稳定，可能改为后续“计算机专业技能展示”。
- AI/深度学习通常不是统一卷重点，项目相关内容更可能在面试追问。

**AI岗策略**：不能因报AI岗就放弃金融经济和邮储知识；公共卷优先，收到专业技能展示通知后再冲刺编程。

### 中国移动

需区分 **集团统一笔试** 与 **专业公司加试**。

**集团统考行测**

- 高频：言语理解、数理运用、逻辑推理、图形推理、空间能力。
- 常见：数字推理、创新能力。
- 资料分析：年度差异较大，部分早期批次出现，近年有批次不单列，应做基础训练但不必重押。
- 通常不考：银行式经济金融、完整408专业卷。

**技术**

- 集团统一卷中的技术题通常很少，AI算法岗也可能先做同一套行测和企业知识卷。
- 中国移动研究院、杭研、成研等可能追加专业测评。
- 2025年中移杭研研发方向加试包括SQL、运维、Python/C++等基础选择和2道编程题。
- AI岗位JD强调Python、SQL、统计、机器学习、深度学习、Spark/Hive等，但JD要求不等于统一笔试题量。

**AI岗策略**：集团统考先攻逻辑、空间和数理；研究院/专业公司再准备Python、SQL、Linux、大数据和编程。

### 中国电信

**行测**

- 常见：言语、数字运算/数字推理、逻辑推理。
- 图形、资料分析、常识：各省或专业公司差异较大。
- 通常不单列：移动式空间能力和创新能力。

官方公告明确只有部分单位参加集团统考，其余由分子公司自行组织，因此不存在全国统一的“必考/不考”清单。

**技术**

- 高频：操作系统、网络、数据结构、数据库、Linux。
- 云网岗常见：存储、虚拟化、云计算、大数据、网络协议和信息安全。
- 通信岗常见：通信原理、移动通信、光通信、信号与系统、数电模电。
- AI岗近年出现：Python、概率统计、线性代数、机器学习、Transformer。
- 编程常见于研究院、数科、天翼云和部分省公司，通常2—3题，范围包括数组、字符串、哈希、链表、图/BFS、前缀和与差分。

**AI岗策略**：九家中应把编程准备得最接近互联网技术岗的一类，同时补云网基础和电信AI业务。

### 中国联通

**行测**

- 常见：言语和逻辑。
- 数量、图形、资料分析：依分子公司，不能视为统一必考。
- 通常不单列：空间能力、创新能力。

**技术**

- 高频：数据结构、操作系统、计算机网络、数据库、Linux、编程语言。
- AI岗常见：Python基础、机器学习基本概念；数据岗还会涉及统计、SQL和数据挖掘。
- 软件研究院近年常见3道编程题，题目多为数组、排序、去重、树遍历等基础算法。
- 2025年一则AI相关岗位笔经记录“行测 + AI/Python选择 + 3道编程”，但只能代表该单位和批次。

**AI岗策略**：先查具体分子公司。联通软件研究院、联通数科等需要准备编程；普通省公司则可能更偏行测和岗位基础。

## AI技术知识分层

### 第一优先级：九家通用底盘

| 领域 | 必备内容 |
| --- | --- |
| 数据结构 | 数组、链表、栈、队列、树、图、哈希表、堆 |
| 算法 | 排序、查找、复杂度、递归、贪心、BFS/DFS、基础动态规划 |
| 操作系统 | 进程线程、调度、同步互斥、死锁、虚拟内存、分页、文件系统 |
| 网络 | OSI/TCP-IP、TCP/UDP、HTTP/HTTPS、DNS、IP与子网、常见设备 |
| 数据库 | SQL、连接、聚合、子查询、索引、B+树、事务、隔离级别、范式 |
| 编程语言 | Python语法与容器；同时能读懂基础C/C++/Java代码 |
| Linux | 文件权限、进程、常用命令、Shell基础 |

### 第二优先级：AI岗高频基础

- 监督、无监督和强化学习的区别。
- 线性/逻辑回归、决策树、随机森林、GBDT/XGBoost、SVM、KNN、朴素贝叶斯、K-Means、PCA。
- 过拟合与欠拟合、偏差方差、L1/L2、交叉验证、数据泄漏。
- Accuracy、Precision、Recall、F1、ROC-AUC、混淆矩阵；回归的MSE、RMSE、R²。
- 数据清洗、缺失值、标准化、特征选择和类别不平衡。
- 概率统计：条件概率、贝叶斯、常见分布、期望方差、假设检验。
- Python数据工具：NumPy、Pandas、scikit-learn；SQL必须能手写。

### 第三优先级：近年偶尔出现

- CNN、RNN/LSTM、Transformer、自注意力、Q/K/V。
- 激活函数、损失函数、反向传播、SGD/Adam、Dropout、BN/LN。
- PyTorch/TensorFlow基础、训练与推理差异。
- Hadoop、HDFS、MapReduce、Spark、Hive。
- 大模型基础、LoRA/微调、RAG、Agent、模型部署与AI安全。

这些内容在运营商研究院、数科、云公司和明确AI专项岗位中优先级更高；在银行统一科技卷中通常只占少量概念题。

## 编程题准备边界

| 目标单位 | 编程题风险 | 建议准备深度 |
| --- | --- | --- |
| 工行分行科技菁英 | 低到中 | 会基础算法；等待是否有专业机构加试 |
| 农行研发中心 | 高 | 重点刷LeetCode简单和部分中等 |
| 中行普通信科卷 | 低 | 选择题为主 |
| 中行软件中心 | 高 | 准备后续3—4题编程测评 |
| 建行信息技术类 | 低到中 | 普通卷选择题为主 |
| 建信金科算法类 | 高 | 树、贪心、遍历、数组字符串 |
| 交行总行/分行科技岗 | 中 | SQL、统计和基础算法 |
| 交银金科/软件中心 | 高 | SQL题 + 1—3道算法题 |
| 邮储统一科技卷 | 低到中 | 以通知为准，防后续技能展示 |
| 中国移动集团统考 | 低 | 重点行测 |
| 中移动研究院/专业公司 | 高 | 基础选择 + 2道左右编程 |
| 中国电信研究院/数科/天翼云 | 高 | 2—3题，至少覆盖图与差分 |
| 中国联通软件研究院/数科 | 高 | 常见3题，简单到中等 |

建议至少掌握：

1. 数组、字符串、哈希、排序、双指针。
2. 链表、栈、队列、二叉树遍历。
3. BFS/DFS、最短路基础。
4. 前缀和、差分、滑动窗口。
5. 简单贪心和一维动态规划。
6. SQL的JOIN、GROUP BY、子查询、窗口函数。

## 针对AI岗的复习时间分配

若同时投递六大行和三大运营商：

| 模块 | 时间占比 |
| --- | ---: |
| 行测限时训练 | 25% |
| 408 + 数据库 + Linux | 25% |
| Python、SQL与算法编程 | 25% |
| 机器学习、统计与数据处理 | 15% |
| 深度学习、Transformer与大模型 | 5% |
| 企业文化、行业动态、金融基础 | 5% |

临考时按单位调整：

- 工行、中行、建行、邮储：提高公共卷和英语比重。
- 农行研发、建信金科、交银金科：提高SQL和编程比重。
- 中国移动集团统考：提高逻辑、空间、数理比重。
- 电信、联通专业公司：提高编程、网络/Linux和AI基础比重。
