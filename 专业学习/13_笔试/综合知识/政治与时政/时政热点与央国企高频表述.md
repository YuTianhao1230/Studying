# 时政热点与央国企高频表述

## 知识点解析

### 概述

时政热点主要考查重大会议、重要政策、年度经济部署、科技成就、央国企改革、核心价值观、双碳目标和国家安全等内容。与常识判断不同，时政具有明显时效性，需要在考前集中刷新。央国企笔试尤其偏好政策原文、固定提法、重大科技“首次/最高/最新”表述和企业文化相关内容。

### 时效口径

本卡片核验日期为2026-10-05。年度目标与历史会议分别注明年份；2026年度部署以政府工作报告、中央经济工作会议、中央一号文件及国资委公开资料为依据。题目指定历史年份时，应使用该年份文件。

### 2026年度政策导航

本卡只维护年度优先级、复习线索和更新入口。会议目标、原则、新质生产力、高质量发展、宏观政策、中央一号文件及金融“五篇大文章”的完整定义统一见[会议政策与新质生产力](<会议政策与新质生产力.md#会议政策与新质生产力>)。

| 年度入口 | 2026年复习重点 | 更新与辨析 |
| --- | --- | --- |
| “十五五”开局 | 2026年是“十五五”规划开局之年；关注高质量发展、改革创新、统筹发展和安全 | “十五五”原则与二十届三中全会改革原则分开记 |
| [2025年中央经济工作会议](https://www.gov.cn/yaowen/liebiao/202512/content_7050963.htm) | 直接部署2026年工作；八项重点任务以“内需、创新、改革、开放、协调、双碳、民生、底线”为索引 | 不与2024年“五个必须统筹好”串用 |
| [2026年政府工作报告](https://www.gov.cn/yaowen/liebiao/202603/content_7062625.htm) | 优先复习经济增长、就业、物价、粮食和降碳等主要预期目标，具体数值见权威卡 | 区分2025年工作回顾与2026年预期目标 |
| 财政与货币政策 | 更加积极的财政政策、适度宽松的货币政策；持续支持“两重”“两新” | “两重”不是设备更新和消费品以旧换新 |
| [2026年中央一号文件](https://www.gov.cn/yaowen/liebiao/202602/content_7056929.htm) | 锚定农业农村现代化、扎实推进乡村全面振兴 | 不沿用2025年文件标题；涉农企业题仍以企业官网定位为准 |
| 金融“五篇大文章” | 科技、绿色、普惠、养老、数字金融 | 名称、重点和协同关系见权威卡；岗位题再结合目标机构 |

考前刷新顺序：先核对国务院与新华社年度文件，再看主管部门和目标企业官网；记录文件发布日期、适用年份、发布主体和原文关键词。年度数字和政策定义只在权威卡维护，本卡仅记录复习优先级与更新入口。

### 重大科技成就

2026年政府工作报告回顾了以下**2025年进展**。复习时把“事件发生年”和“资料发布年”分开，不把项目规划或预测写成已完成事实。

| 领域 | 高频表述 |
| --- | --- |
| 深空 | 天问二号开启“追星”之旅 |
| 导航 | 北斗规模应用全面拓展 |
| 能源工程 | 雅下水电工程开工建设，不能把“开工”写成“全面投产” |
| 舰船装备 | 首艘国产电磁弹射型航母福建舰正式入列 |
| 人工智能 | 国产大模型引领全球开源生态，题目若问具体模型版本需另查发布主体 |

科技成就题重点核对“首次”的地域范围、“开工/投产/发射/返回”的事件阶段和发生日期。上述资料不代表2026年全年科技事件清单。

### 央国企改革重点

总要求：

```text
推动国有资本和国有企业做强做优做大，增强核心功能、提升核心竞争力。
```

2026 央企目标：“两个确保、两个力争”：

- 确保增加值持续增长，力争与 GDP 增速匹配。
- 确保“一利五率”稳中向好，力争总体优化。

“一利五率”：

| 指标 | 内容 |
| --- | --- |
| 一利 | 利润总额 |
| 五率 | 营业收现率、净资产收益率、研发经费投入强度、全员劳动生产率、资产负债率 |

2026年公开口径使用“营业收现率”。旧资料中的“营业现金比率”名称及分子定义不同，不能直接作为同一公式使用；做历史题应以题目年份为准。

“三个集中”：

- 向关系国家安全、国民经济命脉的重要行业和关键领域集中。
- 向关系国计民生的公共服务、应急能力、公益性领域等集中。
- 向前瞻性战略性新兴产业集中。

“五个价值”：

- 增加值。
- 功能价值。
- 经济增加值。
- 战略性新兴产业收入和增加值占比。
- 品牌价值。

国企高频表述：

- 做强做优做大。
- 增强核心功能、提升核心竞争力。
- 因地制宜发展新质生产力。
- 两个毫不动摇。

来源：[国资委转载：两个万亿元，标注国资央企创新刻度（2026-02-03）](http://www.sasac.gov.cn/n4470048/n35313464/n35346844/n35347362/c35340050/content.html)。国资委监管央企的经营指标不能直接当作六大行统一考核口径。

### 固定政策表述入口

社会主义核心价值观、双碳目标和总体国家安全观属于稳定政策知识，不随年度热点重复维护，统一见[会议政策与新质生产力](<会议政策与新质生产力.md#常用固定政策表述>)。

### 央国企企业文化备考法

目标公司三看：

1. 官网“关于我们/企业文化/社会责任”页面。
2. 近期年报。
3. 重大新闻，包括重组、国家战略任务、获奖、重大项目。

必背四类：

- 企业文化与愿景使命。
- 党和国家重大会议。
- 行业知识，例如通信、能源、金融、交通等。
- 重大科技与经济政策热点。
