# 中国联通

## 概述

中国联通是中央企业体系下的电信运营商，业务覆盖公众通信、家庭服务、政企数字化、云与算力、数据和人工智能应用等领域。其近年发展重点是依托连接能力，向数字化综合服务商转型。[U1] [U4]

资料核验日期：2026-10-17。使命、愿景、作风以当前官网企业文化页为准，战略与经营方向结合2026年中期报告；品牌和服务补充2026年9月公开发布内容。六项核心价值观尚未在本次可核验的较新官方材料中找到完整重列，保留2024年报及集团2024年可持续发展报告的明确原文，不能称为2026年新发布版本。[U10] [U11] [U12] [U13] [U14]

## 身份与沿革

### 四个容易混淆的主体

| 层次 | 法定名称 | 区分要点 |
| --- | --- | --- |
| 集团 | 中国联合网络通信集团有限公司 | 集团母公司，不等于A股或港股上市公司。[U1] [U8] |
| A股上市公司 | 中国联合网络通信股份有限公司 | 境内注册的上市主体，股票代码600050。[U1] [U6] |
| 港股上市公司 | 中国联合网络通信（香港）股份有限公司 | 香港注册的上市主体，股票代码00762。[U1] [U3] |
| 境内运营公司 | 中国联合网络通信有限公司 | 港股公司的全资附属公司，承担境内运营业务；名称中没有“股份”二字。[U1] |

A股公司和港股公司是不同法人。A股公司通过控股中国联通（BVI）有限公司间接持有港股公司股权，并保持对港股公司的实际控制权。不能简化成“同一家中国联通公司同时发行A股和H股”，也不能把间接持股写成直接持股。BVI（British Virgin Islands，英属维尔京群岛）是中间持股实体名称中的注册地标识。[U11]

年报中的“本公司”“本集团”必须按该报告定义理解。例如港股年报的“本公司”指港股上市主体，“本集团”通常指该公司及其附属公司，不是所有叫“中国联通”的法人主体的统称。[U1]

### 关键时间

| 时间 | 事件 | 所属层次 |
| --- | --- | --- |
| 1994年 | 中国联通的历史起点。 | 企业历史，不是当前港股公司的注册日期。[U9] |
| 2000-02-08 | 港股上市主体在香港注册成立。 | 港股公司。[U1] [U3] |
| 2000-06-22 | 港股上市主体在香港联合交易所上市。 | 港股公司。[U1] [U3] |
| 2008-10-15 | 港股公司与中国网通集团（香港）有限公司完成合并。 | 上市主体层面的合并，不与集团组建日期混写。[U1] [U3] |
| 2009-01-06 | 中国联合网络通信集团有限公司组建。 | 原联通与原网通重组后的集团层面节点。[U7] [U12] |
| 2017年 | 推进混合所有制改革，通过A股公司引入战略投资者。 | 涉及股份发行、股份转让等安排；混改不是将港股和A股合成同一法人。[U1] |
| 2021-05-18 | 港股公司在纽约证券交易所交易的美国存托证券退市。 | 不能继续把旧材料中的三地上市状态当成现状。[U3] |

“1994年成立”“2000年上市”“2008年合并”“2009年组建”可以同时成立，但回答的是不同主体、不同性质的历史事件。2017年混改也不等于集团不再属于中央企业体系。

## 企业文化与服务

### 当前官网列示的使命、愿景与作风

以下依据截至核验日的官网“企业文化”页，与2025年年度报告文化页一致。[U10] [U1]

| 类别 | 官方表述 | 理解要点 |
| --- | --- | --- |
| 企业使命 | 数字信息运营服务国家队、数字技术融合创新排头兵 | 同时强调数字信息服务责任与数字技术融合创新。 |
| 企业愿景 | 具有全球竞争力的世界一流科技服务企业 | 不能只概括为传统通信管道运营商。 |
| 企业作风 | 严、实、精、细、快 | 属于工作作风要求，不应改标为核心价值观。 |

“国家队”“排头兵”描述的是企业在数字信息服务与技术创新中的角色，不是独立业务品牌，也不是客服口号。当前公司简介及2026年中期报告另用“信息通信事业国家队、主力军”概括企业担当；该表述与文化页的正式使命应按字段分别识别，不能互相替换。[U3] [U4] [U10]

### 核心价值观与经营管理理念的可核验口径

2024年年度报告“企业文化”页明确列出六项核心价值观，集团2024年可持续发展报告亦明确表示“持续弘扬”这六项价值观：[U2] [U12]

| 官方表述 | 理解侧重 |
| --- | --- |
| 客户为本 | 以客户需求和客户价值为出发点。 |
| 员工为根 | 重视员工及其能力对企业发展的支撑。 |
| 服务为上 | 将服务质量与服务价值放在重要位置。 |
| 创新为魂 | 通过创新推动企业发展。 |
| 奋斗为荣 | 倡导担当与实干。 |
| 清廉为基 | 强调廉洁与规范经营的基础作用。 |

2024年年报同页还列出经营管理理念：“为客户创造价值”“市场和创新双轮驱动”“一个联通，一体化能力聚合，一体化运营服务”。[U2]

截至核验日，当前官网文化页及2025年报文化页未完整重列这六项价值观与三条经营管理理念；不能据此判定它们已废止，也不能断言其已获2026年新版本重新确认。记忆具体原文时保留这一来源边界。较新的2026年中期报告明确强调价值经营、“一个中国联通”及“精管理、强运营”，但没有将这些话另行列为新版核心价值观或新版经营管理理念。[U10] [U1] [U4]

### 服务导向与品牌表达

“为客户创造价值”在2024年报中属于经营管理理念。[U2] 2025年报还使用“精准找到需求、快速弄懂需求、高效满足需求”等客户服务表达。[U1]

国资委2026-03-18品牌资料回顾，中国联通于2019年提出“创新与智慧同行”品牌语，并明确称其“沿用至今”；这个“至今”对应该资料发布日期。它属于品牌传播表达，不等于企业使命、愿景或六项核心价值观。[U9]

2026年9月公开发布的服务承诺继续以“百倍用心，十分满意”为服务主题；“向智同行 连接算力新生态”是2026年合作伙伴大会主题，不能直接当作替代上述品牌语的新企业口号。[U13] [U14]

### 2026年9月升级的五大窗口服务承诺

中国联通升级发布五大窗口20项对外承诺，每个窗口四项。以下名称与承诺依据《人民邮电报》2026-09-18的完整发布报道，属于最新服务要求，不属于核心价值观。[U13]

| 服务窗口 | 服务名称 | 四项承诺 |
| --- | --- | --- |
| 营业厅 | 百倍用心 | 受理知情同意；诚信放心服务；事项一站完成；问题当席解决 |
| 政企客户经理 | 数智专家 | 需求快速响应；方案精准定制；业务快速交付；匠心专业服务 |
| 10010热线 | 一号通解 | 来电应接尽接；问题应解尽解；主动暖心服务；智能便捷高效 |
| 智家工程师 | 专业到家 | 预约高效响应；及时履约上门；“480”限时保障；惠民延伸服务 |
| 中国联通APP | 一屏速办 | 查询清晰易懂；资费全量公示；办理足不出户；AI智能推荐 |

“480”指修障4小时、装移机8小时；工程师在工作时间30分钟内回应预约，特殊情况提前告知。10010提供7×24小时人工或自助服务，65岁及以上老年用户一键直入人工。营业厅排队平均等候时长不超过15分钟。具体受理范围、工作时段及履约条件应按正式承诺和当地执行说明理解，不能把这些时间合并成所有业务均无条件适用的时限。[U13]

APP（Application，应用程序）在此指中国联通客户端；AI（Artificial Intelligence，人工智能）用于智能服务与产品能力。

## 业务品牌与服务号码

2025年报区分企业品牌、客户品牌和产品品牌；2026年中期报告延续品牌重塑。2026年9月信息通信展报道将其概括为“1+3+5”品牌体系：企业品牌、三类客户品牌、五大产品品牌。星罗属于算力调度平台，不计入这五大产品品牌。[U1] [U4] [U15]

| 名称 | 层次与定位 | 易混点 |
| --- | --- | --- |
| 中国联通 / UniCom | 2025年报列示的企业品牌。 | 企业品牌不等于某一个具体上市法人的完整名称。 |
| 联通智家 | 家庭场景客户品牌。 | 不等于单项宽带资费或一个云计算平台。 |
| 联通沃派 | 客户品牌，侧重年轻群体相关服务。 | “沃派”不是集团名称或人工智能模型名称。 |
| 联通慧商 | 2025年报列示的客户品牌。 | 具体产品、资费及适用客户以业务资料为准，不仅凭名称扩大其范围。 |
| 联通云 | 云服务相关产品品牌。 | 与天翼云、移动云分属不同运营商。 |
| 联通元景 | 大模型及MaaS相关产品品牌。 | MaaS（Model as a Service，模型即服务）在此指模型服务，不是移动通信客户品牌。 |
| 联通星罗 | 算力调度相关平台名称。 | 与元景的模型能力层次不同。 |
| 联通云犀 | 产品品牌，提供工作流智能体等智能应用能力。 | 不应与联通云这一云品牌混为同名产品。 |
| 联通格物 | 产品品牌，涵盖工业互联网与具身智能等平台、应用能力。 | 属于行业数字化能力，不是公众客服号码。 |
| 联通墨攻 | 安全相关产品品牌，以安全运营服务平台等能力为支撑。 | 不能因有独立安全品牌，就把企业安全职责全部等同于该产品。 |
| 10010 | 内地公众客户服务热线。 | 来自官方联系页面；与投资者关系联系电话不是同一用途。[U5] |

“沃”相关名称常见于中国联通历史品牌材料，但不能据此把不同时期的全部品牌矩阵都简化成一个“沃”字。学习时应保留企业、客户、产品、平台的层次。

2026年9月已公开展示联通云8.0、联通墨攻3.0、联通元景数字员工等较新能力；它们是上述产品品牌下的版本或应用，不构成新的企业使命或客户品牌。品牌矩阵不等于全部在售产品目录。[U15]

## 战略内涵

### 发展主基调与转型方向

当前官网企业战略原文为：“坚持守正创新、坚持主责主业，以‘守正创新、行稳致远’为公司‘十五五’时期发展主基调，聚焦‘连接’‘算力’‘服务’‘安全’核心赛道。”[U10] 2026年中期报告延续上述布局，明确向数字化综合服务商提能升级；当前公司简介明确表述从“基础管道提供商”向“数字化综合服务商”转变。[U4] [U3]

| 表述 | 结合业务内容的理解 |
| --- | --- |
| 守正创新 | 在履行基础通信与信息服务责任的同时，推进技术、产品和服务创新。 |
| 行稳致远 | 强调稳健经营与长期发展，不能仅以短期规模扩张解释。 |
| 数字化综合服务商 | 在连接业务基础上，组合算力、数据、模型、应用与服务能力，解决客户的综合数字化需求。 |

以上是理解层面的归纳，不替代年报中的正式表述。“发展主基调”“企业使命”“业务赛道”“转型方向”分别回答不同问题。

### 四大核心赛道

| 赛道 | 业务位置 | 辨析 |
| --- | --- | --- |
| 连接 | 移动、宽带及相关连接能力构成客户服务基础。 | 不只指手机语音或单一接入方式。 |
| 算力 | 云、计算资源、调度及模型相关能力。 | 不只是购买服务器，也不与某一个模型品牌等同。 |
| 服务 | 将能力转化为客户和行业的综合解决方案及服务体验。 | 不只是客服热线或售后接听。 |
| 安全 | 为网络、数据、平台和应用提供安全保障与相关服务。 | 既有安全产品，也有跨业务的安全要求。 |

四大赛道是经营发展重点，不代表四个完全隔离的收入科目。联通星罗、元景、云犀、格物、墨攻等体现不同层次的能力，不能将品牌数量与赛道数量机械对应。[U1] [U4]

### 2026年的发展与改革表达

2026年中期报告以“健康、鲜活、强劲”组织发展方向，并使用以下改革表达：[U4]

| 表述 | 中期报告对应内容 |
| --- | --- |
| 健康 | 坚持价值经营，统筹当前与长远，提升经营韧性与可持续性 |
| 鲜活 | 推进组织架构、产品体系和经营机制变革，提升运营与服务效能 |
| 强劲 | 立足主责主业、服务国家战略、满足客户需求，向数字化综合服务商提能升级 |
| 唯合不摧 | 深化机构改革，坚持“一个中国联通”，围绕“精管理、强运营”聚合能力 |
| 唯快不破 | 优化产品模式，推行“拖拉拽”等差异化产品与智能化应用 |
| 唯大不阻 | 创新Token运营，完善创造、转运、清洗、存放、应用的全流程运营模式 |

Token（词元）是模型处理与生成信息的计量单元；此处强调围绕模型调用、算力与数据开展服务运营。2026年9月合作伙伴大会进一步提出“唯大不阻、唯快不破、唯合不摧”的发展新范式，发布服务、科创、产品、廉洁四大企业发展图谱。四大图谱与四大核心赛道是不同分类，不能把图谱名称当作赛道答案。[U14] [U15]

### 历史表述的适用边界

2024年报文化页使用“融合创新”战略，愿景带有“加快成为”的措辞。[U2] 当前一般性题目以本卡的官网原文及2026年资料为准；只有题目明确指定旧报告或历史阶段时，才使用该年度表述。“大联接、大计算、大数据、大应用、大安全”等旧阶段分类不能替代当前四大赛道。

## 易混辨析

1. “集团有限公司”“股份有限公司”“（香港）股份有限公司”“有限公司”对应不同法人，不能只因都简称“中国联通”就互相替代。
2. 中国联通A股和港股不是同一法人发行的A股、H股；股权联系也不能一律写成直接控股。
3. 1994年历史起点、2000年港股主体注册上市、2008年上市公司合并、2009年集团组建不是同一个日期问题。
4. 当前官网使命为“数字信息运营服务国家队、数字技术融合创新排头兵”；“严、实、精、细、快”是作风；“创新与智慧同行”是品牌语；“信息通信事业国家队、主力军”是较新的角色担当表述。
5. 六项核心价值观的完整原文由2024年官方报告支撑，不能称为2026年新发布版本；连接、算力、服务、安全是当前四大核心赛道，服务、科创、产品、廉洁是四大企业发展图谱。
6. 联通智家、沃派、慧商属于客户品牌；联通云、元景等属于不同产品与能力层次；内地公众客服号码为10010。
7. “百倍用心，十分满意”属于服务主题；“一号通解”等是五大窗口服务名称；“三唯”属于发展新范式，均不能改标为核心价值观。

## 自编笔试题

以下均为单项选择题，依据本卡注明年份的资料编写，不是官方真题。

### 第1题：法人结构

关于中国联通主体结构，下列说法正确的是：

A. 中国联合网络通信集团有限公司就是股票代码600050对应的上市法人。

B. A股公司和港股公司只是同一法人的两种简称。

C. A股公司与港股公司是不同法人，境内运营公司的名称又与二者不同。

D. 港股公司美国存托证券在2021年退市，意味着中国联通集团于同年解散。

答案：C。

解析：集团、A股公司、港股公司、境内运营公司须分别识别。存托证券退市是证券市场事件，不是集团解散；A股和港股的结构不能照搬同一公司发行A股、H股的模式。[U1] [U3] [U6]

### 第2题：文化层次

根据截至2026-10-17可核验的官方文化资料，下列对应关系正确的是：

A. “严实精细快”是2025年报中的六项核心价值观。

B. “客户为本、员工为根、服务为上、创新为魂、奋斗为荣、清廉为基”是2024年官方报告明确列示的核心价值观，不能仅因较新文化页未重列就认定其已废止。

C. “创新与智慧同行”是2025年报列示的企业使命。

D. “联通沃派”是企业愿景，“10010”是算力平台名称。

答案：B。

解析：六项核心价值观在2024年报与集团2024年可持续发展报告中得到明确列示；当前官网的“严、实、精、细、快”属于企业作风；“创新与智慧同行”是品牌语；沃派和10010分别属于客户品牌与客服号码。[U2] [U5] [U9] [U10] [U12]

### 第3题：战略与产品

关于2025年报及2026年中期业绩中的发展重点，下列说法正确的是：

A. 四大核心赛道是连接、算力、服务、安全，星罗与元景分别体现算力调度和模型服务等不同能力。

B. 四大核心赛道就是全球通、动感地带、神州行、天翼四个客户品牌。

C. “服务”赛道仅指拨打客服热线，不包括行业综合服务。

D. “守正创新、行稳致远”是港股上市主体的法定名称。

答案：A。

解析：赛道划分与品牌名称、法人名称属于不同层次。联通星罗、联通元景等服务于不同能力环节；服务赛道也不能缩减为单一热线功能。[U1] [U4]

### 第4题：最新服务与分类

关于2026年公开发布内容，下列对应关系正确的是：

A. “一号通解”对应10010热线，“一屏速办”对应中国联通APP。

B. “480”指修障48小时、装移机0小时。

C. 服务、科创、产品、廉洁是四大核心赛道。

D. “唯大不阻、唯快不破、唯合不摧”是新发布的六项核心价值观。

答案：A。

解析：“480”指修障4小时、装移机8小时；服务、科创、产品、廉洁是四大企业发展图谱；“三唯”是发展新范式。[U13] [U14]
