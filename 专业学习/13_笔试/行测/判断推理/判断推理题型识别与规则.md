# 判断推理题型识别与规则

## 知识点解析

### 概述

判断推理总览的作用是路由，而不是重复各专题的完整规则。做题时先看题面对象和任务词，定位题型；再按该题型的固定顺序提取约束、调用方法并回代验证。无法在时间预算内形成可验证规则时及时止损，避免凭感觉反复试错。

### 题型识别与专题路由

| 题面线索 | 题型 | 首选动作 | 完整规则 |
| --- | --- | --- | --- |
| 一组平面图形找下一图、分组或补九宫格 | 图形推理 | 比较元素组成，按位置、样式、属性、数量分流 | [图形推理决策树](<图形推理决策树.md#图形推理决策树>) |
| 展开图、立方体、投影、切面、积木或观察方向 | 空间推断 | 把面、边、点或单位块编号，用硬约束排除 | [空间推断折纸盒与立体题](<空间推断折纸盒与立体题.md#空间推断折纸盒与立体题>) |
| 给出概念，问符合或不符合的一项 | 定义判断 | 圈主体、客体、方式、目的、条件、结果 | [定义判断与类比推理](<定义判断与类比推理.md#定义判断与类比推理>) |
| 给出词对，要求选择关系最一致的一组 | 类比推理 | 先定一级关系，再比较方向和二级属性 | [定义判断与类比推理](<定义判断与类比推理.md#定义判断与类比推理>) |
| 出现“如果、只有、除非、所有、有的”等逻辑词 | 翻译推理 | 命名原子命题，翻译成箭头、联言、选言或集合关系 | [翻译推理](<翻译推理.md#翻译推理>) |
| 多人陈述且限定真话或假话数量 | 真假推理 | 标记各陈述并核对真假数量 | [真假推理与分析推理](<真假推理与分析推理.md#真假推理与分析推理>) |
| 人、事、地点、顺序或座位的条件匹配 | 分析推理 | 列表或写位置关系，先放确定条件和强约束 | [真假推理与分析推理](<真假推理与分析推理.md#真假推理与分析推理>) |
| 问最能削弱、加强、作为前提、解释或评价的一项 | 论证题 | 先写论点、论据和缺失桥梁，再判断选项作用点 | [论证削弱与加强](<论证削弱与加强.md#论证削弱与加强>) |

### 图形题识别线索

| 识别线索 | 优先方向 | 首轮检查 |
| --- | --- | --- |
| 元素组成相同 | 位置规律 | 平移的方向与步数，旋转的顺逆与角度，翻转的轴 |
| 元素组成相似 | 样式规律 | 遍历、加减同异、逐格黑白运算、元素换算 |
| 元素组成不同 | 先属性后数量 | 对称、曲直、开闭，再数点、线、角、面、素、笔画 |
| 出现立体图 | 空间规律 | 相对面、投影、切面、块数与凹凸 |
| 3×3 九宫格 | 行列或整体规律 | 横行优先，再看竖列、整体遍历、米字形、中心对称、相邻运算 |
| 黑白块数量稳定且位置在动 | 位置变化 | 先验平移、旋转，不能直接认定黑白运算 |
| 两图逐格叠加得到第三图 | 黑白运算 | 用所有已知组验证同一真值表 |
| 位置不动且分堆明显 | 部分数 | 相连块算一个部分 |
| 黑块个数有稳定变化 | 数量规律 | 数黑块并检查递增、递减或周期 |
| 图形呈明显对称感 | 属性规律 | 检查轴对称、中心对称及对称轴方向 |
| 小黑点、箭头、小圆等醒目标记 | 功能元素 | 看它指向交点、线段、角、面、方向、长短或相邻关系 |

位置题还要注意：

- 平移步数可能恒定、递增、循环或往返。
- 旋转常见 45 度、90 度、180 度；时钟题还要核对指针方向和 30 度、90 度、180 度等夹角。
- 上下翻转时左右关系不变，左右翻转时上下关系不变；相邻顶点的时针方向可辅助区分旋转与翻转。

属性题中，轴对称要同时看对称轴数量和方向，中心对称用旋转 180 度是否重合判断；曲直属性区分全直、全曲和曲直混合，开闭属性区分封闭、半封闭和开放。

数量题的触发信号：

| 对象 | 触发信号 |
| --- | --- |
| 点 | 图形交叉混乱，尤其曲直交点 |
| 线 | 线条多、边数明显 |
| 角 | 锯齿、多边形、直角或锐角突出 |
| 面 | 封闭区域多，有“窟窿” |
| 素 | 一组相同小图形，考个数或种类 |
| 笔画 | 非孤立线条连通，考每条边恰走一次 |

特殊图形只作为尝试线索：五角星、圆、日字常见一笔画考法；田字和字母 A 常见两笔画考法；等腰三角形、箭头常提示轴对称；N、Z、平行四边形常提示中心对称；汉字常考笔画、结构和封闭面。任何线索都必须覆盖全部已知图，不能靠图形名称直接定规则。

### 通用解题顺序

| 阶段 | 操作 | 完成标志 |
| --- | --- | --- |
| 1. 识别 | 看题面对象、任务词和选项形式 | 能落到一个专题入口 |
| 2. 提取 | 圈图形特征、定义要件、命题关系或论证结构 | 写出有限个可检查约束 |
| 3. 选择 | 按专题优先级调用一种方法 | 得到候选规律、安排或选项 |
| 4. 验证 | 覆盖全部已知图或逐条回代题干条件 | 没有反例或漏条件 |
| 5. 决策 | 能唯一确定则作答；否则切换一次方向或止损 | 不在同一路径重复试错 |

选项给出完整方案时优先代入排除；问“可能”时构造一个合法方案即可，问“必然”时必须排除反例。图形规律若只解释局部、逻辑推导若依赖题干未给条件、论证选项若只改变背景，都不能作为答案。

### 止损规则

| 卡住表现 | 允许的下一步 | 止损条件 |
| --- | --- | --- |
| 图形题第一方向无规律 | 按“位置→样式→属性→数量→空间”切换一次 | 候选规律连续两次不能覆盖全部已知图，标记后跳 |
| 空间题开始依赖脑内旋转 | 立即改用面、边、点、端点或单位块编号 | 无法建立统一参照物时先跳 |
| 定义或类比剩两个选项 | 比较必要要件、方向、层级和二级属性 | 只能用宽泛的“有关”解释时不继续脑补 |
| 翻译或真假题推导分支增多 | 回到对应专题顺序并用选项检验 | 需要新增题干未给的唯一性或因果条件时停止 |
| 分析推理正推过长 | 改用选项代入或候选最少对象分支 | 分支不能及时产生确定信息或矛盾时先跳 |
| 论证题反复比较措辞 | 回到论点对象、范围、强度和桥梁 | 选项只影响背景而不改变支持度时排除，不再纠缠 |

止损按个人单题时间预算执行。标记跳过不是放弃验证，而是先保护后续稳定得分题，回看时从已记录的约束继续，不重启整套搜索。
