# 图形推理实战切入与止损

## 使用定位

本卡解决的不是“有哪些图形规律”，而是考场上如何在有限时间内找到切入口、验证规则并及时止损。具体位置、样式、属性、数量和空间规则仍以[图形推理决策树](<图形推理决策树.md#图形推理决策树>)为准。

核心原则：

1. **先宏观后微观**：先判断图形像不像、规整不规整、结构是否明显，再进入点线面计数。
2. **线索只决定优先级**：特征图、简单图和反常图不能直接证明考点。
3. **规则必须全量验证**：同一计数口径覆盖全部已知图，且能唯一排除选项。
4. **30 秒止损**：连续两条候选路径都不能形成稳定规则，先跳过，回看时不从零开始。

## 考场时间轴

| 时间 | 动作 | 完成标志 |
| --- | --- | --- |
| 0-5 秒 | 看题型、元素相似度、整体结构和最醒目差异 | 能确定位置、样式、属性、数量或空间中的首选方向 |
| 5-15 秒 | 选信息量最大的图或图间差异，提出 1-2 个候选考点 | 候选规则可以明确计算或判断 |
| 15-25 秒 | 用全部已知图验证，再用选项反推差异 | 规则无反例且可唯一作答 |
| 25-30 秒 | 只允许切换一次方向 | 第二方向仍失败就记录线索并跳过 |
| 回看 | 从已记录的“首选方向、已排除方向、异常图”继续 | 不重复首轮无效计数 |

## 第一步：宏观分流

| 图形状态 | 优先方向 | 首轮问题 |
| --- | --- | --- |
| 元素完全相同 | 位置 | 是否平移、旋转、翻转；方向和步数是否稳定 |
| 元素部分相同或构成相似 | 样式 | 是否遍历、叠加、去同存异、黑白运算或元素替换 |
| 元素明显不同 | 属性后数量 | 是否对称、曲直、开闭；再看点、线、角、面、素和笔画 |
| 上下、左右、内外结构明显 | 结构拆分 | 整体部分数是否稳定；各区域分别考属性还是数量 |
| 有小黑点、箭头、小圆等 | 功能元素 | 它标记的是点、线、角、面、方向、长短还是相邻关系 |
| 出现展开图、立方体、截面 | 空间 | 改用面、边、点或单位块编号，不继续套平面计数 |

## 第二步：十二个实战切入口

### 1. 特征图

#### 原导图：特征思考法（完整保留）

- **看到直角三角形/垂直线/电话卡  优先考虑数直角**
- **看到中日田字及其变形、五角星、多余小尾巴、奥迪等  优先考虑一笔画问题**
- **看到生活化图形、加黑加粗图形  优先考虑部分数和封闭区域数**
- **看到数字优先考虑封闭区域（封闭面）**
- **看到曲线  优先考虑曲直性**
- **看到五边形/六边形多边形  优先考虑边框及其关系**
- **看到圆弧+直线  优先考虑交点**
- **看到大箭头/平行四边形/梯形及其变形  优先考虑平行线**

原导图中的“优先考虑”表示首轮搜索顺序。下面的表把每条口诀对应到可验证的考点：

| 视觉信号 | 优先检查 | 边界 |
| --- | --- | --- |
| 直角三角形、明显垂直线 | 直角数、垂直关系 | 只能提高直角优先级，仍需验证全部图 |
| 封闭区域外加一条线、日田字、五角星、拖尾 | 一笔画或最少笔画 | 必须按连通性和奇点数计算 |
| X、Y、T 等分叉 | 笔画、交点或端点 | 视觉分叉不等于一定考笔画 |
| 单一直线或多条规整直线 | 横竖线、平行线、线条方向 | 三条互相平行的线通常作为一组平行方向，题目另有定义除外 |
| 圆弧与直线组合 | 曲直、内外、相切、曲直交点和面 | 先统一交点是否含端点、切点 |
| 外框规整、箭头、梯形、平行四边形 | 外框属性、对称或平行关系 | 图形名称只是线索，不是答案 |
| 数字、汉字、字母 | 封闭面、笔画、结构、对称、曲直和书写顺序 | 不按字义或读音强行联想 |

#### 汉字、字母与结构图补充

- 汉字元素相同：优先看遍历、叠加。
- 汉字元素相异：看结构、部分、笔画、封闭面、横竖线、拼音和第一笔。
- 字母：看对称、曲直、封开、书写顺序和特殊规律。
- 结构图形：先分类为上下、左右、内外或组合结构；整体看部分，分开先形后量。
- 黑白球“黑白三剑客”：先看位置变化，再看数量、叠加、对称、部分和一笔画，最后看相邻比较。
- 立体图形：找邻居、挖墙脚，即先固定相邻面，再用相对面或公共边排除。
- 图推六法宝：对称、一笔画、曲直、封开、直角、平行线。

### 2. 简单图

题组中若有明显更简单的图，先列出它可能具备的少量属性，再用其他图快速排除。

例如简单图只有全直、开放、一条对称轴和两个直角，不要同时从十几个数量项开始；先检查这些显性属性能否覆盖其余图形。

边界：简单图只是减少候选，不代表考点一定来自它最显眼的属性。

### 3. 显眼图与功能元素

小黑点、箭头、半圆、短线等数量少且醒目时，优先把它当标记，不先数其个数：

- 标记点：普通点、交点、切点或端点。
- 标记线：长边、短边、直线、曲线或平行线。
- 标记角：最大角、最小角、直角、锐角或钝角。
- 标记面：大面、小面、内外面、左右区域。
- 标记关系：相邻、相对、内部、外部或方向。

有效规则必须让标记对象在每幅图中保持同一种关系。

### 4. 反常图与破坏性元素

某图像是在常见图形上多添或少去一笔时，问：这次改造改变了什么？

原导图口诀：

- **看破坏性元素破坏了什么，就是什么考点。**
- **破坏角：1. 角的数量；2. 直角的数量；3. 相同角的数量。**
- **注意：一定要注意破坏元素的出现。**
- **出现“树杈、横插一脚、相同元素”，直接考虑交点。**

| 改造结果 | 候选考点 |
| --- | --- |
| 多出或减少封闭区 | 面数 |
| 新增曲线或曲直连接 | 曲直性、曲直交点 |
| 改变顶点连接方式 | 交点、端点、笔画 |
| 打破或新增对称 | 对称类型、对称轴数量和方向 |
| 新增或消除垂直关系 | 直角数 |

优先从变化项较少、计数口径更稳定的考点开始。不能把“破坏了什么就一定考什么”当成充分证明。

### 5. 结构图

看到上下、左右、内外或组合结构，按固定顺序：

1. 整体看部分数和结构是否一致。
2. 分区看属性：对称、曲直、开闭。
3. 分区看数量：面、线、点、角。
4. 再看内外或上下两区之间的数量关系。

外框规整不意味着一定数外框线；内部杂乱也不意味着一定数面，仍须全量验证。

原导图的结构计数入口：

- 单一结构：先数总交点。
- 内外结构：先看内部交点。
- 相同元素反复出现：数相同元素上的交点。
- 十字结构明显：优先数十字交点。
- 出现 Z、S 及其变形：考虑轴对称和中心对称。
- 内外结构明显：外部优先数线条，内部视情况而定。

### 6. 同异分析

找构成相同但局部方向或连接不同的两图，问这种变化会影响什么。常见映射：

- 内部线方向变化 -> 交点、面、对称。
- 添减一条线 -> 线、交点、面、角、笔画。
- 相同元素位置互换 -> 相邻、相交、内外或方向关系。

同异分析负责提出候选，不负责证明规律。

### 7. 全局趋势分析

无需立刻精确计数，先看候选数量是否可能形成常见趋势：恒定、递增、递减、周期、等差或分组。

若某候选在视觉上呈大幅无序跳动，可以降低优先级。但“数量变化通常缓和”只是命题经验，不是排除证明；最终仍要精确计数。

### 8. 局部分析

- 位置移动：把多个元素分开追踪，避免整体观察造成错位。
- 对称：分别核对对称类型、轴数和轴方向。
- 面：分别核对面数、大小、形状、相邻和内外位置。
- 交点：分别核对曲直交点、内部交点、边界交点和切点。

局部计数前先固定口径，不能为适配规律临时改变“什么算一个”。

### 9. 相邻捆绑

图形整体相似、单幅无明显规律时，比较相邻两幅：

1. 哪个元素消失或新增。
2. 哪一行、列或区域变化，其余是否保持。
3. 变化位置是否按顺序移动。
4. 是否每步“少一个旧元素、多一个新元素”。

同一转移规则必须解释每一对相邻图。

### 10. 选项倒推

正推后只剩两项时，直接比较二者的最小差异，再反推题干是否持续控制该差异。

常见差异包括：黑白位置、方向、部分数、交点、对称轴和内外关系。倒推只用于缩小搜索范围，不能因选项差异存在就假定题干必考该差异。

### 11. 考点转换

当前考点很显眼却无法选出唯一答案时，检查相关考点：

| 当前线索 | 可转换方向 |
| --- | --- |
| 部分数 | 连通分量、最少笔画 |
| 相切 | 曲直交点、切点数量 |
| 面数 | 外框线数、内部线数、面积关系 |
| 对称 | 对称轴方向、轴与元素关系 |
| 平行线 | 平行方向组数、总线条数 |

转换必须有结构依据，不能在点线面角之间无限轮询。

### 12. 易忘点

建立个人易忘清单，而不是抄统一口诀。常见项：曲直、开闭、平行、横竖、遍历、传递、直角、切点、最少笔画和功能元素。

每次错题只记录“为什么首轮没想到”，连续出现两次再加入个人清单；清单过长会失去兜底作用。

## 第三步：规则验证

每条候选规则至少通过以下检查：

1. **全覆盖**：解释所有已知图，不只解释其中两三幅。
2. **同口径**：点、线、角、面和笔画的计数标准前后一致。
3. **少例外**：不需要为某幅图临时增加补丁。
4. **有区分**：能排除干扰项并唯一确定答案。
5. **不脑补**：不加入题目没有给出的立体连接、相交或书写规则。

若两条规则都能覆盖题干，优先选择结构更简单、假设更少、变化更稳定且能唯一作答的一条。

## 加黑加粗与平行线专项

### 加黑加粗考虑部分数

原导图完整逻辑：

1. 加黑加粗最本质的突出特征就是突出一个部分。
2. 如何区分几部分：看线条是否交叉，线条分开几次就是几部分。
3. 单一考法：部分数递增或一直相同。
4. 复合考法：部分数与其他考点相结合，最常见的是与外框相结合。

### 大箭头、平行四边形、梯形考虑平行线

原导图完整逻辑：

1. 最本质的特征是突出平行线的组数。
2. 复合考法：将平行线与线条数结合。
3. 平行线组数相同，再看线条数是否相同。
4. 三条互相平行的线算一组平行线。

## 止损与回看记录

卡住时在草稿上只记三个短标签：

| 记录项 | 示例 |
| --- | --- |
| 首选 | 结构/属性 |
| 已排 | 面、交点 |
| 异常 | 图 3 多一短线 |

达到时间预算后跳过。回看时先从异常图和未验证的相邻关系继续，不再重数已经排除的项目。

## 口诀边界

| 口诀或经验 | 正确定位 |
| --- | --- |
| 加黑加粗优先考虑部分数 | 加黑可能突出独立部分，但仍可能标记方向、面或其他关系 |
| 大箭头、梯形优先看平行线 | 只是平行关系的特征图，不排除对称、线数和位置 |
| 生活化图形不数点线 | 只能降低优先级，不能禁止计数 |
| 数字优先数封闭面 | 封闭面是高频方向，仍可能考直曲、对称或笔画 |
| 数量变化一般较平缓 | 可用于排序候选，不能据此直接排除规律 |
| 选项二选一就倒推 | 倒推用于定位差异，最终仍须回到题干验证 |

## 复盘模板

| 项目 | 记录内容 |
| --- | --- |
| 宏观分流 | 元素相同、相似、不同，还是结构/空间题 |
| 首个有效线索 | 特征图、简单图、反常图、功能元素或相邻变化 |
| 最终规则 | 用一句可检验的话表达 |
| 统一口径 | 点线面角、笔画或位置如何计算 |
| 首轮错因 | 分流错误、漏看异常、口径不一、验证不全或未止损 |
| 可迁移触发 | 下次看到什么信号应优先尝试该方向 |
