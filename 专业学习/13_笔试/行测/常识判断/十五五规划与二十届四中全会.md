# 十五五规划与二十届四中全会

## 知识点解析

### 定义与时效口径

“十五五”是国民经济和社会发展第十五个五年规划，规划期为2026—2030年，2026年是开局之年。它属于时政与政治理论内容；银行、运营商和央国企笔试可能将其放在行测常识判断或综合知识中，具体以考试大纲为准。

本卡政策事实核验日期为2026-10-18，依据党的二十届四中全会公报和已经批准的国家“十五五”规划纲要。题目指定2025年全会时，应按《建议》及公报回答；指定2026年国家规划时，应按《纲要》回答，不能将草案、正式文件与年度政府工作报告混为一谈。[1][2][3]

五年规划主要阐明国家战略意图，明确政府工作重点，引导规范社会主体行为。它通过中长期目标、重点任务和实施机制衔接年度政策，覆盖经济、科技、社会、生态、安全等领域，不只是五年经济增长率安排。

### 时间线与文件主体

| 时间 | 事件或文件 | 应记住的主体与动作 |
| --- | --- | --- |
| 2021—2025年 | “十四五”规划期 | 全面建设社会主义现代化国家新征程的开局起步阶段 |
| 2025年10月20日至23日 | 党的二十届四中全会在北京举行 | 2025年10月23日审议通过“十五五”规划《建议》 |
| 2026年3月12日 | 十四届全国人大四次会议通过有关决议 | 决定批准国家“十五五”规划《纲要》 |
| 2026年3月13日 | 新华社受权全文播发《纲要》 | 全文公开日期与全国人大批准日期不同 |
| 2026—2030年 | “十五五”规划期 | 承前启后，夯实基础、全面发力 |
| 2035年 | 中长期现代化目标节点 | 基本实现社会主义现代化 |

《建议》全称为《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》；《纲要》全称为《中华人民共和国国民经济和社会发展第十五个五年规划纲要》。

两者关系是：党中央提出规划建议，国务院组织编制规划纲要，提交全国人大审查批准，通过法定程序将党的主张转化为国家意志。四中全会审议通过的是《建议》，不能写成四中全会批准国家规划《纲要》。[1][2][3]

### 历史定位与指导思想关键词

“十五五”时期是基本实现社会主义现代化夯实基础、全面发力的关键时期，在基本实现社会主义现代化进程中具有承前启后的重要地位。目标是确保基本实现社会主义现代化取得决定性进展，不能改成“2030年已经基本实现社会主义现代化”。[1][3]

| 题干所问 | 对应原文关键词 |
| --- | --- |
| 工作总基调 | 稳中求进 |
| 中心 | 经济建设 |
| 主题 | 推动高质量发展 |
| 根本动力 | 改革创新 |
| 根本目的 | 满足人民日益增长的美好生活需要 |
| 根本保障 | 全面从严治党 |
| 经济发展要求 | 质的有效提升和量的合理增长 |

主题回答“发展追求什么质量”，动力回答“靠什么推动”，目的回答“为了谁、满足什么需要”，保障回答“如何保证推进”。配对题先确定题干问的关系，再选原文表述，不能因为某个选项政治表述正确就认为它回答了题干。

### 必须遵循的六个原则

以下六项是“十五五”时期经济社会发展原则，顺序与官方文件一致：[1][3]

1. 坚持党的全面领导：将党的领导贯穿经济社会发展各方面全过程，为现代化建设提供根本保证。
2. 坚持人民至上：尊重人民主体地位，维护人民根本利益，使现代化建设成果更多更公平惠及全体人民。
3. 坚持高质量发展：以新发展理念引领发展，因地制宜发展新质生产力，推动经济结构优化升级。
4. 坚持全面深化改革：破除制约高质量发展的体制机制障碍，增强发展动力和社会活力。
5. 坚持有效市场和有为政府相结合：充分发挥市场在资源配置中的决定性作用，更好发挥政府作用，建设法治经济、信用经济。
6. 坚持统筹发展和安全：在发展中固安全，在安全中谋发展，增强经济和社会韧性。

“有效市场和有为政府相结合”不等于政府替代市场配置一切资源；“统筹发展和安全”也不等于只谈发展速度或只谈风险控制。

容易混淆的是二十届三中全会关于进一步全面深化改革的六个原则：

| 会议及主题 | 六个原则 |
| --- | --- |
| 二十届三中全会：进一步全面深化改革 | 党的全面领导；以人民为中心；守正创新；以制度建设为主线；全面依法治国；系统观念 |
| 二十届四中全会：“十五五”时期经济社会发展 | 党的全面领导；人民至上；高质量发展；全面深化改革；有效市场和有为政府相结合；统筹发展和安全 |

两组都可以简称“六个坚持”，先定位会议和文件，再核对完整清单。三中全会改革总目标、七个聚焦及2029年任务节点见[会议政策与新质生产力](<../../综合知识/政治与时政/会议政策与新质生产力.md>)。

### 七方面主要目标

四中全会公报和《纲要》列出的七方面主要目标是：[1][3]

1. 高质量发展取得显著成效。
2. 科技自立自强水平大幅提高。
3. 进一步全面深化改革取得新突破。
4. 社会文明程度明显提升。
5. 人民生活品质不断提高。
6. 美丽中国建设取得新的重大进展。
7. 国家安全屏障更加巩固。

在此基础上再奋斗五年，到2035年实现经济实力、科技实力、国防实力、综合国力和国际影响力大幅跃升，人均国内生产总值达到中等发达国家水平，人民生活更加幸福美好，基本实现社会主义现代化。

“七方面主要目标”与“六个原则”分别回答发展结果和遵循要求，不属于同一清单。

### 《纲要》的重要量化目标

以下为《纲要》第三章中的部分目标，不是完整指标清单。[3]

| 指标 | “十五五”目标 | 口径与辨析 |
| --- | --- | --- |
| 国内生产总值，即GDP（Gross Domestic Product）增长 | 保持在合理区间，各年度视情提出 | 未设统一固定的五年年均增速；不能将2026年度目标当作整个规划期目标 |
| 全社会研发经费投入 | 年均增长7%以上 | 经费投入增速，不是研发经费占GDP的比重 |
| 城镇调查失业率 | 低于5.5% | 与年度报告中“5.5%左右”的表述不能直接互换 |
| 劳动年龄人口平均受教育年限 | 提高到11.7年 | 劳动年龄人口口径，不是全体人口平均值 |
| 人均预期寿命 | 提高到80岁 | 规划目标，不代表当前所有人都能活到80岁 |
| 单位GDP二氧化碳排放 | 降低17% | 五年累计降幅，以2025年为基期；不是每年降低17%，也不是排放总量降低17% |
| 粮食综合生产能力 | 达到1.45万亿斤左右 | 综合生产能力，不等同于某一年粮食实际产量 |
| 能源综合生产能力 | 达到58亿吨标准煤 | 综合生产能力与标准煤计量口径，不能改成煤炭实物产量 |

《纲要》提出，在结构优化和质量提升基础上，为到2035年人均GDP比2020年翻一番、达到中等发达国家水平打好基础。这里的“翻一番”是变为原来的2倍，时间端点是2020年与2035年，指标是人均GDP；不能改写为“2030年GDP总量翻倍”。

### 重点任务与银行、运营商关联

《纲要》共18篇、62章。下表概括与常识题及银行、运营商笔试联系较紧的任务；业务联系是理解政策的应用示例，不是对具体企业考纲的预测。[2][3]

| 任务方向 | 政策关键词 | 理解与应用示例 |
| --- | --- | --- |
| 现代化产业体系 | 实体经济；智能化、绿色化、融合化；先进制造业为骨干 | 科技与金融服务应支持产业升级；发展新质生产力也包括改造传统产业 |
| 科技自立自强 | 原始创新；关键核心技术攻关；教育科技人才一体发展 | 基础研究、成果转化和人才培养协同，不能只理解成采购新设备 |
| 数字中国 | 算力、算法、数据高效供给；数智技术赋能 | 运营商网络、算力和数据服务可与该任务关联 |
| 强大国内市场 | 扩大内需；提振消费；扩大有效投资；全国统一大市场 | 惠民生和促消费、投资于物和投资于人紧密结合 |
| 高水平对外开放 | 制度型开放；贸易投资合作；共建“一带一路” | 国内循环与国际循环协同，扩大内需不等于封闭经济 |
| 农业农村现代化 | 乡村全面振兴；粮食安全；宜居宜业和美乡村 | 涉农金融、普惠服务和农村信息基础设施可作场景辨析 |
| 人口与民生 | 高质量充分就业；收入分配；社会保障；养老托育 | 与养老金融、公共服务和银发经济关联 |
| 绿色转型 | 降碳、减污、扩绿、增长；新型能源体系；碳达峰 | 强调协同转型，不能直接推成立即停止所有化石能源使用 |
| 国家安全 | 经济安全；公共安全；社会治理；重点领域风险防范 | 发展与安全并重，金融安全、网络安全均有具体场景 |

未来产业方面，《纲要》明确提出推动量子科技、生物制造、氢能和核聚变能、脑机接口、具身智能、第六代移动通信等成为新的经济增长点。第六代移动通信即6G（Sixth Generation Mobile Communication）。这是前瞻布局与技术创新部署，不能据此判定这些技术已全部成熟或已实现全国商用。

新质生产力的一般定义、金融五篇大文章和年度宏观政策统一见[会议政策与新质生产力](<../../综合知识/政治与时政/会议政策与新质生产力.md>)，避免把年度政策与五年规划重复混记。

## 题型识别与易错点

| 题型或陷阱 | 解题步骤 |
| --- | --- |
| 年份错位 | 先确认十三五2016—2020年、十四五2021—2025年、十五五2026—2030年，再核对2035年目标 |
| 主体偷换 | 四中全会审议通过《建议》；全国人大批准《纲要》；新华社受权播发全文 |
| 关键词配对 | 区分中心、主题、动力、目的、保障；按官方对应关系选择 |
| 原则拼接 | 先定位三中全会或四中全会，警惕把两组“六个坚持”混成一组 |
| 目标数量混淆 | 六个原则、七方面主要目标、18篇62章分别对应不同对象 |
| 年度目标替代五年目标 | 先确定题目问2026年度还是整个十五五时期，再核对指标 |
| 增速、比重、累计降幅混淆 | 研发投入年均增速不是投入强度；单位GDP排放降幅不是排放总量降幅 |
| 规划部署当作已完成事实 | “建设”“推进”“培育”是任务，不能直接改写为“已经全面实现” |

资料分析中，问“十五五期间年均增长”，且采用各年年度统计量时，通常比较2025年与2030年，间隔数为5；若明确比较2026年与2030年，则间隔数为4。按题干指定基期计算，公式与边界见[增长类题型](<../资料分析/增长类题型.md>)。

## 自编练习与解析

以下题目为自编训练，不是真题。题1—6为单项选择题，题7—8为计算题，题9—12为判断题。

### 1. “十五五”的规划期是？

A. 2021—2025年；B. 2025—2029年；C. 2026—2030年；D. 2031—2035年。

答案：C。解析：十五五承接十四五，2026年是开局之年。

### 2. 审议通过“十五五”规划《建议》的会议是？

A. 党的二十届三中全会；B. 党的二十届四中全会；C. 十四届全国人大四次会议；D. 2025年中央经济工作会议。

答案：B。解析：四中全会审议通过《建议》，十四届全国人大四次会议批准《纲要》。

### 3. “十五五”时期经济社会发展的根本动力是？

A. 改革创新；B. 全面从严治党；C. 满足人民日益增长的美好生活需要；D. 经济建设。

答案：A。解析：B对应根本保障，C对应根本目的，D对应中心。

### 4. 哪项不属于“十五五”时期必须遵循的六个原则？

A. 坚持人民至上；B. 坚持高质量发展；C. 坚持有效市场和有为政府相结合；D. 坚持以制度建设为主线。

答案：D。解析：“以制度建设为主线”属于二十届三中全会关于进一步全面深化改革的原则。

### 5. 对“十五五”历史定位表述正确的是？

A. 到2030年全面建成社会主义现代化强国；B. 基本实现社会主义现代化夯实基础、全面发力的关键时期；C. 全面建设社会主义现代化国家新征程的开局起步阶段；D. 不涉及2035年目标。

答案：B。解析：C对应十四五；十五五与2035年基本实现社会主义现代化目标衔接。

### 6. 对《纲要》的量化目标理解正确的是？

A. 研发经费占GDP比重每年增加7个百分点；B. 二氧化碳排放总量每年下降17%；C. 人均预期寿命提高到80岁；D. 整个规划期GDP年均增速固定为2026年度目标。

答案：C。解析：7%以上是研发经费投入年均增速；17%是单位GDP二氧化碳排放五年累计降幅；GDP增速各年度视情提出。

### 7. 自编数据：某指标2025年为100，2030年为150。“十五五期间”年均增长量是多少？

答案：10。解析：基期为2025年，间隔为5年，年均增长量为(150−100)÷5=10。不能用五年规划起始年度2026年直接替代基期。

### 8. 自编数据：若2025年单位GDP二氧化碳排放指数为100，五年累计降低17%，2030年指数是多少？

答案：83。解析：100×(1−17%)=83。累计降幅只作用一次，不能按每年下降17%连乘五次；该结果也不能单独用于判断排放总量。

### 9. “十五五”规划《纲要》于2026年3月13日获得全国人大批准。

答案：错误。解析：批准日期是3月12日；3月13日是新华社受权全文播发日期。

### 10. 2035年人均GDP比2020年翻一番，意味着提高到2020年的2倍。

答案：正确。解析：翻一番是增加100%，成为原值的2倍；不是增加200%。

### 11. 发展新质生产力意味着传统产业不再需要改造升级。

答案：错误。解析：现代化产业体系建设同时要求优化提升传统产业、培育壮大新兴产业和未来产业，不能按产业新旧直接排除。

### 12. 《纲要》部署第六代移动通信，证明6G已在全国全面商用。

答案：错误。解析：前瞻布局和技术创新部署不等于已完成商业化，题目偷换了事件阶段。
