## 单选题

### 1. 通信领域混合文本检索

题目：配置命令、日志和故障案例中包含命令行、IP、MAC、端口、VLAN ID、OID 等结构化内容，哪种方案最合理？

- A. 增加专用词表，按命令块或日志条目切分，使用领域微调 Embedding
- B. 统一小写并去除全部符号
- C. 固定长度切分并使用通用模型
- D. 只使用 BM25

答案：A

解析：专用词表和结构感知切分可避免破坏 IP、命令及标识符，领域 Embedding 能补充语义召回。删除符号会损坏结构，纯 BM25 或通用模型都难兼顾精确匹配与语义检索。

### 2. 实验配比对比图

题目：在大模型指令微调实验中，研究人员对比了 3 种训练数据配比（纯指令、指令+多轮对话、指令+知识）下的模型响应准确率，需直观展示不同配比的准确率差异并便于组间对比，最适合的可视化图表是？

- A. 分组柱状图
- B. 雷达图
- C. 饼图
- D. 直方图

答案：A

解析：柱状图适合比较离散实验组的单个或多个指标；直方图用于连续变量分布，饼图用于组成占比。

### 3. 牛顿迭代公式

题目：牛顿迭代公式是哪一个？

- A. $x_{n+1}=x_n-f(x_n)/f'(x_n)$
- B. $x_{n+1}=x_n-f(x_n)$
- C. $x_{n+1}=x_n+f(x_n)/f'(x_n)$
- D. $x_{n+1}=x_n-f'(x_n)/f(x_n)$

答案：A

解析：该公式用当前点切线与横轴交点近似下一次根的位置。

### 4. 张量并行

题目：张量并行（TP）主要用于解决单卡显存无法容纳单个模型层权重的问题，其切分逻辑是？

- A. 按优化器状态切分，不同 GPU 维护不同的优化器状态
- B. 按网络层深度切分，不同层放在不同 GPU 上
- C. 按批次大小切分，不同样本放在不同 GPU 上
- D. 按矩阵运算的维度切分，同一层内的权重被拆分到不同 GPU 上

答案：D

解析：TP（Tensor Parallelism，张量并行）沿矩阵行或列等张量维度拆分同一层权重；按层切分是流水线并行，按样本切分是数据并行。

### 5. 必然可逆的矩阵

题目：下列哪个矩阵一定是可逆的？

- A. 对称矩阵
- B. 行列式为零的矩阵
- C. 单位矩阵
- D. 所有元素都为零的矩阵

答案：C

解析：单位矩阵行列式为 1。对称矩阵可能奇异，B、D 明确不可逆。

### 6. 显存不足时的 KV Cache

题目：在多轮对话推理系统中，如果 GPU/NPU 显存已满但仍有新的 token 需要生成，系统通常采用什么策略？

- A. 将部分 KV Cache swap 到 CPU 或进行 recomputation
- B. 自动降低模型精度
- C. 重启服务器
- D. 直接杀掉进程

答案：A

解析：换出和重计算以传输或计算换显存；自动降精度并非通用即时行为，重启或杀进程不能继续正常请求。

### 7. Conv 与 BN 融合

题目：在部署阶段（Inference），将卷积层（Convolution）与批归一化层（Batch Normalization，BN）进行融合（Folding）是各大编译器的标配操作。以下关于 Conv+BN 融合的描述中，最准确的是？

- A. 融合是为了让 BN 的梯度能更快反向传播到 Conv 层，从而加速推理
- B. 融合是一种纯代数等价变换，在模型编译期（Offline）就将 BN 的缩放和偏移参数直接吸收到 Conv 的权重和偏置中，运行时完全没有 BN 的开销
- C. 融合是在运行时（Runtime）将 BN 的均值和方差传入 Conv 的底层算子中并行计算
- D. Conv+BN 融合会轻微改变模型的输出精度，因为融合后的算子无法使用 Tensor Core 加速

答案：B

解析：推理时 BN 使用固定统计量，其缩放和平移可代数吸收到卷积权重和偏置中，运行时无需独立 BN 算子。它与反向传播无关，浮点精度下是等价变换。

### 8. Pipeline Bubble

题目：在流水线并行（Pipeline Parallel）中，一个模型被切分为多个 Stage，分布在不同 GPU 上。当某些 GPU 在等待上游 Stage 的计算结果时出现空闲，这种现象被称为？

- A. Pipeline Bubble
- B. 显存碎片
- C. GPU Context Switch
- D. 网络拥塞

答案：A

解析：流水线阶段等待上游输入或下游反传而空闲的时段称为流水线气泡。

### 9. HAC 的簇间距离

题目：在层次聚类分析（HAC）中，以下哪一种方法是用于定义簇间距离的常见方式？

- A. Expectation-Maximization
- B. K-means
- C. DBSCAN
- D. Complete Linkage

答案：D

解析：Complete Linkage 用两个簇中最远样本对的距离定义簇间距离，是层次聚类的常见链接准则。

### 10. 类别不平衡下的 Micro-F1

题目：某多分类任务中，类别 A 有 1000 个样本，类别 B 有 10 个样本。若使用 Micro-F1 计算，主要反映的是哪个类别的性能？

- A. 两者权重相同
- B. 取决于具体的 F1 计算公式
- C. 类别 B
- D. 类别 A

答案：D

解析：Micro-F1 先汇总所有样本的混淆计数，大类样本数量远多于小类，因而主要反映类别 A 的表现。

### 11. PyTorch 优化器更新

题目：在 PyTorch 中，以下哪个函数用于执行优化器的一步更新？

- A. `optimizer.zero_grad()`
- B. `optimizer.backward()`
- C. `optimizer.step()`
- D. `optimizer.update()`

答案：C

解析：`zero_grad()` 清空梯度，反向传播通常调用 `loss.backward()`，`step()` 才根据当前梯度更新参数。

### 12. 蒙特卡洛积分与黎曼积分

题目：工程师需要计算一个复杂函数 $f(x)$ 在区间 $[0,1]$ 上的定积分 $\int_0^1 f(x)\,dx$。以下关于蒙特卡洛积分与黎曼积分的对比，说法正确的是？

- A. 蒙特卡洛积分仅适用于低维积分问题，高维时应使用黎曼积分
- B. 蒙特卡洛积分的收敛速度为 $O(N^{-2})$，黎曼积分（等距划分）为 $O(N^{-1})$
- C. 蒙特卡洛积分的计算复杂度远低于黎曼积分，因此总是首选
- D. 蒙特卡洛积分的收敛速度为 $O(N^{-1/2})$，黎曼积分（等距划分）为 $O(N^{-2})$

答案：D

解析：普通蒙特卡洛估计的标准误差为 $O(N^{-1/2})$，且该阶数基本不依赖维度。题目把等距黎曼公式概括为 $O(N^{-2})$，对应梯形或中点等二阶求积口径；若特指左端点矩形公式则通常只有 $O(N^{-1})$，因此原题表述不够严格。

### 13. 高维稀疏向量相似度

题目：适合高维稀疏向量相似度计算的是？

- A. 余弦相似度
- B. 切比雪夫距离
- C. 欧氏距离
- D. 曼哈顿距离

答案：A

解析：余弦主要比较方向，不受向量整体模长影响，并可利用稀疏点积高效计算，常用于文本稀疏向量。

### 14. Encoder-Decoder Attention 的 Query

题目：Transformer 的编码器-解码器注意力（Encoder-Decoder Attention）中，查询（Query）来自哪里？

- A. 输入序列
- B. 解码器的上一层输出
- C. 位置编码
- D. 编码器的输出

答案：B

解析：交叉注意力的 Query 来自解码器当前层输入或上一子层输出，Key 和 Value 来自编码器输出。

### 15. 余弦相似度计算

题目：$a=(1,2,3)$、$b=(4,5,6)$ 的余弦相似度是多少？

- A. 1.0
- B. 0.87
- C. 0.97
- D. 0.67

答案：C

解析：$a\cdot b=32$，模长乘积为 $\sqrt{14\times77}$，故相似度约为 $0.9746$。

## 多选题

### 16. 视觉-语言连接器

题目：多模态大模型中，常见的视觉-语言连接器（Connector）包括？

- A. MLP（多层感知机）
- B. 线性投影层（Linear Projection）
- C. 卷积池化层
- D. Q-Former

答案：A、B、C、D

解析：线性层和 MLP 是最常见投影器，Q-Former 用可学习查询压缩视觉信息，卷积或池化式抽象器也可用于局部聚合和视觉 token 压缩。

### 17. 特征向量相似性或差异度量

题目：适用于机器学习中度量两个特征向量相似度的有哪些？

- A. 欧氏距离
- B. 余弦相似度
- C. 汉明距离
- D. KL 散度

答案：A、B、C、D

解析：欧氏距离、余弦相似度和汉明距离分别适合连续向量方向、几何距离或离散编码；KL 散度可衡量两个概率向量的分布差异，但它不对称且不满足严格距离公理。

### 18. 正态总体参数的 MLE

题目：设 $X_1,\ldots,X_n\sim N(\mu,\sigma^2)$，下面正确的有哪些？

- A. $\mu$ 的 MLE 是样本均值 $\bar X$
- B. $\mu$ 的 MLE 是无偏的
- C. $\sigma^2$ 的 MLE 是 $(1/n)\sum_i(X_i-\bar X)^2$
- D. $\sigma^2$ 的 MLE 是无偏的

答案：A、B、C

解析：$\hat\mu=\bar X$ 且无偏；$\hat\sigma^2=(1/n)\sum_i(X_i-\bar X)^2$ 是 MLE，但其期望为 $(n-1)\sigma^2/n$，因此有偏。

### 19. 反向传播效率

题目：以下关于反向传播计算效率的说法正确的是？

- A. 反向传播的计算量大约是前向传播的 2 倍
- B. 符号微分与数值微分是两种计算体系，在一个模型训练时只能使用其中一种
- C. 反向传播需要存储所有中间层的激活值，因此显存消耗大
- D. 相比于数值微分，符号微分计算梯度的速度快

答案：A、C、D

解析：反向传播计算量通常与前向同阶，常粗略估为前向的约 2 倍；标准反向传播需保存激活，显存占用较大；相较逐参数数值差分，解析计算图上的梯度传播快得多。B 所称两种体系只能二选一并不成立，数值差分还常用于梯度检查。

### 20. TTFT 恶化的即时措施

题目：你维护的在线问答服务（vLLM）在晚高峰出现：TTFT 从 0.9s 升到 2.4s、decode tokens/s 基本不变、平均输入长度从 700 升到 2200、GPU 利用率接近满载。你本班次可立即执行哪些动作？

- A. 对超长输入先走“摘要压缩链路”，再送主模型
- B. 增大 temperature 到 1.2
- C. 把 `max_new_tokens` 从 512 调到 1024
- D. 开启或优化 prefix cache（固定 system prompt 场景）

答案：A、D

解析：输入长度从 700 增至 2200，而 decode 速度不变，瓶颈指向 Prefill 和排队。摘要压缩可缩短输入，固定系统提示下 prefix cache 可复用前缀计算。调高温度不降低 Prefill 成本，增大 `max_new_tokens` 反而增加生成负担。
