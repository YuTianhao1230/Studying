# 机器学习基础

本目录回答“机器学习与深度学习中可跨任务复用的基础公式、概念和组件是什么”。内容从数学、统计和传统机器学习出发，再进入损失函数、激活函数、初始化、归一化、正则化和强化学习基础，为后续模型、训练和评测专题打地基。

本目录只维护数学推导、通用损失、经典模型和神经网络基础组件；模型专属结构见[大模型](<../02_大模型/README.md>)，参数更新方法见[训练优化与对齐](<../03_训练优化与对齐/README.md>)，数据治理与实验评测见[评测实验与数据质量](<../04_评测实验与数据质量/README.md>)。
