# Studying 看板 · 使用说明

把 `Studying/` 下的 Markdown 笔记变成一个可搜索的本地网页看板。

## 核心原则：内容和框架分离

```
Studying/
├── 01_机器学习基础/ ... 11_搜索推荐广告/   ← 内容：随便增删改
├── README.md                              ← 内容
└── _board/                                ← 框架：不用动
    ├── index.html
    ├── 启动看板.bat                        ← 双击：起本地服务 + 打开浏览器（推荐）
    ├── 刷新数据.bat                        ← 只重建数据，不起服务
    ├── server.py                          ← 本地静态服务（含 /__rebuild 一键重建）
    ├── build.py                           ← 扫描内容生成数据的脚本
    └── assets/
        ├── data.js                        ← 自动生成（每次重建会被覆盖）
        ├── md.js                          ← Markdown 渲染器
        ├── app.js                         ← 看板交互逻辑
        └── style.css                      ← 样式
```

**改内容不需要碰框架任何一行代码。** 唯一要做的动作是重建数据。

## 日常三步

1. 在 `Studying/` 下正常编辑 `.md` 笔记（新增、修改、删除、改文件名、新建目录都行）
2. 双击 `_board/刷新数据.bat`
3. 回到浏览器刷新页面

> 没有 Python 的话也可以手动执行：`python _board/build.py`

## 一键重建（推荐）

双击 `_board/启动看板.bat`：它会启动本地服务并打开 <http://localhost:3000>。
之后在页面左下角点 **「⟳ 重建数据」** 就能直接重建当前内容并自动刷新，不用再去双击 bat。

原理：浏览器出于安全限制**不能**自己运行 `build.py`，所以这个按钮必须由本地
`server.py`（提供 `/__rebuild` 接口）代跑。因此：

| 打开方式 | 「重建数据」按钮 |
| --- | --- |
| `启动看板.bat` / `python server.py` | ✅ 可一键重建 |
| 双击 `index.html`（file:// 本地文件） | ⚠️ 无法运行脚本，只能提示你跑 bat |
| 云端部署链接 | ⚪ 自动隐藏（云端不含源笔记，构建无意义）

## 内容上做什么会自动生效

| 你的动作 | 看板的反应 |
| --- | --- |
| 新增一篇 `.md` | 自动出现在对应分类下，可被搜索 |
| 新建一级目录 | 自动成为一个新分类，分配新颜色 |
| 新建二级目录 | 自动成为分类下的子分组 |
| 删掉某篇笔记 | 重建后从看板消失 |
| 改文件名 / 移动位置 | 自动跟着变，无需配置 |
| 笔记里写 `## 知识点解析` `## 面试应对` | 自动出现在目录大纲里，可快速跳转 |
| 修改根目录《学习路线总览.md》的路线 / 步骤 | 首页与路线页的「复习路线」自动更新 |
| 笔记之间用相对链接互链 | 自动变成看板内跳转 |

不需要维护任何索引文件、目录配置或侧边栏清单 —— 全部由目录结构推导。

## 看板功能

- **复习路线**：自动解析根目录《学习路线总览.md》的复习路线（模型训练 / 后训练 / 项目闭环 / 推理部署 / 多模态 / Agent / Coding / 冲刺计划），首页直达、侧边栏可进路线列表，每条路线按步骤顺序展示可点击的笔记
- **总览页**：笔记数 / 分类数 / 字数统计、复习路线卡、知识域卡片、最近更新
- **分类页**：按子目录分组列出全部笔记和摘要
- **阅读页**：正文渲染、右侧目录大纲（滚动自动高亮）、上一篇/下一篇
- **全文搜索**：`Ctrl + K` 或 `/` 聚焦，回车看全部结果，标题正文一起搜，命中处高亮
- **深浅色切换**、代码块一键复制、表格 / 公式 / 图片渲染、键盘 ←/→ 翻篇、回到顶部
- **URL 直达**：地址栏 `#/doc/02_大模型/基础架构/GQA.md` 可直接定位到某篇，`#/route/模型训练主线` 直达某条路线
- **已读标记（手动）**：阅读页标题下有 `○ 标为已读 / ✓ 已读` 按钮；侧栏每条右侧的 `✓ / ● / ○` 也可点一下切换（不会跳转）
- **有更新提醒**：标过已读的笔记若之后内容变了，侧栏显示 `●` 并在打开时弹出「高亮变更处」，标出本次新增/修改的段落
- **重点标黄（做笔记）**：鼠标移到任意段落 / 代码行，点左上角 `✎` 即可标黄；侧栏「我的标注」汇总全部标黄并可点击跳回原处

> 以上标记都存在浏览器本地（localStorage），换浏览器或清缓存会丢失，不影响笔记源文件。

## 备注

- 纯静态、零依赖、不联网也能用，双击 `index.html` 即可打开（但此时「重建数据」按钮不可用，见上文）
- `assets/data.js` 是生成物，建议不要手动编辑；如果用了 Git，可以把它加进 `.gitignore`
- 想改配色、字号、布局，改 `assets/style.css` 顶部的 CSS 变量即可
