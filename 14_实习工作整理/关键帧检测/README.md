## 复习顺序

1. 先看 [模型训练总览.md](<模型训练总览.md>)，建立完整项目叙事。
2. 再看 [任务定义与标注标准.md](<任务定义与标注标准.md>) 和 [BadCase归因与UI元素治理.md](<BadCase归因与UI元素治理.md>)，准备任务难点和归因追问。
3. 接着看 [数据飞轮与主动学习.md](<数据飞轮与主动学习.md>) 和 [CoT蒸馏与RL方案.md](<CoT蒸馏与RL方案.md>)，准备训练和数据闭环追问。
4. 最后看 [部署上线与容量评估.md](<部署上线与容量评估.md>)，准备工程落地和线上排查追问。
