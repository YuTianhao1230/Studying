## 学习路线

1. 先看 [实习项目总复盘与可迁移方法.md](<实习项目总复盘与可迁移方法.md>)，建立三条业务线共同的问题解决框架。
2. 再看 [关键帧检测/方案与训练流程/关键帧检测完整训练方案.md](<关键帧检测/方案与训练流程/关键帧检测完整训练方案.md>)，理解最完整的模型训练、数据治理、评测和上线闭环。
3. 细看关键帧深挖卡片：任务定义、bad case 归因、数据飞轮、SFT、CoT-SFT、GRPO 和部署上线。
4. 再看 [D2C/视觉还原度评估.md](<D2C/视觉还原度评估.md>) 和 [D2C/VLM评估体系与准出治理.md](<D2C/VLM评估体系与准出治理.md>)，理解 VLM 评测、评分一致性和业务准出口径。
5. 接着看 [端模安全/安全评估总览.md](<端模安全/安全评估总览.md>) 和 [端模安全/对抗与海绵攻击实验复盘.md](<端模安全/对抗与海绵攻击实验复盘.md>)，补充 AI 安全、鲁棒性和效率攻击相关工作。
6. 最后看 [实习项目面试问答.md](<实习项目面试问答.md>)，把项目事实转成 30 秒、2 分钟和深挖问题回答。
