## 学习路线

1. 先看 [关键帧检测/模型训练总览.md](<关键帧检测/模型训练总览.md>)，这是实习经历中最能体现模型训练、数据治理、评测和上线闭环的主项目。
2. 细看关键帧深挖卡片：任务定义、bad case 归因、数据飞轮、CoT/RL、部署上线。
3. 再看 [D2C/视觉还原度评估.md](<D2C/视觉还原度评估.md>) 和 [D2C/VLM评估体系与准出治理.md](<D2C/VLM评估体系与准出治理.md>)，理解 VLM 评测、评分一致性和业务准出口径。
4. 接着看 [端模安全/安全评估总览.md](<端模安全/安全评估总览.md>) 和 [端模安全/对抗与海绵攻击实验复盘.md](<端模安全/对抗与海绵攻击实验复盘.md>)，补充 AI 安全、鲁棒性和效率攻击相关工作。
5. 最后看 [实习项目面试问答.md](<实习项目面试问答.md>)，把项目事实转成 30 秒、2 分钟和深挖问题回答。
