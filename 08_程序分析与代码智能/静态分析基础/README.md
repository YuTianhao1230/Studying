# 静态分析基础

本目录整理程序分析和静态分析基础概念，适合在学习 CodeQL、Joern 和代码智能模型之前先建立程序结构表示。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [程序分析.md](<程序分析.md>) | 程序分析的目标、方法和应用场景总览。 |
| [静态分析.md](<静态分析.md>) | 不运行程序时进行代码性质分析的方法。 |
| [AST_CFG_DFG.md](<AST_CFG_DFG.md>) | AST、CFG、DFG 的结构和作用。 |
| [控制流分析.md](<控制流分析.md>) | 分支、循环、函数调用和程序执行路径分析。 |
| [数据流分析.md](<数据流分析.md>) | 变量定义、使用、传播和依赖关系分析。 |
| [污点分析.md](<污点分析.md>) | source、sink、sanitizer 和安全漏洞传播路径。 |

## 学习路线

1. 先看 [程序分析.md](<程序分析.md>) 和 [静态分析.md](<静态分析.md>)。
2. 再看 AST/CFG/DFG、控制流和数据流。
3. 最后看 [污点分析.md](<污点分析.md>)，连接漏洞检测场景。
