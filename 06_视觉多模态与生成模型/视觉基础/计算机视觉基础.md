# 计算机视觉基础

## 知识点解析

### 概述

计算机视觉基础关注如何把像素转换为可用于分类、检测、分割和多模态理解的表示。面试重点包括卷积的归纳偏置、ResNet 的残差结构、ViT 的 Patch 表示、常见视觉任务与指标，以及数据增强和迁移学习的工程取舍。

### 图像与卷积

图像通常表示为 `C × H × W` 张量。卷积核在局部区域共享参数，具备两个重要归纳偏置：

- 局部连接：邻近像素通常具有更强相关性。
- 平移等变性：目标移动后，卷积响应也随之移动。

二维卷积输出尺寸：

```text
H_out = floor((H + 2P - D * (K - 1) - 1) / S + 1)
```

其中 `K` 是卷积核大小，`S` 是步长，`P` 是 Padding，`D` 是空洞率。卷积参数量约为 `K_h * K_w * C_in * C_out`。

### CNN 与 ResNet

CNN 通常通过卷积提取局部特征，通过下采样扩大感受野并压缩空间尺寸。浅层特征偏向边缘和纹理，深层特征偏向语义。

深层网络直接学习目标映射 `H(x)` 较困难，ResNet 改为学习残差：

```text
y = F(x) + x
```

恒等捷径为梯度提供直接传播路径，缓解深层网络退化和优化困难。如果通道数或空间尺寸不同，需要使用投影捷径对齐形状。

### Vision Transformer

ViT 把图像切成固定大小 Patch，将每个 Patch 展平并线性投影成 Token，再加入位置编码送入 Transformer。

若图像大小为 `H × W`、Patch 大小为 `P × P`，视觉 Token 数量为：

```text
N = (H / P) * (W / P)
```

Patch 越小，细节越丰富，但 Attention 复杂度随 Token 数平方增长。相比 CNN，ViT 的局部归纳偏置更弱，通常更依赖数据规模和预训练，但更容易与语言模型架构统一。

| 对比项 | CNN | ViT |
| --- | --- | --- |
| 核心操作 | 局部卷积 | 全局自注意力 |
| 归纳偏置 | 局部性、平移等变 | 较弱 |
| 长距离建模 | 依靠堆叠扩大感受野 | 单层可全局交互 |
| 数据需求 | 相对较低 | 通常更依赖预训练 |
| 多模态衔接 | 需要转换特征 | 天然输出 Token 序列 |

### 分类、检测与分割

- 图像分类：为整张图预测类别，常用 Accuracy、Top-k Accuracy。
- 目标检测：同时预测类别和边界框，常见结构包括两阶段 Faster R-CNN 和单阶段 YOLO、DETR。
- 语义分割：为每个像素预测语义类别，同类目标不区分实例。
- 实例分割：区分同一类别的不同对象实例。
- Grounding：根据文本定位图像区域或根据区域生成文本描述。

DETR 将目标检测转化为集合预测问题，通过 Transformer 和匈牙利匹配减少锚框与 NMS 的依赖。SAM 更强调可提示分割和跨任务泛化。

### IoU 与 mAP

IoU 衡量预测框和真实框的重叠程度：

```text
IoU = 交集面积 / 并集面积
```

检测评测先在给定 IoU 阈值下匹配预测框和真实框，再根据置信度计算 Precision-Recall 曲线及 AP。mAP 是多个类别或多个 IoU 阈值下 AP 的平均值。

需要注意：

- 分类正确但定位不准仍可能是检测错误。
- 置信度阈值会影响 Precision 和 Recall。
- COCO mAP 会综合 `0.50:0.95` 多个 IoU 阈值，比只看 `AP50` 更严格。

### 数据增强

常见增强包括随机裁剪、翻转、颜色扰动、Mixup、CutMix、RandAugment 和随机擦除。增强的目标是引入符合真实场景的不变性，而不是越强越好。

- 几何增强必须同步变换框、Mask 和关键点标签。
- OCR 和方向敏感任务不能随意翻转。
- 颜色是业务关键信号时，颜色扰动要受控。
- 验证集通常只做确定性预处理，不能引入随机增强。

### 迁移学习与微调

数据较少时通常从预训练模型开始：

1. 冻结 Backbone，只训练任务头，快速验证数据和任务定义。
2. 逐步解冻高层，使用较小学习率微调。
3. 数据量充足或领域差异较大时，再考虑全量训练。

如果训练集效果好但验证集差，应优先检查数据切分、重复样本、增强强度和标签噪声，而不是直接换更大模型。

### 多模态中的视觉编码器

VLM 常使用 CLIP/SigLIP ViT 作为视觉编码器，将 Patch Token 通过 MLP、Q-Former 或 Cross-Attention 对齐到 LLM 空间。多图、视频和高分辨率输入的关键矛盾是视觉细节与 Token 成本：

- 提高分辨率有助于 OCR 和小目标，但增加 Token 和计算量。
- AnyRes 或切图可以保留细节，但需要处理全局与局部关系。
- Token Pooling、Q-Former 和动态压缩可以降低上下文占用，但可能损失细粒度信息。

## 面试应对

### CNN 和 ViT 有什么区别？

回答思路：从运算、归纳偏置、数据需求和多模态衔接回答。

回答模板：

CNN 通过局部卷积和参数共享建模图像，天然具有局部性和平移等变的归纳偏置，因此在数据较少时也比较容易训练。ViT 把图像切成 Patch Token，用自注意力做全局交互，长距离建模更直接，也更容易和语言 Transformer 对接，但注意力复杂度随 Token 数平方增长，通常更依赖大规模预训练。实际选择还要看数据量、分辨率、延迟和是否需要接入多模态模型。

### ResNet 为什么有效？

回答思路：说明残差学习和梯度路径，不把原因简单归结为避免梯度消失。

回答模板：

ResNet 让网络学习残差 `F(x)`，输出是 `F(x) + x`。如果新增层暂时学不到有用变换，它至少可以接近恒等映射，因此深层网络不会因为多加几层就更难优化。捷径连接还为梯度提供了直接传播路径，缓解深层网络的退化问题。它不只是解决梯度消失，更重要的是让很深的网络更容易优化。

### IoU 和 mAP 分别衡量什么？

回答思路：先讲单个框重叠，再讲整个检测器的综合排序表现。

回答模板：

IoU 衡量一个预测框和真实框的交并比，反映单次定位有多准确。mAP 则先在指定 IoU 阈值下判断预测是否匹配，再根据不同置信度阈值形成 Precision-Recall 曲线并计算 AP，最后对类别或多个 IoU 阈值取平均。因此 IoU 是框级重叠指标，mAP 是检测系统整体分类、定位和置信度排序能力的综合指标。
