# OCR 与文档理解

## 一句话解释

OCR 是把图片中的文字识别出来；文档理解是在 OCR 基础上进一步理解版面、结构、表格、语义和任务答案。

## OCR 解决什么

OCR，Optical Character Recognition，主要解决：

- 图片文字检测。
- 文本行识别。
- 表格文字提取。
- 票据、合同、证件、截图识别。

传统 OCR 更关注“识别出文字”；文档理解更关注“理解这些文字在文档里的含义和结构”。

## 文档理解任务

常见任务：

- Layout Analysis：版面分析。
- Table Understanding：表格理解。
- Key Information Extraction：关键信息抽取。
- Document VQA：基于文档图像问答。
- Chart Understanding：图表理解。
- Multi-page Reasoning：跨页推理。

## 大模型时代的变化

多模态大模型让 OCR 和文档理解开始融合：

```text
图像输入
  -> 视觉编码
  -> 文本识别 / 版面理解
  -> 多模态推理
  -> 结构化输出
```

模型不只是读字，还要理解：

- 字在哪里。
- 属于哪个字段。
- 和其他元素有什么关系。
- 是否支持用户问题的答案。

## 关键难点

- 低清晰度图片。
- 复杂表格。
- 多栏排版。
- 手写体。
- 旋转、遮挡、噪声。
- 图文位置关系。
- 跨页字段关联。

## 评测指标

- 字符准确率。
- 文本行召回率。
- 字段抽取准确率。
- 表格结构还原准确率。
- VQA 准确率。
- Grounding 准确率。
