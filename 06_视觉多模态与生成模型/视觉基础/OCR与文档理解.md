# OCR 与文档理解

## 一句话解释

OCR 是把图片中的文字识别出来；文档理解是在 OCR 基础上进一步理解版面、结构、表格、语义和任务答案。

## OCR 解决什么

OCR，Optical Character Recognition，主要解决：

- 图片文字检测。
- 文本行识别。
- 表格文字提取。
- 票据、合同、证件、截图识别。

传统 OCR 更关注“识别出文字”；文档理解更关注“理解这些文字在文档里的含义和结构”。

## 文档理解任务

常见任务：

- Layout Analysis：版面分析。
- Table Understanding：表格理解。
- Key Information Extraction：关键信息抽取。
- Document VQA：基于文档图像问答。
- Chart Understanding：图表理解。
- Multi-page Reasoning：跨页推理。

## 大模型时代的变化

多模态大模型让 OCR 和文档理解开始融合：

```text
图像输入
  -> 视觉编码
  -> 文本识别 / 版面理解
  -> 多模态推理
  -> 结构化输出
```

模型不只是读字，还要理解：

- 字在哪里。
- 属于哪个字段。
- 和其他元素有什么关系。
- 是否支持用户问题的答案。

## 关键难点

- 低清晰度图片。
- 复杂表格。
- 多栏排版。
- 手写体。
- 旋转、遮挡、噪声。
- 图文位置关系。
- 跨页字段关联。

## 评测指标

- 字符准确率。
- 文本行召回率。
- 字段抽取准确率。
- 表格结构还原准确率。
- VQA 准确率。
- Grounding 准确率。

## 面试可能怎么问

1. OCR 和文档理解有什么区别？
   - 回答思路：先分别定义两个概念，再从目标、机制、适用场景和工程取舍四个角度对比。
   - 回答模板：先分别定义两个对象，再比较目标、机制、适用场景和风险。围绕 OCR与文档理解，关键是说明它们解决的问题不同。
2. 如何评估一个文档理解模型？
   - 回答思路：按“目标定义 -> 关键步骤 -> 风险控制 -> 指标验证”的顺序回答，避免只讲抽象原则。
   - 回答模板：要分层评估：OCR 字符准确率、字段抽取准确率、表格结构还原、版面定位、DocVQA 正确率和跨页推理能力。复杂任务还要看证据区域是否正确。
3. 多模态大模型如何处理文档图片？
   - 回答思路：先定义问题，再说明核心机制、适用边界、风险和验证方式。
   - 回答模板：这个问题在 OCR与文档理解 场景下，核心是说明它解决什么实际工程问题，以及如何落地。完整回答需要覆盖目标、执行方式、失败风险和验证指标。
4. 表格识别为什么难？
   - 回答思路：先定义问题，再说明核心机制、适用边界、风险和验证方式。
   - 回答模板：这个问题在 OCR与文档理解 场景下，核心是说明它解决什么实际工程问题，以及如何落地。完整回答需要覆盖目标、执行方式、失败风险和验证指标。
5. 如何处理跨页文档理解？
   - 回答思路：按“目标定义 -> 关键步骤 -> 风险控制 -> 指标验证”的顺序回答，避免只讲抽象原则。
   - 回答模板：我会把 处理跨页文档理解 拆成几个步骤：先明确目标和输入输出，再设计关键模块或策略，然后加入失败处理和权限/质量约束，最后用离线指标、线上指标或回归测试验证效果。在 OCR与文档理解 场景里，重点是能落到真实工程流程。
