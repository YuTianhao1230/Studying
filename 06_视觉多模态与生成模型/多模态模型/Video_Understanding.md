# Video_Understanding

## 知识点解析

### 概述

Video Understanding 是让模型理解视频中的时序、画面、动作、声音、文本和事件，并回答问题或完成分类、检索、生成等任务。

### 为什么比图像理解更难

图像理解主要处理单帧信息；视频理解还要处理时间维度。

难点包括：

- 视频帧数量大。
- 时序关系复杂。
- 关键事件可能很短。
- 音频、字幕、画面需要融合。
- 长视频上下文成本高。
- 采样策略会直接影响效果。

### 典型任务

- 视频分类。
- 视频问答。
- 视频摘要。
- 动作识别。
- 事件定位。
- 多模态检索。
- 视频生成质量评估。
- 视频关键帧识别。

### 常见技术路线

#### 固定帧采样

按固定 FPS 或固定间隔抽帧。

优点：

- 简单。
- 成本可控。

缺点：

- 容易错过短时关键事件。
- 对不同节奏视频不够自适应。

#### 自适应帧采样

根据画面变化、动作变化、语义变化选择帧。

适合：

- 长视频。
- 关键事件稀疏的视频。
- 成本敏感场景。

#### 多模态融合

融合：

- 图像帧。
- 音频。
- ASR 字幕。
- OCR 文本。
- 用户行为。
- 时间戳信息。

#### Video-LLM

将视频编码为视觉 token 或片段表示，再接入 LLM 做推理。

### 关键工程问题

- 抽帧 FPS 怎么定？
- 最多输入多少帧？
- 如何压缩长视频？
- 如何定位关键时间段？
- 如何做视频 grounding？
- 如何评估时序推理是否正确？
- 推理成本如何控制？

### 和业务场景的关系

大厂多模态 JD 里经常提到视频理解，因为短视频、直播、电商、广告、内容安全都依赖视频语义。

例如：

- 视频内容推荐。
- 商品短视频理解。
- 广告素材审核。
- 直播内容识别。
- 关键帧质量评估。
- 视频生成结果评测。

## 面试应对

### 视频理解比图像理解难在哪？

回答思路：核心抓住“多了时间维度”，再展开帧数、时序、关键事件稀疏、多模态融合、成本几个具体难点。

回答模板：

图像理解只处理单帧，视频理解多了时间维度，难点主要有几个：一是帧数量大，一段几分钟的视频按 1 FPS 抽也有几百帧，全喂进模型上下文和显存都扛不住；二是时序关系复杂，很多任务要理解动作的先后和因果，不是看单帧能解决的；三是关键事件可能很短，比如进球或者某个动作只有一两秒，采样稍粗就漏了；四是要融合画面、音频、字幕、OCR 多路信息。所以视频理解的核心工程问题往往不是模型，而是怎么采样和怎么压缩长上下文。

### 固定帧采样和自适应帧采样怎么选？

回答思路：先说两者机制和优缺点，再落到“按视频节奏和事件稀疏程度、结合成本预算”做取舍。

回答模板：

固定帧采样就是按固定 FPS 或固定间隔抽帧，优点是简单、成本可控、实现稳定，缺点是对不同节奏的视频不自适应，容易错过短时关键事件。自适应采样根据画面变化、动作变化或语义变化来选帧，更适合长视频和关键事件稀疏的场景，能在同样帧预算下覆盖更多关键信息，代价是要额外算变化度、实现更复杂。实际选型我会看两点：视频是不是长而事件稀疏、成本预算够不够。均匀短视频用固定采样就够，长视频或关键帧任务更适合自适应采样，我在关键帧识别项目里就是走的这条路。

### 长视频理解怎么控制 token 成本？

回答思路：从减少帧数、压缩每帧 token、分层处理三个层面给具体手段。

回答模板：

主要从三个层面压。第一是减少帧数，用自适应采样或先做镜头切分只保留代表帧，而不是密集抽帧。第二是压缩每帧的视觉 token，比如用 Q-Former 或 pooling 把每帧几百个 patch token 压到几十个，或者对相邻相似帧做合并。第三是分层处理，先用轻量模型或检索定位到相关片段，再只把相关片段送给大模型精细理解，而不是一次性把整段视频塞进去。核心思路和长文本一样：先粗筛定位，再精读，避免上下文爆炸。

### 怎么评估视频问答或视频摘要模型？

回答思路：区分有标准答案和开放生成两类，分别给指标，并强调时序正确性和 bad case。

回答模板：

要分任务类型。有明确答案的，比如选择题式视频问答，直接算准确率；有时间定位的，用 temporal IoU 看预测时间段和真实事件段的重叠。开放式的视频摘要或描述，单一指标不够，我会结合参考答案的相似度指标和 LLM-as-judge，重点看是否覆盖了关键事件、有没有时序错误、有没有幻觉出画面里没有的内容。另外一定要看 bad case，特别是短事件漏检和时序颠倒这类问题，平均分往往掩盖了这些关键失败。

### 视频理解在业务里有哪些典型落地？

回答思路：结合大厂多模态场景举例，落到推荐、审核、电商、关键帧质量评估等。

回答模板：

短视频、直播、电商、广告、内容安全都强依赖视频语义。典型的有视频内容推荐里的理解打标、广告和直播素材的机审审核、电商商品短视频的卖点提取，还有视频生成结果的质量评测。我做过的关键帧识别就是其中一环，给视频挑出最有代表性或质量最好的帧，用来做封面、审核或后续理解的输入，本质是把“理解视频”落到“选对帧”这个可量化的子问题上。
