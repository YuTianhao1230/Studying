# 训练优化与对齐

本目录回答“模型参数如何被训练、更新并稳定收敛”。内容覆盖训练路线、训练工程、后训练对齐、参数体系和训练稳定性，按训练阶段、训练系统、优化目标和故障排查组织。

## 内容边界

- 优化器、超参数、并行训练、稳定性及 SFT/DPO/PPO/GRPO/RLVR 等通用训练方法放在这里。
- 训练数据、合成数据、切分、污染、质量治理、指标和实验评测统一由 [04_评测实验与数据质量](<../04_评测实验与数据质量/README.md>)维护，本目录只保留训练流程中的入口。
- 模型结构和生成机制进入 [02_大模型](<../02_大模型/README.md>)；推理与生产部署进入 [05_推理部署与系统](<../05_推理部署与系统/README.md>)。
- 本目录说明可迁移的训练方法；[关键帧检测](<../12_实习工作整理/关键帧检测/README.md>)只记录个人实习中做了什么、为何这样选择、如何实施以及结果如何。
