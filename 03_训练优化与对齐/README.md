# 训练优化与对齐

本目录回答“模型参数如何被训练、更新并稳定收敛”。内容覆盖训练路线、训练工程、后训练对齐、参数体系和训练稳定性，按训练阶段、训练系统、优化目标和故障排查组织。

本目录只维护优化器、超参数、并行训练、稳定性和通用后训练方法；模型结构见[大模型](<../02_大模型/README.md#大模型>)，数据与评测见[评测实验与数据质量](<../04_评测实验与数据质量/README.md#评测实验与数据质量>)，推理部署见[推理部署与系统](<../05_推理部署与系统/README.md#推理部署与系统>)，个人项目事实见[实习工作整理](<../12_实习工作整理/README.md#实习工作整理>)。
