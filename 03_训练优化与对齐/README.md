# 训练优化与对齐

本目录存放模型训练路线、训练工程、后训练对齐、并行框架、损失函数和训练稳定性内容。分类依据是先建立训练总纲，再按训练阶段、训练系统、优化目标和故障排查拆分。

| 子目录 | 内容说明 |
| --- | --- |
| [后训练与对齐](<后训练与对齐/README.md>) | SFT、RLHF、DPO、PPO、GRPO、RLVR、Agentic RL、Reward Model 等后训练方法。 |
| [训练框架与并行](<训练框架与并行/README.md>) | DeepSpeed、ZeRO、FSDP、Megatron-LM、JAX/XLA、混合精度和 Checkpoint。 |
| [训练稳定性](<训练稳定性/README.md>) | Loss 异常、收敛排查、梯度爆炸和梯度消失等训练故障。 |
| [损失函数与激活函数](<损失函数与激活函数/README.md>) | 分类损失、回归损失、激活函数和 GeLU 等基础组件。 |
