# 训练稳定性

本目录存放训练故障排查类内容，不是普通名词卡片。重点是面对 loss、梯度和收敛异常时，能够给出系统排查流程。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [Loss异常与收敛排查.md](<Loss异常与收敛排查.md>) | Loss 不降、突增、NaN、验证指标不升等训练异常的排查方法。 |
| [梯度爆炸与梯度消失.md](<梯度爆炸与梯度消失.md>) | 梯度爆炸/消失的成因、判断方法和解决策略。 |

## 学习路线

1. 先看 [Loss异常与收敛排查.md](<Loss异常与收敛排查.md>)，建立训练异常定位框架。
2. 再看 [梯度爆炸与梯度消失.md](<梯度爆炸与梯度消失.md>)，补齐梯度层面的机制解释。
3. 复习时要结合训练日志、学习率、batch、数据质量和混合精度一起判断。
