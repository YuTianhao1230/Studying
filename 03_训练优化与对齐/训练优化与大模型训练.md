# 训练优化与大模型训练

## 知识点解析

### 概述

训练优化与大模型训练关注如何在有限算力、显存和数据预算下，让模型稳定、高效地收敛。核心问题包括优化器与学习率、Batch 和梯度、混合精度、并行策略、显存管理、数据吞吐、[Checkpoint](<训练框架与并行/Checkpoint.md>)，以及训练异常的定位与恢复。

3. [LoRA](<后训练与对齐/LoRA 低秩适配.md>)、[Adapter](<后训练与对齐/Adapter 参数高效微调.md>)、Prefix Tuning、全量微调有什么区别？
4. LoRA 的低秩假设是什么？`rank`、`alpha`、`target_modules` 如何影响效果？
5. Deepspeed ZeRO-1/2/3 分别切分了什么？
6. 数据并行、张量并行、流水线并行、专家并行的区别是什么？

### 核心知识点

- 训练阶段：pretrain、continual pretrain、SFT、preference alignment、distillation。
- 参数高效微调：LoRA、[QLoRA](<后训练与对齐/PEFT 参数高效微调.md>)、Adapter、Prefix/Prompt Tuning、BitFit。
- 分布式训练：DDP、[FSDP](<训练框架与并行/FSDP.md>)、[ZeRO](<训练框架与并行/ZeRO.md>)、TP、PP、EP、sequence parallel、[多 GPU 通信](<训练框架与并行/多GPU并行通信与吞吐优化.md>)。
- 显存组成：参数、梯度、优化器状态、激活、[KV cache](<../05_推理部署与系统/推理工程/KV_Cache与Prefill_Decode.md>)、临时 buffer。
- 优化策略：gradient accumulation、activation checkpointing、gradient clipping、mixed precision。
- 数据策略：数据配比、去重、质量过滤、packing、mask、采样权重。
- 稳定性监控：loss、grad norm、learning rate、token throughput、OOM、通信耗时。
- checkpoint：保存频率、latest/best、断点恢复、优化器状态、随机种子、版本元数据。

#### 回答要点

- 预训练学习通用语言/世界知识，SFT 学习指令遵循，偏好对齐让模型输出更符合人类偏好或业务偏好。
- LoRA 在冻结原模型参数的基础上，用低秩矩阵近似权重更新，训练成本低但表达能力受 rank 和注入位置影响。
- ZeRO-1 切优化器状态，ZeRO-2 进一步切梯度，ZeRO-3 连参数也切分。
- 显存优化常用混合精度、梯度累积、activation checkpointing、ZeRO/FSDP、降低序列长度或 batch size。
- 训练稳定性不能只看 loss，还要看梯度范数、数据异常、学习率曲线、样本长度分布和异常 batch。

## 面试应对

### 如何判断训练瓶颈在计算、通信还是数据加载？

回答思路：使用阶段耗时和资源利用率定位。

回答模板：

我会把一个 Step 拆成数据等待、前向、反向、集合通信、优化器和 Checkpoint 分别计时。GPU 利用率低且 [DataLoader](<../07_Python与工程/常用库/DataLoader.md>) 等待高，通常是数据瓶颈；计算 Kernel 持续占满且通信占比低，通常是算力瓶颈；多卡扩展后吞吐提升很差、Collective 耗时高，则重点检查通信、拓扑和负载不均。最终用 Profile 和各 Rank 指标验证，而不是只看总 Step 时间。

### 如何估算大模型训练显存？

回答思路：拆分参数、梯度、优化器、激活和临时 Buffer。

回答模板：

训练显存不能只按参数量乘数据类型字节数计算。我会分别估算模型参数、梯度、FP32 主参数、Adam 的一阶和二阶状态、激活、通信 Buffer 以及框架开销。模型状态主要随参数量增长，激活主要随 Batch、序列长度、层数和隐藏维度增长。再根据 ZeRO 或 FSDP 的切分阶段、Activation Checkpointing 和混合精度调整每卡占用，并预留碎片和峰值空间。

### Checkpoint 为什么不能只保存模型权重？

回答思路：说明精确续训还依赖优化器与随机状态。

回答模板：

只保存模型权重可以用于推理，但不能保证精确续训。恢复训练还需要优化器状态、学习率调度器、GradScaler、Global Step、随机数状态、数据迭代位置和并行配置。缺少这些状态可能导致学习率错位、动量丢失、样本重复或结果无法复现，所以训练 Checkpoint 应保存完整训练状态。
