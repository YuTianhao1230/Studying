# 损失函数与激活函数

本目录整理训练中最常用的 loss 和 activation。它们是理解模型优化、梯度流和任务目标设计的基础。

| [常见回归损失函数.md](<常见回归损失函数.md>) | MSE、MAE、Huber 等回归损失及适用场景。 |

## 学习路线

1. 先看 [常见分类损失函数.md](<常见分类损失函数.md>) 和 [常见回归损失函数.md](<常见回归损失函数.md>)，理解任务目标。
2. 再看 [常见激活函数.md](<常见激活函数.md>)，理解非线性表达。
3. 最后看 [GeLU.md](<GeLU.md>)，连接到 Transformer FFN 的常用设计。
