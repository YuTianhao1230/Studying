# Optimizer 优化器

## 知识点解析

### 概述

Optimizer（优化器）决定模型在拿到 loss 和梯度之后，**到底怎么更新参数**。Loss 告诉模型“错了多少”，反向传播算出梯度告诉模型“往哪个方向改”，Optimizer 决定“每一步怎么改、改多大、要不要带历史惯性、要不要做正则”。

训练中的基本链路是：

```text
前向计算 -> 得到 loss
反向传播 -> 得到每个参数的梯度 grad
Optimizer -> 根据 grad 更新参数
```

最朴素的更新公式是：

```text
参数 = 参数 - 学习率 * 梯度
```

不同 optimizer 的区别，本质上就是**如何利用当前梯度、历史梯度、梯度尺度和正则项来更新参数**。

### SGD

SGD 全称是 **Stochastic Gradient Descent，随机梯度下降**。

最基础形式是：

```text
w = w - lr * grad
```

其中：

- `w`：模型参数。
- `lr`：learning rate，学习率。
- `grad`：当前 mini-batch 算出来的梯度。

它的思想很直接：梯度指向 loss 上升最快的方向，所以沿着梯度的反方向走，让 loss 下降。

之所以叫 Stochastic，是因为真实训练不是每次用全量数据算梯度，而是用一个 mini-batch 估计梯度，所以这个梯度带随机性。

优点：

- 原理简单。
- 额外状态少，显存开销低。
- 在一些视觉分类等任务上泛化能力不错。

缺点：

- 收敛较慢。
- 对 learning rate 很敏感。
- 不同参数尺度差异很大时不好调。
- 容易在狭长损失地形里来回震荡。

### Momentum

Momentum 是在 SGD 上加“历史惯性”。

普通 SGD 每一步只看当前梯度，容易被当前 batch 的噪声带偏。Momentum 会维护一个历史方向：

```text
历史方向 = momentum * 历史方向 + 当前梯度
参数 = 参数 - lr * 历史方向
```

直观理解：

- 如果连续很多步都往同一个方向走，Momentum 会加速。
- 如果某个方向梯度来回震荡，历史梯度会互相抵消，更新更稳。

所以 Momentum 主要解决 SGD 的两个问题：**减少震荡、加速收敛**。

### Adam

Adam 是深度学习里非常常用的优化器，它可以看作“Momentum + 自适应学习率”。

Adam 维护两类统计量：

```text
一阶动量 m：梯度的滑动平均，表示历史更新方向
二阶动量 v：梯度平方的滑动平均，表示梯度尺度和波动
```

直观理解：

- 某个参数梯度一直稳定同向，Adam 会更放心地更新。
- 某个参数梯度很大、波动很剧烈，Adam 会自动把步子缩小。
- 不同参数可以有不同的有效学习率。

Adam 的优点是收敛快、好上手、对学习率没有 SGD 那么敏感，所以在 NLP、大模型微调和很多深度学习任务中非常常见。

### AdamW

AdamW 是 Adam 的改进版，也是当前大模型训练和微调里最常用的 optimizer。

它主要解决的是 **weight decay 的处理方式**。

在普通 Adam 里，如果直接把 L2 正则混进梯度，会和 Adam 的自适应学习率机制耦合在一起，导致 weight decay 的实际效果不够干净。AdamW 把 weight decay 从梯度更新里解耦出来，单独对参数做衰减：

```text
Adam：梯度更新里混着 weight decay
AdamW：先按 Adam 更新，再单独做参数衰减
```

这样 weight decay 的含义更清晰，正则效果更稳定。

大模型 SFT / LoRA 微调默认通常优先用 AdamW，因为它兼顾了：

- Adam 的自适应更新能力。
- 比 SGD 更快、更稳的收敛。
- 更清晰的 weight decay 正则。
- 成熟的工程实现和默认配置。

### Adafactor

Adafactor 可以理解成一个更省显存的 Adam 类优化器。

Adam / AdamW 需要为每个参数额外保存一阶动量和二阶动量，优化器状态很占显存。对于大模型训练，优化器状态经常比模型权重本身还要重。

Adafactor 的核心思路是压缩二阶动量的存储，尤其适合超大模型训练或显存非常紧张的场景。

优点：

- 优化器状态更省显存。
- 适合超大模型或资源受限训练。

缺点：

- 比 AdamW 更难调。
- 行为更依赖具体实现和超参数。
- 一般 SFT / LoRA 微调不优先选它，除非显存压力非常大。

### 常用选择建议

| 场景 | 常用 optimizer | 说明 |
| --- | --- | --- |
| LLM SFT / LoRA 微调 | AdamW | 默认首选，稳定、成熟、好调 |
| 大模型预训练 | AdamW / Adafactor | AdamW 常见，显存压力大时可考虑 Adafactor |
| 传统视觉分类 | SGD + Momentum / AdamW | SGD 泛化可能好，但调参成本更高 |
| 小模型快速实验 | Adam / AdamW | 收敛快，默认更省心 |

对你自己的 SFT 任务，可以先记住一个实用结论：**不特殊说明时，LLM SFT / LoRA 微调优先用 AdamW，SGD 基本不是首选。**

## 面试应对

### Optimizer 是干什么的？

回答思路：抓住“loss/梯度只给方向，optimizer 决定如何用梯度更新参数”这个训练链路位置。

回答模板：

Optimizer 决定模型如何根据梯度更新参数。训练时先前向计算 loss，再反向传播得到每个参数的梯度，optimizer 根据这些梯度、学习率和自己的更新规则去改参数。最简单的形式是参数等于参数减去学习率乘以梯度，但实际 optimizer 会进一步利用历史梯度、梯度尺度和正则项，让训练更快、更稳。

### SGD 是什么？为什么现在大模型微调不常用 SGD？

回答思路：先给出 SGD 的更新公式，再说明它简单但收敛慢、对学习率敏感，不适合大模型里参数尺度差异很大的场景。

回答模板：

SGD 是随机梯度下降，基本公式就是 `w = w - lr * grad`，沿着当前 mini-batch 梯度的反方向更新参数。它优点是简单、状态少，有些任务泛化不错；缺点是收敛慢、对学习率敏感，而且不同参数尺度差异大时不好调。大模型微调里参数量大、梯度分布复杂，所以一般不用纯 SGD，而是优先用 AdamW 这种自适应优化器。

### Momentum 解决了 SGD 的什么问题？

回答思路：抓住“给 SGD 加历史惯性”，同向梯度加速、震荡方向抵消。

回答模板：

Momentum 是给 SGD 加历史惯性。普通 SGD 每一步只看当前梯度，容易被 mini-batch 噪声影响，在狭长的 loss 地形里左右震荡。Momentum 会把历史梯度方向累积起来，如果连续多步方向一致就加速，如果某个方向来回震荡就互相抵消，所以它能减少震荡、加快收敛。

### Adam 和 SGD 的核心区别是什么？

回答思路：对比“SGD 用统一学习率直接沿梯度走”与“Adam 用一阶/二阶动量给每个参数自适应调步长”。

回答模板：

SGD 基本上是所有参数共用一个学习率，直接沿当前梯度反方向更新。Adam 会维护两个统计量：一阶动量是梯度的滑动平均，表示历史更新方向；二阶动量是梯度平方的滑动平均，表示梯度尺度。这样 Adam 可以给不同参数自适应调整有效学习率，梯度稳定的参数多更新，梯度波动大的参数少更新，所以通常比 SGD 收敛更快、也更好调。

### 为什么大模型训练和微调常用 AdamW？

回答思路：抓住 AdamW 在 Adam 基础上把 weight decay 解耦，既有自适应更新能力，又让正则含义更清晰。

回答模板：

大模型训练和微调常用 AdamW，因为它保留了 Adam 的自适应学习率能力，能处理不同参数梯度尺度差异大的问题，同时把 weight decay 从梯度更新里解耦出来，单独对参数做衰减。这样正则项的含义更清晰，训练也更稳定。实际做 LLM SFT 或 LoRA 微调时，如果没有特殊原因，我会默认选 AdamW，而不是 SGD。

### Adafactor 适合什么场景？

回答思路：点明它是为了省优化器状态显存的 Adam 类方法，适合超大模型或显存紧张，但一般微调优先 AdamW。

回答模板：

Adafactor 主要适合显存压力很大的超大模型训练。AdamW 需要为每个参数保存一阶和二阶动量，优化器状态很占显存；Adafactor 会压缩二阶动量的存储，所以更省显存。但它比 AdamW 更难调，行为也更依赖具体实现，所以一般 SFT 或 LoRA 微调我会先用 AdamW，只有显存压力特别大时再考虑 Adafactor。
