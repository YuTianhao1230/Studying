# 全史总览与总时间线

## 先抓住六次结构变化

中国历史可以沿“人群怎样组织起来、权力怎样分配、资源怎样流动”来理解。王朝名称提供时间坐标，人物与成语则帮助记住关键冲突。

1. 从史前聚落到早期国家：农业、定居、社会分工和公共权力发展；神话表达观念，考古提供另一类证据。
2. 从夏商周到春秋战国：宗法分封逐渐松动，诸侯通过改革与战争增强动员能力，最终秦统一。
3. 从秦汉到三国两晋南北朝：帝国建立与调整，中央、宗室和地方之间反复争夺权力，统一与分裂交替。
4. 从隋唐到辽宋夏金元：统一恢复、文化交流扩大；区域政权长期并立，商业与城市发展不等于战争消失。
5. 从明清到近代：皇权、地方治理与财政持续调整，海洋交流和边疆关系变化，工业化列强带来新的外部冲击。
6. 从晚清革命到现代：帝制转向共和，经过革命与战争进入国家建设，再走向改革开放与经济社会转型。

这里的日期是常用学习分期，不表示每个地区同时进入同一种制度。夏的年代、春秋战国的分界、清的建国与入关等需要按具体口径辨认。

三国图以称帝节点标吴229年，222年孙权称王另见三国概览。十六国的通常分期始于304年，图从东晋建立的317年开始截取；南北分图中的东西魏、北齐北周合并为继承条带，具体不是一国延续。北魏386年建立、439年统一北方；534—535年分裂为东西魏，550年北齐代东魏，557年北周代西魏，577年北周灭北齐。北方多政权条带与北魏早期相重叠。辽以916年建国计，947年国号“大辽”也是重要节点。

## 怎样把典故串起来

先读一则故事的时空和人物，再看它改变了什么。比如商鞅变法解释秦为何更能动员，长平说明赵为何被削弱，荆轲说明燕面对秦的压力，随后才能理解秦统一。不要把这些故事当作互不关联的道德短文。

另一条线是“宗室与地方权力”：西周分封帮助扩大统治，汉初诸侯王引发七国之乱，西晋宗室竞争酿成内战，明初藩王又卷入靖难。相似问题会重现，但每个时代的制度、财税和军事基础不同，不能简单说历史原样重复。

## 重要日期的读法

| 容易混淆的日期 | 正确区分 |
| --- | --- |
| 春秋前770—前476／《春秋》前722—前481 | 通行时代分期与经典所记时间不同。 |
| 战国前475／前403 | 前者是常用分期；后者为三家分晋获周王承认的重要制度节点。 |
| 魏220／蜀221／吴229 | 三国不是同年建立；吴222年称王、229年称帝。 |
| 南宋1276／1279 | 临安投降与崖山覆亡，分别对应不同节点。 |
| 元1206／1271／1279 | 蒙古政权建立、元国号、灭南宋，含义不同。 |
| 清1636／1644／1912 | 改国号清、入关、退位；1911革命与1912退位要分开。 |
| 抗战1931／1937 | 九一八事变与全民族抗战阶段的开始。 |
