# 在线交互资源

以下网站适合在本地卡片之外进行动态查询、缩放地图、筛选人物和观察关系网络。链接于2026年10月30日核验；外部网站的界面、数据和开放状态可能继续变化。

## 人物、关系与生平轨迹

| 入口 | 可以怎样使用 | 数据边界 |
| --- | --- | --- |
| [CHKG人物检索](https://chkg.org/persons) | 按朝代、姓名、字、号、科举和任官等条件筛选人物，进入人物档案。 | 基于CBDB与CHGIS整合数据，古代早期和材料稀少人物的覆盖不均衡。 |
| [CHKG社会网络](https://chkg.org/network) | 动态查看亲属、师承、政治交往、文学往来等关系，可拖动、缩放和筛选节点。 | 关系类型取决于数据库编码，不等于历史人物全部实际交往。 |
| [上海图书馆CBDB图谱检索](https://cbdb.library.sh.cn/gsearch) | 从人物和关系出发查询中国历代人物传记资料库中的知识图谱。 | 适合查证和扩展关系，本地人物卡仍需回到具体史籍核对。 |
| [北京大学中国历代人物可视化平台](https://cbdb-qvis.pkudh.org/home.html) | 查看[历史人物迁徙](https://cbdb-qvis.pkudh.org/part1_migrate.html)和[学术师承网络](https://cbdb-qvis.pkudh.org/part2_dizinet.html)。 | 迁徙线主要依据出生地或籍贯地与死亡地或最后所知地，不是完整逐年行迹。 |

## 历史地理与行政区

| 入口 | 可以怎样使用 | 数据边界 |
| --- | --- | --- |
| [CHKG历史地图](https://chkg.org/gis) | 拖动时间轴查看前221年至1911年间府、州、县等建制变化，并叠加人物任官和活动地点。 | 行政建制地图不等于精确疆域图，设置机构也不代表所有地区控制强度相同。 |
| [哈佛CHGIS](https://chgis.fas.harvard.edu/) | 查询中国历史地名、行政单位和项目说明，并进入CHGIS第6版数据资源。 | 更适合历史地理研究和数据下载，使用时应注意时间截面与字段定义。 |
| [UNESCO丝绸之路交互地图](https://fr.unesco.org/silkroad/interactive-map-of-the-silk-road) | 按文化遗产、城市、文献、艺术品和自然遗产等类型浏览丝绸之路节点。 | 展示的是跨时代文化遗产网络，不是一条固定的汉代或唐代商路。 |
| [UNESCO中国大运河地图](https://whc.unesco.org/en/list/1443/maps/) | 查看世界遗产范围、组成部分及相关地图资料。 | 世界遗产范围与历代全部运河、漕运线路不是同一口径。 |

## 朝代与文物分期

| 入口 | 可以怎样使用 | 数据边界 |
| --- | --- | --- |
| [中国国家博物馆“古代中国”](https://www.chnmuseum.cn/portals/0/web/zt/gudai/default.html) | 按远古、夏商西周、春秋战国、秦汉、魏晋南北朝、隋唐五代、辽宋夏金元、明清逐段浏览代表文物。 | 这是展览分期和文物入口，不是完整编年史或实时展出清单。 |

## 怎样与本地卡片配合

1. 想快速认识人物，先读本地[人物索引](<人物索引.md>)和人物卡；想扩展亲属、师承、同僚及地理轨迹，再进入CBDB或CHKG。
2. 想理解某一时刻的行政区和地点，使用CHGIS；想理解战争、交通和人口迁徙的因果链，继续阅读本地历史专题与事件卡。
3. 外部可视化适合发现线索，不应仅凭节点相连、色块覆盖或路线动画断定史实。重要关系、年代和疆界仍需核对原典、历史地图集或可靠研究。
