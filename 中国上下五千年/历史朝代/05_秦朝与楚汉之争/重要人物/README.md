# 秦朝与楚汉之争：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [秦始皇](<秦始皇.md>) | 完成六国统一并称皇帝，推行郡县治理及文字、度量衡等制度整合。 |
| [李斯](<李斯.md>) | 秦朝丞相，参与统一后的制度建设与文字规范，是秦政的重要执行者。 |
| [陈胜](<陈胜.md>) | 与吴广发动大泽乡起义，建立张楚政权，推动秦末反抗迅速扩散。 |
| [吴广](<吴广.md>) | 与陈胜共同发动起义，反映秦末征发压力与社会反抗。 |
| [项羽](<项羽.md>) | 巨鹿之战中崛起的反秦领袖，后与刘邦争天下，最终败于垓下。 |
| [刘邦](<刘邦.md>) | 楚汉战争胜者和汉朝建立者，约法三章、鸿门宴体现其争取支持与应对危机。 |
| [韩信](<韩信.md>) | 帮助刘邦赢得楚汉战争的将领，井陉背水布阵与垓下战局均与其相关。 |
| [虞姬](<虞姬.md>) | 项羽所爱的虞美人，相关史料简略；自刎等细节主要由后世文艺扩展。 |
| [宋义](<宋义.md>) | 楚军将领，在救赵途中被项羽杀死，项羽由此取得军队主导权。 |
| [章邯](<章邯.md>) | 镇压反秦力量的秦将，巨鹿战局后降于项羽，关联秦朝军事力量的瓦解。 |
| [王离](<王离.md>) | 率秦军围赵的将领，在巨鹿战役中失败，反映秦军主力的受挫。 |
| [陈余](<陈余.md>) | 赵地军事人物，在井陉之战中败于韩信。 |
| [范增](<范增.md>) | 项羽的重要谋士，鸿门宴叙事中主张及早解决刘邦威胁。 |
| [项庄](<项庄.md>) | 项羽部将，鸿门宴中舞剑的故事形成“项庄舞剑，意在沛公”。 |
| [项伯](<项伯.md>) | 项羽叔父，在鸿门宴前后沟通刘、项双方并保护刘邦。 |
| [樊哙](<樊哙.md>) | 刘邦部将，鸿门宴中闯帐的故事突出其护主与临危应变。 |
| [赵高](<赵高.md>) | 秦末掌握宫廷权力的官员，参与沙丘政变与秦二世时期的政治斗争。 |
