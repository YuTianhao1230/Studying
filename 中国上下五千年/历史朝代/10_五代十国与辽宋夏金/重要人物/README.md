# 五代十国与辽宋夏金：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [王处直](<王处直.md>) | 地方军事统治者，曲阳墓葬中的散乐、奉侍浮雕保存当时贵族生活与石雕艺术的图像。 |
| [赵匡胤](<赵匡胤.md>) | 通过陈桥兵变建立宋朝，逐步调整禁军将领与中央权力的关系。 |
| [宋真宗](<宋真宗.md>) | 澶渊之盟时期的宋帝，与辽朝议和，促成宋辽长期相对稳定的边境关系。 |
| [寇准](<寇准.md>) | 宋真宗时期大臣，在辽军南下时主张皇帝亲征，参与澶渊战和决策。 |
| [辽圣宗](<辽圣宗.md>) | 澶渊之盟时期的辽帝，与萧太后共同参与辽朝对宋军事和外交。 |
| [萧太后](<萧太后.md>) | 辽圣宗之母、重要执政者，参与宋辽战争及和约形成。 |
| [杨业](<杨业.md>) | 归宋后守边的将领，兵败被俘后死去，是杨家将传奇的历史核心之一。 |
| [杨延昭](<杨延昭.md>) | 杨业之子，长期参与宋辽边防，其“六郎”称谓不等于小说家族排行。 |
| [杨文广](<杨文广.md>) | 杨延昭之子、宋代将领，真实世系与杨家将小说中的安排不同。 |
| [宋仁宗](<宋仁宗.md>) | 范仲淹、包拯活动时期的皇帝，庆历新政与北宋文官政治均与其相关。 |
| [包拯](<包拯.md>) | 以直言和廉洁著称的官员，黑脸月牙、铡美案等是后世公案文学的塑造。 |
| [范仲淹](<范仲淹.md>) | 推动庆历新政的政治家与文学家，以“先天下之忧而忧”等表达公共责任。 |
| [王安石](<王安石.md>) | 熙宁变法的主要推动者，试图通过财政、军事与行政改革增强国家能力。 |
| [宋神宗](<宋神宗.md>) | 支持王安石变法的皇帝，改革影响了财政、社会利益和官僚政治。 |
| [司马光](<司马光.md>) | 主持编纂《资治通鉴》的史家、政治家，与王安石政见不同；砸缸是其童年轶事。 |
| [苏轼](<苏轼.md>) | 诗词、散文、书画兼擅的文人，乌台诗案、赤壁作品和杭州治理展现其多面人生。 |
| [张择端](<张择端.md>) | 《清明上河图》作者，以长卷展现城市交通、商业与日常生活。 |
| [李清照](<李清照.md>) | 词人、金石收藏者，南渡后的流离与藏品散失使个人生活和时代动荡交织。 |
| [赵明诚](<赵明诚.md>) | 金石学者、李清照之夫，收藏与考订成果集中于《金石录》。 |
| [宋徽宗](<宋徽宗.md>) | 以书画著称的皇帝，靖康之变后与宋钦宗一同被金军掳走。 |
| [宋钦宗](<宋钦宗.md>) | 北宋末代皇帝，在靖康之变中被金军俘虏。 |
| [宋高宗](<宋高宗.md>) | 建立南宋的皇帝，其统治涉及对金战争、议和及与岳飞等将领的关系。 |
| [岳飞](<岳飞.md>) | 抗金将领，后遭杀害；岳母刺字和《满江红》归属需分别考察来源。 |
| [岳母](<岳母.md>) | 岳飞之母，刺字故事寄托忠义与家教观念，完整情节不能直接当作史实。 |
| [秦桧](<秦桧.md>) | 宋高宗时期主和大臣，与岳飞被害事件及南宋政治争议密切相关。 |
| [朱熹](<朱熹.md>) | 理学代表人物，重视经典阐释与格物穷理，在鹅湖之会与陆氏兄弟讨论学术。 |
| [陆九渊](<陆九渊.md>) | 心学的重要代表人物，在鹅湖之会与朱熹讨论为学方法。 |
| [陆九龄](<陆九龄.md>) | 陆九渊之兄、学者，参加鹅湖之会，体现宋代理学内部的不同路径。 |
| [吕祖谦](<吕祖谦.md>) | 学者、鹅湖之会的组织参与者，推动不同学术主张之间的讨论。 |
| [陆游](<陆游.md>) | 诗人，作品兼有恢复失地的志向和私人情感，沈园故事是其人生的一条线索。 |
| [唐氏](<唐氏.md>) | 陆游前妻，沈园重逢和唱和词的完整情节包含后世本事与传说。 |
| [文天祥](<文天祥.md>) | 抗元大臣，被俘后坚持不降，其诗文与经历形成鲜明的忠节形象。 |
| [陆秀夫](<陆秀夫.md>) | 南宋大臣，崖山战败后负幼帝赵昺投海，关联南宋政权的终结。 |
| [张世杰](<张世杰.md>) | 组织南宋末年海上抵抗的将领，与文天祥、陆秀夫共同见于宋末叙事。 |
| [展昭](<展昭.md>) | 包公公案与《三侠五义》传统中的侠客，不是史传中可直接核实的包拯属官。 |
| [公孙策](<公孙策.md>) | 包公故事中的谋士、幕僚形象，不宜直接列为历史上的开封府官员。 |
| [佘太君](<佘太君.md>) | 杨家将故事中的家族长者，文学形象与可能的历史原型须分别考察。 |
| [穆桂英](<穆桂英.md>) | 杨家将故事中统兵作战的女将，挂帅、破天门阵等属于传奇传统。 |
| [文同](<文同.md>) | 北宋官员、诗人、画家，以墨竹著称。 |
| [欧阳修](<欧阳修.md>) | 北宋政治家、文学家、史学家，古文与史学的重要代表。 |
