# 隋唐：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [隋文帝](<隋文帝.md>) | 建立隋朝并结束南北长期分裂，为跨区域制度和交通整合创造条件。 |
| [隋炀帝](<隋炀帝.md>) | 大规模营建运河的隋帝，工程促进南北交通，也与征发负担和隋末危机相关。 |
| [唐高祖](<唐高祖.md>) | 唐朝建立者，玄武门之变发生时仍在位，随后让位于李世民。 |
| [唐太宗](<唐太宗.md>) | 通过玄武门之变取得继承权，贞观时期重视政治整顿、用人与纳谏。 |
| [李建成](<李建成.md>) | 唐高祖长子、原太子，在玄武门之变中被杀。 |
| [李元吉](<李元吉.md>) | 唐高祖之子，在皇位继承斗争中支持李建成，死于玄武门之变。 |
| [魏征](<魏征.md>) | 唐太宗时期的重要谏臣，“以人为镜”表达了纳谏与纠正决策的理想。 |
| [文成公主](<文成公主.md>) | 入藏与松赞干布成婚的唐宗室女子，是唐蕃交流的重要象征。 |
| [松赞干布](<松赞干布.md>) | 吐蕃统治者，与文成公主联姻，推动吐蕃与唐朝等地区的联系。 |
| [玄奘](<玄奘.md>) | 赴印度求法、回国译经的僧人，真实旅行与《西游记》故事应分别理解。 |
| [武则天](<武则天.md>) | 建立武周政权的女性皇帝，周兴、来俊臣等酷吏活动于其执政时期。 |
| [周兴](<周兴.md>) | 参与酷吏政治的官员，请君入瓮故事中被来俊臣用其自身方法逼供。 |
| [来俊臣](<来俊臣.md>) | 武则天时期酷吏，请君入瓮故事以其审讯周兴表现权术反噬。 |
| [唐玄宗](<唐玄宗.md>) | 开元、天宝时期的皇帝，其后期统治面临权臣、边镇与安史之乱的危机。 |
| [李林甫](<李林甫.md>) | 唐玄宗时期宰相，后世“口蜜腹剑”评价与其排斥政敌的形象相连。 |
| [杨国忠](<杨国忠.md>) | 杨贵妃族兄、玄宗时期宰相，在安史之乱后的马嵬兵变中被杀。 |
| [安禄山](<安禄山.md>) | 兼领重兵的边镇将领，755年起兵反唐，是安史之乱的发动者。 |
| [史思明](<史思明.md>) | 安史之乱中的叛军首领，安禄山之后继续主导战争。 |
| [杨贵妃](<杨贵妃.md>) | 唐玄宗贵妃，在马嵬兵变中被迫死亡；不能以个人爱情概括整个政治危机。 |
| [陈玄礼](<陈玄礼.md>) | 唐玄宗禁军将领，与马嵬兵变及玄宗西行护卫有关。 |
| [高力士](<高力士.md>) | 玄宗时期宦官，后世李白醉写诗故事将“脱靴”塑造成才子傲岸的情节。 |
| [李白](<李白.md>) | 以想象、气势和自由精神著称的诗人，醉写诗、铁杵磨针故事多经后世加工。 |
| [杜甫](<杜甫.md>) | 诗作深刻记录战乱与民生，成都草堂经历连接个人困境和公共关怀。 |
| [颜真卿](<颜真卿.md>) | 书法家与官员，《祭侄文稿》以祭文草稿留下安史之乱中的家族创伤。 |
| [颜杲卿](<颜杲卿.md>) | 颜真卿族兄，在抵抗安史叛军时遇害，其家族遭遇是《祭侄文稿》的背景。 |
| [颜季明](<颜季明.md>) | 颜杲卿之子，遇害后由颜真卿作《祭侄文稿》祭奠。 |
| [崔护](<崔护.md>) | 《题都城南庄》作者，人面桃花的爱情故事围绕其诗句逐步扩展。 |
| [贾岛](<贾岛.md>) | 以苦吟著称的诗人，“推敲”故事表现诗歌创作对字句的反复斟酌。 |
| [韩愈](<韩愈.md>) | 古文运动的重要作家，推敲故事中被写成帮助贾岛定字的前辈。 |
| [淳于棼](<淳于棼.md>) | 《南柯太守传》主人公，梦中仕宦荣枯与醒后蚁穴构成南柯一梦。 |
| [卢生](<卢生.md>) | 《枕中记》中借枕入梦的失意者，醒来时黄粱饭未熟，寓意富贵如梦。 |
| [吕翁](<吕翁.md>) | 《枕中记》中借枕给卢生的道士，不宜直接与所有吕洞宾故事合并。 |
| [柳宗元](<柳宗元.md>) | 唐代文学家、思想家，参与永贞革新，后在永州、柳州任职。 |
