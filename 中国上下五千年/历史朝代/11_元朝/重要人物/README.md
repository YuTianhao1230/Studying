# 元朝：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

[人物关系图](<人物关系图.md>)：按家族、君臣、战争阵营、学术或文学关系分图，并标注跨时代联系。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [成吉思汗](<成吉思汗.md>) | 统一蒙古诸部并建立蒙古帝国的领袖，后世“一代天骄”是文学评价。 |
| [窝阔台](<窝阔台.md>) | 成吉思汗之子与继任大汗，其时期征服扩展与赋税治理同时推进。 |
| [耶律楚材](<耶律楚材.md>) | 服务于蒙古统治者的官员，劝止杀掠、主张税收治理的事迹体现统治方式转变。 |
| [忽必烈](<忽必烈.md>) | 建立元朝、灭南宋的统治者，中央与行省制度帮助组织广阔疆域。 |
| [关汉卿](<关汉卿.md>) | 杂剧作家，《窦娥冤》等作品借舞台冲突表现社会压迫与司法不公。 |
| [王实甫](<王实甫.md>) | 《西厢记》作者，将张生、莺莺故事改写成肯定爱情诉求的杂剧。 |
| [王冕](<王冕.md>) | 擅画墨梅的诗人、画家，以梅花表达清高自守的志趣。 |
| [赵孟頫](<赵孟頫.md>) | 书画家，《鹊华秋色图》以济南山水为友人周密寄托故乡记忆。 |
| [周密](<周密.md>) | 词人、笔记作者，与赵孟頫交往，是《鹊华秋色图》的相关受赠者。 |
| [郭守敬](<郭守敬.md>) | 天文、水利专家，参与编制《授时历》，将观测、仪器与国家历法相结合。 |
| [王恂](<王恂.md>) | 天文学家、数学家，与郭守敬等共同参与《授时历》编制。 |
| [许衡](<许衡.md>) | 学者，参与元朝制度和历法事务，是《授时历》工程的相关人物。 |
| [马可·波罗](<马可·波罗.md>) | 威尼斯旅行者，其游记描写欧亚交通和东方见闻，具体叙述仍需交叉核验。 |
| [韩山童](<韩山童.md>) | 红巾军起事的重要发动者，借宗教与政治号召动员反元力量。 |
| [刘福通](<刘福通.md>) | 红巾军主要领袖之一，反映元末起义并非只有朱元璋一支力量。 |
| [窦娥](<窦娥.md>) | 《窦娥冤》中遭诬陷与冤杀的女性，三桩誓愿以戏剧方式申诉不公。 |
| [张生](<张生.md>) | 与崔莺莺相爱的书生，其文学故事经唐传奇和元杂剧不断改写。 |
| [崔莺莺](<崔莺莺.md>) | 面对礼法与婚姻安排追求爱情的女性，是《西厢记》的核心人物。 |
| [红娘](<红娘.md>) | 帮助张生与崔莺莺交往的侍女，其名字后来成为婚恋牵线者的代称。 |
