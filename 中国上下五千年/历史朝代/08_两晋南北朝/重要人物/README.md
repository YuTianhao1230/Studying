# 两晋南北朝：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [高洋](<高洋.md>) | 北齐开国皇帝，湾漳墓道壁画以仪仗和神兽呈现帝王丧葬空间。 |
| [司马炎](<司马炎.md>) | 代魏建立西晋并灭吴，结束三国并立；与司马昭、司马懿分属三代。 |
| [祖逖](<祖逖.md>) | 东晋北伐将领，与刘琨闻鸡起舞的故事体现乱世中的志向与行动。 |
| [刘琨](<刘琨.md>) | 西晋将领、诗人，与祖逖的青年交往形成闻鸡起舞故事。 |
| [左思](<左思.md>) | 《三都赋》作者，洛阳纸贵的故事表现文学作品的传播与声名。 |
| [苻坚](<苻坚.md>) | 统一北方后南攻东晋，在淝水之战失败，与草木皆兵等故事相关。 |
| [苻融](<苻融.md>) | 苻坚之弟、前秦将领，参与淝水之战并战死。 |
| [谢安](<谢安.md>) | 东晋政治家，在淝水之战时期主持朝政，稳定后方与组织应战。 |
| [谢玄](<谢玄.md>) | 统率北府兵的将领，是淝水之战东晋获胜的重要指挥者。 |
| [谢灵运](<谢灵运.md>) | 山水诗代表人物，后世“才高八斗”评价被归于他对曹植的推崇。 |
| [北魏孝文帝](<北魏孝文帝.md>) | 迁都洛阳并调整姓氏、服饰、语言与婚姻政策的皇帝，推动北方文化整合。 |
| [张僧繇](<张僧繇.md>) | 以佛教绘画、人物与寺院壁画著称，后世画龙点睛传说的主人公。 |
| [王羲之](<王羲之.md>) | 东晋官员、书法家，行书与草书传统中的重要人物。 |
| [陶渊明](<陶渊明.md>) | 东晋诗人，以田园诗、归隐书写和《桃花源记》著称。 |
