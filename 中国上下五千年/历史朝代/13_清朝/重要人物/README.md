# 清朝：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

[人物关系图](<人物关系图.md>)：按家族、君臣、战争阵营、学术或文学关系分图，并标注跨时代联系。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [顺治帝](<顺治帝.md>) | 清军入关时期的皇帝，其初年由多尔衮等摄政。 |
| [多尔衮](<多尔衮.md>) | 清入关与初期统治的重要主持者，参与1644年前后的军事政治重组。 |
| [吴三桂](<吴三桂.md>) | 明朝将领，山海关战局中转而与清军合作，后又发动反清战争。 |
| [康熙帝](<康熙帝.md>) | 平三藩、统一台湾并处理北方与西北事务，疆域治理由多种机制共同推进。 |
| [雍正帝](<雍正帝.md>) | 推动财政与行政整顿的皇帝，与摊丁入亩、耗羡归公等改革相联系。 |
| [乾隆帝](<乾隆帝.md>) | 统治时期国力与文化工程规模扩大，《四库全书》编纂同时伴随审查删禁。 |
| [嘉庆帝](<嘉庆帝.md>) | 乾隆之后的皇帝，乾隆去世后亲政并处置和珅，其抄家财富不宜按传闻夸大。 |
| [道光帝](<道光帝.md>) | 鸦片战争时期的皇帝，禁烟与战和决策反映清朝面对外部冲击的困境。 |
| [光绪帝](<光绪帝.md>) | 戊戌变法时期的皇帝，支持改革但受到既有权力格局制约。 |
| [张英](<张英.md>) | 康熙时期大臣，六尺巷地方故事借其家书表达礼让与家风。 |
| [和珅](<和珅.md>) | 乾隆宠臣，嘉庆时期被处置，财富与权力关系在后世形成广泛传说。 |
| [纪昀](<纪昀.md>) | 《四库全书》总纂官之一，关联典籍整理、学术分类与文化审查。 |
| [曹雪芹](<曹雪芹.md>) | 《红楼梦》的主要作者，以家族兴衰描写情感、礼法与社会关系。 |
| [蒲松龄](<蒲松龄.md>) | 《聊斋志异》作者，借狐鬼故事表现人情、社会压力与现实不平。 |
| [郑燮](<郑燮.md>) | 扬州八怪之一，擅画竹兰石，书画、诗文与从政经历共同构成其形象。 |
| [林则徐](<林则徐.md>) | 主持虎门销烟的官员，禁烟事件与鸦片战争前的中英冲突相连。 |
| [曾国藩](<曾国藩.md>) | 湘军组织者、洋务运动重要人物，参与清廷军事与工业能力的重建。 |
| [李鸿章](<李鸿章.md>) | 洋务运动和晚清外交的重要人物，与北洋海军建设及甲午战败相连。 |
| [左宗棠](<左宗棠.md>) | 洋务运动人物、收复新疆的主要军事主持者；抬棺出征细节含后世加工。 |
| [刘锦棠](<刘锦棠.md>) | 参与收复新疆的将领，说明西征依赖前线指挥、后勤与地方力量协作。 |
| [张之洞](<张之洞.md>) | 洋务运动重要官员，推动工业、教育与军事建设。 |
| [康有为](<康有为.md>) | 维新派代表人物，参与戊戌变法，主张借制度改革应对国家危机。 |
| [梁启超](<梁启超.md>) | 维新派思想家、报刊活动家，以政论和新知识传播推动公共讨论。 |
| [詹天佑](<詹天佑.md>) | 主持京张铁路建设的工程师，山地线路设计是其代表性工程事迹。 |
| [林黛玉](<林黛玉.md>) | 身份：《红楼梦》文学人物，不是已确认的真实历史人物。 |
