# 三国：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [曹操](<曹操.md>) | 逐步统一北方的政治家、军事家和文学家；生前未称帝。 |
| [刘备](<刘备.md>) | 蜀汉建立者，以诸葛亮为重要辅佐者，与孙吴结盟抗曹后又因荆州问题交战。 |
| [孙权](<孙权.md>) | 继承江东基业并建立吴国，与刘备联盟参与赤壁之战。 |
| [诸葛亮](<诸葛亮.md>) | 蜀汉丞相，关联隆中对、南征与北伐；借东风、空城计等须区分史实和小说。 |
| [关羽](<关羽.md>) | 刘备部将，参与荆州争夺，后世文学与信仰塑造了忠义英雄形象。 |
| [张飞](<张飞.md>) | 刘备部将，长坂断桥故事以史书记载为基础，桃园结义则属文学传统。 |
| [赵云](<赵云.md>) | 刘备部将，长坂救护刘禅的事迹经小说扩展成著名英雄故事。 |
| [周瑜](<周瑜.md>) | 孙氏集团将领、赤壁之战的重要指挥者，小说强化了其与诸葛亮的竞争。 |
| [鲁肃](<鲁肃.md>) | 孙权的重要谋臣，参与孙刘联盟与荆州交涉，是单刀赴会史实中的关键人物。 |
| [吕蒙](<吕蒙.md>) | 孙权部将，因学习受到鲁肃刮目相看，后参与夺取荆州。 |
| [陆逊](<陆逊.md>) | 吴国将领，在夷陵之战中击败刘备，体现军队指挥与战略等待的重要性。 |
| [黄盖](<黄盖.md>) | 赤壁之战中提出火攻并参与诈降的孙氏部将；苦肉计的戏剧细节有后世增饰。 |
| [阚泽](<阚泽.md>) | 吴国学者与官员，小说将其写成替黄盖递送诈降书的人物。 |
| [曹丕](<曹丕.md>) | 曹操之子，代汉建魏；与曹植的关系在七步诗故事中被戏剧化。 |
| [曹植](<曹植.md>) | 曹操之子、建安文学代表，七步成诗与才高八斗体现其后世文学声名。 |
| [刘禅](<刘禅.md>) | 刘备之子，蜀汉末代皇帝；“乐不思蜀”来自带有轶事性质的记载。 |
| [司马懿](<司马懿.md>) | 魏国权臣和将领，曾对抗诸葛亮北伐，其家族后来掌握曹魏权力。 |
| [司马昭](<司马昭.md>) | 掌握曹魏实权的司马氏领袖，其时期魏军灭蜀。 |
| [孟获](<孟获.md>) | 诸葛亮南征叙事中的地方首领，“七擒七纵”的具体过程需辨别来源。 |
| [姜维](<姜维.md>) | 诸葛亮之后蜀汉北伐的重要将领，五丈原故事涉及其参与蜀军撤退。 |
| [杨仪](<杨仪.md>) | 诸葛亮属官，在诸葛亮去世后的撤军安排中发挥作用。 |
| [马谡](<马谡.md>) | 诸葛亮部属，街亭失守后被处置，故事涉及任将、军令与责任。 |
| [王平](<王平.md>) | 蜀汉将领，在街亭战役中与马谡意见不同，并组织部分兵力撤退。 |
| [张郃](<张郃.md>) | 曹魏将领，在街亭之战击败马谡，是蜀汉北伐的主要对手之一。 |
| [袁绍](<袁绍.md>) | 北方重要军事领袖，官渡之战败于曹操，影响了北方统一的走向。 |
| [许攸](<许攸.md>) | 由袁绍转投曹操的谋士，其提供的信息与官渡战局逆转相连。 |
| [于禁](<于禁.md>) | 曹操部将，在襄樊战局中因洪水受困而降关羽。 |
| [庞德](<庞德.md>) | 曹操部将，在襄樊战局中被关羽俘杀，后世常突出其拒降形象。 |
| [华雄](<华雄.md>) | 董卓部将，史书记载与孙坚作战时败亡，小说改写为关羽温酒斩华雄。 |
| [孙坚](<孙坚.md>) | 孙策、孙权之父，参加讨董卓战争，史传中的斩华雄战功与其军队有关。 |
| [吕布](<吕布.md>) | 反复参与军阀争战的将领，与王允诛董卓有关；三英战吕布属于小说情节。 |
| [董卓](<董卓.md>) | 控制汉朝中央的军阀，后被吕布等杀死，连环计故事围绕这段政变扩写。 |
| [王允](<王允.md>) | 参与谋划诛杀董卓的汉臣，小说将其与貂蝉、吕布串成连环计。 |
| [甘夫人](<甘夫人.md>) | 刘备夫人、刘禅生母，长坂救护叙事中的重要人物。 |
| [貂蝉](<貂蝉.md>) | 《三国演义》连环计的核心人物，不能直接等同于史书中的某位确定女性。 |
