# 春秋：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [齐桓公](<齐桓公.md>) | 任用管仲改革并成为霸主，“尊王攘夷”体现其组织诸侯的政治方式。 |
| [管仲](<管仲.md>) | 齐桓公的重要辅臣，参与齐国改革；与鲍叔牙的交谊形成“管鲍之交”。 |
| [鲍叔牙](<鲍叔牙.md>) | 齐国大夫，理解并举荐管仲，成为知人、荐贤与友谊故事的代表。 |
| [晋文公](<晋文公.md>) | 长期流亡后回国即位的晋君，城濮之战奠定其霸业。 |
| [楚成王](<楚成王.md>) | 曾接待流亡中的重耳，后与晋国争霸，关联“退避三舍”的故事背景。 |
| [子玉](<子玉.md>) | 楚国令尹，城濮之战中统率楚军，是晋楚争霸的重要参与者。 |
| [楚庄王](<楚庄王.md>) | 使楚国跻身霸主之列的君主，与“一鸣惊人”“问鼎中原”故事相连。 |
| [王孙满](<王孙满.md>) | 周王室大夫，在楚庄王问鼎时以王德回应，体现周室名义权威的维护。 |
| [勾践](<勾践.md>) | 败于吴后重建国力并灭吴，卧薪尝胆故事将其塑造成忍辱复国的典型。 |
| [夫差](<夫差.md>) | 吴国末代君主，与越国长期争战，最终败于勾践。 |
| [范蠡](<范蠡.md>) | 辅佐勾践复国的越国大夫，后世又将其经商事迹与陶朱公形象相联系。 |
| [文种](<文种.md>) | 越国重要谋臣，与范蠡共同参与勾践时期的恢复与对吴斗争。 |
| [孔子](<孔子.md>) | 儒家思想的代表人物，周游列国并讲学，重视仁、礼和政治伦理。 |
| [颜回](<颜回.md>) | 孔子弟子，以好学和德行著称，是理解儒家师生关系的重要人物。 |
| [子路](<子路.md>) | 孔子弟子，以勇毅直率著称，在孔子周游列国的叙事中经常出现。 |
| [晏婴](<晏婴.md>) | 春秋齐国政治家、外交人物，历事齐灵公、庄公、景公。 |
