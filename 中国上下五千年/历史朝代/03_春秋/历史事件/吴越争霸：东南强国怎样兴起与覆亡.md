# 吴越争霸：东南强国怎样兴起与覆亡

## 地域与时间

吴以今太湖流域为重要核心，越的主要活动区域在今浙江一带。两国竞争跨越春秋末年，并延续到通行战国起点前475年之后；前473年越灭吴，因此本篇按事件起源与连续进程归入春秋，战国入口引用同一正文。

## 吴国如何走入中原争霸

晋楚竞争使吴国具有外交价值：晋希望利用吴牵制楚，吴也通过军事组织和区域扩张增强力量。阖闾时期吴向楚发动进攻，前506年柏举之战后攻入楚都郢，显示东南国家已能改变大国格局。

攻入都城并不等于稳定控制楚国。楚的反击、秦的援助及吴自身的安全问题限制了扩张成果。越在吴的南侧，也使吴难以只面向中原作战。

## 从吴胜越到越灭吴

前496年吴越交战，阖闾受伤后死去，夫差继位。前494年夫差击败越军，勾践求和，越国保留了恢复的空间。勾践此后借重范蠡、文种等，恢复生产、积累资源并调整外交。

吴国继续向北用兵，前482年黄池会盟是夫差争夺诸侯领导地位的节点。与此同时，越不断寻找吴后方空虚及国力消耗的机会。此后战争逐步使吴陷入困境，前473年越灭吴，夫差败亡。

| 节点 | 对力量关系的意义 |
| --- | --- |
| 前506年攻入郢 | 吴能够冲击楚国核心，却难维持全部战果 |
| 前494年越败求和 | 吴取得优势，越仍保留政权与恢复能力 |
| 前482年黄池会盟 | 吴向中原争名位，后方安全承受压力 |
| 前473年越灭吴 | 长期资源积累与战略机会改变最终结果 |

## 为什么不能只靠励志故事解释

吴越胜败与兵员、粮食、外交、国内决策和多方向用兵相连。个人坚忍可以成为政治叙事的中心，却不能替代这些条件。“卧薪尝胆”的成语形成和西施相关传说见典故卡，不在此重复展开。

具体军事人数与部分人物计谋在传世记载中存在差异。吴越均不是现代省份，其控制范围随战争变化；现代地名只能帮助定位。
