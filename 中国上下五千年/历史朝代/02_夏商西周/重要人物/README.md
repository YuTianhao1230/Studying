# 夏商西周：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

[人物关系图](<人物关系图.md>)：三张分期图覆盖本目录人物，区分亲属、辅政、对立，并连接上古与春秋人物。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [启](<启.md>) | 禹之子，传统叙事以其继位说明王位由禅让转向世袭。 |
| [盘庚](<盘庚.md>) | 迁都殷的商王，迁殷与商代后期政治、都邑发展相联系。 |
| [商纣王](<商纣王.md>) | 商朝末代君主，牧野之战败于周；暴君形象包含后世政治与文学加工。 |
| [周文王](<周文王.md>) | 周势力兴起时期的领袖，姜太公辅周故事将其塑造成礼贤下士的君主。 |
| [姜尚](<姜尚.md>) | 辅佐周文王、周武王的开国功臣，钓鱼待贤主的情节有后世增饰。 |
| [周武王](<周武王.md>) | 率军在牧野击败商军并建立周王朝，是武王伐纣的中心人物。 |
| [周公旦](<周公旦.md>) | 周武王之弟、周成王时期的辅政者，与分封、宗法和礼制传统密切相连。 |
| [周成王](<周成王.md>) | 周武王之子，幼年即位时由周公辅政，周初秩序在其时期进一步巩固。 |
| [管叔](<管叔.md>) | 周武王之弟，卷入周初反对周公的叛乱，是理解王族内部冲突的人物。 |
| [蔡叔](<蔡叔.md>) | 周武王之弟，与管叔等参与周初叛乱，反映分封亲族并不能消除权力冲突。 |
| [周幽王](<周幽王.md>) | 西周末代君主，其身亡与王室危机相连；“烽火戏诸侯”细节存在争议。 |
| [褒姒](<褒姒.md>) | 周幽王宠妃，后世烽火故事的中心人物，不宜把西周灭亡全部归因于她。 |
| [申侯](<申侯.md>) | 申国统治者，参与西周末年的王室冲突，反映王权与诸侯关系的破裂。 |
| [周平王](<周平王.md>) | 东迁洛邑的周王，平王东迁通常被用作西周、东周的分界。 |
