# 两汉：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

[人物关系图](<人物关系图.md>)：按家族、君臣、战争阵营、学术或文学关系分图，并标注跨时代联系。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [刘胜](<刘胜.md>) | 汉景帝之子、汉武帝之兄，满城一号汉墓墓主；其玉衣、博山炉体现西汉王室丧葬与生活。 |
| [窦绾](<窦绾.md>) | 满城二号汉墓墓主，长信宫灯出自其墓；与刘胜墓的随葬品须分别识别。 |
| [汉文帝](<汉文帝.md>) | 文景之治中的汉朝皇帝，以减轻负担、恢复生产的治理取向著称。 |
| [汉景帝](<汉景帝.md>) | 与文帝并称文景，统治时期延续休养生息，也面临诸侯势力问题。 |
| [汉武帝](<汉武帝.md>) | 推动对外战争与西域交往的汉帝，张骞出使、苏武奉使和司马迁著史均与其相连。 |
| [张骞](<张骞.md>) | 出使西域的使者，其旅行与报告扩大了汉朝对中亚地区的认识。 |
| [苏武](<苏武.md>) | 出使匈奴后长期被扣留的汉使，持节归汉成为守节故事的代表。 |
| [李陵](<李陵.md>) | 兵败降匈奴的汉将，与苏武故事、司马迁受刑事件均有关联。 |
| [司马迁](<司马迁.md>) | 《史记》的主要作者，以纪传体组织人物、政治与社会历史。 |
| [司马谈](<司马谈.md>) | 司马迁之父、汉朝太史令，其史学志向与积累由司马迁继承。 |
| [王昭君](<王昭君.md>) | 出塞与呼韩邪单于和亲的宫人，历史婚姻在后世诗歌中被不断重述。 |
| [汉元帝](<汉元帝.md>) | 昭君出塞时期的皇帝，汉匈和亲是其时边疆外交的一部分。 |
| [呼韩邪单于](<呼韩邪单于.md>) | 与汉朝建立关系并迎娶王昭君的匈奴单于，反映汉匈关系中的合作面向。 |
| [刘秀](<刘秀.md>) | 在王莽政权崩溃后的竞争中建立东汉，恢复刘氏统治。 |
| [张角](<张角.md>) | 太平道首领、黄巾起义领导者，其动员与东汉政治危机相联系。 |
| [匡衡](<匡衡.md>) | 西汉经学家、丞相，以解释《诗》受到重用，凿壁借光是其后世著名勤学故事。 |
| [孟光](<孟光.md>) | 梁鸿之妻，传记描写她主动选择婚姻并共同承担劳动生活，后世视其为夫妻敬重的代表。 |
| [季布](<季布.md>) | 原为项羽部将，获刘邦赦免后在汉廷任官，以守信和敢于进言著称。 |
| [李广](<李广.md>) | 长期对匈奴作战的将领，以善射、爱护士卒和终身未封侯的经历进入史传与诗歌。 |
| [梁鸿](<梁鸿.md>) | 以隐逸、著述和不慕仕进著称的学者，与孟光共同生活的叙事形成举案齐眉典故。 |
| [班超](<班超.md>) | 长期经营西域的军事与外交人物，投笔从戎和不入虎穴的典故均与其传记相连。 |
| [蔡邕](<蔡邕.md>) | 东汉文学家、书法家，参与经籍整理与熹平石经。 |
| [赵充国](<赵充国.md>) | 熟悉西北边情的将领，以现场调查、分化招降和屯田方案处理羌人战事。 |
| [陈皇后](<陈皇后.md>) | 汉武帝首任皇后，皇室婚姻、失宠与废后构成其生平，金屋许诺属于较晚故事。 |
| [马援](<马援.md>) | 归附刘秀后参与边疆战争的将领，老当益壮、马革裹尸体现其传记中的立志形象。 |
| [卫青](<卫青.md>) | 西汉武帝时期将领，与对匈奴战争和汉朝军事扩展有关。 |
| [张衡](<张衡.md>) | 东汉学者，文学、天文、仪器与官场活动均有影响。 |
| [王莽](<王莽.md>) | 西汉外戚与政治人物，9年建立新朝，23年政权崩溃。 |
| [班固](<班固.md>) | 东汉史学家、文学家，《汉书》的主要作者。 |
| [班昭](<班昭.md>) | 东汉学者，参与续成《汉书》，并有女性教育相关著述。 |
| [蔡伦](<蔡伦.md>) | 东汉宫廷官员，与造纸工艺改进和推广有关。 |
| [霍去病](<霍去病.md>) | 西汉武帝时期将领，以河西与漠北战役著称。 |
