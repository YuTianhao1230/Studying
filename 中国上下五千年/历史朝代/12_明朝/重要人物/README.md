# 明朝：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [朱元璋](<朱元璋.md>) | 在元末战争中胜出并建立明朝，着力重建秩序和强化皇权。 |
| [朱允炆](<朱允炆.md>) | 朱元璋之孙，削藩引发与燕王朱棣的冲突，靖难之役后失位。 |
| [朱棣](<朱棣.md>) | 靖难之役后即位，迁都北京，并支持《永乐大典》编纂和郑和航海。 |
| [郑和](<郑和.md>) | 七下西洋的主要统领，其船队体现明朝远洋交往与国家组织能力。 |
| [明宣宗](<明宣宗.md>) | 明朝皇帝，郑和最后一次远航获其支持。 |
| [解缙](<解缙.md>) | 参与主持《永乐大典》编纂的学者，关联大型典籍工程的组织。 |
| [姚广孝](<姚广孝.md>) | 僧人、朱棣谋臣，参与《永乐大典》的编纂事务。 |
| [明英宗](<明英宗.md>) | 土木之变中被俘、后复位的皇帝，两个年号对应其两段统治。 |
| [景泰帝](<景泰帝.md>) | 土木之变后即位，支持于谦保卫北京并组织危机应对。 |
| [于谦](<于谦.md>) | 土木之变后主持北京防御的大臣，与明英宗复位后的政治清算相联系。 |
| [王振](<王振.md>) | 明英宗时期宦官，其专权与土木之变的决策失误密切相关。 |
| [王守仁](<王守仁.md>) | 心学代表人物，龙场经历与其思想转折相连，倡导知行合一、致良知。 |
| [唐寅](<唐寅.md>) | 诗文书画兼擅的文人，点秋香故事是围绕其才子形象形成的文学拼接。 |
| [嘉靖帝](<嘉靖帝.md>) | 海瑞上疏批评的皇帝，相关事件体现君臣关系与直谏的政治风险。 |
| [海瑞](<海瑞.md>) | 以清廉和直谏著称的官员，对皇权与地方利益问题坚持提出批评。 |
| [戚继光](<戚继光.md>) | 抗倭将领，重视兵员训练、战术编组和军队纪律。 |
| [俞大猷](<俞大猷.md>) | 与戚继光同时期的抗倭将领，参与东南沿海军事防御。 |
| [李时珍](<李时珍.md>) | 《本草纲目》主要编撰者，通过搜集、辨误与分类整理药物知识。 |
| [李建元](<李建元.md>) | 李时珍之子，参与《本草纲目》的整理和呈进，体现著作流传中的协作。 |
| [张居正](<张居正.md>) | 万历初年的内阁首辅，推动考成法、财政与赋役改革。 |
| [万历帝](<万历帝.md>) | 在位前期由张居正主持改革，后期财政与政治矛盾逐渐积累。 |
| [徐弘祖](<徐弘祖.md>) | 旅行家，以实地观察记录山川、道路和洞穴，相关文字汇为《徐霞客游记》。 |
| [宋应星](<宋应星.md>) | 《天工开物》作者，系统记录农业、手工业的材料、工序和技术。 |
| [崇祯帝](<崇祯帝.md>) | 明朝在北京统治的末代皇帝，其时期面临财政、军事与农民战争危机。 |
| [李自成](<李自成.md>) | 农民军领袖，建立大顺并进入北京，后与清军及其他力量争战。 |
| [郑成功](<郑成功.md>) | 郑氏海上势力领袖，1662年迫使荷兰殖民者退出台湾并建立统治。 |
| [秋香](<秋香.md>) | 唐伯虎点秋香故事中的女性，故事关系不能直接作为唐寅真实婚姻记载。 |
| [孙悟空](<孙悟空.md>) | 身份：《西游记》文学人物；美猴王、齐天大圣，不是已确认的真实历史人物。 |
| [林冲](<林冲.md>) | 身份：《水浒传》文学人物，故事背景北宋，不是已确认的真实历史人物。 |
| [沙僧](<沙僧.md>) | 身份：《西游记》文学人物；沙悟净、沙和尚，不是已确认的真实历史人物。 |
| [猪八戒](<猪八戒.md>) | 身份：《西游记》文学人物；猪悟能，不是已确认的真实历史人物。 |
