# 历史朝代

按时间顺序收纳14个历史阶段，从上古传说与文明起源到中国近现代。其中既有单一王朝，也有并立政权和跨朝代时期；各阶段保留概览、人物、成语、事件、文物与图片。

## 时代目录

| 顺序 | 入口 | 时间范围 | 内容说明 |
| --- | --- | --- | --- |
| 01 | [上古传说与文明起源](<01_上古传说与文明起源/README.md>) | 史前至约前二千纪 | 先分清神话与考古，再理解中华文明的多地起源。 |
| 02 | [夏商西周](<02_夏商西周/README.md>) | 夏年代存在讨论；商约前1600—前1046；西周约前1046—前771 | 从早期王权、青铜礼制走向宗法分封，最后理解周王室为何衰弱。 |
| 03 | [春秋](<03_春秋/README.md>) | 通常前770—前476年；《春秋》记事前722—前481年 | 周天子衰弱，诸侯用会盟、战争与改革争夺领导权。 |
| 04 | [战国](<04_战国/README.md>) | 通常前475—前221年；前403年亦为重要分界 | 七雄以变法增强动员能力，兼并战争最终通向秦统一。 |
| 05 | [秦朝与楚汉之争](<05_秦朝与楚汉之争/README.md>) | 前221—前202年；秦亡于前207年 | 秦建立统一帝国，过度动员激化矛盾；楚汉竞争决定新帝国由谁接续。 |
| 06 | [两汉](<06_两汉/README.md>) | 西汉前202—公元9年；东汉25—220年 | 汉承秦制而调整治理，从休养生息走向扩张，再经历外戚宦官与地方力量的失衡。 |
| 07 | [三国](<07_三国/README.md>) | 220—280年；故事背景延伸至东汉末 | 从汉末群雄混战，形成魏蜀吴并立，再由西晋完成统一。 |
| 08 | [两晋南北朝](<08_两晋南北朝/README.md>) | 西晋265—316；东晋317—420；南北朝420—589 | 短暂统一后再次分裂，北方政权更替与南方发展并行，民族交往持续深化。 |
| 09 | [隋唐](<09_隋唐/README.md>) | 隋581—618年；唐618—907年 | 隋重新统一，唐发展帝国治理与文化交流，安史之乱后中央与地方关系改变。 |
| 10 | [五代十国与辽宋夏金](<10_五代十国与辽宋夏金/README.md>) | 907—1279年；辽916—1125，西夏1038—1227，金1115—1234 | 宋不是当时唯一政权：城市经济、文官政治与多国竞争并行。 |
| 11 | [元朝](<11_元朝/README.md>) | 蒙古政权兴起于1206年；元1271—1368年 | 区分蒙古帝国与元朝，理解广域统治、行省与跨洲交流。 |
| 12 | [明朝](<12_明朝/README.md>) | 1368—1644年；南明政权延续至其后 | 君主集权进一步加强，海外交流、商业与边防压力同时发展。 |
| 13 | [清朝](<13_清朝/README.md>) | 1636—1912年；入关统治的重要节点为1644年 | 从后金与入关到大一统治理，再面对工业时代的外部冲击与内部危机。 |
| 14 | [中国近现代](<14_中国近现代/README.md>) | 通常以1840年为近代开端；本分卷重点1912年以后 | 沿着共和探索、民族独立、国家建设与改革开放串联，避免只记战争日期。 |
