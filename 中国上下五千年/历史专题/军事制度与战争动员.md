# 军事制度与战争动员

## 战争不只发生在战场

军队能否作战取决于兵员、粮饷、武器、交通、指挥和政治联盟。只讲名将谋略容易忽略后勤与制度；只看军队人数，也不能判断训练、补给和协同能力。

## 主要变化

| 阶段 | 组织方式 | 战争动员特点 |
| --- | --- | --- |
| 商周 | 贵族战车、族众和步兵共同作战 | 军事义务与宗族、等级关系相连 |
| 战国秦汉 | 大规模步骑兵、征兵和军功爵；郡县承担动员 | 户籍、农业生产和道路体系支撑长期战争 |
| 东汉末至三国 | 州郡兵、部曲、募兵与屯田并用 | 政权在战争中把生产、移民和军粮组织结合 |
| 魏晋南北朝 | 世兵、军户、军镇等多种形态 | 政权并立和人口迁徙使军政关系复杂化 |
| 隋唐 | 府兵制与征募并用，后期藩镇军队扩张 | 均田和轮番宿卫的条件变化后，职业化与地方化增强 |
| 宋 | 禁军、厢军、乡兵等并存，以文官体系牵制将领 | 防止武将割据与提高战场效率之间存在张力 |
| 元 | 怯薛、蒙古军与各类地方军队 | 草原军事组织与大范围征服、驻防结合 |
| 明 | 卫所制、营兵与募兵相继并用 | 卫所军户衰弱后，财政供养和将领练兵更重要 |
| 清 | 八旗、绿营，后有湘军、淮军和新军 | 兵制变化反映中央常备军、地方筹饷与现代化压力 |
| 近现代 | 现代军队、总体战争与后方动员 | 工业、交通、财政、政治组织和社会动员共同决定战争能力 |

## 比较战争的四个问题

1. 兵员从哪里来，是临时征发、世袭军户还是职业招募？
2. 粮饷由谁负担，运输距离和季节怎样限制行动？
3. 中央怎样控制将领，控制措施是否损害临机指挥？
4. 胜利能否转化为稳定治理，还是仅改变一场战役的局势？
