# 人口迁徙与经济重心南移

## 两个相连但不同的过程

人口迁徙是人群因战争、灾害、政令、贸易和生计而移动；经济重心南移是农业、人口、财政、城市和商业的重要区域逐渐向长江流域及更南地区增强。一次南迁不会立即完成重心转移，这一过程经历多个阶段。

![人口迁徙与经济重心南移示意](<assets/人口迁徙与经济重心南移.svg>)

> 示意图展示多轮大方向，不表示每个移民群体的起点、终点或规模。箭头跨越不同年代，不能理解为一次迁徙。

三轮重要南迁包括：东汉末至东晋北方战乱和西晋覆亡后的南迁；安史之乱及唐末五代的持续流动；靖康之变至南宋政权与人口的再次南移。江南、岭南等地原本已有不同人群、农业和文化传统，不能把南方发展写成北方移民单方面“带来文明”。

## 主要阶段

| 阶段 | 人口与经济变化 | 不能忽略的因素 |
| --- | --- | --- |
| 秦汉 | 统一国家推动移民、戍边与岭南开发；江南已有本地社会和经济基础 | 不能把南方开发写成北方移民单方面“带来文明” |
| 东汉末至东晋 | 北方战乱推动多轮南迁，东晋政权在江南建立 | 迁徙者与本地群体在土地、政治和文化上既合作也冲突 |
| 南北朝 | 南方农业、水利、手工业和城市继续发展 | 北方也经历恢复、交流和制度重组，并非长期停滞 |
| 隋唐 | 大运河加强南北运输；安史之乱后南方财政地位进一步提高 | 交通体系把南方粮赋与北方政治中心连接起来 |
| 唐末五代至两宋 | 战乱和政权变动继续推动人口南移；江南、东南商业与城市发展 | “苏湖熟，天下足”等说法反映趋势，不是每年、每地都相同 |
| 元明清 | 长江中下游、东南沿海持续重要，湖广、四川等区域开发和人口流动加强 | 海禁、战争、赋役、作物传播和市场网络共同作用 |
| 近现代 | 港口、铁路、工业和区域城市群重塑人口与经济分布 | 现代工业化与古代农业财政重心不能用同一指标衡量 |

## 怎样理解“南移完成”

教材常把两宋视为经济重心南移完成的重要阶段，依据包括人口、粮赋、城市、手工业和商业等综合变化。但“政治中心在北方”和“经济重心在南方”可以同时存在；不同指标的转折时间也不完全相同。
