# 玉器与礼仪：材料、器形与象征怎样相连

玉器不是一种单一用途的物品。佩饰、礼仪器、工具形器和文房用具可以使用相近材料，却有不同功能。传统玉名、矿物鉴定和古人对玉的文化理解也不是完全相同的分类。

## 先看制作，再看象征

玉材需切割、钻孔、琢磨和抛光。孔的位置帮助讨论悬挂与组合，表面的加工痕迹反映制作过程；材料沁色与原来的颜色又需区分。不能把所有孔都解释为佩戴孔，也不能仅靠颜色判定年代。

| 器形 | 可以直接观察的特征 | 解释边界 |
| --- | --- | --- |
| 璧 | 扁平、圆形，中部有孔 | 不同时代的用途及组合需看出土背景 |
| 琮 | 常见外方内圆、纵向穿孔 | 礼仪性质重要，但具体仪式并未全部可知 |
| 龙形器 | 弯曲身躯、头部与装饰 | 龙的动物原型及用途存在不同解释 |
| 鸟凤形器 | 喙、冠、翼、尾等组织 | 不将所有鸟形器都视为同一神祇 |

## 为什么出土背景很关键

器物在墓葬中的位置、同出器组合与墓主人身份，可以帮助判断佩戴、仪式和等级。只看脱离背景的一张图片，很容易将工具形状、神灵象征与身份标志混成一件事。

红山玉龙与良渚玉琮不是同一考古文化的作品；商代玉凤又处于另一套社会与工艺背景。它们能够串起长期的图像和材料传统，但不能据形似便证明五千年间用途从未改变。内圆外方与天圆地方的联系是解释，不冒充良渚人的直接文字说明。
