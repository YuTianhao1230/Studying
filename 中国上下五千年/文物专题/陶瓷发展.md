# 陶瓷发展：从陶器到青瓷、青花与粉彩

陶与瓷都以含黏土的原料成型和烧造，但瓷器一般具有更致密的胎体、更高程度的烧结，胎釉结合也有特点。烧成温度只是判断维度之一，不能靠一个温度数字给所有器物划界。

## 先分清胎、釉和彩

胎是器物的主体；釉是烧成后附着在表面的玻璃质层；彩是装饰所用的色料与绘画。无釉陶、施釉陶和瓷器是不同概念。唐三彩通常属于低温铅釉陶，不是高温瓷，也不意味着每件恰好只有三种颜色。

| 类型 | 看什么 | 代表线索 |
| --- | --- | --- |
| 彩陶 | 陶胎上的绘画与器形 | 人面鱼纹、旋涡纹怎样适应盆罐的曲面 |
| 青瓷 | 青色系釉与致密胎体 | 釉色受铁的状态、配方及烧成气氛影响，不是一桶绿色颜料 |
| 三彩釉陶 | 彩釉流动与塑形 | 骆驼、马和人物造型常见于墓葬明器 |
| 青花瓷 | 白胎上的蓝色釉下绘画 | 以含钴色料绘制，再施釉烧成 |
| 粉彩瓷 | 已烧成器物上的低温彩绘 | 多次加工可以呈现柔和的层次和复杂装饰 |

刻花、划花和印花是造型表面的不同处理，不能与青花、粉彩这些彩绘分类混为一谈。轮制、模制和捏塑也回答不同的问题：器物怎样成型，纹样怎样获得。

## 按时代比较，不只看颜色

羊形青瓷器显示三国时期的器形与青釉；秘色瓷碗可与法门寺地宫衣物账互证；元青花罐把云龙、莲瓣和海水安排在不同装饰带；清代转心瓶则加入多层器体与转动结构。

窑口是生产地点或窑业系统，不是朝代名称。一个窑可能延续很久，同一时代也有多种窑业。款识可能是年款、后刻或仿古表达，不能只见落款便确定烧造年代。官钧类花器的断代仍有研究讨论。
