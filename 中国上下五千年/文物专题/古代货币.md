# 古代货币：钱币不只是圆形方孔钱

货币可以依靠材料重量、印记或约定面值参与交换。古代不同地区、政权和交易场景的币制并不统一，一种新币出现也不意味着旧币立即消失。认识货币时先问怎样计价和是否流通，再问它的形状。

## 区分几种价值方式

| 类型 | 如何理解 | 需要留意 |
| --- | --- | --- |
| 贝币及仿贝币 | 形态和材料与早期交换传统相关 | 出现于墓葬不直接证明所有交易都用贝 |
| 布币、刀币、圜钱 | 战国地域性货币形式 | 形似工具不等于每一枚曾当农具或刀使用 |
| 郢爯等黄金货币 | 金版切割、称量，兼有印记 | 戳印不等于每块都有同一现代面值 |
| 铸造钱币 | 面文、重量和制度共同作用 | 名义价值、金属价值和市场接受程度可能不同 |
| 纸币 | 借助发行权、信用和兑换制度流通 | 印刷技术不能单独保证购买力稳定 |

钱文可以保留年号、币名和价值单位，背文或造像则可能有地域、生产或宗教信息。母钱、钱范、试铸钱和供养钱不是同一层次的市场流通物。

## 两件看似钱币的特殊例子

国宝金匮直万钱的用途与流通情况有讨论，不能只因直万二字便认定任何人都用它买卖。淳化元宝金钱有佛教供养背景，金质与佛像让它承担宗教意义，不代表北宋市民普遍以黄金钱交易。

看纸币时，可以比较票面、发行机构和价值单位；看金银时，还要问是否按重量使用。币制变化要结合税收、贸易和政治管理，不能从货币漂亮或丑判断一个王朝是否繁荣。
