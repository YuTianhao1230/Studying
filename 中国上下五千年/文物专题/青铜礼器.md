# 青铜礼器：鼎、簋、尊、爵怎么认

青铜礼器首先是有用途的器物。它们在祭祀、宴饮与赠赐中被赋予身份意义，器形、组合和铭文又让它们成为理解商周社会的材料。不能只把鼎看成权力象征，也不能把每种青铜器都当作日常餐具。

## 从用途分辨器形

| 器类 | 常见用途与形制 | 识读重点 |
| --- | --- | --- |
| 鼎 | 盛放或烹煮食物；常见三足圆鼎、四足方鼎 | 耳、腹、足如何配合提举和安置；礼仪用途与炊器来源有关 |
| 簋 | 盛黍稷等谷物；通常有圈足和耳 | 不把所有有两耳的容器都认成簋 |
| 尊 | 盛酒；可见圆、方和动物造型 | 认出器口及中空部分，动物形不改变容器功能 |
| 爵 | 酒器；常有流、尾、鋬和三足 | 饮用或温酒等具体功能有讨论，不强定每件的操作 |
| 鉴 | 大型容器，可用于盛水等 | 战国冰鉴是鉴与内器组成的套器，结构不同于单件盆 |

器名有古代用语和后世分类传统，使用时应跟随具体馆藏说明。青铜一般是铜与锡、铅等组成的合金，配比并非一律相同。金银线嵌进青铜表面的槽线称错金银，与在表面附金的鎏金不同。

## 为什么要看铭文

利簋记武王征商与甲子日早晨；大盂鼎记周王对盂的训诰、任命和赏赐。读它们时，器物不再只是造型，而成为有人物、时间和行动的文字材料。铭文也有选择和政治表达，不是全部事件的中立记录。

礼器数量、组合和大小可以帮助讨论等级，但不能把后世总结的九鼎八簋规则不加区分地套给所有商周墓葬。动物纹也不是已经逐一解码的神话人物。
