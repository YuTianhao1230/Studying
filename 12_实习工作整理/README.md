# 实习工作整理

本目录整理实习期间经确认的项目事实、方案、指标、问题与复盘。关键帧检测、D2C 视觉还原度评估和端侧模型安全评估是已确认的三条实习业务线，本目录聚焦其中的选择、实施和结果。

程序分析是补充学习资料，用于扩展静态分析、漏洞分析、代码智能模型及工具链知识，不作为实习项目事实。通用原理通过链接引用对应知识域。
