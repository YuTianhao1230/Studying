# 广告排序与CTR预估

## 知识点解析

### 概述

广告排序系统是在候选广告中预测用户点击、转化和商业价值，并在用户体验、广告主收益和平台收益之间做排序决策。

### 基本链路

```text
用户请求
  -> 广告召回
  -> 粗排
  -> 精排
  -> 出价 / 质量分 / 预估值融合
  -> 重排与过滤
  -> 展示
  -> 点击 / 转化 / 收益反馈
```

### CTR / CVR / eCPM

- CTR：Click Through Rate，点击率。
- CVR：Conversion Rate，转化率。以下定义为点击后的条件转化概率 `P(转化|点击, 曝光)`。
- eCPM：每千次曝光预期收益。

先按计费事件统一到每千次曝光的预期价值。以 bid 近似单位事件价值时：

```text
CPC（按点击计费）：eCPM = 1000 * bid_CPC * pCTR
CPA（按转化计费）：eCPM = 1000 * bid_CPA * pCTR * pCVR
CPM（按千次曝光计费）：eCPM = bid_CPM
```

例如 CPC 出价 2 元、pCTR=0.02，得到 40 元/千次曝光；CPA 出价 100 元、pCTR=0.02、pCVR=0.03，得到 60 元/千次曝光。如果模型直接预测曝光到转化的 pCTCVR，则 CPA 公式直接乘 pCTCVR，不再重复乘 pCTR。

同批广告排序可以省略公共系数 1000，但分数的单位就变成每次曝光价值。bid 是出价，不一定等于拍卖后的实际结算价格，因此上述数值是用于比较的出价价值，实际平台收入还依赖计费与结算机制。

实际系统会更复杂，还会考虑：

- 广告质量。
- 用户体验。
- 预算消耗。
- 频控。
- 行业和内容安全。
- 多目标收益。

### CTR 预估为什么难

- 正负样本极不平衡。
- 用户兴趣变化快。
- 特征稀疏。
- 曝光位置影响点击。
- 广告主预算和出价动态变化。
- 离线训练数据存在选择偏差。

### 常见模型

#### LR / GBDT + LR

早期常用，强调可解释和稳定。

#### Wide & Deep

Wide 记忆高频规则，Deep 学习泛化特征。

#### DeepFM / DCN

建模显式或隐式特征交叉。

#### DIN / DIEN

建模用户历史行为和当前候选广告之间的兴趣相关性。

#### 多任务模型

同时预测 CTR、CVR、GMV、停留时长等目标。

常见问题：

- 多目标冲突。
- 样本空间不一致。
- 负迁移。

### 特征工程

常见特征：

- 用户画像。
- 广告特征。
- 商品特征。
- 上下文特征。
- 历史行为序列。
- 统计特征。
- 交叉特征。

生产系统还会关注：

- Feature Store。
- 特征实时性。
- 训练-serving skew。
- 缺失值处理。
- 特征漂移。

### 评估指标

- AUC：整体排序能力。
- GAUC：按用户或 group 加权的排序能力。
- LogLoss：概率预测的整体质量，对自信的错误惩罚很大，不能单独等同于校准程度。
- Calibration：预估概率和真实概率是否一致。
- CTR/CVR/GMV：线上业务指标。
- p95/p99 latency：线上服务性能。

### 常见面试追问

#### 离线 AUC 涨，线上收益不涨怎么办？

可能原因：

- 离线样本分布和线上流量不一致。
- 业务目标不只点击，还有转化、留存和体验。
- 模型校准不好。
- 位置偏差或曝光偏差未处理。
- 实验流量太小或周期太短。
- 上线链路存在训练-serving skew。

#### 如何处理样本偏差？

可选思路：

- 随机探索流量。
- 负采样校正。
- IPS / Doubly Robust。
- 按曝光位置建模。
- 加入校准层。

## 面试应对

### 广告排序与CTR预估 解决什么业务问题？

回答思路：点明它在候选广告中预估点击/转化/商业价值，并在用户体验、广告主收益、平台收益间做排序权衡，最终用 CTR/CVR/eCPM/GMV 和线上 A/B 验证。

回答模板：

广告排序在有限曝光位置中选择合适的广告。我会把目标拆成用户体验、广告主转化收益和平台收入，先训练点击、转化等预估模型，再结合出价、质量和预算约束排序。离线看排序与概率质量，线上通过 A/B 同时验证收入、转化和用户体验护栏。

### 广告排序与CTR预估 的核心机制是什么？

回答思路：串起“[召回](<../05_推理部署与系统/系统设计/召回粗排精排重排.md>)-粗排-精排-出价融合-重排”，先限定计费事件再换算预期价值。

回答模板：

召回和粗排先缩小候选集，精排根据用户、广告和上下文预测点击或转化概率，然后把不同计费事件换算到曝光价值。CPC 乘 pCTR，CPA 若使用点击后 CVR 则乘 pCTR 和 pCVR，换算 eCPM 时还要乘 1000。最后结合预算、频控和质量约束重排。离线 AUC 高不保证收入高，概率校准、结算规则和流量分布都影响实际效果。

### 广告排序与CTR预估 的常见风险是什么？

回答思路：围绕 CTR 预估特有的难点——正负样本极不平衡、特征稀疏、曝光/位置偏差、冷启动，以及离线 AUC 涨但线上收益不涨来展开。

回答模板：

风险首先来自观测数据：只能看到被展示广告的反馈，位置也会影响点击，直接训练可能固化原排序偏差。其次是负采样后概率失真、未来统计特征泄漏，以及训练和线上特征不一致。我会先核对样本与时间口径，再检查校准和分桶指标，用受控流量实验验证实际收益及用户体验，而不只看 AUC。
