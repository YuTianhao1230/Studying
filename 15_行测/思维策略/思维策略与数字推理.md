# 思维策略与数字推理

## 知识点解析

### 概述

思维策略是银行和运营商 EPI 中常见、但不完全等同于传统数量关系的模块，主要考查在有限条件下寻找规律、统筹资源、优化方案和快速决策。数字推理则要求从数列的加减乘除、倍数、幂次、分组和递推关系中识别生成规则。两类题的共同特点是题面短、规则隐蔽、选项常为具体数，适合用“先识别、后验证、再放弃”的方式处理。

### 数字推理识别顺序

1. 先看相邻差：一阶差、二阶差、周期差。
2. 再看相邻比：等比、倍数、交替倍数。
3. 看幂次和特殊数：平方、立方、质数、阶乘。
4. 看拆分：奇偶项、两两分组、隔项组合。
5. 看递推：`a(n)=a(n-1)+a(n-2)`、乘前项加常数等。
6. 看数字自身特征：各位数字和、首尾数字、数字翻转。

### 常见数列模型

| 模型 | 识别信号 |
| --- | --- |
| 等差 | 相邻差相等 |
| 等比 | 相邻比相等 |
| 二阶等差 | 一阶差构成等差 |
| 间隔数列 | 奇数项、偶数项分别成规律 |
| 幂次变式 | `n^2±n`、`n^3±n`、平方与常数叠加 |
| 递推数列 | 后项由前两项或前一项计算得到 |
| 质数数列 | 2、3、5、7、11、13…… |
| 数字特征 | 各位和、个位与十位运算、数字反转 |

### 思维策略常见模型

- 统筹安排：有限资源分配给多个任务，追求总收益最大或总时间最短。
- 最优配比：两类产出必须配套，短板决定最终套数。
- 排队与路径：比较不同顺序、路线或服务规则下的总成本。
- 方案决策：将多个条件转成表格，逐项计算收益、风险和约束。
- 创新规则：先从题干中寻找“定义规则”，不要套用日常常识。

## 笔试应对

### 常考题型

- 数列找规律和填空。
- 交替数列、分组数列和递推数列。
- 资源分配、任务排序和最优方案。
- 套路不明显的创新思维题。

### 解题方法

数字推理严格按“差、比、幂、分组、递推、数字特征”顺序排查；思维策略先列变量和约束，再比较候选方案。两分钟内仍找不到稳定规律时先跳过，避免陷入无效试探。

### 易错点

- 只看相邻差，忽略奇偶项或隔项规律。
- 找到一个能解释前三项的规律就直接确定，没有验证后续项。
- 把创新题当成常规数学题，忽略题干自定义规则。
- 资源配置题只看单项收益，忽略配套、容量和时间约束。
