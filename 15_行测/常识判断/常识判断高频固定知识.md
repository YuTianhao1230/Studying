# 常识判断高频固定知识

## 知识点解析

### 概述

常识判断覆盖经济、地理、历史、党史、哲学、法律、公文、科技生活和文学文化。它的特点是分值相对低、范围极广、上限有限，因此复习策略应是只背高频固定知识和易混概念，不做无边界扩展。常识题通常通过关键词、限定词和易混项设错，做题时要优先抓“主体、时间、性质、适用范围”。

### 经济指标

| 指标 | 含义 |
| --- | --- |
| GDP | 国内生产总值，强调地域范围内的生产成果 |
| GNP | 国民生产总值，强调本国国民创造的生产成果 |
| NNP | 国民生产净值 |
| CPI | 消费者价格指数，反映居民消费价格变化 |
| PPI | 生产者价格指数，反映工业生产者出厂价格变化 |
| 恩格尔系数 | 食品支出占消费总支出的比重，反映生活水平 |
| 基尼系数 | 衡量收入分配差距 |
| 赤字率 | 财政赤字占 GDP 比重，反映财政风险 |

三驾马车是投资、消费、出口。记忆口诀：GDP 国内，GNP 国民；PPI 生产者，CPI 消费者；恩格尔生活水平，基尼收入分配。

### 二十四节气

口诀：

```text
春雨惊春清谷天，
夏满芒夏暑相连，
秋处露秋寒霜降，
冬雪雪冬小大寒。
```

对应顺序：

| 季节 | 节气 |
| --- | --- |
| 春 | 立春、雨水、惊蛰、春分、清明、谷雨 |
| 夏 | 立夏、小满、芒种、夏至、小暑、大暑 |
| 秋 | 立秋、处暑、白露、秋分、寒露、霜降 |
| 冬 | 立冬、小雪、大雪、冬至、小寒、大寒 |

每个节气约 15 天。节气题常考顺序、季节归属和农事含义。

| 部门法 | 高频知识 |

### 公文 15 种

公文种类：

```text
决议、决定、命令(令)、公报、公告、通告、意见、通知、通报、
报告、请示、批复、议案、函、纪要。
```

易混点：

| 公文 | 用法 |
| --- | --- |
| 请示 | 上行文，请求批准，应一文一事、事前行文 |
| 报告 | 上行文，汇报工作、反映情况，不要求直接批准 |
| 批复 | 下行文，答复请示 |
| 函 | 不相隶属机关之间商洽、询问或答复 |
| 通知 | 发布、传达、批转，使用频率高 |
| 通报 | 表彰先进、批评错误、传达重要情况 |

## 面试应对

### 常考点及考法

- 经济指标题考 GDP/GNP、CPI/PPI、恩格尔系数/基尼系数。
- 节气题考顺序、季节和口诀定位。
- 地理题考邻国、地势、河流、高原和重大工程。
- 法律题考部门法归属、基本原则、权利义务和程序。
- 公文题考文种用途和上行、下行、平行关系。
- 文史题考作者、朝代、代表作品和基础排序。

### 解法/回答思路

1. 先判断题目属于经济、法律、文史、地理还是科技。
2. 找限定词：国内/国民、生产者/消费者、请示/报告、上行/平行。
3. 对明显跨领域错配的选项优先排除。
4. 常识不会时不纠结，保留时间给资料、判断和言语。
5. 考前只背高频表，不做冷门扩展。

### 易错点

- GDP 和 GNP 混淆：一个看地域，一个看国民。
- CPI 和 PPI 混淆：一个消费者，一个生产者。
- 请示和报告混淆：请示求批准，报告做汇报。
- 函的适用机关关系记错：函用于不相隶属机关。
- 节气顺序背乱。
- 法律题把民法、刑法、行政法概念混在一起。

### 回答模板

常识判断我只抓高频固定知识。做题时先判断所属领域，再看题干限定词和选项中的主体、时间、性质、范围是否匹配。经济题重点区分 GDP/GNP、CPI/PPI、恩格尔/基尼；公文题重点区分请示、报告、函、批复；法律题重点看部门法归属和基本原则。不会的常识题不恋战，快速排除明显错误后果断作答。
