# 常识判断高频固定知识

## 知识点解析

### 概述

常识判断覆盖政治理论、国家制度、经济金融、法律、公文、历史文化、地理、生态环境、自然科学、科技生活和社会治理。它的特点是范围广、单点分散、时政变化快，因此要把固定概念、制度边界、易混表达和高频口诀分层整理。常识题通常通过主体、时间、性质、范围、因果和限定条件设错。

### 一、经济指标与宏观经济

| 指标 | 含义 |
| --- | --- |
| GDP | 国内生产总值，强调一国或地区境内生产的最终产品和服务价值 |
| GNP | 国民生产总值，强调本国国民创造的生产成果 |
| NNP | 国民生产净值，GNP 扣除资本折旧 |
| CPI | 消费者价格指数，反映居民消费价格变化 |
| PPI | 生产者价格指数，反映工业生产者出厂价格变化 |
| 恩格尔系数 | 食品支出占消费总支出的比重，通常用于反映生活水平 |
| 基尼系数 | 衡量收入分配差距 |
| 赤字率 | 财政赤字占 GDP 的比重 |
| M0 | 流通中的现金 |
| M1 | 2025 年新口径为 M0、单位活期存款、个人活期存款、非银行支付机构客户备付金之和；旧题可能采用旧口径 |
| M2 | M1 加准货币，包含单位和个人定期存款、其他存款等，反映更广义的货币供给 |

三驾马车是投资、消费、出口。通货膨胀一般表现为物价总水平持续上涨；通货紧缩一般表现为物价总水平持续下降并伴随需求不足。财政政策主要通过税收和政府支出调节，货币政策主要通过利率、存款准备金率、公开市场操作等工具调节。M1 新口径自 2025 年 1 月统计数据起启用，具体以中国人民银行最新公告为准。来源：[国务院政策解读：M1 统计口径“纳新”](https://www.gov.cn/zhengce/202412/content_6990643.htm)。

### 二、国家制度与政治理论

- 国体是人民民主专政；政体是人民代表大会制度。
- 人民代表大会制度是我国根本政治制度。
- 中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度是基本政治制度的重要组成部分。
- 全国人民代表大会是最高国家权力机关；全国人大常委会是全国人大的常设机关。
- 国务院是最高国家行政机关；人民法院是审判机关；人民检察院是法律监督机关。
- 中国人民政治协商会议是统一战线组织，不是国家权力机关。
- 总体国家安全观以人民安全为宗旨、以政治安全为根本、以经济安全为基础、以军事科技文化社会安全为保障、以促进国际安全为依托。
- 新发展理念是创新、协调、绿色、开放、共享；创新解决发展动力问题，协调解决发展不平衡问题，绿色解决人与自然和谐共生问题，开放解决发展内外联动问题，共享解决社会公平正义问题。

### 三、二十四节气与地理口诀

```text
春雨惊春清谷天，
夏满芒夏暑相连，
秋处露秋寒霜降，
冬雪雪冬小大寒。
```

春：立春、雨水、惊蛰、春分、清明、谷雨；夏：立夏、小满、芒种、夏至、小暑、大暑；秋：立秋、处暑、白露、秋分、寒露、霜降；冬：立冬、小雪、大雪、冬至、小寒、大寒。

中国陆上邻国 14 个：朝鲜、俄罗斯、蒙古、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、阿富汗、巴基斯坦、印度、尼泊尔、不丹、缅甸、老挝、越南。海上邻国通常记韩国、日本、菲律宾、文莱、马来西亚、印度尼西亚。

地理高频：我国地势西高东低，呈三级阶梯；四大高原为青藏、内蒙古、黄土、云贵；主要河流包括长江、黄河、珠江、黑龙江；南水北调、西气东输是常见重大工程考点。

### 四、历史、党史、哲学与文化口诀

```text
夏商与西周，东周分两段；
春秋和战国，一统秦两汉；
三分魏蜀吴，二晋前后延；
南北朝并立，隋唐五代传；
宋元明清后，皇朝至此完。
```

党史关键节点：1921 年中共一大、1935 年遵义会议、1949 年新中国成立、1978 年十一届三中全会。唯物辩证法两大总特征是联系和发展，三大规律是对立统一、质量互变、否定之否定。

唐宋八大家：韩愈、柳宗元、欧阳修、王安石、曾巩、苏洵、苏轼、苏辙。四大名著及作者：《三国演义》罗贯中、《水浒传》施耐庵、《西游记》吴承恩、《红楼梦》曹雪芹。四大发明：造纸术、印刷术、火药、指南针。

### 五、法律与公文

| 部门法 | 高频范围 |
| --- | --- |
| 宪法 | 根本法、国家机构、公民基本权利和义务 |
| 民法 | 民事主体、民事行为能力、物权、合同、侵权、诉讼时效 |
| 刑法 | 犯罪构成、刑事责任年龄、正当防卫、紧急避险 |
| 行政法 | 行政许可、行政处罚、行政复议、行政诉讼 |

民事行为能力属于民法，刑事责任年龄属于刑法。普通诉讼时效通常为三年。正当防卫要求针对正在进行的不法侵害，不能事后报复。

15 种法定公文：决议、决定、命令、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。请示是上行求批准，报告是上行汇报，批复用于答复请示，函用于不相隶属机关之间商洽、询问和答复，通知用于发布、传达和批转，通报用于表彰、批评和传达重要情况。请示应一文一事、事前行文。

### 六、自然科学、生态与健康

- 声音传播需要介质，真空不能传声；光具有直线传播、反射和折射现象。
- 浮力等于物体排开液体所受的重力；物体漂浮时浮力等于物重。
- 常压下水的沸点为 100 摄氏度，气压变化会影响沸点。
- 酸雨主要与二氧化硫、氮氧化物等污染物有关。
- 细胞是生命活动的基本单位，DNA 通常呈双螺旋结构，皮肤是人体最大的器官。
- 光合作用吸收二氧化碳并释放氧气，呼吸作用通常消耗氧气并释放能量。
- PM2.5 指空气动力学当量直径小于等于 2.5 微米的颗粒物。
- 绿色低碳发展常考碳达峰、碳中和、可再生能源、循环经济和生态保护红线。
- 计算机基础常考二进制、CPU、IP、HTTP、TCP、数据库和信息安全常识。

## 面试应对

### 常考点及考法

- 经济指标题考 GDP/GNP、CPI/PPI、M1/M2、恩格尔系数和基尼系数。
- 政治理论题考国家制度、国家机构、新发展理念和国家安全观。
- 法律题考部门法归属、权利义务、行政复议和公文用途。
- 地理历史题考节气、邻国、地形、朝代、党史和文化常识。
- 科技生态题考物理、生物、环境、健康和信息技术的基础原理。

### 解法/回答思路

先判断所属领域，再抓主体、时间、性质、适用范围和限定条件。口诀用于快速定位，制度题回到概念边界，科技题回到基本原理，法律题先判断部门法归属。不会的题不恋战，先排除绝对化、跨部门和违反基本原理的选项。

### 易错点

- GDP 和 GNP、CPI 和 PPI、M1 和 M2 混淆。
- 把人大、政府、法院、检察院和政协的职能混淆。
- 把民事行为能力和刑事责任年龄混在一起。
- 把请示和报告、函和通知混淆。
- 节气、邻国、朝代顺序背乱。
- 忽略“常压”“正在进行”“不相隶属”等限定条件。

### 回答模板

常识判断要按领域建立知识网络，而不是只背零散口诀。经济题区分指标对象和政策工具，政治题区分国体、政体和国家机构，法律题先定部门法和适用程序，历史地理题用时间线和空间线定位，科技生态题用基本原理判断。口诀负责提速，概念边界负责排错。
