# 法律经济政治公文

## 知识点解析

### 概述

法律、经济、政治和公文是常识判断中最稳定的制度类考点。法律题重在部门法归属和基本原则，经济题重在指标含义和宏观政策，政治题重在党史、哲学和国家制度，公文题重在文种用途和行文关系。这类题不要求深度论述，但要求概念边界清楚。

### 法律

| 部门法 | 高频范围 |
| --- | --- |
| 宪法 | 根本法、国家机构、公民基本权利和义务 |
| 民法 | 民事主体、民事行为能力、物权、合同、侵权、诉讼时效 |
| 刑法 | 犯罪构成、刑事责任年龄、正当防卫、紧急避险 |
| 行政法 | 行政许可、行政处罚、行政复议、行政诉讼 |

易混：民事行为能力属于民法，刑事责任年龄属于刑法。

### 经济

| 考点 | 重点 |
| --- | --- |
| GDP/GNP | 国内与国民 |
| CPI/PPI | 消费者与生产者 |
| 恩格尔系数 | 食品支出占比，反映生活水平 |
| 基尼系数 | 收入分配差距 |
| 宏观调控 | 财政政策、货币政策 |
| 三驾马车 | 投资、消费、出口 |

### 政治与哲学

- 中国共产党成立：1921 年。
- 遵义会议：1935 年，生死攸关的转折点。
- 新中国成立：1949 年。
- 十一届三中全会：1978 年，改革开放。
- 唯物辩证法总特征：联系和发展。
- 三大规律：对立统一、质量互变、否定之否定。

### 公文

| 文种 | 用途 |
| --- | --- |
| 请示 | 上行，请求批准，一文一事，事前行文 |
| 报告 | 上行，汇报工作或反映情况 |
| 批复 | 下行，答复请示 |
| 函 | 平行或不相隶属机关商洽、询问、答复 |
| 通知 | 发布、传达、批转 |
| 通报 | 表彰、批评、传达重要情况 |

## 面试应对

### 常考点及考法

- 法律题考部门法归属。
- 经济题考指标含义和政策工具。
- 政治题考党史节点和哲学规律。
- 公文题考文种用途和行文方向。

### 解法/回答思路

先分类，再看关键词。法律看归属，经济看指标对象，政治看时间节点，公文看上行、下行还是平行。

### 易错点

- 民法和刑法概念混淆。
- GDP/GNP、CPI/PPI 混淆。
- 请示和报告混淆。
- 把函当成上下级机关文种。

### 回答模板

制度类常识先分法律、经济、政治和公文。法律题看部门法归属，经济题看指标对象，政治题看党史节点和哲学规律，公文题看行文方向和用途。请示是上行求批准，报告是上行汇报，函用于不相隶属机关。
