# 常识判断补充考点

## 知识点解析

### 概述

央国企和银行笔试的常识题，常把普通行测知识与经济金融、企业治理、国家治理、法律社会治理和科技生态结合起来。此类题不一定要求专业计算，但会考概念之间的边界、政策工具的作用对象以及制度安排的目的。

### 一、货币金融基础

- 货币的基本职能包括价值尺度、流通手段、支付手段、贮藏手段和世界货币。
- 利率上升通常会提高融资成本，抑制投资和部分消费；利率下降通常有利于降低融资成本。
- 存款准备金率上调通常会收缩商业银行可用于贷款的资金，属于紧缩性货币政策方向。
- 公开市场操作是中央银行买卖有价证券以调节基础货币和市场流动性。
- 商业银行主要业务包括吸收存款、发放贷款和办理结算等。
- 风险管理关注风险识别、风险评估、风险控制和风险监测；内部控制重点是岗位分离、授权审批、相互制约和流程留痕。
- 保险的基本功能是分散风险、补偿损失和资金融通；保险不是保证投资收益的工具。
- 股票代表股东权益，债券通常代表债权债务关系；股票收益和风险一般高于普通债券。

### 二、财政、税收与企业治理

- 财政政策通过政府支出、税收和政府债务等影响总需求。
- 扩大政府支出、减税降费通常属于扩张性财政政策方向；减少支出、增税通常属于紧缩性方向。
- 增值税以商品和服务流转过程中的增值额为计税依据，具有环环抵扣特征。
- 企业法人、股东、董事、监事和高级管理人员的法律责任不能混同。
- 公司治理常考股东会、董事会、监事会和经理层的职责边界，题目会通过“谁有权决定”设错。
- 国有企业改革常见关键词是完善现代企业制度、增强核心功能、提升核心竞争力、防止国有资产流失。

### 三、法律与社会治理

- 民事主体包括自然人、法人和非法人组织。
- 8 周岁以上未成年人是限制民事行为能力人；成年人一般为完全民事行为能力人，不能把民事行为能力和刑事责任年龄混用。
- 行政许可是行政机关根据申请准予从事特定活动；行政处罚是对违反行政管理秩序行为的制裁；行政强制是为实现行政管理目的采取的强制措施或执行。
- 行政复议和行政诉讼都可以对部分行政行为进行救济，但程序、受理机关和审查方式不同。
- 消费者的知情权、自主选择权、公平交易权、安全保障权和依法求偿权是常见考点。
- 个人信息处理要遵循合法、正当、必要原则，不能无限制收集和使用。
- 公共管理题常考依法行政、权责清单、政务公开、社会信用和基层治理。

### 四、生态环境与能源

- 碳达峰是二氧化碳排放量达到峰值后进入下降阶段；碳中和是通过减排、吸收和抵消实现净排放接近零。
- 可再生能源包括太阳能、风能、水能、生物质能、地热能和海洋能等。
- 节能不等于简单停产，绿色发展强调资源节约、污染防治、产业升级和循环利用的协同。
- 生态保护红线、永久基本农田、城镇开发边界是国土空间开发保护的重要控制线。
- 酸雨、臭氧层破坏、温室效应和雾霾的成因与治理措施不能混为一谈。

### 五、科技与信息安全

- 5G 常考高带宽、低时延、大连接，但具体性能取决于频段、网络部署和应用场景。
- 云计算提供计算、存储和软件等资源服务；大数据强调规模、多样性、速度和价值挖掘；人工智能强调从数据中学习模式并完成预测或决策。
- 对称加密使用同一密钥加解密；非对称加密使用公钥和私钥；数字签名主要用于身份认证、完整性和不可否认性。
- HTTP 是应用层协议，TCP 提供面向连接、可靠的传输服务，IP 负责网络层寻址和路由。
- 二维码、条形码、传感器、物联网和区块链常以应用场景设题，不要把“去中心化”“不可篡改”等宣传性表述当作绝对性质。

## 面试应对

### 常考点及考法

- 银行笔试把货币金融、内部控制和普通常识放在同一职业能力单元。
- 央国企笔试把企业治理、国企改革、科技产业和政策表述结合起来。
- 法律题通过概念相近的制度安排设置边界陷阱。
- 生态科技题通过污染类型、能源类型和信息技术协议设置对应关系。

### 解法/回答思路

先判断题目考的是概念、主体、政策工具还是程序；再问“这个制度解决什么问题、谁来执行、作用对象是谁”。经济金融题看政策方向，法律题看主体和程序，科技题看协议层级和基本原理。

### 易错点

- 把财政政策和货币政策的执行主体、工具混淆。
- 把内部控制等同于监控所有个人行为。
- 把行政许可、行政处罚、行政强制混为一谈。
- 把碳达峰和碳中和年份或含义记反。
- 把 HTTP、TCP、IP 放在同一协议层级。

### 回答模板

央国企和银行常识题的关键是概念边界。金融题区分货币政策、财政政策、商业银行业务和内部控制；法律题区分民事、行政和刑事制度及其程序；企业治理题看股东会、董事会、监事会和经理层的权责；科技生态题回到协议层级、能源类型和污染成因。遇到选项表述绝对化，要优先检查它是否把局部作用说成全部作用。
