# 行测

行测包括政治理论、常识判断、言语理解与表达、数量关系、判断推理和资料分析六类官方考试内容；央国企笔试还常把时政、企业文化和行业知识单独设为综合知识。核心复习目标不是把知识无限铺开，而是把题型识别、公式规则、解题顺序、易错陷阱和考场取舍固定下来。官方范围可参考[2025年度国考公共科目笔试考试大纲](https://www.trs.gov.cn/xwzx/tzgg/zkxx/202410/t20241015_85940275.html)。

## 模块优先级

1. 资料分析：公式固定、套路强、性价比最高，应作为稳定拿分模块。
2. 判断推理：图推靠特征分流，逻辑判断靠翻译和论证规则，适合系统提速。
3. 言语理解：重点在结构阅读和选项排除，不靠全文精读。
4. 数量关系：不追求全做，优先挑代入、赋值、工程、行程、最值等套路题。
5. 常识判断：只背高频固定知识，不做无边界扩展。
6. 时政热点：考前集中刷新，尤其关注央国企、重大会议、科技成就和政策原文表述。

## 单套行测时间策略

| 模块 | 建议策略 |
| --- | --- |
| 常识判断 | 5-8 分钟，不会就过，不恋战。 |
| 言语理解 | 30-35 分钟，先抓结构和主题词，再排除选项。 |
| 判断推理 | 35 分钟，图推 30 秒无思路先跳。 |
| 资料分析 | 25-28 分钟，作为必拿模块优先保证准确率。 |
| 数量关系 | 10-15 分钟，只做会做的套路题，其余统一蒙同一选项。 |
