# 真假推理与分析推理

## 知识点解析

### 概述

真假推理考命题之间的真假关系，分析推理考条件匹配和排序安排。真假推理的核心是找矛盾、反对和下反对关系；分析推理的核心是把条件表格化，从最大信息、确定条件和代入排除入手。二者都不适合凭直觉猜，要把语言条件转成结构。

### 真假推理

常见关系：

| 关系 | 特点 |
| --- | --- |
| 矛盾关系 | 必有一真一假，如 A 与非 A |
| 反对关系 | 不能同真，可以同假，如“所有都是”和“所有都不是” |
| 下反对关系 | 不能同假，可以同真，如“有的是”和“有的不是” |

常见等价：

- “所有 A 都是 B”的矛盾是“有的 A 不是 B”。
- “所有 A 都不是 B”的矛盾是“有的 A 是 B”。
- “有的 A 是 B”不能推出“有的 A 不是 B”。

### 分析推理

常见题型：

- 人物与事件匹配。
- 名次排序。
- 座位排列。
- 职业、城市、物品对应。
- 条件真假混合。

标准方法：

1. 列表或画线，把对象和属性分开。
2. 找确定条件，先填必然信息。
3. 找最大信息，即出现次数最多的对象。
4. 对条件复杂的选项用代入排除。
5. 排序题用不等式链条。

### 代入排除

当选项给出完整方案时，优先代入排除。把选项逐一代回所有条件，违反任一条件即可排除。这比从零推理更快。

## 面试应对

### 常考点及考法

- 真假题给若干人说话，问谁真谁假。
- “只有一真/只有一假”考矛盾关系。
- 分析推理考人、事、物多维匹配。
- 排序题考先后、高低、左右位置。

### 解法/回答思路

真假推理先找矛盾对，再结合“几真几假”推出其余命题。分析推理先列表，填确定条件，复杂题直接代入选项。

### 易错点

- 把反对关系当矛盾关系。
- “有的”命题理解成“只有一部分”。
- 条件匹配题不列表，靠脑记导致遗漏。
- 代入选项时只验证部分条件。

### 回答模板

真假推理先找矛盾关系，因为矛盾命题必一真一假，再结合题干给出的真假数量推出其他命题。分析推理先把对象和属性列表化，优先填确定条件和最大信息；如果选项给出完整方案，就直接代入排除。
