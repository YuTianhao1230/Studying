# 翻译推理

## 知识点解析

### 概述

翻译推理体系强调把自然语言转成箭头关系，再按形式逻辑推理。翻译推理不靠语感，靠固定关联词：如果、只要、所有通常是前推后；只有、不 A 不 B、除非通常是后推前。翻译完成后，只能用肯前必肯后、否后必否前，不能用否前或肯后强推结论。

### 前推后

| 语言 | 翻译 |
| --- | --- |
| 如果 A 就 B | `A -> B` |
| 只要 A 就 B | `A -> B` |
| 所有 A 都是 B | `A -> B` |
| A 必须 B | `A -> B` |

### 后推前

| 语言 | 翻译 |
| --- | --- |
| 只有 A 才 B | `B -> A` |
| 不 A 不 B | `B -> A` |
| 除非 A 否则不 B | `B -> A` |
| A 是 B 的必要条件 | `B -> A` |

记忆：谁是必要条件，箭头就指向谁。

### 推理规则

若 `A -> B`：

| 已知 | 能否推出 |
| --- | --- |
| A 成立 | B 成立 |
| B 不成立 | A 不成立 |
| A 不成立 | 不能推出 B 不成立 |
| B 成立 | 不能推出 A 成立 |

### 德摩根定律

```text
非(A 且 B) = 非A 或 非B
非(A 或 B) = 非A 且 非B
```

看到“不都”“并非都”“不可能同时”等表述，要优先转成德摩根形式。

## 面试应对

### 常考点及考法

- 给一组条件，问一定能推出什么。
- 用“只有、除非、不……不……”考后推前。
- 用“并非 A 且 B”考德摩根。
- 用否前或肯后设置错误选项。

### 解法/回答思路

先圈关联词，翻译成箭头；再用肯前、否后推理；遇到复合命题先用德摩根展开。不要凭日常语感理解“只有”和“除非”。

### 易错点

- 把“只有 A 才 B”翻译成 `A -> B`。
- 否前推出否后。
- 肯后推出肯前。
- 德摩根中“且”和“或”没有互换。

### 回答模板

翻译推理先把自然语言变成箭头。遇到如果、只要、所有，一般前推后；遇到只有、不 A 不 B、除非，一般后推前。推理时只能肯前肯后、否后否前，否前和肯后没有必然结论。复合命题用德摩根展开后再判断。
