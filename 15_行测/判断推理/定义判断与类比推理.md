# 定义判断与类比推理

## 知识点解析

### 概述

定义判断和类比推理是判断推理中规则最稳定的文字题。定义判断考“给定概念是否满足条件”，关键是拆出主体、客体、方式、目的、条件和结果；类比推理考“两个词之间的关系是否一致”，关键是先定一级关系，再用二级辨析排除干扰项。

### 定义判断

定义判断的拆解维度：

| 维度 | 问题 |
| --- | --- |
| 主体 | 谁实施行为 |
| 客体 | 行为作用于谁 |
| 方式 | 通过什么方式 |
| 目的 | 为了什么 |
| 条件 | 在什么前提下 |
| 结果 | 造成什么结果 |

做题顺序：

1. 圈定义关键词。
2. 标出必要条件。
3. 逐项核对选项。
4. 主体、客体、条件不一致直接排除。
5. 注意题干问“符合”还是“不符合”。

### 类比推理一级关系

| 关系 | 内容 |
| --- | --- |
| 语义关系 | 近义、反义、象征、比喻 |
| 语法关系 | 主谓、动宾、偏正、并列 |
| 逻辑关系 | 全同、并列、包容、交叉、对应 |
| 常识关系 | 功能、材料、组成、场所、因果、时间顺序 |

### 类比推理二级辨析

一级关系相同后，看：

- 词性是否一致。
- 感情色彩是否一致。
- 程度轻重是否一致。
- 主体对象是否一致。
- 必然关系还是或然关系。
- 词语结构是否一致。

## 面试应对

### 常考点及考法

- 定义判断考主体、条件、目的缺失。
- 类比推理考包容、对应、功能、材料和因果。
- 干扰项常一级关系相似，但二级属性不一致。

### 解法/回答思路

定义判断按关键词逐项核对，不做常识扩展；类比推理先定一级关系，再用词性、色彩、主体和必然性做二级辨析。

### 易错点

- 定义判断把“可能符合”当“严格符合”。
- 忽略题干“不属于”的反向问法。
- 类比只看表面相似，不看关系一致。
- 一级关系一致后不做二级辨析。

### 回答模板

定义判断先拆主体、客体、方式、目的、条件和结果，选项缺少必要条件就排除。类比推理先判断两个词的一级关系，如语义、语法、逻辑或常识对应；若多个选项都像，再比较词性、感情色彩、程度、主体和必然性。
