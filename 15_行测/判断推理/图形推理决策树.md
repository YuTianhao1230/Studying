# 图形推理决策树

## 知识点解析

### 概述

图形推理决策树的核心是按“元素组成”快速分流，避免在没有方向时盲目数点线面。图推第一判断不是规律本身，而是图形之间像不像：元素完全相同看位置，元素相似看样式，元素不同先看属性再看数量，出现立体图再进入空间规律。

### 四类分流

| 图形状态 | 优先规律 |
| --- | --- |
| 元素组成相同 | 位置：平移、旋转、翻转 |
| 元素组成相似 | 样式：遍历、加减同异、黑白运算 |
| 元素组成不同 | 属性：对称、曲直、开闭；再数量：点线角面素 |
| 立体图形 | 空间：折纸盒、截面、三视图、拼合 |

### 九宫格横行优先

看到 3x3 九宫格，优先看横行：

1. 横行是否有相同变化。
2. 横行没有，再看竖列。
3. 再看整体遍历。
4. 再看米字形或中心对称。
5. 最后看相邻运算。

### 黑白块两路分流

黑白块先判“动不动”：

- 位置在动：按黑白运算处理。
- 位置不动：数黑块、数部分、看对称或看面积。

黑白块题最忌一上来数数量，因为很多题本质是位置运算。

### 功能元素

黑点、箭头、小圆、小三角等功能元素常用于标记：

- 交点。
- 线段。
- 角。
- 面。
- 方向。
- 长短。
- 相邻或相对关系。

功能元素不是普通数量元素，优先看它“指向哪里”或“落在哪里”。

## 面试应对

### 常考点及考法

- 一组图形元素完全相同，考平移、旋转、翻转。
- 黑白块题考黑白运算或部分数。
- 九宫格考横行、竖列、整体遍历。
- 小黑点、箭头考功能元素。

### 解法/回答思路

先按元素组成分流，再进入具体规律。元素相同不数数量，先看位置；元素不同才看属性和数量。黑白块先判断位置是否变化。

### 易错点

- 所有图推都先数点线面。
- 黑白块位置变化时仍然数数量。
- 九宫格不看横行，直接找复杂关系。
- 功能元素当普通元素数个数。

### 回答模板

图形推理决策树的核心是元素分流：相同看位置，相似看样式，不同先属性后数量，立体看空间。九宫格先横行后竖列，黑白块先判断位置动不动，功能元素看标记位置和指向。这样能先确定大方向，再进入具体规律。
