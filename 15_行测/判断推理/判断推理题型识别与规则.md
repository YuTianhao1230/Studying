# 判断推理题型识别与规则

## 知识点解析

### 概述

判断推理包括图形推理、定义判断、类比推理、[翻译推理](<翻译推理.md>)、真假推理、分析推理和论证题。它的核心不是主观感觉，而是规则分流：图推先看元素组成，逻辑题先找命题关系或论证结构。图推按“元素相同看位置、元素相似看样式、元素不同先属性后数量、出现立体看空间”处理；逻辑判断按“翻译、真假、匹配、削弱加强”分别套规则。

### 图形推理总决策树

| 图形特征 | 优先考点 |
| --- | --- |
| 元素组成相同 | 位置规律：平移、旋转、翻转 |
| 元素组成相似 | 样式规律：遍历、加减同异、黑白运算 |
| 元素组成不同 | 先属性后数量：对称、曲直、开闭、点线角面素 |
| 出现立体图 | 空间规律：折纸盒、截面、三视图、拼合 |

图推 30 秒没有方向就跳，不要陷入“硬想”。属性规律通常最快，数量规律最慢；先用特征分流，不能一上来就数点线面。

### 九宫格与黑白块

九宫格优先看横行规律，横行无规律再看竖列、整体遍历、米字形、中心对称和相邻运算。常见运算是“图 1 加减图 2 得图 3”，或“第一行加第二行得第三行”。

黑白块题先判断位置是否在动：

| 情况 | 解法 |
| --- | --- |
| 黑白块位置在动 | 按位置做黑白运算，如黑+白、白+黑、黑+黑、白+白 |
| 位置不动、分堆明显 | 数部分数，连在一起算 1 部分 |
| 黑块个数有变化 | 数黑块数量、看数量递增递减 |
| 图形有对称感 | 看轴对称、中心对称或对称轴方向 |

方向判断错会导致整题错，所以黑白块不能默认就是数数量。

### 位置规律

| 类型 | 判断方法 |
| --- | --- |
| 平移 | 看方向：上下、左右、对角线；看步数：恒定、递增、循环、往返 |
| 旋转 | 看顺逆时针和角度，常见 45 度、90 度、180 度 |
| 翻转 | 上下翻时左右不变，左右翻时上下不变 |
| 时针法 | 相邻顶点连成的时针方向改变可区分旋转与翻转 |

时钟和指针题重点看指针旋转方向、角度变化和时分针夹角。常见角度是 30 度、90 度和 180 度。

### 样式规律

| 类型 | 识别信号 |
| --- | --- |
| 遍历 | 每行或每列元素种类齐全，缺什么补什么 |
| 加减同异 | 两图叠加后去同存异、去异存同 |
| 黑白运算 | 黑白块位置变化，按同一位置运算 |
| 元素换算 | 不同小元素存在数量换算关系，如 1 圆 = 2 三角 |

### 属性规律与数量规律

属性规律包括对称、曲直和开闭：

- 对称：轴对称看对称轴数量与方向，中心对称看旋转 180 度是否重合。
- 曲直：全直、全曲、曲直混合。
- 开闭：全封闭、半封闭、开放。

数量规律包括点、线、角、面、素和笔画：

| 数量对象 | 触发信号 |
| --- | --- |
| 点 | 图形交叉混乱，尤其曲直交点 |
| 线 | 线条多、边数明显 |
| 角 | 锯齿、多边形、直角或锐角明显 |
| 面 | 封闭区域多，有“窟窿” |
| 素 | 一堆相同小图形，数个数和种类 |
| 笔画 | 奇点数为 0 或 2 可一笔画 |

特殊图形速记：五角星、圆、日字常考一笔画；田字和字母 A 常考两笔画；等腰三角形和箭头常考轴对称；N、Z、平行四边形常考中心对称；汉字常考笔画、结构和封闭面。

### 空间规律

折纸盒题不要靠脑内折叠，按四步机械排除：

1. 相对面法：正方体有 3 对相对面，相对面折叠后不能同时出现。
2. 画边法：选一个特征面，固定起点，顺时针标 1-4 条边，比对每条边相邻图形是否一致。
3. 时针法：三个相邻面共顶点时，顺时针顺序在展开图和立体图中不变。
4. 公共点/公共边法：带小黑点、斜线、箭头时，看公共点周围特征和公共边两侧位置是否一致。

截面题看切割平面与立体相交后的形状；三视图看正视、俯视、侧视投影；拼合题看凹凸互补和体积块数。

### 定义判断

定义判断要抓“主体、客体、方式、目的、条件、结果”。先确定被定义项属于哪一类，再看区别特征，即“属 + 种差”。

排除时优先看：

- 主体是否一致。
- 客体是否一致。
- 条件是否缺失或新增。
- 选项是否只“可能相关”但不满足定义。
- 题干问“符合”还是“不符合”。

### 类比推理

一级关系包括语义、语法和逻辑关系：

| 关系 | 例子 |
| --- | --- |
| 语义 | 近义、反义、象征 |
| 语法 | 主谓、动宾、偏正 |
| 逻辑 | 全同、并列、包容、交叉、对应 |

一级关系一致时进入二级辨析：词性、感情色彩、程度、必然/或然、主体、词语结构。对应关系最杂，包括功能、材料、组成、场所、因果和时间顺序，优先选最直接的对应。

### 翻译推理

| 关联词 | 翻译 |
| --- | --- |
| 如果 A 就 B、只要 A 就 B、所有 A 是 B | `A -> B` |
| 只有 A 才 B、不 A 不 B、除非 A 否则不 B | `B -> A` |

推理规则：

- 肯前必肯后。
- 否后必否前。
- 否前和肯后没有必然结论。

德摩根定律：

```text
非(A 且 B) = 非A 或 非B
非(A 或 B) = 非A 且 非B
```

翻译推理是逻辑判断中最该拿满分的小题，看到关联词先翻译，不要凭语感。

### 真假推理、分析推理与论证

真假推理先找矛盾关系，如 `A` 与 `非A`、“所有是”与“有的不是”。如果题干说“只有一真”，则矛盾对中一真一假，其余命题可按条件推。

分析推理用代入排除、最大信息优先和确定条件突破。信息匹配题不要手算全局，先找出现次数最多、限制最强的条件。

论证题第一步永远是找论点。常见力度如下：

| 类型 | 力度顺序 |
| --- | --- |
| 削弱 | 否定论点 > 拆桥 > 否定论据 > 他因削弱 |
| 加强 | 搭桥 > 补充论据 > 解释原因 |
| 前提假设 | 缺了它论证不成立，通常是搭桥或排除他因 |

## 面试应对

### 常考点及考法

- 图推给出一组图形，让判断下一图或分组分类。
- 定义判断给出抽象定义，让选最符合或最不符合的一项。
- 类比推理给两词关系，让找结构最一致的一组。
- 翻译推理考关联词、逆否命题和德摩根。
- 论证题考削弱、加强、前提、解释和评价。

### 解法/回答思路

1. 图推先按元素组成分流，不直接数数量。
2. 黑白块先判位置动不动，动则运算，不动再数数量或看对称。
3. 定义判断圈主体、客体、方式、目的、条件、结果。
4. 类比先定一级关系，再用二级辨析排除。
5. 翻译推理先翻译成箭头，再用肯前否后。
6. 论证题先找论点，再看选项是否直接针对论点或论证桥梁。

### 易错点

- 图推把所有题都往数量规律上靠，忽略属性和样式。
- 黑白运算和黑块数量混淆。
- 翻译推理把“只有 A 才 B”误翻成 `A -> B`，正确是 `B -> A`。
- 否前、肯后强行推出结论。
- 论证题没有先找论点，选了只攻击背景或论据细节的弱选项。
- 类比题一级关系相同后，忽略词性、褒贬和主体。

### 回答模板

判断推理先分题型。图推题我先看元素组成：相同看位置，相似看样式，不同先属性后数量，立体看空间；逻辑题我先找结构，翻译推理看关联词，定义判断抓主体客体和条件，类比推理先定一级关系再二级辨析，论证题先找论点再判断选项是削弱、加强还是无关。这个模块的关键是按规则分流，而不是凭直觉硬猜。
