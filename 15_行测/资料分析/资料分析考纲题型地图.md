# 资料分析考纲题型地图

## 知识点解析

### 概述

资料分析的考纲范围可以概括为“读材料、找数据、套统计关系、做近似计算”。材料形式包括文字、表格、柱状图、折线图、饼图和综合材料；题型包括直接查找、增长类、比重类、平均数类、倍数类、贡献率与拉动增长、指数、进出口和综合判断。标准方法是先识别统计口径，再确定公式，最后根据选项差距选择精算或估算。

### 材料类型

| 材料 | 读法 |
| --- | --- |
| 文字材料 | 先圈主体、时间、单位和指标，避免信息串行读错 |
| 表格材料 | 先看行列含义，再按题干关键词定位单元格 |
| 柱状图 | 适合比较数量大小和增减变化 |
| 折线图 | 适合看趋势、增速和峰谷 |
| 饼图 | 适合看结构占比 |
| 综合材料 | 先判断题目落在哪一张图表或哪一段文字 |

### 标准题型范围

| 题型 | 问法 | 方法 |
| --- | --- | --- |
| 直接查找 | 最大、最小、多少、第几 | 定位后核对单位 |
| 增长率 | 增长了百分之几 | `(现期-基期)/基期` |
| 增长量 | 增加多少 | `现期-基期` 或 `现期 x r/(1+r)` |
| 基期量 | 上年/去年为多少 | `现期/(1+r)` |
| 比重 | 占比、比重 | `部分/整体` |
| 基期比重 | 上年占比 | `(部分/整体)x(1+整体r)/(1+部分r)` |
| 平均数 | 人均、单位量 | `总量/份数` |
| 倍数 | 是几倍、多几倍 | 直接相除或相除后减 1 |
| 拉动增长 | 拉动几个百分点 | `部分增量/整体基期` |
| 贡献率 | 贡献多少 | `部分增量/整体增量` |
| 指数 | 以某期为 100 | `100 x 现期/基期` |
| 进出口 | 顺差、逆差、总额 | 出口、进口、差额分别处理 |

### 综合判断题

综合判断题通常一题四个选项，每个选项对应一种小题型。常见设错位置是主体、时间、单位、增长率与增长量、百分点与百分比。做法是先看问“正确”还是“不正确”，再从 C、D 项开始验证，遇到确定答案立即停止。

## 面试应对

### 常考点及考法

- 图表定位题考材料阅读速度。
- 增长、比重、平均数、倍数题考公式识别。
- 综合判断题考多口径核对。
- 进出口题考顺差、逆差和混合增速。

### 解法/回答思路

先按题干关键词确定题型，再去材料定位；定位时核对时间、主体和单位；计算时看选项差距决定精度。综合判断题不逐项精算，找到确定项就停。

### 易错点

- 把增长量和增长率混用。
- 忽略单位换算。
- 基期、现期拿反。
- 比重差写成百分比。

### 回答模板

资料分析的考纲范围主要是统计材料阅读和固定公式计算。正常做法是先判断材料类型和题干题型，再核对时间、主体、单位，最后按增长、比重、平均数、倍数、贡献率等公式计算。综合判断题要从选项后部开始验证，重点防主体、时间、单位和百分点陷阱。
