# 比重平均数与倍数

## 知识点解析

### 概述

比重、平均数和倍数是资料分析中最容易因概念混淆而丢分的题型。比重看部分与整体，平均数看总量与份数，倍数看两个量之间的比值。解题时要先判断题干在问“占多少”“平均多少”还是“是几倍/多几倍”，再套对应公式。

### 比重三件套

| 题型 | 公式 |
| --- | --- |
| 现期比重 | `部分 / 整体` |
| 基期比重 | `(部分 / 整体) x (1 + 整体增长率) / (1 + 部分增长率)` |
| 两期比重差 | `现期比重 x (部分增长率 - 整体增长率) / (1 + 部分增长率)` |

方向判断：

```text
部分增长率 > 整体增长率 -> 比重上升
部分增长率 < 整体增长率 -> 比重下降
```

### 百分点

比重差的单位是“百分点”。例如：

```text
30% - 25% = 5 个百分点
```

不能说“增长 5%”。`%` 表示比例，百分点表示两个百分数相减后的差值。

### 平均数

平均数公式：

```text
平均数 = 总量 / 份数
```

平均数增长率：

```text
r = (a - b) / (1 + b)
```

其中 `a` 是总量增长率，`b` 是份数增长率。若总量增长率大于份数增长率，则平均数上升；反之下降。

### 倍数

| 表述 | 含义 |
| --- | --- |
| A 是 B 的 n 倍 | `A / B = n` |
| A 比 B 多 n 倍 | `A / B - 1 = n` |
| A 比 B 增长 n% | `(A - B) / B = n%` |

“多 2 倍”等于“是 3 倍”，这是倍数题最高频陷阱。

## 面试应对

### 常考点及考法

- 问某部分占整体的比重。
- 问基期比重或比重变化方向。
- 问平均数是否上升、平均数增长率是多少。
- 问 A 是 B 的几倍或比 B 多几倍。

### 解法/回答思路

比重题先找部分和整体；平均数题先找总量和份数；倍数题先判断“是几倍”还是“多几倍”。比重变化方向只看部分增长率和整体增长率的大小。

### 易错点

- 把百分点写成百分号。
- 基期比重增长率项写反。
- 平均数增长率把总量增速和份数增速混淆。
- “多 n 倍”误解为“是 n 倍”。

### 回答模板

比重、平均数和倍数题要先辨别语言。出现“占”就是比重，找部分和整体；出现“平均”就是总量除以份数；出现“是几倍”直接相除，出现“多几倍”要在相除后减 1。比重变化方向看部分增长率和整体增长率，部分增速更高则比重上升。
