# 材料阅读与综合判断

## 知识点解析

### 概述

资料分析结构阅读方法强调先读材料结构和统计口径，再做题定位。资料分析错题很大一部分不是公式不会，而是主体、时间、单位、同比/环比、累计/当期读错。结构阅读的目标是建立材料地图，让每道题能快速回到对应段落、图表和指标。

### 材料阅读顺序

1. 先看标题，确定统计对象。
2. 看时间范围，区分年度、季度、月度、累计值。
3. 看单位，尤其是亿元、万美元、万人、百分点。
4. 看图表列名，确认主体和指标。
5. 再读题干，带着关键词回材料定位。

### 三核对

资料定位必须核对三件事：

| 核对项 | 作用 |
| --- | --- |
| 时间 | 防止把 2020 看成 2021，把累计看成当月 |
| 主体 | 防止把全国、某地区、某行业混用 |
| 单位 | 防止亿元/万元、百分数/百分点错位 |

### 综合判断题策略

综合判断题通常问“正确的是”或“不正确的是”。做法：

1. 先看题干问正确还是不正确。
2. 从 C 或 D 选项往上验证，错误常放在后面。
3. 每个选项只验证关键数字或关键逻辑。
4. 找到确定错误或确定正确后即停。
5. 不要为了一个选项做过长精算。

### 选项语言陷阱

| 选项表述 | 处理 |
| --- | --- |
| 约、可能、大致 | 语气温和，容许估算误差 |
| 一定、均、全部、唯一 | 语气绝对，重点核对 |
| 高于、低于、超过、不足 | 注意方向 |
| 增长、增加、提高 | 区分增长率和增长量 |
| 百分点、% | 单位不能混用 |

## 面试应对

### 常考点及考法

- 图表材料问某年某主体数值，考定位能力。
- 综合判断题考多个选项正误。
- 题干故意改变单位、时间、主体。
- 选项用“约”“超过”“不足”等词制造判断难度。

### 解法/回答思路

资料分析先读材料结构，不先算。每道题都回到标题、时间、主体和单位四个口径上校验；综合判断题从后往前验证，找到明显错误就停止。

### 易错点

- 没看单位，亿元和万元混用。
- 没看时间，把基期和现期拿反。
- 把“累计同比”和“当月同比”混在一起。
- 综合判断题逐项精算，导致时间爆炸。

### 回答模板

结构阅读的核心是先建立材料地图。做资料分析时我先看标题、时间范围、单位和图表列名，再根据题干关键词定位。每个数据都核对时间、主体、单位，综合判断题从 C 或 D 往前验证，找到确定项就停。这样能减少读错材料造成的低级错误。
