# 速算技巧

## 知识点解析

### 概述

资料分析速算的重点不是把简单百分数机械换成分数，而是处理 6.2%、15.4%、28.6%、43%、67% 等非常见数据。常用方法包括非常见百化分、放缩、取中、反向代入、凑整平衡、插值、溶液法和差分比较。所有估算都必须服从选项区分度，不能为了快而失去方向。

### 截位直除与误差控制

| 选项差距 | 处理 |
| --- | --- |
| 首位不同、差距很大 | 分母截两位，算商的首位 |
| 首位相同、次位差较大 | 分母截两位，算商的前两位 |
| 首位相同、次位差很小 | 分母截三位，必要时精算 |

操作顺序：先读题干和选项，判断结果量级；再决定截几位；先估首位，再判断是否需要补算；估算结果靠近两个选项时，回到精算或换方法。

### 非常见百化分

资料分析中更值得背的是中小百分数。看到这些数据，先想到倒数，再决定是否使用增长量公式：

| 分数 | 百分数近似 | 分数 | 百分数近似 |
| --- | ---: | --- | ---: |
| 1/6 | 16.7% | 1/7 | 14.3% |
| 1/9 | 11.1% | 1/11 | 9.1% |
| 1/12 | 8.3% | 1/13 | 7.7% |
| 1/14 | 7.1% | 1/15 | 6.7% |
| 1/16 | 6.25% | 1/17 | 5.9% |
| 1/18 | 5.6% | 1/19 | 5.3% |
| 1/21 | 4.8% | 1/22 | 4.5% |
| 1/23 | 4.3% | 1/24 | 4.2% |
| 1/27 | 3.7% | 1/28 | 3.6% |
| 1/32 | 3.125% | 1/33 | 3.0% |

看到 16.7%，优先想到 1/6；看到 14.3%，想到 1/7；看到 11.1%，想到 1/9；看到 9.1%，想到 1/11。

### 放缩与取中

熟悉分数可以通过倍数和中间值覆盖非常见数据：

| 百分数 | 近似分数 |
| --- | --- |
| 1.43% | 1/70 |
| 2.86% | 1/35 |
| 4.76% | 1/21 |
| 5.88% | 1/17 |
| 7.69% | 1/13 |
| 9.09% | 1/11 |
| 18.2% | 2/11 |
| 28.6% | 2/7 |
| 42.9% | 3/7 |
| 57.1% | 4/7 |

- 15.4% 介于 1/6≈16.7% 和 1/7≈14.3%，可取 1/6.5。
- 18.5% 介于 1/5=20% 和 1/6≈16.7%，可取 1/5.5。
- 6.2% 接近 1/16=6.25%，可取 n=16。

任意增长率都可以先估 `n≈100/r`，再选择最近的整数或中间值。

### 首数法与尾数法

首数法适合比较型和选项差距较大的计算题。只要商的首位或前两位能唯一对应选项，就不继续算。尾数法适合加减、乘法和选项尾数不同的题，只算末位或末两位即可排除。

### 增长量的非常规计算

增长量公式：

```text
增长量 = 现期 × r / (1+r)
```

当 `r≈1/n` 时：

```text
增长量≈现期/(n+1)
下降量≈现期/(n-1)
```

当 `r≈m/n` 且 m 不等于 1 时，不要机械使用 n+1 法，而应使用：

```text
增长量≈现期 × m/(n+m)
```

例如：

- 67%≈2/3，增长量约为现期的 `2/5`。
- 43%≈3/7，增长量约为现期的 `3/10`。
- 37.5%=3/8，增长量约为现期的 `3/11`。
- 28.6%≈2/7，增长量约为现期的 `2/9`。

### 基期量化除为乘

```text
基期 = 现期/(1+r)
```

当 `r` 较小时，可用 `1/(1+r)≈1-r+r²`。当 `r≈1/n` 时：

```text
1/(1+1/n)=n/(n+1)
```

例如增长率约为 14.3%≈1/7，基期约为现期的 7/8；增长率约为 28.6%≈2/7，基期约为现期的 7/9。

### 凑整平衡法

乘除混合时，把一个数拆成容易计算的整百、整十或熟悉倍数：

```text
234 × 0.125 = (240-6) × 1/8 = 30-0.75 = 29.25
89 × 0.64 ≈ 90 × 0.63 = 56.7
```

凑整时要保持误差方向一致。若是在比较选项，应优先让估算值落在同一侧，而不是盲目四舍五入。

### 溶液法与分母凑整

比较接近 `A/B` 的分数时，可以同时对分子、分母做小幅调整，把分母凑成 100：

```text
69/97≈(69+3×0.7)/(97+3)=71.1/100=71.1%
```

这种方法适合选项按整数百分数给出、且原分数分母接近 100 的题。

### 插值法与反向代入

当选项本身是百分数或比例时，可以反向把选项代入原公式，判断哪一个最接近，而不必先算出完整结果。尤其适合基期量、两期比重差、混合增长率和增长量比较。若两个相邻选项分别对应偏大和偏小，可以先判断答案落在二者之间，再用一次插值定位。

### 差分法

比较 `A/B` 和 `C/D`，且 `B>D`、`A>C` 时：

```text
A/B > C/D  等价于  (A-C)/(B-D) > C/D
```

也就是把两个分数的差分数与较小分数比较。使用前要确认分子、分母差值方向，不能机械套公式。

## 面试应对

### 常考点及考法

- 题目给出 6.2%、15.4%、28.6%、43%、67% 等非整齐增长率。
- 给出比重接近 14%、15%、17% 的整体或部分量。
- 选项差距很小，要求在估算和精算之间切换。
- 给出两个接近分数，考差分、插值或反向代入。

### 解法/回答思路

先判断题型，再把百分数化成最接近的 m/n。m=1 用 n+1 法，m>1 用 `现期×m/(n+m)`；基期题把 `1/(1+r)` 改写成分数或二阶近似；分数比较用差分，分母接近整百用凑整平衡。最后必须用选项检查误差。

### 易错点

- 看到非标准百分数就放弃百化分。
- 把 r≈m/n 错套成现期/(n+1)。
- 增长量和基期量的分母方向混淆。
- 差分法不检查分子、分母差值方向。
- 凑整后没有判断误差是否会跨过选项。

### 回答模板

资料分析速算的重点不是背几个简单百分数，而是把增长率转成最接近的分数。1/6、1/7、1/9、1/11 等用于非常见增长率和比重；一般的 m/n 用 `现期×m/(n+m)` 估算增长量；基期量用 n/(n+1) 或 `1-r+r²` 改写；分数比较用差分，分母接近整百用凑整平衡。任何估算都要回到选项差距验证。

## 真题案例

### 案例一：14% 比重求整体

2016 年全国公园绿地面积为 89591 公顷，占全国公园绿地面积比重约 14%，问全国公园绿地面积约为多少万公顷？

解法：14%≈1/7，整体约为 `89591×7≈62.7 万公顷`，选项通常选约 64 万公顷。

来源：[2018 年国考资料分析第 127 题公开解析](https://m.jl.huatu.com/2021/0624/1721609.html)。

### 案例二：9.6% 增长量

2017 年上半年人均财产净收入 1056 元，同比增长 9.6%，问比上年增加多少元？

解法：9.6% 介于 1/11≈9.1% 和 1/10=10% 之间，可取 n≈10.5，增长量约为 `1056/(10.5+1)≈92` 元。

来源：[2018 年联考 B 类资料分析第 108 题公开解析](https://m.jl.huatu.com/2021/0624/1721609.html)。
