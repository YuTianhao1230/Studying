# 增长类题型

## 知识点解析

### 概述

增长类题型是资料分析的半壁江山，围绕现期量、基期量、增长量、增长率、年均增长、间隔增长和增长量比较展开。解题关键是先判断题干问的是“率”还是“量”，再确定已知条件是现期、基期还是增长率。增长题最常用的[速算技巧](<速算技巧.md>)是百化分和 `1/n` 法。

### 基础公式

| 问法 | 公式 |
| --- | --- |
| 增长率 | `r = (现期 - 基期) / 基期` |
| 增长量 | `现期 - 基期` |
| 已知基期和增长率求现期 | `现期 = 基期 x (1 + r)` |
| 已知现期和增长率求基期 | `基期 = 现期 / (1 + r)` |
| 已知现期和增长率求增长量 | `增长量 = 现期 x r / (1 + r)` |

### 1/n 法

当 `r 约等于 1/n`：

```text
增长量 约等于 现期 / (n + 1)
下降量 约等于 现期 / (n - 1)
```

例：增长率 14.3% 约等于 1/7，则增长量约等于现期除以 8。

### 增长量比较

精确公式：

```text
增长量 = 现期 x r / (1 + r)
```

当增长率不大时，可近似看：

```text
增长量 约等于 现期 x r
```

如果现期大且增长率也大，可以直接判断增长量更大；如果一项现期大但增长率小，另一项现期小但增长率大，需要用 `1/n` 法或精算比较。

### 年均增长

| 题型 | 公式 |
| --- | --- |
| 年均增长量 | `(现期 - 基期) / n` |
| 年均增长率 | `(现期 / 基期)^(1/n) - 1` |

`n` 是间隔年数。例如 2018 到 2021 是 3 年。问“年均增长最快”看年均增长率，问“年均增长最多”看年均增长量。

### 间隔增长率

连续两年增长率为 `r1`、`r2`，隔一年总增长率为：

```text
R = r1 + r2 + r1 x r2
```

若 `r1`、`r2` 很小，先用 `r1 + r2` 粗估，再根据选项判断是否补乘积项。

## 面试应对

### 常考点及考法

- 已知现期和增长率，求基期或增长量。
- 比较多个行业、地区的增长量大小。
- 求年均增长率或年均增长量。
- 用两年增速求间隔增长率。

### 解法/回答思路

先判断问的是增长率、增长量、基期还是年均。增长量题优先用 `1/n` 法；增长量比较先看“现期 x r”；间隔增长率记住 `r1 + r2 + r1r2`。

### 易错点

- 增长量比较只看增长率。
- 基期公式忘记除以 `1 + r`。
- 下降题仍按增长题套 `n + 1`。
- 年均增长的间隔年数数错。

### 回答模板

增长类题先分清问“率”还是“量”。问增长率用增长量除以基期，问基期用现期除以 `1+r`，问增长量用 `现期 x r/(1+r)`，若增长率接近 `1/n` 就用现期除以 `n+1` 秒算。比较增长量时不能只看增长率，要看现期和增长率共同作用。
