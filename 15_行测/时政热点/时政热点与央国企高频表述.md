# 时政热点与央国企高频表述

## 知识点解析

### 概述

时政热点主要考查重大会议、重要政策、年度经济部署、科技成就、央国企改革、核心价值观、双碳目标和国家安全等内容。与常识判断不同，时政具有明显时效性，需要在考前集中刷新。央国企笔试尤其偏好政策原文、固定提法、重大科技“首次/最高/最新”表述和企业文化相关内容。

### 时效口径

本卡片中的年度政策、科技成就和央企指标以 2026 年中前后的备考口径为基准。实际考试前应再核对最新会议、公报、政策文件和目标公司新闻。

### 二十大与三中全会

进一步全面深化改革的总目标：

```text
继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
```

关键时间：

- 锚定 2035 年基本实现社会主义现代化。
- 到 2029 年，即中华人民共和国成立 80 周年时，完成本决定提出的改革任务。

三中全会“六个坚持”：

| 序号 | 内容 |
| --- | --- |
| 1 | 坚持党的全面领导 |
| 2 | 坚持以人民为中心 |
| 3 | 坚持守正创新 |
| 4 | 坚持以制度建设为主线 |
| 5 | 坚持全面依法治国 |
| 6 | 坚持系统观念 |

三中全会“七个聚焦”：

- 聚焦构建高水平社会主义市场经济体制。
- 聚焦发展全过程人民民主。
- 聚焦建设社会主义文化强国。
- 聚焦提高人民生活品质。
- 聚焦建设美丽中国。
- 聚焦建设更高水平平安中国。
- 聚焦提高党的领导水平和长期执政能力。

### 新质生产力与高质量发展

新质生产力的内涵：

- 创新起主导作用。
- 摆脱传统经济增长方式和生产力发展路径。
- 具有高科技、高效能、高质量特征。
- 以全要素生产率大幅提升为核心标志。
- 特点是创新，关键在质优，本质是先进生产力。

新发展理念：

```text
创新、协调、绿色、开放、共享。
```

其中创新发展居首，是第一动力。高质量发展是全面建设社会主义现代化国家的首要任务；实体经济是坚实支撑，数字经济是重要驱动。

高频原文表述：

- 因地制宜发展新质生产力。
- 健全因地制宜发展新质生产力体制机制。
- 加快形成同新质生产力相适应的生产关系。

### “十五五”开局与中央经济工作会议

2026 年是“十五五”规划开局之年，也是深入推进科技强国建设的关键之年。

中央经济工作会议“五个必须统筹好”：

| 统筹关系 | 关键词 |
| --- | --- |
| 有效市场和有为政府 | 既放得活又管得住 |
| 总供给和总需求 | 畅通国民经济循环 |
| 培育新动能和更新旧动能 | 因地制宜发展新质生产力 |
| 做优增量和盘活存量 | 提高资源配置效率 |
| 提升质量和做大总量 | 夯实现代化物质基础 |

宏观政策表述：

- 实施更加积极的财政政策。
- 实施适度宽松的货币政策。
- 加力扩围实施“两新”政策。
- 推进“两重”建设。

### 中央一号文件与乡村振兴

2025 年中央一号文件为《关于进一步深化农村改革 扎实推进乡村全面振兴的意见》，是 21 世纪以来第 22 个、党的十八大以来第 13 个指导“三农”的中央一号文件。

两个重要目标：

- 确保国家粮食安全。
- 确保不发生规模性返贫致贫。

土地政策高频点：

```text
有序推进第二轮土地承包到期后再延长三十年试点。
```

### 金融五篇大文章

| 方向 | 重点 |
| --- | --- |
| 科技金融 | 投早、投小、投长期、投硬科技 |
| 绿色金融 | 坚持先立后破，统筹绿色发展与低碳转型 |
| 普惠金融 | 中小微、民营、乡村振兴、社会民生 |

### 重大科技成就

以下为截至 2026 年中前后常见的高频科技表述，考试前应核对最新口径。

| 领域 | 高频表述 |
| --- | --- |
| 深空 | 嫦娥六号实现世界首次月球背面采样返回，带回 1935.3 克样品；天问二号小行星探测；神舟二十三号 2026 年 5 月发射 |
| 深海深地 | “奋斗者”号常态化万米深潜；蛟龙号首次北极冰区下潜；我国首口超万米科学探索井完钻 |
| 量子 | “九章”系列光量子计算原型机、“祖冲之三号”超导量子计算，105 比特，多次打破量子优越性世界纪录 |
| 能源 | EAST “人造太阳”实现 1 亿摄氏度 1066 秒“亿度千秒”世界纪录；聚变主机关键设施命名“夸父”园区 |
| 信息与装备 | 6G 融合系统、盘古大模型 5.5、C919/C929 大飞机、运-20B“鲲鹏”等 |

### 央国企改革重点

总要求：

```text
推动国有资本和国有企业做强做优做大，增强核心功能、提升核心竞争力。
```

2026 央企目标：“两个确保、两个力争”：

- 确保增加值持续增长，力争与 GDP 增速匹配。
- 确保“一利五率”稳中向好，力争总体优化。

“一利五率”：

| 指标 | 内容 |
| --- | --- |
| 一利 | 利润总额 |
| 五率 | 营业收现率、净资产收益率、研发经费投入强度、全员劳动生产率、资产负债率 |

2025 年起国资委用“营业收现率”替换原“营业现金比率”，遇到旧资料时要知道是同一位置指标的口径变化。

“三个集中”：

- 向关系国家安全、国民经济命脉的重要行业和关键领域集中。
- 向公共服务等公益性领域集中。
- 向前瞻性战略性新兴产业集中。

“五个价值”：

- 增加值。
- 功能价值。
- 经济增加值。
- 战略性新兴产业收入和增加值占比。
- 品牌价值。

国企高频表述：

- 做强做优做大。
- 增强核心功能、提升核心竞争力。
- 因地制宜发展新质生产力。
- 两个毫不动摇。

### 核心价值观、双碳与国家安全

社会主义核心价值观：

| 层面 | 内容 |
| --- | --- |
| 国家 | 富强、民主、文明、和谐 |
| 社会 | 自由、平等、公正、法治 |
| 个人 | 爱国、敬业、诚信、友善 |

双碳目标：

```text
2030 年前碳达峰，2060 年前碳中和。
```

总体国家安全观：

```text
以人民安全为宗旨，以政治安全为根本，以经济安全为基础，
以军事科技文化社会安全为保障，以促进国际安全为依托。
```

### 央国企企业文化备考法

目标公司三看：

1. 官网“关于我们/企业文化/社会责任”页面。
2. 近期年报。
3. 重大新闻，包括重组、国家战略任务、获奖、重大项目。

必背四类：

- 企业文化与愿景使命。
- 党和国家重大会议。
- 行业知识，例如通信、能源、金融、交通等。
- 重大科技与经济政策热点。

## 面试应对

### 常考点及考法

- 填空或判断政策原文，如新质生产力、高质量发展、六个坚持。
- 选择题混淆会议目标、时间节点和政策表述。
- 科技成就题考“首次、世界首次、数量、时间、限定场景”。
- 央国企题考“一利五率”“三个集中”“两个确保、两个力争”。
- 企业文化题考目标公司的使命、愿景、价值观和近期重大事件。

### 解法/回答思路

1. 先识别题目是会议、政策、科技、国企改革还是企业文化。
2. 政策题优先匹配原文表述，不随意改词。
3. 科技题盯限定词：首次、背面、万米、亿度千秒、比特数。
4. 国企题背固定表述：做强做优做大、核心功能、核心竞争力、一利五率。
5. 考前 3 天集中刷新当年会议、科技成就和目标公司新闻。

### 易错点

- 把“月球背面采样返回”说成普通月球采样。
- 把“营业收现率”和旧口径“营业现金比率”混淆。
- 新质生产力只记“科技”，漏掉全要素生产率、质优和先进生产力。
- 双碳年份记反：2030 碳达峰，2060 碳中和。
- 三中全会总目标和时间节点记不准。
- 时政资料过期，没有考前刷新。

### 回答模板

时政题我先按主题分类：会议政策看原文表述，科技成就看限定词和数字，央国企改革看固定提法和指标体系。新质生产力要记住创新主导、高科技高效能高质量、全要素生产率提升；国企改革要记住做强做优做大、增强核心功能、提升核心竞争力；双碳是 2030 碳达峰、2060 碳中和。时政具有时效性，考前必须再刷新最新会议、政策和目标公司新闻。
