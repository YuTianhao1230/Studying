# 央国企时政高频技巧

## 知识点解析

### 概述

央国企时政题偏好政策原文、年度会议、国企改革指标、重大科技成就和目标企业文化。复习方法不是泛泛刷新闻，而是背固定表述、抓限定词、看目标公司官网和年报。题目常通过替换关键词、混淆年份、改动指标名称来设错。

### 四类必背

| 类型 | 内容 |
| --- | --- |
| 重大会议 | 二十大、三中全会、中央经济工作会议 |
| 经济政策 | 新质生产力、高质量发展、财政货币政策 |
| 国企改革 | 做强做优做大、一利五率、三个集中、五个价值 |
| 企业文化 | 目标公司使命、愿景、价值观、社会责任、重大新闻 |

### 原文表述优先

遇到政策题，优先背原文：

- 继续完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。
- 因地制宜发展新质生产力。
- 增强核心功能、提升核心竞争力。
- 推动国有资本和国有企业做强做优做大。

政策题选项如果把“核心功能”和“核心竞争力”换成看似相近但非原文的词，要提高警惕。

### 科技成就抓限定词

科技成就题常考：

- 首次。
- 世界首次。
- 月球背面。
- 万米深潜。
- 亿度千秒。
- 比特数。
- 发射时间。

不要只记事件名，要记事件的限定条件。

### 目标公司三看

1. 官网“关于我们/企业文化/社会责任”。
2. 最近一年年报或社会责任报告。
3. 近期重大新闻：重组、重大工程、国家战略任务、获奖。

## 面试应对

### 常考点及考法

- 政策原文挖空。
- 国企改革指标排序和名称。
- 科技成就限定词判断。
- 目标企业文化和近期新闻。

### 解法/回答思路

时政题先判断主题，再用原文表述匹配。科技成就题盯限定词，国企题盯指标名称，企业文化题考前看官网和年报。

### 易错点

- 用近义词替代政策原文。
- 只记科技事件，不记首次、时间、数量。
- 目标企业文化临考前不看。
- 时政资料不更新。

### 回答模板

央国企时政复习要抓原文和限定词。政策题背会议原文，新质生产力、做强做优做大、核心功能和核心竞争力这些表述不能随意改；科技成就题记首次、数量、时间和场景；企业文化题考前看目标公司官网、年报和重大新闻。
