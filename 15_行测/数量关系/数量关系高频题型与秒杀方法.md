# 数量关系高频题型与秒杀方法

## 知识点解析

### 概述

数量关系的复习目标不是全题型全覆盖，而是在有限时间内稳定拿下可识别的套路题。核心方法是代入排除、数字特性和赋值法；核心题型包括工程问题、行程问题、利润经济、排列组合概率、容斥原理、最值问题、几何问题、年龄日期、植树方阵、牛吃草、溶液和数列。考场策略是优先做 3-5 道能快速识别的题，其余不恋战。

### 三大秒杀法

| 方法 | 触发信号 | 做法 |
| --- | --- | --- |
| 代入排除 | 选项给具体数值 | 从中间值开始代回题干验证 |
| 数字特性 | 出现整数、倍数、余数、奇偶、整除 | 用末位、数字和、奇偶、倍数关系排除 |
| 赋值法 | 只给比例、效率、倍数，没有具体量 | 赋最小公倍数或特值，把比例变成整数 |

数量关系中，只要选项是具体数，优先考虑代入排除。很多题不需要列复杂方程。

### 数字特性

#### 整除规则

| 数 | 判断方法 |
| --- | --- |
| 2 | 末位为偶数 |
| 3 | 各位数字和能被 3 整除 |
| 4 | 末两位能被 4 整除 |
| 5 | 末位是 0 或 5 |
| 8 | 末三位能被 8 整除 |
| 9 | 各位数字和能被 9 整除 |

#### 奇偶与尾数

- 奇 + 偶 = 奇，偶 + 偶 = 偶，奇 + 奇 = 偶。
- 奇 x 奇 = 奇，只要有偶数相乘结果就是偶数。
- `a + b` 与 `a - b` 同奇偶。
- 乘方尾数有循环，2 的尾数 2、4、8、6 循环，5 恒为 5，6 恒为 6。

#### 倍数特性

若 `a = (m/n)b`，且 `m` 与 `n` 互质，则 `a` 是 `m` 的倍数，`b` 是 `n` 的倍数。比例题可用这个性质直接筛选选项。

### 工程问题

基本关系：

```text
工作总量 = 工作效率 x 工作时间
合作效率 = 各自效率之和
```

给完工时间时，常用赋值总量法。比如甲 6 天完工，乙 8 天完工，总量赋为 24，则甲效率 4，乙效率 3，合作时间为 `24 / (4 + 3)`。

给效率比时，常用赋效率法。比如甲乙效率比为 2:3，可设甲效率 2，乙效率 3，再根据时间或总量求解。

### 行程问题

| 类型 | 公式 |
| --- | --- |
| 基本行程 | `s = v x t` |
| 相遇 | `路程和 = (v1 + v2) x t` |
| 追及 | `路程差 = (v1 - v2) x t` |
| 流水行船 | 顺速 = 船速 + 水速，逆速 = 船速 - 水速 |
| 环形相遇 | 同地反向相遇 n 次，合走 n 圈 |
| 时钟问题 | 时针 0.5 度/分，分针 6 度/分，追及速度 5.5 度/分 |

行程题最重要的是判断“相遇”还是“追及”。相遇用速度和，追及用速度差。

### 利润与经济问题

| 概念 | 公式 |
| --- | --- |
| 利润 | `售价 - 进价` |
| 利润率 | `利润 / 进价` |
| 折扣价 | `原价 x 折扣` |
| 总价 | `单价 x 数量` |

分段计费题按区间逐段算再相加，不能把最高档费率套到全部数量。总价一定时，单价和数量反向变化。

### 排列组合与概率

基本原则：

- 分类用加法。
- 分步用乘法。
- 相邻问题用捆绑法。
- 不相邻问题用插空法。
- 正面情况复杂时，先求反面，再用 `1 - 对立概率`。

常见公式：

| 类型 | 公式 |
| --- | --- |
| 排列 | `A(n,m) = n! / (n-m)!` |
| 组合 | `C(n,m) = n! / [m!(n-m)!]` |
| 圆桌排列 | `n` 人圆桌为 `(n-1)!` |
| 平均分组 | 需要除以组数的阶乘去重 |
| 概率 | `满足条件数 / 总数` |

### 容斥原理

| 类型 | 公式 |
| --- | --- |
| 两集合 | `A + B - A交B = 总数 - 都不满足` |
| 三集合 | `A + B + C - 两两交 + 三者交 = 总数 - 都不满足` |
| 非标准三集合 | `A + B + C - 只满足两两 - 2 x 三者交 = 总数 - 都不满足` |

容斥题先画集合关系或列公式，不要凭感觉加减。

### 最值问题

和定最值：

- 求某量最大，则其余量尽量小。
- 求某量最小，则其余量尽量大。
- 涉及不同整数时，常用等差构造。

最不利原则：

```text
保证拿到 n 件 = 最坏情况下仍差一点 + 1
```

例如要保证拿到某颜色球，先把不满足条件的最大数量都取完，再加 1。

### 几何与其他高频题型

几何题重点背基础公式和常见勾股数：

- 长方形、圆、三角形、柱体的周长、面积、体积。
- 勾股数：3-4-5、5-12-13、8-15-17 及其倍数。
- 不规则图形用割补、相似、等积变形。

其他题型：

| 题型 | 核心规则 |
| --- | --- |
| 年龄 | 年龄差永远不变，代入验证最稳 |
| 日期星期 | 平年 365 天，闰年 366 天，星期加减 7 等价 |
| 植树 | 线型 +1，环型不加，楼间 -1 |
| 方阵 | 总人数 `N^2`，最外层 `(N - 1) x 4` |
| 牛吃草 | `y = (N - x) x T`，`y` 为原有量，`x` 为草长速度 |
| 溶液 | 浓度 = 溶质 / 溶液，混合用十字交叉 |
| 数列 | 先看等差、等比、做差、做商、平方立方 |
| 余数同余 | 余同取余，和同加和，差同减差 |

## 面试应对

### 常考点及考法

- 选项给具体数，考代入排除。
- 题干给比例、效率、时间，考赋值法。
- 出现整数、倍数、余数，考数字特性。
- 工程和行程题考基本公式和合作、相遇、追及。
- 排列组合考相邻、不相邻、分类分步、反面求解。
- 最值题考和定最值、最不利原则。

### 解法/回答思路

1. 先判断题是否值得做：熟悉题型做，不熟悉先跳。
2. 有具体选项先代入排除，从中间选项开始。
3. 只有比例没有实际量，用赋值法。
4. 看到整数和倍数，用数字特性先筛选。
5. 工程题赋总量，行程题分清相遇和追及。
6. 时间不够时只保留能 1-2 分钟解决的题。

### 易错点

- 数量关系想全做，导致高性价比模块时间不够。
- 工程题忘记合作效率相加。
- 行程题把相遇速度和写成速度差。
- 分段计费把最高费率套到全部。
- 排列组合没有区分排列和组合。
- 平均分组忘记除以组数阶乘去重。
- 最不利题忘记最后 `+1`。

### 回答模板

数量关系我不追求全做，而是先识别能快速拿分的题。选项是具体数就优先代入排除；只有比例没有具体量就赋值；出现整除、奇偶、倍数、余数就先用数字特性筛选；工程、行程、利润、容斥和最值题按固定公式走。考场上数量放后面，挑 3-5 道套路题稳定做对，其余统一蒙同一选项，不让它挤占资料、判断和言语时间。
