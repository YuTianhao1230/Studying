# 利润最值几何与杂题

## 知识点解析

### 概述

利润、最值、几何和杂题是数量关系中常见的中低难度得分点。利润题围绕进价、售价、利润率和折扣；最值题围绕极端构造和最不利原则；几何题围绕基础公式、勾股数和割补；杂题包括年龄、日期、植树、方阵、牛吃草、溶液和数列。掌握标准模型后，很多题可快速识别。

### 利润问题

| 概念 | 公式 |
| --- | --- |
| 利润 | `售价 - 进价` |
| 利润率 | `利润 / 进价` |
| 售价 | `进价 x (1 + 利润率)` |
| 折扣价 | `原价 x 折扣` |
| 总收入 | `单价 x 数量` |

分段计费题按每一段单独计算，再求和。

### 最值问题

和定最值：

- 求某项最大，让其他项尽量小。
- 求某项最小，让其他项尽量大。
- 若要求互不相同，按最小等差序列构造。

最不利原则：

```text
保证发生 = 最坏情况 + 1
```

### 几何问题

高频内容：

- 长方形、正方形、三角形、圆的周长面积。
- 长方体、正方体、圆柱的体积表面积。
- 勾股数：3-4-5、5-12-13、8-15-17。
- 相似三角形、割补、等积变形。

### 杂题模型

| 题型 | 核心规则 |
| --- | --- |
| 年龄 | 年龄差不变 |
| 日期星期 | 每 7 天星期相同，平年 365、闰年 366 |
| 植树 | 线型 +1，环型不加，楼间 -1 |
| 方阵 | 总人数 `N^2`，最外层 `(N-1)x4` |
| 牛吃草 | `原有草量 = (牛数 - 草长速度) x 时间` |
| 溶液 | 浓度 = 溶质 / 溶液，混合可用十字交叉 |
| 数列 | 等差、等比、做差、做商、平方立方 |

## 面试应对

### 常考点及考法

- 利润折扣和分段计费。
- 和定最值、最不利原则。
- 基础几何面积体积。
- 年龄差、星期周期、植树方阵、牛吃草。

### 解法/回答思路

利润题先列进价、售价和利润率；最值题先构造极端情况；几何题先看是否能套基础公式或割补；杂题先识别模型。

### 易错点

- 利润率分母用错，利润率通常除以进价。
- 最不利原则忘记加 1。
- 方阵最外层公式写错。
- 溶液混合把溶质和溶液混淆。

### 回答模板

利润、最值、几何和杂题要先识别模型。利润题围绕进价、售价、利润率；最值题用极端构造和最不利加一；几何题先套基础公式和勾股数；年龄、日期、植树、方阵、牛吃草、溶液等题都有固定模型，识别后按公式快速求解。
