# 排列组合概率与容斥

## 知识点解析

### 概述

排列组合、概率和容斥题本质都是计数问题。解题时先判断是分类还是分步，是有序还是无序，是正面直接算还是反面更简单。容斥题要先明确集合范围和交集关系，再按公式加减。

### 排列组合

| 情况 | 方法 |
| --- | --- |
| 分类讨论 | 加法 |
| 分步完成 | 乘法 |
| 与顺序有关 | 排列 |
| 与顺序无关 | 组合 |
| 相邻 | 捆绑法 |
| 不相邻 | 插空法 |
| 圆桌 | 固定一人，`(n-1)!` |
| 平均分组 | 除以组数阶乘去重 |

### 概率

```text
概率 = 满足条件数 / 总数
```

若正面情况复杂，优先算反面：

```text
目标概率 = 1 - 对立事件概率
```

### 容斥

两集合：

```text
A + B - A交B = 总数 - 都不满足
```

三集合：

```text
A + B + C - 两两交 + 三者交 = 总数 - 都不满足
```

非标准三集合：

```text
A + B + C - 只满足两两 - 2 x 三者交 = 总数 - 都不满足
```

## 面试应对

### 常考点及考法

- 相邻或不相邻排列。
- 平均分组去重。
- 概率正难则反。
- 两集合、三集合容斥。

### 解法/回答思路

先判断顺序是否重要，再判断分类还是分步。排列组合复杂时先看是否有相邻、不相邻或平均分组。概率题看反面是否更简单。容斥题先列集合公式。

### 易错点

- 把排列当组合。
- 平均分组忘记除以阶乘。
- 不相邻题没有插空。
- 三集合容斥交集加减号错。

### 回答模板

排列组合先看顺序是否重要，有序用排列，无序用组合；分类用加法，分步用乘法；相邻捆绑，不相邻插空。概率题用满足条件数除以总数，正面复杂就算反面。容斥题先列集合公式，再代入数量。
