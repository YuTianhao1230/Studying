# 工程与行程问题

## 知识点解析

### 概述

工程问题和行程问题是数量关系中最稳定的公式题。工程问题围绕工作总量、效率和时间，常用赋值总量法；行程问题围绕路程、速度和时间，关键是区分相遇、追及、流水行船和环形运动。两类题都适合优先拿分。

### 工程问题

基本公式：

```text
工作总量 = 工作效率 x 工作时间
合作效率 = 各效率之和
```

给完成时间时，总量赋各时间的最小公倍数。比如甲 6 天、乙 8 天完成，总量赋 24，甲效率 4，乙效率 3，合作时间为 `24 / 7`。

给效率比时，直接赋效率。比如甲乙效率比 2:3，可设甲效率 2、乙效率 3。

### 行程问题

| 类型 | 公式 |
| --- | --- |
| 基本 | `s = v x t` |
| 相遇 | `路程和 = (v1 + v2) x t` |
| 追及 | `路程差 = (v1 - v2) x t` |
| 流水行船 | 顺速 = 船速 + 水速，逆速 = 船速 - 水速 |
| 环形相遇 | 合走圈数 = 相遇次数 |
| 时钟 | 时针 0.5 度/分，分针 6 度/分，追及速度 5.5 度/分 |

### 判断相遇和追及

- 两者相向而行，距离被共同缩短，用速度和。
- 同向快追慢，距离被速度差缩短，用速度差。
- 环形同向追及用速度差，反向相遇用速度和。

## 面试应对

### 常考点及考法

- 多人合作完工，求合作时间。
- 工程中有人中途加入或退出。
- 两车相遇、追及、环形跑道。
- 顺水逆水求船速或水速。

### 解法/回答思路

工程题先赋总量或效率，再列效率关系。行程题先判断是相遇还是追及，再决定用速度和还是速度差。

### 易错点

- 合作效率没有相加。
- 相遇用成速度差，追及用成速度和。
- 流水题把顺速和逆速写反。
- 环形题没把相遇次数转成圈数。

### 回答模板

工程题我先看给的是时间还是效率比，给时间就把总量赋为最小公倍数，给效率比就赋效率；合作时效率相加。行程题先判断相遇还是追及，相遇用速度和，追及用速度差；流水题顺速加水速，逆速减水速。
