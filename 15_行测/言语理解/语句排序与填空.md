# 语句排序与填空

## 知识点解析

### 概述

语句排序和语句填空考查语段连贯性。核心不是逐句翻译，而是找首句、找捆绑、看指代、看关联词和看话题一致。排序题把散句拼成完整逻辑，填空题判断横线位置承担总领、承转还是总结功能。

### 排序题步骤

1. 定首句：背景句、下定义句、提出话题句优先。
2. 排除不能做首句的句子：指代词开头、转折词开头、结论词开头。
3. 找捆绑：指代词、关联词、同一话题、时间顺序。
4. 验尾句：总结、对策、结论常做尾句。

### 常见捆绑

| 捆绑类型 | 例子 |
| --- | --- |
| 指代捆绑 | 这、其、该、上述，前文必须有指代对象 |
| 关联词捆绑 | 不仅...而且、虽然...但是、因为...所以 |
| 话题捆绑 | 同一主体连续展开 |
| 时间捆绑 | 先后顺序、历史发展顺序 |
| 逻辑捆绑 | 提出问题 -> 分析原因 -> 解决问题 |

### 填空题位置

| 横线位置 | 作用 |
| --- | --- |
| 开头 | 引出话题、总领全文 |
| 中间 | 承上启下、解释说明、转折递进 |
| 结尾 | 总结观点、提出对策 |

填空选项必须与前后文话题一致、语气一致、逻辑一致。

## 面试应对

### 常考点及考法

- 语句排序考首句排除和句间捆绑。
- 语句填空考横线前后的承接关系。
- 选项设置指代不明、话题突变和逻辑断裂。

### 解法/回答思路

排序题先排除不能做首句的句子，再找指代和关联词捆绑，最后通读验证。填空题先看横线位置，再判断它要总领、承转还是总结。

### 易错点

- 让“这、其、该”等指代词做首句。
- 忽略“虽然...但是”等固定关联词搭配。
- 填空题只看横线后，不看横线前。
- 话题从一个主体跳到另一个主体。

### 回答模板

语句排序先定首句，再找捆绑。背景、下定义、提出话题适合做首句，指代词、转折词、结论词一般不做首句。语句填空要看横线位置，开头总领，中间承转，结尾总结或对策，同时保证话题和逻辑前后一致。
