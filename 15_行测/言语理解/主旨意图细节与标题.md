# 主旨意图细节与标题

## 知识点解析

### 概述

主旨概括、意图判断、细节理解、标题填入和词句理解是言语理解的标准题型。主旨题问文段核心观点，意图题问作者目的，细节题问选项是否符合原文，标题题要求短小覆盖主题，词句理解题要求回到上下文解释。标准方法是先判断题型，再用结构、主题词和选项排雷处理。

### 主旨概括

主旨题常见问法：

- 这段文字主要说明。
- 这段文字意在强调。
- 对这段文字概括最准确的是。

解法：

1. 找行文结构。
2. 找主题词。
3. 找作者观点句。
4. 排除例子、背景、局部内容。

### 意图判断

意图题比主旨题多一步“言外之意”。若文段指出问题、危害、缺陷，优先选对策；若文段只是提出观点或解释现象，则同主旨。

对策项必须针对问题，不能过度引申。

### 细节理解

细节题常见错误：

| 错误 | 表现 |
| --- | --- |
| 无中生有 | 原文没有提 |
| 偷换概念 | 主体、对象、范围变化 |
| 偷换程度 | 可能变必然，部分变全部 |
| 偷换时态 | 已然、未然、正在混淆 |
| 强加因果 | 把相关或先后说成因果 |

### 标题填入

标题要满足：

- 覆盖主题。
- 简洁凝练。
- 适合文体。
- 不夸大、不偏题。

新闻类抓导语核心，议论文同主旨，说明文抓说明对象，记叙文抓主题或情感。

### 词句理解

词句理解遵循就近原则。先看该词句前后是否有解释、转折、总结或例子，再确定含义。不能脱离语境按字面意思发挥。

## 面试应对

### 常考点及考法

- 主旨题考结构和主题词。
- 意图题考对策选择。
- 细节题考选项设错。
- 标题题考主题覆盖和文体适配。
- 词句理解题考上下文解释。

### 解法/回答思路

主旨题找核心观点，意图题看是否有问题对策，细节题逐词比对原文，标题题选短小且覆盖主题，词句理解回到上下文。

### 易错点

- 主旨题选择例子或背景。
- 意图题选择无中生有的对策。
- 细节题忽略程度词和时态词。
- 标题题选项太宽或太窄。

### 回答模板

言语的标准题型要分开处理：主旨题找文段核心观点，意图题看是否需要针对问题提出对策，细节题逐词比对原文排除偷换和无中生有，标题题要求短小准确覆盖主题，词句理解必须回到上下文解释。
