# 片段阅读

## 知识点解析

### 概述

片段阅读方法强调“找结构、定重点、比选项”。片段阅读不是逐字读懂全部材料，而是通过行文脉络、关联词和主题词判断作者重点。主旨题抓核心观点，意图题看是否需要对策，细节题回原文逐项比对。

### 行文脉络

| 结构 | 重点 |
| --- | --- |
| 总-分 | 总句 |
| 分-总 | 结论句 |
| 分-总-分 | 中间总句或首尾呼应 |
| 并列 | 全面概括 |
| 问题-危害-对策 | 对策 |
| 现象-原因-结论 | 原因或结论 |

### 关联词重点

| 关联词 | 重点位置 |
| --- | --- |
| 但、然而、其实、事实上 | 转折后 |
| 因此、所以、可见 | 结论 |
| 甚至、更、尤其 | 递进后 |
| 同时、此外、另一方面 | 并列各方面都要覆盖 |

### 主题词秒杀

文段反复出现或贯穿全文的核心对象就是主题词。正确选项通常必须包含主题词或同义替换；没有主题词的选项，大概率偏离文段。

### 意图判断

若文段提出问题、危害、不足，优先选针对性对策。若文段已经给出明确观点，没有可执行对策，则按主旨题处理。

## 面试应对

### 常考点及考法

- 主旨概括题考结构重点。
- 意图判断题考问题后的对策。
- 标题题考短小准确和主题覆盖。
- 选项设置局部概括、过度引申、无中生有。

### 解法/回答思路

先看首尾句和关联词，再圈主题词。主旨题选全面概括，意图题优先选针对性对策，选项对比时排除偏离主题、范围过大或过小的项。

### 易错点

- 并列结构只选其中一部分。
- 看到对策就选，但对策并不针对文段问题。
- 主题词被偷换。
- 把例子当主旨。

### 回答模板

片段阅读的核心是结构优先。做题时先看文段是总分、分总、并列还是问题对策，再用关联词定位重点，用主题词排除偏题选项。主旨题选全面准确的概括，意图题有问题就找针对性对策，没有合适对策就退回主旨。
