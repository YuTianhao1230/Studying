# 三视图截面拼合与方位

## 知识点解析

### 概述

三视图、截面、立体拼合和空间方位是空间推断中除折纸盒外的标准题型。三视图考投影，截面考平面切割后的形状，拼合考单位块组合和凹凸互补，方位题考观察者方向和相邻关系。这些题的标准方法是固定观察方向、抽象成二维投影或单位块关系，而不是完全依赖想象。

### 三视图

| 视图 | 观察方向 | 保留维度 |
| --- | --- | --- |
| 主视图 | 从前往后 | 宽和高 |
| 俯视图 | 从上往下 | 宽和深 |
| 左视图 | 从左往右 | 深和高 |

做法：

1. 固定观察方向。
2. 把该方向上能看到的外轮廓投影到平面。
3. 遮挡的内部结构不画。
4. 多个方块叠放时，俯视图只看平面位置，主视和左视看高度。

### 截面

常见立体截面：

| 立体 | 常见截面 |
| --- | --- |
| 立方体 | 三角形、四边形、五边形、六边形 |
| 圆柱 | 圆、矩形、椭圆 |
| 圆锥 | 圆、三角形、椭圆 |
| 球 | 圆 |

截面题先判断切割平面穿过哪些面、边、顶点，再判断截面边数和曲直。

### 立体拼合

拼合题步骤：

1. 数单位块总量是否一致。
2. 看外轮廓长宽高是否一致。
3. 看凹凸能否互补。
4. 判断零件是否允许旋转，通常不能镜像翻转。
5. 关注 L 块、T 块、阶梯块、长条块的方向。

### 空间方位

方位题先固定观察者方向。观察方向变化时，前后左右会随观察者变化，上下通常不变。判断相邻位置时，优先用六方向：上、下、左、右、前、后。

## 面试应对

### 常考点及考法

- 给立体图选三视图。
- 给三视图还原立体。
- 给切割方式判断截面。
- 给零件判断能否拼成立体。
- 给观察者方向判断左右前后。

### 解法/回答思路

三视图固定观察方向做投影；截面判断切割平面经过的面和边；拼合先数体积再看凹凸；方位题先固定观察者方向。

### 易错点

- 三视图把看不见的内部结构画出。
- 截面边数凭感觉判断。
- 拼合题忽略零件不能镜像。
- 方位题没有固定观察者方向。

### 回答模板

三视图、截面、拼合和方位题都要先固定空间规则。三视图看对应方向的投影，截面看切面穿过哪些面和边，拼合先数单位块再看凹凸互补，方位题先确定观察者方向再判断前后左右上下。
