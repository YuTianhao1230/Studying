# 银行特色知识

## 知识点解析

### 概述

六大行笔试常把通用知识与目标银行自身的历史、战略、企业文化、特色业务、重大新闻和金融服务结合起来。该部分不适合用一本通用教材替代，应在笔试前根据目标银行官网、招聘公告、年报和近期新闻建立专属速记表。

### 通用考点

- 成立时间、前身沿革和重要历史节点。
- 核心价值观、企业使命、愿景和发展战略。
- 总行所在地、业务范围和全球化布局。
- 特色产品、特色客群和重点服务领域。
- 普惠金融、绿色金融、数字金融、养老金融和乡村振兴业务。
- 近半年重大合作、科技成果、品牌排名和经营数据。

### 六大行方向

| 银行 | 重点关注 |
| --- | --- |
| 工商银行 | 综合金融、科技金融、数字化转型、企业文化和工行特色产品 |
| 建设银行 | 住房租赁、普惠金融、数字金融、金融科技和建行战略 |
| 中国银行 | 国际化、跨境金融、全球化布局、金融科技和中行发展战略 |
| 农业银行 | 三农金融、县域金融、乡村振兴、普惠金融和农业银行特色业务 |
| 交通银行 | 综合化经营、跨境金融、数字化转型和交行历史文化 |
| 邮储银行 | 普惠金融、涉农贷款、县域服务、数字邮储和“五化转型” |

### 信息来源优先级

1. 招聘公告和官方招聘网站。
2. 银行官网“关于本行”“企业文化”“新闻中心”。
3. 年报、社会责任报告和年度业绩发布。
4. 官方微信公众号和权威媒体报道。
5. 考生回忆和培训机构整理，仅作为补充。

### 复习方法

建立一页纸表格，字段包括：成立年份、使命愿景、核心价值观、战略目标、特色业务、重大新闻、数字和专有名词。不要把不同银行的口号和战略混在一起。

## 笔试应对

### 常考题型

- 企业文化和核心价值观匹配。
- 银行成立时间、发展历史和战略定位。
- 特色业务与目标客群匹配。
- 近期重大新闻、排名、合作和科技成果。

### 解题方法

先判断题目考的是历史、文化、业务还是新闻；专有名词优先与目标银行匹配；遇到数字和年份要注意统计口径和新闻发布时间。

### 易错点

- 把六大行的企业文化混记。
- 用过时的战略口号回答新题。
- 把集团、子公司、研究院的新闻归到错误主体。
- 把金融行业通用业务误认为某银行独有业务。
