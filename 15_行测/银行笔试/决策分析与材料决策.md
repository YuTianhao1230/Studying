# 决策分析与材料决策

## 知识点解析

### 概述

决策分析是部分银行，尤其是工商银行等笔试中出现的特色模块，常把金融业务场景、资源配置、收益计算、排队安排、路径选择和风险约束组合起来。它不是单纯的数量关系，而是要求先读懂材料，再在多个可行方案中比较目标函数。

### 决策题基本结构

一个完整决策题通常包含：

1. 决策对象：项目、客户、资源、岗位或路线。
2. 可选方案：不同组合、顺序或投入方式。
3. 约束条件：预算、容量、时间、人力、风险和配套要求。
4. 目标函数：收益最大、成本最小、时间最短或风险最低。

### 标准解题流程

1. 列出变量和单位。
2. 把材料中的自然语言转成等式、不等式或表格。
3. 先处理硬约束，排除不可行方案。
4. 再比较收益、成本、时间或风险。
5. 检查是否存在“短板”“配套”“整数”和“至少/至多”条件。

### 常见模型

| 模型 | 核心方法 |
| --- | --- |
| 配套生产 | 两种产出按套数匹配，短板决定总套数 |
| 预算分配 | 总预算约束下比较边际收益 |
| 排队安排 | 比较等待时间、处理时间和总完成时间 |
| 路径选择 | 比较路径长度、成本、风险或节点限制 |
| 投资收益 | 统一时间口径，比较净收益或收益率 |
| 资源调度 | 先满足硬约束，再优化剩余资源 |

### 方案比较

如果题目要求“最优”，不能只比较单项收益；必须确认所有方案满足同一约束。收益率、总收益和边际收益的排序可能不同，题干问什么就比较什么。

## 笔试应对

### 常考题型

- 金融业务场景中的收益与成本决策。
- 多部门资源分配。
- 项目排序和排队。
- 配套模块生产。
- 最短路径和最优方案。

### 解题方法

先做可行性筛选，再做目标函数比较。出现“至少/最多”时关注边界；出现“配套”时寻找短板；出现多种方案时用表格统一比较。

### 易错点

- 把可行方案和最优方案混为一谈。
- 忽略预算、容量和时间约束。
- 把收益率当成总收益。
- 配套生产中只最大化某一种产品。
- 没有统一金额、时间和数量单位。
