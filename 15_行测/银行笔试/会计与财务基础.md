# 会计与财务基础

## 知识点解析

### 概述

银行和央国企笔试中的会计财务通常考会计要素、会计等式、三大财务报表、收入费用、资产负债、存货与固定资产、财务指标和基础财务管理。题目大多是概念判断和简单计算，重点是区分“确认、计量、列报”和不同报表反映的内容。

### 会计基础

会计六要素：资产、负债、所有者权益、收入、费用、利润。

基本会计等式：

```text
资产 = 负债 + 所有者权益
利润 = 收入 - 费用
```

借贷记账法中，资产和费用增加通常记借方；负债、所有者权益和收入增加通常记贷方。

### 三大财务报表

| 报表 | 反映内容 |
| --- | --- |
| 资产负债表 | 某一时点的资产、负债和所有者权益 |
| 利润表 | 一定期间的收入、费用和利润 |
| 现金流量表 | 一定期间经营、投资和筹资活动的现金流量 |

### 常见会计概念

- 收入是日常活动形成的、会导致所有者权益增加且与投入资本无关的经济利益总流入。
- 费用是日常活动形成的、会导致所有者权益减少且与分配利润无关的经济利益总流出。
- 资产是企业过去交易或事项形成、由企业拥有或控制、预期带来经济利益的资源。
- 负债是过去交易形成、预期导致经济利益流出的现时义务。
- 固定资产折旧会减少账面价值和当期利润，但不等于当期现金流出。

### 财务指标

| 指标 | 公式或含义 |
| --- | --- |
| 流动比率 | 流动资产 / 流动负债 |
| 速动比率 | 速动资产 / 流动负债 |
| 资产负债率 | 负债总额 / 资产总额 |
| 毛利率 | 毛利 / 营业收入 |
| 净利率 | 净利润 / 营业收入 |
| 净资产收益率 | 净利润 / 平均净资产 |
| 存货周转率 | 营业成本 / 平均存货 |

### 财务管理

常考资金时间价值、成本收益、投资回收期、净现值、风险收益关系、资本结构和预算管理。简单题优先列现金流和时间点，不要把利润直接当成现金流。

## 笔试应对

### 常考题型

- 会计要素和会计等式。
- 三大报表的内容归属。
- 收入、费用、资产和负债的定义。
- 财务指标计算。
- 折旧、利润、现金流和投资决策。

### 解题方法

概念题先判断时间范围和对象；报表题看“时点/期间”；计算题先写公式再代数值；财务管理题区分利润、现金流和资金时间价值。

### 易错点

- 把资产负债表当成期间报表。
- 把收入等同于收到现金。
- 把费用等同于现金支出。
- 资产负债率、流动比率分子分母写反。
- 折旧减少利润却误判为当期现金流出。
