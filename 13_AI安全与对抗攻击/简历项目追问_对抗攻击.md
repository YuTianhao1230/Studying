# 简历项目追问：对抗攻击

## 知识点解析

### 概述

本文围绕简历中的通用多模态对抗攻击和通用视觉模态对抗攻击两段科研经历，整理项目介绍、技术追问、实验追问、创新性追问和可直接复述的回答模板。

### 简历相关项目

你的简历中与对抗攻击最相关的两段经历是：

1. 通用多模态对抗攻击方法研究：面向 VLM/MLLM 黑盒迁移攻击，围绕 CLIP、ALBEF、GPT、Qwen 等模型，设计图像侧特征扰动、图文对齐扰动和视觉引导文本攻击。
2. 通用视觉模态对抗攻击方法研究：以语义分割模型为源模型，通过多头判别器和源模型对抗博弈，学习可迁移到分类、检测、分割任务的单个通用扰动。

这两段经历的共同主线是“迁移性”。第一段强调跨模态、跨 VLM/MLLM；第二段强调跨视觉任务、跨视觉架构。

### 30 秒项目介绍

回答模板：

我主要做过两个对抗攻击相关项目。第一个是多模态对抗攻击，目标是在黑盒场景下提升对 VLM 和 MLLM 的迁移攻击能力。我围绕 CLIP、ALBEF 等模型的图文对齐机制，设计图像侧特征扰动和图文对齐扰动，并加入视觉引导文本攻击，让图像和文本扰动协同破坏多模态语义一致性。第二个是通用视觉扰动项目，用一个可迁移扰动同时影响分类、检测和分割任务，重点证明视觉模型存在跨任务共享的脆弱表征。

### 2 分钟项目介绍

回答模板：

我的对抗攻击研究可以分成两条线。第一条是多模态攻击，问题背景是 VLM 和 MLLM 依赖图文对齐完成检索、描述、VQA 等任务，但现有攻击在黑盒迁移到不同模型时效果不稳定。我做的方向是从跨模态对齐机制入手，在图像侧同时优化视觉特征破坏和图文对齐破坏，在文本侧使用视觉引导的词替换，使被替换的词更集中在影响图文匹配的关键语义上。评估时不仅看传统 VLP 的检索下降，也看 MLLM 上的 ASR，并补充 baseline 对齐、防御评估和消融实验。

第二条是通用视觉扰动，目标是学习一个可以跨图片、跨模型、跨任务使用的扰动。分类、检测、分割虽然输出不同，但底层视觉表征有共享部分，所以我参与的方法以语义分割模型为源模型，通过多头判别器和源模型对抗博弈，让扰动攻击更任务无关的视觉特征，最终迁移到分类、检测、分割以及 ViT 架构。两段项目共同体现的是：我不只关注白盒攻击成功，而是关注攻击是否能在更真实的黑盒、跨模型、跨任务场景下成立。

### 如何讲清 Syner-Attack 的方法

可以按四层讲：

1. 问题：多模态模型在黑盒跨模型场景下仍可能被扰动图像和文本误导。
2. 机制：VLM/MLLM 依赖视觉表征和图文对齐，攻击应作用在跨模态对齐空间。
3. 方法：图像侧优化 feature loss 与 alignment loss，文本侧做 visual-guided word replacement，联合破坏图文一致性。
4. 证据：用跨模型、跨任务、MLLM、消融、防御和计算开销证明有效性与边界。

### 如何回应“这是不是已有方法拼接”

回答时不要直接否认已有方法的影响，应承认基础组件来自成熟攻击范式，然后说明你的贡献在问题定义、组织方式和证据链。

回答模板：

这个问题我会分层看。底层优化确实会用到已有的梯度攻击、输入变换或文本替换技术，这些是对抗攻击领域的基础工具。我的工作重点不是把每个底层算子都包装成全新方法，而是针对 VLM/MLLM 的跨模态对齐脆弱性，把图像特征扰动、图文对齐扰动和视觉引导文本攻击组织成一个协同框架。为了证明它不是简单拼接，我会通过去掉 alignment loss、去掉 VGA、只攻击图像、只攻击文本、联合攻击等消融来验证每个组件是否带来独立贡献，并用跨模型和 MLLM 迁移结果说明它确实改善了目标问题。

### 如何讲实验设计

回答模板：

我会从公平性和可信度两方面设计实验。公平性上，对所有方法使用相同数据集、相同源模型和目标模型、相同扰动预算、相同迭代步数或尽量可比的查询成本，并说明 baseline 的实现来源。可信度上，不只报平均 ASR，还会报告 clean 性能、样本量、不同任务指标、不同目标模型结果和防御下结果。对于 MLLM 这种开放输出任务，我会固定 prompt 和 decoding 配置，用一致的判定规则或人工复核判断攻击后输出是否与原始语义不一致。

### 如何讲防御和局限

回答模板：

我会把防御分成低成本输入预处理、模型级鲁棒训练和检测类方法。输入预处理如 JPEG、blur、noise、resize padding 可以验证扰动是否过度依赖高频噪声，但不能代表强防御；对抗训练证据更强，但训练成本高，且对大规模多模态模型不一定现实；跨模态一致性检测适合多模态攻击场景，但需要控制误报。项目局限上，我会承认不同商业 MLLM 的安全策略、视觉编码器和 prompt 敏感性不同，攻击结果不能无限外推，所以需要更多模型、更多任务和更清晰的威胁模型来支撑结论。

### 如何讲“单扰动跨任务通用攻击”

回答模板：

单扰动跨任务攻击的核心是学习一个对多张图片和多个任务都有效的通用扰动，而不是为每个样本单独优化。它成立的原因是分类、检测和分割虽然任务头不同，但底层视觉 backbone 会共享边缘、纹理、局部结构和语义特征。方法上可以用一个源任务或源模型提供训练信号，再通过多头判别器或对抗博弈让扰动不只适配单一任务头，而是攻击更通用的视觉表征。评估时必须在未见过的数据、不同架构和不同任务指标上验证，比如分类 accuracy drop、检测 mAP drop 和分割 mIoU drop。

## 面试应对

### 面试官问：你这个项目最核心的技术难点是什么？

回答思路：不要泛泛说“攻击模型”，要讲迁移性和语义保持。

回答模板：

我认为核心难点有两个。第一个是迁移性，白盒攻击在源模型上成功不难，但要迁移到不同架构、不同任务甚至商业 MLLM，就必须避免扰动过拟合源模型局部梯度。第二个是语义保持，尤其是多模态场景下，图像扰动不能明显改变视觉内容，文本扰动也不能破坏原始语义。我的方法围绕跨模态对齐空间做优化，并用视觉相关性指导文本替换，本质上是在尽量保持输入语义的前提下破坏模型内部的图文绑定关系。

### 面试官问：你的方法为什么能迁移到 GPT、Qwen 这类商业模型？

回答思路：不能说知道商业模型内部，只能讲共享机制和实验观察。

回答模板：

我们并不知道商业模型的内部结构和参数，所以这里不是白盒攻击，而是迁移攻击。它能够迁移的原因主要是现代 MLLM 普遍依赖视觉编码器和语言模型之间的跨模态对齐，很多模型在视觉语义、图文匹配和指令理解上存在共享脆弱性。我们在开源 VLM 上优化的扰动如果能稳定破坏这些共享表征，就可能迁移到商业模型。当然这不是理论保证，所以实验上需要用固定 prompt、足够样本量、统一 ASR 判定和多个目标模型来验证，而不能只靠个别 case。

### 面试官问：如果让你继续改进这个方向，你会做什么？

回答思路：从方法、评估、防御三个方向回答。

回答模板：

我会从三方面继续改。方法上，会进一步减少对单一源模型的依赖，引入多源模型集成、低频约束或更强的语义保持目标，提升黑盒迁移稳定性。评估上，会扩展到更多 MLLM、更多任务和更清晰的 ASR 判定协议，并补充统计显著性和失败案例分析。防御上，会评估输入预处理、跨模态一致性检测和对抗训练等方法，分析攻击在哪些场景下失效，从而把结论从“方法有效”推进到“风险边界清楚”。
