# Gradient Masking

## 知识点解析

### 概述

Gradient Masking 是防御评估中的常见陷阱，指模型或防御机制让梯度变得不可用、不稳定或误导攻击，使梯度攻击看似失败，但真实决策边界并没有变鲁棒。

### 解决的问题

理解 Gradient Masking 是为了避免把“攻击没优化好”误判成“模型真的鲁棒”。很多防御方法表面上降低 PGD ASR，但换成更强攻击、黑盒迁移或自适应攻击后会失效。

### 常见表现

- 白盒攻击弱于黑盒迁移攻击。
- 增大攻击步数，攻击成功率不上升。
- 增大扰动预算，攻击成功率不上升。
- 随机防御导致梯度噪声大，但 EOT 后被打穿。
- 非可导预处理让普通反传失效，但 BPDA 后失效。

### 典型原因

| 原因 | 说明 | 绕过方式 |
| --- | --- | --- |
| 非可导操作 | JPEG、量化、round | BPDA |
| 随机化防御 | random resize、noise | EOT |
| 饱和激活 | 梯度接近 0 | 换 loss、换优化 |
| 破碎梯度 | 梯度方向不稳定 | 黑盒攻击、迁移攻击 |

### 如何检查

1. 比较白盒攻击和黑盒攻击强度。
2. 增加 PGD steps 和 restarts。
3. 增大 `epsilon`，观察 ASR 是否合理上升。
4. 使用 BPDA/EOT 处理不可导或随机防御。
5. 使用无梯度攻击或迁移攻击交叉验证。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 概念题 | 什么是 gradient masking | 梯度攻击失败但真实边界不鲁棒 |
| 判断题 | 防御 PGD 打不穿是否可信 | 看黑盒、步数、预算、BPDA/EOT |
| 方法题 | 随机防御怎么攻 | EOT |
| 方法题 | 非可导防御怎么攻 | BPDA |

### 易错点

- 看到 PGD ASR 低就认为防御强。
- 不做 restarts，低估攻击强度。
- 不测黑盒迁移。
- 随机防御不做 EOT。

## 面试应对

### 什么是 Gradient Masking？

回答思路：区分“梯度攻击失败”和“真实鲁棒”。

回答模板：

Gradient Masking 是指防御让梯度变得不可用、不稳定或不准确，使基于梯度的攻击看起来失败，但模型的真实决策边界并没有变得鲁棒。典型现象是白盒攻击反而弱于黑盒攻击，或者增加攻击步数和扰动预算后 ASR 不上升。排查时需要用更强 PGD、多 restart、黑盒迁移、BPDA、EOT 或无梯度攻击验证，不能只看普通 PGD 打不穿就说防御有效。
