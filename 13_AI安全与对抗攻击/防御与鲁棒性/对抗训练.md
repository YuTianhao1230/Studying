# 对抗训练

## 知识点解析

### 概述

对抗训练是在训练过程中加入对抗样本，使模型在扰动邻域内也保持正确预测，是经典且证据较强的鲁棒训练方法。

### 解决的问题

标准训练只优化 clean 样本上的平均损失，不保证样本附近小扰动下预测稳定。对抗训练把最坏扰动纳入训练目标，提升局部鲁棒性。

### Min-Max 目标

```text
min_theta E_{(x,y)} [ max_{||delta|| <= epsilon} L(f_theta(x + delta), y) ]
```

- 内层 `max`：用 FGSM/PGD 等方法找最坏扰动。
- 外层 `min`：更新模型参数，让模型在最坏扰动下仍正确。

### 训练流程

1. 对 batch 中每个样本生成对抗样本。
2. 用对抗样本计算训练 loss。
3. 反向传播更新模型参数。
4. 每轮评估 clean accuracy 和 robust accuracy。

PGD adversarial training 常用 PGD 近似内层最大化。

### 优点和代价

| 维度 | 说明 |
| --- | --- |
| 优点 | 证据强，能显著提升对应预算下鲁棒性 |
| 成本 | 每个 batch 多次 forward/backward，训练成本高 |
| clean 性能 | 可能降低 clean accuracy |
| 泛化 | 对未训练过的范数、预算、攻击类型泛化有限 |
| 大模型/多模态 | 全量对抗训练成本更高，数据和评估更复杂 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | 写对抗训练目标 | min-max 目标 |
| 流程题 | PGD adversarial training 怎么做 | 内层 PGD，外层更新模型 |
| 代价题 | 为什么难用于大模型 | 训练成本、显存、任务复杂度 |
| 局限题 | 为什么不是万能防御 | 预算和攻击类型外泛化有限 |

### 易错点

- 把对抗训练说成数据增强；它是显式最坏扰动优化。
- 只报 robust accuracy，不报 clean accuracy。
- 用弱攻击训练，却用弱攻击评估，得到虚假鲁棒性。
- 忽略训练预算和评估预算是否一致。

## 面试应对

### 对抗训练是什么？

回答思路：用 min-max 目标解释。

回答模板：

对抗训练是在训练时把对抗样本加入优化目标，让模型不仅在 clean 样本上正确，也在扰动预算内的最坏样本上正确。形式上是一个 min-max 问题：内层用 PGD 等攻击方法寻找使损失最大的扰动，外层更新模型参数最小化这个最坏情况下的损失。它是经典鲁棒训练方法，但代价是训练成本高，可能降低 clean accuracy，并且对没覆盖过的攻击范数或预算泛化有限。
