### 方法关系

```text
VLM/MLLM attack
  -> image branch: visual feature / CLIP alignment attack
  -> text branch: semantic-preserving word replacement
  -> alignment branch: image-text matching disruption
  -> evaluation: retrieval / VQA / caption / MLLM ASR
```

## 面试应对

### 怎么系统介绍多模态对抗攻击？

回答思路：从攻击对象、攻击分支和评估方式回答。

回答模板：

多模态对抗攻击和普通图像攻击不同，它攻击的不只是视觉分类输出，还包括图像、文本和跨模态对齐关系。图像侧可以扰乱视觉特征或 CLIP 对齐空间，文本侧可以在语义保持约束下替换关键 token，联合攻击则同时破坏图像表征、文本语义和图文匹配。评估时要按任务定义 ASR，比如图文检索看 Recall@K，VQA 看答案正确性，caption 和 MLLM 输出要看关键对象、属性和关系是否被误导。
