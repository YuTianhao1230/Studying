### 关系框架

```text
defense evaluation
  -> robust training: adversarial training
  -> input-level defense: JPEG / blur / resize / denoise
  -> detection defense: feature / uncertainty / cross-modal consistency
  -> reliability check: adaptive attack / BPDA / EOT / gradient masking
```

## 面试应对

### 怎么系统介绍对抗防御评估？

回答思路：按防御类型和可信评估回答。

回答模板：

对抗防御可以分成三类：第一是对抗训练，用 min-max 目标让模型在扰动邻域内也正确；第二是输入预处理，如 JPEG、模糊、降 bit-depth，用低成本方式削弱扰动；第三是检测与一致性防御，判断输入、特征或图文关系是否异常。评估时不能只看普通 PGD 是否打穿，还要报告 clean 性能、多攻击多预算结果、黑盒迁移和 adaptive attack，并排查 gradient masking。
