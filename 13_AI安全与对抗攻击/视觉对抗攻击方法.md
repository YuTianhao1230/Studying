# 视觉对抗攻击方法

## 知识点解析

### 概述

本文作为视觉对抗攻击方法总览，整理 [FGSM](<视觉攻击方法/FGSM.md>)、I-FGSM/BIM、[PGD](<视觉攻击方法/PGD.md>)、[MI-FGSM](<视觉攻击方法/MI-FGSM.md>)、DIM/TIM 和 [CW 攻击](<视觉攻击方法/CW攻击.md>)的关系，并提供单独知识卡片入口。

### 方法关系

```text
FGSM
  -> I-FGSM/BIM: 单步变多步
  -> PGD: 多步 + 随机初始化 + 投影
  -> MI-FGSM: 多步 + 动量，偏迁移
  -> DIM/TIM: 输入变换/梯度平滑，偏迁移
  -> CW: 改为连续优化小扰动和攻击目标
```

### 横向对比

| 方法 | 更新方式 | 主要优势 | 主要局限 |
| --- | --- | --- | --- |
| FGSM | 单步梯度符号 | 快、公式清楚 | 攻击较弱 |
| I-FGSM/BIM | 多步梯度符号 | 白盒更强 | 可能过拟合源模型 |
| PGD | 随机初始化 + 多步投影 | 强白盒基线 | 成本更高 |
| MI-FGSM | 动量累积梯度 | 迁移性更好 | 仍依赖源模型 |
| DIM/TIM | 输入变换 / 梯度平滑 | 降低固定预处理和空间位置过拟合 | 需要调随机策略和卷积核 |
| CW | 优化扰动 + margin loss | 扰动小、攻击强 | 计算成本高 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | FGSM/PGD 更新公式 | 先写 loss，再写梯度、步长、投影和裁剪 |
| 对比题 | PGD 和 MI-FGSM 区别 | PGD 偏强白盒，MI-FGSM 偏迁移 |
| 迁移题 | DIM/TIM 为什么有效 | 减少固定输入形态和空间位置过拟合 |
| 防御题 | PGD 打不穿是否鲁棒 | 还要检查 adaptive attack 和 gradient masking |

## 面试应对

### 怎么系统介绍视觉对抗攻击方法？

回答思路：按单步、多步、迁移增强和优化型攻击组织。

回答模板：

视觉对抗攻击可以按优化方式分层。FGSM 是单步梯度符号攻击，用一阶泰勒展开得到 `epsilon * sign(gradient)`；I-FGSM/BIM 把单步变成多步迭代；PGD 在多步基础上加入随机初始化和投影，常作为强白盒基线；MI-FGSM 加入动量，DIM/TIM 加入输入多样性和平移不变梯度，主要提升黑盒迁移性；CW 则把攻击成功和扰动大小写成连续优化目标，用 logit margin 生成小扰动强攻击。
