# CW 攻击

## 知识点解析

### 概述

CW 攻击是一类基于连续优化的强白盒攻击方法，通过同时优化扰动大小和攻击成功目标，生成扰动较小但攻击能力强的对抗样本。

### 解决的问题

FGSM/PGD 通常固定扰动预算并最大化损失。CW 攻击换了思路：把“扰动尽量小”和“模型输出目标错误”写进同一个优化目标中，直接寻找小扰动成功攻击。

### 优化目标

以 `L_2` CW 攻击为例：

```text
minimize ||delta||_2^2 + c * f(x + delta)
subject to x + delta in [0, 1]
```

其中 `f` 是攻击损失。定向攻击常用 logit margin：

```text
f(x_adv) = max(max_{i != t} Z_i(x_adv) - Z_t(x_adv), -kappa)
```

- `Z_i`：第 `i` 类 logit。
- `t`：目标类别。
- `kappa`：confidence，控制攻击置信度。
- `c`：扰动大小和攻击成功之间的权衡系数。

### 变量变换

为了保证像素范围合法，CW 常用 `tanh` 变换，把无约束变量 `w` 映射到 `[0,1]`：

```text
x_adv = 1/2 * (tanh(w) + 1)
```

这样优化器可以直接优化 `w`，不用每一步手动 clip 像素。

### 攻击流程

1. 选择攻击范数，常见是 `L_2`。
2. 设置目标类别、confidence `kappa` 和权衡系数 `c`。
3. 用 Adam 等优化器优化变量 `w`。
4. 同时降低扰动大小并满足 logit margin 攻击条件。
5. 通过 binary search 调整 `c`，找到较小扰动下的成功攻击。

### 和 PGD 的区别

| 对比项 | [PGD](<PGD.md>) | CW |
| --- | --- | --- |
| 思路 | 固定预算内最大化损失 | 同时优化扰动大小和攻击目标 |
| 损失 | 通常 cross entropy | logit margin loss |
| 约束 | 每步投影 | 常用 `tanh` 变量变换 |
| 成本 | 中等 | 较高 |
| 常见用途 | 鲁棒评估、[对抗训练](<../防御与鲁棒性/对抗训练.md>) | 强白盒攻击、小扰动攻击 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | CW 优化目标是什么 | `||delta|| + c * attack_loss` |
| 机制题 | 为什么不用 cross entropy | logit margin 更直接控制目标类别超过其他类别 |
| 约束题 | 如何保证像素合法 | 用 `tanh` 变量变换或显式裁剪 |
| 对比题 | CW 和 PGD 区别 | 固定预算攻击 vs 小扰动优化攻击 |

### 易错点

- 只写 `||delta||`，不写攻击成功损失。
- 把 `c` 当学习率；它是扰动和攻击目标的权衡。
- 忽略 `kappa`，说不清 confidence 的作用。
- 认为 CW 一定适合大规模迁移实验；它通常成本较高。

## 面试应对

### CW 攻击的核心思想是什么？

回答思路：突出优化目标和 margin loss。

回答模板：

CW 攻击的核心是把对抗攻击写成连续优化问题，不是只在固定预算内最大化交叉熵，而是同时最小化扰动大小和满足攻击成功条件。以 `L_2` 版本为例，它优化 `||delta||_2^2 + c * f(x+delta)`，其中 `f` 通常是基于 logits 的 margin loss，要求目标类别 logit 超过其他类别。为了保证像素合法，CW 常用 `tanh` 变量变换。它攻击强、扰动小，但计算成本比较高。
