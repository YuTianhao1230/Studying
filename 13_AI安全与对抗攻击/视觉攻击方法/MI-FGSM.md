# MI-FGSM

## 知识点解析

### 概述

MI-FGSM 是在迭代梯度攻击中加入动量的迁移攻击方法，通过累积历史梯度方向减少局部震荡和源模型过拟合，常用于提升[黑盒迁移攻击](<../迁移与通用攻击/黑盒迁移攻击.md>)成功率。

### 解决的问题

普通 I-FGSM 白盒攻击强，但容易过拟合源模型的局部决策边界，导致迁移到目标模型时效果下降。MI-FGSM 引入动量，希望保留跨迭代稳定一致的方向，使扰动更接近多模型共享脆弱方向。

### 攻击公式

梯度归一化：

```text
g_raw = grad_x L(f(x_adv_t), y)
g_norm = g_raw / ||g_raw||_1
```

动量更新：

```text
g_{t+1} = mu * g_t + g_norm
```

样本更新：

```text
x_adv_{t+1} = clip_{x, epsilon}(x_adv_t + alpha * sign(g_{t+1}))
```

其中 `mu` 是动量衰减系数，常见取值接近 1。

### 完整流程

1. 初始化 `x_adv = x`，`g = 0`。
2. 对当前对抗样本求输入梯度。
3. 用 `L1` 范数归一化梯度，避免梯度尺度影响动量。
4. 累积动量。
5. 用动量符号方向更新样本。
6. 投影回扰动预算并裁剪像素范围。

### 为什么动量提升迁移性

迁移攻击希望找到不同模型共享的脆弱方向。单步梯度可能包含源模型局部噪声，多步 I-FGSM 又可能沿源模型特有边界过拟合。动量通过累积多个 step 的梯度：

- 强化持续一致的方向。
- 抑制单步噪声梯度。
- 让优化轨迹更稳定。
- 降低对源模型局部曲率的敏感性。

因此 MI-FGSM 往往比 I-FGSM 有更好的黑盒迁移性。

### 和 PGD 的区别

| 对比项 | [PGD](<PGD.md>) | MI-FGSM |
| --- | --- | --- |
| 核心目的 | 强白盒攻击/鲁棒评估 | 提升迁移性 |
| 起点 | 常随机初始化 | 通常从原图开始 |
| 更新方向 | 当前梯度符号 | 历史动量梯度符号 |
| 关注点 | 找局部最坏扰动 | 找稳定共享方向 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | MI-FGSM 更新公式 | 写归一化梯度、动量累积、符号更新 |
| 原因题 | 为什么提升迁移 | 稳定方向，减少源模型局部过拟合 |
| 对比题 | MI-FGSM 和 PGD 区别 | 一个偏迁移，一个偏强白盒 |
| 项目题 | 为什么多模态攻击会用动量 | 提升跨模型、跨任务迁移稳定性 |

### 易错点

- 只说“加速收敛”，没有讲迁移性。
- 忘记梯度归一化，动量被梯度尺度主导。
- 把动量系数 `mu` 和学习率 `alpha` 混淆。
- 认为 MI-FGSM 一定比 PGD 白盒更强；它更关注迁移。

## 面试应对

### MI-FGSM 为什么能提升黑盒迁移性？

回答思路：围绕源模型过拟合和稳定共享方向回答。

回答模板：

MI-FGSM 在迭代攻击中加入动量，不只使用当前 step 的梯度，而是累积历史梯度方向。普通 I-FGSM 容易过拟合源模型的局部边界，白盒很强但迁移可能下降；动量会强化多步中持续一致的方向，抑制局部噪声梯度，使扰动更可能落在不同模型共享的脆弱方向上。因此 MI-FGSM 常用于黑盒迁移攻击，而不仅是追求源模型上的攻击成功率。
