# 通用扰动

## 知识点解析

### 概述

通用扰动是对一批样本都有效的共享扰动，它不为每个样本单独优化，而是学习一个可跨样本、跨模型甚至跨任务使用的扰动模式。

### 解决的问题

普通对抗样本通常每个输入对应一个扰动，攻击成本高且不容易批量部署。通用扰动解决的是：能否预先学习一个扰动 `delta`，让许多不同样本都被误导。

### 基本形式

```text
find delta
subject to ||delta||_p <= epsilon
for many x_i: f(x_i + delta) != f(x_i)
```

训练目标可以写成：

```text
maximize sum_i L(f(x_i + delta), y_i)
subject to ||delta||_p <= epsilon
```

### 和样本级扰动的区别

| 对比项 | 样本级扰动 | 通用扰动 |
| --- | --- | --- |
| 扰动数量 | 每个样本一个 | 多个样本共享一个 |
| 优化难度 | 较低 | 更高 |
| 攻击强度 | 通常更强 | 单样本上可能弱 |
| 泛化价值 | 较弱 | 更强 |
| 现实风险 | 需要逐样本生成 | 可预生成、可批量使用 |

### 为什么能成立

通用扰动说明模型存在共享脆弱方向：

- 许多样本在特征空间中对某些方向敏感。
- 模型决策边界在数据流形附近存在共性结构。
- CNN/ViT 等视觉模型会依赖类似的非鲁棒特征。
- 多任务模型可能共享 backbone，扰动可攻击共享表示。

### 训练流程

1. 初始化一个全局扰动 `delta`。
2. 在训练样本 batch 上计算攻击损失。
3. 更新同一个 `delta`，而不是更新每张图独立扰动。
4. 投影到扰动预算内。
5. 在未见过样本和目标模型上测试泛化。

### 项目关联

你的“单扰动跨任务通用攻击”可以这样解释：

- 核心不是单样本白盒攻击，而是学习共享扰动。
- 源任务可以是语义分割，因为它提供像素级 dense supervision。
- 目标任务覆盖分类、检测、分割，证明扰动影响共享视觉表征。
- 迁移到 ViT 说明扰动不完全依赖 CNN 架构。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 概念题 | 通用扰动和普通扰动区别 | 一个样本一个 vs 多样本共享 |
| 原因题 | 为什么一个扰动能攻击多图 | 模型存在共享非鲁棒方向 |
| 实验题 | 怎么证明通用性 | 训练/测试样本分离，跨模型、跨任务评估 |
| 项目题 | 单扰动跨任务攻击怎么讲 | 攻击共享 backbone/视觉表征 |

### 易错点

- 在训练样本上成功就说通用，未在测试样本验证。
- 只看分类，不看检测/分割等任务级指标。
- 不控制扰动预算，导致扰动可见。
- 把通用扰动和 universal trigger 混淆；前者常指连续视觉扰动，后者常用于离散文本触发。

## 面试应对

### 通用扰动为什么有研究价值？

回答思路：强调泛化和现实风险。

回答模板：

通用扰动的价值在于它不是为每个样本单独优化，而是学习一个能影响许多样本的共享扰动。它说明模型在数据流形附近存在共性的非鲁棒方向，攻击不只是个别样本的偶然现象。现实上，通用扰动可以预先生成并批量使用，攻击成本更低。我的跨任务通用攻击项目也是这个思路：攻击共享视觉表征，让同一个扰动同时影响分类、检测和分割任务。
