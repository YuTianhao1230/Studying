# 模型集成与特征攻击

## 知识点解析

### 概述

模型集成与特征攻击是提升对抗样本迁移性的两类重要方法：前者通过多个源模型寻找共享攻击方向，后者通过攻击中间表示减少对单一任务头的过拟合。

### 解决的问题

单模型攻击容易过拟合源模型，分类头攻击容易过拟合特定任务。模型集成和特征攻击分别从模型维度和表示维度缓解这个问题。

### 模型集成攻击

集成攻击同时优化多个源模型的损失：

```text
L_total = sum_i w_i * L_i(f_i(x_adv), y)
```

常见做法：

- logits ensemble：平均多个模型 logits 后计算 loss。
- loss ensemble：分别算 loss 再加权求和。
- gradient ensemble：分别算梯度再融合。

核心直觉：如果扰动能同时攻击多个架构不同的源模型，它更可能命中目标模型共享的脆弱方向。

### 特征攻击

特征攻击不只攻击最终输出，而是攻击中间层表示：

```text
maximize distance(h_l(x_adv), h_l(x))
```

或让对抗样本特征靠近目标类别/目标样本：

```text
minimize distance(h_l(x_adv), h_l(x_target))
```

常见特征层：

- CNN 中间 stage。
- [ViT](<../../02_大模型/模型细节/里程碑模型/ViT.md>) patch token。
- [CLIP](<../../06_视觉多模态与生成模型/多模态模型/CLIP.md>) image embedding。
- [VLM](<../../06_视觉多模态与生成模型/多模态模型/VLM与Vision_Instruction_Tuning.md>) 图文融合层。

### 为什么有助于迁移

最终分类头往往和具体数据集、类别空间绑定；中间特征更接近通用视觉表示。攻击中间特征可以减少对某个任务头的依赖，更容易迁移到检测、分割、检索和多模态模型。

模型集成则从多个模型共同优化，减少单一模型梯度偏差。

### 在 Syner-Attack 中的对应

Syner-Attack 的图像侧 feature loss 可以从特征攻击角度理解：

- 不只攻击最终检索分数。
- 直接扰乱视觉特征或跨模态对齐表示。
- 目标是提升跨 VLM/MLLM 的黑盒迁移性。

如果结合多个 VLP 源模型，还可以进一步解释为集成迁移攻击。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 方法题 | 怎么提升迁移性 | 模型集成和中间特征攻击 |
| 原因题 | 为什么攻击特征比攻击分类头更通用 | 特征更共享，任务头更专用 |
| 公式题 | 集成 loss 怎么写 | 多模型 loss 加权求和 |
| 项目题 | feature loss 有什么作用 | 扰乱共享表示，提升跨模型迁移 |

### 易错点

- 集成模型和目标模型重合，导致黑盒设定不干净。
- 只攻击最后 logits，迁移到不同任务时效果弱。
- 特征层选择没有消融，无法说明为什么有效。
- 多个 loss 权重未说明，实验不可复现。

## 面试应对

### 为什么模型集成和特征攻击能提升迁移性？

回答思路：从减少源模型和任务头过拟合回答。

回答模板：

迁移攻击最怕扰动只适配某个源模型或某个任务头。模型集成通过同时优化多个源模型的损失，逼迫扰动寻找不同模型共享的脆弱方向；特征攻击则不只优化最终分类结果，而是扰乱中间层或语义 embedding，这些表示通常比任务头更通用。因此两者都能减少源模型特异性，提升跨模型、跨任务或跨多模态系统的迁移概率。
