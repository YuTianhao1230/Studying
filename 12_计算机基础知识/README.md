## 复习路线

建议按“先通用底层，再应用场景”的顺序复习：

1. 先背各分类 README 中标记为“高频”的卡片。
2. 数据结构与算法：保证笔试和在线编程题的基本盘。
3. 操作系统：理解进程、线程、内存、锁和 IO，这是工程面试追问的基础。
4. 计算机网络：重点掌握 TCP、HTTP、DNS、TLS 和常见排查链路。
5. 数据库：重点掌握索引、事务、锁、SQL 优化和高并发场景。
6. 计算机组成原理：重点掌握 Cache、流水线、存储层次和性能分析。
7. 编程语言基础：按目标岗位补 Java/Python/C++。
8. Linux 与 Shell：补生产排查和笔试命令题。
9. 分布式与中间件：补大厂和银行科技岗常见系统题。
10. 扩展基础：补信息安全、软件工程、设计模式和金融科技热点。

## 高频交叉问题

- 进程、线程、协程的区别。
- 用户态和内核态为什么要区分。
- 虚拟内存为什么能让程序以为自己有连续大内存。
- B+ 树为什么适合数据库索引。
- TCP 为什么需要三次握手和四次挥手。
- HTTP 和 HTTPS 的区别。
- 数据库事务 ACID 和隔离级别。
- 哈希冲突怎么解决。
- Cache 为什么能提升性能，局部性原理是什么。
- Redis 为什么快，缓存穿透/击穿/雪崩怎么解决。
- SQL 注入、XSS、CSRF 怎么防。
- 消息队列如何保证不丢、不重、不乱序。

## 使用方式

- 笔试前：先看各分类 README 的“笔试常考”，再刷对应知识卡片。
- 面试前：优先背知识卡片里的“回答模板”。
- 查漏补缺：不会的问题直接定位到对应分类，不在总纲里反复翻找。
