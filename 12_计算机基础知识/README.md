## 复习路线

建议按“先通用底层，再应用场景”的顺序复习：

1. 数据结构与算法：先保证笔试和在线编程题的基本盘。
2. 操作系统：理解进程、线程、内存、锁和 IO，这是工程面试追问的基础。
3. 计算机网络：重点掌握 TCP、HTTP、DNS、TLS 和常见排查链路。
4. 数据库：重点掌握索引、事务、锁、SQL 优化和高并发场景。
5. 计算机组成原理：重点掌握 Cache、流水线、存储层次和性能分析。
6. 扩展基础：补信息安全、软件工程、设计模式、中间件和金融科技热点。

## 高频交叉问题

- 进程、线程、协程的区别。
- 用户态和内核态为什么要区分。
- 虚拟内存为什么能让程序以为自己有连续大内存。
- B+ 树为什么适合数据库索引。
- TCP 为什么需要三次握手和四次挥手。
- HTTP 和 HTTPS 的区别。
- 数据库事务 ACID 和隔离级别。
- 哈希冲突怎么解决。
- Cache 为什么能提升性能，局部性原理是什么。

## 使用方式

- 笔试前：优先看每篇里的“笔试常考”。

- 查漏补缺：遇到不会的问题，再回到“知识点解析”补概念链条。
