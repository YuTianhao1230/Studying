# 运营商技术基础

## 概述

本目录整理三大运营商笔试中的通信与网络技术基础，重点覆盖通信原理、移动通信、5G、光纤、运营商网络、物联网、云网融合和算力网络。内容定位为技术原理和笔试概念，不重复 `15_行测/运营商笔试` 中的企业文化、行业新闻和考试考情。

## 知识卡片

| 卡片 | 重点 |
| --- | --- |
| [通信原理与数字通信](<通信原理与数字通信.md>) | 采样、量化、编码、调制、复用、香农公式、误码率。 |
| [移动通信与5G](<移动通信与5G.md>) | 1G-5G、eMBB/mMTC/URLLC、SA/NSA、MIMO、切片和边缘计算。 |
| [光纤通信与运营商网络](<光纤通信与运营商网络.md>) | 光纤、WDM、PON、接入网、承载网、核心网和路由交换。 |
| [物联网云网与算力网络](<物联网云网与算力网络.md>) | 物联网分层、NB-IoT、云计算、大数据和算力调度。 |

## 复习顺序

1. 先掌握通信系统、采样、调制、复用和信道容量。
2. 再掌握 1G-5G、5G 三大场景和关键无线技术。
3. 然后学习光纤、PON、运营商网络层级和 QoS。
4. 最后补物联网、云网融合、算力网络和新技术应用。

## 与计算机网络的边界

- `计算机网络`：主机通信、TCP/IP、HTTP、DNS、子网和通用路由。
- `运营商技术基础`：通信信号、无线接入、光纤承载、运营商网络和行业技术。
