# 通信原理与数字通信

## 知识点解析

### 概述

通信原理研究信息如何经过发送设备、信道和接收设备从信源传递到信宿。三大运营商笔试中的通信基础通常不要求复杂推导，但会考查模拟与数字通信、采样量化、调制解调、复用、信道容量、噪声和误码率等概念边界。做题时要先判断题目问的是“信号表示”“传输方式”“共享信道方法”还是“传输质量指标”。

### 通信系统基本组成

```text
信源 -> 输入变换器 -> 发送设备 -> 信道 -> 接收设备 -> 输出变换器 -> 信宿
```

- 信源：产生语音、图像、文字或数据。
- 发送设备：完成编码、调制、放大和发射。
- 信道：传输信号的媒介，可以是光纤、双绞线、无线空间等。
- 接收设备：完成滤波、放大、解调和译码。
- 噪声：传输过程中叠加在有用信号上的随机干扰。

通信系统的主要性能指标是有效性和可靠性。有效性强调传输速率和频带利用率，可靠性强调抗干扰能力、误码率和通信稳定性。

### 模拟通信与数字通信

| 对比项 | 模拟通信 | 数字通信 |
| --- | --- | --- |
| 信号 | 连续信号 | 离散符号或比特 |
| 抗干扰能力 | 再生困难，噪声容易累积 | 可通过再生和纠错恢复 |
| 保密和复用 | 相对不便 | 便于加密、压缩和复用 |
| 典型问题 | 噪声随传输累积 | 需要同步、量化和编码 |

数字通信并不是“没有噪声”，而是接收端可以根据判决门限把受干扰的波形恢复为 0 或 1。噪声过大时仍会产生误码。

### 采样、量化和编码

模拟信号数字化通常经历：

```text
采样 -> 量化 -> 编码
```

1. 采样：按一定时间间隔读取模拟信号的瞬时值。
2. 量化：把连续幅度映射到有限个离散等级。
3. 编码：把量化等级表示成二进制码。

根据奈奎斯特采样定理，若信号最高频率为 `f_max`，为了无失真恢复原信号，采样频率应满足：

```text
f_s >= 2f_max
```

采样频率过低会发生混叠。量化级数越多，量化误差通常越小，但每个样本需要的编码位数和数据量也越大。量化级数为 `L` 时，理想情况下每个样本的编码位数为：

```text
n = log2(L)
```

### 信号、带宽和速率

- 频率：单位时间内周期性变化的次数，单位为 Hz。
- 周期：完成一次重复变化所需的时间，`T = 1/f`。
- 带宽：信号占用的频率范围，带宽越大通常能承载更高的数据速率。
- 比特率：每秒传输的比特数，单位 bit/s。
- 波特率：每秒传输的码元数，单位 Baud。

如果一个码元可以表示 `M` 种状态，则理想情况下：

```text
比特率 = 波特率 × log2(M)
```

比特率和波特率不是同一个概念。一个码元只表示 1 bit 时，二者数值才相同。

### 调制与解调

调制是用数字基带信号改变载波的某个参数，使信号适合在信道中传输；解调是接收端从载波中恢复原始信息。

| 调制方式 | 改变参数 | 记忆点 |
| --- | --- | --- |
| ASK | 振幅 | 振幅键控 |
| FSK | 频率 | 频率键控 |
| PSK | 相位 | 相位键控 |
| QAM | 振幅和相位 | 提高单位码元携带比特数 |

高阶调制可以提高频谱效率，但星座点间距变小，对信噪比和信道质量要求更高。5G 中常见 QPSK、16QAM、64QAM、256QAM 等调制方式，实际调制阶数会根据无线信道质量自适应调整。

### 复用技术

复用允许多个信号共享一条传输媒介，接收端再通过解复用分离信号。

| 复用方式 | 区分维度 | 典型理解 |
| --- | --- | --- |
| FDM | 频率 | 不同用户占用不同频段 |
| TDM | 时间 | 不同用户占用不同时间片 |
| CDM | 编码 | 不同用户使用不同码序列 |
| WDM | 光波长 | 光纤中使用不同波长传输 |
| OFDM | 正交子载波 | 把高速数据分到多个正交子载波 |

OFDM 能有效利用频谱并抵抗多径影响，但对频偏和同步误差较敏感。WDM 是光纤通信中的波分复用，不能和无线通信中的 OFDM 混为一谈。

### 香农公式与奈奎斯特公式

有噪声信道的最大传输速率可用香农公式表示：

```text
C = B log2(1 + S/N)
```

- `C`：信道容量。
- `B`：信道带宽。
- `S/N`：信噪比，使用线性值而不是分贝值。

香农公式说明，增加带宽或提高信噪比可以提高理论容量，但容量存在上限。奈奎斯特公式主要描述无噪声有限带宽信道的理想码元速率：

```text
码元速率 <= 2B
```

题目给出 dB 信噪比时，先转换为线性值再代入香农公式。

### 噪声、误码率和编码

- 信噪比越高，接收端越容易正确判决。
- 误码率 BER 是错误比特数与接收总比特数之比。
- 检错只能发现错误，纠错还要能够根据冗余信息恢复错误。
- 奇偶校验、CRC 主要用于检错。
- 海明码、卷积码、LDPC 等可以提供纠错能力。

增加冗余通常会降低有效数据速率，但可以提升可靠性。通信系统需要在速率、时延、频谱效率和可靠性之间取舍。

## 笔试常考

- 采样频率与最高信号频率的关系。
- 量化级数、编码位数和数据速率计算。
- 比特率、波特率和调制阶数的换算。
- ASK、FSK、PSK、QAM 的区别。
- FDM、TDM、CDM、WDM、OFDM 的区分。
- 香农公式中带宽、信噪比和信道容量的关系。
- CRC 能检错但不能直接纠错。
- 高阶调制频谱效率高，但对信道质量要求更高。

## 易错点

- 采样频率至少是最高频率的两倍，不是信号带宽的两倍。
- 波特率表示码元速率，比特率还要乘以每个码元携带的比特数。
- 香农公式中的信噪比必须使用线性值，不能直接把 dB 数字代入。
- 数字通信仍然会发生误码，不是完全不受噪声影响。
- WDM 面向光波长，OFDM 面向正交子载波，二者不是同一种复用。
