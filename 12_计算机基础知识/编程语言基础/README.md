# 编程语言基础

本目录存放央国企、银行科技岗和大厂面试中常见的编程语言基础知识卡片。笔试通常考语法、类型、异常、面向对象和集合；大厂面试更常追问运行时、并发、内存管理和工程问题。

## 知识卡片

| 卡片 | 重点 |
| --- | --- |
| [Java基础](<Java基础.md>) | 集合、HashMap、异常、面向对象、JVM、GC、线程池和锁。 |
| [Python基础](<Python基础.md>) | 可变对象、深浅拷贝、生成器、装饰器、GIL、异常和面向对象。 |
| [C++基础](<C++基础.md>) | 指针引用、内存管理、虚函数、多态、STL、RAII、编译链接。 |

## 复习顺序

1. 央国企/银行科技岗：先看 Java 或 Python 基础语法、集合、异常和面向对象。
2. 大厂后端：重点看 Java 集合、JVM、GC、线程池、锁和并发。
3. C++ 岗位：重点看内存、对象模型、虚函数、STL 和编译链接。
