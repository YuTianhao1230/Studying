# C++基础

## 知识点解析

### 概述

C++ 基础常出现在央国企、银行科技岗和系统研发类岗位中。高频考点包括指针和引用、内存管理、构造析构、虚函数、多态、STL、RAII、智能指针和编译链接。

### 指针和引用

指针是变量，保存地址，可以为空，也可以改变指向；引用是已有对象的别名，定义时必须初始化，之后不能再绑定到别的对象。函数参数如果需要修改外部对象，可以使用指针或引用；如果不希望拷贝大对象，可以使用常量引用。

### 内存管理

C++ 中对象可能分配在栈、堆、静态区和常量区。栈上对象由作用域自动管理；堆上对象由 `new/delete` 或智能指针管理。`new` 和 `delete`、`new[]` 和 `delete[]` 必须匹配，否则可能内存泄漏或未定义行为。

### 构造、析构和拷贝

构造函数负责初始化对象，析构函数负责释放资源。拷贝构造和拷贝赋值控制对象复制行为。如果类管理堆内存、文件句柄、锁等资源，需要特别注意深拷贝、浅拷贝和资源释放问题。

### 虚函数和多态

C++ 运行时多态通过虚函数实现。父类指针或引用指向子类对象时，调用虚函数会根据真实对象类型动态绑定。包含虚函数的类通常有虚函数表，对象中保存虚表指针。基类析构函数如果可能通过基类指针删除子类对象，应声明为虚析构函数。

### STL

常见 STL 容器：

- `vector`：动态数组，随机访问快。
- `list`：双向链表，随机访问慢。
- `deque`：双端队列。
- `map`/`set`：通常基于红黑树，有序，操作 O(log n)。
- `unordered_map`/`unordered_set`：哈希表，平均 O(1)。
- `priority_queue`：优先队列，通常基于堆。

### RAII 和智能指针

RAII 是 Resource Acquisition Is Initialization，把资源生命周期绑定到对象生命周期。对象构造时获取资源，析构时释放资源。智能指针是 RAII 的典型应用：`unique_ptr` 表示独占所有权，`shared_ptr` 表示共享所有权，`weak_ptr` 用于打破 `shared_ptr` 循环引用。

### 编译链接

C++ 程序通常经历预处理、编译、汇编和链接。预处理处理宏和头文件；编译生成汇编；汇编生成目标文件；链接把多个目标文件和库组合成可执行文件。常见链接错误包括符号未定义、重复定义、库路径或链接顺序错误。

## 面试应对

### 指针和引用有什么区别？

回答思路：从是否可为空、是否可变更绑定、语义和使用场景回答。

回答模板：

指针是一个保存地址的变量，可以为空，也可以在运行时改变指向；引用是对象的别名，定义时必须初始化，之后不能再绑定到其他对象。语义上，引用更适合表达“这个参数一定存在”，指针更适合表达“可能为空”或需要改变指向的场景。函数传参时，如果只是避免拷贝且不修改对象，通常用 const 引用。

### C++ 为什么需要虚析构函数？

回答思路：说明基类指针删除子类对象时的析构链问题。

回答模板：

如果一个类会被当作基类使用，并且可能通过基类指针删除子类对象，那么基类析构函数应该声明为虚函数。否则 `delete basePtr` 时只会调用基类析构函数，子类析构函数可能不执行，导致子类资源泄漏。虚析构函数能保证析构时根据真实对象类型动态绑定，先执行子类析构，再执行基类析构。
