# 央国企与大厂高频考点对照

## 知识点解析

### 概述

央国企、银行科技岗和互联网大厂都会考计算机基础，但侧重点不同。三大运营商更偏网络、协议、子网划分和通信基础；六大行科技岗更偏计算机基础综合、SQL、数据库事务、安全和软件工程；大厂技术面更偏高并发、MySQL/Redis、TCP/HTTP、操作系统并发与工程排查。

本文件用于做查漏补缺，不替代各专题文件。

### 考点来源

本次整理参考了公开题库和经验贴中的考点分布，不照搬题目原文，只提炼高频知识域：

- 三大运营商笔试：数据结构与算法、计算机网络、操作系统、数据库、软件工程和 5G/IoT 等新技术。
- 银行科技岗笔试：建设银行等信息技术类笔试常见计算机网络、操作系统、软件工程、信息安全、中间件、分布式架构、设计模式、数据结构与算法、开发语言和数据库语法。
- 大厂后端面试：MySQL 索引/MVCC/锁、Redis、TCP/HTTP/HTTPS、IO 多路复用、进程线程、线程池、锁、JVM 和线上排查。

## 笔试常考

### 央国企题型

- 单选/多选：概念区分、协议层次、复杂度、SQL 语法、事务隔离级别。
- 判断题：常见定义陷阱，例如虚拟内存、索引、线程共享资源、HTTP 状态码。
- 简答题：TCP/UDP 区别、数据库事务、银行系统数据安全、软件开发流程。
- 编程题：字符串处理、数组查找、排序、二分、递归、简单动态规划。
- SQL 题：聚合统计、多表连接、Top N、分组筛选、去重。

### 大厂题型

- 原理追问：B+ 树、MVCC、TCP 可靠传输、epoll、锁、线程池。
- 场景设计：缓存一致性、接口变慢排查、慢 SQL、线上 OOM、连接数打满。
- 横向对比：HTTP/1.1 vs HTTP/2 vs HTTP/3，B 树 vs B+ 树，进程 vs 线程 vs 协程。
- 代码实现：LRU、Top K、生产者消费者、线程安全单例、并发控制。

## 面试应对

### 央国企和大厂复习策略有什么区别？

回答思路：央国企覆盖面广，大厂追问深；复习时先建宽度，再补深度。

回答模板：

央国企和银行科技岗的计算机基础更像综合考试，覆盖网络、数据库、操作系统、数据结构、软件工程、安全和新技术，题型以选择、多选、简答和基础编程为主，所以复习要保证覆盖面，尤其是概念、公式和常见陷阱。大厂面试更关注少数高频模块的深度，比如 MySQL 索引和 MVCC、TCP 可靠传输、epoll、线程和锁，会不断追问原理、场景和线上排查。所以我的复习策略是先用央国企题库补全知识面，再用大厂面经把 MySQL、网络、OS 并发和算法题练深。
