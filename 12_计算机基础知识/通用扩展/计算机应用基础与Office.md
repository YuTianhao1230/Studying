# 计算机应用基础与 Office

## 知识点解析

### 概述

银行综合知识和部分运营商笔试会考计算机应用基础，题目通常比技术岗专业题浅，但覆盖面较广。重点包括硬件、软件、存储单位、文件格式、操作系统、网络常识和 Office 基础操作。

### 硬件与软件

- CPU：执行指令和进行运算。
- 内存：为正在运行的程序提供临时存储，断电后通常丢失数据。
- 硬盘/SSD：持久化存储文件和系统。
- 显卡：处理图形和并行计算任务。
- 网卡：连接网络并完成数据帧收发。
- 输入设备：键盘、鼠标、扫描仪、摄像头。
- 输出设备：显示器、打印机、音箱。

系统软件包括操作系统、驱动程序和运行库；应用软件面向具体业务和用户任务。

### 存储单位和进制

```text
1 Byte = 8 bit
1 KB = 1024 B
1 MB = 1024 KB
1 GB = 1024 MB
```

网络带宽通常使用 bit/s，文件大小通常使用 Byte。题目出现 MB/s 和 Mb/s 时，要先注意大小写和 8 倍换算。

### 常见文件格式

| 格式 | 常见用途 |
| --- | --- |
| `.docx` | Word 文档 |
| `.xlsx` | Excel 工作簿 |
| `.pptx` | PowerPoint 演示文稿 |
| `.pdf` | 固定版式文档 |
| `.csv` | 逗号分隔文本数据 |
| `.zip` | 压缩归档 |
| `.jpg/.png` | 图片 |
| `.mp3` | 音频 |
| `.mp4` | 视频 |
| `.html/.css/.js` | Web 页面相关文件 |

文件扩展名是常见格式标识，但不能完全证明文件内容安全。陌生附件仍需要进行来源校验和安全扫描。

### 操作系统和文件管理

操作系统负责进程、内存、文件、设备和用户权限管理。常见文件操作包括创建、复制、移动、重命名、删除、压缩、解压和权限设置。

回收站通常用于暂存删除的文件，但彻底删除、格式化、磁盘故障或网络盘删除不一定能通过回收站恢复。重要文件应定期备份。

### Excel 基础

Excel 中常见概念：

- 工作簿：一个 Excel 文件。
- 工作表：工作簿中的单个表格页面。
- 单元格：行列交叉形成的基本数据单元。
- 相对引用：复制公式时引用位置随公式移动。
- 绝对引用：使用 `$` 固定行、列或单元格。
- 混合引用：只固定行或只固定列。

常见函数：

| 函数 | 作用 |
| --- | --- |
| `SUM` | 求和 |
| `AVERAGE` | 平均值 |
| `COUNT/COUNTA` | 计数 |
| `MAX/MIN` | 最大值和最小值 |
| `IF` | 条件判断 |
| `SUMIF/SUMIFS` | 条件求和 |
| `COUNTIF/COUNTIFS` | 条件计数 |
| `VLOOKUP/XLOOKUP` | 查找匹配 |
| `ROUND` | 四舍五入 |

排序会改变数据展示顺序，筛选通常只隐藏不符合条件的行。使用排序前应选中完整数据区域，否则可能造成行列错位。

### Word 与 PowerPoint

Word 常考样式、页眉页脚、分页、目录、查找替换、表格和邮件合并。使用样式设置标题比手动调整字体更适合自动生成目录。

PowerPoint 常考主题、母版、版式、动画和切换。母版用于统一控制多个页面的版式、字体和背景，动画用于对象或内容的出现效果，切换用于页面之间的过渡效果。

### 网络和办公安全

- 不打开来源不明的宏和可执行附件。
- 不在公共电脑保存密码和敏感文件。
- 使用复杂密码和多因素认证。
- 通过官方渠道安装软件和更新补丁。
- 重要文件遵循备份和版本管理。
- 发送含个人信息或业务数据的文件前进行脱敏和权限确认。

## 易错点

- `1 MB` 和 `1 Mb` 不是同一个单位。
- 内存不是永久存储设备。
- Excel 复制公式时，相对引用会变化，绝对引用不会变化。
- 筛选通常隐藏行，不等同于删除数据。
- 文件扩展名不能作为安全性的唯一判断依据。
