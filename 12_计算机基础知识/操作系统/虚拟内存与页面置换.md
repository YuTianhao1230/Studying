# 虚拟内存与页面置换

## 知识点解析

### 概述

虚拟内存是操作系统内存管理的核心抽象。它让每个进程看到独立、连续的地址空间，再通过页表映射到物理内存，实现隔离、保护、按需加载和换页。

### 地址映射

程序使用的是虚拟地址，CPU 访问内存时需要把虚拟地址转换成物理地址。页表保存虚拟页到物理页框的映射。TLB 是页表缓存，用于加速地址转换。

虚拟地址通常拆成：

```text
虚拟页号 + 页内偏移
```

页大小决定页内偏移位数，剩余高位是虚拟页号。

### 缺页中断

如果访问的虚拟页不在物理内存中，会触发缺页中断。操作系统暂停当前进程，从磁盘或交换区加载页面到内存，更新页表后继续执行。缺页太多会导致频繁换页，严重时系统大部分时间都在换页，称为 thrashing。

### 页面置换算法

| 算法 | 思路 | 特点 |
| --- | --- | --- |
| FIFO | 淘汰最早进入内存的页 | 简单，但可能出现 Belady 异常 |
| LRU | 淘汰最近最久未使用的页 | 符合局部性，精确实现成本高 |
| OPT | 淘汰未来最长时间不用的页 | 理论最优，实际不可实现 |
| Clock | 用访问位近似 LRU | 工程实现成本较低 |

## 面试应对

### 为什么需要虚拟内存？

回答思路：从隔离、抽象、按需加载和扩展地址空间回答。

回答模板：

虚拟内存让每个进程看到独立、连续的地址空间，再通过页表映射到物理内存。它的好处是进程隔离更安全，程序编写更简单，而且可以按需加载页面，只有真正访问的数据才进入物理内存。虚拟内存不是凭空增加物理内存，而是通过地址映射、换页和磁盘交换扩展可用地址空间，代价是地址转换和缺页中断会带来开销。

### LRU 和 FIFO 有什么区别？

回答思路：说明淘汰依据和局部性。

回答模板：

FIFO 淘汰最早进入内存的页面，实现简单，但不考虑页面最近是否被频繁访问，可能把热点页面淘汰掉。LRU 淘汰最近最久未使用的页面，更符合程序的时间局部性，效果通常更好，但精确维护访问顺序成本较高。工程上常用 Clock 这类算法近似 LRU，在效果和实现成本之间折中。

### 缺页中断是什么？

回答思路：说明页面不在内存时，操作系统如何加载并恢复执行。

回答模板：

缺页中断是进程访问某个虚拟页时，发现这个页当前不在物理内存中，于是 CPU 触发异常进入内核。操作系统会把页面从磁盘或交换区加载到内存，必要时先淘汰其他页面，然后更新页表并恢复进程执行。缺页太频繁会导致系统大量时间花在换页上，性能会明显下降。
