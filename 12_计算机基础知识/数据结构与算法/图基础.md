# 图基础

## 知识点解析

### 概述

本文整理图的 BFS、DFS、拓扑排序、Dijkstra 和并查集，包括适用条件、实现方法、复杂度和题型识别。

### 核心算法

| 算法 | 解决问题 | 注意 |
| --- | --- | --- |
| BFS | 无权图最短路、层序扩展 | 用队列 |
| DFS | 连通性、回溯、路径搜索 | 用递归或栈 |
| 拓扑排序 | 有向无环图依赖顺序 | 入度为 0 的点先出 |
| Dijkstra | 非负权单源最短路 | 不能处理负权边 |
| 并查集 | 动态连通性、集合合并 | 路径压缩 + 按秩合并 |

### Dijkstra

Dijkstra 用于求非负权图中某个源点到其他节点的最短距离。核心是贪心：每次从尚未确定的节点中选择当前距离最小的节点，将它的最短距离确定下来，再用它更新相邻节点。

更新相邻节点距离的过程称为松弛。对于边 `u -> v`，权重为 `w`：

```text
如果 dist[u] + w < dist[v]
则更新 dist[v] = dist[u] + w
```

#### 为什么不能处理负权边

Dijkstra 默认当前距离最小的节点一旦被取出，其最短距离就不会再被后续路径改善。负权边可能让一个已经确定的节点得到更短路径，从而破坏这个贪心前提。

- 存在负权边：考虑 Bellman-Ford。
- 需要检测负环：使用 Bellman-Ford。
- 无权图或所有边权相同：使用 BFS 更简单。
- 多源最短路：可以建立虚拟源点，或根据题目使用 Floyd。

#### Python 模板

```python
import heapq


def dijkstra(
    graph: list[list[tuple[int, int]]],
    source: int,
) -> list[float]:
    distances = [float("inf")] * len(graph)
    distances[source] = 0
    heap = [(0, source)]

    while heap:
        current_distance, node = heapq.heappop(heap)

        if current_distance != distances[node]:
            continue

        for neighbor, weight in graph[node]:
            new_distance = current_distance + weight
            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance
                heapq.heappush(heap, (new_distance, neighbor))

    return distances
```

Python 的 `heapq` 不支持直接修改堆中旧元素，因此距离变短时直接压入新状态，取出过期状态时跳过。这种方式称为懒删除。

使用邻接表和最小堆时，时间复杂度通常为 `O((V + E) log V)`，常简写为 `O(E log V)`；空间复杂度为 `O(V + E)`。使用邻接矩阵并线性选择最小距离节点时，时间复杂度为 `O(V^2)`，适合稠密图或节点数较小的情况。

### 并查集

并查集维护若干互不相交的集合，主要支持两个操作：

- `find(x)`：查询元素 `x` 所属集合的代表节点。
- `union(x, y)`：合并 `x` 和 `y` 所在的集合。

两个元素是否连通，只需判断它们的代表节点是否相同：

```text
find(x) == find(y)
```

并查集常用于无向图动态连通性、连通分量统计、冗余边检测和 Kruskal 最小生成树。它擅长回答“是否属于同一集合”，但不能直接给出两点之间的具体路径，也不擅长处理删除边后的连通性变化。

#### 路径压缩

查找代表节点时，把沿途节点直接连接到根节点，降低后续查询的树高：

```python
def find(self, node: int) -> int:
    if self.parent[node] != node:
        self.parent[node] = self.find(self.parent[node])
    return self.parent[node]
```

#### 按大小合并

合并时让较小的树连接到较大的树，避免退化成长链。按秩合并的思想相同，只是维护的是树高近似值。

#### Python 模板

```python
class UnionFind:
    def __init__(self, size: int) -> None:
        self.parent = list(range(size))
        self.component_size = [1] * size
        self.count = size

    def find(self, node: int) -> int:
        if self.parent[node] != node:
            self.parent[node] = self.find(self.parent[node])
        return self.parent[node]

    def union(self, first: int, second: int) -> bool:
        root_first = self.find(first)
        root_second = self.find(second)

        if root_first == root_second:
            return False

        if self.component_size[root_first] < self.component_size[root_second]:
            root_first, root_second = root_second, root_first

        self.parent[root_second] = root_first
        self.component_size[root_first] += self.component_size[root_second]
        self.count -= 1
        return True

    def connected(self, first: int, second: int) -> bool:
        return self.find(first) == self.find(second)
```

同时使用路径压缩和按大小或按秩合并后，单次操作的均摊复杂度为 `O(alpha(n))`，其中 `alpha` 是反阿克曼函数，在实际数据规模下可以近似看成常数；空间复杂度为 `O(n)`。

### 题型识别

- 最少步数、层数：优先 BFS。
- 枚举路径、连通块：优先 DFS。
- 课程安排、依赖顺序：拓扑排序。
- 网络延迟、最短距离：Dijkstra。
- 朋友圈、连通分量、冗余连接：并查集。

## 面试应对

### BFS 和 DFS 有什么区别？

回答思路：数据结构、搜索顺序、适用场景。

回答模板：

BFS 用队列，按层向外扩展，适合求无权图最短路径和层序遍历；DFS 用递归或栈，一条路走到底再回溯，适合连通性、路径搜索和回溯问题。BFS 的空间通常和最大层宽有关，DFS 的空间和递归深度有关。题目如果问最少步数，我会优先考虑 BFS；如果是枚举所有路径或连通性，我会优先考虑 DFS。

### Dijkstra 适合什么场景？

回答思路：先说明非负权单源最短路，再解释贪心、松弛、复杂度和负权限制。

回答模板：

Dijkstra 用来求非负权图中的单源最短路径。它维护源点到各节点的当前最短距离，每次从最小堆取出距离最小的未确定节点，再通过松弛操作更新邻接点。使用邻接表和最小堆时，时间复杂度通常是 `O((V + E) log V)`。它不能处理负权边，因为后续负边可能推翻已经确定的最短距离；存在负权边时应考虑 Bellman-Ford。

### 并查集解决什么问题？

回答思路：说明集合代表、两个核心操作、优化方法和能力边界。

回答模板：

并查集用于维护动态连通性，核心操作是 `find` 查询元素所属集合的代表节点，以及 `union` 合并两个集合。判断两个节点是否连通，只需比较它们的根节点是否相同。通过路径压缩和按秩或按大小合并，单次操作的均摊复杂度接近 `O(1)`。它常用于连通分量、冗余边和 Kruskal 最小生成树，但只能高效判断集合关系，不能直接返回两点之间的具体路径，也不适合频繁删除边的场景。

### Dijkstra 和 BFS 怎么选？

回答思路：根据边权判断。

回答模板：

如果图是无权图，或者所有边权都相同，BFS 按层扩展就能保证第一次到达节点时是最短距离，时间复杂度是 `O(V + E)`。如果边权不同但都非负，需要用 Dijkstra，每次优先扩展当前累计距离最小的节点。两者本质上都在逐步确定最短距离，只是 BFS 的优先级由层数自然保证，Dijkstra 需要最小堆维护距离优先级。
