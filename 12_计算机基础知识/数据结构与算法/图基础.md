# 图基础

## 知识点解析

### 概述

图基础在笔试中常考 BFS、DFS、拓扑排序、Dijkstra 和并查集。面试重点是能根据问题识别算法类型。

### 核心算法

| 算法 | 解决问题 | 注意 |
| --- | --- | --- |
| BFS | 无权图最短路、层序扩展 | 用队列 |
| DFS | 连通性、回溯、路径搜索 | 用递归或栈 |
| 拓扑排序 | 有向无环图依赖顺序 | 入度为 0 的点先出 |
| Dijkstra | 非负权单源最短路 | 不能处理负权边 |
| 并查集 | 动态连通性、集合合并 | 路径压缩 + 按秩合并 |

### 题型识别

- 最少步数、层数：优先 BFS。
- 枚举路径、连通块：优先 DFS。
- 课程安排、依赖顺序：拓扑排序。
- 网络延迟、最短距离：Dijkstra。
- 朋友圈、连通分量、冗余连接：并查集。

## 面试应对

### BFS 和 DFS 有什么区别？

回答思路：数据结构、搜索顺序、适用场景。

回答模板：

BFS 用队列，按层向外扩展，适合求无权图最短路径和层序遍历；DFS 用递归或栈，一条路走到底再回溯，适合连通性、路径搜索和回溯问题。BFS 的空间通常和最大层宽有关，DFS 的空间和递归深度有关。题目如果问最少步数，我会优先考虑 BFS；如果是枚举所有路径或连通性，我会优先考虑 DFS。

### Dijkstra 适合什么场景？

回答思路：非负权单源最短路。

回答模板：

Dijkstra 用来求非负权图中的单源最短路径。它每次选择当前距离源点最近的未确定节点，并用这个节点去松弛其他边。它不能处理负权边，因为一旦某个节点被确定为最短距离，后续负边可能推翻这个结论。如果有负权边，要考虑 Bellman-Ford 或 SPFA 这类算法。
