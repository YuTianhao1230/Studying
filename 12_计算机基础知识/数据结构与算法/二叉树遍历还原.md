# 二叉树遍历还原

## 知识点解析

### 概述

二叉树遍历还原是数据结构笔试高频题，核心问题是：给定两种遍历序列，能不能唯一确定一棵二叉树。判断关键在于是否能确定根节点，并且能否用中序遍历把左右子树边界切开。

### 常见遍历

- 前序遍历：根、左、右。
- 中序遍历：左、根、右。
- 后序遍历：左、右、根。
- 层序遍历：按层从左到右。

### 可以唯一确定二叉树的组合

| 遍历组合 | 是否能唯一确定 | 原因 |
| --- | --- | --- |
| 前序 + 中序 | 可以 | 前序确定根，中序划分左右子树 |
| 中序 + 后序 | 可以 | 后序确定根，中序划分左右子树 |
| 中序 + 层序 | 可以 | 层序先遇到根，中序划分左右子树 |

前序的第一个元素是根，后序的最后一个元素是根，层序中当前子树最先出现的元素是根。中序遍历能把根左边的节点划为左子树、根右边的节点划为右子树，所以只要有中序，再配合能确定根的遍历，通常就能递归还原唯一二叉树。

### 不能唯一确定二叉树的组合

一般情况下，**前序 + 后序不能唯一确定普通二叉树**。原因是前序和后序都能确定根，但不能可靠划分左右子树边界，尤其当某个节点只有一个孩子时，无法判断这个孩子是左孩子还是右孩子。

例如只有两个节点：

```text
前序：A B
后序：B A
```

可能是：

```text
  A
 /
B
```

也可能是：

```text
A
 \
  B
```

二者前序和后序完全相同，所以不能唯一确定。

### 特殊情况

如果题目明确说明是**满二叉树**，也就是每个节点要么有 0 个孩子，要么有 2 个孩子，那么前序 + 后序可以唯一确定。因为不存在“只有一个孩子但不知道在左还是右”的歧义。

## 笔试常考

- 前序 + 中序能唯一确定二叉树。
- 中序 + 后序能唯一确定二叉树。
- 中序 + 层序能唯一确定二叉树。
- 前序 + 后序一般不能唯一确定普通二叉树。
- 前序 + 后序在满二叉树条件下可以唯一确定。
- 只有一种遍历序列不能唯一确定二叉树。

## 面试应对

### 哪些遍历组合可以唯一确定二叉树？

回答思路：先给结论，再解释中序的作用。

回答模板：

能唯一确定普通二叉树的常见组合有前序加中序、中序加后序、中序加层序。原因是前序第一个是根，后序最后一个是根，层序里当前子树最先出现的是根；而中序可以根据根的位置把节点划分成左子树和右子树，然后递归还原。一般前序加后序不能唯一确定普通二叉树，因为当某个节点只有一个孩子时，无法判断这个孩子在左边还是右边。

### 为什么前序和后序不能唯一确定普通二叉树？

回答思路：说明无法划分左右子树，并举单孩子例子。

回答模板：

前序和后序都能确定根节点，但缺少中序时，无法稳定划分左右子树。比如前序是 `A B`，后序是 `B A`，这棵树可以是 A 的左孩子是 B，也可以是 A 的右孩子是 B，两种结构的前序和后序完全一样。所以对于普通二叉树，前序加后序不能唯一确定；只有题目限制为满二叉树时，前序加后序才可以唯一确定。
