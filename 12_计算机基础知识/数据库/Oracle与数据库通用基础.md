# Oracle 与数据库通用基础

## 知识点解析

### 概述

银行科技岗常见数据库考查不只限于 MySQL，还可能涉及 Oracle、关系数据库对象、事务、权限、备份和恢复。复习重点是掌握通用数据库概念，再识别 Oracle 的常见语法和对象，不必把所有厂商命令都当成重点。

### Oracle 常见对象

- 表：保存业务数据。
- 视图：保存查询定义，对外提供逻辑表。
- 索引：加速查询，但增加写入和存储成本。
- 序列：生成递增或按规则变化的数值，常用于主键。
- 同义词：为对象提供别名。
- 存储过程/函数：把业务逻辑封装在数据库端。
- 触发器：在插入、更新、删除等事件发生时自动执行。

视图通常保存查询定义而不是独立复制一份数据。索引并不改变 SQL 逻辑结果，触发器则可能在隐式情况下修改或校验数据，使用时需要关注副作用。

### Oracle 常见伪表和伪列

- `DUAL`：Oracle 提供的单行单列表，常用于计算或查询系统表达式。
- `ROWNUM`：结果行的伪列，常用于限制返回行数，但与排序结合时要注意执行顺序。
- `ROWID`：用于标识物理行位置的伪列，不应当作为长期稳定的业务主键。

查询“排序后的前 N 条”时，不能简单把 `ROWNUM` 和 `ORDER BY` 放在同一层而忽略逻辑顺序，通常需要先排序，再在外层限制行数。

### 常见函数

| 类型 | 函数示例 | 作用 |
| --- | --- | --- |
| 空值处理 | `NVL`、`COALESCE` | 把 NULL 转换为指定值 |
| 字符串 | `SUBSTR`、`LENGTH`、`INSTR` | 截取、计算长度和查找 |
| 日期 | `SYSDATE`、`ADD_MONTHS` | 获取和计算日期 |
| 数值 | `ROUND`、`TRUNC`、`MOD` | 舍入、截断、取模 |
| 转换 | `TO_CHAR`、`TO_DATE`、`TO_NUMBER` | 类型转换 |

`NULL` 表示未知或不存在，不等于 0、空字符串或空格。判断空值应使用 `IS NULL` 或 `IS NOT NULL`，不能使用 `= NULL`。

### Oracle 与通用 SQL

SQL 的基本思想仍然是关系查询、连接、过滤、聚合和排序。不同数据库可能在以下方面存在差异：

- 分页语法。
- 日期和字符串函数。
- 自增主键实现。
- 空值和空字符串语义。
- 连接符号和层级查询语法。
- 存储过程语言。

迁移数据库时不能只做语法替换，还要检查事务、锁、索引、执行计划、字符集、时区和数据类型。

### 事务与锁

事务保证一组操作的原子性、一致性、隔离性和持久性。常见命令包括：

- `COMMIT`：提交事务。
- `ROLLBACK`：回滚事务。
- `SAVEPOINT`：建立局部回滚点。

锁用于协调并发访问。读写冲突、更新冲突和长事务都可能导致等待。银行业务中要特别关注余额更新、库存扣减、流水状态和批量处理的锁范围。

### Oracle 物理文件

- 数据文件：保存表、索引等实际数据库对象。
- 控制文件：记录数据库结构、检查点和文件状态等元数据。
- 重做日志文件：记录变更信息，用于实例恢复。
- 归档日志：保存已切换的重做日志，便于时间点恢复。

“数据文件存业务数据，控制文件存数据库结构信息，重做日志用于恢复”是常见基础判断题。

### 备份与恢复

- 冷备：数据库停止后复制文件。
- 热备：数据库运行时进行备份。
- 物理备份：复制数据文件、日志等物理文件。
- 逻辑备份：导出表、对象或逻辑数据。
- 完全备份：备份完整数据集。
- 增量备份：只备份上次备份后发生变化的数据。

备份策略要结合 RPO、RTO、数据量、恢复速度和存储成本。备份本身必须经过恢复演练，否则不能证明可用。

### OLTP 与 OLAP

- OLTP：面向交易处理，强调高并发、低延迟和事务一致性。
- OLAP：面向分析，强调聚合、报表、多维查询和历史数据。

银行核心账务偏 OLTP，经营分析、风险建模和监管报送偏 OLAP。一个系统也可能同时建设交易库、ODS、数据仓库和数据集市。

## 笔试常考

- `DUAL`、`ROWNUM`、`ROWID`。
- `NVL`、`COALESCE`、日期函数和类型转换。
- 视图、索引、序列、触发器和存储过程。
- `COMMIT`、`ROLLBACK`、`SAVEPOINT`。
- 数据文件、控制文件、重做日志和归档日志。
- 逻辑备份与物理备份。
- OLTP 与 OLAP。
- `NULL` 的判断和聚合影响。

## 易错点

- `ROWNUM` 不是稳定的业务编号，也不等价于排序后的行号。
- `ROWID` 是物理定位信息，不能替代业务主键。
- `NULL` 不能用 `= NULL` 判断。
- 视图通常保存查询定义，不等于自动复制数据。
- 有备份不等于可恢复，恢复时间和恢复结果必须演练验证。
