# 计算机基础面试笔试总纲

## 知识点解析

### 概述

计算机基础面试通常考察两类能力：一类是笔试和在线编程中的硬能力，比如算法题、SQL 题、网络状态判断和操作系统计算题；另一类是面试表达能力，比如能否把一个概念讲清楚，能否解释工程取舍，能否从现象定位到底层原因。

### 复习优先级

如果时间有限，建议优先级如下：

1. 数据结构与算法：直接决定笔试和在线编程题表现。
2. 数据库：SQL、索引、事务和锁是后端、数据、算法工程岗位都常问的基础。
3. 计算机网络：TCP、HTTP、HTTPS、DNS 高频且容易结合线上排查。
4. 操作系统：进程线程、内存、锁和 IO 是工程能力的底层支撑。
5. 计算机组成原理：Cache、流水线、数据表示和性能指标常用于区分基础深度。
6. 扩展基础：信息安全、软件工程、设计模式、中间件、云计算、5G、区块链在央国企和银行科技岗中经常以选择题出现。

### 面试回答结构

回答基础八股时，不建议只背定义。更稳的结构是：

```text
一句话定义 -> 核心机制 -> 为什么这样设计 -> 工程场景/常见坑
```

例如回答“为什么 TCP 需要三次握手”：

- 一句话定义：三次握手用于建立连接和同步序列号。
- 核心机制：SYN、SYN+ACK、ACK。
- 为什么这样设计：确认双方发送和接收能力，避免历史连接请求干扰。
- 工程场景：连接建立失败、SYN backlog、网络抖动时可能影响服务可用性。

### 笔试准备结构

笔试题更关注快速识别题型：

- 算法题：先判断是双指针、滑动窗口、前缀和、树、图、堆、DP 还是并查集。
- SQL 题：先判断是否需要 join、group by、窗口函数、去重、Top N。
- 操作系统题：先判断是调度、缺页、死锁、页表还是同步互斥。
- 网络题：先判断是协议顺序、状态码、TCP 状态机、子网划分还是拥塞控制。
- 组成原理题：先判断是补码、Cache 地址划分、流水线还是 CPI 计算。

## 高频面试题清单

### 操作系统

- 进程、线程、协程的区别。
- 用户态和内核态的区别，为什么要有系统调用。
- 进程间通信方式有哪些，怎么选。
- 什么是虚拟内存，页表和 TLB 的作用是什么。
- 分页和分段有什么区别。
- 什么是缺页中断，频繁缺页会发生什么。
- 死锁产生条件和解决方法。
- 互斥锁、自旋锁、读写锁、信号量的区别。
- epoll 为什么适合高并发。

### 数据结构与算法

- 数组和链表怎么选。
- 哈希表为什么平均 O(1)，冲突怎么解决。
- 快排、归并、堆排的复杂度、稳定性和适用场景。
- BFS 和 DFS 的区别。
- 二叉搜索树、平衡树、堆的区别。
- B 树和 B+ 树的区别。
- 动态规划题怎么设计状态。
- Top K、滑动窗口、单调栈、并查集分别适合什么题型。

### 数据库

- B+ 树为什么适合数据库索引。
- 聚簇索引、非聚簇索引、覆盖索引是什么。
- 联合索引的最左前缀原则。
- 什么情况下索引会失效。
- 事务 ACID 是什么。
- 隔离级别分别解决什么问题。
- MVCC 是什么，解决什么问题。
- undo log、redo log、binlog 的作用。
- 慢 SQL 怎么排查。

### 计算机网络

- OSI 七层和 TCP/IP 四层怎么对应。
- TCP 和 UDP 的区别。
- TCP 三次握手和四次挥手。
- TIME_WAIT 的作用。
- TCP 如何保证可靠传输。
- 流量控制和拥塞控制的区别。
- HTTP/1.1、HTTP/2、HTTP/3 的区别。
- HTTPS 的 TLS 握手和安全性来源。
- 从输入 URL 到页面展示发生了什么。

### 计算机组成原理

- 原码、反码、补码的区别，为什么用补码。
- 浮点数为什么有精度误差。
- CPU 执行一条指令的过程。
- 流水线为什么提高吞吐。
- Cache 为什么快，局部性原理是什么。
- Cache 地址如何划分。
- DMA 和中断的作用。
- CPI、IPC、主频和程序执行时间的关系。

### 扩展基础

- SQL 注入、XSS、CSRF、DDoS 的区别和防护。
- 对称加密、非对称加密、哈希、数字签名、数字证书的区别。
- 黑盒测试、白盒测试、单元测试、集成测试、系统测试、回归测试的区别。
- 敏捷开发、瀑布模型、DevOps 的区别。
- 单例、工厂、策略、观察者、代理模式的适用场景。
- 消息队列如何实现异步、解耦、削峰。
- 消息丢失、重复消费、顺序消息、消息积压怎么处理。
- IaaS、PaaS、SaaS 的区别。
- 5G、云计算、区块链、人工智能在金融科技中的应用。

## 面试应对

### 基础八股怎么答得不像背书？

回答思路：每个概念都补“为什么”和“工程场景”。

回答模板：

我会先给定义，再解释它解决的问题和核心机制，最后补一个工程场景。比如讲索引时，不只说索引能加速查询，还会说明 B+ 树为什么适合磁盘页和范围查询、索引为什么会增加写入成本、什么情况下会回表或索引失效。这样回答能体现我不是只背概念，而是理解它在真实系统里的取舍。

### 笔试怎么快速进入状态？

回答思路：先分类题型，再套模板，最后处理边界。

回答模板：

我会先判断题目属于哪类模型，比如数组题先看能不能用双指针、滑动窗口或前缀和；图题先看是连通性、最短路还是拓扑排序；SQL 题先看是聚合、连接、去重还是 Top N。确定题型后先写出清晰的状态或循环不变量，再补边界条件。笔试里速度重要，但我不会一上来就写代码，会先用一两分钟确认数据规模和复杂度目标。
