# 大模型

本目录回答“LLM/VLM 是什么、由哪些结构组成、如何表示输入并生成输出”。内容覆盖 Attention、Transformer、模型架构、预训练与生成机制、视觉多模态模型及相关应用问题；大模型发展史作为跨目录总览放在当前层。

本目录聚焦模型结构、生成机制和模型系列演进；优化器、训练并行、稳定性及 SFT/DPO/PPO/GRPO 归入 [03_训练优化与对齐](<../03_训练优化与对齐/README.md#训练优化与对齐>)，数据、指标与实验设计归入 [04_评测实验与数据质量](<../04_评测实验与数据质量/README.md#评测实验与数据质量>)，推理引擎、Serving 与部署归入 [05_推理部署与系统](<../05_推理部署与系统/README.md#推理部署与系统>)。
