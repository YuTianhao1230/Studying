本目录整理大模型应用中的典型能力、问题和工程方法，重点是把 RAG、CoT、Prompt、幻觉等概念和实际系统设计联系起来。

## 学习路线

1. 先看 [NLP与大语言模型.md](<NLP与大语言模型.md>) 建立应用总览。
2. 再看 [prompt调优.md](<prompt调优.md>)、[CoT.md](<CoT.md>)，理解输入侧和推理侧增强。
3. 接着看 [RAG.md](<RAG.md>)，理解外部知识接入。
4. 最后看 [Model Hallucination.md](<Model Hallucination.md>)，复习大模型可靠性问题。
