# T5

## 知识点解析

### 概述

T5 是 Encoder-Decoder Transformer 模型，核心思想是把所有 NLP 任务统一成 text-to-text 格式，用同一套输入输出接口完成翻译、摘要、分类、问答和生成任务。

### 解决的问题

T5 之前，不同 NLP 任务往往有不同建模方式：分类接分类头，问答预测 span，摘要用 seq2seq。T5 解决的是任务形式割裂问题，把所有任务写成：

```text
input text  -> output text
```

例如：

```text
translate English to German: That is good.
  -> Das ist gut.

mnli premise: ... hypothesis: ...
  -> entailment
```

### 典型模型规格

| 版本 | 层数 | hidden size | heads | 参数量 |
| --- | --- | --- | --- | --- |
| T5-Small | 6 encoder + 6 decoder | 512 | 8 | 约 60M |
| T5-Base | 12 encoder + 12 decoder | 768 | 12 | 约 220M |
| T5-Large | 24 encoder + 24 decoder | 1024 | 16 | 约 770M |
| T5-3B | 24 encoder + 24 decoder | 1024 | 32 | 约 3B |
| T5-11B | 24 encoder + 24 decoder | 1024 | 128 | 约 11B |

不同实现细节可能略有差异，面试时重点讲清 Encoder-Decoder 和 text-to-text 统一范式。

### 完整架构

```text
input task prefix + input text
  -> SentencePiece tokenization
  -> shared token embedding
  -> Transformer Encoder stack
       -> bidirectional self-attention
       -> FFN
  -> encoder hidden states

decoder input
  -> Transformer Decoder stack
       -> causal self-attention
       -> cross-attention over encoder states
       -> FFN
  -> LM head
  -> output text
```

T5 使用相对位置偏置，而不是原始 Transformer 的正弦位置编码。

### 训练目标

T5 的预训练目标是 span corruption：

```text
original: Thank you for inviting me to your party last week.
corrupt:  Thank you <X> me to your party <Y> week.
target:   <X> for inviting <Y> last <Z>
```

模型学习根据上下文恢复被替换的文本 span。相比逐 token mask，span corruption 更接近生成式补全。

### 做了什么改变

相比 BERT：

- BERT 是 encoder-only，输出表示；T5 是 encoder-decoder，直接生成文本。
- BERT 用 MLM，T5 用 span corruption。
- BERT 下游任务通常接任务头，T5 用文本输出统一任务。

相比 GPT：

- GPT 只用 decoder 自回归生成。
- T5 有 encoder 充分理解输入，再由 decoder 生成输出。
- T5 对输入输出边界明确的条件生成任务更自然。

### 适用场景

- 翻译、摘要、改写。
- 文本分类但希望统一成文本标签输出。
- 问答和结构化生成。
- 多任务 instruction tuning 的早期框架，如 FLAN-T5。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 架构题 | T5 和 GPT/BERT 区别 | T5 是 encoder-decoder，BERT 是 encoder-only，GPT 是 decoder-only |
| 目标题 | span corruption 是什么 | 输入替换 span，目标生成被替换片段 |
| 范式题 | text-to-text 有什么好处 | 任务接口统一，分类也可生成标签文本 |
| 选型题 | 什么时候用 T5 | 翻译、摘要、条件生成、输入输出边界明确 |

### 易错点

- 把 T5 当成只做摘要的模型；它是统一 text-to-text 框架。
- 把 T5 的 decoder-only 说成 GPT 式架构；T5 有 encoder 和 decoder。
- 忽略 task prefix，它是 T5 区分任务的重要方式。

## 面试应对

### T5 的核心思想和架构是什么？

回答思路：用 text-to-text 统一范式串起架构和训练目标。

回答模板：

T5 的核心思想是把所有 NLP 任务统一成 text-to-text：输入是带任务前缀的文本，输出也是文本。架构上它是 Encoder-Decoder Transformer，Encoder 用双向 self-attention 编码输入，Decoder 用 causal self-attention 和 cross-attention 自回归生成输出。T5-Base 是 12 层 encoder 加 12 层 decoder，hidden size 768，12 个 heads，约 220M 参数。预训练时使用 span corruption，把连续片段替换成 sentinel token，再让模型生成被替换的片段。
