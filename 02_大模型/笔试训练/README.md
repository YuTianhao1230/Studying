# 大模型笔试训练

## 概述

本目录将大模型知识整理为架构理解、推理效率、预训练生成、应用和多模态方向的选择题、公式题、计算题、场景判断题和判断题。题目均为自编训练题，不标记为具体单位真题。

基础架构是本分支的重点，相关题目约占总题量 60%，重点训练 Attention、位置编码、归一化、KV Cache、GQA/MLA、MoE 和推理性能之间的关系。

## 使用方法

1. 先完成两份基础架构题集，再做预训练和应用题集。
2. 结构题先画出数据流，计算题先写变量和张量形状。
3. 推理题同时判断计算量、显存、通信、延迟和吞吐，不只比较参数量。
4. RAG、多模态和模型选型题先判断业务目标，再选择技术方案。
5. 把错误回链到对应知识卡片，一周后进行四个专项的混合训练。
