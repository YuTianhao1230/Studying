# 高效架构与推理训练

## 说明

本组题重点覆盖 KV Cache、Prefill/Decode、MHA/MQA/GQA/MLA、MoE、Dense Model、长上下文、FlashAttention、量化和推理服务。题目为自编训练题，优先训练显存、计算、通信、延迟和吞吐之间的关系。

## 选择题

### 1. 自回归 Decode 阶段使用 KV Cache 的主要作用是（ ）

A. 缓存历史 Token 的 Key/Value，避免每步重复计算历史部分  
B. 缓存所有未来 Token  
C. 只缓存最终 Logits  
D. 删除当前 Query

**答案：A**

**解析：** 历史位置的 K/V 在后续生成中不变，可以缓存；当前步的 Query 仍需根据最新隐藏状态计算。

### 2. Prefill 阶段与 Decode 阶段的典型差异是（ ）

A. Prefill 可并行处理输入上下文，Decode 通常逐 Token 生成  
B. Prefill 不产生 KV Cache  
C. Decode 可以一次生成任意多 Token 而不依赖前一步  
D. 两个阶段计算完全相同

**答案：A**

**解析：** Prefill 处理已有 Prompt，适合矩阵并行；Decode 每步依赖新生成 Token，通常受单步延迟和内存带宽限制。

### 3. MHA、MQA、GQA 的主要差异集中在（ ）

A. Query 头数与 Key/Value 头数的共享方式  
B. 是否使用词表  
C. 是否需要训练数据  
D. 是否能计算 Softmax

**答案：A**

**解析：** MHA 通常每个 Query 头有独立 K/V，MQA 共享一组 K/V，GQA 将 Query 头分组共享多组 K/V。

### 4. MQA 相比 MHA 通常能够（ ）

A. 显著减少 KV Cache 大小和 Decode 访存  
B. 增加 K/V 头数  
C. 消除所有计算  
D. 使模型不再需要 Query

**答案：A**

**解析：** MQA 只保留一组 K/V，历史缓存显著变小，但过度共享可能损失模型表达能力。

### 5. GQA 的典型设置是（ ）

A. 多个 Query 头共享一个或一组 Key/Value 头  
B. 每个 Query 头都必须拥有两个独立 K/V  
C. 只有一个 Query 头且没有 K/V  
D. 只用于卷积网络

**答案：A**

**解析：** GQA 在 MHA 和 MQA 之间折中，用较少 K/V 头降低缓存和带宽成本，同时保留多组 K/V 表达能力。

### 6. 若 Query 头数为 32、KV 头数为 8，GQA 中每组 KV 通常对应（ ）

A. 2 个 Query 头  
B. 4 个 Query 头  
C. 8 个 Query 头  
D. 32 个 Query 头

**答案：B**

**解析：** `32/8=4`，每组 KV 被 4 个 Query 头共享。

### 7. MLA 的核心思路更接近于（ ）

A. 将 KV 表示压缩到低维 latent，再在需要时恢复或参与注意力计算  
B. 为每个 Token 增加完整的独立大矩阵  
C. 删除所有位置信息  
D. 用随机路由替代 Attention

**答案：A**

**解析：** MLA 通过低秩潜变量压缩 KV 表示，目标是降低推理时 KV Cache 和带宽成本。

### 8. MLA 中采用解耦位置编码的主要动机是（ ）

A. 在压缩内容表示的同时保留位置关系建模能力  
B. 让所有 Token 共享同一位置  
C. 取消 Q/K 点积  
D. 只服务于图像分类

**答案：A**

**解析：** 内容压缩和位置编码存在耦合难题，解耦设计使模型能够分别处理压缩内容信息和位置关系。

### 9. MoE 模型中的 Router 主要负责（ ）

A. 为每个 Token 选择或分配要激活的专家  
B. 生成所有最终文本  
C. 只负责词表初始化  
D. 替代 Tokenizer

**答案：A**

**解析：** Router 根据 Token 表示计算专家选择权重，稀疏激活少量专家完成 FFN 计算。

### 10. MoE 中“总参数量”和“激活参数量”的关系通常是（ ）

A. 总参数量可以很大，但每个 Token 只激活部分专家参数  
B. 二者永远相等  
C. 激活参数量一定大于总参数量  
D. MoE 没有专家参数

**答案：A**

**解析：** MoE 将参数分布到多个专家，单个 Token 只经过 Top-k 专家，因此总容量和单 Token 计算量可以分离。

### 11. MoE 训练中的负载均衡损失主要用于（ ）

A. 防止大量 Token 集中到少数专家  
B. 提高词表大小  
C. 删除通信  
D. 让所有专家参数完全相同

**答案：A**

**解析：** 路由塌缩会造成专家过载、其他专家闲置和训练不稳定，负载均衡机制鼓励更均匀的 Token 分配。

### 12. MoE 的 capacity factor 或容量限制主要用于（ ）

A. 限制每个专家接收的 Token 数，避免局部过载  
B. 增加每个 Token 激活的专家数到全部专家  
C. 改变位置编码  
D. 计算 BLEU

**答案：A**

**解析：** 专家容量限制可以控制显存和通信，但容量不足时可能发生 Token 丢弃或溢出处理。

### 13. Dense Model 与 MoE 的典型区别是（ ）

A. Dense 模型对每个 Token 通常激活同一套完整参数，MoE 只激活部分专家  
B. Dense 模型没有 FFN  
C. MoE 不能训练  
D. Dense 模型没有推理成本

**答案：A**

**解析：** Dense 计算路径固定且通信简单，MoE 通过稀疏激活扩大总参数容量，但引入路由和通信复杂度。

### 14. MoE 在多卡训练中可能引入额外的（ ）

A. Token dispatch 和 All-to-All 通信  
B. 词表排序  
C. 单机磁盘格式转换  
D. 位置编码查表

**答案：A**

**解析：** Token 可能需要发送到不同设备上的专家，跨卡 dispatch 和回收会增加通信开销。

### 15. KV Cache 的显存占用随生成上下文长度通常（ ）

A. 近似线性增长  
B. 始终不变  
C. 随长度立方增长  
D. 只由词表大小决定

**答案：A**

**解析：** 每增加一个 Token，就需要保存其 K/V 表示，因此缓存空间通常与层数、KV 头数、头维度和序列长度线性相关。

### 16. FlashAttention 的主要优化方向是（ ）

A. 通过分块和 IO-aware 计算减少 Attention 中间矩阵的显存读写  
B. 把 Attention 的数学结果改成随机近似  
C. 删除 Q/K/V  
D. 只在 CPU 上运行

**答案：A**

**解析：** FlashAttention 通常保持精确 Attention 数学结果，通过 tiling 和片上存储减少 HBM 读写，不改变标准复杂度阶数。

### 17. 长上下文的标准全注意力主要瓶颈是（ ）

A. 注意力矩阵随序列长度二次增长，且 KV Cache 也变大  
B. 词表自动变小  
C. 参数量一定为零  
D. 只增加输出层计算

**答案：A**

**解析：** Prefill 阶段有 `O(n^2)` 注意力关系，Decode 阶段还要读取更长 KV Cache，带来计算、显存和带宽压力。

### 18. Paged Attention 主要针对推理服务中的（ ）

A. KV Cache 动态分配和显存碎片问题  
B. 训练标签平滑  
C. 词表构建  
D. 图像增强

**答案：A**

**解析：** 将 KV Cache 按块管理可以提高动态请求场景中的显存利用率，减少连续大块分配要求。

### 19. 推理服务中 Continuous Batching 的主要作用是（ ）

A. 动态合并不同请求的进行中序列，提高 GPU 利用率  
B. 等所有请求结束后再统一处理  
C. 只服务一个固定长度请求  
D. 禁止请求退出

**答案：A**

**解析：** Continuous Batching 可以在请求完成和新请求到达时动态调整批次，提升吞吐并减少空闲。

### 20. Prefill 和 Decode 的性能指标侧重点通常不同，正确的是（ ）

A. Prefill 更关注首 Token 延迟和吞吐，Decode 更容易受单 Token 延迟与内存带宽影响  
B. 两者都只看参数量  
C. Decode 永远比 Prefill 更易并行  
D. Prefill 不消耗显存

**答案：A**

**解析：** Prefill 处理大块输入，通常计算密集；Decode 逐步生成，常受访存、KV Cache 和调度影响。

### 21. 量化可以降低推理成本，主要因为（ ）

A. 使用更低位宽表示权重、激活或 KV Cache，减少存储和带宽  
B. 让模型不再需要矩阵乘法  
C. 自动增加训练数据  
D. 使所有误差变为零

**答案：A**

**解析：** 量化减少数据表示位宽，可降低显存占用和访存量，但可能产生精度损失，需要校准或量化感知训练。

### 22. Speculative Decoding 的基本思想是（ ）

A. 用较快的小模型提出候选，再由目标大模型并行验证  
B. 只使用小模型而不验证  
C. 将大模型参数全部删除  
D. 让每步只生成随机 Token

**答案：A**

**解析：** 草稿模型提出多个候选，目标模型验证并接受其中一部分，在保证目标分布一致性的前提下减少逐 Token 等待。

### 23. GQA 相比 MHA 通常会带来（ ）

A. 更小的 KV Cache 和较低的 Decode 带宽，但可能有表达能力权衡  
B. 更大的 KV Cache 且没有任何代价  
C. 完全取消 Query 头  
D. 只能用于 Encoder

**答案：A**

**解析：** 减少 KV 头数可以降低缓存和访存，但共享 K/V 也可能影响模型质量，需要在任务和规模上验证。

### 24. Decode 阶段对单个新 Token 使用 KV Cache 时，通常不需要（ ）

A. 重新计算历史所有 Token 的 K/V  
B. 计算当前 Token 的 Q/K/V  
C. 用当前 Query 与缓存 K/V 做注意力  
D. 更新缓存

**答案：A**

**解析：** 历史 K/V 已缓存，当前步只需计算新 Token 的表示并追加新 K/V。

### 25. 当目标是提高并发推理吞吐时，合理的分析维度包括（ ）

A. KV Cache 显存、批处理策略、带宽、算力和请求长度分布  
B. 只看模型总参数量  
C. 只看词表大小  
D. 只看训练准确率

**答案：A**

**解析：** 生产推理是系统问题，需要同时考虑显存容量、访存、计算、调度和请求形态。

## 计算题与场景判断

### 26. 单层 MHA 的 KV Cache 使用 16 个 KV 头、每头维度 128、序列长度 2048、FP16（2 字节），同时缓存 K 和 V。该层缓存约占（ ）

A. 4 MiB  
B. 8 MiB  
C. 16 MiB  
D. 32 MiB

**答案：C**

**解析：** 元素数为 `2×16×128×2048`，字节数再乘 2，得到 `16,777,216` 字节，约 16 MiB；实际模型还要乘层数和 batch。

### 27. 若将上题的 KV 头数从 16 降到 8，其他条件不变，KV Cache 显存约变为原来的（ ）

A. 1/8  
B. 1/4  
C. 1/2  
D. 2 倍

**答案：C**

**解析：** KV Cache 对 KV 头数线性，16 降到 8 后占用变为 1/2，这正是 GQA 降低缓存的直接效果。

### 28. MoE 有 64 个等规模专家，每个 Token 只激活 Top-2 专家。忽略 Router 和通信，单 Token 专家 FFN 计算量约为所有专家都激活时的（ ）

A. 1/64  
B. 1/32  
C. 1/16  
D. 1/2

**答案：B**

**解析：** 只计算 2 个专家，比例为 `2/64=1/32`；实际还要考虑共享层、路由和通信开销。

### 29. 某请求的 KV Cache 已保存 2048 个 Token，继续生成到总长度 4096，其他设置不变。KV Cache 显存约变为原来的（ ）

A. 1/2  
B. 1 倍  
C. 2 倍  
D. 4 倍

**答案：C**

**解析：** KV Cache 对序列长度近似线性，长度翻倍时缓存占用也约翻倍。

### 30. 一个模型有 32 个 Query 头、8 个 KV 头、每头维度 128、序列长度 4096、FP16。GQA 相对 MHA 的 KV Cache 读取量约为（ ）

A. 1/2  
B. 1/4  
C. 1/8  
D. 4 倍

**答案：B**

**解析：** MHA 使用 32 个 KV 头，GQA 使用 8 个，比例为 `8/32=1/4`。

### 31. 若标准 Attention 的序列长度从 n 增加到 2n，忽略其他因素，QK^T 的计算量约变为（ ）

A. 2 倍  
B. 3 倍  
C. 4 倍  
D. 8 倍

**答案：C**

**解析：** Attention 的主要长度项为 `n^2`，因此 `(2n)^2/n^2=4`。

## 判断题

### 32. 使用 KV Cache 后，Decode 阶段不再需要任何 Attention 计算，只需查表即可。（ ）

**答案：错误。**

KV Cache 只避免历史 K/V 重算，当前 Query 仍需与缓存 K/V 计算注意力并生成新的输出。

### 33. MoE 的总参数量可以远大于单个 Token 的激活参数量。（ ）

**答案：正确。**

MoE 的专家参数总和很大，但稀疏路由使单个 Token 只经过少量专家。

### 34. FlashAttention 将标准全注意力的渐进长度复杂度从 O(n²) 变成 O(n)。（ ）

**答案：错误。**

FlashAttention 主要优化显存读写和中间矩阵存储，标准精确 Attention 的主要计算复杂度阶数仍是 O(n²)。

### 35. 低比特量化一定不会造成模型质量下降，因为它只改变存储格式。（ ）

**答案：错误。**

量化会改变数值表示精度，可能影响输出质量，需要通过校准、量化策略和任务评测验证影响。
