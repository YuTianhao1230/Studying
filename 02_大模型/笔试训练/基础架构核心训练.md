# 基础架构核心训练

## 说明

本组题覆盖 Transformer、Self-Attention、Q/K/V、Multi-Head Attention、Decoder-only、自回归建模、位置编码、RoPE、Pre-Norm/Post-Norm 和 RMSNorm。题目为自编训练题，重点训练结构辨析、张量形状和复杂度计算。

## 选择题

### 1. Transformer 相比 RNN 在训练阶段的一个主要优势是（ ）

A. 可以对序列位置完全不建模  
B. 同一序列的多个位置可以并行计算  
C. 不需要任何参数  
D. 只能处理单个 Token

**答案：B**

**解析：** Self-Attention 在训练时可以同时计算所有位置的表示，而 RNN 通常依赖前一时刻隐状态，难以完全并行。

### 2. Scaled Dot-Product Attention 的标准形式是（ ）

A. `softmax(QK^T/sqrt(d_k))V`  
B. `softmax(Q+K)V`  
C. `QKV/sqrt(d_model)`  
D. `softmax(VQ^T)K`

**答案：A**

**解析：** 注意力先计算 Q 与 K 的相似度，再除以 `sqrt(d_k)`、softmax 归一化，最后对 V 加权聚合。

### 3. Attention 分数除以 `sqrt(d_k)` 的主要原因是（ ）

A. 降低点积随维度增大而导致的数值尺度，避免 softmax 过度饱和  
B. 删除 Query 向量  
C. 把注意力复杂度变为常数  
D. 让所有 Value 变成单位向量

**答案：A**

**解析：** Q、K 的点积方差会随维度增长，缩放可以使 softmax 输入尺度更稳定，改善梯度。

### 4. 对一个查询位置，Attention 的 softmax 权重通常满足（ ）

A. 和为 0  
B. 和为 1 且非负  
C. 全部相同  
D. 可以出现任意负数

**答案：B**

**解析：** softmax 将分数转为非负概率权重，单个查询位置对应的权重和为 1。

### 5. Multi-Head Attention 的主要作用之一是（ ）

A. 让不同头在不同表示子空间中捕捉关系  
B. 让所有头共享完全相同的 Q/K/V  
C. 删除位置编码  
D. 把序列压缩为一个 Token

**答案：A**

**解析：** 多头将表示分到多个子空间，能够并行学习不同类型的依赖关系，再拼接并线性变换。

### 6. 原始 Self-Attention 本身对输入序列的顺序缺少敏感性，因此通常需要（ ）

A. 位置编码或位置偏置  
B. 随机删除 Token  
C. 只保留第一个 Token  
D. 把所有 Token 排序

**答案：A**

**解析：** 不加入位置信息时，注意力主要依据内容相似度，无法区分相同 Token 的不同位置。

### 7. Decoder-only Transformer 在自回归生成时使用因果 Mask，主要为了（ ）

A. 阻止当前位置看到未来 Token，避免训练目标泄漏  
B. 让每个位置只能看到自己  
C. 删除所有历史信息  
D. 让训练不能并行

**答案：A**

**解析：** 第 t 个位置只能访问不晚于 t 的信息，保证训练目标与生成时的信息条件一致。

### 8. Encoder Self-Attention 与 Decoder Cross-Attention 的主要区别是（ ）

A. Cross-Attention 的 Query 来自 Decoder，Key/Value 通常来自 Encoder 输出  
B. Cross-Attention 不需要 Query  
C. Encoder 只能使用单个 Token  
D. 两者都必须使用同一组隐藏状态

**答案：A**

**解析：** Encoder-Decoder 结构中，Decoder 通过 Cross-Attention 读取 Encoder 编码的输入表示。

### 9. Encoder-only、Decoder-only 和 Encoder-Decoder 的典型对应关系是（ ）

A. BERT、GPT、T5  
B. GPT、BERT、T5  
C. T5、BERT、GPT  
D. GPT、T5、BERT

**答案：A**

**解析：** BERT 主要是 Encoder-only，GPT 主要是 Decoder-only，T5 使用 Encoder-Decoder。

### 10. 自回归语言模型对长度为 T 的序列的联合概率通常分解为（ ）

A. `P(x_1:T)=prod_t P(x_t|x_<t)`  
B. `P(x_1:T)=prod_t P(x_t)` 且没有条件  
C. `P(x_1:T)=sum_t P(x_t)`  
D. `P(x_1:T)=P(x_T|x_1)`

**答案：A**

**解析：** 链式法则将序列概率分解为每个 Token 在此前缀条件下的条件概率。

### 11. Decoder-only 模型训练时可以并行计算多个位置的 next-token loss，原因是（ ）

A. 因果 Mask 同时约束所有位置，矩阵运算可以并行  
B. 训练时模型可以看到标签未来信息  
C. 训练不需要目标 Token  
D. 生成阶段也能同时生成所有 Token

**答案：A**

**解析：** 训练时整段序列已知，因果 Mask 保证每个位置只能看前文，因此各位置的前向计算可批量并行；生成仍需逐步解码。

### 12. Teacher Forcing 的含义通常是（ ）

A. 训练下一位置时使用真实历史 Token，而不是模型刚生成的历史 Token  
B. 推理时强制输出正确答案  
C. 删除训练标签  
D. 只训练 Encoder

**答案：A**

**解析：** Teacher Forcing 能提高训练效率，但训练和推理之间可能存在 exposure bias。

### 13. Pre-Norm Transformer 通常将归一化放在（ ）

A. 子层输入、残差计算之前  
B. 所有模型输出之后且没有残差  
C. Tokenizer 之前  
D. 只放在最终分类头

**答案：A**

**解析：** Pre-Norm 常写成 `x + Sublayer(Norm(x))`，为深层网络提供更直接的残差和梯度路径。

### 14. Post-Norm Transformer 的典型形式是（ ）

A. `Norm(x + Sublayer(x))`  
B. `x + Norm(x)` 且没有子层  
C. `Sublayer(Norm(x))` 且没有残差  
D. `Norm(x)` 后直接输出 Token

**答案：A**

**解析：** Post-Norm 在残差相加之后归一化，原始 Transformer 常采用这种结构。

### 15. Pre-Norm 相较 Post-Norm 的常见训练特点是（ ）

A. 深层训练通常更稳定、对 warmup 依赖可能较低  
B. 一定具有更高最终精度  
C. 完全不需要残差连接  
D. 不能使用 Attention

**答案：A**

**解析：** Pre-Norm 的梯度传播路径更直接，但最终性能和收敛特性仍与初始化、学习率和模型规模有关，不能绝对化。

### 16. RMSNorm 与 LayerNorm 的核心区别是（ ）

A. RMSNorm 通常只按均方根缩放，不减均值  
B. RMSNorm 必须计算 batch 均值  
C. LayerNorm 不包含方差  
D. 两者完全没有可学习参数

**答案：A**

**解析：** LayerNorm 会减均值并按方差归一化，RMSNorm 主要根据均方根进行缩放，计算更简化。

### 17. 残差连接在 Transformer 中的重要作用之一是（ ）

A. 提供恒等路径，改善深层网络的梯度传播  
B. 使所有层参数共享  
C. 把 Attention 变成卷积  
D. 删除 FFN

**答案：A**

**解析：** 残差连接让子层学习增量，保留原输入信息并缓解深层优化困难。

### 18. FFN/MLP 子层在 Transformer 中主要负责（ ）

A. 对每个位置独立进行非线性特征变换  
B. 只负责跨位置复制 Token  
C. 存储 KV Cache  
D. 完成 Tokenizer 分词

**答案：A**

**解析：** FFN 通常对每个位置分别应用升维、非线性和降维，提供位置内的通道混合能力。

### 19. 长度为 n、隐藏维度为 d 的标准全注意力，其主要注意力矩阵计算复杂度随长度通常是（ ）

A. `O(n)`  
B. `O(log n)`  
C. `O(n^2 d)`  
D. `O(d^2)` 与 n 无关

**答案：C**

**解析：** QK^T 需要构造 n×n 的位置关系，主要复杂度约为 `O(n^2 d)`，也是长上下文瓶颈之一。

### 20. 没有位置编码的 Self-Attention 更准确的性质是（ ）

A. 对输入排列具有等变性，而不是天然理解绝对顺序  
B. 自动知道文本从左到右  
C. 必然使用因果 Mask  
D. 只能处理图像

**答案：A**

**解析：** 内容相同但位置置换时，输出会按同样方式置换；模型本身并不因此获得顺序信息。

### 21. Decoder-only 模型适合统一处理生成、问答和代码补全，主要因为（ ）

A. 不同任务都可以转化为条件序列的 next-token prediction  
B. 它不需要训练数据  
C. 它不需要 Attention  
D. 它只能输出固定长度

**答案：A**

**解析：** 通过 Prompt 和目标序列格式，分类、问答、翻译、代码等任务都可以统一为序列生成。

### 22. 自回归生成与训练的主要差异是（ ）

A. 训练已知整段目标且可并行，生成需要逐 Token 使用前一步结果  
B. 训练不能计算 loss，生成可以  
C. 生成不需要概率分布  
D. 两者完全相同

**答案：A**

**解析：** 训练阶段使用 teacher forcing 和因果 Mask，推理阶段每步生成一个 Token 并追加到上下文。

### 23. RoPE 将位置信息注入到（ ）

A. Query 和 Key 的旋转表示中  
B. 只有 Value 中  
C. 词表 ID 中且不改变 Q/K  
D. 只注入最终输出层

**答案：A**

**解析：** RoPE 对 Q、K 的二维子空间进行与位置相关的旋转，使点积中体现相对位置信息。

### 24. RoPE 的一个重要性质是（ ）

A. 旋转后的 Q/K 内积可以体现相对位置差  
B. 所有位置的编码完全相同  
C. 它只支持绝对位置查表  
D. 它会删除 Token 语义

**答案：A**

**解析：** 位置相关旋转的组合关系使 Q_i 与 K_j 的内积依赖相对位置关系，同时保留内容向量的结构。

### 25. 关于 LSTM 与 Transformer 的说法正确的是（ ）

A. LSTM 通过门控递归处理序列，Transformer 更适合训练阶段并行建模长距离依赖  
B. LSTM 完全没有状态  
C. Transformer 不能处理序列  
D. 二者都必须逐 Token 训练

**答案：A**

**解析：** LSTM 使用隐状态和门控缓解 RNN 的长期依赖问题，Transformer 用 Attention 建模全局关系并支持更高的训练并行度。

## 计算题与结构判断

### 26. 输入序列长度为 5，隐藏维度为 8，单头 Self-Attention 的 Q、K、V 形状分别是（ ）

A. 都是 `5×8`  
B. 都是 `8×5` 且不能转置  
C. 都是 `5×5`  
D. 都是 `8×8`

**答案：A**

**解析：** 每个位置对应一个 8 维表示，长度为 5 的序列形成 `5×8` 的 Q、K、V 矩阵；QK^T 才得到 `5×5` 分数矩阵。

### 27. 单头 Attention 的 Key 维度 `d_k=64`，计算 QK^T 后应除以（ ）

A. 4  
B. 8  
C. 16  
D. 64

**答案：B**

**解析：** 缩放因子为 `sqrt(d_k)=sqrt(64)=8`。

### 28. 长度为 4 的因果 Attention 中，若每个位置都能看到自己和之前的位置，可见位置总数是（ ）

A. 4  
B. 7  
C. 10  
D. 16

**答案：C**

**解析：** 可见数量为 `1+2+3+4=10`，对应下三角区域；完整无 Mask 矩阵有 16 个位置。

### 29. 一个 MHA 的隐藏维度为 8，忽略 bias，Q/K/V/输出四个线性层均为 `8×8` 矩阵，参数总数是（ ）

A. 64  
B. 128  
C. 192  
D. 256

**答案：D**

**解析：** 四个矩阵各有 `8×8=64` 个参数，总数为 `4×64=256`。

### 30. 对长度为 3 的序列做自回归分解，若三个条件概率分别为 0.5、0.25、0.1，则该序列的联合概率是（ ）

A. 0.0125  
B. 0.025  
C. 0.085  
D. 0.85

**答案：A**

**解析：** 链式分解下联合概率为 `0.5×0.25×0.1=0.0125`。

### 31. 在二维位置向量 `[1,0]` 上施加 90° 逆时针旋转，得到（ ）

A. `[1,0]`  
B. `[0,1]`  
C. `[-1,0]`  
D. `[0,-1]`

**答案：B**

**解析：** 二维旋转矩阵作用后，`[1,0]` 变为 `[cos90°,sin90°]=[0,1]`；RoPE 在多组二维子空间中执行类似旋转。

## 判断题

### 32. 没有位置编码的 Self-Attention 对输入排列具有等变性，因此不会自动理解 Token 的绝对顺序。（ ）

**答案：正确。**

内容注意力本身不提供顺序信息，位置编码或位置偏置负责补充位置信息。

### 33. Decoder 的因果 Mask 能阻止位置 t 读取未来位置的 Token，从而避免 next-token 训练中的目标泄漏。（ ）

**答案：正确。**

Mask 使第 t 个位置只能访问不晚于 t 的信息，保证训练条件与自回归生成一致。

### 34. Pre-Norm 在任何模型规模、学习率和训练设置下都一定比 Post-Norm 最终精度高。（ ）

**答案：错误。**

Pre-Norm 通常更有利于深层训练稳定性，但最终精度还取决于初始化、优化器、数据和模型结构，不能绝对化。

### 35. RMSNorm 的核心操作是先减去均值，再除以标准差，因此与 LayerNorm 完全相同。（ ）

**答案：错误。**

RMSNorm 通常不做均值中心化，主要根据均方根缩放，并保留可学习的缩放参数。
