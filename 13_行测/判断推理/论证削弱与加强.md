# 论证削弱与加强

## 知识点解析

### 概述

论证题考查论点、论据和论证关系。削弱题要找能让论点不成立或论据无法支持论点的选项；加强题要找能让论据更能推出论点的选项。解题第一步必须找论点，不能只看题干材料中的背景信息。常见技巧是先看结论词，如“因此、说明、认为、由此可见”。

### 论证结构

```text
论据 -> 论证桥梁 -> 论点
```

论点是作者要证明的结论，论据是支持结论的事实或理由，桥梁是论据和论点之间隐含的关系。

### 削弱力度

| 力度 | 类型 | 说明 |
| --- | --- | --- |
| 最强 | 否定论点 | 直接说明结论不成立 |
| 强 | 拆桥 | 切断论据和论点之间的联系 |
| 中 | 否定论据 | 说明论据本身不可靠 |
| 弱 | 他因削弱 | 给出其他原因解释现象 |

### 加强力度

| 力度 | 类型 | 说明 |
| --- | --- | --- |
| 最强 | 搭桥 | 建立论据到论点的必要联系 |
| 中 | 补充论据 | 增加支持结论的新事实 |
| 较弱 | 解释原因 | 解释为什么论点可能成立 |

### 前提假设

前提假设题常问“以下哪项是上述论证成立所必须假设的”。判断方法是“否定代入”：把选项否定后代回题干，如果论证立刻崩掉，该选项就是必要前提。

## 笔试应对

### 常考题型

- 问最能削弱或最能加强的一项。
- 问论证成立的前提。
- 问解释某种矛盾现象。
- 选项偷换论点、只攻击背景或只讨论无关对象。

### 解题方法

先找论点，再找论据，最后判断选项攻击或支持的是论点、论据还是桥梁。削弱优先选否定论点或拆桥，加强优先选搭桥。

### 易错点

- 没找论点就看选项。
- 选择了只削弱论据细节但不影响论点的弱项。
- 他因削弱和拆桥混淆。
- 前提题没有用否定代入。
