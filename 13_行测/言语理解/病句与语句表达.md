# 病句与语句表达

## 知识点解析

### 概述

病句与语句表达是银行和运营商言语题中常见的补充题型，主要考查句子成分、搭配、语序、逻辑和表意完整性。常见病句包括成分残缺、搭配不当、语序不当、重复赘余、结构混乱、不合逻辑和主客体偷换。

### 常见病句类型

| 类型 | 判断方法 |
| --- | --- |
| 成分残缺 | 看主语、谓语、宾语是否完整 |
| 搭配不当 | 看主谓、动宾、定中是否能搭配 |
| 语序不当 | 看时间、范围、逻辑顺序 |
| 重复赘余 | 看是否重复表达同一含义 |
| 结构混乱 | 两套句式杂糅 |
| 不合逻辑 | 因果、递进、并列关系不成立 |
| 主客体混乱 | “对/使/由”引出的对象关系错误 |
| 两面对一面 | “是否/能否”与单一结果不匹配 |

### 快速检查顺序

1. 找主干：主语、谓语、宾语。
2. 看搭配：动词与宾语、形容词与中心词。
3. 看关联词：因为所以、虽然但是、不仅而且是否成对。
4. 看逻辑：因果、递进、并列、时间顺序是否合理。
5. 看限定词：是否、能否、至少、主要、通过等是否前后一致。

### 语句表达

常见题型包括语句排序、语句衔接、下文推断和句子改写。排序先定首句，再找指代和关联词捆绑；下文推断要承接文段最后一个话题，不能引入无关新主题。

## 笔试应对

### 常考题型

- 下列句子有语病/没有语病。
- 句子排序。
- 横线处语句衔接。
- 根据文段推断下文。

### 解题方法

先压缩句子主干，再检查搭配和逻辑；排序题先排除指代词、转折词开头的句子；下文推断重点看文段尾部话题、观点和未解决的问题。

### 易错点

- 只凭读起来顺不顺判断。
- 忽略“通过……使……”造成主语残缺。
- 忽略“是否/能否”造成两面对一面。
- 排序题只看单句，不看句间指代和话题连续。
