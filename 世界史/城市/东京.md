# 东京

## 位置与首都身份

东京是日本政治、经济与文化中心，中央政府主要机构和皇居所在地。常用“日本首都”称谓应与其法制和都市行政结构区分。

常用外文名：Tokyo。城市身份：旧称江户；1868年改称东京。

## 城市发展与历史联系

德川家康建立江户政治中心，幕府时期城市在武士、商人和水运网络中迅速发展。1868年江户改称东京，天皇迁入。

1923年关东大地震和第二次世界大战空袭造成巨大破坏。战后铁路与都市圈扩张，1964年奥运会成为现代城市建设的重要节点。

## 主要地区与地标

皇居位于原江户城区域，浅草、上野与现代商务区反映不同空间。东京不是单一“市”：东京都包括特别区、市町村与岛屿，都市圈又延伸到邻近县。

照片中的摩天楼代表现代发展，不是江户时代原貌。人口排名需明确东京都与整个都市圈的口径。

| 地点 | 位置与特点 | 阅读重点 |
| --- | --- | --- |
| 皇居与江户城遗址 | 现代政治文化中心与旧城址叠加 | 皇居不等于完整保存的幕府城堡，石垣、护城河与后建建筑年代不同 |
| 浅草与浅草寺 | 传统商业、寺院和游览地区 | 寺院建筑经历毁坏和重建，不能仅按最早建寺传说判断构件年代 |
| 上野 | 公园、博物馆与交通节点 | 博物馆收藏来源与建筑年代分开理解 |
| 东京塔与东京晴空塔 | 分别是两座不同的现代塔 | 东京塔在港区，晴空塔在墨田区，形态和建成年代不同 |
| 富士山与河口湖 | 东京西南方向及山北湖区 | 能从部分地点远望不等于山峰位于东京都中心 |

1923年震灾不仅造成建筑破坏，也伴随针对朝鲜人等群体的暴力，不能把历史后果只写为自然灾害与重建工程。战后高速增长、铁路通勤和1964年奥运建设共同改变城市规模，并非由单一活动创造整个现代东京。
