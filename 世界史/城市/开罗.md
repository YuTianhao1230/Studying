# 开罗

## 位置与首都身份

开罗是埃及首都，位于尼罗河谷进入三角洲的交会地带，是阿拉伯世界的重要政治、文化和人口中心。现代大开罗包含多个城市与行政区域，不能与开罗市本身完全等同。

常用外文名：Cairo。城市身份：969年法蒂玛王朝建城；周边聚落更早。

## 城市发展与历史联系

7世纪阿拉伯征服后，福斯塔特成为重要据点。969年法蒂玛王朝建立开罗；爱资哈尔清真寺与相关教育传统随后发展。萨拉丁时期的城堡、马穆鲁克时期的宗教建筑和奥斯曼时期的街区，构成旧城的历史层次。

19世纪以来，城市在传统街区之外建设新道路和行政空间；20世纪后继续扩张。吉萨金字塔位于尼罗河西岸的吉萨，不能简单说成开罗旧城中的建筑。

## 主要地区与地标

尼罗河、岛屿、旧城集市与现代道路共同塑造城市。历史开罗的清真寺、陵墓、学校与商贸街区反映伊斯兰时期城市生活；吉萨高原则属于古埃及遗产。

阅读城市时可把三条线分开：古埃及遗址、伊斯兰旧城、近现代首都建设。城市照片展示的是现代空间，不是法老时代城市原貌。

| 地点 | 位置与特点 | 与其他地点的区别 |
| --- | --- | --- |
| 历史开罗 | 清真寺、学校、陵墓与老街组成的历史城区 | 核心体现伊斯兰时期城市，不是吉萨金字塔建筑群 |
| 爱资哈尔 Al-Azhar | 清真寺与长期教育传统 | 建筑、教学机构和后来的大学体系应按各自发展理解 |
| 汗哈利利集市 Khan al-Khalili | 历史商贸街区 | 传统商业与现代旅游并置，并非所有摊铺都有中世纪连续经营记录 |
| 开罗城堡 | 萨拉丁时期起形成的防御和统治空间 | 城堡内穆罕默德·阿里清真寺属于更晚建设层次 |
| 吉萨金字塔与狮身人面像 | 尼罗河西岸吉萨高原的古埃及遗产 | 狮身人面像常与哈夫拉时代联系，但具体解释存在讨论 |

卢克索的卡纳克神庙、卢克索神庙与帝王谷在埃及更南部，不在开罗老城。埃及古代都城孟斐斯也不是969年法蒂玛王朝建立的开罗，两者应按地理与年代分别定位。
