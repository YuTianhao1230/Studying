# 德里

## 位置与首都身份

德里是印度重要都市和首都地区，新德里是其内部的国家首都与政府所在地。德里、旧德里、新德里不是完全相同的空间概念。

常用外文名：Delhi。城市身份：古代与中世纪城市群；新德里为印度首都。

## 城市发展与历史联系

德里地区存在多个不同时期的城市中心，德里苏丹国和莫卧儿王朝留下堡垒、清真寺和墓葬。沙贾汗建设沙贾汗纳巴德，构成旧德里的重要基础。

1911年英国宣布将殖民首都从加尔各答迁往德里，新德里于1931年举行落成仪式。1947年独立与分治带来大量人口迁入和社会变化。

## 主要地区与地标

红堡、贾玛清真寺、顾特卜塔和胡马雍陵展现不同王朝；新德里的行政轴线体现殖民规划。城市范围持续扩大，不能用行政首都核心的面积或人口代表整个都市区。

阿格拉的泰姬陵不在德里市内，两座城市通过历史与交通相连但地理位置不同。

| 地点 | 时空定位 | 阅读重点 |
| --- | --- | --- |
| 顾特卜塔与建筑群 Qutb Minar | 德里南部，与苏丹国早期建筑传统关联 | 塔、清真寺及更早材料的利用属于不同问题 |
| 胡马雍陵 Humayun’s Tomb | 16世纪莫卧儿陵墓建筑群 | 花园与陵墓布局是后世建筑的重要参照，不是泰姬陵的别名 |
| 红堡与贾玛清真寺 | 沙贾汗时期旧德里空间 | 两处相邻但功能不同；红堡也不等于阿格拉堡 |
| 印度门 India Gate与行政轴线 | 新德里近现代规划区 | 原纪念阵亡军人，不能当作中世纪皇城城门 |
| 亚穆纳河 Yamuna | 德里相关河流，后汇入恒河 | 新德里不是恒河干流沿岸城市 |

德里保存的多座“历史城市”并不全在同一位置。把苏丹国遗址、莫卧儿旧城和新德里行政核心连成阅读顺序，能看到政权更替如何改变中心，而不是把所有建筑归为一个王朝。
