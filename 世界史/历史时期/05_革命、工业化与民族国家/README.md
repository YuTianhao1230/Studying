# 革命、工业化与民族国家

保留时期介绍与本期事件。时期介绍串联区域并行变化和人物，事件正文解释背景、阶段、结果与史料；跨期过程通过介绍页互链。

| [海地革命](<海地革命.md>) | 海地革命发生于法国殖民地圣多明各，以被奴役者起义为核心，最终建立独立的海地国家。 |
| [滑铁卢战役](<滑铁卢战役.md>) | 滑铁卢战役发生于今比利时，拿破仑军队与威灵顿指挥的盟军及布吕歇尔的普鲁士军队交战，最终法国战败。 |

| [美国独立战争](<美国独立战争.md>) | 美国独立战争发生于英国与北美十三殖民地之间，与更广泛的大西洋政治和帝国竞争联系。 |
