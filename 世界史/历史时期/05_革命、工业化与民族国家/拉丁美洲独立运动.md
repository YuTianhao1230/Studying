# 拉丁美洲独立运动

## 时空定位

18世纪末至19世纪前期，美洲不同殖民地经历独立与政权重组。重点包括西属美洲的革命战争及巴西1822年独立；海地革命另有权威正文，葡、西殖民地道路不能混同。

## 背景与起因

殖民税收、贸易与身份秩序引发矛盾，启蒙与先前革命提供思想资源。1808年拿破仑入侵伊比利亚造成王权危机，地方委员会与合法性争论推动变化。

克里奥尔精英、原住民、自由黑人、被奴役者和城市平民目标不同。不能把全体美洲居民写成早已拥有相同民族意识。

## 经过与转折

| 阶段 | 过程与转折 |
| --- | --- |
| 1808年以后 | 王权危机与地方政治组织发展，保王和独立阵营不断变化。 |
| 1810—1820年代 | 玻利瓦尔、圣马丁等领导的战争推进；墨西哥、中美洲和南美各自有重要过程。 |
| 1822年及以后 | 巴西以君主制独立；新国家边界、联邦与中央集权争论延续，1824年阿亚库乔战役是南美战争重要节点。 |

## 结果与影响

独立结束多个殖民政权的直接统治，却未消除土地、种族和阶层不平等。奴隶制废除时间因国而异，政治独立并不等于所有居民取得同等权利。

新国家在战争债务、资源、外贸和地方军政势力之间组织制度。玻利瓦尔设想的联合与实际国家分化需要区分。

后世纪念绘画塑造国家英雄，不能单凭画面核对行军路线、兵力与各参与者的贡献。
