# 妇女选举权运动

## 时空定位

妇女选举权运动推动女性取得投票与参选资格，19世纪以后形成多种组织和策略。各国、殖民地和不同社群取得权利的时间不同，不能用一个年份代表全球女性。

外文检索名：Women's suffrage。

## 背景与起因

财产、婚姻、教育和公民定义排斥女性，工业劳动、废奴及改革网络提供组织基础。运动内部存在阶级、种族和帝国立场分歧，并非所有人拥有同样诉求。

## 经过与转折

请愿、游说、报刊、游行和部分激进行动并行，组织选择取决于选举制度与镇压。战争改变女性劳动和政治环境，但不能说仅靠参战即自动换得权利。

| 时段 | 关键变化 |
| --- | --- |
| 19世纪 | 请愿、社团和公共写作扩大参政主张。 |
| 1893年 | 新西兰给予女性议会投票权，参选权更晚。 |
| 1918—1928年 | 英国先给予部分女性投票权，后与男性年龄条件一致。 |
| 1920年 | 美国第十九修正案禁止因性别剥夺投票权，但种族化障碍持续。 |
| 20世纪以后 | 更多国家改革，法律资格与实际参与继续存在差距。 |

## 结果与影响

投票、参选、实际登记与当选是不同层面。原住民、黑人和殖民地女性常面对额外门槛，法律改进与社群持续争取共同扩大参与。
