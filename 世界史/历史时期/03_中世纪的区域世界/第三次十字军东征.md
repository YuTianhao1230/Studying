# 第三次十字军东征

## 时空定位

第三次十字军东征通常指1189—1192年的远征，起于1187年萨拉丁胜利与耶路撒冷失陷后的拉丁基督教动员。主要君主包括腓特烈一世、腓力二世和理查一世；这里腓力二世指法国君主。

外文检索名：Third Crusade。

## 背景与起因

宗教使命、君主声望和地中海政治交织，穆斯林与拉丁阵营内部均有分歧。不能把两方写成完全统一的现代民族军队。

## 经过与转折

海运、补给、围城和君主间竞争影响远征，阿克俘虏遭处决显示暴力成本。理查没有重新夺取耶路撒冷，胜利海岸战役不等于所有目标达成。

| 时段 | 关键变化 |
| --- | --- |
| 1187年 | 哈丁战役和耶路撒冷失陷。 |
| 1189—1190年 | 欧洲军队东行，腓特烈一世在安纳托利亚死亡。 |
| 1191年 | 阿克陷落，理查一世在阿尔苏夫战役获胜。 |
| 1192年 | 和议保留部分沿岸拉丁控制，允许基督徒朝圣。 |

## 结果与影响

和议保障一部分朝圣与沿岸据点，阿尤布王朝保有耶路撒冷。战争、外交和商业联系继续，并非一次战斗决定后续整个地区。
