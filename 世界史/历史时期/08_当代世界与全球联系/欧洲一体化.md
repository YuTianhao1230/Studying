# 欧洲一体化

## 时空定位

欧洲一体化是二战后持续发展的区域制度建设，不只是1993年欧盟成立。煤钢共同体、经济共同体、欧盟、申根和欧元区成员并不完全重合，本卡归当代时期并保留1950年代的前史。

## 背景与起因

战争记忆、法德关系、重建、安全及市场需求推动合作。冷战、美国支持与各国国内政治提供条件，但不同国家对主权、经济和社会规则有不同目标。

## 经过与转折

| 阶段 | 过程与转折 |
| --- | --- |
| 1951—1957年 | 煤钢共同体与罗马条约建立共同体合作框架。 |
| 1992—1993年 | 马斯特里赫特条约签署、生效，欧盟形成。 |
| 1999—2002年 | 欧元先用于非现金交易，随后纸币硬币进入流通。 |
| 此后 | 扩员、金融与移民危机、英国2020年退出等显示合作会调整且并非单向扩大。 |

## 结果与影响

共同市场、法律、人员流动与区域资助深化联系，各国仍保留不同国家制度。欧盟不是整个欧洲，欧洲委员会也不是欧盟委员会。

申根处理边境旅行，欧元区处理共同货币，成员范围与加入时间需另查，不在卡中以永久固定名单代替动态资料。

一体化提供合作机制，也带来民主代表性、财政、发展差异和政策协调争论。和平的形成有多种条件，不能全部归因于单一组织。
