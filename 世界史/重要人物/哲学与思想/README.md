| [亚里士多德](<亚里士多德.md>) | 亚里士多德是古希腊哲学家，曾在柏拉图学园学习，后来创办吕克昂。他的研究涉及逻辑、伦理、政治、生物学、修辞和诗学。 |

| [苏格拉底](<苏格拉底.md>) | 苏格拉底是古雅典哲学家，以通过对话追问德性、知识和生活方式闻名。他没有留下可确认的亲笔哲学著作，主要形象来自学生与同时代作者。 |
| [笛卡尔](<笛卡尔.md>) | 笛卡尔是法国哲学家和数学家，长期在荷兰地区生活，晚年赴瑞典。 |
| [康德](<康德.md>) | 康德是启蒙时期哲学家，生活和任教于普鲁士柯尼斯堡，即今俄罗斯加里宁格勒。 |
| [伊本·赫勒敦](<伊本·赫勒敦.md>) | 伊本·赫勒敦是北非历史学家、思想家与政治事务参与者，生于突尼斯，曾在马格里布和安达卢斯活动，晚年在开罗任职。 |
| [马基雅维利](<马基雅维利.md>) | 尼科洛·马基雅维利，1469—1527年，是佛罗伦萨政治官员和思想家，著有《君主论》《论李维》和《战争艺术》。 |
| [亚当·斯密](<亚当·斯密.md>) | 亚当·斯密，1723—1790年，是苏格兰启蒙思想家，著有《道德情操论》和《国富论》。 |
