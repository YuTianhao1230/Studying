# 笛卡尔

## 人物简介

笛卡尔是法国哲学家和数学家，长期在荷兰地区生活，晚年赴瑞典。他以方法怀疑、心灵与身体问题及代数和几何的联系闻名。“我思故我在”属于寻求知识基础的论证，不能解释成只要主观想象某事就能使其成为现实。

常用外文名：René Descartes。年代：1596—1650年。

## 生平时间线

| 时间 | 经历与转折 |
| --- | --- |
| 1596年 | 生于法国拉埃，今城名笛卡尔。 |
| 青年时期 | 接受耶稣会学校教育，后学习法律并旅行。 |
| 1620年代后期起 | 长期居住在荷兰，开展哲学与科学写作。 |

## 重要活动与影响

### 方法怀疑的功能

他将感官错误、梦境等作为怀疑途径，以寻找不能被轻易推翻的认识起点。思考者在怀疑时仍进行思维活动，由此论述自身存在。论证与后续关于上帝、外部世界的论证应分开，不是简单宣布所有现实都虚假，也不是一般生活中拒绝所有经验。

### 心灵、身体与解释困难

笛卡尔把思维与广延分别作为心灵和物体的重要性质，形成著名的二元论问题：两者怎样相互作用？这是其体系中有争议的议题。现代神经科学并不自动验证他的具体身心理论，但相关问题继续影响哲学讨论。

### 解析几何与科学方法

《几何学》把几何问题与代数方程联系起来，给曲线和作图问题提供新的处理方式。今天教科书的直角坐标体系是后来标准化的结果，费马等人也有独立贡献，不能将全部解析几何记法都归给笛卡尔。数学方法与其物理学的具体结论也应分别评价。

### 出版与思想环境

宗教、大学和宫廷影响作品发表及接受。笛卡尔在得知伽利略事件后对部分出版采取谨慎态度。原著、通信和反对意见能够帮助理解论证发展；一条名言不能替代其整套知识体系。
