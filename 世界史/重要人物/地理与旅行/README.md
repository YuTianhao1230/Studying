# 地理与旅行

收录8位人物，从古代坐标地理、欧亚游记、跨洋航海到科学旅行。区分亲历、转述、文本传承与后世制图，不把现代国籍套用于古代人物。

## 内容索引

| 入口 | 内容说明 |
| --- | --- |
| [伊本·白图泰](<伊本·白图泰.md>) | 伊本·白图泰（Ibn Baṭṭūṭa，1304—约1368/1369）是出生于丹吉尔的穆斯林旅行者，其活动连接北非、西亚、东非、南亚等地区。精确去世年份和部分行程有不确定性，不能将所有游记段落都视为亲眼记录。 |
| [托勒密](<托勒密.md>) | 托勒密是罗马统治时期在亚历山大城活动的希腊语天文学家、数学家和地理学家。 |
| [马可·波罗](<马可·波罗.md>) | 马可·波罗是威尼斯商人和旅行叙述者。 |
| [麦哲伦](<麦哲伦.md>) | 麦哲伦是葡萄牙出生、后来受西班牙王室支持的航海领队。 |
| [亚历山大·冯·洪堡](<亚历山大·冯·洪堡.md>) | 洪堡是普鲁士自然研究者与科学旅行者，研究地理、植物、气候、地磁及地质等问题。 |
| [爱德华·蒂奇](<爱德华·蒂奇.md>) | 爱德华·蒂奇，约1680—1718年，通常称黑胡子，是18世纪初加勒比与北美沿岸海盗。 |
| [萨卡加维亚](<萨卡加维亚.md>) | 萨卡加维亚，约1788年出生，是肖肖尼女性，1805—1806年参与刘易斯与克拉克远征。 |
| [恩里克王子](<恩里克王子.md>) | 恩里克王子，1394—1460年，是葡萄牙王室成员和航海扩张赞助者，常称航海家亨利。 |
