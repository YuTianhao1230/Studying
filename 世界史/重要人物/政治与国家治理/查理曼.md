# 查理曼

## 人物简介

查理曼是加洛林王朝的法兰克国王，768—814年统治，800年在罗马被加冕为皇帝。他的出生年有742、747或748年等讨论，不能用现代法国或德国国籍概括其王权。

外文检索名：Charlemagne。现代地理定位：法国、德国、意大利；定位用于检索，不代表古代国籍或精确控制边界。

## 生平时间线

| 时段 | 活动与变化 |
| --- | --- |
| 768年 | 与弟弟卡洛曼分别继承法兰克王权。 |
| 774年 | 征服伦巴第王国，取得意大利王权。 |
| 772—804年 | 在多阶段战争中征服萨克森地区，伴随强制改宗与地方反抗。 |
| 800—814年 | 获得皇帝称号，继续治理与继承安排，814年去世。 |

## 重要活动与影响

### 征服与地方治理

伯爵、教会、王家使者及地方贵族合作支撑统治。行政依赖人员巡行、文书和地方义务，而非近代常设官僚体系；战争和宗教强制带来社会代价，不能只谈统一功绩。

### 教会与皇帝称号

与教皇合作改变西欧王权的宗教合法性，也引发与东罗马帝国的称号及外交关系。800年不是现代意义德法两国的建国日，也不等于后世神圣罗马帝国全部制度已完整形成。

### 教育与文本

阿尔昆、宫廷及修道院学校、抄写和加洛林小写体推动知识整理。所谓加洛林文艺复兴依靠多个机构与学者，不表示所有居民获得教育，更不是15世纪文艺复兴的同义词。
