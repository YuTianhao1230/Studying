# 巴贝奇

## 人物简介

巴贝奇是英国数学家、计算机械设计者和科学制度改革的参与者。他试图把航海、天文和工程所依赖的数表制作从人工计算转为机械运算，提出差分机与分析机两类不同方案。其历史位置在机械自动计算向通用可编程计算的转折处，不能简单等同于制造出第一台现代电子计算机。

常用外文名：Charles Babbage。年代：1791—1871年。

## 生平时间线

| 时间 | 经历与转折 |
| --- | --- |
| 1810—1814年 | 在剑桥学习，与赫歇尔、皮科克推动解析学会，介绍欧洲大陆的微积分方法。 |
| 1822年 | 公开展示以有限差分方法计算数表的小型机械装置。 |
| 1823年起 | 获得英国政府资助，尝试建设大型差分机；精密制造、经费和协作问题使工程停顿。 |

## 重要活动与影响

### 差分机为何能只用加法制作数表

对多项式的等间距取值反复作差，最终会得到常数差分。机器可以保存各阶差分，通过一系列加法逐行生成数值，减少人工抄算错误。这种专用方案与分析机的通用运算目标不同；差分机不是先执行任意程序再计算数表的现代电脑。

### 分析机的构件与可编程思想

分析机方案中的“仓库”负责保存数值，“磨坊”承担运算，打孔卡控制操作和数据输入。织机用孔位控制花纹的实践提供了重要启发。巴贝奇还讨论重复执行和条件控制，使设计超出单一公式计算。然而设计图、局部构件、后世按图制造的机器是三类不同证据，必须分开。

### 工业社会与工程失败

项目面对的是精密齿轮制造、公私资助和科学组织能力问题，而非只缺一项数学公式。巴贝奇与制造者约瑟夫·克莱门特的合作及冲突，说明机器概念需要工艺和项目治理才能落实。他的制造业著作还分析劳动分工、生产成本和机械化，连接计算史与工业革命。

### 如何评价历史影响

后世重建差分机展示了部分设计的可实施性，但不能据此断言19世纪就已有成熟计算产业。分析机与现代计算机有可比较的功能组织，也存在十进制机械部件、规模和速度方面的根本差异。其贡献应与洛夫莱斯、工匠、资助机构及后来独立发展的电子计算共同阅读。
