# 世界史知识卡片防劣化规范

## 1. 文档定位

本文件是 `/mlx_devbox/users/yutianhao/Studying/世界史/` 下历史知识卡片生成、补充、改写、拆分、合并、迁移和校对时的统一质量规范。处理本目录内容前，应先阅读本文件，再检查目标目录的 `README.md`、目标卡片和相关索引。

本目录用于历史兴趣阅读，不设置考题、自测、笔面试章节或背诵模板。正文应围绕明确的时间、空间、主体和证据展开，兼顾区域内部演变与跨区域联系。

涉及地图、时间线、人物关系图、图片、动态图、视频或在线交互资源时，还必须完整阅读并遵循根目录的[历史知识库可视化与外部资源规范](<../历史知识库可视化与外部资源规范.md>)。

## 2. 核心原则

1. 一个主题保留一个权威正文，其他位置使用相对链接。
2. 同时交代时间、地理范围、参与主体、因果链和历史结果。
3. 区分原始史料、考古证据、学术解释、民族记忆、传说与文学。
4. 不以欧洲历史代替世界史，也不机械追求各地区篇幅完全相等。
5. 不用现代国界、民族国家、种族分类或价值观直接套用古代社会。
6. 对译名、年代、地域边界和学术争议明确采用口径。

## 3. 一票否决项

出现以下任一问题，卡片不得视为完成：

- 编造年代、引文、人物关系、统计数字、地图边界或史料结论。
- 把神话、民族叙事、文学作品或后世宣传写成已证实史实。
- 将今天的国家、民族或宗教身份无条件回溯到形成之前。
- 只写事件结论或文明标签，没有解释形成条件、过程和变化。
- 以“先进/落后”“文明/野蛮”等单一价值标签替代具体历史分析。
- 比较不同地区时使用不同指标、不同时间尺度或不对称证据。
- 图片、地图、时间线与正文冲突，或未说明示意性质与时间截面。
- 新增卡片未加入最近一级 README，或迁移后留下断链和旧路径。
- 覆盖、回滚或清理来源不明的未提交改动。
- 留下空章节、占位符、聊天口吻、审计过程或未完成标记。

## 4. 目录与主题归属

世界史优先按以下层次组织：

| 层次 | 职责 |
| --- | --- |
| 时期总览 | 建立同一时期各区域并行发展的时间框架 |
| 区域与文明 | 讲清特定区域内部的政治、经济、社会、宗教与文化演变 |
| 人物 | 介绍人物生平、政治或文化环境、重要活动和史料记载 |
| 历史事件 | 叙述战争、迁徙、革命、改革、外交、制度和社会变化 |
| 跨区域专题 | 比较贸易、帝国、宗教传播、技术交流、殖民、全球化等联系 |
| 历史地理 | 说明政权范围、路线、人口移动和环境条件 |

同一事件涉及多个区域时保留一篇主卡，区域目录通过链接进入。跨区域专题负责比较和联系，不重复复制各区域历史正文。

## 5. 内容要求

### 5.1 时期与区域总览

总览应说明时间范围、地理范围、主要政治实体、社会经济特征、关键变化和与其他区域的联系。不得将某一帝国或某一大陆的分期直接当作全世界通用分期。

### 5.2 人物

人物卡应包含身份与活动时期、生平时间线、重要活动、所处制度与社会环境、历史影响和史料记载。姓名应给出统一中文译名，并在首次出现时保留必要的原文名称或常见异译。

传说或文学人物必须明确性质，不得伪造生卒年、官职和历史活动。存在同名人物、王号或罗马数字序号时必须准确区分。

### 5.3 历史事件

事件卡至少说明：

- 时间、地点、参与方与历史背景。
- 直接起因、结构性条件和各方目标。
- 关键阶段、转折点和因果链。
- 直接结果、长期影响和不同地区的后果。
- 史料限制、主要争议和不同解释。

战争不能只写胜负，革命不能只写口号，殖民与全球交流不能只从单一参与方叙述。

### 5.4 跨区域比较

比较卡必须使用同一组维度和可比时间范围，例如国家形成、财政能力、军事组织、贸易网络、土地制度、宗教结构或工业化条件。相似性不等于直接影响，时间先后也不自动构成因果关系。

比较应明确：

- 比较对象和时间截面。
- 共同指标及其定义。
- 相似点、差异点与形成条件。
- 资料不对称和不可比部分。
- 是否存在贸易、迁徙、战争、翻译或制度借鉴等实际联系证据。

### 5.5 年代、纪年与地名

- 公元前后跨越时不得设置不存在的公元 0 年。
- 使用“公元前/公元”或其他纪年时保持全文一致，并在必要时说明换算。
- 对约数、传统年代和学界争议年代使用“约”“通常认为”等限定。
- 历史地名优先使用当时名称，现代地名只用于辅助定位。
- 政权控制范围、文化影响范围和人口分布范围必须区分。

## 6. 事实、史料与翻译

来源优先级通常为：考古报告和原始史料、权威史料整理本、同行评议研究与学术专著、博物馆和大学资料、可靠通识著作。百科和普通网页只用于发现线索，不能单独支撑有争议的结论。

- 直接引文核对原文、作者、作品、篇章和上下文。
- 翻译文本注明采用版本；关键概念必要时保留原文。
- 殖民时期、民族冲突、死亡人数和人口统计等敏感数字必须说明口径和范围。
- 史料由胜利者、殖民者、宗教机构或国家机关保存时，应说明材料偏向和缺失。
- 学术解释存在争议时并列主要观点及证据，不虚构统一结论。

## 7. 地图、时间线与图片

- 地图标明时间截面、图例、方向、关键节点和示意性质。
- 不把势力影响区画成稳定主权边界，也不以现代国界裁切古代文明。
- 路线图区分已证实路线、推测路线和概略方向。
- 时间线兼顾同一时期不同区域的并行事件，避免只沿单一文明排列。
- 图片注明对象、年代、馆藏或来源；复原图、艺术创作和影视图像不得作为实物证据。
- 资产放入对应主题的 `assets/` 目录，并使用有效相对路径。

## 8. 索引与链接

- 新卡片加入最近一级 README；文明、城市、建筑文物、事件与人物统一加入根目录的 `查询索引.md`，按“国家（所在洲）、首都、著名地区、事件、人物”五列维护，不另建分类查询索引。
- 国家列采用现代地理定位；跨国主题使用全球行或在有关国家中交叉引用，古代人物与政权注明历史关联，不按现代国籍或国界强行归属。首都、历史都城、最大城市与政府所在地需区分。
- 每个已列对象应链接到本地正文、已含简述的确切章节或可靠外部来源；空缺使用“—”，不把相关卡片伪装成缺失对象的独立正文。新增条目后检查全量具体卡片是否仍可从统一索引进入。
- README 只保留目录简介和直属内容索引。
- 整卡入口直接链接文件；只有明确指向特定内容时才使用章节锚点。
- 人名异译、旧译、王号和地名异译应合并到同一权威对象。
- 移动、重命名、合并或删除后，搜索旧路径并更新全部引用。
- 合并前先迁移独有事实、史料、时间线、比较维度和争议说明。

## 9. 修改与验证流程

修改前：

1. 运行 `git status --short`，识别已有改动。
2. 阅读目标卡片、同目录 README、上级索引和相关时期或区域卡片。
3. 搜索中文名、原文名、异译名、旧地名和交叉主题，确认权威归属。
4. 判断任务属于新增、补充、纠错、合并、拆分、迁移还是审计。
5. 批量修改前统计候选数量并抽样核对语义。

交付前至少检查：

- 年代、地名、人物身份、译名、引文和统计口径可核验。
- 史料事实、学术解释、传说和文学已经区分。
- 比较对象使用相同维度和合理时间范围。
- 地图、时间线、图片与正文一致并注明边界。
- 最近一级 README 和必要索引已经更新。
- 本地相对链接、图片路径和标题层级有效。
- 旧路径没有残留，没有新增孤立文件。
- `git diff --check` 和本次修改文件的 scoped 检查通过。
- 最终 diff 不覆盖来源不明的用户改动。

除非用户明确要求，不创建提交，不推送远端。
