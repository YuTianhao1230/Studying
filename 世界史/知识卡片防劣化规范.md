# 世界史知识卡片防劣化规范

## 1. 文档定位

本文件是 `/mlx_devbox/users/yutianhao/Studying/世界史/` 下历史知识卡片生成、补充、改写、拆分、合并、迁移和校对时的统一质量规范。处理本目录内容前，应先阅读本文件，再检查目标目录的 `README.md`、目标卡片和相关索引。

本目录用于历史兴趣阅读，不设置考题、自测、笔面试章节或背诵模板。正文应围绕明确的时间、空间、主体和证据展开，兼顾区域内部演变与跨区域联系。

涉及地图、时间线、人物关系图、图片、动态图、视频或在线交互资源时，还必须完整阅读并遵循根目录的[历史知识库可视化与外部资源规范](<../历史知识库可视化与外部资源规范.md>)。

## 2. 核心原则

1. 一个主题保留一个权威正文，其他位置使用相对链接。
2. 同时交代时间、地理范围、参与主体、因果链和历史结果。
3. 区分原始史料、考古证据、学术解释、民族记忆、传说与文学。
4. 不以欧洲历史代替世界史，也不机械追求各地区篇幅完全相等。
5. 不用现代国界、民族国家、种族分类或价值观直接套用古代社会。
6. 对译名、年代、地域边界和学术争议明确采用口径。

## 3. 一票否决项

出现以下任一问题，卡片不得视为完成：

- 编造年代、引文、人物关系、统计数字、地图边界或史料结论。
- 把神话、民族叙事、文学作品或后世宣传写成已证实史实。
- 将今天的国家、民族或宗教身份无条件回溯到形成之前。
- 只写事件结论或文明标签，没有解释形成条件、过程和变化。
- 以“先进/落后”“文明/野蛮”等单一价值标签替代具体历史分析。
- 比较不同地区时使用不同指标、不同时间尺度或不对称证据。
- 图片、地图、时间线与正文冲突，或未说明示意性质与时间截面。
- 新增卡片未加入最近一级 README，或迁移后留下断链和旧路径。
- 覆盖、回滚或清理来源不明的未提交改动。
- 留下空章节、占位符、聊天口吻、审计过程或未完成标记。

## 4. 目录与主题归属

世界史按对象类型直接组织，类型目录均为世界史根目录的直属目录，不设置“地区→类型→卡片”的中间层。地区和文明归属由正文与统一查询表说明：

| 层次 | 职责 |
| --- | --- |
| 时期总览 | 建立同一时期各区域并行发展的时间框架 |
| 文明与国家 | 保存已有文明与历史政权的背景卡片，不作为人物、事件等类型的上级目录，不以完整国家通史为扩充目标 |
| 城市 | 写清首都身份、著名地区、空间发展与历史联系 |
| 建筑与文物 | 解释建筑、遗址和实物的年代、用途、变化与证据 |
| 自然景观 | 解释地貌、生态、位置与人地联系 |
| 重要人物 | 按主要贡献领域分组，介绍人物生平、历史环境、重要活动和史料 |
| 历史时期与事件 | 在八个时期目录中保存时期介绍与具体事件，叙述战争、迁徙、革命、改革及制度变化 |
| 跨时代专题 | 科技、文化、宗教、经贸各设主线总览与具体主题卡片 |

同一事件涉及多个区域时保留一篇主卡，由统一查询表、时期总览和专题交叉引用。历史时期重点串联事件和人物，标注活动年代、先后关系及跨期延续；城市、建筑与自然景观只有在解释某个历史节点时才作辅助链接，不机械归入单一时期。跨时代专题负责比较和联系，不重复复制对象正文。

单一对象类型的比较说明归入对应目录：城市位置和首都概念放在城市，人物关系放在重要人物，战争与革命比较放在历史时期，帝国治理放在文明与国家。阅读方法、中国史衔接统一在世界史总览中说明。在线数据库入口嵌入相关卡片或主题总览，不保留只罗列外链的独立资源页；合并时迁移独有内容、图注、许可、参考来源、核验范围及有效链接。

人物按政治与国家治理、军事与战略、数学、自然科学与医学、哲学与思想、文学与艺术、计算与信息、社会运动与权利、地理与旅行九个领域组织。领域表示本库的主要阅读角度，不是排他的现代职业分类；跨领域贡献在正文中说明。人物卡唯一，其他领域使用正文关联链接，不复制一套生平。

人物分类须与实际内容覆盖相匹配。不能为一个孤立人物创建空泛领域，也不能只换目录而不补充代表性内容；新设领域应能说明多个对象之间的阶段或问题联系，内容不足时优先放入现有最具体领域。扩充人物时检查理论、工程、制度、艺术实践与跨区域知识交流的覆盖，不只重复增加同一时代的相似人物。

历史时期采用“时期目录/时期介绍.md＋具体事件.md＋README.md”。时期介绍保留区域并行变化、社会生活、因果联系、事件人物串联和专题线索，README只导航。长时段事件在最能解释核心转折的时期保存权威正文，其他时期交叉引用并说明跨期阶段；不得因归档删除较早背景或后续影响。

## 5. 内容要求

### 5.1 时期与区域总览

总览应说明时间范围、地理范围、主要政治实体、社会经济特征、关键变化和与其他区域的联系。不得将某一帝国或某一大陆的分期直接当作全世界通用分期。

### 5.2 人物

人物卡应包含身份与活动时期、生平时间线、重要活动、所处制度与社会环境、历史影响和史料记载。姓名应给出统一中文译名，并在首次出现时保留必要的原文名称或常见异译。

传说或文学人物必须明确性质，不得伪造生卒年、官职和历史活动。存在同名人物、王号或罗马数字序号时必须准确区分。

科学、计算与工程人物须解释具体问题、方法或构件、代表成果、协作及机构背景。对“第一”“之父”“独自发明”等称号说明判据，区分设计、发表、实际建成、推广和后世命名；不能以人物名单或奖项清单代替贡献正文。跨期人物保留青年训练、主要活动及后期接受史，不把所有成果塞进同一年代。

### 5.3 历史事件

事件卡至少说明：

- 时间、地点、参与方与历史背景。
- 直接起因、结构性条件和各方目标。
- 关键阶段、转折点和因果链。
- 直接结果、长期影响和不同地区的后果。
- 史料限制、主要争议和不同解释。

战争不能只写胜负，革命不能只写口号，殖民与全球交流不能只从单一参与方叙述。

### 5.4 跨区域比较

比较卡必须使用同一组维度和可比时间范围，例如国家形成、财政能力、军事组织、贸易网络、土地制度、宗教结构或工业化条件。相似性不等于直接影响，时间先后也不自动构成因果关系。

比较应明确：

- 比较对象和时间截面。
- 共同指标及其定义。
- 相似点、差异点与形成条件。
- 资料不对称和不可比部分。
- 是否存在贸易、迁徙、战争、翻译或制度借鉴等实际联系证据。

### 5.5 年代、纪年与地名

- 公元前后跨越时不得设置不存在的公元 0 年。
- 使用“公元前/公元”或其他纪年时保持全文一致，并在必要时说明换算。
- 对约数、传统年代和学界争议年代使用“约”“通常认为”等限定。
- 历史地名优先使用当时名称，现代地名只用于辅助定位。
- 政权控制范围、文化影响范围和人口分布范围必须区分。

### 5.6 固定结构与阅读顺序

同类对象卡片统一二级标题名称与顺序。标题之后先用文字交代对象、位置、身份或活动时期，再将图片及完整图注放入“图片与图注”，随后展开正文。来源与关联阅读放在末尾，不以图片开篇，不将“首都”等身份属性填入年代字段。

| 卡片类型 | 固定二级标题顺序 |
| --- | --- |
| 城市 | 位置与首都身份；图片与图注；城市发展与历史联系；主要地区与地标；参考资料；关联阅读 |
| 建筑与文物 | 时空定位；图片与图注；建造与历史变迁；实物特点与用途；史料与参考；关联阅读 |
| 自然景观 | 位置与范围；图片与图注；形成机制；主要看点；人地联系与保护；参考资料；关联阅读 |
| 重要人物 | 人物简介；图片与图注；生平时间线；重要活动与影响；史料与参考；关联阅读 |
| 历史事件 | 时空定位；图片与图注；背景与起因；经过与转折；结果与影响；史料与参考；关联阅读 |
| 文明与国家 | 时空定位；图片与图注；发展进程；社会、制度与文化；史料与参考；关联阅读 |
| 历史时期 | 时间与主题；形成条件；各地区的并行变化；社会生活与历史联系；事件与人物串联；四条主线在本期的交汇；延伸阅读；相邻时期 |
| 跨时代专题 | 主题与范围；连续时间线；关键问题与机制；与另外三条线的关系；关联阅读；资料与证据 |
| 科技具体主题 | 技术定位；图片与图注；发展时间线；原理与关键变化；传播与社会影响；史料与参考；关联阅读 |
| 宗教与信仰具体主题 | 传统与形成背景；图片与图注；发展时间线；信仰、文本与实践；传播、组织与内部差异；史料与参考；关联阅读 |
| 文化具体主题 | 主题与历史环境；图片与图注；发展时间线；作品、实践与传播机制；社会影响与解释边界；史料与参考；关联阅读 |
| 经贸具体主题 | 范围与参与者；图片与图注；发展时间线；商品、劳动与运行机制；制度变化与利益分配；史料与参考；关联阅读 |
| 对象目录中的辅助说明页 | 主题说明；内容解析；关联阅读 |

人物的“重要活动与影响”下可设置“生平与重要事件”“贡献与影响”等三级标题；“关联阅读”下用三级标题保留“所属时期与串联阅读”。事件的时期回链同样放在“关联阅读”下。专题的不同问题作为“关键问题与机制”的三级标题，保持内容差异，不能为统一结构删掉独有解释。

辅助说明页指城市位置、人物关系、战争比较、革命比较和帝国治理，不套用单座城市或单个事件的模板。总览、查询表和README承担各自职责；README统一为简短简介与直属内容索引。交互资源说明使用“关联阅读”下的三级标题，保留具体用途与数据边界。

改名、移段时完整保留正文、图注、许可和参考链接，更新所有指向旧标题的锚点。没有材料的三级子项不设空标题，不为凑结构补造史实；新卡片应先补足本类型所需的实际内容再交付。

### 5.7 具体专题的深度

四条主线不能只有一篇概览或名单。每个分支保留连续主线，并对具备独立解释价值的主题形成正文：

- 科技：交代技术解决什么问题、关键构件或工作机制、前身、多个参与者、发明与推广的区别、应用条件和社会代价。不能把改良者称为最初发明者，也不使用“一个天才改变世界”代替生产与传播条件。
- 宗教与信仰：区分形成时期、历史传统、信徒自述、核心概念、文本、组织、礼仪、内部流派和传播。超自然信条用“信徒相信”等归属表达；不能把一个教派、民族或国家当作全部传统，也不把原住民信仰写成单一宗教。
- 文化：解释作品、实践、资助者、读者或观众、媒介与流通网络，保留具体例子，不只列艺术家姓名。
- 经贸：说明商品、劳动、运输、货币信用、制度、参与者和利益分配；强制迁徙不能改写成普通贸易或自愿移民。

新增主题至少有具体阶段或案例、机制解释、传播与影响、边界和可靠参考。需要实物或场景帮助理解时配真实开放许可图片；相关图片可以复用，但必须标清其证据范围。不得靠重复模板语句、空章节或链接数量凑篇幅。

## 6. 事实、史料与翻译

来源优先级通常为：考古报告和原始史料、权威史料整理本、同行评议研究与学术专著、博物馆和大学资料、可靠通识著作。百科和普通网页只用于发现线索，不能单独支撑有争议的结论。

- 直接引文核对原文、作者、作品、篇章和上下文。
- 翻译文本注明采用版本；关键概念必要时保留原文。
- 殖民时期、民族冲突、死亡人数和人口统计等敏感数字必须说明口径和范围。
- 史料由胜利者、殖民者、宗教机构或国家机关保存时，应说明材料偏向和缺失。
- 学术解释存在争议时并列主要观点及证据，不虚构统一结论。

## 7. 地图、时间线与图片

- 地图标明时间截面、图例、方向、关键节点和示意性质。
- 不把势力影响区画成稳定主权边界，也不以现代国界裁切古代文明。
- 路线图区分已证实路线、推测路线和概略方向。
- 时间线兼顾同一时期不同区域的并行事件，避免只沿单一文明排列。
- 图片注明对象、年代、馆藏或来源；复原图、艺术创作和影视图像不得作为实物证据。
- 资产放入对应主题的 `assets/` 目录，并使用有效相对路径。

## 8. 索引与链接

- 新卡片加入最近一级 README；文明、城市、建筑文物、事件与人物统一加入根目录的 `查询索引.md`，按“国家（所在洲）、首都、著名地区、事件、人物”五列维护，不另建分类查询索引。
- 自然景观直接放入根目录下的“自然景观”目录，并接入同一五列查询表的“著名地区”列；写清位置、地貌或生态成因、主要看点与人地联系，区分整个自然地域、保护区和旅游地点。
- 国家列采用现代地理定位；跨国主题使用全球行或在有关国家中交叉引用，古代人物与政权注明历史关联，不按现代国籍或国界强行归属。首都、历史都城、最大城市与政府所在地需区分。
- 每个已列对象应链接到本地正文、已含简述的确切章节或可靠外部来源；空缺使用“—”，不把相关卡片伪装成缺失对象的独立正文。新增条目后检查全量具体卡片是否仍可从统一索引进入。
- README 只保留目录简介和直属内容索引。
- 整卡入口直接链接文件；只有明确指向特定内容时才使用章节锚点。
- 人名异译、旧译、王号和地名异译应合并到同一权威对象。
- 移动、重命名、合并或删除后，搜索旧路径并更新全部引用。
- 合并前先迁移独有事实、史料、时间线、比较维度和争议说明。

## 9. 修改与验证流程

修改前：

1. 运行 `git status --short`，识别已有改动。
2. 阅读目标卡片、同目录 README、上级索引和相关时期或区域卡片。
3. 搜索中文名、原文名、异译名、旧地名和交叉主题，确认权威归属。
4. 判断任务属于新增、补充、纠错、合并、拆分、迁移还是审计。
5. 批量修改前统计候选数量并抽样核对语义。

交付前至少检查：

- 年代、地名、人物身份、译名、引文和统计口径可核验。
- 史料事实、学术解释、传说和文学已经区分。
- 比较对象使用相同维度和合理时间范围。
- 地图、时间线、图片与正文一致并注明边界。
- 最近一级 README 和必要索引已经更新。
- 本地相对链接、图片路径和标题层级有效。
- 旧路径没有残留，没有新增孤立文件。
- `git diff --check` 和本次修改文件的 scoped 检查通过。
- 最终 diff 不覆盖来源不明的用户改动。

除非用户明确要求，不创建提交，不推送远端。
