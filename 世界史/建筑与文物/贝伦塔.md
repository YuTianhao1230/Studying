# 贝伦塔

## 时空定位

贝伦塔位于葡萄牙里斯本塔霍河口附近，主要建于1514—1520年，是曼努埃尔一世时期的防御与王权展示建筑。它服务河口交通与炮兵防御，今天陆岸关系与16世纪环境不完全相同。

外文检索名：Tower of Belém。现代地理定位：葡萄牙；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 16世纪初 | 里斯本与跨洋航运联系增强，河口防御需要扩充。 |
| 1514—1520年 | 弗朗西斯科·德·阿鲁达参与设计，塔及炮台建成。 |
| 后世 | 用途曾涉及监禁、海关及其他管理活动。 |
| 19—20世纪 | 进行修复并逐渐成为国家纪念物和世界遗产。 |

## 实物特点与用途

### 防御与火炮

低矮炮台与较高塔楼组合，兼顾水面射击、驻防和视野。它属于火药武器时代的防御调整，不能仅依外观称为典型中世纪城堡。河道、船舶路线与其他防御据点共同决定作用。

### 曼努埃尔式装饰

绳索纹样、纹章、十字和植物等装饰将航海、王室与宗教符号嵌入石工。海洋意象反映国家表达，但不能据此认为所有海外航行都和平互利；殖民、强制劳动与军事控制也是背景。

### 岸线与遗产

淤积、工程及城市发展改变周边水陆关系，今天步行可达不等于原来就是同样岸上塔。旅游照片呈现维护后的纪念建筑，需要与历史图像和工程资料比较。

## 史料与参考

贝伦塔与热罗尼莫斯修道院同属一个世界遗产项目，但不是同一建筑。修复可能增强某些历史风格，现景不能单独证明初建状态。
