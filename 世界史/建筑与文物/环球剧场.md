# 环球剧场

## 时空定位

环球剧场原址位于伦敦泰晤士河南岸，1599年建成，莎士比亚所属剧团在此演出。原剧场已毁；今天1997年开放的莎士比亚环球剧场是依据研究建造的现代重建，地点也不与原址完全重合。

外文检索名：Globe Theatre。现代地理定位：英国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1599年 | 第一座环球剧场建成。 |
| 1613—1614年 | 火灾烧毁后重建。 |
| 1642—1644年 | 剧场关闭，建筑随后拆除。 |
| 1997年 | 现代重建剧场正式开放。 |

## 实物特点与用途

### 演出空间

露天庭院、分层观众席与伸出式舞台塑造观演关系。现代重建依据多种证据，但原始细部没有完整图纸，不能把今天每个构件都视为1599年精准复制。

### 剧团与市场

莎士比亚既是剧作者，也是剧团成员和经营参与者。演出依赖演员、赞助、售票和城市人群，戏剧流行不是孤立天才写作的结果；当时男女角色的表演制度与今天也不同。

### 重建与实践

现代演出可帮助研究声学、距离和观众互动，也同时受消防、无障碍和当代管理约束。实验演出不能证明古代每次上演都采用完全相同节奏或布景。

## 史料与参考

原剧场、1614年重建和20世纪再建是三种不同对象状态。文学作品、地产档案和考古比旅游宣传中的完全复原说法更可取。
