# 匈牙利国会大厦

## 时空定位

匈牙利国会大厦位于布达佩斯多瑙河岸，是奥匈帝国时期匈牙利议会的重大公共建筑。伊姆雷·施泰因德尔设计，1885年开工，1896年举行重要启用活动，全部工程延续至1904年。

外文检索名：Hungarian Parliament Building。现代地理定位：匈牙利；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |

| 1867年 | 奥匈妥协确立双元体制背景。 |
| 1885年 | 国会大厦开工。 |

## 实物特点与用途

### 议会与王国

宏大建筑表现匈牙利政治地位及国家历史叙事。其初建背景是君主制和有限选举权，不能将19世纪议会无条件称为现代普选民主制度，也不能忽略多民族王国背景。

### 风格与空间

新哥特式外部、中央穹顶及轴线布局兼容不同建筑语言。会议厅、走廊和仪式空间承担实际功能，石材、装饰和施工需要庞大工匠组织；外观接近威斯敏斯特不等于简单复制。

### 国家象征与开放

圣冠展陈和历史人物装饰将建筑转为国家记忆空间。馆藏、参访和议会使用属于不同管理功能，现代国界与政治制度不能倒推初建年代的全部象征意义。

## 史料与参考

官方建筑史需区分1896年的部分启用与1904年的完成。夜景照明与维护后的石材色泽属于现状，不是19世纪施工现场。
