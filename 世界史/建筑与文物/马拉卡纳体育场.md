# 马拉卡纳体育场

## 时空定位

马拉卡纳体育场位于里约热内卢，官方名称为马里奥·菲略体育场。它为1950年足球世界杯兴建，后来多次改造；历史最大观众规模与今天安全规范下的座席容量不是同一统计。

外文检索名：Maracanã Stadium。现代地理定位：巴西；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1948年 | 体育场开工，服务世界杯筹备。 |
| 1950年 | 启用并举行世界杯比赛，巴西与乌拉圭之战成为公共记忆。 |
| 20世纪后期 | 改造结构和看台，举办大型体育及文化活动。 |
| 2010年代 | 为世界杯、奥运会等进一步改建。 |

## 实物特点与用途

### 公共工程与观众

场地、环形看台和交通疏散支撑大规模集会。建筑依赖国家投资、设计协作与施工劳动；容量受站席、座席、安全及售票口径影响，不能直接比较不同时代数字。

### 足球与记忆

1950年乌拉圭战胜巴西的比赛被赋予强烈民族情绪。体育记忆由媒体、球迷和政治环境塑造，不能以一次比赛解释全部巴西社会身份，也不能把竞技结果写成战争。

### 改建与利益

现代屋盖、座席和设施不同于最初版本。国际赛事带动城市更新，同时涉及公共开支、管理合同和居民使用；工程完成不等于争议自动消失。
