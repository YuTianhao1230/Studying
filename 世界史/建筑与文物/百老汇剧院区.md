# 百老汇剧院区

## 时空定位

百老汇剧院区主要位于纽约曼哈顿中城时代广场附近，是一组专业剧院、演出公司和城市商业网络，不是一栋名叫百老汇的建筑。百老汇街道的范围远大于剧院区，部分重要剧院也不直接坐落于这条街。

外文检索名：Broadway theatre district。现代地理定位：美国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 19世纪 | 纽约商业剧场随城市扩张逐渐向北迁移。 |
| 19世纪末—20世纪初 | 中城交通、广告和剧院集中发展。 |
| 20世纪 | 音乐剧、长演剧目和全国巡演体系成熟。 |
| 近现代 | 剧场保护、旅游与商业更新继续影响街区。 |

## 实物特点与用途

### 演出产业

制片人募集资本，剧作者、作曲家、导演、演员及技术工人共同生产演出。票房、评论、合同和巡演影响剧目寿命，成功并非只由一首歌曲或一个明星决定。

### 音乐剧的媒介

对白、歌曲、舞蹈与舞台调度组合叙事，但具体结构不断变化。录音、电影改编和国际授权扩展传播，不能把舞台原版、电影版和地方译演视为同一份作品。

### 城市空间

时代广场广告、酒店、地铁和夜间经济支持集聚。剧院产权、地价与观众消费也可能排挤其他城市使用者；剧场分类有行业约定，不能简单按离百老汇街道的距离划分。

## 史料与参考

剧院区、街道和百老汇演出行业是不同概念。照片中的广告与剧目具有拍摄时点，不能据此推断当前仍在上演。
