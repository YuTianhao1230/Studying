# 额尔德尼召

## 时空定位

额尔德尼召位于蒙古国哈拉和林遗址附近，1586年阿巴岱汗时期开始营建，是蒙古佛教史的重要寺院。寺院使用古都附近材料并发展多座殿堂，不能把它与13世纪哈拉和林宫城直接视为同一建筑。

外文检索名：Erdene Zuu Monastery。现代地理定位：蒙古；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1586年 | 阿巴岱汗时期开始建立寺院。 |
| 17—19世纪 | 寺院殿堂及围墙等分阶段发展。 |
| 1930年代 | 镇压导致僧侣受迫害、许多建筑遭毁。 |
| 20世纪后期以后 | 部分作为博物馆保护，宗教活动也逐渐恢复。 |

## 实物特点与用途

### 佛教与政治

寺院联系蒙古贵族、藏传佛教师承及地方社群。建筑与仪式吸收多个区域的工艺和宗教传统，不宜用单一风格或现代国界概括所有影响。

### 围墙与建筑

白色佛塔围墙形成可辨识外观，但围墙、各殿堂与最初建寺不同龄。寺院曾有远多于今天的建筑，现存空间不能反映毁坏前完整人数和日常组织。

### 保护与宗教恢复

遗产展示保留部分实物，活态宗教使用则涉及人员、师承和仪式重建。1930年代暴力造成的断裂不能仅称为自然衰败，现代恢复也不等于所有原有藏品已回归。

## 史料与参考

鄂尔浑河谷世界遗产涵盖多处遗址，额尔德尼召只是其中一部分。蒙古国境内寺院与中国境内同类对象不混用，传统记载须与建筑调查比较。
