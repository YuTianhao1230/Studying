# 乌菲齐美术馆

## 时空定位

乌菲齐位于佛罗伦萨，建筑1560年开始建设，原本服务美第奇统治下的行政办公，名称与办公室相关。王室收藏、陈列及后来的公共博物馆制度逐步改变其用途，不能称为从开工起就一直完全相同的美术馆。

外文检索名：Uffizi Galleries。现代地理定位：意大利；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1560年起 | 乔尔乔·瓦萨里主持办公建筑设计。 |
| 16世纪后期 | 收藏与展示空间逐步发展。 |
| 18世纪 | 洛林统治背景下公共开放及博物馆组织推进。 |
| 近现代 | 收藏、保护、展陈和参访设施持续变化。 |

## 实物特点与用途

### 行政与城市

狭长院落、连廊和阿诺河岸位置连接宫廷、城市管理及公共空间。瓦萨里长廊与美术馆主楼有关却不是同一部分，使用和开放条件也不相同。

### 收藏与赞助

美第奇家族及后续管理者留下绘画、雕塑和其他对象。波提切利等名作属于不同年代、原委托地点和宗教社会环境，不能把今天并列展出当作原来一起制作。

### 公共展示

博物馆通过分类、研究及保存改变作品观看方式。收藏继承与家族契约联系佛罗伦萨城市遗产，公众开放与宫廷收藏的准入规则存在差异。

## 史料与参考
