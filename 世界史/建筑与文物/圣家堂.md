# 圣家堂

## 时空定位

圣家堂是西班牙巴塞罗那的大型天主教宗教建筑，1882年开工，安东尼·高迪于次年接手并深刻改变设计。其长期营建体现建筑设计、宗教捐资、工匠技术和现代工程的延续。高迪去世后仍由多代团队建设，不能将现存全部构件都称为他的亲手作品。

巴塞罗那城市扩展区；19世纪末开始营建。UNESCO“高迪的作品”仅将圣家堂的特定组成部分纳入，不能说整座不断增建的建筑全部拥有相同遗产范围。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 1882年 | 按最初建筑师方案开工。 |
| 1883年起 | 高迪接手，发展自然几何、结构和宗教象征结合的设计。 |
| 1926年 | 高迪去世，建筑尚远未完成。 |
| 1936年 | 西班牙内战中部分模型和资料受损。 |
| 20—21世纪 | 后继建筑师据保存资料、研究及现代工具持续施工；2010年由教皇祝圣。 |

## 实物特点与用途

### 柱与曲面如何工作

树枝般分叉的柱将上部荷载逐级传向地面；双曲面等几何形式影响结构、开口和采光。自然形态不是仅在表面添加树木装饰，而与支撑和空间组织相关。今天的实现仍有现代材料、计算及施工的作用。

### 立面中的宗教叙事

诞生、受难等立面通过雕塑与空间讲述基督教主题，不同阶段和作者的风格并不相同。建筑表达信仰叙事，但不能把雕塑当成古代事件的考古实物。

### 长期工程的争议

捐款、旅游、城市基础设施和设计解释影响营建。后继团队如何理解残存模型、是否忠于高迪设想，存在讨论。计划完工时间会变化，本卡不以某个预测年份冒充全部工程已竣工。

## 史料与参考

施工进度是时效性事实，应以管理方最新公告为准。现存内外空间与高迪在世时不同；UNESCO登记的圣家堂地下礼拜堂和诞生立面须与整个建筑区分。
