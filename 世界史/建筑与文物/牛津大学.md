# 牛津大学

## 时空定位

牛津大学是位于英国牛津的大学共同体，至少在1096年已有教学活动，但没有一个可以无争议确定的单一创立日。它由大学机构、学院及众多建筑组成，不能将某座图书馆或一所学院等同于整个大学。

外文检索名：University of Oxford。现代地理定位：英国；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1096年；可见教学线索 | 牛津已有教学活动，大学共同体随后逐渐发展。 |
| 12—13世纪 | 学者流动、城镇冲突和组织制度推动大学形成。 |
| 中世纪以后 | 学院、图书馆和教学建筑逐步增加。 |
| 近现代 | 学科、研究制度与入学群体变化，女性资格和学院开放经历长期改革。 |

## 实物特点与用途

### 大学与学院

大学组织考试、授予学位并提供学科机构，学院则在居住、辅导及共同体生活中具有重要角色。大学不是英国所有高校制度的唯一模板，学院名称、法人和建筑年代应区分。

### 书籍与建筑

博德利图书馆、拉德克利夫阅览建筑及学院庭院反映不同时期知识与资助。哥特或古典风格不能证明全部建筑属于中世纪，现代研究也不只发生在游客常拍的历史空间。

### 准入与社会

早期学习机会与宗教、性别及社会资源有关。女性学院19世纪成立后，大学在1920年才正式授予女性学位；知名毕业生并不能代替对制度门槛、帝国联系和科研组织的分析。

## 史料与参考
