# 艾尔米塔什博物馆

## 时空定位

艾尔米塔什博物馆位于圣彼得堡，收藏史常从1764年叶卡捷琳娜二世购藏起算。主馆由冬宫等多座建筑组成；冬宫是一座18世纪王室宫殿，博物馆是收藏、研究与展示机构，二者不能完全等同。

外文检索名：State Hermitage Museum。现代地理定位：俄罗斯；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1754—1762年 | 拉斯特雷利主持现存冬宫的重要建设。 |
| 1764年 | 王室收藏活动成为博物馆机构纪年起点。 |
| 1852年 | 新艾尔米塔什等空间扩大公共展示。 |
| 1917年以后 | 革命、国有化、战争疏散及收藏政策改变机构。 |

## 实物特点与用途

### 宫殿与馆群

冬宫巴洛克式立面与仪式厅堂服务帝国宫廷，后来的博物馆建筑满足展示和保存。参观路线横跨不同年代建筑，不能把每间展室都说成1764年原有。

### 收藏与流动

作品通过购买、赠与、转移、考古及其他方式进入馆藏。收藏规模不等于来源伦理已经全部解决，战争、殖民与国家政策背景须按具体对象研究。

### 公共知识

编目、保护、研究和教育使机构超出珍宝存放。1917年冬宫事件的艺术再现与真实经过不同，博物馆建筑不能作为所有革命镜头的现场证据。

## 史料与参考

馆史与藏品档案分别核对机构年代和对象来历，冬宫与艾尔米塔什不能互为所有语境的别名。
