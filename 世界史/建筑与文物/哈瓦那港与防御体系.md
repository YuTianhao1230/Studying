# 哈瓦那港与防御体系

## 时空定位

哈瓦那港的堡垒与城防主要在西班牙殖民时期分阶段发展，服务加勒比航运、舰队补给及城市防御。莫罗城堡、皇家军队城堡和卡瓦尼亚等属于不同年代，不能合称一座同时完成的堡垒。

外文检索名：Havana harbour and fortifications。现代地理定位：古巴；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 16世纪 | 港口重要性上升，皇家军队城堡等防御工程发展。 |
| 16世纪末—17世纪 | 莫罗城堡等控制港口入口。 |
| 1762—1763年 | 英国攻占哈瓦那后归还，暴露旧防御弱点。 |
| 18世纪后期 | 卡瓦尼亚等大型防御工程扩展。 |

## 实物特点与用途

### 港口与炮台

狭窄入口、岸线高地和火炮射界决定据点位置。城墙并非单独保证安全，舰队、补给和陆上控制同样重要；1762年的围攻不能解释为仅一座炮台火力不足。

### 殖民航运

港口联系美洲财富、欧洲贸易和西班牙舰队制度，也依赖奴役劳动与殖民资源。殖民城市美学与强制劳动、种族等级和战争需要一并阅读。

### 防御遗产

后世监禁、军事与旅游用途改变堡垒。灯塔、城堡和海堤并非同一种设施，现代港湾照片也不能推定16世纪岸线或全部防御范围。
