# 香通寺

## 时空定位

香通寺位于老挝琅勃拉邦半岛北端，通常记为1559—1560年塞塔提拉王时期建立，是王都礼仪与上座部佛教的重要寺院。寺内主殿、附属礼拜空间和后增建筑不同龄，不宜全部归入一个建寺日期。

外文检索名：Wat Xieng Thong。现代地理定位：老挝；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1559—1560年 | 塞塔提拉王时期建立寺院。 |
| 王国时期 | 承担宗教及王室相关礼仪。 |
| 19—20世纪 | 修复、装饰与附属建筑增加。 |
| 近现代 | 继续宗教使用，纳入琅勃拉邦历史城市保护。 |

## 实物特点与用途

### 屋顶与主殿

层叠而低垂的屋顶、木构和装饰形成琅勃拉邦风格。主殿供礼拜与僧团活动，外观不能说明所有梁架年代，气候与材料需要定期维护。

### 图像与工艺

金饰、彩色玻璃镶嵌和佛像来自不同阶段。生命树等著名装饰的现存形态含近现代制作，不能把现代材料直接认定为16世纪原作。

### 王都与僧团

寺院联系王室仪式、居民供养及僧人训练。现代旅游带来收入也影响空间使用，国家城市遗产不等于全部居民拥有同一宗教身份。

## 史料与参考

城市遗产档案与寺院调查需共同核对。主殿、王室灵车馆及其他附属建筑要分别断代，避免因名称统一而抹平变迁。
