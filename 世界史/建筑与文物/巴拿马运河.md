# 巴拿马运河

## 时空定位

巴拿马运河横穿中美洲巴拿马地峡，1914年通航，通过船闸和加通湖连接大西洋侧与太平洋侧港口。它不是海平面直通水道，也不沿自然海峡开凿；1999年底管理权移交巴拿马。

外文检索名：Panama Canal。现代地理定位：巴拿马；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1880年代 | 法国主导工程受疾病、财务和工程问题影响而失败。 |
| 1904—1914年 | 美国主导建设，改用船闸体系并改善防疫与施工组织。 |
| 1977—1999年 | 条约安排逐步移交，1999年完成控制权转移。 |
| 2016年 | 扩建船闸投入运行，扩大可通过船型。 |

## 实物特点与用途

### 船闸与水

船只通过船闸升降到湖面高程，再下降回海面。水资源来自流域降雨与蓄水，运行、城市供水和生态因此相互牵连；干旱会限制通航，扩建也不能消除全部水量约束。

### 劳动与疾病

挖掘、滑坡控制、铁路运输及闸体工程需要大量跨区域劳工。黄热病和疟疾防控是建设转折，但改善并非自动惠及所有劳动者；种族化工资和居住分隔是工程社会史的一部分。

### 主权与贸易

运河缩短一些航线，却使航运依赖船闸尺寸、收费、等待和政治条件。运河区历史涉及美国权力及巴拿马主权争取，不能仅用技术成功遮蔽土地、劳动和国家关系。

## 史料与参考

巴拿马运河管理局资料适合核对通航、移交和工程机制；死亡、成本和工人数字必须明确时期与统计口径。现代扩建闸不能冒充1914年原闸。
