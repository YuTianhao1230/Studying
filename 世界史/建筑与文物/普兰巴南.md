# 普兰巴南

## 时空定位

普兰巴南位于爪哇岛日惹附近，是以印度教神庙为核心的9世纪宗教建筑群。中心三座主庙分别与湿婆、毗湿奴和梵天联系；遗产区周边同时存在佛教建筑，反映爪哇政治与宗教环境的交错。

外文检索名：Prambanan Temple Compounds。现代地理定位：印度尼西亚；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 9世纪 | 中爪哇王权背景下形成主要建筑，856年湿婆格里哈铭文是年代线索。 |
| 10世纪及以后 | 政治中心和营建重心变化，部分建筑损坏与荒废。 |
| 近现代 | 开展考古记录和重建，1953年湿婆主庙完成一项重要修复阶段。 |
| 2006年及以后 | 地震损伤推动结构评估、修复与游客管理。 |

## 实物特点与用途

### 建筑与宇宙秩序

主庙、配庙、围院和高耸塔身组成等级化空间。湿婆主庙内有湿婆、杜尔迦、象头神和阿伽斯蒂亚等神像；围绕庙体行走使浮雕、神像与礼仪路线相互结合。不同神像不代表这里存在四个互不相关的独立宗教。

### 史诗与地方实践

《罗摩衍那》相关浮雕把文学故事转为视觉叙事，但图像次序与艺术风格具有地方选择。现代舞剧是延续与重塑传统的表演，不能据此直接还原9世纪仪式。

### 修复与宗教环境

今天看到的建筑包含原石、重组构件及修复工作。部分小庙缺少足够原件，不能任意完整复建。建筑群与附近佛教遗迹共同说明不同王室、工匠和信仰传统的联系，不能用一次性宗教替代解释全部变化。

## 史料与参考

铭文、建筑布局和石雕比后世关于公主与千座庙的民间故事更适合确定营建过程。传说可作为文化记忆阅读，不能给神话人物编写真实生卒年。
