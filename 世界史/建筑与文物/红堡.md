# 红堡

## 时空定位

红堡位于印度德里，是沙贾汗时期沙贾汗纳巴德新城的莫卧儿宫廷与防御核心，主要建于1638—1648年。它与阿格拉堡是不同建筑群，不能因同用红砂岩而混为一处。

外文检索名：Red Fort, Delhi。现代地理定位：印度；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1638—1648年 | 沙贾汗迁建都城背景下营建城堡。 |
| 莫卧儿后期 | 宫廷及统治变化影响建筑使用。 |
| 1857年及以后 | 起义、英军控制和拆改改变内部布局。 |
| 1947年以后 | 成为印度独立与公共纪念的重要空间。 |

## 实物特点与用途

### 宫廷布局

城墙、入口、庭院、接见厅、居住和水景构成等级空间。红砂岩防御外部与白色大理石等精细内部不同，不能将红堡看作仅有一面外墙的军事据点。

### 水与礼仪

水渠、花园及接见空间把舒适、秩序和君主权力联系。建筑整合波斯及南亚工艺传统，不宜用单一现代国籍概括工匠和艺术来源。

### 毁坏与记忆

英国控制后拆除许多宫廷设施并加入军营，现存空间并非完整1648年宫城。独立日仪式赋予新国家意义，这一作用与莫卧儿王室原用途应分别说明。

## 史料与参考
