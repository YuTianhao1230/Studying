# 复活节岛摩艾石像

## 时空定位

摩艾是拉帕努伊岛的巨型石雕，岛屿位于东南太平洋，现代行政属智利，常用欧洲名称复活节岛。石像与当地祖先、群体权威和仪式场所相关。拉帕努伊人创造并维护这些遗产，不能以外星人或失落外族解释取代考古及原住民知识。

主要营建活动属于第二千纪，具体石像和平台年代不同；雕刻集中于拉诺拉拉库等采石区域，部分石像立于称为ahu的平台。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 岛上定居以后 | 形成农业、聚落和仪式传统，定居年代及具体阶段仍有研究。 |
| 约13—16世纪等阶段 | 石像雕刻及平台建设繁盛，年代应按对象区分。 |
| 后续阶段 | 部分石像被推倒，岛内社会与仪式发生变化。 |
| 18—19世纪 | 欧洲接触、奴隶掳掠和疾病严重冲击人口及社会。 |
| 20世纪以后 | 考古、复立与原住民遗产管理持续发展。 |

## 实物特点与用途

### 石材、身体与平台

许多摩艾用凝灰岩雕刻，形象强调头部与上身；采石场中的“石头脑袋”有部分身体埋于沉积物中。红色顶饰、眼部材料及平台配置因对象而异，不是每尊都保持同一完整形态。

### 搬运与组织

石像运输需要人员、路线和协作，研究者提出并试验摇摆移动、拖运等方式。实验说明可行性，却不直接证明每尊古代石像都用相同方法。

### 群体与祖先

石像及平台与地方群体、祖先和权威相连，立面方向常与社区生活空间有关。宗教解释应结合口述、遗址和材料，不宜只用“面朝海洋”概括全部配置。

## 史料与参考

“砍光树木后必然自毁”的单一生态崩溃故事受到新研究挑战。资源变化、欧洲接触、掳掠和疾病需要分阶段讨论；殖民冲击不能被自然因素掩盖。汤加里基现存排列含20世纪复立成果，不是全部石像从未倒塌。
