# 克里姆林宫

## 时空定位

莫斯科克里姆林宫是莫斯科河畔的城防、宗教与宫廷建筑群，也是俄罗斯国家权力的重要象征。“克里姆林”本为城堡或城市核心的通称，不只莫斯科有克里姆林；本卡专指莫斯科建筑群，红场位于城墙之外。

俄罗斯莫斯科；现存城墙和塔楼主要形成于15世纪后期，并与不同年代的教堂、宫殿及行政建筑并存。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 中世纪 | 莫斯科的城防及统治中心逐步形成。 |
| 15世纪后期 | 伊凡三世时期重建城墙和主要教堂，意大利等地建筑师参与。 |
| 16—17世纪 | 随俄罗斯统治中心发展继续增建。 |
| 18—19世纪 | 宫廷与都城关系变化，19世纪建设大克里姆林宫。 |
| 1918年以后 | 苏维埃政府迁入莫斯科，使克里姆林再次成为国家政治中心。 |

## 实物特点与用途

### 城防与宫廷的复合空间

红色砖墙、塔楼、门道与河流共同构成防御边界，内部建筑则承担礼仪、宗教和统治职能。所谓“一座宫殿”不足以解释多时期、多用途的组成。

### 教堂与王权

圣母升天大教堂、天使长大教堂等与加冕、墓葬和宗教权威相连。俄罗斯建筑传统和外来工程经验共同形成样式，不能把所有建筑简单归为单一民族风格。

### 实物与政治象征

钟、炮、兵器、礼服和宝物等展品提供不同类型的宫廷及工艺证据；大型铸件的象征意义不等于实际战场使用。近现代政治新闻中“克里姆林宫”也常作政府的代称，应与建筑本体区分。

## 史料与参考

红场、圣瓦西里大教堂与克里姆林宫彼此关联但不是同一建筑。参观开放范围与政府办公区域也不同。不同政权对旧建筑的拆除、改造和保护应纳入历史，不能只强调未经改变的连续性。
