# 鲁尔工业区

## 时空定位

鲁尔工业区位于德国西部北莱茵—威斯特法伦州，是以煤矿、钢铁、铁路和城市群形成的历史工业地域。它不是单一工厂；埃森关税同盟煤矿工业建筑群可作为其发展、关闭与文化转型的具体实物案例。

外文检索名：Ruhr industrial region。现代地理定位：德国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 19世纪 | 煤炭开采与钢铁生产推动工业化、铁路和人口增长。 |
| 20世纪上半叶 | 战争、赔偿及国际政治使鲁尔成为竞争焦点。 |
| 20世纪后半叶 | 煤矿和传统重工业调整，失业与环境问题推动转型。 |
| 1986年及以后 | 关税同盟煤矿关闭，旧设施逐步转为文化、设计及公共参访空间。 |

## 实物特点与用途

### 煤钢体系

焦煤、炼焦、炼铁和钢铁加工通过运输与能源网络联系。矿井、焦炉和铁路是不同工序构件，不能把矿坑直接叫炼钢厂；产业集中依赖地质资源、资本、市场及国家政策。

### 劳动与城市

矿工及其他劳工来自多地，企业住宅、工会和公共设施塑造城市生活。工业产量不等于居民生活同样改善，危险劳动、污染和阶层冲突需要与技术变化一起讨论。

### 遗产与转型

关税同盟煤矿具有现代主义工业设计和完整生产设施，今天部分空间再利用。建筑保留能帮助理解产业，但文化旅游不能自动补偿所有失去的就业；环境治理、教育与新产业同样重要。
