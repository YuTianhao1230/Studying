# 古罗马大竞技场

## 时空定位

古罗马大竞技场位于罗马帕拉蒂尼山与阿文提诺山之间，是主要服务战车竞赛的大型赛场。它与斗兽场是不同设施：竞技场的长度、中央隔带及观众席适应赛道，斗兽场则围绕竞技区形成椭圆形建筑。

外文检索名：Circus Maximus。现代地理定位：意大利；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 王政时期；文献传统 | 谷地竞赛与早期设施起源相连。 |
| 共和国—帝国时期 | 看台、赛道和装饰持续扩建。 |
| 帝国时期 | 战车竞赛成为城市公共娱乐与政治表达的重要活动。 |
| 晚古代以后 | 使用衰退，材料被利用，近现代考古和公共空间管理展开。 |

## 实物特点与用途

### 战车与赛道

队伍沿中央隔带转圈，转弯、车轴、马匹控制与道路状况影响竞赛。竞赛组织需要马场、车手、后勤与赞助，不是完全自发的群众活动，车手也未必拥有自由身份。

### 派别与政治

颜色派别、支持者、皇帝观赛和赠予把娱乐与城市社会联系。观众规模在古代文本及现代估计中不同，不能把最大数字当作已逐席确认的固定容量。

### 遗存与再用

今天主要保留开放场地及局部考古遗迹，古代高层看台没有完整存续。音乐会和公众活动是现代再利用，不能据草地现状认为古代从无大型建筑。
