# 巨石阵

## 时空定位

巨石阵位于英国英格兰威尔特郡索尔兹伯里平原，是由环形土工设施、石圈、墓葬与周边遗迹组成的史前景观。主要建造和调整跨越新石器时代晚期至青铜时代，不能把今天可见石圈当作某一年一次完成的孤立建筑。

约前3000年开始营建早期围沟，约前2500年形成主要石构；位置在英格兰南部。世界遗产范围还包括埃夫伯里及相关遗址，不止石圈本身。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 约前3000年 | 修筑环形围沟与土堤，地点用于火葬及其他活动。 |
| 约前2500年 | 大型砂岩立石与横梁构成主要结构，蓝石配置又经历变化。 |
| 青铜时代 | 周边继续形成墓冢和相关景观。 |
| 近现代 | 进行考古研究、局部加固及倒石复立，形成今天的保护与参观安排。 |

## 实物特点与用途

### 石材、连接与运输

巨大砂岩和较小蓝石来自不同地质来源。部分横梁与立石以类似榫接的石工结构连接，显示不仅搬运石头，还需要设计高度与相互支撑。石源、运输方式和年代是不同研究问题，不能用一种最新石源发现自动解决所有搬运路径。

### 轴线与太阳

主轴与至日太阳方向有联系，适合说明天象如何进入仪式空间。对齐方向可被测量，但完整仪式、参与者身份与所有用途仍不能仅靠几何关系推定。称其为现代意义的精密天文台过于确定。

### 墓葬与区域联系

火葬、人骨和相关遗迹使解释范围超出石圈审美。达灵顿墙等周边地点提供聚集、生活和建设组织的线索，理解时应将遗迹、饮食及区域移动证据结合。

## 史料与参考

巨石阵早于中世纪的德鲁伊形象，后世传说和现代仪式不等于史前用途。没有文字记录留下唯一设计者，所谓外星人建造缺少考古证据。今天的照片包含加固与修复后的状态，也不能把全部石块位置直接当作未经改变的原貌。
