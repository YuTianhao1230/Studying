# 西斯廷礼拜堂

## 时空定位

西斯廷礼拜堂位于梵蒂冈宗座宫建筑群，15世纪西克斯图斯四世时期重建，名称由其教宗名而来。墙面、天顶和祭坛墙壁画由不同时期的艺术家完成，不能都归于米开朗基罗。

外文检索名：Sistine Chapel。现代地理定位：梵蒂冈；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1470—1480年代 | 礼拜堂重建，墙面壁画由多位艺术家绘制。 |
| 1508—1512年 | 米开朗基罗绘制天顶。 |
| 1536—1541年 | 米开朗基罗绘制《最后的审判》。 |
| 后世 | 出现遮绘、修补及现代清洁修复。 |

## 实物特点与用途

### 图像与神学

墙面基督与摩西的叙事、天顶《创世记》主题和祭坛墙审判图构成复杂安排。作品表现基督教故事与教会权威，不是历史学能够直接确认的神迹现场。

### 委托与艺术

教宗资助、艺术家团队、助手和材料组织共同决定工程。米开朗基罗并非靠躺着画完全部天顶的简单传奇，脚手架、工作姿态和湿壁画技术应结合研究。

### 礼仪与观看

礼拜堂承担宗教仪式及教宗选举等功能，同时供公众参访。灯光、游客和修复影响观感，今天鲜明色彩涉及清洁与保存选择，不能与多年烟尘覆盖时的照片无条件比较。

## 史料与参考

作品年代、作者及宗教解释应分别核对。礼拜堂是宗座宫的组成部分，现代馆藏参观路线不等于最初礼仪路线。
