# 巴黎圣母院

## 时空定位

巴黎圣母院位于巴黎西岱岛，是天主教巴黎主教座堂，1163年开始主要营建，工程跨越中世纪多个阶段。它以哥特式结构、雕塑和城市仪式著称，2019年大火及后续修复是新的历史阶段。

外文检索名：Notre-Dame de Paris。现代地理定位：法国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1163年起 | 主教座堂主要工程开工。 |
| 12—14世纪 | 唱诗班区、立面、塔楼及其他部分逐步形成。 |
| 19世纪 | 维奥莱-勒-迪克等主持修复，加入或重建部分形制。 |
| 2019—2024年 | 火灾毁坏木屋架与尖塔，修复后于2024年重新开放。 |

## 实物特点与用途

### 哥特式结构

尖拱、肋拱顶和飞扶壁共同处理重量及侧推力，使高墙和较大窗洞成为可能。飞扶壁、墙体和屋架有不同阶段，不能只靠一个构件解释全部建筑。

### 礼仪与艺术

雕塑、彩窗和空间联系礼拜、教会教育及赞助。西岱岛的城市位置使它参与政治和公共仪式，小说对建筑的再认识属于19世纪接受史，不是营建时的原始用途。

### 火灾与修复

2019年火灾主要破坏屋顶系统及尖塔，石构主体部分保留并需加固。修复选择涉及材料、工艺和历史阶段，重新开放不意味着所有维护自此结束。
