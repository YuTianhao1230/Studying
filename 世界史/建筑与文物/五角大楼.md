# 五角大楼

## 时空定位

五角大楼位于美国弗吉尼亚州阿灵顿，靠近华盛顿，是美国国防部总部建筑。1941年开工、1943年正式落成，最初为战争时期集中陆军部门办公而建；国防部制度名称后来形成。

外文检索名：The Pentagon。现代地理定位：美国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1941年 | 在快速扩大的战争行政需求下开工。 |
| 1943年 | 建筑正式落成。 |
| 1947年及以后 | 美国国防组织重组，建筑成为新的国防系统总部。 |
| 2001年及以后 | 恐怖袭击造成局部破坏，重建与纪念设施形成。 |

## 实物特点与用途

### 布局与办公

五边形、同心环和放射走廊组织大量办公室及交通，造型和原选址条件相关。建筑位于阿灵顿，不在华盛顿特区内，行政功能也不等于所有美国军事机构都集中于此。

### 战争与工程

快速施工依赖材料、劳动力及联邦组织，结构和设施随后持续更新。完成日期不能理解为之后所有房间和系统都未变化，现代国防部也并非1941年已有同样名称与架构。

### 袭击与记忆

2001年袭击影响建筑、工作人员和乘客，重建及纪念分别承担办公恢复与悼念。公开照片展现外部形制，不意味着内部全区开放参访。
