# 特诺奇蒂特兰大神庙

## 时空定位

特诺奇蒂特兰大神庙位于今天墨西哥城历史中心，是墨西加人的王室宗教核心。两座并列神殿与维齐洛波奇特利、特拉洛克联系；它不是现代完整重建的金字塔，而是多次扩建留下的建筑遗存。

外文检索名：Templo Mayor。现代地理定位：墨西哥；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 14世纪起 | 特诺奇蒂特兰形成并发展神圣中心。 |
| 15—16世纪初 | 大神庙反复包覆、扩建，配合王权与礼仪。 |
| 1521年以后 | 征服与殖民城市建设造成毁坏和材料再利用。 |
| 1978年及以后 | 科约尔绍基浮雕发现推动系统考古和博物馆建设。 |

## 实物特点与用途

### 双神殿与社会

战争及太阳神崇拜与雨水、农业神崇拜共享台基，体现国家权力和生计秩序的联系。不能把整个纳瓦宗教压缩为一个好战神祇，也不能忽略不同神、地区和礼仪的差异。

### 层叠营建与献纳

统治者在旧建筑外增建新层，保存了可比较的阶段和供奉物。献纳坑中的动物、植物、海产及工艺品反映长距离资源与仪式选择，出土地点不必等于物品产地。

### 暴力与征服资料

人祭具有考古和文字证据，但人数、仪式频率与叙述目的必须分别核对。殖民记录可能服务基督教征服合法化，不能照单全收；也不能因来源有偏向而否认全部直接证据。

## 史料与参考

墨西哥国家人类学与历史研究所的发掘、原住民图文记录和西班牙叙述应互相校验。今天街道和教堂覆盖古城，现代定位不能完整重现旧湖泊城市布局。
