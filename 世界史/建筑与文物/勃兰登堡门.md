# 勃兰登堡门

## 时空定位

勃兰登堡门位于柏林，主要建于1788—1791年，由卡尔·戈特哈德·朗汉斯设计，是普鲁士首都的古典主义城门。门顶四马车1793年安装，战争、分裂和统一不断改变其象征意义。

外文检索名：Brandenburg Gate。现代地理定位：德国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1788—1791年 | 普鲁士王室营建新门。 |
| 1793年 | 沙多设计的四马车安装。 |
| 1806—1814年 | 拿破仑军队夺取车像，后来归还。 |
| 1961—1989年及以后 | 处于柏林墙相关边界空间，开放与统一赋予新意义。 |

## 实物特点与用途

### 古典语言

柱列与门廊借鉴古希腊形式，在18世纪表达首都秩序。它不是古代希腊建筑搬来德国，名称也不意味着门是当代勃兰登堡州政府所有。

### 四马车与战争

车像的迁移、归还和徽章变化使原来设计进入国家胜利记忆。雕塑经历战损和修复，今日所见不能简单当作完整1793年原件。

### 分裂与公共空间

柏林墙时期附近通行受到控制，门成为分裂象征。1989年开放后又成为团聚与纪念空间，建筑本身的含义由制度、媒体和公共活动持续塑造。

## 史料与参考

城门建成年、雕塑安装年和修复阶段需区分。把它只定义为统一德国的专用纪念门，会掩盖其更早普鲁士背景。
