# 联合国总部

## 时空定位

联合国总部位于纽约曼哈顿东河沿岸，主要建筑群在1940年代末至1950年代初建设，1952年正式落成。它是联合国机构办公、会议和外交活动的空间；总部位于美国，不意味着联合国是美国政府部门。

外文检索名：United Nations Headquarters。现代地理定位：美国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1945—1946年 | 联合国成立并讨论永久总部地点。 |
| 1947年 | 多国建筑师团队展开设计，总部协定确立相关法律安排。 |
| 1949—1952年 | 秘书处、大会议厅及会议建筑等逐步建成。 |
| 21世纪 | 开展总体维修工程以更新设施、提高安全和能源表现。 |

## 实物特点与用途

### 国际合作设计

华莱士·哈里森主持设计协调，勒·柯布西耶、奥斯卡·尼迈耶等参与方案工作。最终建筑来自团队讨论与调整，不能只归功于某一名建筑师。秘书处高层楼与低层会议空间体现不同工作功能。

### 建筑与外交

大会厅、安理会会议厅、秘书处及代表活动区承担不同制度角色。拥有会议空间不等于各机构权限相同，建筑大小也不能用来推断国际法权力。公共艺术和成员国赠礼体现外交表达。

### 法律与维护

总部有由国际协定保障的特权与豁免，但土地并不是脱离地球国家体系的独立主权国家。办公、安保和后期维修都依赖成员国财政及东道国条件；今天参观安排与1940年代开放理念存在变化。

## 史料与参考

联合国官方建筑史与总部协定可以核对设计、启用和法律地位。新闻中所谓国际领土常是简化表达，不能据此宣称纽约总部拥有国家主权。
