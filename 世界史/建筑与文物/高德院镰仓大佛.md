# 高德院镰仓大佛

## 时空定位

镰仓大佛位于日本神奈川县镰仓高德院，是13世纪阿弥陀佛青铜像。今天露天端坐的状态来自佛殿毁坏后的变化，不能认为塑像从初建起就一直被设计为露天景观。

外文检索名：Great Buddha of Kamakura, Kōtoku-in。现代地理定位：日本；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1243年；传统记录 | 较早木造大佛及殿堂形成。 |
| 1252年 | 青铜大佛铸造的主要年代依据。 |
| 中世纪后期 | 佛殿遭风暴及其他灾害毁坏，塑像逐渐露天。 |
| 近现代 | 进行基础加固、内部调查和保护。 |

## 实物特点与用途

### 铸造与结构

大型铜像通过分段铸造和连接完成，内部空腔与铸接痕迹提供工艺线索。铜合金表面和原有镀金痕迹不能从今天色泽直接推断全部原貌，塑像与莲座、基座的年代也应分别核对。

### 阿弥陀信仰

阿弥陀佛与净土传统的救度观念联系，手印和坐姿属于宗教图像体系。信徒对佛的理解不等于历史学能够证明超自然存在，也不能把这座佛像等同于所有日本佛教流派。

### 资助与城市

大型营建依赖募资、工匠与地方宗教网络。镰仓是武家政治中心，但不能据地点就认定全部工程由某位幕府将军独立发起；赞助与主持传统需要原始记录支持。

## 史料与参考

高德院官方沿革和工艺调查可区分传统灾害叙述与实物研究。照片展现后期露天和维护状态，并非13世纪完整寺院复原。
