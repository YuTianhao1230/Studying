# 亚历山大图书馆

## 时空定位

古亚历山大图书馆形成于托勒密王朝早期，与缪斯学宫及王室知识赞助体系联系。它不是今天2002年开放的新亚历山大图书馆；古代主馆建筑、馆藏规模和终结过程都无法完整复原。

外文检索名：Ancient Library of Alexandria。现代地理定位：埃及；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 前3世纪初 | 托勒密王室建立学术机构并组织藏书。 |
| 希腊化时期 | 学者参与整理、校勘、数学、地理和自然研究。 |
| 前48年及以后 | 战争与城市火灾留下可能涉及藏书损失的记录。 |
| 罗马时期—晚古代 | 学术、王室区及相关宗教空间持续变化，不能以单次火灾概括所有机构消亡。 |

## 实物特点与用途

### 知识与王权

学者、抄写员、译者和采购网络共同维持收藏。文本以卷轴计数时，一部作品可能由多卷组成，古代数十万卷的说法不是现代书籍数量，也不能视为已盘点确认的统计。

### 研究与文本工作

校勘荷马诗篇、目录编纂与不同学科讨论把阅读转为机构化工作。卡利马科斯等人的目录实践与埃拉托色尼等学者的研究具有不同职责，不应把所有古代科学成果都说成在此完成。

### 损失与重建记忆

凯撒战事、后续王室区破坏和晚古代宗教冲突发生在不同时段。塞拉皮斯神庙的藏书与主馆关系需要区分；有关阿拉伯征服者一次烧毁全部古典知识的故事缺乏可靠同时代支持。
