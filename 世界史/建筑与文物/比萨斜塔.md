# 比萨斜塔

## 时空定位

比萨斜塔是意大利比萨主教座堂建筑群的独立钟楼。它因基础土层和结构荷载引起倾斜，工程在数百年间分阶段完成。塔、主教座堂、洗礼堂和墓园共同说明中世纪城市宗教与海上商贸实力，不能把斜塔当作专门为倾斜而设计的建筑。

意大利托斯卡纳比萨；1173年开工，主要营建延续至14世纪。塔在主教座堂广场，距离罗马和佛罗伦萨均有独立地理位置。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 1173年 | 钟楼开工。 |
| 12世纪后期 | 工程早期已出现倾斜，施工多次中断。 |
| 13—14世纪 | 继续加层，尝试在结构中补偿倾斜；钟室完成。 |
| 1990—2001年 | 因安全问题关闭，工程团队采用加固、配重及地基处理等措施，后重新开放。 |

## 实物特点与用途

### 地基为何使塔倾斜

不均匀沉降来自软弱且变化的地层与建筑荷载。增建上层会改变重心，补偿处理又使塔身并非单一直线。解释不能只说“地下有水”，而须考虑土、基础、时间和结构相互作用。

### 钟楼的城市功能

回廊、柱列和白色石材形成独特视觉节奏，顶部钟室服务宗教及公共报时。斜塔属于比萨罗曼式建筑环境，与城市教会、商人及工匠组织相关。

### 保护不是把它完全扶直

近现代工程降低风险并保留历史倾斜特征，采取渐进监测和干预。稳定状态要按具体工程报告理解，不能写成永久无需维护，也不能凭游客照片量出可靠倾角。

## 史料与参考

伽利略在塔上投球的著名故事缺少同等强度的直接史料，宜视为有争议轶事；不能据此证明其全部实验都在斜塔完成。建筑多阶段修正也不代表建造者已经理解现代土力学。
