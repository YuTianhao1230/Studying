# 卡霍基亚土丘

## 时空定位

卡霍基亚位于今美国伊利诺伊州密西西比河东岸、圣路易斯附近，是密西西比文化的大型聚落及土丘群。主要兴盛期约1050—1350年；今天的地名来自后来的族群称名，不能直接认定建造者与同名历史社群完全一致。

外文检索名：Cahokia Mounds。现代地理定位：美国；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 约1050年 | 聚落规模和公共工程显著扩展。 |
| 11—13世纪 | 大型土丘、广场与居民区形成复杂中心。 |
| 14世纪 | 主要中心衰退，具体原因涉及多种解释。 |

## 实物特点与用途

### 土丘与公共劳动

僧侣丘等大型台地由分阶段搬运土方形成，顶部建筑与公共空间联系。土丘是人造工程，不是天然山峰；不同土丘的形态、年代和葬仪功能不能一概而论。

### 农业与交流

玉米农业、河流交通、工艺与远距离物品流动支撑人口集中。中心政治组织存在等级，但人口估计与政权结构需要依据考古推断，不能凭规模编造确定国王名单。

### 环境与离散

洪水、资源使用、社会竞争与气候条件是衰退研究的重要方向，没有足够证据用一个原因解释全部过程。居民离开中心不意味着所有原住民消失，也不能以欧洲抵达作为文明存在的起点。

## 史料与参考

土层、居址、墓葬与环境样本相互补充，复立木圈属于现代考古重建。现代族群关系与古代遗存的连续性应尊重原住民研究和不同证据。
