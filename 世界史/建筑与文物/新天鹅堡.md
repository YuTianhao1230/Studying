# 新天鹅堡

## 时空定位

新天鹅堡位于德国巴伐利亚施旺高附近，1869年开始建设，是路德维希二世委托的19世纪王室居所与艺术想象。它借用中世纪城堡语言，不能被称为真正中世纪军事堡垒。

外文检索名：Neuschwanstein Castle。现代地理定位：德国；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1869年 | 营建开始。 |
| 1880年代 | 国王短期使用部分已完成房间。 |
| 1886年 | 国王死亡，建筑未全部按原计划完成并转向参观开放。 |
| 后世 | 进行保护、旅游管理和结构维护。 |

## 实物特点与用途

### 想象与技术

外观借鉴罗曼式及骑士题材，内部却使用19世纪供水、采暖和其他设施。风格来源与真实建造年代是两种问题，不能因塔楼和城垛而认定用于实际守城。

### 艺术与王权

瓦格纳作品和骑士叙事影响室内图像，国王的艺术追求与失去部分政治作用的王室环境联系。私人幻想、财政和宫廷制度共同解释工程，不宜以一个浪漫称号代替分析。

### 未完成与旅游

许多设计未实施，今天参访只进入部分空间。后世旅游宣传强化童话意象，游客熟悉的剪影并不能证明所有房间已完工或全部陈设原封不动。
