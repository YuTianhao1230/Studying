# 普罗拉建筑群

## 时空定位

普罗拉位于德国吕根岛波罗的海岸，1936—1939年由纳粹“力量来自欢乐”组织营建大型度假建筑群。计划没有作为完整度假设施投入原定运营，战争及后来的军用、旅游改造形成不同阶段。

外文检索名：Prora。现代地理定位：德国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1936年 | 大型海滨度假工程开工。 |
| 1939年 | 战争爆发，工程未完整实现并停顿。 |
| 战后 | 不同军队及东德军事机构使用部分建筑。 |
| 德国统一后 | 纪念、博物馆、住宿和地产开发改变用途。 |

## 实物特点与用途

### 设计与宣传

克莱门斯·克洛茨设计的长条建筑试图集中大批休假人员。休闲政策同时服务政权动员和劳动控制，不能把宣传口号当作所有工人已享有平等假期的证据。

### 规模与未完成

连绵立面呈现集中式布局，计划容量与实际使用人数是不同指标。未建成的公共设施不能依据规划图当作已经存在，今天改造房间也不代表1939年住宿状态。

### 困难遗产

遗址保存、商业开发和历史教育之间存在张力。将纳粹工程只称为壮观酒店会遮蔽政治背景，完全拆除也不自动解决记忆问题，需要解释各阶段用途。

## 史料与参考

施工照片、规划、军用记录及遗产机构资料可区分宣传与实际。建筑没有完成原定度假运营，不能写成纳粹成功开办的常规海滨酒店。
