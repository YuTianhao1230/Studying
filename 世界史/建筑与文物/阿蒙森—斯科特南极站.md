# 阿蒙森—斯科特南极站

## 时空定位

阿蒙森—斯科特南极站位于地理南极附近，由美国南极计划运营。首站于1956—1957年国际地球物理年准备期间建立，站名纪念1911年先后到达南极的阿蒙森与斯科特探险队；他们并没有建造今天的科研站。

外文检索名：Amundsen–Scott South Pole Station。现代地理定位：美国为运营国；站址在南极洲，非该国主权领土。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1911—1912年 | 阿蒙森队与斯科特队先后到达南极，留下不同探险经历。 |
| 1956—1957年 | 美国建立第一代常驻站并开始观测。 |
| 1975年 | 穹顶站成为第二代核心设施。 |
| 2008年 | 高架新站正式启用，改善积雪、居住和科研条件。 |

## 实物特点与用途

### 冰上建筑

站址处于厚冰层上，冰体会运动，地理南极标志需要定期调整。高架结构可降低积雪堵塞影响，并通过可调整构件适应沉降；极寒、强风和高海拔决定材料与施工季节。

### 观测与保障

大气、天文、冰川及粒子物理研究利用长期观测和特殊环境。科研同时依赖航空运输、能源、食物与越冬人员，不能只把站点写成一个孤立纪念碑；IceCube探测设施与生活站区也不是同一栋建筑。

### 国际制度

南极条约体系与环境规则限制活动并促进科学合作。运营国家不意味着站址具有被普遍承认的美国主权，科学设施也不等于允许无限开采资源。极地研究有燃料、废弃物与物流环境成本。

## 史料与参考

美国南极计划的站史和站点说明适合核对各代建筑。关于极夜、海拔和坐标应区分站区、地理点及冰面变化，不套用固定不变的城市坐标。
