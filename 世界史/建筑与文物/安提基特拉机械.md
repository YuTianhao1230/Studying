# 安提基特拉机械

## 时空定位

安提基特拉机械是从希腊安提基特拉岛附近沉船发现的古代齿轮装置残片，现藏雅典国家考古博物馆。它将齿轮与天文周期联系，可显示历法和预测某些天象，常被称为古代模拟计算装置。它不是电子电脑，也不是能执行任意程序的通用计算机。

机械通常定于前2世纪末至前1世纪，制作年代仍有不同估计；沉船年代、装置制造年代与20世纪发现时间必须区分。

## 建造与历史变迁

| 阶段 | 变化与证据 |
| --- | --- |
| 希腊化时期 | 天文模型、历法和精密金属加工为装置提供背景。 |
| 前1世纪 | 装置随船沉没，实际制造可能更早。 |
| 1900—1901年 | 海绵潜水者发现并打捞沉船物品。 |
| 20世纪以来 | 研究者识别齿轮、刻度和铭文。 |
| 21世纪 | X射线断层扫描及表面成像推进内部结构与文字辨识。 |

## 实物特点与用途

### 齿轮怎样对应天象

按比例啮合的齿轮把手动旋转转成不同周期的指示，例如联系阴阳历协调的默冬周期和食相的沙罗周期。具体显示系统需按保存结构和铭文核对，不是每个现代复原方案都已被残片完整证明。

### 计算不只存在于数字电子时代

机械能把已知周期关系嵌入结构，操作者据指针读取结果。这种专用模拟计算与布尔逻辑、存储程序是不同技术路线，适合用来扩展计算史而非争夺同一个“第一台电脑”标签。

### 残片与复原

腐蚀损坏留下部分齿轮和外壳信息，成像能揭示不可直接看见的细节。现代完整模型包含解释和补足，应明确已知、推定及不同方案的差异。

## 史料与参考

确切作者、作坊及全部功能尚不能确定。与阿基米德等人的联系可作为研究背景，不能将缺少直接证据的具体作者归属写成事实；现存原件的复杂性也不支持外星科技叙事。
