# 里约基督像

## 时空定位

里约基督像位于巴西里约热内卢科尔科瓦多山顶，1931年揭幕，是钢筋混凝土结构、表面覆皂石拼片的基督像。它表达20世纪天主教公共纪念和城市景观，不是葡萄牙殖民初期留存的雕像。

外文检索名：Christ the Redeemer。现代地理定位：巴西；只用于定位，不代表古代国界。

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1920年代 | 宗教团体募资并确定建设方案。 |
| 1926—1931年 | 雕塑、结构和山顶施工展开。 |

| 后世 | 经历雷击、风化和多轮维护，交通及参访设施扩充。 |

## 实物特点与用途

### 协作与工程

巴西工程师海托尔·达·席尔瓦·科斯塔负责重要设计组织，保罗·朗多夫斯基参与雕塑，阿尔贝·卡科参与结构工作。造型、结构计算和现场施工是不同环节，不能以单个名字抹去团队及工人。

### 材质与地形

山顶风、雨和雷击影响保护，混凝土承担结构，皂石拼片形成表面。张开双臂的形象具有宗教意义，不能只以纯装饰概括；由山下照片也无法判断内部结构状态。

### 宗教与城市

雕像与山、海湾、城市及森林组成可辨认景观。纪念工程联系宗教公共角色和现代国家身份，但巴西居民并非全部属于同一信仰，城市地标不等于统一教籍。

## 史料与参考

雕像及里约世界遗产景观的范围不同；后世修复和灯光是现状组成。作者版权与摄影许可应分别核对，不能把现代雕塑默认视为公共领域。
