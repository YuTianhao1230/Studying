# 伦敦塔白塔

## 时空定位

白塔是伦敦塔城堡群的核心石砌主塔，11世纪后期威廉一世时期开始营建。伦敦塔后来扩展围墙、塔楼、居住及管理建筑，白塔不能等同整个城堡群。

外文检索名：White Tower, Tower of London。现代地理定位：英国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 约1078年起 | 诺曼王权组织主塔建设。 |
| 12—13世纪 | 城堡群扩充外部防御与居住空间。 |
| 后世 | 承担王室居住、拘禁、军械及其他管理用途。 |
| 近现代 | 作为历史遗产与军械展示空间保护。 |

## 实物特点与用途

### 主塔与征服

厚石墙、大厅和礼拜堂表达军事控制与王权。伦敦城市位置使堡垒同时面向居民与外部威胁，不能仅称为保护居民的建筑而忽略征服统治。

### 内部功能

圣约翰礼拜堂、居住和仪式空间说明主塔不只是监狱。伦敦塔各时期囚禁故事与地点要区分，不能把每位囚犯都关在白塔同一房间。

### 武器与展示

军械收藏和博物馆陈列来自不同年代，装甲不能都认作11世纪原装。珍宝展区、外墙塔与白塔属于不同空间，旅游路线不等于原始宫廷通行制度。

## 史料与参考

皇家宫殿与世界遗产资料可核对工程和用途。白塔初建年采用约数，后世窗口与屋顶调整影响现景。
