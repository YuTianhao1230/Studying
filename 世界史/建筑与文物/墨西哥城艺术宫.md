# 墨西哥城艺术宫

## 时空定位

墨西哥城艺术宫是20世纪形成的剧院、美术展示与文化机构建筑，1904年开工、1934年正式开放。外部艺术风格与内部装饰来自不同工程阶段，不能将整个建筑简单归为单一风格。

外文检索名：Palacio de Bellas Artes。现代地理定位：墨西哥；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1904年 | 阿达莫·博阿里主持的新剧院工程开工。 |
| 1910年代 | 革命、财政及地基问题影响施工。 |
| 1930年代 | 费德里科·马里斯卡尔等推动完成。 |
| 1934年及以后 | 开放并成为表演、壁画与展览的重要场所。 |

## 实物特点与用途

### 结构与地基

墨西哥城软弱地层和沉降影响大型石构工程，建筑需要持续监测。外部华丽材料不能抵消地质约束，长期工期不能只归因于政治事件。

### 艺术风格与协作

外部包含新艺术与古典语言，内部则有装饰艺术等特征。舞台、幕帘、装饰和壁画由多位艺术家参与，不能把所有艺术都归给建筑师。

### 公共文化

歌剧、音乐、舞蹈和美术展览支持国家文化展示。里韦拉等壁画与革命后政治艺术相连，作品叙事应视为艺术解释而非中立历史照片。

## 史料与参考

开工、设计更替和开放日应区分。艺术宫与其他城市同名宫馆不混用，馆藏壁画的年代不等于建筑开工年。
