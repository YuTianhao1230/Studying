# 巴特西发电站

## 时空定位

巴特西发电站位于伦敦泰晤士河南岸，是20世纪燃煤发电工业建筑，两个主要建设阶段分别在1930年代和1950年代完成。它已停止发电并进行商业再利用，四座烟囱是工业历史的外部标志。

外文检索名：Battersea Power Station。现代地理定位：英国；只用于定位，不代表古代国界。

## 建造与历史变迁

| 时段 | 营建、使用与变化 |
| --- | --- |
| 1930年代 | A站建成并投入供电。 |
| 1950年代 | B站扩建，形成四烟囱总体形象。 |
| 1975—1983年 | 两站先后停止发电。 |
| 21世纪 | 修复及再开发后转为商店、办公、住宅等用途。 |

## 实物特点与用途

### 发电流程

燃煤加热水产生蒸汽，汽轮机驱动发电机，电力再接入城市系统。锅炉、汽轮机、冷却与排烟是不同环节，烟囱不是直接产生电能的设备。

### 工业与城市

大规模电力支撑交通、照明和生产，也依赖煤炭运输、劳动及空气和水环境。建筑外观受到吉尔斯·吉尔伯特·斯科特等设计参与影响，但技术系统出自多方协作。

### 再利用与分配

保留外壳与修复烟囱帮助延续工业景观，内部则有重大改造。商业成功需要与土地、住房及公共可达性一起评价，购物空间不能代替对原发电劳动的解释。

## 史料与参考

原始机组、现存外壳和新开发空间需区分。宣传中的重新开放指商业用途，不是恢复燃煤发电。
