# 电力与电报

## 技术定位

电力系统将能量以电的形式产生、输送和使用；电报把消息编码为电信号。前者解决动力与照明，后者解决远距离通信，二者相关却有不同技术链。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 1800年 | 伏打电堆提供相对持续的电流来源。 |
| 1831年 | 法拉第研究电磁感应，为发电技术提供重要基础。 |
| 1830—1840年代 | 针式电报和莫尔斯系统等方案进入应用；1844年美国华盛顿—巴尔的摩线路成为著名节点。 |
| 19世纪后期 | 海底电缆、发电机与城市供电扩大，交流与直流方案竞争并发展。 |

## 原理与关键变化

电磁感应使变化磁通产生电动势，发电机将机械运动与线圈、磁场结合。供电还需要导线、绝缘、保护、计量与负荷管理，发电机发明不等于家庭立刻通电。

电报通过键控、编码、线路和接收装置传输信息。海底电缆需要防水绝缘、敷设、信号检测和维修，长线路也面对衰减与干扰。新闻和报价可以先于货物到达，改变商业时间尺度。

爱迪生、特斯拉、西门子等人的贡献应放在公司、工程师和国家网络中理解。交流便于通过变压器改变电压，降低远距离输电损耗，但系统选择也由安全、投资和设备条件影响。

## 传播与社会影响

照明与电动机改变工厂、家庭和城市生活，电报加强新闻、外交、军事与金融联系。通信快并不意味着信息平等，收费、线路控制与识字条件决定接入。

发电仍需要能源，电力不是无代价资源。煤电、水电与其他发电方式有不同环境影响；基础设施故障也能让社会活动同时受阻。
