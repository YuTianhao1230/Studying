# 蒸汽机与铁路

## 技术定位

蒸汽机将热能转为机械功，铁路把动力、车辆、轨道和运输组织结合起来。瓦特改良蒸汽机，之前已有纽科门等人的实用机器；一台机器与覆盖区域的铁路系统也不能混为一谈。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 1712年 | 纽科门式大气蒸汽机用于矿井排水，耗燃料较多。 |
| 1769年 | 瓦特取得分离式冷凝器相关专利，减少汽缸反复冷热带来的损耗。 |
| 19世纪初 | 高压蒸汽与机车实验发展，1825年斯托克顿—达灵顿铁路、1830年利物浦—曼彻斯特铁路成为重要节点。 |
| 19世纪后期 | 铁路扩张与钢轨、时刻表、金融和国家建设相互结合。 |

## 原理与关键变化

早期大气机利用蒸汽凝结形成压差，使活塞运动；瓦特把冷凝移到独立部件，避免工作汽缸每次被冷却。后来的高压和复合膨胀等改进又提高动力与适用范围。

铁路依靠轨道导向、轮轨承载、动力传递与制动系统。铺轨还要处理坡度、桥梁、隧道、信号和维护，不能用机车照片代替整个运输系统。

煤炭、金属加工、机器维修、资本和货源共同决定经济性。水力和人力在很多地区继续存在，工业化不是蒸汽在同一年替代所有动力。

## 传播与社会影响

铁路缩短部分运输时间，改变工厂选址、市场范围、城市增长与军队调动。统一时刻表促进时间标准化，线路也可能服务殖民资源外运。

收益包括更稳定的运输，代价包括征地、事故、污染与不平等票价。判断某地铁路的历史作用，要看货物方向、产权、劳动和国家政策，而不仅是里程。
