| [晶体管与集成电路](<晶体管与集成电路.md>) | 晶体管用半导体控制电流，可以执行放大或开关功能；集成电路在共同基底上制造多个器件与互连。二者是相关的不同层次：晶体管是器件，芯片是组织大量器件的制造体系。 |
| [电力与电报](<电力与电报.md>) | 电力系统将能量以电的形式产生、输送和使用；电报把消息编码为电信号。前者解决动力与照明，后者解决远距离通信，二者相关却有不同技术链。 |
