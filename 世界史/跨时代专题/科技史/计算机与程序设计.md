# 计算机与程序设计

## 技术定位

计算机把可明确描述的操作交由机器执行，程序设计则将任务转为指令、数据表示和控制流程。计算史包含机械数表、逻辑代数、理论模型、机电和电子机器、编程语言及软件工程等不同路线。自动、数字、可编程、电子、通用和存储程序是不同判据，不能只争论一个没有定义的“第一台电脑”。

本卡解释连续发展，人物的生平、具体作品和贡献边界进入各自权威正文。互联网、晶体管与信息论也与计算联系，但不能互相替代。

## 发展时间线

| 阶段 | 解决的问题与代表性变化 |
| --- | --- |
| 古代至近世 | 算盘、数学表、专用天文齿轮装置和机械计算器采用不同方法辅助运算，不属于同一种机器。 |
| 19世纪前半叶 | 巴贝奇的差分机针对数表；分析机尝试通用程序控制，洛夫莱斯解释程序与符号处理潜力。 |
| 19世纪中叶 | 布尔推进逻辑代数，后人逐渐发展形式逻辑与工程联系。 |
| 1930年代 | 图灵等研究可计算性；香农将逻辑代数用于开关电路，理论与工程解决不同问题。 |
| 1930—1940年代 | 祖塞等制造可编程机电机器，英美团队推进电子计算。战争需求与国家资助改变规模。 |
| 1940—1950年代 | 存储程序思想传播，机器指令与数据可保存在机器可访问的存储中；报告、原型与投入使用须区分。 |
| 1950—1960年代 | 霍珀等推进自动编程、业务语言和标准；麦卡锡发展Lisp与人工智能研究议程。 |
| 1960年代以后 | 分时计算、操作系统、软件工程及可靠性设计回应多人使用和大型系统需求；阿波罗软件是重要案例。 |
| 1970年代以后 | 集成电路、个人电脑与网络降低部分使用门槛，也形成新的产业、标准和平台权力。 |

## 原理与关键变化

### 从公式机器到通用程序

差分机把特定数学方法嵌入机构，擅长一个定义清楚的任务。分析机、后来的通用机器则让操作顺序由程序决定，使同一硬件能够处理不同任务。硬件通用性、可用编程工具和实际运行效率是不同层次，不能由理论模型直接推断商业机器的性能。

### 理论、电路和信息

图灵机用抽象规则研究算法能够完成什么，以及不可计算问题的界限；它不是一份必须按纸带和读写头制造现代芯片的工程图。布尔代数描述逻辑关系，香农把它用于开关电路，又建立通信不确定性的量化理论。这些工作相互联系，但逻辑真值、信息量和一条消息在现实中的真假不是同一问题。

### 存储程序与软件层次

机器能读取存储中的指令后，装载和修改程序更加方便。汇编、编译器、操作系统与高级语言把不同职责分开：语言表达任务，编译或解释工具实现执行，操作系统管理资源。编译器发展是团队和长期规范的成果，“第一编译器”需说明功能，不能把早期子程序组合系统无条件等同于今天完整工具链。

### 正确性与可靠性

一个算法算对输入，不代表整个系统可靠。设备故障、资源过载、时序、中断及人员误操作可能导致失败。阿波罗机载软件中的优先级、重启及错误预防说明，软件工程要将需求、设计、测试和运行条件共同处理。著名照片或一个恢复故事不能覆盖所有参与者。

## 传播与社会影响

军事、科研和企业管理提出不同计算需求，机器制造依赖材料、仪器、能源与资金。大型机、分时终端和个人电脑改变谁能使用计算资源，业务语言与标准影响程序的维护和迁移。

计算提升部分处理能力，也改变劳动分工、数据收集和权力分配。自动化效果取决于任务、数据、成本及制度，不是只要接入电脑就必然提高效率。计算史应保留操作者、程序员、制造团队和维护劳动，而非只排列“计算机之父”。
