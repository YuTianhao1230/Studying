# 农业、灌溉与粮食生产

## 技术定位

农业是一组管理植物、动物、土地和水源的技术与社会实践。西亚、东亚、美洲等地存在不同驯化中心；定居、种植和畜牧的先后关系并不一致。灌溉提高部分地域的生产稳定性，也要求维护、分水和处理盐碱化。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 约前一万纪起 | 西亚部分社群逐步增加栽培和动物管理；东亚等地区形成各自的作物体系。 |
| 新石器时代 | 磨制工具、储藏、陶器和房屋改变劳动与食物管理，野生采集仍长期存在。 |
| 早期国家时代 | 水渠、堤岸、田地丈量与粮食征收把农业工程和政治组织连接起来。 |

## 原理与关键变化

驯化是长期选择带来植物或动物性状变化的过程，不能等同于某次播种。人们保存种子、控制繁殖、调节水肥并改变环境，作物反过来约束劳动日历与聚落位置。

灌溉通过渠系把水引向田地，必须同时解决坡度、淤积、蒸发与排水。尼罗河洪水、两河人工渠系、东亚水田和安第斯梯田各有环境条件，不存在一套适用于所有地区的最佳技术。

储粮使季节间调配成为可能，也带来虫害、损耗与粮仓管理。考古应联合种子、骨骼、工具、聚落和土壤分析，不能仅凭一处粮仓证明存在中央国家。

## 传播与社会影响

农业支持更大人口和劳动分工，但疾病暴露、饮食单一、劳役及财产不平等也可能增加。人口增长不是所有家庭生活改善的证明。

国家可以协调工程，也可以征收剩余；村落、家族和地方合作同样能管理水利。不能从大型灌溉直接推出必然存在专制制度。今天的机械与肥料改变生产条件，早期农业的地方经验仍影响作物和景观。
