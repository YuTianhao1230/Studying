# 冶金与铁器

## 技术定位

冶金是从矿物获取、提纯、熔炼和加工金属的技术体系。自然铜加工、铜冶炼、青铜合金和铁冶炼是不同步骤；青铜时代、铁器时代只是部分地区的考古分期，不能作为全球同步年表。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 铜器阶段 | 自然铜可锤打，冶炼则需要处理矿石与炉内温度、气氛。 |
| 前四至前三千纪及以后 | 部分地区青铜技术发展，铜与锡等原料交换扩大；具体合金和年代因地区而异。 |
| 前二至前一千纪 | 铁冶炼与锻造逐渐扩散，后续钢铁技术并非一次出现。 |

## 原理与关键变化

青铜常由铜与锡合金化，铸造便于制作复杂形状，硬度与耐用性取决于成分和加工。矿山、燃料、炉子、坩埚、模具与工匠经验缺一不可；原料贸易能连接相距很远的生产地区。

早期块炼铁常得到夹杂炉渣的海绵状铁，需要锻打净化。铁不是天然就比所有青铜器硬；含碳量、热处理、锻造和用途共同决定性能。陨铁使用也不等于已经掌握矿石冶炼。

铁矿分布较广，但高温工艺、木炭供给与专业技能决定扩散速度。中国、南亚、西亚、欧洲及非洲冶金需按各自证据比较，不能仅从器物外观推定传播路线。

## 传播与社会影响

金属工具与武器改变劳动、战争和交换，国家可能控制原料与工匠，也存在家庭及区域生产。武器材料本身不能解释一场战争胜负。

冶金扩大采矿、燃料消耗和职业风险，木材需求可能改变环境。器物、炉渣、矿源分析和铸造遗址比后世英雄传说更适合重建技术链。
