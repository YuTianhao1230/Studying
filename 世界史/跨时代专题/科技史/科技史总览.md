# 科技史

## 主题与范围

从记录、证明到实验与计算。

本线同时讨论“如何认识自然”与“如何制造和应用工具”。科学、技术与生产相互促进，但不是每项技术都先有现代科学理论，也不是科学发现立即带来可用产品。

生产与测量需求、教学传统、文本传抄、仪器和学术机构共同支持研究。不同传统之间的翻译和交流既传递知识，也产生新的问题。

## 关键问题与机制

### 古代计算与证明

两河流域的计算实践、欧几里得的演绎组织、阿基米德求积和花拉子米方程方法分别展示不同形式，不能按现代学科边界把古代研究全部重分类。

### 知识为什么能够传播

纸张、印刷、翻译和学校共同改变知识传递的成本。中国雕版印刷、东亚活字实践与15世纪欧洲金属活字印刷体系应分别理解，不能把古腾堡写成全世界印刷术的唯一发明者。868年印制的《金刚经》是具有明确纪年的早期印本实物；它证明当时已有成熟印刷能力，不能单凭存世日期认定印刷术就在这一年诞生。

“印度—阿拉伯数字”也不是一次性由一个人送到欧洲的完整体系。数字字形、位值记数、零的使用、计算方法与拉丁文翻译经过多阶段发展。花拉子米体现的是这一网络中的研究与传播节点，伊斯兰世界学者也开展原创数学、天文和光学研究。

### 从科学革命到工业技术

科学革命改变自然研究的证据组织，但工业革命不能只解释为牛顿理论的直接应用。煤炭、矿井排水需求、机械加工、商业投资、劳动力与市场均参与其中。纽科门蒸汽机先服务于排水，瓦特后来改进效率和应用；“瓦特发明了第一台蒸汽机”会把已有工程传统删掉。

蒸汽动力让工厂在一定程度上摆脱水力地点限制，铁路降低部分运输成本；企业因此能够扩大市场和集中生产。电力又需要发电、输配电与设备网络，不能只列一位发明家或一件机器。技术的社会效果取决于这些配套条件，也涉及劳动安全、污染与资源分配。

### 现代科学与大规模研究

爱因斯坦的理论研究、诺特的数学结构与图灵的可计算性问题具有不同对象，不应合并成“都发明了计算机”。电子计算机的发展涉及逻辑、工程、存储、程序与组织协作；理论上可计算，不表示在现实时间和资源内都可完成。

航天把基础研究、火箭工程、材料、控制、通信和长期项目管理结合起来。太空竞赛既有科学探索，也有军备与国家声望目标；1969年登月是重要成果，不能代表所有太空探索从此结束。现代科研的跨国协作与军事、商业竞争往往同时存在。

牛顿的数学化运动与引力研究、达尔文的演化证据和居里夫人的放射性实验，体现不同对象的证据标准；并非所有研究都采用同一种实验。评价贡献时，应区分获奖理由、理论意义和公共知名度。

### 具体主题与核心问题

| 正文 | 要解释的变化 |
| --- | --- |
| [计算机与程序设计](<计算机与程序设计.md>) | 从机械数表、逻辑与可计算性到存储程序、语言和软件工程；区分理论、机器、程序、推广及多位参与者。 |
| [互联网与万维网](<互联网与万维网.md>) | 互联网是互联网络使用协议交换数据的基础设施，万维网是在其上通过地址、超文本和浏览器组织资源的应用体系。电子邮件、文件传输和网页不属于同一历史起点；互联网也不是一家公司或一位发明家单独建成。 |
| [农业、灌溉与粮食生产](<农业、灌溉与粮食生产.md>) | 农业是一组管理植物、动物、土地和水源的技术与社会实践。西亚、东亚、美洲等地存在不同驯化中心；定居、种植和畜牧的先后关系并不一致。灌溉提高部分地域的生产稳定性，也要求维护、分水和处理盐碱化。 |
| [冶金与铁器](<冶金与铁器.md>) | 冶金是从矿物获取、提纯、熔炼和加工金属的技术体系。自然铜加工、铜冶炼、青铜合金和铁冶炼是不同步骤；青铜时代、铁器时代只是部分地区的考古分期，不能作为全球同步年表。 |
| [晶体管与集成电路](<晶体管与集成电路.md>) | 晶体管用半导体控制电流，可以执行放大或开关功能；集成电路在共同基底上制造多个器件与互连。二者是相关的不同层次：晶体管是器件，芯片是组织大量器件的制造体系。 |
| [电力与电报](<电力与电报.md>) | 电力系统将能量以电的形式产生、输送和使用；电报把消息编码为电信号。前者解决动力与照明，后者解决远距离通信，二者相关却有不同技术链。 |
| [疫苗与公共卫生](<疫苗与公共卫生.md>) | 疫苗通过暴露于适当抗原或相关信息训练免疫反应；公共卫生则以人群为对象组织预防、监测和环境改善。早期人痘接种与牛痘接种是不同方法，现代疫苗也不只有一种技术。 |
| [蒸汽机与铁路](<蒸汽机与铁路.md>) | 蒸汽机将热能转为机械功，铁路把动力、车辆、轨道和运输组织结合起来。瓦特改良蒸汽机，之前已有纽科门等人的实用机器；一台机器与覆盖区域的铁路系统也不能混为一谈。 |
| [造纸与印刷](<造纸与印刷.md>) | 造纸把纤维制成适合书写的薄片，印刷使文字或图像重复转移到材料表面。纸张、雕版、活字、油墨和压力机构分别有自身历史；中国、朝鲜与欧洲的工艺发展不能压缩成一位发明家的一次创造。 |
| [青霉素与抗生素](<青霉素与抗生素.md>) | 青霉素是一类抗菌药物的重要起点，其历史包括抑菌现象发现、有效物质研究、临床应用与工业生产。1928年弗莱明的观察不是大规模制药的完成；弗洛里、钱恩及其他团队把发现推进为治疗。 |
