# 造纸与印刷

## 技术定位

造纸把纤维制成适合书写的薄片，印刷使文字或图像重复转移到材料表面。纸张、雕版、活字、油墨和压力机构分别有自身历史；中国、朝鲜与欧洲的工艺发展不能压缩成一位发明家的一次创造。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 古代中国 | 纸张逐渐发展；蔡伦约105年的改进记载不等于此前完全没有纸。 |
| 东亚中世纪 | 雕版印刷广泛使用；11世纪毕昇活字及后来朝鲜金属活字体现不同技术路径。 |
| 15世纪欧洲 | 古登堡把金属活字、铸字、油墨与压印组织成印刷体系，圣经约1450年代中期印成。 |
| 工业时代 | 机械印刷和廉价纸张扩大报刊与出版规模。 |

## 原理与关键变化

纸的制作包括纤维处理、制浆、抄纸和干燥，原料与胶料影响耐久性。雕版把整页刻在版上，活字则允许拆开重组；字符数量、版式、印量与劳动力成本决定哪种工艺划算。

古登堡的贡献在于一套能够稳定生产的体系，既不是纸张的发明，也不是全球最初印刷。金属字模和铸字提高规格一致性，适合的油墨及压力使大量印张可读。

翻译、校对、装订、纸商、出版商和销售网络同样参与传播。便宜的复制并不自动造成识字普及，还需要学校、语言标准和读者购买力。

## 传播与社会影响

印刷使宗教文本、科学图表、法规与文学作品更易复制和比较，也使错误、宣传与审查扩大。相同版本有助于讨论，但出版的重复性不保证内容真实。

宗教改革与印刷相互促进，仍受政治保护、城市市场与教派组织影响。东亚雕版在活字出现后长期存在，不能用单线替代旧技术的故事理解实际生产。
