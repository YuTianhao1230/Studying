# 互联网与万维网

## 技术定位

互联网是互联网络使用协议交换数据的基础设施，万维网是在其上通过地址、超文本和浏览器组织资源的应用体系。电子邮件、文件传输和网页不属于同一历史起点；互联网也不是一家公司或一位发明家单独建成。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 1960年代 | 分组交换和网络研究发展，1969年ARPANET初始节点联网。 |
| 1983年 | ARPANET转换到TCP/IP，成为互联网演变的重要节点。 |
| 1989—1991年 | 蒂姆·伯纳斯-李在CERN提出并实现万维网体系。 |
| 1990年代以后 | 浏览器、商业接入、移动网络和平台扩大应用，网络治理与接入差异持续存在。 |

## 原理与关键变化

分组交换把数据拆成带地址信息的包，共享链路并由网络转发。TCP/IP把互联、传输与应用区分，使不同底层网络可以通信；协议普及还需要设备、地址分配和运维。

万维网结合URL、HTTP与HTML：地址定位资源，协议传递内容，标记语言描述页面及链接。浏览器呈现内容，搜索引擎后来帮助检索；搜索不是互联网本身。

开放标准、大学和公共研究、商业服务和国际合作共同推动扩散。无线接入、电缆、数据中心和能源仍是物质条件，所谓虚拟空间并非脱离地理。

## 传播与社会影响

网络降低部分信息传播成本，改变学术、商业与日常交流，也使追踪、错误信息和平台权力扩大。能够联网不等于有同等数字素养、隐私保护或表达机会。

当代研究应区分网络协议、应用、内容、平台商业模式与国家规则。万维网起源于科学信息共享，但后续商业化不能从一份最初提案直接推导出来。
