# 疫苗与公共卫生

## 技术定位

疫苗通过暴露于适当抗原或相关信息训练免疫反应；公共卫生则以人群为对象组织预防、监测和环境改善。早期人痘接种与牛痘接种是不同方法，现代疫苗也不只有一种技术。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 近代以前及近代早期 | 中国、奥斯曼等地有人痘实践，既有保护作用也有传播疾病和严重不良反应的风险。 |
| 1796年 | 詹纳开展牛痘接种研究，后来成为天花预防的重要方向。 |
| 19世纪后期 | 巴斯德等人发展疫苗研究，微生物学、无菌与卫生措施相互促进。 |
| 1980年 | 世界卫生组织确认全球天花根除，依赖疫苗、监测和持续组织工作。 |

## 原理与关键变化

免疫记忆使再次接触相应病原时更快反应。减毒、灭活、亚单位与后来的核酸平台各有制备与使用条件，不能把任何一种机制写成全部疫苗的共同工艺。

公共卫生把个体保护与群体传播联系起来。接种需要有效产品、冷链、剂次、覆盖、监测和社区信任；干净水源、污水处理、营养和住房也影响疾病。

历史上许多接种实践缺少现代知情同意与试验规范，不能用成功结果替其伦理问题辩护。疫苗不是感染后针对所有病原的药物，效果和风险必须按具体产品、疾病及人群评价。

## 传播与社会影响

天花根除说明技术与国际协调能共同改变疾病负担。强制防疫、殖民医疗和不平等获取也可能引发冲突，卫生政策必须考虑信息、信任与资源。

卫生改善不只由某位医生贡献。护士、接种者、实验室、地方机构与公众参与构成持续系统；把死亡率变化全归功于单一疫苗会忽略其他条件。
