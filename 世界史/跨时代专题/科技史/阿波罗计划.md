# 阿波罗计划

## 技术定位

阿波罗计划是美国1960—1970年代的载人航天工程，1969年阿波罗11号完成首次载人月面着陆，1972年阿波罗17号完成该计划最后一次登月。

外文检索名：Apollo program。

## 发展时间线

| 时段 | 关键变化 |
| --- | --- |
| 1961年 | 肯尼迪提出十年内载人登月并返回目标。 |
| 1967年 | 阿波罗1号地面火灾造成三名航天员死亡。 |
| 1968—1969年 | 阿波罗8号绕月，11号登月。 |
| 1970—1972年 | 13号事故后返航，后续任务扩大科研。 |

## 原理与关键变化

### 任务链

土星五号、指令服务舱和登月舱通过月球轨道交会连接发射、着陆和返回。导航、通信、推进和热防护需要整套系统，登月舱不直接飞回地球。

### 风险与协作

承包商、工程师、航天员和地面控制共同工作，事故推动设计与流程调整。计算机能力有限不意味着飞行只靠心算，软硬件和地面体系协同。

## 传播与社会影响

月岩、仪器及观测为月球历史提供证据，计划同时服务冷战声望并消耗预算。首次载人登月与首次探测器抵月是不同成就。
