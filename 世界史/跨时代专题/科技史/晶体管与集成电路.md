# 晶体管与集成电路

## 技术定位

晶体管用半导体控制电流，可以执行放大或开关功能；集成电路在共同基底上制造多个器件与互连。二者是相关的不同层次：晶体管是器件，芯片是组织大量器件的制造体系。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 1947年 | 贝尔实验室巴丁与布拉顿实现点接触晶体管，肖克莱随后推进结型方案。 |
| 1958—1959年 | 基尔比展示集成电路，诺伊斯发展适合平面工艺的硅集成方案。 |
| 1960—1970年代 | MOS工艺、规模集成和微处理器发展。 |
| 此后 | 更高密度、存储、封装与专用架构持续变化，不能仅用晶体管数量判断系统性能。 |

## 原理与关键变化

半导体导电性可通过掺杂和结构控制。双极型晶体管与场效应晶体管工作方式不同；数字电路利用开关状态实现逻辑，模拟电路则处理连续信号。

集成减少分立器件连接，但要求晶圆、光刻、沉积、刻蚀、互连和测试等工序。平面工艺与制造良率让大量器件更容易重复生产，实验样品与经济可行的量产仍有距离。

器件缩小并不自动解决功耗、散热与可靠性。摩尔定律属于对产业趋势的观察，不是永远成立的自然定律；实际进步依赖材料、设计、软件和供应链。

## 传播与社会影响

小型化推动计算机、通信和控制设备普及，也依赖军事采购、消费市场、教育与企业投资。成果由科学家、工程师、工厂和标准体系共同实现。

制造集中、设备和材料依赖使芯片成为经济与国际政治问题。比较一项芯片技术时应同时看工艺、成本、性能、能耗和可制造性，不以单一尺寸给出时代排名。
