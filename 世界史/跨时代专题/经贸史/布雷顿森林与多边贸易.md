# 布雷顿森林与多边贸易

## 范围与参与者

布雷顿森林体系围绕战后货币、融资和国际合作设计；GATT与后来的WTO主要处理贸易规则。货币汇率、发展融资与贸易谈判是不同职责，不是一套机构在同一年成立。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 1944年 | 布雷顿森林会议设计国际货币基金组织与国际复兴开发银行相关安排。 |
| 1947—1948年 | GATT签署并开始适用，多边关税谈判发展。 |
| 1971—1973年 | 美元黄金兑换暂停及汇率安排变化，原固定汇率体系瓦解。 |
| 1995年 | WTO成立，覆盖货物、服务及知识产权等领域。 |

## 商品、劳动与运行机制

原货币制度以美元对黄金的官方兑换与其他货币固定但可调整平价为核心。资本流动限制、国内政策与国际收支支持共同维持体系，不能简化为任何人都能自由把所有纸币换成黄金。

IMF处理国际货币合作与国际收支相关问题；世界银行体系侧重发展融资，各机构后来也改变业务。GATT/WTO涉及关税、非歧视、规则与争端，决策和执行受到成员政府条件约束。

1971年美国暂停美元黄金兑换，不意味着这些机构同时终止。贸易规则也不能自动消除运输、政治或发展差距，关税降低与收入分配要分别观察。

## 制度变化与利益分配

战后合作旨在避免经济分裂，同时体现当时权力分布与政策选择。发展中国家的代表性、政策自主和调整代价受到持续争论，机构自述不能作为全部政策成功的独立证明。

国际制度与区域合作共存，欧洲一体化是另一条有自身法律和政治条件的路径。全球化既包括贸易增长，也包括供应链依赖、危机传播与劳动分配。
