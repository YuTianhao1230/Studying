# 印度洋季风与港口网络

## 范围与参与者

印度洋贸易连接东非、阿拉伯、南亚、东南亚及更广海域，长期早于欧洲殖民公司。季风是航海条件，港口、商人、国家和金融安排则把环境条件转为可运作的网络。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 古代 | 红海、阿拉伯海与南亚港口已有远程交流。 |
| 中世纪 | 季风航行、穆斯林等多种商人社群与东非沿海城市发展。 |
| 15—17世纪 | 南亚与亚洲网络延续，葡萄牙及后来欧洲公司以武力和垄断参与。 |
| 近现代 | 蒸汽航运、运河、殖民港口和独立国家改变网络组织。 |

## 商品、劳动与运行机制

季风季节性改变风向，商船安排出发、停留与返航，港口提供仓储、补给和转运。等待季风也促进居留、婚姻、宗教与语言接触，但不表示所有路线都固定半年往返。

香料、纺织品、陶瓷、粮食和黄金等有不同生产地与消费市场。信用、代理与社群关系减少远程交易风险，关税及地方政治仍是重要约束。

东非沿海与大津巴布韦等内陆地区通过中介联系。发现中国瓷器可以证明交换链的一环，不能直接证明每个产地居民都亲赴遗址。

## 制度变化与利益分配

港口既能积累财富和文化多样性，也受强制劳动、战争和垄断影响。葡萄牙到来没有创造全部印度洋贸易，也没有立即控制所有航线。

伊本·白图泰游记提供城市和社群线索，但记忆、转述和成书过程需要核验。现代新加坡港不能直接投射为中世纪同样规模的中心。
