# 丝绸之路与跨撒哈拉贸易

## 范围与参与者

丝绸之路指欧亚多段陆海交换网络，跨撒哈拉贸易连接北非、沙漠绿洲与西非地区。二者不是一条永久路线或同一制度，但都依赖中介、运输、补给与地方政治条件。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 古代 | 欧亚多中心交换发展，商人往往只走其中一段。 |
| 中世纪 | 中亚城市、绿洲与西非黄金盐贸易扩大区域联系。 |
| 蒙古时代及其他阶段 | 部分欧亚交通条件变化，安全与统一并不覆盖所有地域或时期。 |
| 近代以来 | 海路、殖民边界和国家政策改变旧网络，区域交换仍延续。 |

## 商品、劳动与运行机制

丝绸、马匹、金属、香料与其他货物沿不同网络流动，丝绸只是命名的一部分。中介承担语言、风险与价格信息，关税、驿站和地方关系影响可达性。

跨撒哈拉贸易需要骆驼运输、绿洲补给和沙漠知识，黄金、盐与被奴役者等不是可以不区分的普通商品。马里资源还依赖农业、贡赋和地方生产，不能只用黄金解释国家。

货物移动、商人迁移和宗教传播速度不同。一个地点出现异地器物，不自动证明工匠或君主亲自走过全程；路线图应标明概略与已证实部分。

## 制度变化与利益分配

交换促进城镇、语言与知识联系，也伴随税收、暴力和奴役。欧亚与非洲内部都有自主参与者，不能把长距离贸易写成欧洲扩张之前的空白。

网络变化受到疾病、战争、气候和海运影响，不能用1453年一个事件概括丝路完全关闭。比较时应统一时间范围，分别核对货物、路线和实际政治控制。
