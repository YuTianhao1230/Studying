# 大西洋奴隶贸易与全球白银

## 范围与参与者

近代跨洋体系把美洲矿山、殖民种植园、欧洲市场、非洲社群和亚洲商品联系起来。奴隶贸易是强制迁徙与暴力制度，白银流动是货币与商品交换；二者有交织，不能写成单一三角形覆盖所有航次。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 16世纪起 | 美洲银矿与跨洋航线发展，殖民强制劳动和疫病改变人口。 |
| 16—18世纪 | 跨大西洋奴隶贸易、种植园与欧洲公司扩大，不同国家和时期路线有差异。 |
| 16—19世纪 | 马尼拉等航线联系美洲白银与亚洲商品，区域税收和市场需求影响流动。 |
| 废奴及以后 | 合法奴隶贸易与奴隶制度的终止时间不同，强迫劳动及土地不平等并未自动消失。 |

## 商品、劳动与运行机制

白银作为支付与税收媒介，流动受到矿山供给、价格、贸易政策和亚洲需求影响。波托西矿山的开采依赖劳动力制度、汞、设备和运输，矿藏不是自动转化成社会财富。

被奴役者遭遇捕获、买卖、海上运输和种植园强制劳动，同时通过逃亡、社群与革命抵抗。非洲各地参与者、欧洲国家和美洲经营者的权力与责任需具体分析。

三角贸易是示意，不是所有船只走完全相同三段。统计要限定年代、区域、出发或登陆人数并区分档案记录与估算，缺失记录不能当作没有受害者。

## 制度变化与利益分配

殖民财富增加与被奴役者或矿工福利下降可以同时发生。海地革命显示被奴役者不是被动商品，奴隶制废除与独立之间也有不同关系。

白银和种植园网络促进全球交换，也放大资源开采、生态破坏和人口损失。货物流向只能解释部分关系，不能单独证明整个世界在同一时刻形成统一市场。
