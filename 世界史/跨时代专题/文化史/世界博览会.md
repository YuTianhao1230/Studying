# 世界博览会

## 主题与历史环境

世界博览会把工业产品、科学技术、建筑和国家形象集中展示，1851年伦敦万国工业博览会是现代传统的重要起点。国际展览分类与监管机构在后来逐步形成。

外文检索名：World's fairs and international exhibitions。

## 发展时间线

| 时段 | 关键变化 |
| --- | --- |
| 1851年 | 伦敦水晶宫展示工业和帝国商品。 |
| 1889年 | 巴黎展览与埃菲尔铁塔联系。 |
| 1893年 | 芝加哥哥伦布纪念博览会重塑城市及展陈空间。 |
| 1928年以后 | 国际展览公约和国际展览局建立监管框架。 |

## 作品、实践与传播机制

### 作品与组织

临时建筑、展馆、目录和奖项把商品转为可比较的展示，国家、企业与城市竞争声望。一次展览不能代表该国所有人口的生活水平。

### 展览与权力

技术进步叙事常包含殖民分类和种族化展示，殖民地人与物品被置入不平等观看关系。不能仅以热闹国际交流省略受展示者处境。

## 社会影响与解释边界

展馆、基础设施和公共娱乐推动建设，部分建筑保留并改变用途。博览会、专业展、奥运会和商业展销并非同一制度。
