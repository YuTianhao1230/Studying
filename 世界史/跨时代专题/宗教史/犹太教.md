# 犹太教

## 传统与形成背景

犹太教形成于古代以色列及犹太社会，并在圣殿、文本解释与散居历史中变化。亚伯拉罕、出埃及和摩西等传统叙事属于宗教经典，不能未经考古与文本核验当作完整可证实年表。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 前一千纪 | 古代以色列与犹太政权、圣殿崇拜和文本传统逐渐发展。 |
| 前6世纪及以后 | 巴比伦流亡与回归、第二圣殿时期重塑社群生活。 |
| 公元70年以后 | 第二圣殿毁灭，拉比传统、会堂与文本学习持续发展。 |
| 近现代 | 散居、解放、改革、反犹迫害与大屠杀等经历影响不同社群。 |

## 信仰、文本与实践

一神信仰、盟约与律法是重要观念。托拉既指摩西五经，也可在广义上指教导；《塔纳赫》与后来的米示拿、塔木德不是同一时代的一部书。

安息日、饮食规则、逾越节、祷告与学习构成实践，不同社群遵守方式不同。会堂兼有祈祷、学习与社群功能，拉比也不等同于所有传统中的献祭祭司。

犹太身份可以包含宗教、家庭、文化和群体历史。不能把所有犹太人写成具有相同信仰、政治观点或现代国籍。

## 传播、组织与内部差异

散居形成塞法迪、阿什肯纳兹及其他社群，语言和礼仪各有变化。现代正统派、改革派、保守派等名称主要解释部分现代组织，不宜直接套用古代。

基督教从犹太历史环境中形成，两者并非完全相同。宗教历史、现代以色列国家和当前政治冲突应分开研究；反犹迫害不能仅用宗教意见分歧解释。
