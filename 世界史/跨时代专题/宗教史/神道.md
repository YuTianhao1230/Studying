# 神道

## 传统与形成背景

神道（Shintō）是日本与神（kami）、神社和祭祀相关的多种传统。古代地方信仰、宫廷仪式、佛教交流和近代国家制度共同形成历史，没有单一创始人，也不是从古代到现代始终不变的一套统一教义。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 古代 | 地方祭祀与宫廷仪式发展，《古事记》《日本书纪》兼含神话与政治叙事。 |
| 中世纪 | 神佛习合形成多种理解与实践。 |
| 明治时期 | 神佛分离及国家对神社体系的组织改变传统。 |
| 1945年以后 | 国家制度与宗教组织关系改变，地方神社和节日继续发展。 |

## 信仰、文本与实践

神可以涉及自然、地方、祖先与历史人物，其含义不完全等同于西方神学中的全能创造神。祭（matsuri）、净化、参拜和供奉在具体社群中实践。

鸟居标示神社空间边界，神社常有手水与参道，建筑形式却并不统一。参拜动作、节日和守护对象各有地方规则，不能把旅游经验当作所有神社的规范。

经典神话表达宇宙、王权和地域认同，不能当作天皇世系每个节点都可考证的史实。许多人同时参与佛教、神社或其他仪式，宗教身份不总是排他选择。

## 传播、组织与内部差异

神佛关系经历结合、区分和制度化，不是一条从混杂走向纯粹的必然道路。近代国家神道与地方信仰既有联系又有区别，不能把全部传统视为一种政治意识形态。

严岛鸟居可帮助理解神圣空间、景观与潮汐，但照片不能推出所有神社都建在水上。保护还涉及木构维修、观光与地方生活。
