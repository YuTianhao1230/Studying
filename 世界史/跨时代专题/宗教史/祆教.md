# 祆教

## 传统与形成背景

祆教又称琐罗亚斯德教（Zoroastrianism），与伊朗先知扎拉图斯特拉的教导有关。其活动年代争议很大，不固定成一个无争议年份；阿契美尼德王室的信仰与后世完整祆教制度也不能直接画等号。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 古代伊朗传统 | 《伽萨》等材料保留古老宗教语言和伦理教导，成书与传承需分开。 |
| 萨珊时期 | 王权、祭司与火庙组织增强，宗教与帝国制度相互联系。 |
| 伊斯兰扩张以后 | 伊朗社群经历长期变化，部分迁往南亚并形成帕西社群。 |
| 近现代 | 伊朗、印度和海外社群面对身份、改宗与传统延续的讨论。 |

## 信仰、文本与实践

阿胡拉·马兹达、善恶选择与人的责任是重要观念，善思、善言、善行常用于伦理概括。不同历史文本对宇宙论与善恶关系的表达有差异，不能粗略写成崇拜两个同等地位的神。

《阿维斯陀》是重要文本集合，口传、书写与后世整理有不同阶段。火具有礼仪与洁净意义；称其为拜火教是历史称呼，却容易误导为把火本身当作唯一神。

入教礼、洁净规则和丧葬实践因地区及时期而变。天葬塔不是所有当代信徒都使用的统一葬法，城市法律与环境条件改变了实践。

## 传播、组织与内部差异

帕西与伊朗社群保持联系，也有语言、礼仪与改宗政策差异。关于奶中加糖等移民传说应按传说处理，不能当成精确迁徙档案。

古代伊朗宗教与其他传统存在交流，但相似观念不足以单独证明直接借用。研究影响应核对年代、文本和实际接触渠道。
