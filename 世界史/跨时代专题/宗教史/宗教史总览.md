# 宗教史

## 主题与范围

宗教如何进入不同地区。

宗教史关注传统怎样形成、文本如何解释、信仰怎样进入社会，以及宗教组织与政治、经济的关系。教义自述、信徒记忆和历史研究属于不同证据层次；宗教史介绍传播与变化，不替任何信仰作真假判定。

相同宗教在不同地区的语言、仪式与组织可以不同；接受新传统也不意味着所有旧实践立即消失。

## 关键问题与机制

### 主要传统怎样区分

佛教起源于南亚，佛陀生平的具体纪年存在研究差异；阿育王铭文是研究孔雀王朝治理与宗教伦理的重要材料，但不能把“法”全部等同于现代意义的单一佛教教义。佛教进入中亚、东亚、东南亚后，经典翻译、寺院组织和地方实践均有变化。

印度教包含长期形成的文本、仪式、神祇和思想传统，不宜指定一个唯一创始人和统一创立年份。犹太教的经典、法律与社群历史也经过长时期发展，不能仅以一个王朝的政治存续代表整个宗教。

基督教产生于犹太社会背景，早期社群、帝国承认和教会制度发展经历不同阶段。罗马帝国后期与拜占庭的教会政治不是教义之外的附属情节，而是理解宗教组织与权力的重要条件。东正教、天主教和后来新教诸传统具有历史分化过程。

伊斯兰教在7世纪阿拉伯半岛兴起。早期哈里发政权扩张、居民逐步改宗、法律教育和日常礼仪不能合并成一个瞬间。逊尼派和什叶派的形成与共同体领导及后续历史相关，也不能把全部政治冲突直接解释为教义差异。

### 传播为什么会改变传统

僧侣和学者翻译文本时，需要用当地词汇解释陌生概念；商人社群可建立跨港口联系；统治者资助寺院和学校可提高制度地位；家庭、婚姻和地方仪式则影响日常实践。因此，宗教进入新地区既涉及教义，也涉及语言、组织与社会关系。

征服也可能改变宗教权力，但传播不能全部解释为武力强迫。教堂、清真寺和寺庙兼具祭祀、教育、社区与财富管理功能，建筑用途的变化因而也涉及社会资源和国家决定。

马里统治者的伊斯兰身份不说明所有臣民立即遵行相同宗教。吴哥窟从印度教背景转为重要佛教空间，体现长期用途变化；圣索菲亚的教堂、清真寺和博物馆等不同用途则与国家决定相连。建筑现状只能证明今天的用途，不能覆盖其全部历史。

### 改革、战争与国家

16世纪宗教改革涉及救赎、教会权威、经典与仪式，也涉及城市和诸侯的财政、司法与政治利益。印刷促进论争，改革后的教会仍需要学校、牧职和礼仪组织。三十年战争既有宗教冲突，也有王朝竞争与战略利益；1648年和约不能简单说成“此后宗教退出政治”。

印度分治涉及殖民治理、政治代表、政党目标、族群认同和地方暴力。不能只用“不同宗教不能共同生活”解释，更不能据此把今天的国家或居民描述为内部完全同质。

### 证据与差异

官方信仰、地方实践与个人选择不一定相同。铭文、建筑、礼仪文本和日常器物提供不同角度，不能只凭统治者信仰推断全部居民。

### 具体主题与核心问题

| 正文 | 要解释的变化 |
| --- | --- |
| [伊斯兰教](<伊斯兰教.md>) | 伊斯兰教形成于7世纪阿拉伯半岛，穆罕默德的活动与《古兰经》传统居于核心。信徒相信《古兰经》是启示；历史写作把这一信仰与手稿、传记、碑刻和早期政治材料区分。 |
| [佛教](<佛教.md>) | 佛教起源于南亚，以释迦牟尼（Siddhārtha Gautama）的教导为核心。其生卒年代存在学术争议，通常置于前一千纪中期。传统传记包含宗教叙述，历史研究需另用文本、碑刻与考古材料。 |
| [印度教](<印度教.md>) | 印度教是南亚多种文本、仪式、神祇崇敬、哲学与地方传统的集合，没有单一创始人或统一教会。吠陀传统与后来的史诗、往世书、寺庙和奉爱实践逐步形成不同面貌；现代总称不能原样回溯为一套始终不变的古代制度。 |
| [原住民信仰与口述传统](<原住民信仰与口述传统.md>) | 原住民信仰不是一个全球统一宗教的名称。澳大利亚不同原住民群体、美洲不同民族、太平洋岛屿社群及其他地域各有语言、土地关系、知识和仪式；民族自称与社区解释应优先于外来笼统标签。 |
| [基督教](<基督教.md>) | 基督教形成于公元1世纪罗马统治下的犹太地区，以耶稣及其生命、死亡和复活的信仰为中心。历史研究可以讨论耶稣运动和早期社群，复活与救赎属于信徒的信仰宣称。 |
| [犹太教](<犹太教.md>) | 犹太教形成于古代以色列及犹太社会，并在圣殿、文本解释与散居历史中变化。亚伯拉罕、出埃及和摩西等传统叙事属于宗教经典，不能未经考古与文本核验当作完整可证实年表。 |
| [祆教](<祆教.md>) | 祆教又称琐罗亚斯德教（Zoroastrianism），与伊朗先知扎拉图斯特拉的教导有关。其活动年代争议很大，不固定成一个无争议年份；阿契美尼德王室的信仰与后世完整祆教制度也不能直接画等号。 |
| [神道](<神道.md>) | 神道（Shintō）是日本与神（kami）、神社和祭祀相关的多种传统。古代地方信仰、宫廷仪式、佛教交流和近代国家制度共同形成历史，没有单一创始人，也不是从古代到现代始终不变的一套统一教义。 |
| [耆那教](<耆那教.md>) | 耆那教是南亚独立的宗教传统，以渡津者（tīrthaṅkara）的教导为核心。传统把大雄（Mahāvīra）列为第24位渡津者；更早人物的宗教传承与可考历史应分别处理。大雄通常置于前一千纪中期，精确年代有争议。 |
| [锡克教](<锡克教.md>) | 锡克教形成于15—16世纪旁遮普，以古鲁那纳克（Guru Nanak，1469—1539）及其后古鲁传统为核心。它处于南亚多种宗教和政治环境之中，但有自身经典、社群与认同，不能称为印度教和伊斯兰教的简单混合。 |
