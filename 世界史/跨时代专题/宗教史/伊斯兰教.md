# 伊斯兰教

## 传统与形成背景

伊斯兰教形成于7世纪阿拉伯半岛，穆罕默德的活动与《古兰经》传统居于核心。信徒相信《古兰经》是启示；历史写作把这一信仰与手稿、传记、碑刻和早期政治材料区分。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 7世纪初 | 穆罕默德在麦加活动，622年迁徙到麦地那成为伊斯兰纪年基点。 |
| 7—8世纪 | 哈里发政权扩张，政治控制与居民改宗的速度不同。 |
| 中世纪 | 法学、神学、苏菲修行、城市教育与贸易网络发展。 |
| 近现代 | 殖民、改革、国家形成与跨国移民影响多种社群。 |

## 信仰、文本与实践

独一神信仰、先知与末日观念是重要内容。信仰宣认、礼拜、施舍、斋戒和朝觐常概括为五功；具体实践需要能力、法律传统与地方条件。

《古兰经》与圣训是不同材料，圣训的传承、真伪与解释有专门研究。沙里亚是宗教规范的广义概念，法学（fiqh）是人的解释传统，不能把某国现行法律直接当作全部伊斯兰。

逊尼派与什叶派在继承、权威及历史记忆上有差异，各自内部也有多种组织。苏菲传统可跨越这一分类，不是与二者完全互斥的第三宗派。

## 传播、组织与内部差异

贸易、学者、征服、婚姻和地方传播共同形成全球穆斯林社会；阿拉伯人并不等于全部穆斯林。西非、南亚与东南亚均有自身历史。

杰内大清真寺连接社群礼拜、工匠维护与萨赫勒环境。宗教建筑形态多样，沙漠、阿拉伯语言和某一国家制度都不能作为所有信徒的唯一定义。
