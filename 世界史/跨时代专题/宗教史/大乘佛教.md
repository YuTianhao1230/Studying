# 大乘佛教

## 传统与形成背景

大乘佛教是在南亚佛教内部逐步形成的多种经典、修行理想与思想传统，约在公元前后出现重要发展，其确切起点和地点仍有争议。它不是一个统一教会，也不是某位个人在某一年创立、随后完全替代其他佛教的组织。

常用外文名：Mahāyāna。

## 发展时间线

| 阶段 | 变化与联系 |
| --- | --- |
| 公元前后 | 早期大乘经典及菩萨道路逐步发展，不同地区的形成过程仍需文本和考古研究。 |
| 2—5世纪 | 中观、瑜伽行等思想体系发展，对空性、认识及修行作系统讨论。 |
| 古代—中世纪 | 经典通过翻译、僧侣、商路和地方资助传播，东亚与东南亚形成多种传统。 |
| 近现代 | 居士团体、教育改革、社会参与及跨国移民改变组织和传播方式。 |

## 信仰、文本与实践

菩萨道把发菩提心、智慧和慈悲联系起来，六度等修行表达布施、持戒、忍辱、精进、禅定和般若。将菩萨简单解释为拒绝解脱也不准确：不同传统对佛果、涅槃和利益众生的关系有不同说明。

空性指诸法没有独立不变的自性，与缘起联系，并非宣称世界什么都没有或行为没有后果。般若经典、《法华经》、净土相关经典及其他文本组成多样的经藏传统，不能把一部经代表全部大乘。

## 传播、组织与内部差异

中观、瑜伽行、如来藏、净土和禅等是不同问题、经典或实践形成的传统，分类并不总是互斥。大乘僧侣仍可能采用不同部派传承的戒律，因此经典归属与授戒系谱不能机械一一对应。

金刚乘在许多历史和教义分类中属于大乘范围，三种常用名称不是三块完全排斥的地域版图。婆罗浮屠说明爪哇的大乘建筑和礼仪传统，不能用其形式代表日本、越南或其他地区的全部佛教。
