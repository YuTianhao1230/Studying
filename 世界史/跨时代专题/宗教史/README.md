# 宗教史

先读主线总览，再读具体对象。各主题保留历史阶段、原理或实践、传播、影响与证据；不同地区及流派不强行统一。

## 内容索引

| 入口 | 内容说明 |
| --- | --- |
| [伊斯兰教](<伊斯兰教.md>) | 伊斯兰教形成于7世纪阿拉伯半岛，穆罕默德的活动与《古兰经》传统居于核心。信徒相信《古兰经》是启示；历史写作把这一信仰与手稿、传记、碑刻和早期政治材料区分。 |
| [佛教](<佛教.md>) | 佛教起源于南亚，以释迦牟尼（Siddhārtha Gautama）的教导为核心。其生卒年代存在学术争议，通常置于前一千纪中期。传统传记包含宗教叙述，历史研究需另用文本、碑刻与考古材料。 |
| [印度教](<印度教.md>) | 印度教是南亚多种文本、仪式、神祇崇敬、哲学与地方传统的集合，没有单一创始人或统一教会。吠陀传统与后来的史诗、往世书、寺庙和奉爱实践逐步形成不同面貌；现代总称不能原样回溯为一套始终不变的古代制度。 |
| [原住民信仰与口述传统](<原住民信仰与口述传统.md>) | 原住民信仰不是一个全球统一宗教的名称。澳大利亚不同原住民群体、美洲不同民族、太平洋岛屿社群及其他地域各有语言、土地关系、知识和仪式；民族自称与社区解释应优先于外来笼统标签。 |
| [基督教](<基督教.md>) | 基督教形成于公元1世纪罗马统治下的犹太地区，以耶稣及其生命、死亡和复活的信仰为中心。历史研究可以讨论耶稣运动和早期社群，复活与救赎属于信徒的信仰宣称。 |
| [宗教史总览](<宗教史总览.md>) | 宗教如何进入不同地区。 |
| [犹太教](<犹太教.md>) | 犹太教形成于古代以色列及犹太社会，并在圣殿、文本解释与散居历史中变化。亚伯拉罕、出埃及和摩西等传统叙事属于宗教经典，不能未经考古与文本核验当作完整可证实年表。 |
| [祆教](<祆教.md>) | 祆教又称琐罗亚斯德教（Zoroastrianism），与伊朗先知扎拉图斯特拉的教导有关。其活动年代争议很大，不固定成一个无争议年份；阿契美尼德王室的信仰与后世完整祆教制度也不能直接画等号。 |
| [神道](<神道.md>) | 神道（Shintō）是日本与神（kami）、神社和祭祀相关的多种传统。古代地方信仰、宫廷仪式、佛教交流和近代国家制度共同形成历史，没有单一创始人，也不是从古代到现代始终不变的一套统一教义。 |
| [耆那教](<耆那教.md>) | 耆那教是南亚独立的宗教传统，以渡津者（tīrthaṅkara）的教导为核心。传统把大雄（Mahāvīra）列为第24位渡津者；更早人物的宗教传承与可考历史应分别处理。大雄通常置于前一千纪中期，精确年代有争议。 |
| [锡克教](<锡克教.md>) | 锡克教形成于15—16世纪旁遮普，以古鲁那纳克（Guru Nanak，1469—1539）及其后古鲁传统为核心。它处于南亚多种宗教和政治环境之中，但有自身经典、社群与认同，不能称为印度教和伊斯兰教的简单混合。 |
| [天主教](<天主教.md>) | 天主教是基督教的重要传统，以罗马主教即教皇及与其共融的地方教会为组织核心。 |
| [东正教](<东正教.md>) | 东正教通常指保持拜占庭礼传统、承认前七次大公会议并处于相关共融关系中的教会。 |
| [新教](<新教.md>) | 新教是与16世纪宗教改革及其后发展有关的多种基督教传统总称，没有统一的全球教会。 |
| [上座部佛教](<上座部佛教.md>) | 上座部佛教是以巴利经典和相关注释、僧团戒律传承为重要依据的佛教传统，主要见于斯里兰卡、缅甸、泰国、柬埔寨和老挝。 |
| [大乘佛教](<大乘佛教.md>) | 大乘佛教是在南亚佛教内部逐步形成的多种经典、修行理想与思想传统，约在公元前后出现重要发展，其确切起点和地点仍有争议。 |
| [金刚乘佛教](<金刚乘佛教.md>) | 金刚乘通常指与佛教密续、灌顶、真言、曼荼罗和特定观修有关的传统，在南亚佛教中逐步发展，并传播到喜马拉雅地区、蒙古、日本等地。 |
| [湿婆派](<湿婆派.md>) | 湿婆派是以湿婆崇敬为核心的多种印度教传统，包含寺庙、奉爱、苦行、哲学及地方仪式。 |
| [圣殿骑士团](<圣殿骑士团.md>) | 圣殿骑士团是12世纪初在耶路撒冷形成的拉丁基督教军事修会，兼具宗教誓愿、军事和财产管理。 |
