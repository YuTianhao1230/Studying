# 新教

## 传统与形成背景

新教是与16世纪宗教改革及其后发展有关的多种基督教传统总称，没有统一的全球教会。路德宗、改革宗、圣公会及后来的浸礼宗、循道宗、五旬节传统各有组织和神学差异，不能将马丁·路德视为所有宗派的唯一创始人。

常用外文名：Protestantism。

## 发展时间线

| 阶段 | 变化与联系 |
| --- | --- |
| 1517年起 | 路德关于赎罪券及教会权威的争论，与印刷、大学、诸侯政治共同推动改革。 |
| 1520—1530年代 | 德意志、瑞士和英格兰出现不同改革路径，国家与地方制度影响教会重组。 |
| 17—18世纪 | 宗教冲突、虔敬主义、清教徒传统和循道运动继续改变礼仪及社群生活。 |
| 19—20世纪 | 传教、移民、复兴运动及五旬节运动推动全球扩展，地方教会形成独立实践。 |

## 信仰、文本与实践

许多新教传统强调圣经权威、因信称义及信徒的直接信仰责任，但各宗派对这些原则的解释并不完全相同。“唯独圣经”也不意味着所有教会拒绝信经、教育、传统和牧职。

洗礼和圣餐通常是重要礼仪；婴儿洗礼或信徒洗礼、圣餐中基督临在、主教制度、长老制度与会众自治存在不同立场。不能以不用圣像、不设主教或牧师可以结婚等单一特征定义全部新教。

## 传播、组织与内部差异

宗教改革与王权、城市自治、印刷出版和财产重分配交织。英格兰脱离罗马与后来的教义、礼仪改革是不同步骤，不能说亨利八世一人完成全部新教改革。

传教与殖民有交集，但非洲、亚洲和美洲教会形成了自身领导、音乐、礼拜及社会行动。福音派是一组跨宗派运动或立场，不能直接等同于所有新教；新教内部也有保守与自由派等不同取向。

## 史料与参考
