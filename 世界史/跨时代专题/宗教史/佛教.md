# 佛教

## 传统与形成背景

佛教起源于南亚，以释迦牟尼（Siddhārtha Gautama）的教导为核心。其生卒年代存在学术争议，通常置于前一千纪中期。传统传记包含宗教叙述，历史研究需另用文本、碑刻与考古材料。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 前一千纪中期 | 佛陀相关教导与出家社群形成，处于南亚多种修行传统之中。 |
| 前3世纪 | 阿育王时代的碑刻和王权支持成为传播的重要证据。 |
| 古代—中世纪 | 佛教通过商路、僧侣、翻译和王权进入中亚、东亚、东南亚及藏地。 |
| 近现代 | 殖民、改革、复兴与跨国移民产生新的组织和实践。 |

## 信仰、文本与实践

四谛讨论苦、苦的原因、止息与道路；八正道联系见解、行为与修习。业、缘起和无常是重要概念，涅槃的理解也不能简化成死亡或虚无。

佛教重视僧团及在家支持者，戒律、禅修、布施、诵经和节日因传统不同。经典有巴利语、汉译、藏译等多种传承，不能假定所有佛教徒阅读同一版本。

上座部、大乘与金刚乘是常用分类，内部还有诸多学派和地方实践；金刚乘在不少分类中属于大乘体系，不宜视作完全互斥的三块。

## 传播、组织与内部差异

传播依靠路线、语言翻译、社群资助和国家条件，佛教艺术出现犍陀罗、东亚和东南亚等不同形式。婆罗浮屠体现特定地区的佛教建筑，不等于印度原初僧院。

佛教与地方神祇、祖先礼仪和政治权力可以共存或冲突。其不以创造神为核心，不意味着所有传统都没有神灵、仪式或超自然信念；和平伦理也不能抹去佛教社群中的实际历史矛盾。
