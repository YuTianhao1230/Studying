# 上座部佛教

## 传统与形成背景

上座部佛教是以巴利经典和相关注释、僧团戒律传承为重要依据的佛教传统，主要见于斯里兰卡、缅甸、泰国、柬埔寨和老挝。它与古代上座部系谱有关，但现存传统经历长期重组，不能直接称为毫无变化的原始佛教，更不宜使用带贬义的小乘作为其同义名称。

常用外文名：Theravāda。

## 发展时间线

| 阶段 | 变化与联系 |
| --- | --- |
| 古代南亚 | 佛教部派及戒律、经典传承发展；传统把斯里兰卡的传承与阿育王时代传教联系起来。 |
| 约公元前1世纪 | 斯里兰卡传统记载巴利三藏被书写保存，具体过程还需结合传承文本研究。 |
| 5世纪及中世纪 | 觉音等注释传统发展；斯里兰卡与东南亚之间的僧团、经典和授戒交流加强。 |
| 近现代 | 殖民、僧团改革、居士运动与禅修传播产生新的制度和跨国网络。 |

## 信仰、文本与实践

巴利三藏分为经藏、律藏和论藏，注释和《清净道论》等也具有重要地位。四谛、八正道、缘起、戒定慧及阿罗汉理想是重要内容，不意味着信徒完全不讨论菩萨、佛陀过去世或其他宗教对象。

僧团与居士通过布施、持戒、诵经、节日和修习建立关系。禅修包括止与观等方法，但现代内观课程只是诸多实践中的一部分；不能把全部上座部生活缩成个人冥想。

## 传播、组织与内部差异

传播依靠授戒系谱、译写、王室与地方资助，斯里兰卡和东南亚之间存在多次恢复与改革。泰国等地的不同僧团组织、各国政治关系和地方仪式并不相同。

吴哥地区从早期印度教、大乘佛教环境逐步转向以上座部为重要传统，说明宗教空间可以再使用；不能把12世纪吴哥窟的原始营建说成上座部寺院。民间神灵崇敬及护佑仪式也可与经典修习并存。

## 史料与参考

巴利经典的形成、传承系谱与近现代改革者关于纯正传统的自述应分别研究。上座部既不是全部早期佛教，也不是大乘形成后被简单替代的残余。
