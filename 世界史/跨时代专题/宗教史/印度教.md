# 印度教

## 传统与形成背景

印度教是南亚多种文本、仪式、神祇崇敬、哲学与地方传统的集合，没有单一创始人或统一教会。吠陀传统与后来的史诗、往世书、寺庙和奉爱实践逐步形成不同面貌；现代总称不能原样回溯为一套始终不变的古代制度。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 吠陀时期 | 吠陀赞歌与祭祀传统发展，具体年代依文本与研究口径。 |
| 前一千纪及以后 | 奥义书、史诗和多种哲学讨论业、轮回与解脱。 |
| 公元第一千纪—中世纪 | 寺庙、神像、地方传统与奉爱运动发展并向东南亚传播。 |
| 近现代 | 殖民分类、改革、民族政治和全球移民重新组织传统。 |

## 信仰、文本与实践

信徒对法（dharma）、业、轮回与解脱有不同解释。毗湿奴、湿婆与女神传统各有经典和礼仪，不能用神祇数量概括全部印度教；也存在不以人格神为中心的哲学路径。

吠陀、奥义书、《摩诃婆罗多》及其中《薄伽梵歌》、《罗摩衍那》和往世书承担不同角色，不是一部由统一机构确定的圣经。家庭祭祀、寺庙礼拜、节日、朝圣与修习因地区和社群而异。

种姓与宗教、劳动、婚姻和政治有关，但各时期实践及改革存在差异，不能把不平等写成所有信徒共同认可的单一教义。

## 传播、组织与内部差异

印度教经贸易、王权和地方吸收传播到东南亚；吴哥窟的宗教用途又在长期历史中变化。传播不意味着所有地方照搬南亚社会结构。

佛教、耆那教与锡克教有各自传统与自我认同，不应为了简化强行归成印度教支派。近现代印度教改革和海外实践也有内部争论；宗教身份不等于现代印度国籍。
