# 天主教

## 传统与形成背景

天主教是基督教的重要传统，以罗马主教即教皇及与其共融的地方教会为组织核心。它从古代教会长期发展而来，不能指定一位中世纪教皇为全部传统的创始人，也不能把今天的教会制度原样套回公元1世纪。

常用外文名：Roman Catholicism。

## 发展时间线

| 阶段 | 变化与联系 |
| --- | --- |
| 古代晚期 | 罗马主教地位、主教网络与修道传统发展；教义争论通过会议、文本和政治协商形成不同结果。 |
| 11—13世纪 | 教皇改革、叙任权争论、修会及大学兴起，教会与王权既合作也竞争。 |
| 1545—1563年 | 特伦托会议回应宗教改革，重申教义，并推动神职教育和纪律改革。 |
| 19—20世纪 | 梵蒂冈第一届、第二届大公会议分别处理教皇权威与现代教会更新等问题。 |

## 信仰、文本与实践

天主教以《圣经》、圣传和教会训导共同解释信仰，承认洗礼、坚振、圣体、和好、病人傅油、圣秩及婚姻七件圣事。弥撒以圣体礼仪为中心，信徒相信圣体与基督的临在相关；历史说明应把这种信仰归属和可考礼仪制度区分。

对圣母、圣人和圣像的敬礼不等于教会自认为崇拜多个创造神。修会、朝圣、慈善、学校及家庭实践具有不同功能，不宜只用教皇和大教堂代表全部信徒生活。

## 传播、组织与内部差异

教皇、主教、堂区和修会构成多层组织，但天主教并非只有拉丁礼：东方天主教会保持不同礼仪和部分纪律。地方社会、语言、殖民历史和迁徙影响美洲、非洲及亚洲的实践。

传教与殖民扩张有时结合，也出现地方改造、反抗和内部批评。不能把教会的学校及慈善贡献与殖民强制、迫害及其他制度问题相互抵消；具体事件需分别考察。

## 史料与参考

教会文本说明其自我理解，不能自动代替独立历史研究。1054年是东西教会分裂的常用节点，差异形成及关系破裂经历长期过程；“天主教”也不等于所有使用天主一词的基督教团体。
