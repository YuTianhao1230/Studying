# 锡克教

## 传统与形成背景

锡克教形成于15—16世纪旁遮普，以古鲁那纳克（Guru Nanak，1469—1539）及其后古鲁传统为核心。它处于南亚多种宗教和政治环境之中，但有自身经典、社群与认同，不能称为印度教和伊斯兰教的简单混合。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 15—16世纪 | 古鲁那纳克的教导与社群形成。 |
| 16—17世纪 | 后继古鲁组织文本、礼仪与社群空间。 |
| 1699年 | 古鲁戈宾德·辛格建立卡尔萨，成为重要社群节点。 |
| 18世纪以来 | 政治组织、殖民时期变化、1947年分治与海外迁移持续影响社群。 |

## 信仰、文本与实践

独一神信仰、诚实劳动、分享与服务是重要观念。《古鲁·格兰特·萨希卜》承载经典权威，在谒师所中受到尊敬；古鲁的概念不能直接翻译成普通教会祭司。

公共食堂（langar）通过共同饮食与服务表达社群伦理，实践仍受到现实社会条件影响。卡尔萨入门、五件信物和头巾等有重要意义，但不应仅凭外观推断每个人的宗教身份和遵守程度。

信徒反对以种姓决定灵性价值，现实社群仍可能存在阶层与婚姻差异。规范理想与历史实践要分别解释。

## 传播、组织与内部差异

阿姆利则金庙兼有礼拜与公共服务功能，政治冲突和社群记忆影响其历史。旁遮普地区并不等于今天单一国家，1947年分治造成迁移和暴力。

海外锡克社群通过谒师所、语言教育与服务维系联系。宗教成员有不同政治立场，不能把一个政治运动等同于全部锡克教。
