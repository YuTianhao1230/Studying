# 金刚乘佛教

## 传统与形成背景

金刚乘通常指与佛教密续、灌顶、真言、曼荼罗和特定观修有关的传统，在南亚佛教中逐步发展，并传播到喜马拉雅地区、蒙古、日本等地。它常处于大乘思想和菩萨道框架中，不是与大乘完全分离的一种宗教，也不能把所有密教直接等同于藏传佛教。

常用外文名：Vajrayāna。

## 发展时间线

| 阶段 | 变化与联系 |
| --- | --- |
| 公元第一千纪中后期 | 南亚佛教密续、仪轨及修行体系逐渐丰富；具体经典的形成年代并不完全一致。 |
| 7—9世纪 | 密教文本和仪式经僧侣、译经与王权资助传播到多个地区。 |
| 中世纪 | 喜马拉雅及蒙古地区形成不同传承；日本真言宗等也保存独特的密教传统。 |
| 近现代 | 迁徙、教育和跨国传播使仪式、师承与翻译进入新的社会环境。 |

## 信仰、文本与实践

灌顶与师承为特定修行提供资格和解释，真言、手印、曼荼罗及本尊观修把身、语、意联系起来。信徒认为这些实践可以转化经验、培养智慧与慈悲；历史说明不把其宗教效力当作已经实验验证的事实。

曼荼罗是有结构的礼仪和观修空间，不只是装饰图案；忿怒尊图像也不能直接理解为鼓励现实暴力。不同级别密续、象征语言、戒律和修行资格有不同要求，不能从个别争议仪式概括所有信徒。

## 传播、组织与内部差异

经典翻译、寺院、地方政治与老师传承共同影响传播。宁玛、噶举、萨迦、格鲁等藏传体系与日本真言宗的制度和仪轨不相同；同一地区也可能并存显教、密教和地方传统。

转世制度不是金刚乘全部传统共有的组织原则，也不能把所有藏传僧侣都称作活佛。理解一个对象时应先确定年代、地区、文本和传承，而不是只凭服饰或图像判断。
