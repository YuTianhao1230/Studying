# 基督教

## 传统与形成背景

基督教形成于公元1世纪罗马统治下的犹太地区，以耶稣及其生命、死亡和复活的信仰为中心。历史研究可以讨论耶稣运动和早期社群，复活与救赎属于信徒的信仰宣称。

## 发展时间线

| 阶段 | 变化及其意义 |
| --- | --- |
| 公元1世纪 | 耶稣运动、使徒活动和早期社群发展。 |
| 4世纪 | 帝国政策改变，教会会议、信条与教会组织发展；313年政策变化不能等同于立即成为唯一国教。 |
| 中世纪 | 东、西方教会与其他古老教会各自发展，1054年是常用分裂节点而非所有差异的起点。 |
| 16世纪及以后 | 宗教改革、殖民扩张、传教与全球移民形成更多组织。 |

## 信仰、文本与实践

多数基督教传统以三位一体理解上帝，以基督的救赎为核心。少数群体的神学不同，应标明范围。《圣经》包含旧约和新约，不同教会对正典及解释传统存在差异。

洗礼、圣餐、祷告和礼仪年承担社群作用。教会对圣礼数量、主教制度、教皇权威与称义有不同理解；天主教、东正教、新教不能只按建筑样式区分。

修道院、学校、慈善机构和家庭信仰实践共同构成历史。宗教图像具有神学与礼仪功能，艺术作品不等于照片式事件记录。

## 传播、组织与内部差异

基督教通过城市网络、政治支持、传教和移民跨洲传播，也与殖民强制、教育及地方回应交织。非洲、亚洲和美洲社群并非只是被动接受欧洲版本。

圣索菲亚的用途变化说明政权与宗教空间可以多次转换。不能从一座教堂推出当地人口始终信奉同一宗教，也不能把所有现代教会政策归为早期基督徒的共同立场。
