# Agent 实战落地

本目录面向“把 Agent 做成可运行、可评测、可维护的业务系统”。基础概念回答 Agent、Workflow、Tool Call、Context、Skill、RAG 和评测是什么；本目录回答如何选型、如何拆链路、如何接入真实数据和外部系统、如何授权、如何排障，以及如何把 Demo 变成稳定服务。

D2C 视觉一致性评估场景用于贯穿本目录：比较设计稿与跨端页面渲染结果，经过数据采集、结构化清洗、对象匹配、确定性检测、模型复核、报告输出和评测回流。文档聚焦可迁移的方法论、系统职责和工程链路。

## 案例主链路

```text
业务目标与验收标准
  -> case / GT / 输入契约
  -> 设计稿与页面运行结果采集
  -> 统一结构协议与状态收敛
  -> 语义匹配 + 几何校验 + 一对一约束
  -> 颜色 / 圆角 / 尺寸 / 字号 / 字重 / 间距规则检测
  -> 模型复核与不确定样本人工确认
  -> JSON / HTML / 结果平台输出
  -> 轨迹记录、bad case 归因、GT vNext、回归评测
```

## 推荐学习顺序

1. 阅读 [实战总览：从问题到生产 Agent](<实战总览：从问题到生产Agent.md>)，建立从需求到上线的总框架。
2. 阅读 [D2C 视觉一致性评估 Agent 案例](<D2C视觉一致性评估Agent案例.md>)，把抽象框架映射到业务场景。
3. 阅读 Skill、Workflow、Tool/MCP 三张卡片，掌握能力接入和编排。
4. 阅读 RAG、数据采集、评测三张卡片，掌握数据、知识和回归闭环。
5. 阅读可靠性、安全和排障三张卡片，补齐生产边界。
6. 最后阅读 AI Coding 卡片，把这些方法迁移到日常研发。

## 实战卡片的统一结构

每张卡片按以下顺序组织：

- `知识点解析`：说明目标、架构、流程、实现原则和边界。
- `落地步骤`：说明从输入、接口、状态、工具到输出的实施顺序。
- `失败与排障`：给出可观察信号、定位层次和修复动作。
- `面试应对`：包含常考点及考法、解法/回答思路、易错点和可直接背诵的回答模板。
