# D2C 视觉一致性评估 Agent 实战地图

## 知识点解析

### 概述

本卡片是 D2C 视觉一致性评估的诊断路由图，不重复各专题的通用流程。遇到问题时，先描述可观察症状，再做一个能够缩小范围的首个诊断决策，核对项目证据，最后进入对应专题。

## 面试应对

### 如何把一个 bad case 路由到正确专题？

回答思路：用症状、首个诊断决策和项目证据三步定位。

回答模板：

我先把“效果不好”改成可观察症状，再做一个能排除大类原因的首个决策，例如输入是否同状态同批次、错误是否发生在外部调用、知识注入还是状态合并。随后核对对应证据，如 artifact、state snapshot、工具原始响应、知识版本或 GT diff。定位到首次偏离层后进入对应专题处理，避免在案例卡里重复一套通用修复流程。
