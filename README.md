# Studying 知识库

本仓库分为专业学习、中国史和世界史三个独立知识域。每个知识域分别维护内容索引和防劣化规范，新增或修改内容时应遵循目标目录内的规范；中国史与世界史共同使用根目录的历史可视化与外部资源规范。
