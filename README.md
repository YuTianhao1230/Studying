## 分类说明

### 机器学习基础

回答基础公式和通用组件是什么，放数学、统计、传统机器学习、通用神经网络组件、损失函数和强化学习基础。

- `数学与机器学习/`：数学基础、机器学习基础、统计推断、因果推断、余弦相似度等。
- `深度学习基础/`：MLP、LSTM、激活函数、损失函数、初始化、Normalization、正则化和特征表示。
- `概率与序列决策/`：马尔可夫链、HMM、概率图模型、高斯过程、MDP 与强化学习基础。
- `传统模型与表示学习/`：集成学习、核方法、异常检测、聚类降维和表示学习。
- `笔试训练/`：数学、经典模型、深度学习基础、概率模型和强化学习专项题。

### 大模型

回答 LLM/VLM 如何组成和生成，放模型结构、生成范式、注意力机制、大模型发展历史及应用层问题；训练工程进入03。

- `基础架构/`：Transformer、Self-Attention、Autoregressive Model、Dense Model、MoE、GQA、MLA、RMSNorm、RoPE 等。
- `模型细节/`：阶段性里程碑模型、当前 SOTA 模型系列、模型架构对比与选型。
- `应用与问题/`：RAG、CoT、Prompt 调优、模型幻觉、NLP 与大语言模型综述等。
- `视觉多模态与生成模型/`：视觉基础、VLM/视频/grounding、多模态任务和扩散生成模型。

### 训练优化与对齐

回答参数如何训练和更新，放模型训练路线、分布式优化、后训练、对齐算法和稳定性；数据正文统一进入04，个人项目事实进入12。

- `训练框架与并行/`：DeepSpeed、ZeRO、FSDP、Megatron-LM、JAX/XLA、Mixed Precision Training、Checkpoint 等训练工程概念。
- `后训练与对齐/`：后训练发展史、SFT、RLHF、DPO、PPO、GRPO、RLVR、Agentic RL、Reward Model、PEFT、蒸馏和模型合并。
- `超参数与优化器/`：学习率、batch、warmup、SFT 参数设置、Optimizer、weight decay 和 gradient clipping。
- `训练稳定性/`：梯度爆炸、梯度消失、Loss 异常、NaN、发散和收敛排查等。
- `笔试训练/`：训练优化、混合精度和稳定性专项题。

### 评测实验与数据质量

回答数据是否可信、模型是否真的变好。所有数据类知识统一放在这里，包括训练数据、合成数据、数据工程、切分、污染和质量治理；同时覆盖指标统计、实验设计、模型评测、LLM Judge 和 AI 产品判断。Agent 评测脚手架进入 `08_Agent/`。

### 推理部署与系统

回答模型如何稳定高效地上线运行，放推理工程、Serving 和生产系统设计。

- `推理工程/`：模型部署、推理框架、Serving、KV Cache、Batching、量化、Speculative Decoding、TensorRT-LLM、CUDA Graph、CUDA/Triton、算子、vLLM、ms-swift 等工程概念。
- `生产系统设计/`：网关、模型路由、容量、SLO、可观测性、MLOps、灰度、回滚和降级。Agent 调度与编排概念进入 `08_Agent/`。

### Python 与工程

回答如何用通用语言和工具实现，放 Python、刷题模板、工程库、深度学习框架基础、PyTorch API 和方向无关的工程工具。

- `Python语法/`：字典、内置函数、异常、列表推导式、lambda、collections、Counter、pairwise 等。
- `算法刷题/`：回溯、并查集、刷题技巧、下一个排列。
- `常用库/`：argparse、DataLoader、re、tqdm、可视化。
- `深度学习框架/`：PyTorch、TensorFlow/Keras、JAX、Hugging Face、Trainer、Accelerate、Lightning 等框架选型和训练脚手架基础。
- `PyTorch/`：torch、torchvision、torch.unsqueeze 和 Beam Search。
- `常用函数/`：detach、enumerate、torch.inference_mode、折叠注释。
- `工程工具/`：Docker 等训练、推理和普通软件项目都能复用的基础工具。

### 程序分析与代码智能

放程序分析理论、安全漏洞分析、代码大模型和工具。

- `静态分析基础/`：程序分析、静态分析、控制流、数据流、污点分析、AST/CFG/DFG。
- `安全漏洞分析/`：CWE与CVE、CWE-Bench-Java。
- `代码智能模型/`：CodeBERT、GraphCodeBERT、CodeT5、CodeT5+、UniXcoder、大模型和静态分析。
