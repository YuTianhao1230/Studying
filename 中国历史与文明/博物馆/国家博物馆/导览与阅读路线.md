# 国家博物馆：导览与阅读路线

国博可以从两种方向进入：沿“古代中国”理解历史变化，或者选玉器、瓷器、钱币、服饰等专题理解一种材料与生活方式。先读代表文物，再按兴趣扩大范围，比逐条翻公开目录更容易建立联系。

第一次阅读可先看[★代表文物先看清单](<代表文物先看清单.md>)，从八件具体文物建立线索。

## 三条阅读路线

| 路线 | 建议顺序 | 能串起什么 |
| --- | --- | --- |
| 文明与国家 | 人面鱼纹彩陶盆 → 玉龙 → 后母戊鼎 → 利簋 → 大盂鼎 | 聚落生活、礼仪象征、王权与文字证据 |
| 日常生活与交流 | 击鼓说唱俑 → 载乐骆驼 → 鎏金银香囊 → 淳化元宝金钱 → 南都繁会图 | 娱乐、技术、宗教和城市生活 |
| 宫廷与工艺 | 四羊方尊 → 螺钿镜 → 孝端皇后凤冠 → 转心瓶 → 乾隆南巡图 | 器物结构、装饰技术和权力表达 |

这里的顺序是学习路线，不是保证相邻展柜或当日可见的参观路线。

## 楼层与展览位置

| 楼层 | 主题与展厅 | 阅读方式 |
| --- | --- | --- |
| B1层 | 古代中国：北20—北25、南15—南20 | 按下方八个历史阶段串联 |
| 1、2层 | 入口、中央大厅及部分临时展厅 | 临展更换频繁，按当期展览页面核对 |
| 3层 | 饮食北11；复兴之路；北8—北10、南6—南10等展厅 | 从器物功能及近现代主题进入 |
| 4层 | 瓷器北17、服饰北18、玉器北19；钱币南11、书画南12、佛造像南13、铜镜南14 | 从材料、工艺和图像比较 |

楼层以[官方场馆地图](https://www.chnmuseum.cn/cg/)为依据，展厅名称见[当前展览列表](https://www.chnmuseum.cn/zl/)。展览名称与展厅由官网核验，逐件展柜位置未公开者不补写。已经结束的“李静训和她的时代”等临展不列为正在展出。

楼层与展览记录核验于2026年10月18日。参观前查看官网当天信息；馆藏、公开选介、常设展和临展的范围不同，个别文物还可能轮换、出借或休展。
