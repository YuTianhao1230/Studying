# 中国历史与文明

以历史时期为时间主轴，以人物、事件、典故和文物保存具体史实，并用城市古都、建筑遗址、自然地理、科技发明、文化生活和跨时代专题理解中国文明的空间与长期变化。内容覆盖文明起源至中国近现代；传说、考古、史书与文学分别标明。
