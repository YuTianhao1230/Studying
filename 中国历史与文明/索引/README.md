# 索引

本目录集中维护中国历史与文明知识库的全部索引。综合与专项索引用于完整查询，主题索引按照学习问题重新组合权威正文，不复制卡片内容。

## 综合与专项索引

| 入口 | 内容说明 |
| --- | --- |
| [查询索引](<查询索引.md>) | 按时期、对象和主题进入整个知识库。 |
| [人物索引](<人物索引.md>) | 按姓名、别名、时代和身份查询全部人物卡。 |
| [人物主题索引](<人物主题索引.md>) | 按治理、军事、思想、文学、科技、交流和改革阅读精选人物。 |
| [历史事件索引](<历史事件索引.md>) | 按时期查询战争、改革、制度和社会文化事件。 |
| [成语与典故索引](<成语与典故索引.md>) | 按词条、时代、人物和材料类型查询故事。 |
| [文物索引](<文物索引.md>) | 按名称、时代、器类和收藏机构查询文物。 |
