# 阅读方法与出处说明

## 怎样读这一模块

第一遍读全史总览和各时期概览，建立先后顺序与并立关系。再随兴趣阅读人物、成语与典故、历史事件。可从[查询索引](<索引/查询索引.md>)统一定位对象，也可通过[跨时代专题](<跨时代专题/README.md>)观察制度、社会、思想、技术、文化和交通的长期变化。

按人物阅读时，从[人物索引](<索引/人物索引.md>)或各时代的“重要人物”进入独立人物卡，先认识其身份、生平、主要贡献与历史影响，再沿卡内链接阅读相关事件。每人保留一篇权威介绍；战争、改革和制度进程放在“历史事件”；轶事、寓言和文学故事与词义、用法合写于“成语与典故”。

神话、传说和文学人物可以通过同一索引查找，但卡中明确注明性质；不为材料有限的人物虚构生卒、履历或心理。跨时代人物按主要活动归入一个时代，其早晚经历和相关材料通过链接衔接。

按空间阅读时，可从[城市与古都](<城市与古都/README.md>)进入政治与交通节点，从[建筑与遗址](<建筑与遗址/README.md>)观察具体工程和物质遗存，从[自然地理与历史区域](<自然地理与历史区域/README.md>)理解地形、水系与路线条件。现代城市、行政区和照片只用于辅助定位，不能直接代替古代城址、历史辖域和始建原貌。

按文明主题阅读时，可从[科技与发明](<科技与发明/README.md>)进入具体工艺，从[文化与社会生活](<文化与社会生活/README.md>)观察日常实践，再通过[索引](<索引/README.md>)按奇观、科技、文化生活或交通路线组合阅读。索引中的主题路线只提供入口，不建立第二份正文。

本模块以兴趣阅读与文化积累为主。故事正文为概述与解释，不是古籍全文，也不是完整的中国史教材。

“中国历史与文明”是一种常用的文明史表达。考古能够讨论距今五千年前后的复杂社会与早期国家，不能据此断言五千年间每一年都已有连续文字记载。公元前标“前”，公元后一般直接写年份；公元纪年没有公元0年。

## 五种材料分别告诉我们什么

| 材料类型 | 可以帮助理解什么 | 需要注意的边界 |
| --- | --- | --- |
| 考古材料 | 聚落、器物、生产、等级、环境与年代 | 遗址不会自动写出传说人物姓名；文化与王朝不能直接一一对应。 |
| 传世史书 | 人物、制度、事件及史家的解释 | 成书时间、材料来源、叙事选择会影响可靠性；史书不等于现场录像。 |
| 神话传说 | 祖先认同、世界观、灾难与秩序想象 | 没有可考的逐年纪年，不能当作确定王朝世系。 |
| 寓言与轶事 | 思想论证、人物形象与文化记忆 | 寓言服务于论点，轶事可能增饰；不同版本应分清。 |
| 诗歌、小说、戏曲与绘画 | 情感、观念、表达方式和后世记忆 | 允许夸张、虚构与构图选择，不能直接拿来证实每个事件细节。 |

同一篇故事可能跨两类材料。勾践是史书人物，但“卧薪”的流行细节不能全部归入《史记》；玄奘确有西行，孙悟空师徒则属于小说。

成语与典故卡统一在正文开头标注“材料类型”。标签说明主要材料的性质，可以写成“史书叙事”“思想史与寓言”“文学虚构”“史书记载与文学增饰”等组合，不等于对故事作简单的真伪二分。判断时仍应继续查看卡内的出处与辨析。

## 来源层次与使用方式

正文先叙述，再标必要出处。对历史典故优先识别原典篇名，对年代口径参考博物馆和研究机构，对成语含义辅以辞典。百度百科可用于入门查名词，但不能把百科某一版本的短摘要代替原典或专业研究。

本模块中的古籍链接有些进入全书目录，具体篇名写在故事末尾。这不表示故事里的每一句解释都是古籍原文；现代意义和历史主线分析属于对材料的概括。故事被记在较晚的书里，也不意味着人物生活在那本书的成书年代。

| 来源 | 主要用途 |
| --- | --- |
| [中国国家博物馆：Ancient China](https://en.chnmuseum.cn/exhibition/current_exhibitions_648/201911/t20191127_174983.html) | 古代中国分期与政治、经济、文化背景；不是每则轶事的独立证明。 |
| [国家文物局：中华文明探源工程访谈](https://www.ncha.gov.cn/vipchat/home/site/1/120/article.html) | 理解文明起源、早期国家与考古证据。 |
| [《史记》](https://ctext.org/shiji/zh) | 商周、春秋战国、秦汉的重要叙事；需辨别上古传说和人物增饰。 |
| [《左传》](https://ctext.org/chun-qiu-zuo-zhuan/zh) | 春秋事件与外交故事；按鲁君纪年查找。 |
| [《论语》](https://ctext.org/analects/zh) | 孔子相关言论及儒家思想，不是逐日生活记录。 |
| [《汉书》](https://ctext.org/han-shu/zh) | 苏武、张骞等西汉人物与制度。 |
| [《三国志》](https://ctext.org/sanguozhi/zh) | 三国人物与事件；正文、裴松之注和《三国演义》分别辨认。 |
| [《资治通鉴》](https://ctext.org/zizhi-tongjian/zh) | 跨时代编年与事件衔接，仍需看其依据的材料。 |
| [成语典](https://dict.idioms.moe.edu.tw/) | 词义、读音与典源版本；纸上谈兵、退避三舍、请君入瓮等卡片保留具体词条入口。 |
| [故宫博物院](https://www.dpm.org.cn/) | 明清帝系、清帝退位与作品介绍。 |
| [中国政府网：百年大事记](https://www.gov.cn/xinwen/2021-06/28/content_5621160.htm) | 近现代政治与社会变迁的关键日期，不能代替所有专题研究。 |

年份以通行学习口径为主。夏的年代、春秋战国分界等争议处保留说明；吴称帝229年可参看[南京地方志资料](https://dfz.nanjing.gov.cn/gzdt/202403/t20240315_4186987.html)，南宋1279年终结可参看[中国历史研究院的崖山相关讨论](https://hrczh.cass.cn/ywdt/zt/pplsxwzy/202502/t20250218_5846178.shtml)，清帝1912年退位可参看[故宫宣统帝资料](https://www.dpm.org.cn/court/lineage/226255.html)。

## 文物资料与图片

文物卡逐件链接国博资料与真实照片，官方介绍的直接引文已标出。引文保留旧页口径，卡片解读对有争议的断代、用途和绝对排名另作说明。图像用于学习识读，国博图片权利归原权利人，未将官网公开等同可自由商用。馆藏、官网选介、常设展和临展是不同范围，具体当天陈列以现场为准。

新增人物画像及历史画作保留文件页、作者与权利标记；画像是历史艺术作品，不能证明本人实际容貌。

跨时代地图放在 `跨时代专题/assets/`，具体时代的地图放在该时代的 `assets/`。城市、建筑遗址与山河区域的图片分别放在对应目录的 `assets/`。原创示意图不表示精确疆域、等比例距离或唯一行进路线；外部开放图片保留作者、来源、许可和适用边界。
