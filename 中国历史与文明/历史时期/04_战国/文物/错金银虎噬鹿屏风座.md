# 错金银虎噬鹿屏风座

> ★ 河北博物院“十大珍宝”。除了虎与鹿的冲突，还要看虎背上安装屏风的两个孔。

## 名称、时代与收藏

| 项目 | 内容 |
| --- | --- |
| 名称 | 错金银虎噬鹿屏风座；错金银铜虎噬鹿屏座 |
| 时代 | 战国，中山国 |
| 材质与尺寸 | 青铜，错金银；长51厘米 |
| 出土 | 1977年，河北平山县三汲村中山王墓 |
| 收藏与展览 | 河北博物院；战国雄风——古中山国，南区二层西侧 |

## 是什么与真实图像

![错金银虎噬鹿屏风座官方实物图](<../assets/文物/错金银虎噬鹿屏风座.png>)

图片来自[河北博物院屏风座专题](https://www.hebeimuseum.org.cn/shida/pingzuo.html)，原图权利归原权利人。

猛虎弓身，一足抬起，把小鹿送向张开的口部。强健虎身与细小鹿体形成鲜明对比，姿态紧张而有动感。虎身装饰以金银嵌出的纹样，在铜质表面形成颜色与线条的变化。

它原本是家具构件。木质屏风扇面已经腐朽，铜质底座保存下来，今天单独陈列时容易被看成一尊动物雕塑。

## 两个孔揭示了用途

虎的项部和臀部各设一个长方形銎，即承插构件的孔。两孔所对应的屏风方向接近直角，用来支撑曲折排列的屏面。銎口两侧又处理成动物形象，使承插结构融入整体雕塑。

这套屏风还配有其他动物形铜座，虎噬鹿座只是其中一件。不能把单件底座误称为已经完整保存的整扇屏风。

## 为什么值得看

这件作品最有趣的是，动物动作与实际承重并不冲突：虎身的厚实体量承担支撑功能，抬爪和吞噬姿势增加动态。雕塑、家具、金属镶嵌三种技术在同一器物上结合。

腹部还保存铭文，与制作年代及官匠信息有关。结合中山国其他器物，可认识王室作坊如何留下生产和管理记录。铭文内容须按完整释文解释，不应从简短介绍扩写出未经证实的具体人物故事。

## 与中原文化的联系

中山国器物中常见富有动感的动物造型，同时又采用礼器、案、屏风等中原贵族生活形式。这种结合显示地区间长期交往，不能只凭一个动物图案推定器物的全部民族归属或政治意义。
