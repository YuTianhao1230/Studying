# 战国：重要人物

按人物阅读身份、生平、主要贡献与历史影响；相关成语与典故、历史事件在人物卡中继续展开。神话、传说及文学人物分别注明性质。

[人物关系图](<人物关系图.md>)：按家族、君臣、战争阵营、学术或文学关系分图，并标注跨时代联系。

| 人物 | 身份与阅读线索 |
| --- | --- |
| [中山王厝](<中山王厝.md>) | 战国中山国君主，其王墓出土铜鼎等器物；长篇铭文补充了中山国政治与战争史。 |
| [商鞅](<商鞅.md>) | 主持秦国变法，推动军功爵、县制等制度调整；徙木立信强调政令信用。 |
| [秦孝公](<秦孝公.md>) | 任用商鞅变法的秦国君主，为秦国增强国家动员能力提供支持。 |
| [孙膑](<孙膑.md>) | 齐国军事家，与田忌赛马、围魏救赵相连；与春秋的孙武不是同一人。 |
| [田忌](<田忌.md>) | 齐国将领，与孙膑共同参与对魏战争，赛马故事突出配对与整体取舍。 |
| [庞涓](<庞涓.md>) | 魏国将领，在孙膑相关叙事中既是旧同门也是军事对手。 |
| [蔺相如](<蔺相如.md>) | 赵国大臣，完璧归赵、渑池会和与廉颇和解的故事体现外交与政治担当。 |
| [廉颇](<廉颇.md>) | 赵国名将，负荆请罪表现其与蔺相如化解冲突，亦参与长平前期防御。 |
| [赵惠文王](<赵惠文王.md>) | 蔺相如、廉颇活动时期的赵王，完璧归赵发生在其统治时期。 |
| [秦昭襄王](<秦昭襄王.md>) | 长期在位的秦王，秦赵外交与长平之战均发生在其统治时期。 |
| [孟子](<孟子.md>) | 儒家思想家，强调仁政、民本与性善，是诸子争鸣的重要代表。 |
| [庄子](<庄子.md>) | 道家思想家，善用寓言讨论自由、认识和价值判断。 |
| [韩非](<韩非.md>) | 法家思想的重要代表，以法、术、势讨论治理，常借寓言说明政治道理。 |
| [赵括](<赵括.md>) | 长平之战中接替廉颇的赵将，后世以“纸上谈兵”概括其失败。 |
| [白起](<白起.md>) | 秦国名将，指挥长平之战击败赵军，其事迹涉及大规模战争与杀降问题。 |
| [赵孝成王](<赵孝成王.md>) | 长平之战时期的赵王，换将等决策与赵国战局变化密切相关。 |
| [荆轲](<荆轲.md>) | 受燕太子丹之托刺杀秦王政，刺秦失败成为燕国危局中的著名事件。 |
| [燕太子丹](<燕太子丹.md>) | 燕国太子，策划荆轲刺秦，试图阻止秦国吞并燕国。 |
| [秦舞阳](<秦舞阳.md>) | 随荆轲入秦的副手，名字在传世记载中有不同写法。 |
