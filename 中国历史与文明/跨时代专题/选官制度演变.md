# 选官制度演变

## 选官不只是考试

国家需要决定谁有资格任官、由谁评价、怎样升迁和监督。血缘、军功、荐举、门第、学校、考试和皇帝任命在不同时期以不同方式组合，科举出现后也没有取代全部入仕渠道。

## 从贵族政治到考试取士

| 阶段 | 主要方式 | 影响与限制 |
| --- | --- | --- |
| 西周至春秋 | 世卿世禄和贵族身份 | 政治职位与宗族等级紧密相连，但各国改革逐渐改变旧秩序 |
| 战国秦 | 军功爵、客卿和官僚任用 | 出身之外的军功和才能更受重视，君主对官僚的任免加强 |
| 两汉 | 察举、征辟、博士弟子等 | 地方长官和中央官员承担推荐责任；名望、人际网络也会影响评价 |
| 魏晋南北朝 | 九品中正制 | 初意在统一人物品评，后来门第对品第与仕途的影响增强 |
| 隋唐 | 科举形成并发展，仍有门荫、荐举等渠道 | 进士等科逐渐重要，但唐代官僚来源不能只用科举解释 |
| 宋 | 科举规模扩大，殿试与考试程序发展 | 扩大士人参政路径，也促进围绕经典、文章和教育资源的竞争 |
| 元 | 科举曾停废，恢复后设有分类与名额安排 | 不能以科举一项概括元代复杂的身份和任官结构 |
| 明清 | 科举制度成熟，学校、乡试、会试、殿试衔接 | 程式化有利于统一标准，也可能限制知识表达；捐纳、荫叙等仍存在 |
| 近代 | 清末废科举，新式学堂、考试与现代文官制度探索 | 选官标准转向现代教育、专业训练和公共考试 |

## 怎样评价科举

科举扩大了非世袭入仕机会，为统一国家提供较一致的知识和选拔标准，但“开放”不等于人人条件相同。家庭教育、经济资源、性别限制与地区文教差异都会影响参与。科举也不是现代公务员考试，两者的国家结构、课程和权利观念不同。
