# 土地、赋税与财政制度

## 为什么把三者放在一起

土地关系决定谁生产、谁占有收益；赋税与徭役决定国家怎样取得粮食、货币和劳动力；财政制度则决定这些资源怎样征收、运输和支出。三者彼此关联，但“土地制度名称”不等于全部社会现实，法令与实际占有也可能不同。

## 长期变化

| 阶段 | 代表制度或现象 | 观察重点 |
| --- | --- | --- |
| 西周至春秋 | 井田等理想化记述、贡赋与劳役；鲁国初税亩 | 典籍描述与各国实际有差异；按田征税反映土地和财政变化 |
| 战国秦汉 | 授田、军功与编户；田租、口赋、算赋、徭役；盐铁等国家经营 | 国家以户籍和土地掌握人口资源，统一战争和边防推高支出 |
| 魏晋南北朝 | 屯田、占田、均田等多种安排 | 战乱、人口流动和无主土地促使政权重新组织生产 |
| 隋唐 | 均田制、租庸调，后转向两税法 | 户籍与授田基础变化后，征税逐渐更重资产与实际居处 |
| 宋 | 两税延续，商业税、专卖和货币财政更重要 | 城市与商品经济扩展，但农业税和基层负担仍然存在 |
| 元明 | 税粮、役法和里甲；明中后期一条鞭法 | 多项赋役折并、货币化，与白银流通相互影响 |
| 清 | 地丁银、摊丁入亩及地方财政实践 | 丁税并入田赋不等于所有额外差役和地方费用同时消失 |
| 近现代 | 现代预算、税制与土地制度重建 | 财政从皇朝收支转向现代国家公共财政，制度目标和产权结构改变 |

## 两条理解线索

第一，看征收单位从身份、人口、土地到资产和交易怎样组合变化。第二，看实物、劳役与货币之间怎样转换。货币化可以降低运输成本，也可能在银贵钱贱或市场波动时增加纳税者压力。

不能把“均田制”理解为平均分配全部土地，也不能把“一条鞭法”理解为全国同日、完全一致地实施。制度落实受地区、人口、土地登记和地方执行影响。
