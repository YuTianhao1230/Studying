# 科技与生产变迁

科技史不仅是发明名称和“世界第一”清单，还包括知识怎样积累、工具怎样制造、劳动怎样组织，以及技术能否在具体制度和环境中长期运行。农业、水利、冶金、印刷、航海和近代工业都需要结合生产体系理解。

## 长期主线

| 领域 | 关键变化 | 历史条件 |
| --- | --- | --- |
| 农业 | 作物驯化、铁制农具、牛耕、复种与新品种传播 | 土地制度、水利、人口和区域生态 |
| 水利 | 灌溉、运河、堤防、河工和海塘持续发展 | 岁修组织、财政投入与地方协作 |
| 冶金制造 | 青铜铸造、铁器普及、瓷器和机械工艺扩展 | 矿产、燃料、工匠组织和市场 |
| 知识传播 | 纸、雕版印刷和活字提高复制能力 | 识字群体、出版市场与国家需求 |
| 航海与测量 | 船型、指南针应用、海图和天文历法演进 | 港口、贸易网络和国家动员 |
| 近代工业 | 机器生产、铁路、电报和现代工程教育发展 | 全球贸易、资本、制度和战争压力 |

## 农业与水利

中国不同区域分别发展粟作、稻作等农业传统。战国秦汉时期铁制农具、牛耕与大型水利工程逐步扩展，但传播速度和使用方式并不一致。都江堰之所以能长期发挥作用，不只因始建设计，还依赖河道变化下的持续维护。

中古以后，江南水网开发、圩田和稻麦复种推动部分地区产量提高。宋代以来占城稻、明清时期玉米和甘薯等作物传播，改变部分地区的种植选择与人口承载，但也可能伴随坡地开发和生态压力。

## 材料、制造与能源

商周青铜礼器体现采矿、配料、制范与铸造协作。铁器普及降低部分工具成本，并改变农业和战争装备。瓷器生产则依赖原料、窑炉温度、燃料和分工，景德镇等中心与国内外市场相连。

技术水平不能只由最精美成品判断。宫廷和官营作坊能够集中资源，普通生产中的工具普及度、维修能力和成本同样重要。煤炭、木材和水力的可得性会影响冶炼与制造，但不会自动导向工业化。

## 纸、印刷与知识复制

纸的改进与普及降低书写材料成本，雕版印刷在唐宋以后扩大文本复制。活字印刷具有重要技术意义，但在汉字字数、排版规模、刻版复用和市场需求不同的场景中，雕版与活字长期并存。

印刷增加了经典、历书、医书和文学作品的流通，却不等于全民识字。教育制度、书价、城市市场和审查同样决定知识能传播到哪些群体。

## 航海、历法与近代转型

指南针相关知识从磁性认识发展到定向应用，宋元以后在航海中的使用更明确。船舶、季风知识、港口补给和航线经验共同决定远航能力，不能用一项发明解释海上贸易全部发展。

19世纪以后，机器制造、铁路、电报和现代兵工体系进入中国。洋务企业、新式学堂与工程翻译推动技术移植，但资金、管理、核心设备依赖和政治环境限制成效。现代工业化是制度、教育、市场和全球体系共同变化的过程。

## 常见误区

- 把发明首次记载、实物出现、广泛应用和社会影响当作同一时间点。
- 只比较“谁最早”，忽略技术的成本、维护、传播和生产组织。
- 把大型工程长期运行归功于一位人物，忽略后世岁修与地方知识。
- 用近代专利和实验室概念直接套用古代工匠体系。
