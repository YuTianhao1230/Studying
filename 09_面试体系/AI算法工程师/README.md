# AI 算法工程师面试知识体系索引

## 使用方式

这组文件按面试考察面组织，每个主题文件包含：

- 面试问题：面试官可直接提问的问题。
- 核心知识点：回答该类问题需要掌握的基础概念。
- 回答要点：候选人回答时应覆盖的关键判断。
- 常见追问：用于区分基础掌握和深入理解。

建议复习顺序：

1. 数学基础
2. 机器学习基础
3. 深度学习基础
4. NLP 与大语言模型
5. 训练优化与大模型训练
6. 模型评测与实验设计
7. 数据工程与数据质量
8. 模型部署与推理工程
9. AI 系统设计
10. 编程与算法工程能力
11. 实验分析与问题排查
12. AI 安全伦理与产品判断
13. 训练超参数调参指南

## 面试官综合考察维度

### 基础理论

- 是否理解数学、概率、优化的基本概念。
- 是否能解释模型为什么这样设计，而不是只背结论。
- 是否能把 loss、指标、优化目标和业务目标联系起来。

### 模型能力

- 是否理解传统机器学习和深度学习模型的适用边界。
- 是否掌握 Transformer、大语言模型、多模态模型的核心机制。
- 是否理解训练、微调、对齐、推理之间的关系。

### 数据能力

- 是否重视数据质量、数据版本和数据隔离。
- 是否能识别标签噪声、数据泄漏、分布漂移。
- 是否能构建可靠的训练集、验证集、测试集和回归集。

### 工程能力

- 是否能写稳定、可复现、可维护的训练与评测代码。
- 是否理解并发、断点续跑、日志、监控、错误恢复。
- 是否能把模型接入线上服务并分析性能瓶颈。

### 实验判断

- 是否能设计控制变量实验。
- 是否能做 bad case 分析和错误归因。
- 是否能判断指标提升是否可信、是否值得上线。
- 是否能根据 loss、eval 指标、显存、吞吐和 bad case 现象调整训练超参数。

### 产品与安全

- 是否理解模型效果、成本、延迟、安全之间的 tradeoff。
- 是否能识别 prompt injection、隐私泄露、越权工具调用等风险。
- 是否能把算法目标转化为真实用户价值。

## 高质量回答的一般结构

1. 先定义问题和目标。
2. 再说明关键机制或原理。
3. 然后结合场景说明适用条件和限制。
4. 最后给出排查、优化或落地方案。

示例：

```text
这个问题本质是在考察 X。
核心机制是 Y。
在实际系统中，需要注意 A、B、C。
如果出现异常，我会先验证 P，再检查 Q，最后通过 R 做闭环。
```
