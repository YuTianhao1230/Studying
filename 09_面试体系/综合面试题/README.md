# 综合面试题

本目录存放跨主题的综合面试问题，适合在完成知识点复习后做统一查漏补缺。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [面试题.md](<面试题.md>) | 综合面试题集合，覆盖算法、模型、工程和项目追问。 |
| [自我介绍与行为面试.md](<自我介绍与行为面试.md>) | 自我介绍、STAR、失败经历、协作冲突、职业规划和反问。 |
| [AI面试常见问题与作答模板.md](<AI面试常见问题与作答模板.md>) | AI 视频/语音初筛的考察形式、高频题型、答题结构和可背模板。 |

## 学习路线

1. 先完成对应知识目录的复习。
2. 再用 [面试题.md](<面试题.md>) 做综合测试。
3. 用 [自我介绍与行为面试.md](<自我介绍与行为面试.md>) 准备通用面、HR 面和用人领导面。
4. 用 [AI面试常见问题与作答模板.md](<AI面试常见问题与作答模板.md>) 准备录制式初筛和开放问答。
5. 对答不上来的问题回到对应知识卡片补齐。
