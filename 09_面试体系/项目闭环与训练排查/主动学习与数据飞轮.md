# 主动学习与数据飞轮

## 知识点解析

### 概述

在模型训练项目里，“数据飞轮”如果只说成“把 bad case 回流训练”，会显得比较工程化但不够系统。更专业的表述是：这是一个带主动学习思想的数据闭环。

主动学习关注的是：在标注成本有限时，模型应该优先请求哪些样本被人工标注，才能最大化下一轮训练收益。关键帧识别项目中的“模型筛 bad case -> 人工复查 -> relabel -> 回流训练”，本质上就是一种面向业务准出的主动学习闭环。

### 数据飞轮和主动学习的关系

| 概念 | 重点 | 在关键帧识别中的对应 |
| --- | --- | --- |
| 数据飞轮 | 从线上或评测错误中持续回流数据，推动模型迭代 | 模型预测 -> bad case -> 人工复查 -> 重标 -> 再训练 |
| 主动学习 | 标注预算有限时，选择最值得标注的样本 | 优先选择高价值业务线、低分指标、模型不确定或错误集中的样本 |
| 难例挖掘 | 找模型当前不会的样本 | 购物车角标、小元素、白膜、二次刷新、边界帧 |
| 数据治理 | 修正标签、标准、schema 和版本 | relabel、标注标准沉淀、数据版本管理 |

因此，面试里可以把关键帧项目表述为：以主动学习思想驱动的数据飞轮，而不是简单的数据清洗。

### 为什么不能平均补数据

平均补数据的问题是资源利用率低。关键帧识别里有 170+ 指标，不同业务线和指标的数据量、业务价值、当前准确率差异很大。如果平均补数据，会出现：

- 高分指标继续占用训练预算，边际收益很低。
- 低价值指标被过度优化，对业务准出帮助有限。
- 真正影响上线的高优低分指标没有被优先解决。
- 长尾指标样本太少，补少量数据也难以形成稳定收益。

主动学习式数据飞轮更关注“下一条标注最值不值得”。判断标准包括：

1. 业务价值高不高。
2. 当前指标是否低于准出线。
3. 样本量是否足够支撑训练。
4. 错误类型是否集中。
5. 人工复查后是否能形成明确标注标准。
6. 回流后是否可能带来泛化收益。

### 样本选择策略

关键帧识别项目中，可以把候选回流样本分成几类：

| 样本类型 | 价值 | 处理方式 |
| --- | --- | --- |
| 高优业务线低分指标 | 直接影响业务准出 | 优先送标和回流 |
| 模型预测与 GT 差异大 | 可能暴露标注错或模型短板 | 人工复查后分类处理 |
| 模型不确定样本 | 可能接近边界，标注信息量高 | 精筛并补充边界证据 |
| 小元素相关错误 | 暴露细粒度 UI 感知不足 | 补样本或引入 UI primitive |
| 标注标准冲突样本 | 会污染训练目标 | 先修标准，再重标 |
| 异常视频或坏样本 | 训练价值低且风险高 | 过滤或单独归档 |

### 主动学习闭环

一个更专业的闭环可以写成：

1. 训练初版模型。
2. 在干净评测集和业务回放集上推理。
3. 按业务线、task_type、误差大小和模型置信度筛选候选样本。
4. 对候选样本做人工复查和错误归因。
5. 按类型决定 relabel、修标准、补数据、过滤异常或加入回归集。
6. 构建新数据版本，训练新模型。
7. 比较全量指标、核心业务指标、目标 bad case 指标和数据成本。
8. 进入下一轮选择。

这比“模型错了就重标”更严谨，因为它显式包含样本选择、标注预算、收益评估和回归验证。

### 和强化学习的区别

主动学习和 RL 不一样。

- 主动学习解决“哪些样本值得标注或回流”。
- RL 解决“模型输出什么更应该被奖励”。

关键帧识别中，两者可以结合：

- 主动学习用于选择高价值视频样本、边界样本和错误样本。
- Structured CoT SFT 用于冷启动模型的证据表达。
- RL 用 `R_time + R_format + R_boundary_evidence - P_length` 继续优化输出质量。

### 数据飞轮的风险

数据飞轮如果设计不好，会引入新的问题：

1. 过度采样 bad case，导致训练分布偏离真实线上分布。
2. 只修当前模型错例，模型对历史能力遗忘。
3. 人工重标标准变化，但旧数据没有同步处理。
4. 将评测集 bad case 回流训练后，继续用同一评测集报指标。
5. 模型筛选样本存在偏差，导致只优化模型能暴露的问题。

因此每轮飞轮都要保留稳定回归集，并同时观察全量指标和目标指标。

## 面试应对

### 你这个数据飞轮和主动学习有什么关系？

回答思路：说明主动学习是样本选择思想，数据飞轮是工程闭环。

回答模板：

我理解数据飞轮是工程闭环，主动学习是其中的样本选择策略。关键帧项目里不是把所有数据平均送标，而是先用当前模型跑评测和业务样本，筛出高价值 bad case、低分指标和不确定边界样本，再由人工复查和重标，最后回流训练。这样做的本质是：在标注成本有限的情况下，优先选择最能提升模型准出能力的样本。所以我会把它描述为带主动学习思想的数据飞轮。

### 为什么不能所有 bad case 都送标？

回答思路：强调标注预算、样本质量和泛化收益。

回答模板：

所有 bad case 都送标不一定划算。第一，有些 bad case 是异常视频或数据映射问题，训练价值低；第二，有些是评测集本身 GT 错，直接回流会污染训练；第三，有些错误只影响长尾低价值指标，对业务准出帮助有限。更合理的做法是按业务价值、当前 ACC、样本量、错误集中度和可修复性排序，优先处理能带来泛化收益的样本。

### 主动学习怎么选择样本？

回答思路：结合 uncertainty、diversity、representativeness 和 business value。

回答模板：

我会结合四类信号选样本。第一是不确定性，比如模型预测和 GT 接近边界、或者多次推理结果不一致。第二是错误严重程度，比如预测时间和 GT 差异很大。第三是代表性，样本要覆盖高频业务场景和典型错误模式。第四是业务价值，高优业务线和准出相关指标优先。关键帧项目里，我会优先选国际电商等核心业务线中 ACC 低、样本量足、错误类型集中的指标做回流。

### 数据飞轮怎么避免过拟合 bad case？

回答思路：强调回归集、分布控制和新旧数据混合。

回答模板：

我会避免只用 bad case 训练。回流数据应该和原始高质量数据混合，并控制比例，防止模型过度适配少数错误模式。同时要保留独立回归集和干净测试集，不能把评测 bad case 回流后继续用同一集合报最终指标。评估时除了目标 bad case 是否修复，还要看全量 ACC、业务线 ACC 和历史能力是否退化。

### 如何判断一轮数据飞轮是否有效？

回答思路：不要只看平均分，看目标指标和错误类型是否变化。

回答模板：

我会看四类结果。第一是目标指标是否提升，比如高优业务线或低分 task_type 的 ACC 是否过准出线。第二是全量指标是否没有明显退化。第三是 bad case 类型是否发生变化，比如原来集中在标注错误和标准冲突，下一轮是否明显减少。第四是单位标注成本收益，也就是这轮新增数据带来的边际提升是否值得继续投入。如果边际收益下降，就要考虑换模型、改输入表示或调整推理策略。

### 主动学习和难例挖掘有什么区别？

回答思路：难例挖掘是样本来源之一，主动学习还要考虑标注价值。

回答模板：

难例挖掘通常关注模型当前做错或做不好的样本，而主动学习更关注“哪些样本值得花标注成本”。难例不一定都值得标注，比如异常样本、低价值长尾样本或无法形成泛化收益的样本。主动学习会综合不确定性、代表性、多样性和业务价值。关键帧项目里，bad case 是候选池，但最终是否送标还要看业务线、指标重要性和错误类型。

### 数据飞轮什么时候应该停？

回答思路：看边际收益和瓶颈是否迁移。

回答模板：

当连续几轮回流后目标指标提升很小，bad case 不再主要来自标注错误或标准冲突，而是集中在模型感知能力、低 FPS 漏帧或复杂推理能力上，就说明单纯数据飞轮接近收益上限。这时应该切换优化方向，比如更强基座、UI primitive、粗筛加精筛、Structured CoT SFT 或 RL，而不是继续机械补数据。
