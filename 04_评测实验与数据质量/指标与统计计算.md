# 指标与统计计算

## 知识点解析

### 概述

分类和排序指标从不同角度衡量模型：Precision/Recall 衡量阈值决策，ROC-AUC 衡量正负样本排序，AP 和 NDCG 衡量相关结果的位置。统计推断在点估计之外表达抽样不确定性，需要明确独立样本单位、配对关系、置信水平和最小可检测效果。指标定义、同分规则、聚合权重及采样单位变化，都可能改变模型比较结论。

### 一、混淆矩阵与阈值计算

设 TP=30、FP=10、FN=20、TN=40，总样本数 100：

```text
Precision = TP/(TP+FP) = 30/40 = 0.75
Recall    = TP/(TP+FN) = 30/50 = 0.60
F1        = 2TP/(2TP+FP+FN) = 60/90 ≈ 0.6667
Accuracy  = (TP+TN)/N = 0.70
```

考法：给混淆矩阵求指标，或问调整阈值后的变化。解题时先固定哪类是正类，阈值升高通常减少预测正例，Recall 不增加，但有限样本上的 Precision 不保证单调增加。零分母时指标未定义，代码可以按预先约定返回 0 或 NaN，不能默默更改口径。

多分类 micro 指标先汇总 TP/FP/FN，macro 指标先逐类算再等权平均；weighted macro 按类别样本数加权。类别不均衡时三者可能差很多。

### 二、AUC：正负配对与同分

二分类 ROC-AUC 为：

$$
\mathrm{AUC}=\frac{1}{n_+n_-}\sum_{i:y_i=1}\sum_{j:y_j=0}
\left[\mathbf1(s_i>s_j)+\frac12\mathbf1(s_i=s_j)\right].
$$

**例题：**正样本分数 `[0.9, 0.5]`，负样本分数 `[0.5, 0.1]`。

四对分别贡献 `1、1、0.5、1`，所以 AUC=`3.5/4=0.875`。不能将同分当全胜或全负。所有分数相同时，若正负类都存在，AUC=0.5；只有一个类别时 AUC 未定义。

手写时可从双循环开始，复杂度 `O(n_+n_-)`；优化为排序后给同分样本平均秩：

$$
\mathrm{AUC}=\frac{\sum_{i:y_i=1}\mathrm{rank}(s_i)-n_+(n_++1)/2}{n_+n_-}.
$$

秩从小到大、从 1 开始，排序复杂度 `O(n log n)`。上例秩为 `4、2.5、2.5、1`，正样本秩和 `6.5`，得到 `(6.5-3)/4=0.875`。

**GAUC：**先逐用户/请求算 AUC，再按约定权重聚合。单类分组无法计算 AUC，常见做法是排除这些组，并报告排除比例。例如有效组 A 的 AUC=1、样本数=2，B 的 AUC=0.5、样本数=4，样本数加权 GAUC=`(2×1+4×0.5)/6=2/3`；等组加权则为 0.75。GAUC 不等于全局 AUC，两者比较的样本对不同。

### 三、AP 与 PR-AUC：先确定积分规则

二元相关性、无同分时，按预测分数降序排列标签 `[1,0,1,0]`，共有两个正例：

| 排名 k | 标签 | Precision@k | Recall@k |
| --- | --- | --- | --- |
| 1 | 1 | 1 | 0.5 |
| 2 | 0 | 0.5 | 0.5 |
| 3 | 1 | 2/3 | 1 |
| 4 | 0 | 0.5 | 1 |

非插值 Average Precision 为：

$$
AP=\sum_k (R_k-R_{k-1})P_k=(1+2/3)/2=5/6.
$$

本例若将 PR 曲线起点约定为 `(R=0,P=1)`，按线性梯形积分，得到 `0.5+(0.5+2/3)×0.5/2=19/24≈0.7917`，与 AP≈0.8333 不同。因此“PR-AUC”需要说明是 AP、梯形积分还是其他插值定义。

**同分按阈值成组处理。**若一个正例、一个负例分数相同，不能依输入排列人为先放正例。两者同时进入预测正类，Recall 从 0 到 1，Precision=0.5，非插值 AP=0.5。全负样本下 Recall 无定义；若实现按约定给 AP=0，需注明。目标检测 AP 还包含 IoU 匹配和插值协议，不可直接套用这里的分类 AP 数值。

### 四、NDCG 与 MRR：相关程度和首次命中

给出已排序结果的相关等级 `[3,0,2]`，采用增益 `2^rel-1`：

$$
DCG@K=\sum_{i=1}^{K}\frac{2^{rel_i}-1}{\log_2(i+1)},\qquad
NDCG@K=\frac{DCG@K}{IDCG@K}.
$$

```text
DCG@3  = 7 + 0/log2(3) + 3/2 = 8.5
IDCG@3 = 7 + 3/log2(3) + 0/2 ≈ 8.8928
NDCG@3 ≈ 0.9558
```

先按真实相关等级降序得到理想顺序，再计算分母。不得拿模型预测顺序同时算分子与分母。IDCG=0 时通常约定 NDCG=0，并说明查询是否纳入平均。若相关性取线性增益而非指数增益，数值会变；不同协议不能混比。

MRR 只看每个查询第一个相关结果的倒数排名。三个查询首次命中排名为 `1、3、未命中`，MRR=`(1+1/3+0)/3=4/9`。它不关注第二个及以后的相关结果；多结果质量可用 NDCG 或 AP。上述 NDCG 假设顺序已确定，若需按预测分数排序，另外约定同分排序规则。

### 五、准确率的 Wilson 区间

**例题：**100 个独立样本中答对 80 个，求 95% 区间。取 `p̂=0.8`、`n=100`、`z=1.96`：

$$
c=\frac{\hat p+z^2/(2n)}{1+z^2/n},\quad
h=\frac{z}{1+z^2/n}
\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}.
$$

得到 `c≈0.7889`、`h≈0.0777`，区间约 `[0.7112, 0.8666]`。即使准确率为 0 或 1，Wilson 区间仍有宽度，通常比直接使用 `p̂ ± 1.96√(p̂(1-p̂)/n)` 更合适。

频率学派的 95% 指重复抽样并构造区间时约 95% 的区间覆盖真实参数；不是给已经固定的真实参数分配 95% 概率。区间只描述该抽样模型下的不确定性，无法修复数据泄漏、标签偏差或不代表线上流量的问题。

### 六、配对 Bootstrap 与视频分组

两个模型在同一批案例上评测，必须保存一一对应关系。设四个独立案例的新减旧得分差为 `[1,0,-1,1]`，平均差为 0.25：

1. 从案例索引 `{0,1,2,3}` 有放回抽 4 个索引。
2. 两模型使用同一组索引，重新计算完整指标差。
3. 重复如 2000 次，取 2.5% 与 97.5% 分位数作为百分位区间。
4. 报告随机种子、抽样单位和统计量。四个案例仅用于理解流程，实际区间很不稳定。

一次抽到 `[0,0,1,3]`，差值为 `[1,1,0,1]`，均值 0.75；抽到 `[2,2,1,3]`，均值 -0.25。对 F1/AUC 等非加性指标，应在重采样数据上重新算指标，不能平均所谓“逐样本 AUC”。单类重采样导致 AUC 未定义时，需要预先规定分层抽样或无效重采样处理方式并报告。

**关键帧与攻击评估：**

- 同一视频中的帧相互相关；一张源图生成的多个扰动版本也相关。独立单位通常是视频、会话或源图，应整组重采样，两个模型仍保持配对。
- 若三个视频分别有 `100、2、2` 帧，其帧准确率为 `0.9、0.5、0.5`，按帧加权总体准确率=`92/104≈0.8846`，每视频等权准确率=`(0.9+0.5+0.5)/3≈0.6333`。这两个指标回答不同问题，采样单位与聚合权重应分别说明。
- 新模型将同一视频的结束帧误差降低，可对“每视频误差之差”做配对分析；先定义误差方向，避免把越低越好的指标误写为越高越好。
- Bootstrap 区间跨零意味着当前证据不足，不能宣称模型相等；不跨零也不能排除选择性汇报或评测偏差。

### 七、A/B 样本量：绝对提升与相对提升

**例题：**CTR 从 10% 提高到 11%，希望双侧显著性水平 5%、功效 80%，两组等量且观测独立。

取 `p0=0.10`、`p1=0.11`、`δ=0.01`、`p̄=0.105`、`z_(1-α/2)≈1.96`、`z_(1-β)≈0.84`。两独立比例正态近似下，每组样本量：

$$
n\approx
\frac{\left[
1.96\sqrt{2\bar p(1-\bar p)}
+0.84\sqrt{p_0(1-p_0)+p_1(1-p_1)}
\right]^2}{(p_1-p_0)^2}
\approx14734.
$$

规划时向上取整为每组约 1.48 万个独立观测，总计约 2.96 万。该提升是 **1 个百分点、相对提升 10%**。若目标为“相对提升 1%”，则 `p1=0.101`，差值只有 0.001，所需样本量大约增至原来的百倍量级。

这是固定样本量、简单随机分组、单次主指标检验的近似。按用户分流但每个用户多次曝光时，曝光并不独立，需按用户统计或考虑聚类设计效应；长周期、季节性、流量损失、多重检验也会改变计划。不断看 p-value 并在首次显著时停止会抬高误报率，需要预设周期或使用合适的序贯方法。

## 面试应对

### AUC 高，为什么线上 Precision 仍可能低？

回答思路：区分跨阈值排序、类别基率和具体阈值决策。

回答模板：

AUC 衡量随机正例高于负例的概率，同分计半分。它不直接规定业务阈值。即使排序较好，线上正例很稀少或阈值设置不合适，预测正例中仍可能有很多误报。我会结合真实基率下的 PR 曲线、阈值指标和错误成本选阈值，并检查概率校准。

### AP 和 PR-AUC 可以直接当成同一个数吗？

回答思路：先约定离散阈值、同分处理和积分规则，再讨论数值。

回答模板：

不一定。非插值 AP 用每段 Recall 增量乘该阈值的 Precision；梯形 PR-AUC 在相邻点间线性插值，两者可能不同。分数相同的样本还必须一起进入阈值，不能靠排序打破同分制造收益。我会说明使用的协议和无正例处理，再比较模型。

### 同一批视频上准确率提高了两个百分点，怎么验证？

回答思路：固定指标和独立单位，保持配对，检查区间、分桶和混杂因素。

回答模板：

先固定视频集合、标注版本和帧误差容限，并明确是每视频等权还是按帧加权。两个模型在同一批视频上比较，按视频或更高层独立会话做配对 Bootstrap；每次整组抽取并重新计算指标差。如果区间支持提升，再看关键业务分桶是否退化，以及数据、Prompt、模型等变化能否通过对照区分。不能把同一视频的很多帧当作独立样本放大置信度。

### 提升 1% 需要多少实验样本？

回答思路：先澄清绝对/相对提升，再列出基线、显著性水平、功效和随机化单位。

回答模板：

没有固定答案。CTR 从 10% 到 11% 是提升一个百分点、相对提升 10%；到 10.1% 才是相对提升 1%。明确基线和最小可检测差异后，结合显著性水平、统计功效与分组方式估算样本量。独立两组比例的样本量近似与差异平方成反比，因此目标差异缩小十倍，样本量会增长约百倍。
