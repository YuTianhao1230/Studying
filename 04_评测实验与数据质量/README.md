## 学习路线

1. 先看 [模型评测与实验设计.md](<模型评测与实验设计.md>)，建立评测基本框架。
2. 再看 [实验分析与问题排查.md](<实验分析与问题排查.md>) 和 [LLM_Judge.md](<LLM_Judge.md>)。
3. 接着看数据相关文件，重点理解泄漏、合成数据和数据质量。
4. 最后看 [AI安全伦理与产品判断.md](<AI安全伦理与产品判断.md>)，补充上线风险视角。
