# 评测实验与数据质量

本目录回答“数据是否可信、模型是否真的变好”。所有数据类知识统一放在这里，包括训练数据、合成数据、数据处理与治理、数据切分与污染；同时覆盖指标、统计、实验设计、模型评测和安全伦理。

## 内容边界

- 数据是本目录的权威内容，无论它用于预训练、后训练、评测还是线上特征。
- `训练数据构造与合成数据`描述的是数据资产及质量控制，不归入训练算法目录。
- 优化器、训练工程和 SFT/DPO/PPO/GRPO 等参数更新方法进入 [03_训练优化与对齐](<../03_训练优化与对齐/README.md>)。
- 项目中的具体数据选择、方案实施和结果复盘可链接本目录方法，但保留在对应项目目录。

## 学习路线

1. 先看 [模型评测与实验设计.md](<模型评测与实验设计.md>)，建立评测基本框架。
   随后完成[指标与统计计算](<指标与统计计算.md>)中的手算，核对指标口径和独立样本单位。
2. 再看 [实验分析与问题排查.md](<实验分析与问题排查.md>) 和 [LLM_Judge.md](<LLM_Judge.md>)。
3. 接着看 [训练数据构造与合成数据.md](<训练数据构造与合成数据.md>)、[数据工程与数据质量.md](<数据工程与数据质量.md>) 和 [Hive_Spark与Feature_Store.md](<Hive_Spark与Feature_Store.md>)，建立数据构造、治理与基础设施视角。
4. 最后看 [AI安全伦理与产品判断.md](<AI安全伦理与产品判断.md>)，补充上线风险视角。
