# 评测实验与数据质量笔试训练

本目录训练数据质量、概率校准、指标解释和实验设计判断，答案以04中的权威知识卡为准。

## 训练材料

| 文件 | 内容 |
| --- | --- |
| [数据质量与实验设计训练.md](<数据质量与实验设计训练.md>) | 数据泄漏、不平衡、校准、阈值、A/B、SRM、CUPED 与统计推断。 |

## 使用方法

1. 先按数据、指标、实验三类完成题目，不先查看答案。
2. 场景题先判断信息在部署时是否可获得，再判断统计结论是否可信。
3. 错题回链到[数据工程与数据质量](<../数据工程与数据质量.md>)、[指标与统计计算](<../指标与统计计算.md>)和[模型评测与实验设计](<../模型评测与实验设计.md>)。
