# 搜索推荐广告专题索引

这个目录用于补齐大厂算法工程师 JD 中高频出现的业务算法能力：搜索、推荐、广告、召回、排序、重排、CTR/CVR 预估、A/B 测试和线上指标。

## 为什么要单独成目录

大厂算法岗不只看模型基础，更看你能不能把算法放进真实业务链路。搜索、推荐、广告是最典型的算法落地场景，也是字节、阿里、美团、Meta、Google 等公司 JD 和面试中反复出现的方向。

## 核心知识框架

```text
用户请求 / Query / User Context
  -> 召回 Retrieval
  -> 粗排 Pre-ranking
  -> 精排 Ranking
  -> 重排 Re-ranking
  -> 规则 / 多样性 / 安全过滤
  -> 展示
  -> 用户反馈
  -> 日志回流
  -> 训练数据
  -> 模型迭代
```
