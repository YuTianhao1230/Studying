# 广告排序与CTR预估

## 知识点解析

### 概述

广告排序系统是在候选广告中预测用户点击、转化和商业价值，并在用户体验、广告主收益和平台收益之间做排序决策。

### 基本链路

```text
用户请求
  -> 广告召回
  -> 粗排
  -> 精排
  -> 出价 / 质量分 / 预估值融合
  -> 重排与过滤
  -> 展示
  -> 点击 / 转化 / 收益反馈
```

### CTR / CVR / eCPM

- CTR：Click Through Rate，点击率。
- CVR：Conversion Rate，转化率。
- eCPM：每千次曝光预期收益。

常见广告排序目标：

```text
eCPM = bid * pCTR * pCVR * calibration_factor
```

实际系统会更复杂，还会考虑：

- 广告质量。
- 用户体验。
- 预算消耗。
- 频控。
- 行业和内容安全。
- 多目标收益。

### CTR 预估为什么难

- 正负样本极不平衡。
- 用户兴趣变化快。
- 特征稀疏。
- 曝光位置影响点击。
- 广告主预算和出价动态变化。
- 离线训练数据存在选择偏差。

### 常见模型

#### LR / GBDT + LR

早期常用，强调可解释和稳定。

#### Wide & Deep

Wide 记忆高频规则，Deep 学习泛化特征。

#### DeepFM / DCN

建模显式或隐式特征交叉。

#### DIN / DIEN

建模用户历史行为和当前候选广告之间的兴趣相关性。

#### 多任务模型

同时预测 CTR、CVR、GMV、停留时长等目标。

常见问题：

- 多目标冲突。
- 样本空间不一致。
- 负迁移。

### 特征工程

常见特征：

- 用户画像。
- 广告特征。
- 商品特征。
- 上下文特征。
- 历史行为序列。
- 统计特征。
- 交叉特征。

生产系统还会关注：

- Feature Store。
- 特征实时性。
- 训练-serving skew。
- 缺失值处理。
- 特征漂移。

### 评估指标

- AUC：整体排序能力。
- GAUC：按用户或 group 加权的排序能力。
- LogLoss：概率校准。
- Calibration：预估概率和真实概率是否一致。
- CTR/CVR/GMV：线上业务指标。
- p95/p99 latency：线上服务性能。

### 常见面试追问

#### 离线 AUC 涨，线上收益不涨怎么办？

可能原因：

- 离线样本分布和线上流量不一致。
- 业务目标不只点击，还有转化、留存和体验。
- 模型校准不好。
- 位置偏差或曝光偏差未处理。
- 实验流量太小或周期太短。
- 上线链路存在训练-serving skew。

#### 如何处理样本偏差？

可选思路：

- 随机探索流量。
- 负采样校正。
- IPS / Doubly Robust。
- 按曝光位置建模。
- 加入校准层。

### 广告排序与CTR预估 的核心机制是什么？

回答思路：从样本、特征、模型、排序链路和反馈闭环回答。

回答模板：

广告排序系统是在候选广告中预测用户点击、转化和商业价值，并在用户体验、广告主收益和平台收益之间做排序决策。 核心是把用户行为、内容特征和上下文信号转成可学习的排序或匹配问题。

回答思路：围绕偏差、冷启动、离线线上不一致回答。
