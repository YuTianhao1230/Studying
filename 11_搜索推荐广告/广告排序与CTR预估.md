# 广告排序与 CTR 预估

## 一句话解释

广告排序系统是在候选广告中预测用户点击、转化和商业价值，并在用户体验、广告主收益和平台收益之间做排序决策。

## 基本链路

```text
用户请求
  -> 广告召回
  -> 粗排
  -> 精排
  -> 出价 / 质量分 / 预估值融合
  -> 重排与过滤
  -> 展示
  -> 点击 / 转化 / 收益反馈
```

## CTR / CVR / eCPM

- CTR：Click Through Rate，点击率。
- CVR：Conversion Rate，转化率。
- eCPM：每千次曝光预期收益。

常见广告排序目标：

```text
eCPM = bid * pCTR * pCVR * calibration_factor
```

实际系统会更复杂，还会考虑：

- 广告质量。
- 用户体验。
- 预算消耗。
- 频控。
- 行业和内容安全。
- 多目标收益。

## CTR 预估为什么难

- 正负样本极不平衡。
- 用户兴趣变化快。
- 特征稀疏。
- 曝光位置影响点击。
- 广告主预算和出价动态变化。
- 离线训练数据存在选择偏差。

## 常见模型

### 1. LR / GBDT + LR

早期常用，强调可解释和稳定。

### 2. Wide & Deep

Wide 记忆高频规则，Deep 学习泛化特征。

### 3. DeepFM / DCN

建模显式或隐式特征交叉。

### 4. DIN / DIEN

建模用户历史行为和当前候选广告之间的兴趣相关性。

### 5. 多任务模型

同时预测 CTR、CVR、GMV、停留时长等目标。

常见问题：

- 多目标冲突。
- 样本空间不一致。
- 负迁移。

## 特征工程

常见特征：

- 用户画像。
- 广告特征。
- 商品特征。
- 上下文特征。
- 历史行为序列。
- 统计特征。
- 交叉特征。

生产系统还会关注：

- Feature Store。
- 特征实时性。
- 训练-serving skew。
- 缺失值处理。
- 特征漂移。

## 评估指标

- AUC：整体排序能力。
- GAUC：按用户或 group 加权的排序能力。
- LogLoss：概率校准。
- Calibration：预估概率和真实概率是否一致。
- CTR/CVR/GMV：线上业务指标。
- p95/p99 latency：线上服务性能。

## 常见面试追问

### 离线 AUC 涨，线上收益不涨怎么办？

可能原因：

- 离线样本分布和线上流量不一致。
- 业务目标不只点击，还有转化、留存和体验。
- 模型校准不好。
- 位置偏差或曝光偏差未处理。
- 实验流量太小或周期太短。
- 上线链路存在训练-serving skew。

### 如何处理样本偏差？

可选思路：

- 随机探索流量。
- 负采样校正。
- IPS / Doubly Robust。
- 按曝光位置建模。
- 加入校准层。

## 面试可能怎么问

1. CTR 预估模型怎么设计？
   - 回答思路：先明确目标和约束，再拆系统模块，最后说明指标、风险和上线验证方式。
   - 回答模板：先明确曝光样本和点击/转化标签，再构造用户、广告、上下文和历史行为特征，选择 LR/DeepFM/DCN/DIN 等模型，并同时评估 AUC、校准和线上收益。
2. AUC 和 LogLoss 分别反映什么？
   - 回答思路：先定义问题，再说明核心机制、适用边界、风险和验证方式。
   - 回答模板：这个问题在 广告排序与CTR预估 场景下，核心是说明它解决什么实际工程问题，以及如何落地。完整回答需要覆盖目标、执行方式、失败风险和验证指标。
3. GAUC 为什么比 AUC 更适合推荐/广告？
   - 回答思路：先给适用条件，再给不适用条件，最后说明真实系统里如何组合使用。
   - 回答模板：这个问题在 广告排序与CTR预估 场景下，核心是说明它解决什么实际工程问题，以及如何落地。完整回答需要覆盖目标、执行方式、失败风险和验证指标。
4. 如何处理曝光偏差和位置偏差？
   - 回答思路：按“目标定义 -> 关键步骤 -> 风险控制 -> 指标验证”的顺序回答，避免只讲抽象原则。
   - 回答模板：我会把 处理曝光偏差和位置偏差 拆成几个步骤：先明确目标和输入输出，再设计关键模块或策略，然后加入失败处理和权限/质量约束，最后用离线指标、线上指标或回归测试验证效果。在 广告排序与CTR预估 场景里，重点是能落到真实工程流程。
5. 如何设计广告排序系统？
   - 回答思路：按“目标定义 -> 关键步骤 -> 风险控制 -> 指标验证”的顺序回答，避免只讲抽象原则。
   - 回答模板：广告排序通常包括召回、粗排、精排、出价与质量融合、重排、频控和安全过滤。排序目标要综合 pCTR、pCVR、bid、用户体验和预算。
