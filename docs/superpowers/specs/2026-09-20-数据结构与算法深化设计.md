# 数据结构与算法深化设计

## 目标

深化 `10_计算机基础知识/数据结构与算法`，使其从“高频知识点集合”升级为适合银行、运营商笔试和基础面试的系统知识库。保留现有成熟卡片，合并重叠主题，新增缺失的算法基础和高级数据结构。

## 现状与边界

现有卡片已经覆盖：

- 线性表、栈队列、双指针、滑动窗口、前缀和和链表技巧。
- 二叉树、BST、遍历还原。
- 堆、哈希、排序、二分。
- BFS/DFS、Dijkstra、并查集。
- 背包、LIS、LCS、编辑距离。
- P/NP/NP 完全/NP 难及伪多项式时间。

现有内容的主要问题不是完全缺失，而是以下内容不够系统：

- 复杂度分析缺少递归、摊销、输入编码和正确性证明的统一入口。
- 树结构缺少 AVL、红黑树、Trie、B 树/B+ 树的关系梳理。
- 图算法缺少 Bellman-Ford、Floyd、最小生成树、拓扑排序和二分图匹配的完整对比。
- KMP 只有 README 中的概要，没有独立的字符串算法卡片。
- 贪心、分治、回溯没有统一的适用条件、正确性和剪枝框架。
- 缺少面向笔试的综合题、计算题、代码输出题和错题入口。

## 组织方案

采用方案 A：

1. 保留已有主题文件名和已有相对链接。
2. 对 `README.md`、`线性表.md`、`排序算法.md`、`图基础.md`、`动态规划入门模型.md` 等已有成熟文件做定向深化。
3. 新增边界清晰、无法自然并入现有卡片的主题文件。
4. 将重复内容合并到已有卡片，不为每个术语单独创建碎片文件。

新增文件：

```text
数据结构与算法/
├── 复杂度分析与算法基础.md
├── 树结构进阶.md
├── 字符串算法.md
├── 图算法进阶.md
├── 贪心分治与回溯.md
└── 数据结构算法笔试题.md
```

## 每张卡片的内容标准

每张正文卡片至少包含：

- `### 概述`：说明问题、核心机制和适用边界。
- 核心定义与结构组成。
- 基本操作或算法流程。
- 复杂度表，并说明复杂度成立的前提。
- 典型题型和识别流程。
- 边界条件、易错点和对比表。
- 至少一个可复用的伪代码或代码模板。
- 笔试自测或面试回答模板。

## 主题设计

### 复杂度分析与算法基础

覆盖大 O、Ω、Θ、最好/平均/最坏复杂度、递归树、主定理、摊销分析、正确性证明、循环不变量、空间复杂度和输入编码。与现有 NP 卡片关联，但不重复 P/NP 定义。

### 树结构进阶

统一比较 AVL、红黑树、Trie、B 树和 B+ 树，解释旋转、平衡条件、磁盘页、前缀查询、范围查询及典型复杂度。将并查集继续保留在图卡片中，因为它的主要用途是动态连通性和最小生成树。

### 字符串算法

覆盖朴素匹配、前缀函数/next、KMP、Trie、字符串哈希、最长公共子串与子序列的区别，并给出模式匹配和前缀查询题型。

### 图算法进阶

覆盖拓扑排序、Bellman-Ford、Floyd、Kruskal、Prim、二分图匹配、欧拉回路与哈密顿回路的复杂度区别，并明确不同图结构和边权条件。

### 贪心分治与回溯

分别说明贪心选择性质、交换论证、分治合并、递归搜索树、剪枝、状态去重和分支限界。覆盖区间调度、霍夫曼、归并、快速选择、全排列、组合、N 皇后、子集和等题型。

### 数据结构算法笔试题

集中整理银行和运营商常见的复杂度判断、树图计算、排序稳定性、递推、代码输出、算法选择和综合辨析题。题目标记为“自编训练题”，不冒充具体单位真题。
