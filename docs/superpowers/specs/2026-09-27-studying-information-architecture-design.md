# Studying 知识库信息架构设计

日期：2026-09-27

## 目标

以知识领域作为一级目录边界，使每个通用知识点只有一个权威正文。其他目录通过链接复用该正文，学习路线、面试问题、项目案例和笔试题不再重复维护概念定义。

## 核心规则

1. **唯一所有权**：同一知识的定义、公式、推导、边界和通用例题只保留一份。
2. **引用代替复制**：下游场景只保留必要背景、场景差异和链接。
3. **知识与视图区分**：README、学习路线、面试题和笔试题是知识的不同视图，不是新的知识所有者。
4. **先迁移后删除**：旧卡中的独有内容完成归并并建立映射后，才删除冗余文件。
5. **稳定编号**：保留现有13个编号一级目录，不做全仓库重新编号。

## 新内容归档判定

按顺序判断：

1. 是否是数学、统计、传统模型或通用神经网络原理？进入01。
2. 是否描述模型结构、模型家族或生成机制？进入02。
3. 是否描述参数如何训练、更新、并行或对齐？进入03。
4. 是否描述数据可信度、指标和实验结论？进入04。
5. 是否描述模型如何高效稳定地在线运行？进入05。
6. 是否主要是语言、API或代码实现？进入06或10。
7. 是否是垂直领域、项目经历、面试视图或笔试训练？进入对应下游目录，并链接权威卡。

如果一篇文章同时满足多个所有权条件，应拆成专题正文和导航页，不建立跨领域“大而全”正文。

## 验证要求

1. 建立旧路径到新路径映射，确认每张旧卡都有去向。
2. 迁移前后对独有章节逐项核对，不以文件数代替内容完整性。
3. 更新全仓库相对链接，验证普通链接和尖括号链接。
4. 检查所有非README知识卡至少被一个索引引用。
5. 检查一级目录职责描述与实际文件一致。
6. 扫描跨一级目录的同名卡和高相似正文。
7. 运行`git diff --check`，不提交未获确认的其他改动。
