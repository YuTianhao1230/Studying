# 算法刷题

本目录整理 coding 面试中常见算法题型和刷题方法。它不追求覆盖所有题，而是沉淀高频模式和可迁移模板。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [刷题技巧.md](<刷题技巧.md>) | 算法题审题、复杂度、边界条件和复盘方法。 |
| [高频算法模板.md](<高频算法模板.md>) | 双指针、滑动窗口、前缀和、单调栈、堆、树图搜索、贪心和动态规划模板。 |
| [回溯算法.md](<回溯算法.md>) | 组合、排列、子集、搜索树和剪枝。 |
| [并查集.md](<并查集.md>) | 动态连通性、路径压缩、按秩合并和典型题。 |
| [下一个排列.md](<下一个排列.md>) | next permutation 的字典序变换和原地算法。 |
| [数据结构class最小示例.md](<数据结构class最小示例.md>) | 链表、栈、队列、二叉树节点的最小 Python class 写法。 |

## 学习路线

1. 先看 [刷题技巧.md](<刷题技巧.md>)，建立通用解题框架。
2. 看 [数据结构class最小示例.md](<数据结构class最小示例.md>)，熟悉面试中常见 class 模板。
3. 用 [高频算法模板.md](<高频算法模板.md>) 掌握最常用的识别信号、代码骨架和边界检查。
4. 再看 [回溯算法.md](<回溯算法.md>) 和 [并查集.md](<并查集.md>)，掌握专项模式。
5. 最后看 [下一个排列.md](<下一个排列.md>)，训练细节实现和边界处理。
