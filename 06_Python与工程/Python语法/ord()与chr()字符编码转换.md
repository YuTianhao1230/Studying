# `ord()` 与 `chr()` 字符编码转换

## 知识点解析

### 概述

`ord()` 和 `chr()` 是一对互逆的 Python 内置函数，用于在单个 Unicode 字符与其整数码点之间转换。它们适合处理字符偏移、字符范围判断和简单的字符映射，不等同于字符串与字节之间的编码、解码。

### 基本用法

`ord()` 接收长度为 1 的字符串，返回该字符对应的 Unicode 码点：

```python
ord("A")   # 65
ord("中")  # 20013
```

`chr()` 接收合法的 Unicode 码点，返回对应字符：

```python
chr(65)     # "A"
chr(20013)  # "中"
```

二者满足以下互逆关系：

```python
chr(ord("A")) == "A"  # True
ord(chr(65)) == 65     # True
```

### 字符数字转整数

字符 `'0'` 到 `'9'` 的码点连续，因此可以通过码点差计算一位数字的值：

```python
digit = "5"
value = ord(digit) - ord("0")  # 5
```

该写法的前提是已经确认字符位于 `'0'` 到 `'9'`：

```python
if "0" <= digit <= "9":
    value = ord(digit) - ord("0")
```

一般业务代码直接使用 `int(digit)` 更清晰；手写解析器、字符扫描和算法题中需要进行字符级计算时，码点差写法更常见。

### 字符偏移

因为连续英文字母的码点也是连续的，可以计算字符位置或进行有限范围内的偏移：

```python
index = ord("c") - ord("a")  # 2
letter = chr(ord("a") + 2)   # "c"
```

偏移前必须明确字符范围。简单地对任意字符加减整数，可能得到标点、控制字符或超出合法范围的码点。

### 与 `encode()`、`decode()` 的区别

| 操作 | 输入 | 输出 | 用途 |
| --- | --- | --- | --- |
| `ord("A")` | 单个字符 | 整数码点 `65` | 字符与码点转换 |
| `chr(65)` | 整数码点 | 单个字符 `"A"` | 码点与字符转换 |
| `"中".encode("utf-8")` | 字符串 | 字节序列 | 按指定编码序列化文本 |
| `data.decode("utf-8")` | 字节序列 | 字符串 | 按指定编码还原文本 |

Unicode 码点是字符的抽象编号，而 UTF-8 等编码规定码点如何表示为一个或多个字节。不能把 `ord()` 返回值直接理解为 UTF-8 字节值。

### 边界与异常

- `ord()` 的参数必须是长度为 1 的字符串，否则抛出 `TypeError`。
- `chr()` 只接受合法 Unicode 码点范围内的整数，否则抛出 `ValueError`。
- `ord("12")` 不能用于多位数字；多位数字字符串应使用 `int("12")`。
- 大小写字母的码点范围不同，字符偏移时不能混用基准字符。
