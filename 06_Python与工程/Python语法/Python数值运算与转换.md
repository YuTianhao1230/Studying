# Python 数值运算与转换

## 知识点解析

### 常用语法速查

```python
import math

a, b = 7, 3

# 基本算术
a + b          # 10，加法
a - b          # 4，减法
a * b          # 21，乘法
a / b          # 2.333...，真除法，结果通常是 float
a // b         # 2，向下取整除法
a % b          # 1，取模
divmod(a, b)   # (2, 1)，同时得到商和余数

# 幂、平方与平方根
a ** 2         # 49，平方
pow(a, 2)      # 49，等价于 a ** 2
a ** 0.5       # 2.645...，平方根，通常返回 float
math.sqrt(a)   # 2.645...，平方根，结果是 float
math.isqrt(a)  # 2，整数平方根，即 floor(sqrt(a))

# 取整与绝对值
math.ceil(2.3)   # 3，向上取整
math.floor(2.7)  # 2，向下取整
int(2.7)         # 2，向 0 截断
round(2.6)       # 3，舍入到最近整数
abs(-5)          # 5，绝对值

# 类型转换
int("123")       # 123
float("3.14")    # 3.14
str(123)         # "123"
int("101", 2)    # 5，二进制字符串转十进制整数
bin(10)          # "0b1010"
oct(10)          # "0o12"
hex(10)          # "0xa"
```

### 基本算术运算

| 运算 | 语法 | 示例结果 | 说明 |
| --- | --- | --- | --- |
| 加法 | `a + b` | `7 + 3 == 10` | 数值相加 |
| 减法 | `a - b` | `7 - 3 == 4` | 数值相减 |
| 乘法 | `a * b` | `7 * 3 == 21` | 数值相乘 |
| 真除法 | `a / b` | `7 / 3 == 2.333...` | 即使整除，通常也返回 `float` |
| 向下取整除法 | `a // b` | `7 // 3 == 2` | 商向负无穷取整 |
| 取模 | `a % b` | `7 % 3 == 1` | 与 `//` 满足 `a == (a // b) * b + a % b` |
| 幂运算 | `a ** b` | `2 ** 3 == 8` | `**` 的优先级高于一元负号 |

除数为 `0` 时，`/`、`//` 和 `%` 都会抛出 `ZeroDivisionError`。

### 平方、幂与平方根

```python
import math

x = 9

x * x           # 81，平方
x ** 2          # 81，平方
pow(x, 2)       # 81，平方
x ** 0.5        # 3.0，结果是 float，不是 int
math.sqrt(x)    # 3.0，浮点平方根
math.isqrt(10)  # 3，满足 3**2 <= 10 < 4**2
```

常见选择：

- 普通幂运算使用 `x ** n`，表达最直接。
- `x ** 0.5` 表示开平方。对于非负 `int` 或 `float`，结果通常是 `float`；即使 `9` 的平方根在数学上是整数，`9 ** 0.5` 得到的也是 `3.0`。
- 非负整数需要精确的整数平方根时使用 `math.isqrt(x)`，避免浮点精度问题。
- `math.sqrt(x)` 不接受负实数；需要复数平方根时使用 `cmath.sqrt(x)`。
- `pow(a, b, mod)` 可直接计算 `(a ** b) % mod`，适合快速幂和大整数取模，且不会先构造完整的巨大幂。

```python
pow(2, 10, 1000)  # 24
```

如果需要判断非负整数是否为完全平方数，可以使用 `math.isqrt()`：

```python
import math

a = 16
root = math.isqrt(a)
is_perfect_square = root * root == a  # True
```

### 取整方法对比

取整方法的核心区别是“朝哪个方向取整”：

| 写法 | 规则 | `2.7` | `-2.7` |
| --- | --- | ---: | ---: |
| `math.ceil(x)` | 向正无穷取整 | `3` | `-2` |
| `math.floor(x)` | 向负无穷取整 | `2` | `-3` |
| `int(x)` | 向 `0` 截断 | `2` | `-2` |
| `round(x)` | 舍入到最近整数，正好居中时取偶数 | `3` | `-3` |
| `x // 1` | 向负无穷取整，结果通常保持数值类型 | `2.0` | `-3.0` |

因此，`int(x)` 不能等同于向下取整：

```python
import math

int(-2.7)         # -2
math.floor(-2.7)  # -3
```

`round()` 使用“银行家舍入”，即正好位于两个候选值中间时选择偶数：

```python
round(2.5)   # 2
round(3.5)   # 4
round(2.675, 2)  # 2.67，受二进制浮点表示影响
```

财务等需要明确十进制舍入规则的场景，应使用 `decimal.Decimal`，不要依赖二进制浮点数的 `round()`。

### 除法、整除与取模

Python 的 `//` 是向下取整，不是向 `0` 截断，所以负数结果容易出错：

```python
-7 // 3   # -3
-7 % 3    # 2
```

商和余数始终满足：

```text
a = (a // b) * b + (a % b)
```

当除数 `b` 非零时，余数 `a % b` 与 `b` 同号。需要同时获得商和余数时，使用 `divmod(a, b)`：

```python
quotient, remainder = divmod(17, 5)
# quotient == 3, remainder == 2
```

### 常见数值类型转换

```python
# 字符串与数字
int("42")          # 42
float("3.5")       # 3.5
str(42)            # "42"

# 指定进制
int("1010", 2)     # 10
int("ff", 16)      # 255
bin(10)            # "0b1010"
oct(10)            # "0o12"
hex(255)           # "0xff"

# 浮点数转整数：直接舍弃小数部分，朝 0 截断
int(3.9)           # 3
int(-3.9)          # -3
```

`int("3.14")` 会抛出 `ValueError`，因为字符串不是合法的整数字面量。若业务允许小数字符串，应先转为 `float` 再明确选择取整规则：

```python
import math

text = "3.14"
math.floor(float(text))  # 3
```

### 易错点

1. `^` 是按位异或，不是幂运算；平方应写成 `x ** 2`。
2. `-2 ** 2` 等价于 `-(2 ** 2)`，结果是 `-4`；若要计算负数的平方，应写 `(-2) ** 2`。
3. `//` 对负数向下取整，而 `int()` 向 `0` 截断。
4. `round()` 不是固定的“四舍五入”，并且会受到浮点表示误差影响。
5. 对非负数使用 `x ** 0.5` 通常返回 `float`，且会受到浮点精度限制；大整数需要精确整数平方根时使用 `math.isqrt(x)`。
6. 浮点数不适合直接用 `==` 判断计算结果是否相等，可使用 `math.isclose()`。

```python
import math

0.1 + 0.2 == 0.3                  # False
math.isclose(0.1 + 0.2, 0.3)      # True
```

## 面试应对

### Python 中 `//`、`int()`、`floor()` 有什么区别？

回答思路：先说明三者的目标，再用负数举例区分向下取整和向零截断。

回答模板：

`//` 是向下取整除法，`math.floor()` 是对一个数向负无穷取整，`int()` 则是直接舍弃小数部分、向零截断。正数时它们的结果经常相同，但负数时不同，例如 `-7 // 3` 等于 `-3`，`math.floor(-2.7)` 等于 `-3`，而 `int(-2.7)` 等于 `-2`。

### Python 的 `round()` 为什么可能不符合直觉？

回答思路：回答居中取偶规则和二进制浮点误差两个原因，并给出需要严格十进制舍入时的替代方案。

回答模板：

Python 的 `round()` 在正好居中时采用取偶数规则，所以 `round(2.5)` 是 `2`，`round(3.5)` 是 `4`。此外，很多十进制小数不能被二进制浮点数精确表示，例如 `round(2.675, 2)` 可能得到 `2.67`。如果是财务等需要严格十进制舍入的场景，我会使用 `decimal.Decimal` 并显式指定舍入模式。

### 如何选择平方根的计算方式？

回答思路：按照浮点实数、精确整数和复数三种输入选择 API。

回答模板：

普通非负实数开平方可以使用 `math.sqrt()`。如果输入是非负整数，并且需要避免浮点误差、得到精确的向下取整平方根，应使用 `math.isqrt()`。如果需要处理负数的复数平方根，则使用 `cmath.sqrt()`。不建议在大整数精确计算中直接使用 `x ** 0.5`。
