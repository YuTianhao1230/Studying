# 知识点

## 知识点解析

### 概述

每个 Python 模块都有内置变量 `__name__`。当文件作为程序入口直接执行时，`__name__` 的值是 `"__main__"`；当文件被其他模块导入时，`__name__` 通常是该模块的限定名称。因此，`if __name__ == "__main__":` 中的代码只会在文件被直接执行时运行，不会在模块被导入时自动运行。

### 列表推导式

```python
numbers = [1, 2, 3, 4]
squares = [number * number for number in numbers]
```

条件过滤、条件表达式、嵌套循环、可读性边界和面试回答见[列表推导式](<列表推导式.md>)。

### 将字符数字转换为整数数字：ord(c) - ord('0')

`ord(c)` 返回字符 `c` 的 Unicode 码点。例如，`ord('5')` 是 53，`ord('0')` 是 48，所以 `ord('5') - ord('0')` 等于 5。该写法只应在已经确认字符位于 `'0'` 到 `'9'` 时使用；一般字符串转整数应使用 `int()`。

### 字符串反转方法

```python
x1 = "abcde"

# 使用 join 和 reversed
x2 = "".join(reversed(x1))

# 使用切片
x3 = x1[::-1]

# 转成列表后原地反转，再拼接回字符串
char_list = list(x1)
char_list.reverse()
x4 = "".join(char_list)
```

## 面试应对

### `__name__ == "__main__"` 是什么意思？

回答思路：先说明模块被直接执行和被 import 时 `__name__` 的不同取值。

回答模板：

在 Python 里，每个模块都有一个内置变量 `__name__`。当这个文件被直接运行时，`__name__` 会等于 `"__main__"`；当它被其他文件 import 时，`__name__` 会等于模块名。因此 `if __name__ == "__main__":` 常用来放脚本入口、测试代码或命令行执行逻辑，避免模块被 import 时自动执行这些代码。

### 字符串反转有哪些常见写法？

回答思路：说明切片、reversed 和列表原地反转的区别。

回答模板：

字符串反转最常见写法是 `s[::-1]`，简洁直接。也可以用 `"".join(reversed(s))`，它返回一个反向迭代器再拼接成字符串。如果先转成 list 再 `reverse()`，适合需要对字符列表做更多原地操作的场景。面试里要注意字符串不可变，`reverse()` 不能直接作用在字符串上。
