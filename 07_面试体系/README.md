## 建议顺序

1. 先看[专业知识面试题（算法）.md](<专业知识面试题（算法）.md>)，定位需要回到正文补强的技术主题。
2. 再看[专业知识面试题（计算机基础）.md](<专业知识面试题（计算机基础）.md>)，覆盖央国企和大厂基础面试。
3. 根据目标岗位复习[大厂算法工程师 JD 能力矩阵](<大厂算法工程师JD能力矩阵.md>)。
4. 最后用综合素质和真实面试复盘材料练习项目表达与追问。
