# 面试体系

本目录整理算法工程师面试中的专业知识、计算机基础、项目复盘和综合素质表达，作为知识卡片到面试回答的转换层。

## 内容索引

| 文件 | 内容说明 |
| --- | --- |
| [专业知识面试题（算法）.md](<专业知识面试题（算法）.md>) | 数学、模型训练、评测、工程和多模态方向的算法面试题。 |
| [专业知识面试题（计算机基础）.md](<专业知识面试题（计算机基础）.md>) | 数据结构、操作系统、数据库、网络和组成原理面试题。 |
| [大厂算法工程师JD能力矩阵.md](<大厂算法工程师JD能力矩阵.md>) | 按岗位要求拆解模型、数据、评测、系统和业务能力。 |
| [综合素质面试题.md](<综合素质面试题.md>) | 自我介绍、项目表达、协作、失败经历和职业规划。 |
| [真实面试题与回答复盘.md](<真实面试题与回答复盘.md>) | 实际面试问题、回答复盘和易错点。 |

## 建议顺序

1. 先看[专业知识面试题（算法）.md](<专业知识面试题（算法）.md>)，定位需要回到正文补强的技术主题。
2. 再看[专业知识面试题（计算机基础）.md](<专业知识面试题（计算机基础）.md>)，覆盖央国企和大厂基础面试。
3. 根据目标岗位复习[大厂算法工程师 JD 能力矩阵](<大厂算法工程师JD能力矩阵.md>)。
4. 最后用综合素质和真实面试复盘材料练习项目表达与追问。
