# 模型集成与特征攻击

## 知识点解析

### 概述

模型集成与特征攻击是提升对抗样本迁移性的两类重要方法：前者通过多个源模型寻找共享攻击方向，后者通过攻击中间表示减少对单一任务头的过拟合。

### 解决的问题

单模型攻击容易过拟合源模型，分类头攻击容易过拟合特定任务。模型集成和特征攻击分别从模型维度和表示维度缓解这个问题。

### 模型集成攻击

集成攻击同时优化多个源模型的损失：

```text
L_total = sum_i w_i * L_i(f_i(x_adv), y)
```

常见做法：

- logits ensemble：平均多个模型 logits 后计算 loss。
- loss ensemble：分别算 loss 再加权求和。
- gradient ensemble：分别算梯度再融合。

核心直觉：如果扰动能同时攻击多个架构不同的源模型，它更可能命中目标模型共享的脆弱方向。

### 特征攻击

特征攻击不只攻击最终输出，而是攻击中间层表示：

```text
maximize distance(h_l(x_adv), h_l(x))
```

或让对抗样本特征靠近目标类别/目标样本：

```text
minimize distance(h_l(x_adv), h_l(x_target))
```

常见特征层：

- CNN 中间 stage。
- [ViT](<../../02_大模型/模型细节/里程碑模型/ViT.md>) patch token。
- [CLIP](<../../02_大模型/模型细节/里程碑模型/CLIP.md>) image embedding。
- [VLM](<../../02_大模型/视觉多模态与生成模型/多模态模型/VLM与Vision_Instruction_Tuning.md>) 图文融合层。

### 为什么有助于迁移

最终分类头往往和具体数据集、类别空间绑定；中间特征更接近通用视觉表示。攻击中间特征可以减少对某个任务头的依赖，更容易迁移到检测、分割、检索和多模态模型。

模型集成则从多个模型共同优化，减少单一模型梯度偏差。

### 在 Syner-Attack 中的对应

Syner-Attack 的图像侧 feature loss 可以从特征攻击角度理解：

- 不只攻击最终检索分数。
- 直接扰乱视觉特征或跨模态对齐表示。
- 目标是提升跨 VLM/MLLM 的黑盒迁移性。

如果结合多个 VLP 源模型，还可以进一步解释为集成迁移攻击。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 方法题 | 怎么提升迁移性 | 模型集成和中间特征攻击 |
| 原因题 | 为什么攻击特征比攻击分类头更通用 | 特征更共享，任务头更专用 |
| 公式题 | 集成 loss 怎么写 | 多模型 loss 加权求和 |
| 项目题 | feature loss 有什么作用 | 扰乱共享表示，提升跨模型迁移 |

### 易错点

- 集成模型和目标模型重合，导致黑盒设定不干净。
- 只攻击最后 logits，迁移到不同任务时效果弱。
- 特征层选择没有消融，无法说明为什么有效。
- 多个 loss 权重未说明，实验不可复现。

## 面试应对

### 1. 模型集成攻击有哪些实现方式，为什么可能提升迁移性？

回答思路：写出加权多模型目标，区分 logits、loss 和 gradient 融合，并从共享方向解释收益。

回答模板：

> 模型集成可写成 `L_total=sum_i w_i L_i(f_i(x_adv),y)`，也可以先融合 logits 或直接融合各模型梯度。它限制扰动不能只贴合一个源模型的局部边界，而要兼顾多个模型，因此更可能保留跨模型一致的攻击方向。三种融合方式并不完全等价，尤其当模型输出尺度、类别空间或梯度范数不同，需要先做对齐或归一化，并通过权重消融验证结果。

### 2. 特征攻击与输出层攻击有什么区别，特征层如何选择？

回答思路：对比任务头特异性与中间表示通用性，说明浅层、深层和跨模态层的取舍，避免声称中间层天然最优。

回答模板：

> 输出层攻击直接改变最终类别或分数，目标清晰，但容易绑定特定标签空间和任务头；特征攻击则最大化干净与对抗中间表示的距离，或把对抗表示拉向目标表示，更适合寻找共享语义脆弱性。浅层偏纹理和边缘，迁移面广但语义弱；深层语义更强，却可能更依赖模型和任务；CLIP embedding 或融合层还会引入跨模态对齐信息。因此层选择应结合目标任务，并用多层消融而不是凭经验固定。

### 3. 集成或特征攻击没有提高迁移性时，如何定位原因？

回答思路：检查源目标泄漏、模型同质性、梯度冲突、尺度失衡和特征层选择，再用 hold-out 目标与消融验证。

回答模板：

> 我会先确认目标模型没有进入源模型集成或超参数选择，否则黑盒结论不成立。随后检查源模型是否过于同质、各损失和梯度尺度是否失衡，以及不同模型梯度是否严重冲突；对特征攻击则比较浅层、深层和多层组合，并确认特征距离没有被某一层维度主导。实验应保持预算和迭代次数一致，分别报告单模型、集成、输出损失、特征损失及组合版本在 hold-out 目标上的结果。只有目标模型上的稳定增益才能说明迁移性提高。
