# 检测与一致性防御

## 知识点解析

### 概述

检测与一致性防御不一定修复对抗输入，而是判断输入、特征或跨模态关系是否异常，从而拒绝、降级、人工复核或触发额外验证。

### 解决的问题

有些场景难以让模型完全鲁棒，但可以检测高风险输入，避免直接给出错误结果。多模态场景下，攻击可能让图像和文本单独看都正常，但联合表示异常。

### 常见检测方法

| 方法 | 检测对象 | 思路 |
| --- | --- | --- |
| 输入统计检测 | 像素、频谱、压缩残差 | 对抗扰动可能改变高频分布 |
| 特征分布检测 | 中间层 embedding | 对抗样本特征偏离 clean manifold |
| 不确定性检测 | entropy、margin、置信度 | 攻击可能降低模型决策置信 |
| 多模型一致性 | 多模型输出 | 攻击样本在不同模型间输出不稳定 |
| 跨模态一致性 | 图文 embedding / answer consistency | 图像、文本或输出语义不匹配 |

### 多模态一致性检测

多模态攻击中可以检查：

- 图像 embedding 和文本 embedding 相似度是否异常。
- caption 与图像是否一致。
- VQA 答案是否被图像证据支持。
- 多 prompt 下答案是否稳定。
- CLIP/BLIP/Qwen-VL 等多个模型判断是否一致。

### 局限

- 检测器本身也可能被攻击。
- 阈值难设，可能误杀 clean 样本。
- 强攻击可以同时优化主任务和绕过检测。
- 多模型一致性成本高。
- 跨模态一致性检测容易受模型幻觉影响。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 方法题 | 有哪些检测防御 | 输入统计、特征、置信度、多模型、跨模态一致性 |
| 多模态题 | 如何检测图文攻击 | 检查图文相似度、caption 证据、多 prompt 一致性 |
| 局限题 | 检测为什么不等于鲁棒 | 检测器可被绕过，阈值有误报漏报 |
| 工程题 | 高风险样本怎么办 | 拒答、降级、人工复核、触发强模型验证 |

### 易错点

- 把检测成功率当作模型鲁棒准确率。
- 不报告误报率和漏报率。
- 没有评估 adaptive attack 绕过检测。
- 多模态检测只看图像，不看文本和输出一致性。

## 面试应对

### 1. 对抗样本检测与提升模型鲁棒性有什么区别？

回答思路：区分预测正确与风险识别，说明检测后的工程动作及两套指标，避免把检测率当 robust accuracy。

回答模板：

> 鲁棒模型的目标是在攻击输入上仍给出正确结果，检测防御则判断输入是否可疑，并触发拒答、降级、人工复核或二次验证；它不一定修复原预测。因此主任务应报告 clean/robust accuracy 或任务指标，检测器应报告真正率、误报率、漏报率、AUROC 或固定误报率下的检出率。把被拒绝样本全部计为预测正确会高估系统鲁棒性，必须单独说明覆盖率和拒绝策略。

### 2. 多模态攻击可以从哪些一致性信号检测？

回答思路：按输入、单模态特征、跨模态对齐和输出证据四层回答，并说明多模型或多 prompt 的成本。

回答模板：

> 我会从四层构造信号：输入层看像素频谱、压缩残差和异常 token；特征层看视觉或文本 embedding 是否偏离 clean 分布；对齐层看图文相似度、对象和属性是否一致；输出层看 caption、VQA 回答是否有图像证据，以及多 prompt 或多模型结果是否稳定。多模态攻击可能让单个模态看似正常但破坏两者关系，所以跨模态一致性通常比只看图像噪声更有针对性，不过多模型验证会增加延迟和成本。

### 3. 如何选择检测阈值并评估自适应攻击下的可靠性？

回答思路：在独立验证集上按业务代价定阈值，报告完整曲线和分布外表现；让攻击同时优化主任务和检测损失。

回答模板：

> 阈值应在与测试集分离的验证集上选择，并根据误杀 clean 请求和漏过攻击的业务代价确定，不能在测试攻击上调到最好结果。评估时报告 ROC/PR 曲线、固定误报率下的检出率、不同攻击和未见数据上的表现。自适应攻击要知道检测器，并联合优化主任务攻击目标与绕过检测的目标；若检测率在这种设置下明显下降，就说明它主要识别了已有攻击的表面特征，不能作为通用防御。
