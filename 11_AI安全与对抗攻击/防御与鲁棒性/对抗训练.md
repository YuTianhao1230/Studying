# 对抗训练

## 知识点解析

### 概述

对抗训练是在训练过程中加入对抗样本，使模型在扰动邻域内也保持正确预测，是经典且证据较强的鲁棒训练方法。

### 解决的问题

标准训练只优化 clean 样本上的平均损失，不保证样本附近小扰动下预测稳定。对抗训练把最坏扰动纳入训练目标，提升局部鲁棒性。

### Min-Max 目标

```text
min_theta E_{(x,y)} [ max_{||delta|| <= epsilon} L(f_theta(x + delta), y) ]
```

- 内层 `max`：用 FGSM/PGD 等方法找最坏扰动。
- 外层 `min`：更新模型参数，让模型在最坏扰动下仍正确。

### 训练流程

1. 对 batch 中每个样本生成对抗样本。
2. 用对抗样本计算训练 loss。
3. 反向传播更新模型参数。
4. 每轮评估 clean accuracy 和 robust accuracy。

[PGD](<../视觉攻击方法/PGD.md>) adversarial training 常用 PGD 近似内层最大化。

### 优点和代价

| 维度 | 说明 |
| --- | --- |
| 优点 | 证据强，能显著提升对应预算下鲁棒性 |
| 成本 | 每个 batch 多次 forward/backward，训练成本高 |
| clean 性能 | 可能降低 clean accuracy |
| 泛化 | 对未训练过的范数、预算、攻击类型泛化有限 |
| 大模型/多模态 | 全量对抗训练成本更高，数据和评估更复杂 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | 写对抗训练目标 | min-max 目标 |
| 流程题 | PGD adversarial training 怎么做 | 内层 PGD，外层更新模型 |
| 代价题 | 为什么难用于大模型 | 训练成本、显存、任务复杂度 |
| 局限题 | 为什么不是万能防御 | 预算和攻击类型外泛化有限 |

### 易错点

- 把对抗训练说成数据增强；它是显式最坏扰动优化。
- 只报 robust accuracy，不报 clean accuracy。
- 用弱攻击训练，却用弱攻击评估，得到虚假鲁棒性。
- 忽略训练预算和评估预算是否一致。

## 面试应对

### 1. 对抗训练的 min-max 目标如何理解？

回答思路：分别解释内层攻击和外层参数更新，说明内层只能由具体攻击近似求解。

回答模板：

> 对抗训练优化 `min_theta E[max_{||delta||<=epsilon} L(f_theta(x+delta),y)]`。内层固定模型参数，在威胁模型允许的邻域内寻找高损失扰动；实践中常用多步 PGD 近似，而不是真正得到全局最大值。外层把生成的对抗样本当作当前最坏案例，更新 `theta` 以降低其损失。它不同于普通随机数据增强，因为扰动是针对当前模型和目标主动优化出来的。

### 2. 对抗训练为什么不是万能防御，适用边界在哪里？

回答思路：从计算成本、clean-robust 权衡和威胁模型外泛化回答，避免把某一预算下鲁棒推广到所有攻击。

回答模板：

> 对抗训练通常提高训练时所覆盖范数、预算和攻击类型下的局部鲁棒性，但这种收益不会自动泛化到更大预算、其他范数、空间变换、文本攻击或跨模态攻击。多步内层攻击会显著增加训练计算和显存成本，也可能牺牲 clean accuracy。对大模型或多模态模型，还要处理离散文本、开放式输出和多任务目标。因此它是证据较强的基线，但鲁棒结论必须限定在明确威胁模型内。

### 3. 如何判断对抗训练真的提升了鲁棒性，而不是训练和评估都用了弱攻击？

回答思路：分离训练攻击与评估攻击，报告 clean/robust 曲线，引入更强和自适应攻击，并检查训练过程。

回答模板：

> 我会完整报告 clean accuracy 和多个预算下的 robust accuracy，评估攻击不能只复用训练时的弱配置，而应增加步数、步长扫描、随机重启和不同损失，并补充迁移或自适应攻击。训练中还要监控内层攻击是否持续提高损失，以及训练后期验证鲁棒指标是否回落。若只有训练攻击下指标高，而更强攻击迅速打穿，说明内层最大化不足或出现梯度问题，不能据此宣称模型获得真实鲁棒性。
