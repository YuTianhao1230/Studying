# I-FGSM 与 BIM

## 知识点解析

### 概述

I-FGSM/BIM 是 [FGSM](<FGSM.md>) 的多步迭代版本，把一次大步攻击拆成多次小步更新，并在每一步后把样本裁剪回扰动预算范围。

### 解决的问题

FGSM 只做一次线性近似，攻击方向可能不够精细。I-FGSM/BIM 通过多步迭代沿损失曲面持续优化，通常能得到更强的白盒攻击效果。

### 攻击公式

初始化：

```text
x_adv_0 = x
```

每一步更新：

```text
x_adv_{t+1} = clip_{x, epsilon}(x_adv_t + alpha * sign(grad_x L(f(x_adv_t), y)))
```

其中：

- `epsilon`：总扰动预算。
- `alpha`：每一步攻击步长。
- `clip_{x, epsilon}`：投影回以原图 `x` 为中心的 `L_inf` 球。

### 攻击流程

1. 输入干净图像 `x` 和标签 `y`。
2. 设置 `epsilon`、`alpha` 和迭代步数。
3. 对当前 `x_adv` 求输入梯度。
4. 沿梯度符号方向更新一步。
5. 投影回扰动预算内，并裁剪到合法像素范围。
6. 重复直到达到步数。

### 和 FGSM 的区别

| 对比项 | FGSM | I-FGSM/BIM |
| --- | --- | --- |
| 更新次数 | 1 次 | 多次 |
| 步长 | `epsilon` | `alpha` |
| 攻击强度 | 较弱 | 白盒更强 |
| 计算成本 | 低 | 更高 |
| 迁移性 | 有时更好 | 可能过拟合源模型 |

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 公式题 | 写 I-FGSM 更新式 | 写小步更新 + 投影 + 像素裁剪 |
| 参数题 | `alpha` 和 `epsilon` 怎么设 | `alpha` 是单步，`epsilon` 是总预算 |
| 对比题 | 为什么 I-FGSM 白盒更强 | 多步优化更接近局部最大损失 |
| 迁移题 | 为什么多步攻击迁移性可能下降 | 可能更过拟合源模型局部边界 |

### 易错点

- 只做像素 `clip(0,1)`，忘记投影到 `epsilon` 范围。
- `alpha * steps` 远大于 `epsilon`，但没有投影，导致预算越界。
- 把 I-FGSM 和 [PGD](<PGD.md>) 完全等同；PGD 通常还包含随机初始化。

## 面试应对

### I-FGSM/BIM 相比 FGSM 有什么改进？

回答思路：讲多步优化、投影约束、强度和代价。

回答模板：

I-FGSM 或 BIM 可以看作 FGSM 的多步版本。FGSM 一次沿梯度符号方向走 `epsilon`，而 I-FGSM 每次走较小步长 `alpha`，每一步重新计算梯度并投影回 `epsilon` 扰动球内。这样能更充分地搜索样本邻域中的高损失区域，所以白盒攻击通常更强。但它计算成本更高，也更可能过拟合源模型，因此黑盒迁移性不一定比单步攻击更好。
