# 对抗样本基础

## 知识点解析

### 概述

本文整理对抗样本的基本定义、威胁模型、扰动约束、攻击目标、白盒与黑盒设定，以及常见评估指标。

### 对抗样本是什么

对抗样本是在原始输入上加入人眼或业务规则难以察觉的扰动，使模型输出发生错误或偏离预期的样本。形式上，给定干净样本 `x`、标签 `y`、模型 `f` 和损失函数 `L`，攻击通常求解：

```text
maximize   L(f(x + delta), y)
subject to ||delta||_p <= epsilon
           x + delta in valid_input_range
```

其中 `delta` 是扰动，`epsilon` 是扰动预算，`p` 常见为 `inf`、`2` 或 `0` 范数。

- `L_inf`：限制单个像素最大变化，图像攻击中最常见。
- `L_2`：限制整体欧氏距离，更接近整体能量约束。
- `L_0`：限制被修改的像素或 token 数量。
- 感知约束：除范数外，还可用 SSIM、LPIPS、CLIPScore、人审语义一致性等约束可感知变化。

### 攻击目标

| 类型 | 目标 | 例子 |
| --- | --- | --- |
| 非定向攻击 | 让模型预测错即可 | 分类模型不再输出原类别 |
| 定向攻击 | 让模型输出指定目标 | 把猫识别成狗 |
| 可用性攻击 | 让模型性能显著下降 | 检索 Recall 下降、VQA accuracy 下降 |
| 安全绕过攻击 | 绕过安全策略 | 多模态越狱、违规内容漏检 |
| 语义误导攻击 | 输出与图像或文本事实不一致 | MLLM 描述错误对象、属性或关系 |

非定向攻击通常更容易成功，定向攻击更能说明攻击可控性。面试中如果只说“攻击成功”，需要继续说明成功标准到底是分类错误、检索排序下降、答案不一致，还是触发有害输出。

### 威胁模型

威胁模型定义攻击者能看到什么、能改什么、要达到什么效果，是对抗攻击论文和实验最容易被追问的部分。

| 维度 | 常见设定 | 需要说明的问题 |
| --- | --- | --- |
| 访问权限 | 白盒、灰盒、黑盒 | 是否知道模型结构、参数、梯度、输出概率 |
| 可修改输入 | 图像、文本、音频、多模态联合 | 攻击者能否同时改图和文本 |
| 扰动约束 | 范数、文本替换率、语义相似度 | 改动是否可感知、是否破坏原始语义 |
| 查询预算 | 无限制、有限查询、零查询迁移 | 黑盒攻击能调用目标模型多少次 |
| 攻击目标 | 非定向、定向、任务退化 | 用什么指标定义攻击成功 |
| 攻击场景 | 分类、检索、VQA、caption、安全问答 | 任务输出形式不同，ASR 定义也不同 |

### 白盒攻击和黑盒攻击

白盒攻击知道模型结构和参数，可以直接使用梯度优化扰动。典型方法包括 [FGSM](<视觉攻击方法/FGSM.md>)、[PGD](<视觉攻击方法/PGD.md>)、CW。

黑盒攻击不知道目标模型梯度，常见路线有三类：

1. 迁移攻击：在源模型上生成对抗样本，直接迁移到目标模型。
2. 查询攻击：反复查询目标模型，用输出估计梯度或搜索扰动方向。
3. 决策边界攻击：只依赖最终类别或成功失败信号逼近边界。

对于大模型和商业 MLLM，真实评估中常用迁移攻击，因为目标模型通常不开放梯度，查询成本也较高。

### 为什么会有对抗样本

常见解释包括：

- 高维线性效应：单个维度扰动很小，但高维空间中大量微小变化会累积成显著 logit 改变。
- 决策边界复杂：深度模型在训练样本附近可能存在距离很近但不可感知的错误分类区域。
- 数据分布外泛化不足：模型学到的特征不完全等同于人类语义特征。
- 训练目标不含鲁棒性约束：标准 ERM 主要优化平均准确率，不保证局部邻域内预测稳定。

面试中不要把原因说成“模型太复杂所以容易被骗”。更好的表达是：模型在高维输入空间中学习到的判别边界和人类感知语义不完全一致，局部小扰动可能显著改变模型特征或 logits。

### 常见考法与解题方法

| 考法 | 怎么考 | 怎么解 |
| --- | --- | --- |
| 概念辨析 | 对抗样本、噪声、数据增强、分布外样本区别 | 看是否有攻击目标、是否针对模型损失优化、是否保持原语义 |
| 威胁模型 | 给一个攻击实验，问是否公平 | 检查访问权限、扰动预算、目标模型、查询次数、语义约束和指标 |
| 公式推导 | 推 FGSM 或 PGD 更新公式 | 从一阶泰勒展开和范数约束推 `sign(gradient)` |
| 指标设计 | 问 ASR 怎么定义 | 先定任务，再定成功条件、样本集合和统计口径 |
| 防御判断 | 问某防御是否有效 | 看是否真的降低自适应攻击 ASR，是否保持 clean accuracy |

### FGSM 的推导思路

对损失函数在 `x` 附近做一阶近似：

```text
L(x + delta, y) ~= L(x, y) + delta^T grad_x L(x, y)
```

在 `||delta||_inf <= epsilon` 约束下，要最大化内积，最优扰动方向是梯度符号：

```text
x_adv = x + epsilon * sign(grad_x L(f(x), y))
```

如果是定向攻击，希望模型输出目标标签 `y_target`，则要最小化目标类别损失：

```text
x_adv = x - epsilon * sign(grad_x L(f(x), y_target))
```

### 评估指标

- ASR：Attack Success Rate，攻击成功样本数 / 可攻击样本数。
- Clean Accuracy：干净样本准确率，防止攻击只在原本就错的样本上统计成功。
- Robust Accuracy：攻击后仍预测正确的比例。
- Accuracy Drop：干净准确率与攻击后准确率差值。
- Transfer ASR：源模型生成样本在目标模型上的攻击成功率。
- Perturbation Budget：扰动预算，如 `8/255`、`16/255`。
- Query Count：黑盒查询次数。
- Perceptual Quality：SSIM、LPIPS、人审、语义保持比例。

ASR 统计通常应只在 clean 样本原本预测正确的集合上计算，否则会高估攻击效果。

### 易错点

- 只报攻击后准确率，不报 clean accuracy 和样本过滤口径。
- 把[黑盒迁移攻击](<迁移与通用攻击/黑盒迁移攻击.md>)说成完全不知道任何模型，其实源模型仍是攻击者拥有的 surrogate。
- 扰动预算没有说明像素范围是 `[0, 1]` 还是 `[0, 255]`。
- 文本攻击只看替换成功，不检查语义、语法和实体一致性。
- 防御只测普通攻击，不测 adaptive attack，容易得到虚假的鲁棒性。

## 面试应对

### 什么是对抗样本？

回答思路：定义、约束、目标、为什么重要四步回答。

回答模板：

对抗样本是在原始输入上加入很小且通常不易察觉的扰动，使模型输出发生错误或偏离预期的样本。它不是普通噪声，而是根据模型损失或决策边界有目的地构造出来的。形式上是在扰动预算内最大化模型损失，同时保持输入仍然合法、语义尽量不变。它的重要性在于可以暴露模型对局部扰动和分布外输入的脆弱性，也常用于评估模型鲁棒性和设计防御方法。

### 白盒攻击和黑盒攻击有什么区别？

回答思路：按访问权限、方法和真实场景说。

回答模板：

白盒攻击假设攻击者知道模型结构、参数和梯度，可以直接对输入求梯度来优化扰动，典型方法是 FGSM、PGD 和 CW。黑盒攻击不能直接拿到目标模型梯度，通常通过迁移攻击、查询估计或决策边界搜索实现。实际商业模型更接近黑盒场景，所以评估迁移 ASR、查询预算和攻击成本比只看白盒攻击更有现实意义。

### 设计攻击实验时最重要的是什么？

回答思路：强调威胁模型和公平评估。

回答模板：

我会先定义威胁模型，包括攻击者能访问什么、能修改哪些输入、扰动预算是多少、目标任务和成功标准是什么。然后保证 baseline 使用相同数据、相同预算、相同目标模型和可比的超参数。最后同时报告 clean accuracy、ASR、扰动大小、查询次数、语义保持和防御下结果。这样才能判断方法是否真的更强，而不是因为实验设定更宽松。
