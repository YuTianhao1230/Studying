## 学习路线

1. 先看 [对抗样本基础.md](<对抗样本基础.md>)，建立威胁模型、扰动预算和攻击目标的基本框架。
2. 再看 [视觉对抗攻击方法.md](<视觉对抗攻击方法.md>)，按需进入 FGSM、PGD、MI-FGSM、DIM/TIM、CW 单卡片。
3. 接着看 [迁移攻击与通用扰动.md](<迁移攻击与通用扰动.md>)，理解黑盒迁移、通用扰动、跨任务攻击和特征攻击。
4. 重点看 [多模态对抗攻击.md](<多模态对抗攻击.md>)，进入 CLIP 对齐攻击、文本攻击、联合图文攻击和 MLLM 评估卡片。
5. 最后看 [防御评估与鲁棒性.md](<防御评估与鲁棒性.md>) 和 [简历项目追问_对抗攻击.md](<简历项目追问_对抗攻击.md>)，准备项目答辩、实验设计和防御追问。
