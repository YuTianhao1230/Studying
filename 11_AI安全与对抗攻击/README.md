# AI安全与对抗攻击

本目录整理对抗样本、视觉攻击、迁移攻击、多模态攻击、防御评估和简历项目追问相关知识。内容重点是把攻击目标、威胁模型、优化方法、评估协议和面试表达串起来。

索引顺序即建议学习路线：先建立基础威胁模型，再学习视觉攻击、迁移与通用攻击、多模态攻击，最后完成防御评估与项目复盘。
