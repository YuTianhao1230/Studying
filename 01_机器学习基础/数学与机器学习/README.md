## 学习路线

1. 先看 [数学基础.md](<数学基础.md>)，沿“链式求导 → 网络反传 → 概率估计 → 投影优化”学习，核对损失归一化和矩阵形状。
2. 再看 [机器学习基础.md](<机器学习基础.md>)，从目标函数推导经典模型的一轮更新，再用部署对象和时间约束选择验证集。
3. 接着看 [统计推断与因果推断基础.md](<统计推断与因果推断基础.md>)，理解实验结论是否可信。
4. 最后看 [Cosine Similarity.md](<Cosine Similarity.md>)，连接到 embedding、检索和对比学习。
