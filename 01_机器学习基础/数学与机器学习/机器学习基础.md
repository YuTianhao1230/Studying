# 机器学习基础

## 知识点解析

### 概述

机器学习基础关注模型如何从数据中学习规律，核心包括监督学习、无监督学习、泛化能力、损失函数、评估指标、过拟合与正则化。面试中要能把算法原理、数据假设和工程评估连接起来。

#### 高频问题

1. 监督学习、无监督学习、半监督学习、自监督学习、强化学习分别是什么？
2. 生成模型和判别模型有什么区别？请举例说明。
3. 过拟合和欠拟合如何判断？分别怎么处理？
4. Bias-Variance Tradeoff 是什么？模型复杂度如何影响二者？
5. 逻辑回归为什么叫回归？它如何做二分类？
6. SVM 的最大间隔思想是什么？核函数解决了什么问题？
7. 决策树、随机森林、GBDT、XGBoost、LightGBM 的区别是什么？
8. KMeans、GMM、DBSCAN 分别适合什么聚类场景？
9. PCA 的目标函数是什么？它和自编码器有什么关系？
10. AUC、Accuracy、Precision、Recall、F1 分别适合什么场景？
11. 类别极不均衡时应该如何建模和评估？
12. 特征工程包括哪些步骤？如何处理缺失值、异常值和类别特征？

### 核心知识点

- 学习范式：监督、无监督、半监督、自监督、强化学习。
- 模型类型：线性模型、树模型、核方法、概率图模型、集成学习。
- 泛化能力：训练误差、验证误差、测试误差、交叉验证、数据泄漏。
- 过拟合控制：正则化、降维、早停、集成、数据增强、简化模型。
- 经典模型：Linear Regression、Logistic Regression、Naive Bayes、SVM、KNN、Decision Tree、Random Forest、GBDT。
- 聚类与降维：KMeans、GMM、DBSCAN、PCA、t-SNE、UMAP。
- 评估指标：Accuracy、Precision、Recall、F1、AUC、PR-AUC、LogLoss、Calibration。
- 数据问题：长尾分布、样本偏差、标签噪声、类别不均衡、训练/线上分布偏移。

#### 回答要点

- 判别模型学习 `P(y|x)` 或决策边界，生成模型学习 `P(x,y)` 或 `P(x|y)`。
- 过拟合表现为训练集好、验证/测试集差；欠拟合表现为训练集和验证集都差。
- AUC 衡量正负样本排序能力，对阈值不敏感；PR-AUC 在正样本稀少时更敏感。
- GBDT 是按梯度方向逐步拟合残差的加法模型，XGBoost/LightGBM 在工程效率、正则、采样和分裂策略上做了增强。
- 处理类别不均衡时不能只看 Accuracy，应关注 Recall、Precision、F1、PR-AUC、业务成本矩阵。
- 数据泄漏是面试高频问题，例如使用了未来信息、全量统计特征、重复样本跨 train/test。

### 经典监督学习模型

#### 线性回归与逻辑回归

线性回归直接预测连续值，常用均方误差：

```text
MSE = (1/n) * Σ(y_i - w^T x_i)^2
```

逻辑回归虽然名字带“回归”，实际是分类模型。它先计算线性得分 `z = w^T x + b`，再通过 Sigmoid 将其映射到 `[0, 1]`：

```text
P(y=1|x) = 1 / (1 + exp(-z))
```

二分类时通常最小化二元交叉熵。逻辑回归具有训练快、可解释、概率输出自然等优点，但只能直接学习线性决策边界，复杂非线性关系需要特征交叉或其他模型。

#### SVM

SVM 的目标是在正确分类的前提下最大化两类样本之间的间隔。硬间隔要求样本线性可分；软间隔通过松弛变量允许少量样本越界，并使用参数 `C` 权衡间隔大小与分类错误：

- `C` 大：更重视训练样本分类正确，可能过拟合。
- `C` 小：允许更多误分类，间隔更宽，正则更强。

核函数通过计算隐式高维空间中的内积，让模型获得非线性决策边界。常见核包括线性核、多项式核和 RBF 核。样本量很大时，核 SVM 的训练和存储成本通常较高。

#### 决策树与集成学习

决策树通过不断选择特征和切分点划分样本。分类树常用信息增益、信息增益率或基尼指数，回归树常用平方误差。单棵树可解释但方差较大，容易过拟合。

| 模型 | 核心思想 | 优势 | 主要风险 |
| --- | --- | --- | --- |
| Random Forest | 多棵树并行训练并投票，样本和特征随机采样 | 降低方差、鲁棒、易并行 | 模型较大，可解释性弱于单树 |
| GBDT | 后一棵树拟合前面模型的残差或负梯度 | 表格数据效果强、可表达非线性 | 串行训练，对噪声和参数较敏感 |
| XGBoost | 二阶梯度、显式正则、列采样和工程优化 | 精度与工程效率兼顾 | 参数较多，调参成本较高 |
| LightGBM | 直方图、叶子优先生长、特征捆绑 | 大数据训练快、内存占用低 | 小数据上叶子优先生长可能过拟合 |

树模型通常不要求特征归一化，因为分裂依据是特征大小关系，而不是欧氏距离或梯度尺度。

### 无监督学习与降维

- KMeans 假设簇近似球形，使用欧氏距离，速度快但需要预先指定簇数，对初始点和异常值敏感。
- GMM 用多个高斯分布描述数据，输出样本属于各簇的概率，能表达不同形状和协方差结构。
- DBSCAN 根据密度形成簇，不需要预先指定簇数，能识别噪声，但对密度差异大的数据较敏感。
- PCA 寻找方差最大的正交方向，等价于对中心化数据协方差矩阵做特征分解，也可通过 SVD 实现。
- t-SNE 和 UMAP 更适合可视化局部结构，不应直接把二维图上的距离当成严格的全局距离。

### 评估与数据划分

| 指标 | 关注点 | 适用场景 |
| --- | --- | --- |
| Accuracy | 总体预测正确率 | 类别相对均衡、错误成本接近 |
| Precision | 预测为正的样本中有多少是真的 | 误报成本高 |
| Recall | 实际正样本中有多少被找出 | 漏报成本高 |
| F1 | Precision 与 Recall 的调和平均 | 需要平衡误报和漏报 |
| ROC-AUC | 随机正样本排在随机负样本前的概率 | 关注整体排序能力 |
| PR-AUC | 不同阈值下 Precision-Recall 权衡 | 正样本稀少 |
| LogLoss | 概率预测与真实标签的差异 | 关注概率质量 |
| Calibration | 预测概率与真实发生频率是否一致 | 风控、医疗、广告等概率决策 |

数据划分必须与真实泛化目标一致。时间相关任务优先按时间切分；用户行为任务应按用户切分；同源图片、视频帧或近重复文本不能跨训练集和测试集。交叉验证适合数据量较小的场景，但不能修复本身有偏的数据采样。

### 类别不均衡

处理类别不均衡需要同时考虑训练和评测：

1. 指标上使用 Recall、F1、PR-AUC、分桶指标和业务成本，而不是只看 Accuracy。
2. 数据上可以欠采样多数类、过采样少数类或构造困难负样本。
3. 训练上可以使用类别权重、Focal Loss 或代价敏感学习。
4. 推理上根据业务成本调整阈值，并检查概率校准。
5. 验证集应保持真实分布，否则离线阈值无法直接用于线上。

## 面试应对

### 逻辑回归为什么叫回归，却用于分类？

回答思路：说明它回归的是对数几率，再说明如何得到分类概率。

回答模板：

逻辑回归不是直接回归类别，而是用线性模型拟合正类的对数几率，再通过 Sigmoid 映射成概率。训练时通常最小化交叉熵，推理时再根据阈值把概率转成类别。它的优点是概率解释清晰、训练稳定、可解释性强，局限是默认决策边界是线性的。

### 随机森林、GBDT 和 XGBoost 有什么区别？

回答思路：先区分 Bagging 和 Boosting，再比较训练方式、偏差方差与工程特点。

回答模板：

随机森林属于 Bagging，多棵树可以并行训练，通过样本和特征随机采样降低模型方差；GBDT 属于 Boosting，树按顺序训练，后一棵树拟合前面模型的残差或负梯度，主要降低偏差。XGBoost 是对 GBDT 的工程和目标函数增强，引入二阶梯度、显式正则、列采样和缺失值处理。数据噪声大、希望鲁棒和易并行时可以优先考虑随机森林；表格数据追求效果时通常考虑 GBDT、XGBoost 或 LightGBM。

### AUC 的概率解释是什么？

回答思路：从排序能力解释，并说明它不直接代表概率质量。

回答模板：

AUC 可以解释为随机抽取一个正样本和一个负样本，模型把正样本得分排在负样本前面的概率。它衡量的是跨阈值的整体排序能力，对类别比例相对不敏感。但 AUC 高不代表概率已经校准，也不代表某个业务阈值下 Precision 或 Recall 一定满足要求，所以实际还要结合 PR-AUC、阈值指标和业务成本判断。
