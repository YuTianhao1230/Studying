# 数学基础

## 知识点解析

### 概述

线性代数描述表示与投影，微积分描述参数如何影响损失，概率模型给出数据生成假设，统计估计把这些假设转化为训练目标。链式法则将 softmax 与交叉熵连接为简洁梯度；最大后验估计将先验连接为正则项；PCA 则将最大方差投影、约束优化和奇异值分解统一起来。

### 基本对象与计算约定

除树模型的熵另作说明外，对数均为自然对数。数据矩阵的每一行是一个样本；`n` 为样本数，`d` 为特征数。概率向量元素非负且和为 1，损失的求和、均值及 `1/2` 系数在各节明确给出。

| 对象 | 定义与用途 |
| --- | --- |
| 矩阵与秩 | 矩阵表示线性映射；秩是独立列的数量。满列秩使最小二乘的 `X^T X` 可逆；实际求解通常用 QR/SVD，避免显式求逆。 |
| 特征分解与 SVD | `Av=\lambda v` 表示方向不变的缩放；SVD `X=U\Sigma V^T` 对矩形矩阵也成立，左右奇异向量正交，奇异值非负。 |
| 梯度与方向导数 | 标量函数的梯度汇集各偏导；单位方向 `u` 上方向导数为 `\nabla f^T u`，负梯度是在欧氏单位步长下局部下降最快的方向。 |
| Jacobian 与 Hessian | 向量映射的 Jacobian 为 `J_{ij}=\partial f_i/\partial x_j`；标量函数的 Hessian 为二阶偏导矩阵，刻画曲率。 |
| 期望与协方差 | `Var(X)=E[(X-E[X])^2]`，`Cov(X,Y)=E[(X-E[X])(Y-E[Y])]`；相关系数除以两者标准差，无量纲。零相关一般不等于独立，非退化联合高斯是重要例外。 |
| 常见分布 | Bernoulli 表示一次二元结果，Binomial 表示独立同概率试验的成功次数；Categorical 表示一次多类结果，Multinomial 表示多次类别计数；Gaussian 常建模连续噪声。 |

### Softmax、交叉熵与 Jacobian

#### 定义与推导

单样本 logits 为 `z \in R^K`，目标分布为 `y`，满足 `\sum_i y_i=1`。one-hot 标签是特例，soft label 也适用：

```text
p_i = exp(z_i) / \sum_k exp(z_k)
J_{ij} = \partial p_i / \partial z_j
       = p_i(\delta_{ij} - p_j)
J = diag(p) - pp^T
\ell = -\sum_i y_i log p_i
\partial \ell / \partial z_j
  = -\sum_i (y_i/p_i) p_i(\delta_{ij}-p_j)
  = p_j - y_j
L = (1/n)\sum_a \ell_a  =>  \partial L/\partial Z = (P-Y)/n
```

`J` 的非对角项不可丢掉：一个 logit 上升会压低其他类概率。每行之和为零，与 logits 同加常数不改变概率一致。若 `p=softmax(z/T)`、`T>0`，则对原始 `z` 的 Jacobian 和损失梯度都多一个 `1/T`；对 logits 的损失 Hessian 为 `(diag(p)-pp^T)/T^2`。类别加权损失 `-\sum_i a_i y_i log p_i` 的梯度是 `p_j\sum_i a_i y_i-a_jy_j`，不能无条件套 `p-y`。

数值计算使用 `m=max(z)` 和 `log p_i=z_i-m-log\sum_k exp(z_k-m)`；直接从 logits 计算 log-softmax/交叉熵可避免指数溢出与 `log(0)`。接受 logits 的融合损失接口不应再先做 softmax。其他损失的用途见[常见分类损失函数](<../../03_训练优化与对齐/参数/常见分类损失函数.md>)。

#### 三分类算例与考法

取 `z=(log 2,log 3,log 5)`、`y=(0,1,0)`，则：

```text
p = (0.2, 0.3, 0.5),  \ell = -log(0.3) = 1.203973
J = [[ 0.16, -0.06, -0.10],
     [-0.06,  0.21, -0.15],
     [-0.10, -0.15,  0.25]]
\nabla_z \ell = (0.2, -0.7, 0.5)
```

常考给 logits 手算概率和梯度，或追问 soft label、温度和 batch mean。解法是先确定归一化与目标分布，再求 Jacobian、用链式法则收缩求和。显式 Jacobian 用 `O(K^2)` 空间；直接算 `p-y` 只需 `O(K)` 时间和空间。易错点是漏掉负号、温度或 batch 的 `1/n`，以及将交叉熵对概率的梯度 `-y/p` 当成对 logits 的梯度。

### 两层 MLP 的矩阵反向传播

#### 前向、形状与梯度

两层指两个可训练仿射层，中间用 ReLU，输出用 softmax。输入 `X:n×d`，隐藏宽度 `h`，类别数 `K`；偏置用行向量并沿 batch 广播。无正则、无样本权重，目标为 batch 平均交叉熵：

```text
W1:d×h, b1:1×h, W2:h×K, b2:1×K, 1_n:n×1
A = XW1 + 1_n b1          # n×h
H = ReLU(A)              # n×h
Z = HW2 + 1_n b2         # n×K
P = softmax_rows(Z)       # n×K
L = -(1/n)\sum_{i,k} Y_{ik} log P_{ik}

D2 = (P-Y)/n             # n×K
\nabla W2 = H^T D2       # h×K
\nabla b2 = 1_n^T D2     # 1×K
D1 = (D2 W2^T) \odot 1[A>0]  # n×h
\nabla W1 = X^T D1       # d×h
\nabla b1 = 1_n^T D1     # 1×h
\nabla X  = D1 W1^T      # n×d
```

`\odot` 是逐元素乘法。ReLU 在零点不可导，实现通常约定导数为 0。所有梯度要用同一次前向的参数计算完再更新；`D2` 已含 `1/n`，后续不能重复平均。

#### 可逐项复核的数值例

取 `n=d=h=K=2`，`b1=b2=(0,0)`：

```text
X  = [[ 1, 2], [-2, 1]]
W1 = [[ 1,-1], [ 1, 1]]
W2 = [[ 1, 0], [ 0, 1]]
Y  = [[ 1, 0], [ 0, 1]]

A = [[3,1],[-1,3]], H = Z = [[3,1],[0,3]]
P = [[0.880797,0.119203],[0.047426,0.952574]]
L = 0.087758
D2 = [[-0.059601, 0.059601],[0.023713,-0.023713]]
D1 = [[-0.059601, 0.059601],[0,       -0.023713]]
\nabla W2 = [[-0.178804, 0.178804],[ 0.011537,-0.011537]]
\nabla b2 = [-0.035889, 0.035889]
\nabla W1 = [[-0.059601, 0.107027],[-0.119203, 0.095490]]
\nabla b1 = [-0.059601, 0.035889]
\nabla X  = [[-0.119203,0],[0.023713,-0.023713]]
```

例如 `(\nabla W1)_{12}=1×0.059601+(-2)×(-0.023713)=0.107027`。第二个样本第一隐藏单元的预激活为负，所以对应 `D1` 为零；并不是整个样本的梯度都消失。

常考补矩阵形状、手算某个权重梯度或定位广播错误。按“前向缓存 → 输出误差 → 权重外积求和 → 激活门控”解题，并确认梯度与参数同形。前后向时间均为 `O(ndh+nhK)`；缓存激活约 `O(nh+nK)`，另计输入与参数。易错点是转置反了、把偏置梯度取均值两次、反传途中先更新 `W2`。MLP 的结构用途见[多层感知机](<../深度学习基础/Multi-Layer Perceptron.md>)。

### MLE、MAP 与 L2 的系数对应

#### 从概率假设到损失

给定输入，假设样本条件独立，参数为 `\theta`：

```text
MLE: \hat\theta = argmax_\theta \prod_i p(y_i|x_i,\theta)
               = argmin_\theta -\sum_i log p(y_i|x_i,\theta)
p(\theta|D) = p(D|\theta)p(\theta)/p(D)
MAP: \hat\theta = argmin_\theta [-\sum_i log p(y_i|x_i,\theta)-log p(\theta)]
```

证据 `p(D)` 与待优化参数无关，求 MAP 时可忽略。分类的 Categorical/Bernoulli 似然给出交叉熵；连续变量用的是概率密度，不是某个精确点的概率。

在线性回归中设 `y_i=x_i^T w+b+\epsilon_i`，`\epsilon_i` 独立服从 `N(0,\sigma^2)`，噪声方差固定已知；权重先验为 `w~N(0,\tau^2 I)`，偏置不惩罚：

```text
负对数后验 = (1/(2\sigma^2))\sum_i(y_i-x_i^T w-b)^2
             + (1/(2\tau^2))||w||_2^2 + const
同乘 \sigma^2/n 后：
L = (1/(2n))\sum_i(y_i-x_i^T w-b)^2 + (\lambda/2)||w||_2^2
\lambda = \sigma^2/(n\tau^2),  \nabla_w 正则项 = \lambda w
```

若基础损失用 `MSE=(1/n)\sum r_i^2`、正则用 `\alpha||w||^2`，则 `\alpha=\sigma^2/(n\tau^2)`；若仍用半 MSE 而正则不带 `1/2`，系数应为 `\sigma^2/(2n\tau^2)`。分类平均 NLL 加 `(\lambda/2)||w||^2` 对应 `\lambda=1/(n\tau^2)`，没有回归噪声方差因子。固定先验下样本数变大，平均损失口径的系数减小；固定超参数 `\lambda` 则不是固定先验。

#### 一维算例与适用边界

无截距，`x=(1,2)`、`y=(1,2)`，`\sigma^2=1`、`\tau^2=2`、`n=2`，所以半 MSE 口径下 `\lambda=1/4`：

```text
w_MLE = (\sum x_i y_i)/(\sum x_i^2) = 5/5 = 1
w_MAP = 5/(5+n\lambda) = 5/5.5 = 10/11 = 0.909091
L(w) = (5/4)(1-w)^2 + (1/8)w^2
L'(w) = (5/2)(w-1) + w/4 = 0
```

常考“L2 为什么等价于高斯先验”及系数换算。解法先写似然、先验，取负对数，再把整个目标统一缩放；只缩放数据项会改变最优解。非各向同性高斯先验得到 `w^T\Sigma^{-1}w/2`，不再是普通 L2；Laplace 先验对应 L1。若同时估计 `\sigma^2`，不能丢掉 `n log\sigma` 项。稠密岭回归形成正规矩阵并求解约 `O(nd^2+d^3)`，大维度通常用迭代法。

正则化方法及几何直觉见[正则化](<../深度学习基础/正则化.md>)，回归损失比较见[常见回归损失函数](<../../03_训练优化与对齐/参数/常见回归损失函数.md>)。L2 通常收缩但不主动制造稀疏性，不意味着权重绝不为零；L2 与解耦 weight decay 只在普通 SGD 等特定更新规则下等价，在 Adam 与 AdamW 中不能直接混同。

### PCA 的约束优化、SVD 与二维例题

#### 最大方差与最小重构误差

先用训练集均值中心化得到 `X \in R^{n×d}`，定义 `C=X^T X/n`。一维投影方向 `v` 要求单位长度，防止仅靠放大向量无限增大方差：

```text
max_v v^T C v, subject to v^T v=1
\mathcal L(v,\lambda)=v^T C v-\lambda(v^T v-1)
\nabla_v \mathcal L=2Cv-2\lambda v=0 => Cv=\lambda v
取最大特征值对应的单位特征向量。

k 维：max_{V_k^T V_k=I} tr(V_k^T C V_k)
等价于 min ||X-XV_k V_k^T||_F^2
X=U\Sigma V^T => C=V(\Sigma^T\Sigma/n)V^T
投影分数 T=XV_k=U_k\Sigma_k
重构 \hat X=TV_k^T，原空间重构再加训练均值
```

保留方差为前 `k` 个特征值之和，解释方差比例为它除以全部特征值之和。改用 `1/(n-1)` 协方差只统一缩放特征值，不改变方向与比例；常量数据总方差为零时比例无定义。

#### 二维降到一维

四个点为 `(2,1),(1,2),(-2,-1),(-1,-2)`，均值为零：

```text
C = [[2.5,2],[2,2.5]]
\lambda_1=4.5, v1=(1,1)^T/sqrt(2)
\lambda_2=0.5, v2=(1,-1)^T/sqrt(2)
\sigma_1=sqrt(4×4.5)=sqrt(18), \sigma_2=sqrt(2)
T = (3/sqrt(2),3/sqrt(2),-3/sqrt(2),-3/sqrt(2))^T
\hat X = [(1.5,1.5),(1.5,1.5),(-1.5,-1.5),(-1.5,-1.5)]
解释方差比例 = 4.5/(4.5+0.5) = 90%
总平方重构误差 = 2
每样本平方欧氏误差 = 2/4 = 0.5 = 被丢弃特征值
```

这里没有再除以维数 `d`；若报告逐元素 MSE，值为 `2/(4×2)=0.25`。奇异向量整体变号不影响投影子空间或重构。

常考推导约束、由 SVD 求方差、手算投影与重构。解法按“中心化 → 协方差 → 特征对排序 → 投影 → 加回均值”进行。稠密完整 SVD 时间约 `O(nd min(n,d))`；截断/随机 SVD 可降低成本。易错点是漏中心化、把最大方差当最大类别区分度、混用归一化分母。不同量纲是否标准化取决于保留原始方差是否有意义，标准化后相当于改变目标。PCA 是线性无监督方法；线性瓶颈自编码器在平方重构损失且达到全局最优时可恢复同一主子空间，但编码基不一定就是正交主成分。

### 信息论与优化的连接

离散分布满足 `H(P)=-\sum p_i log p_i`、`H(P,Q)=-\sum p_i log q_i`、`KL(P||Q)=H(P,Q)-H(P)`。当 `p_i>0,q_i=0` 时 KL 为无穷大；约定 `0 log 0=0`。固定目标 `P` 时，最小化交叉熵等价于最小化 KL。互信息 `I(X;Y)=KL(p(x,y)||p(x)p(y))` 衡量联合分布偏离独立的程度。

二阶 Taylor 近似为 `f(w+\Delta)\approx f(w)+g^T\Delta+\Delta^T H\Delta/2`。凸域上二次可微函数的 Hessian 处处半正定可保证凸性，凸问题的局部最优也是全局最优；驻点处正定 Hessian 给出局部严格极小，但神经网络整体通常非凸。驻点处 Hessian 不定说明是鞍点，仅半正定不足以判定局部极小。

参数量为 `p` 时，完整 Hessian 存储 `O(p^2)`，稠密线性求解 `O(p^3)`；Hessian-vector product 可避免显式矩阵，但不等于免费求逆。独立同分布梯度取 batch 均值时方差约随 `1/B` 下降，有相关性时需加入协方差项；batch 更大并不自动保证更好泛化。

## 面试应对

### 如何推导 softmax 加交叉熵，并推广到 MLP？

回答思路：先报损失与形状约定，再从 Jacobian 推出输出误差，最后按层传回。

回答模板：

对温度为一、目标概率和为一的单样本，softmax 的 Jacobian 是 diag(p) 减去 pp 的转置外积，交叉熵通过链式法则得到 logits 梯度 p 减 y。batch 平均时再除以样本数。两层 MLP 中，第二层权重梯度是隐藏输出转置乘输出误差，偏置沿样本维求和；误差乘第二层权重转置，再经过 ReLU 门控，得到第一层误差。整个反传必须使用同一次前向的参数，不能重复除 batch size。

### 最大似然估计和交叉熵有什么关系？

回答思路：从最大化真实标签概率转到最小化负对数似然。

回答模板：

最大似然估计选择让观测数据出现概率最大的模型参数。分类模型对真实类别给出概率，把所有样本的似然连乘后取对数，就得到真实类别对数概率之和；最大化它等价于最小化负对数似然，而分类任务中的交叉熵正是这种形式。使用对数还能把连乘变成求和，数值和优化都更稳定。

### 为什么 MAP 会得到 L2，系数由什么决定？

回答思路：明确高斯噪声、高斯先验和是否惩罚偏置，最后统一损失尺度。

回答模板：

MAP 最大化似然乘先验。高斯噪声的负对数似然给出平方残差，高斯权重先验给出二次惩罚。若噪声方差为 sigma 平方、先验方差为 tau 平方，数据项写成二分之一的平均平方误差，正则写成 lambda 除以二乘权重平方和，那么 lambda 等于 sigma 平方除以 n 倍 tau 平方。这个对应依赖先验和损失归一化，不能把任意 L2 系数都解释为同一个高斯先验。

### PCA 为什么可以用 SVD，如何检查计算结果？

回答思路：从单位长度约束推特征方程，再连接奇异值、投影方差与重构误差。

回答模板：

PCA 在中心化数据上寻找最大方差的正交子空间。单位方向下最大化投影方差，拉格朗日条件给出协方差矩阵的特征方程，取最大特征值对应的方向。若协方差定义为 X 转置乘 X 再除以 n，SVD 的右奇异向量就是主方向，奇异值平方除以 n 就是对应方差。保留前 k 个方向后，每样本平方重构误差等于被丢弃特征值之和；计算时要确认中心化、分母和误差是否按维度平均。

### 为什么深度学习很少直接使用二阶优化？

回答思路：说明 Hessian 的存储和计算成本。

回答模板：

二阶方法利用 Hessian 曲率信息，理论上可能用更少步骤收敛，但模型参数很多时，Hessian 的存储和求逆成本无法接受，近似二阶方法也会增加大量通信与计算。深度学习通常使用 SGD、AdamW 等一阶方法，再配合动量、学习率调度和归一化，在单步成本和收敛速度之间取得更实际的平衡。

### KL 散度为什么不对称？

回答思路：说明期望分布决定惩罚重点。

回答模板：

KL(P||Q) 是在 P 分布下计算 log(P/Q) 的期望，因此更重视 Q 是否覆盖 P 概率高的区域；交换方向后，期望分布和惩罚重点都会改变，所以一般不相等。直观上，KL(P||Q) 更不能容忍 Q 漏掉 P 的主要模式，而 KL(Q||P) 更倾向让 Q 集中在 P 的高概率区域。
