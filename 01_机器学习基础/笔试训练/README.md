# 机器学习基础笔试训练

## 概述

本目录将机器学习基础知识整理为银行、运营商、算法工程和数据科学岗位常见的选择题、公式题、手算题、场景判断题和判断题。题目均为自编训练题，不标记为具体单位真题。

建议先遮住答案，按专项完成，再把错误归类为概念混淆、公式错误、计算失误、数据泄漏或场景判断错误。

## 使用方法

1. 首次学习后限时完成对应专项，不先看答案。
2. 公式题先写出变量定义和适用条件，再代入数值。
3. 场景题先判断部署时可获得的信息，再选择模型、切分方式或指标。
4. 一周后重做错题，并回链到对应知识卡片。
5. 最后进行本目录四个专项的混合限时训练；训练优化题见[03笔试训练](<../../03_训练优化与对齐/笔试训练/README.md>)，数据实验题见[04笔试训练](<../../04_评测实验与数据质量/笔试训练/README.md>)。
