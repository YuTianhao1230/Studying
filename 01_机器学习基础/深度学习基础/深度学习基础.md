# 深度学习基础

## 知识点解析

### 概述

深度学习基础关注多层神经网络如何通过表示学习拟合复杂函数，核心包括前向传播、反向传播、激活函数、归一化、优化器、[正则化](<正则化.md>)和训练稳定性。

#### 高频问题

1. 神经网络为什么可以拟合复杂函数？万能近似定理如何理解？
2. 前向传播和反向传播分别做了什么？链式法则如何应用？
3. 激活函数 [ReLU](<../../03_训练优化与对齐/参数/常见激活函数.md>)、Sigmoid、Tanh、GELU、SiLU 有什么区别？
4. 梯度消失和梯度爆炸是什么？如何缓解？
5. BatchNorm、LayerNorm、[RMSNorm](<../../02_大模型/基础架构/RMSNorm.md>) 的区别是什么？
6. Dropout 为什么能缓解过拟合？训练和推理阶段有什么差异？
7. Adam、SGD、AdamW 的区别是什么？为什么 AdamW 常用于大模型训练？
8. 学习率调度有哪些常见策略？Warmup 的作用是什么？
9. 残差连接为什么重要？它如何改善深层网络训练？
10. 初始化方法为什么重要？Xavier 和 Kaiming 初始化分别适合什么激活函数？
11. 混合精度训练为什么能加速？FP16、BF16 有什么区别？
12. 如何判断训练过程是否正常？

### 核心知识点

- 基础结构：MLP、CNN、RNN、[Transformer](<../../02_大模型/基础架构/Transformer.md>)、残差网络。
- 前后向计算：计算图、链式法则、自动微分、梯度累积。
- 激活函数：非线性、饱和区、稀疏激活、平滑性。
- 归一化：BatchNorm、LayerNorm、InstanceNorm、GroupNorm、RMSNorm。
- 优化器：SGD、Momentum、RMSProp、Adam、AdamW、Adafactor。
- 训练技巧：Warmup、Cosine Decay、Gradient Clipping、EMA、Label Smoothing、Dropout。
- 精度与性能：FP32、TF32、FP16、BF16、AMP、loss scaling。
- 稳定性：loss 曲线、梯度范数、参数范数、激活分布、吞吐、显存。

#### 回答要点

- 反向传播本质是对计算图应用链式法则，高效复用中间梯度。
- ReLU 简单高效但可能出现死亡 ReLU；GELU/SiLU 更平滑，常用于 Transformer。
- BatchNorm 依赖 batch 统计，更常用于 CNN；LayerNorm 对单样本特征维归一化，更适合序列模型和 Transformer。
- AdamW 将权重衰减从 Adam 的梯度更新中解耦，正则行为更清晰。
- Warmup 可避免训练初期参数随机、梯度不稳定时学习率过大导致发散。
- BF16 指数位更宽，动态范围接近 FP32，通常比 FP16 更不容易溢出。

## 面试应对

### 反向传播的本质是什么？

回答思路：从计算图和链式法则回答。

回答模板：

反向传播是在计算图上应用链式法则，从损失函数开始反向计算每个中间变量和参数的梯度。它会复用前向传播保存的中间结果，避免对每个参数单独求导，因此能够高效训练多层网络。前向传播计算预测和损失，反向传播计算梯度，优化器再根据梯度更新参数。

### BatchNorm、LayerNorm 和 RMSNorm 怎么选？

回答思路：比较归一化维度、对 Batch 的依赖和典型场景。

回答模板：

BatchNorm 使用一个 Batch 的统计量，适合 Batch 较稳定的 CNN，但小 Batch 或变长序列下统计不稳定；LayerNorm 对单个样本的特征维归一化，不依赖其他样本，因此更适合 Transformer；RMSNorm 只按均方根缩放，不减均值，计算更简单，是许多大模型的常用选择。选择时主要看数据结构、Batch 大小和训练稳定性。

### 训练 loss 出现 NaN 怎么排查？

回答思路：按数据、损失、学习率、精度和梯度逐层排查。

回答模板：

我会先定位 NaN 第一次出现的 Step 和 Rank，检查输入、标签和 mask 是否包含非法值，再验证 loss 公式有没有除零、对零取对数或空样本。然后检查学习率、梯度范数和异常 Batch，确认混合精度是否溢出以及 loss scaling 是否正常。最后用小数据、单卡和 FP32 逐步缩小范围，而不是直接降低学习率碰运气。
