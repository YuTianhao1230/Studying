# 常见分类损失函数

## 知识点解析

### 概述

在机器学习和深度学习中，**损失函数（Loss Function）**用于衡量模型预测与监督目标之间的偏差。分类损失常基于概率与对数似然构造，但 Hinge Loss 等方法也可以直接作用于分类分数或 margin。

以下是常见的分类损失函数及其应用场景：

### 交叉熵损失 (Cross-Entropy Loss) —— 最主流
这是目前分类任务中最常用、默认的损失函数。它源于信息论，用于衡量两个概率分布之间的差异。

#### (1) 二元交叉熵 (Binary Cross-Entropy, BCE)
*   **场景：** **二分类**（如：垃圾邮件过滤、判别是不是猫）。
*   **概率形式：** 若损失函数接收概率，需要先通过 **Sigmoid** 将单个 logit 转为正类概率。
*   **Logits API：** PyTorch 的 `BCEWithLogitsLoss` 直接接收未经 Sigmoid 的 logits，并在内部合并 Sigmoid 与 BCE，以获得更好的数值稳定性；此时不应在模型末尾重复添加 Sigmoid。
*   **逻辑：** 当真实标签为 1 时，预测概率越接近 0，损失越大；反之亦然。

#### (2) 多类交叉熵 (Categorical Cross-Entropy, CCE)
*   **场景：** **多分类**（如：手写数字识别 0-9、图像识别猫/狗/花）。
*   **概率形式：** 从数学上会通过 **Softmax** 将各类别 logits 转为概率，但是否显式添加 Softmax 取决于损失 API。
*   **Logits API：** PyTorch 的 `CrossEntropyLoss` 直接接收原始 logits；仅在目标是类别索引时，其计算才等价于 `LogSoftmax` 与 `NLLLoss` 的组合，目标是类别概率（如 soft label）时则按各类别目标概率计算加权交叉熵。两种分支都不应先手动 Softmax。`from_logits` 是 `tf.keras.losses.*Crossentropy` 的参数；`tf.nn.*_with_logits` 直接接收 logits，不提供该参数。
*   **标签形式：** API 可以接收类别索引或类别概率。PyTorch `CrossEntropyLoss` 最常见的是整数类别索引；one-hot 或软标签并非所有多分类交叉熵接口的强制要求。

#### (3) 稀疏多类交叉熵 (Sparse Categorical Cross-Entropy)
*   **区别：** 与 CCE 逻辑完全一致，但不需要将标签转为 One-hot，直接输入类别索引（如：标签直接是 `2` 而不是 `[0,0,1]`）。
*   **优点：** 节省内存，在类别非常多（如几万个词）时非常有用。

### 合页损失 (Hinge Loss) —— 强调“边界”
*   **场景：** **支持向量机 (SVM)**。
*   **公式含义：** 它不只是要求分类正确，还要求预测结果与分类边界保持一定的**距离（Margin）**。
*   **特点：** 
    *   如果分类正确且离边界足够远，损失为 0。
    *   如果分类错误或离边界太近，损失会线性增加。
*   **缺点：** 导数不连续，不适合概率预测，现代神经网络中使用较少。

### Focal Loss —— 解决“不平衡”问题
*   **背景：** 由何恺明等人提出，最初用于目标检测（解决背景样本远多于目标样本的问题）。
*   **原理：** 在交叉熵的基础上增加了一个权重因子 $(1-p)^\gamma$。
*   **核心逻辑：**
    *   **降低容易样本的权重：** 让模型不要花太多精力在那些已经分得很准的简单样本上。
    *   **专注困难样本：** 强迫模型去学习那些容易混淆、分类错误的少数派样本。
*   **场景：** **样本极度不平衡**的任务（如：金融欺诈检测、罕见病诊断）。

### KL 散度 (Kullback-Leibler Divergence)
*   **场景：** **知识蒸馏（[Knowledge Distillation](<../../03_训练优化与对齐/后训练与对齐/Knowledge Distillation 知识蒸馏.md>)）**、变分自编码器（VAE）。
*   **逻辑：** 衡量两个概率分布 $P$ 和 $Q$ 之间的差异。
*   **在分类中的应用：** 在知识蒸馏中，让“学生模型”的输出概率分布去模仿“老师模型”的输出概率分布。

### 指数损失 (Exponential Loss)
*   **场景：** **AdaBoost** 算法。
*   **逻辑：** 对分类错误的样本给予极大的惩罚（指数级增长）。
*   **缺点：** 对**离群点（Outliers）**和**噪声**极其敏感，容易导致过拟合。

### 基于余弦相似度的损失 (Cosine-based Losses)
*   **场景：** **人脸验证**、**度量学习**、**对比学习**、文本匹配等表征学习任务，而不是普通闭集分类的默认损失。
*   **优化目标：** 余弦相似度 $s=\cos(\mathbf{x}_1,\mathbf{x}_2)$ 是分数而非损失。对正样本对可最小化 $1-s$ 或 $-s$，两者仅相差常数；对负样本对可使用 $\max(0,s-m)$，只惩罚相似度高于 margin $m$ 的样本。
*   **Cosine Embedding Loss：** 对标签 $y=1$ 使用 $1-s$，对 $y=-1$ 使用 $\max(0,s-m)$，从而同时拉近正样本并将负样本分离到 margin 之外。
*   **边界说明：** `1-cos` 也常称余弦距离，但一般不是严格数学度量；完整公式与区别见 [Cosine Similarity](<../数学与机器学习/Cosine Similarity.md>)。

### 总结：我该选哪一个？

| 任务类型 | 推荐损失函数 | 最后一层激活函数 |
| :--- | :--- | :--- |
| **二分类** | **Binary Cross-Entropy** | 概率 API 用 Sigmoid；logits API 不显式添加 |
| **多分类 (标签为One-hot/软标签)** | **Categorical Cross-Entropy** | 概率 API 用 Softmax；logits API 不显式添加 |
| **多分类 (标签为整数ID)** | **Sparse Categorical Cross-Entropy** | 概率 API 用 Softmax；logits API 不显式添加 |
| **类别极其不平衡** | **Focal Loss** | 取决于 API 接收 logits 还是概率 |
| **传统 SVM 分类** | **Hinge Loss** | 无 / 线性 |
| **模型压缩/蒸馏** | **KL Divergence** | 通常基于温度缩放后的概率或对数概率 |

**为什么不用 MSE（均方误差）做分类？**
MSE 并非不能用于分类，也不能笼统地说它“总是非凸”：MSE 对预测值本身是凸的，但与 Sigmoid 或深层网络复合后的整体目标可能非凸，交叉熵训练深层网络时同样通常是非凸的。实际更常选交叉熵，是因为它对应分类分布的最大似然；相比 Sigmoid 与 MSE 的组合，交叉熵对置信但错误的预测惩罚更合理，且可避免额外的 Sigmoid 导数造成梯度进一步衰减。若任务目标是概率校准、软标签拟合或具有特殊统计假设，MSE 仍可能作为可选目标。
## 面试应对

### 常见分类损失函数有哪些？

回答思路：以交叉熵家族为主线（BCE 二分类、CCE/稀疏 CCE 多分类），再按需求补充 Hinge、Focal、KL 散度和基于余弦相似度的损失，并区分概率分布损失、margin 损失与表征学习目标。

回答模板：

分类任务最常用的是交叉熵损失，它等价于最大化正确类别的对数似然。二分类常用 BCE 或 BCEWithLogitsLoss，多分类常用 CrossEntropyLoss，多标签分类通常用独立的二分类损失。

### 交叉熵为什么适合分类？

回答思路：抓住交叉熵度量预测概率分布与真实标签分布的差异、等价于最大化正确类对数似然，说明它对置信但错误的预测惩罚较强；再对比 Sigmoid 与 MSE 组合会额外乘上激活函数导数，但不要把 MSE 或交叉熵在深层网络中的凸性绝对化。

回答模板：

交叉熵直接度量预测概率分布和真实标签分布的差异。模型对正确类别越有信心，loss 越低；如果把概率分给错误类别，loss 会升高。配合 softmax 后，它能为分类模型提供清晰的优化信号。

### 使用分类损失有哪些注意事项？

回答思路：点明要对齐标签格式（one-hot 还是索引）、输入是 logits 还是概率（PyTorch CrossEntropyLoss 吃 logits 无需先 softmax），以及类别不均衡时用 class weight、Focal Loss 或重采样。

回答模板：

要确认标签格式、logits/probability 输入要求和类别不均衡问题。PyTorch 的 CrossEntropyLoss 期望输入 logits，不需要先手动 softmax；BCEWithLogitsLoss 同样不需要先做 sigmoid。类别极不均衡时可以考虑 class weight、focal loss 或重采样。
