# 常见激活函数

## 知识点解析

### 概述

激活函数是神经网络的“灵魂”，它的核心作用是**引入非线性因素**。如果没有激活函数，无论神经网络有多少层，最终都只能表达线性映射，无法处理现实世界中复杂的非线性问题。

以下是深度学习中常见的激活函数，按演进过程和应用场景分类：

### 经典激活函数（早期常用）

#### **Sigmoid**
*   **公式：** $f(x) = \frac{1}{1 + e^{-x}}$
*   **输出范围：** (0, 1)
*   **特点：** 将输入压缩到 0 到 1 之间，像一个平滑的阶跃函数。
*   **缺点：** 
    *   **梯度消失：** 当 $x$ 很大或很小时，梯度趋近于 0，导致深层网络无法训练。
    *   **计算量大：** 包含幂运算。
    *   **非零中心：** 输出全是正数，会影响梯度下降的效率。
*   **现常用场景：** 二分类任务的输出层。

#### **Tanh (双曲正切)**
*   **公式：** $f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
*   **输出范围：** (-1, 1)
*   **特点：** 零中心化（Zero-centered），收敛速度比 Sigmoid 快。
*   **缺点：** 依然存在梯度消失问题。
*   **现常用场景：** 循环神经网络 (RNN) 的内部控制。

### ReLU 系列（CNN 和通用 MLP 中广泛使用）

#### **ReLU (Rectified Linear Unit, 整流线性单元)**
*   **公式：** $f(x) = \max(0, x)$
*   **输出范围：** [0, +∞)
*   **优点：** 
    *   **计算极快：** 只是一个阈值判定。
    *   **缓解梯度消失：** 正区间梯度恒为 1。
    *   **稀疏激活性：** 让一部分神经元输出为 0，提高泛化能力。
*   **缺点：** **Dead ReLU 问题**（神经元“死亡”）。如果学习率过大，某些神经元可能永远不再被激活（输出一直为0）。

#### **Leaky ReLU (带泄露的 ReLU)**
*   **公式：** $f(x) = \max(\alpha x, x)$，其中 $\alpha$ 是一个很小的常数（如 0.01）。
*   **目的：** 解决 Dead ReLU 问题，给负区间留一点点“活路”。

### 现代大模型常用（Transformer / LLM）

#### **GeLU (Gaussian Error Linear Unit, 高斯误差线性单元)**
*   **设计动机：** ReLU 用 $0$ 作为硬阈值，负半轴的局部梯度为 0；如果某个神经元对训练样本持续产生负预激活，可能形成 Dead ReLU。GeLU 用标准正态分布的累积概率作为平滑门控比例，在 0 附近平滑过渡。
*   **精确定义：**

    $$GELU(x)=x\Phi(x)=xP(X\le x),\quad X\sim\mathcal{N}(0,1)$$

    其中 $\Phi(x)$ 是标准正态分布的累积分布函数。$x$ 很大时输出接近 $x$，$x$ 很小时输出接近 0，负区间尤其是 0 附近仍会保留少量负输出。
*   **工程近似：** 为降低 CDF 的计算成本，常使用 tanh 近似：

    $$GELU(x)\approx 0.5x\left(1+\tanh\left(\sqrt{\frac{2}{\pi}}\left(x+0.044715x^3\right)\right)\right)$$

*   **确定性门控：** 概率分布只提供 $\Phi(x)$ 的解释，标准 GeLU 实际计算的是确定函数 $x\Phi(x)$，不会像 Dropout 那样在每次前向传播中随机采样。
*   **与 ReLU 对比：** ReLU 计算简单，但在 $x=0$ 处有硬拐角并将所有负输入置零；GeLU 处处平滑可导，允许负区间的部分信号和梯度通过，但计算更复杂。平滑性有助于优化，不代表一定收敛更快或达到更高精度。
*   **应用与边界：** GeLU 常见于 [BERT](<../../02_大模型/模型细节/里程碑模型/BERT.md>)、GPT-2/3 等 Transformer 的 FFN。它没有全面取代 ReLU，也不是所有 Transformer 的固定选择；实际效果取决于模型结构、初始化和训练设置，LLaMA/Llama 2 等模型采用的是 SiLU 驱动的 SwiGLU。

#### **Swish / SiLU (Sigmoid Linear Unit)**
*   **公式：** $f(x) = x \cdot \text{Sigmoid}(x)$
*   **开发者：** Google。
*   **特点：** 无上界、有下界、平滑且非单调，在部分深层模型中可比 ReLU 表现更好。
*   **应用：** 常用在 EfficientNet 和一些 Llama 变体模型中。

#### **GLU / SwiGLU（门控前馈网络）**
*   **GLU：** Gated Linear Unit 将两路线性投影逐元素相乘，一路传递值，另一路经 Sigmoid 产生门控：

    $$GLU(X)=(XW_v+b_v)\odot\sigma(XW_g+b_g)$$

*   **SwiGLU：** 用 SiLU/Swish 替换 GLU 的 Sigmoid 门控，Transformer FFN 中常写为：

    $$SwiGLU(X)=\left(SiLU(XW_g)\odot XW_v\right)W_o$$

*   **概念边界：** GeLU、SiLU 是逐元素激活函数；GLU、SwiGLU 是包含多路线性投影、门控乘法和输出投影的 FFN 设计。说“模型使用 SwiGLU”不等于把一个普通激活函数直接替换成 SiLU。

### 输出层专用

#### **Softmax**
*   **公式：** $P_i = \frac{e^{x_i}}{\sum e^{x_j}}$
*   **特点：** 将一组向量转换为**概率分布**（所有输出之和等于 1）。
*   **场景：** **多分类任务**的最后一层。

### 总结：我该选哪一个？

1.  **初学者/通用场景：** 首选 **ReLU**，它简单且效果通常不错。
2.  **Transformer/LLM：** 按模型架构选择 **[GeLU](<#gelu-gaussian-error-linear-unit-高斯误差线性单元>)**、SiLU 或 SwiGLU，不能一概而论。
3.  **如果发现神经元大量死亡：** 尝试 **Leaky ReLU**。
4.  **二分类的最后一步：** 用 **Sigmoid**。
5.  **多分类的最后一步：** 用 **Softmax**。
6.  **循环神经网络 (RNN)：** 尝试 **Tanh**。

**金句：** 激活函数为神经网络引入非线性。ReLU 因简单高效而广泛用于 CNN 和 MLP；GeLU、SiLU 及其门控变体则常见于不同的 Transformer 架构。
## 面试应对

### 激活函数有什么作用？

回答思路：抓住“引入非线性、否则多层线性叠加仍等价于单层线性”这个本质，再顺带按演进列举 Sigmoid/Tanh、ReLU 系、GELU/SiLU 等代表。

回答模板：

激活函数为神经网络引入非线性，否则多层线性变换叠加后仍然等价于一个线性模型。常见激活函数包括 ReLU、GELU、SiLU、Tanh 和 Sigmoid。

### GeLU 是什么？

回答思路：抓住 $GELU(x)=x\Phi(x)$ 的定义，说明它用标准正态 CDF 对输入做确定性的平滑门控，是 ReLU 的平滑替代。

回答模板：

GeLU 是 Gaussian Error Linear Unit，定义为 $x\Phi(x)$，其中 $\Phi(x)$ 是标准正态分布的累积分布函数。它根据输入大小进行确定性的平滑门控，不会随机采样；与 ReLU 的硬截断相比，GeLU 在 0 附近更平滑，并保留少量负区间信号。

### GeLU 为什么适合 Transformer？

回答思路：说明平滑非线性和保留弱负信号对优化的作用，同时强调这是经验性架构选择，不能断言 GeLU 普遍更优。

回答模板：

GeLU 在整个区间平滑可导，而且不会把所有负输入直接置零，因此能在 Transformer 的前馈网络中提供平滑非线性并保留部分弱负信号。BERT、GPT-2/3 等模型采用了 GeLU，但它不是 Transformer 的唯一选择，具体效果仍取决于架构和训练设置。

### ReLU、GELU、SiLU 怎么取舍？

回答思路：对比 ReLU 的硬截断与 GeLU/SiLU 的平滑负区间，并区分 SiLU 激活函数和 SwiGLU 门控 FFN；说明选择还要看模型结构、初始化和框架[算子](<../../05_推理部署与系统/推理工程/算子.md>)支持。

回答模板：

ReLU 计算最简单，正输入保持不变、负输入直接置零，但可能出现 Dead ReLU。GELU 用标准正态 CDF 做确定性的平滑门控，SiLU 用 Sigmoid 做平滑门控，两者都允许负区间保留少量输出。GELU 常见于 BERT、GPT-2/3，SiLU 也常作为 SwiGLU 门控的一部分；选择时要结合模型架构、训练稳定性和算子支持。

### 激活函数有哪些风险？

回答思路：点明 Sigmoid/Tanh 深层易饱和致梯度消失、ReLU 有神经元死亡、复杂激活计算成本高，并补充大模型里还影响混合精度数值稳定性和算子融合效率。

回答模板：

Sigmoid/Tanh 在深层网络中容易饱和导致梯度变小；ReLU 可能出现神经元死亡；更复杂的激活函数计算成本略高。大模型里激活函数还会影响混合精度数值稳定性和算子融合效率。
