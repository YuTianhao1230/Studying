# 机器学习基础

本目录存放机器学习和深度学习的基础知识。分类依据是先建立数学、统计和传统机器学习的底层概念，再进入神经网络结构、特征表示、归一化、正则化等深度学习基础组件。

| 子目录 | 内容说明 |
| --- | --- |
| [数学与机器学习](<数学与机器学习/README.md>) | 数学基础、机器学习基础、统计推断、因果推断、相似度度量等内容。 |
| [深度学习基础](<深度学习基础/README.md>) | MLP、Feature Map、高阶特征、Normalization、正则化等深度学习基础概念。 |
| [概率与序列决策](<概率与序列决策/README.md>) | 马尔可夫链、HMM、概率图模型、高斯过程、MDP 与强化学习基础。 |
| [传统模型与表示学习](<传统模型与表示学习/README.md>) | 集成学习、核方法、异常检测、聚类降维、表征学习、学习范式与泛化。 |
| [优化、数据与实验方法](<优化、数据与实验方法/README.md>) | 训练优化诊断、数据泄漏与不平衡、概率校准和 A/B 实验方法。 |
| [笔试训练](<笔试训练/README.md>) | 数学与经典模型、深度学习、概率强化学习、数据实验和传统表示学习专项题集。 |

## 推导与计算入口

1. [数学基础](<数学与机器学习/数学基础.md>)：Softmax/交叉熵、两层网络反传、MLE/MAP 与 PCA。
2. [机器学习基础](<数学与机器学习/机器学习基础.md>)：LR、树与 Boosting、SVM、朴素贝叶斯、KMeans 和 GMM/EM。
3. [概率图模型与序列模型](<概率与序列决策/概率图模型与序列模型.md>)：马尔可夫链、HMM、贝叶斯网络、CRF 和高斯过程。
4. [强化学习基础](<概率与序列决策/强化学习基础.md>)：MDP、Bellman、TD、Q-learning 与策略梯度。
5. [传统模型与表示学习](<传统模型与表示学习/README.md>)：从集成方法到自监督、迁移和泛化。
6. [训练优化、数据质量与实验设计](<优化、数据与实验方法/训练优化、数据质量与实验设计.md>)：收敛诊断、数据切分、校准与实验结论。
7. [指标与统计计算](<../04_评测实验与数据质量/指标与统计计算.md>)：指标手算与抽样不确定性。
