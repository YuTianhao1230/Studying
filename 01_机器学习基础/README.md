# 机器学习基础

本目录回答“机器学习与深度学习中可跨任务复用的基础公式、概念和组件是什么”。内容从数学、统计和传统机器学习出发，再进入损失函数、激活函数、初始化、归一化、正则化和强化学习基础，为后续模型、训练和评测专题打地基。

## 内容边界

- 数学推导、通用损失、经典模型和神经网络基础组件放在这里。
- Attention、Transformer、LLM/VLM 等模型专属结构进入 [02_大模型](<../02_大模型/README.md>)。
- 优化器、分布式训练、SFT/DPO/PPO/GRPO 等参数更新方法进入 [03_训练优化与对齐](<../03_训练优化与对齐/README.md>)。
- 数据构造、质量治理、指标、统计与实验设计进入 [04_评测实验与数据质量](<../04_评测实验与数据质量/README.md>)。

## 推导与计算入口

1. [数学基础](<数学与机器学习/数学基础.md>)：Softmax/交叉熵、两层网络反传、MLE/MAP 与 PCA。
2. [机器学习基础](<数学与机器学习/机器学习基础.md>)：LR、树与 Boosting、SVM、朴素贝叶斯、KMeans 和 GMM/EM。
3. [概率图模型与序列模型](<概率与序列决策/概率图模型与序列模型.md>)：马尔可夫链、HMM、贝叶斯网络、CRF 和高斯过程。
4. [强化学习基础](<概率与序列决策/强化学习基础.md>)：MDP、Bellman、TD、Q-learning 与策略梯度。
5. [传统模型与表示学习](<传统模型与表示学习/README.md>)：从集成方法到自监督、迁移和泛化。
6. [参数初始化与数值稳定性](<深度学习基础/参数初始化与数值稳定性.md>)：Xavier/He、稳定 Softmax、LogSumExp 和融合交叉熵。
7. [指标与统计计算](<../04_评测实验与数据质量/指标与统计计算.md>)：指标手算与抽样不确定性。
