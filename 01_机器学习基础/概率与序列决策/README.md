# 概率与序列决策

本目录覆盖具有状态、时间依赖或长期回报的机器学习模型。学习顺序是先理解随机过程和隐变量，再学习序列决策。

本目录统一维护 MDP、值方法、策略梯度、GAE 和采样校正等强化学习基础；大模型后训练算法见 [PPO](<../../03_训练优化与对齐/后训练与对齐/PPO 近端策略优化.md#ppo-近端策略优化>)与 [GRPO](<../../03_训练优化与对齐/后训练与对齐/GRPO 组相对策略优化.md#grpo-组相对策略优化>)。
